## Abstract

## 摘要

In-database analytics is of great practical importance as it avoids the costly repeated loop data scientists have to deal with on a daily basis: select features, export the data, convert data format, train models using an external tool, reimport the parameters. It is also a fertile ground of theoretically fundamental and challenging problems at the intersection of relational and statistical data models.

数据库内分析具有重大实践意义，它避免了数据科学家日常需要处理的昂贵重复循环：选择特征、导出数据、转换数据格式、使用外部工具训练模型、重新导入参数。这也是关系型数据模型与统计数据模型交叉领域中理论基础深厚且充满挑战的问题沃土。

This paper introduces a unified framework for training and evaluating a class of statistical learning models inside a relational database. This class includes ridge linear regression, polynomial regression, factorization machines, and principal component analysis. We show that, by synergizing key tools from relational database theory such as schema information, query structure, recent advances in query evaluation algorithms, and from linear algebra such as various tensor and matrix operations, one can formulate in-database learning problems and design efficient algorithms to solve them.

本文提出在关系数据库内训练和评估一类统计学习模型的统一框架。该类别包括岭线性回归、多项式回归、因子分解机和主成分分析。研究表明，通过协同利用关系数据库理论中的模式信息、查询结构、查询评估算法最新进展等关键工具，以及线性代数中的各类张量和矩阵运算，可以构建数据库内学习问题并设计高效求解算法。

The algorithms and models proposed in the paper have already been implemented and deployed in retail-planning and forecasting applications, with significant performance benefits over out-of-database solutions that require the costly data-export loop.

论文提出的算法模型已在零售规划与预测应用中落地实施，相比需要昂贵数据导出循环的库外解决方案展现出显著性能优势。

## 1 引言

Although both disciplines of databases and statistics occupy foundational roles for the emerging field of data science, they are largely seen as complementary. Most fundamental contributions made by statisticians and machine learning researchers are abstracted away from the underlying infrastructure for data management. However, there is undoubtedly clear value in tight integration of statistics and

尽管数据库与统计学这两门学科在数据科学这一新兴领域都扮演着基础性角色，但普遍认为它们具有互补性。统计学家和机器学习研究者做出的多数基础性贡献，都脱离了数据管理的底层基础设施。然而，将统计学与

database models and techniques. A prime example of such a tight integration is provided by in-database analytics, which is receiving an increasing interest in both academia and industry $\left\lbrack  {2,{34},{44}}\right\rbrack$ . This is motivated by the realization that in many practical cases data resides inside databases and bringing the analytics closer to the data saves non-trivial time usually spent on data import/export at the interface between database systems and statistical packages [30]. A complementary realization is that large chunks of statistical machine learning code can be expressed as relational queries and computed inside the database $\left\lbrack  {{19},{21},{35},{48}}\right\rbrack$ . In-database analytics problems naturally lend themselves to a systematic investigation using the toolbox of concepts and techniques developed by the database theorist, and by synergizing ideas from both relational and statistical data modeling. To solve optimization problems over relational data, one can exploit database schema information, functional dependencies, state-of-the-art query evaluation algorithms, and well-understood complexity analysis.

数据库模型及技术紧密集成显然具有重要价值。这种紧密集成的典型范例就是库内分析，该领域正日益受到学术界与工业界的关注$\left\lbrack  {2,{34},{44}}\right\rbrack$。其动因在于人们认识到：在许多实际场景中，数据本就存储在数据库内部，让分析更接近数据可以显著节省通常耗费在数据库系统与统计软件包接口处数据导入/导出上的时间[30]。另一个互补性认知是：大量统计机器学习代码可以表述为关系查询并在数据库内部执行$\left\lbrack  {{19},{21},{35},{48}}\right\rbrack$。库内分析问题天然适合运用数据库理论家开发的概念与技术工具箱进行系统研究，并通过融合关系型与统计型数据建模思想来解决。针对关系数据的优化问题，我们可以利用数据库模式信息、函数依赖、前沿查询评估算法以及成熟完备的复杂度分析。

Our conceptual contribution in this paper is the introduction of a unified in-database framework for training and evaluating a class of statistical learning models. This class, commonly used in retail-planning and forecasting applications [11], includes ridge linear regression, polynomial regression, factorization machines, classification, and principal component analysis.

本文的概念性贡献在于提出了一个统一的库内框架，用于训练和评估一类统计学习模型。这类模型常见于零售规划与预测应用[11]，包括岭线性回归、多项式回归、因子分解机、分类以及主成分分析。

In such applications, the training dataset is the result of a feature extraction query over the database. Typical databases include weekly sales data, promotions, and product descriptions. A retailer would like to compute a parameterized model, which can predict, for instance, the additional demand generated for a given product due to promotion. As is prevalent in practical machine learning, the models are trained using a first-order optimization algorithm such as batch or stochastic gradient descent, in part because their convergence rates are dimension-free (for well-behaved objectives). This is a crucial property given the high-dimensionality of our problem as elaborated next.

在此类应用中，训练数据集是对数据库执行特征提取查询的结果。典型数据库包含周销售数据、促销活动与产品描述。零售商希望计算参数化模型，用以预测例如某产品因促销产生的额外需求。正如当前机器学习实践中的普遍做法，这些模型采用一阶优化算法（如批量或随机梯度下降）进行训练，部分原因是其收敛速率与维度无关（对于性质良好的目标函数）。鉴于下文将阐述的问题高维特性，这一性质至关重要。

The main computational challenge posed by in-database analytics is the large number of records and of features in the training dataset. There are two types of features: continuous (quantitative) such as price and revenue; and categorical (qualitative) such as colors, cities, and countries. ${}^{1}$ While continuous features allow for aggregation over their domains, categorical features cannot be aggregated together. To accommodate the latter, the state-of-the-art approach is to one-hot encode their active domain: each value in the active domain of an attribute is encoded by an indicator vector whose dimension is the size of the domain. For instance, the colors in the domain $\{$ red,green,blue $\}$ can be represented by indicator vectors $\left\lbrack  {1,0,0}\right\rbrack$ for red, $\left\lbrack  {0,1,0}\right\rbrack$ for green,and $\left\lbrack  {0,0,1}\right\rbrack$ for blue. The one-hot encoding amounts to a relational representation of the training dataset with one new attribute per distinct category of each categorical feature and with wide tuples whose values are mostly 0 . This entails huge redundancy due to the presence of the many 0 values. The one-hot encoding also blurs the usual database-theory distinction between schema and data, since the schema can become as large as the input database.

库内分析面临的主要计算挑战来自训练数据集中海量的记录与特征。特征分为两类：连续型（定量）如价格与收入；类别型（定性）如颜色、城市与国家。${}^{1}$连续型特征允许在其定义域上聚合，而类别型特征则不能直接聚合。为处理后者，当前最先进的方法是对其活跃域进行独热编码：属性活跃域中的每个值用一个维度等于域大小的指示向量表示。例如颜色域$\{$红、绿、蓝$\}$可表示为$\left\lbrack  {1,0,0}\right\rbrack$代表红、$\left\lbrack  {0,1,0}\right\rbrack$代表绿、$\left\lbrack  {0,0,1}\right\rbrack$代表蓝的指示向量。独热编码相当于用关系型表示训练数据集——为每个类别型特征的每个不同类别新增一个属性，形成主要由0组成的宽元组。这因大量0值的存在导致巨大冗余。独热编码还模糊了数据库理论中模式与数据的常规区分，因为模式可能变得与输入数据库同样庞大。

Closely related to the computational challenge is a cultural challenge: the feasibility of in-database analytics is often called into question. In terms of pure algorithmic performance, why would an in-database optimization algorithm be more efficient than an out-of-database optimization implementation, given the widely available plethora of tools and techniques for the latter?

与计算挑战密切相关的是文化挑战：库内分析的可行性常受质疑。就纯算法性能而言，面对库外优化实现已有大量可用工具和技术，为何库内优化算法会更高效？

Our answer to these challenges is that, for a large class of feature extraction queries, it is possible to train a model in time sub-linear in the output size of the feature extraction query! More concretely, our approach entails three database-centric technical contributions.

我们的应对方案是：对于大量特征提取查询，模型训练时间可低于特征提取查询输出规模的线性阶！具体而言，我们的方法包含三项数据库核心技术贡献。

First, we exploit join dependencies and their factorization in the training dataset to asymptotically improve the per-iteration computation time of a gradient descent algorithm.

首先，利用训练数据中的连接依赖及其因子化特性，渐进式提升梯度下降算法单次迭代计算效率。

Second, we exploit functional dependencies present in the database to reduce the dimensionality of the underlying optimization problem by only optimizing for those parameters that functionally determine the others and by subsequently recovering the functionally determined parameters using their dependencies.

其次，通过数据库函数依赖关系降低优化问题维度——仅优化那些能函数决定其他参数的变量，再根据依赖关系推导被决定参数。

Third, we address the shortcomings of one-hot encoding by expressing the sum-product aggregates used to compute the gradient and point evaluation as functional aggregate queries (FAQs) [8]. The aggregates over continuous features are expressed as FAQs without free variables and their computation yields scalar values. In contrast, aggregates over categorical features originating from a set $S$ of database attributes are expressed as FAQs with free (i.e., group-by) variables $S$ . The tuples in the result of such FAQs are combinations of categorical values that occur in the database. The ensemble of FAQs defining the gradient form a sparse tensor representation and computation solution with lower space and time complexity than solutions based on one-hot encoding. In particular, the complexity of our end-to-end solution can be arbitrarily smaller than that of materializing the result of the feature extraction query.

第三，将用于计算梯度及点评估的和积聚合表达为函数聚合查询(FAQ)[8]，克服独热编码缺陷。连续特征的聚合查询无自由变量，计算结果为标量值；而源自属性集$S$的分类特征聚合查询则含自由(即分组)变量$S$，其结果元组为数据库中存在的分类值组合。构成梯度形式的FAQ集合形成稀疏张量表示方案，其时空复杂度低于独热编码方案。特别地，我们的端到端方案复杂度可能远低于物化特征提取查询结果的复杂度。

Related work. It has been recently acknowledged that database theory can effectively contribute to the arms race for in-database analytics [2]. Recent works highlight the potential of applying key database theory tools to this growing research of practical interest, e.g., the formal relational framework for classifier engineering [33] and in-database factorized learning of regression models with low data complexity [48].

相关工作。学界近期认识到数据库理论可为库内分析军备竞赛做出实质贡献[2]。最新研究强调将关键数据库理论工具应用于这一具有实际价值的研究领域，例如分类器工程的形式化关系框架[33]，以及具有低数据复杂度的库内因子化回归模型学习[48]。

Most related efforts in the database and distributed systems communities are on designing systems to support machine learning libraries or statistical packages on top of large-scale database architectures, e.g., MLLib [37] and DeepDist [38] on Spark [50], GLADE [45], TensorFlow [1], and SystemML [15, 31]. This approach relies on the expensive data export/import at the interface between the machine learning library process and the database system process: The feature extraction query is computed inside the database system, its result exported and imported into the data format of a machine learning library, where the model is learned. This approach is very expensive due to the import/export step and the unnecessary repetitions of data blocks in the query result as prescribed by the joins in the query. Our approach avoids these pitfalls. It differs from all these efforts in that it tightly integrates the analytics with the database query engine.

数据库与分布式系统领域的大多数相关研究聚焦于设计支持机器学习库或统计包的大规模数据库架构系统，例如基于Spark平台的MLLib[37]和DeepDist[38]、GLADE[45]、TensorFlow[1]以及SystemML[15,31]。这类方法依赖机器学习库进程与数据库系统进程间昂贵的数据导出/导入接口：特征提取查询在数据库系统内部计算后，其结果需导出并转换为机器学习库的数据格式才能进行模型训练。由于存在数据导入/导出步骤，以及查询连接操作导致的查询结果中数据块不必要的重复，这种方法效率低下。我们的方法规避了这些缺陷，其核心差异在于将分析过程与数据库查询引擎深度集成。

There are three lines of prior work closest to ours.

现有研究中与我们的工作最密切相关的可分为三类。

One line of work investigates the ability to express parts of analytical tasks within query languages. An important bulk of early work is on query languages with data mining, also called descriptive or backward-looking analytics, capabilities [17] and in-database data mining solutions, e.g., frequent itemsets [42] and association rule mining [10]. More recent work investigated how to (partly) express predictive (forward-looking) analytics, such as learning regression models and Naïve Bayes classification, together with the feature extraction query as a single optimized query with joins and sum-product aggregates [35, 48]. MADlib [30] casts analytics as user-defined aggregate functions (UDAFs) that can be used in SQL queries and executed inside PostgreSQL. These UDAFs remain black boxes for the underlying query engine, which has to compute the feature extraction query and delegate the UDAF computation on top of the query result to the MADLib's specialized code.

第一类研究探索在查询语言中表达分析任务的能力。早期重要成果集中在具备数据挖掘（亦称描述性或回溯性分析）功能的查询语言[17]，以及库内数据挖掘解决方案，如频繁项集[42]和关联规则挖掘[10]。近期研究则致力于（部分）实现预测性（前瞻性）分析，例如将回归模型和朴素贝叶斯分类的学习过程与特征提取查询整合为包含连接和求和-乘积聚合的单一优化查询[35,48]。MADlib[30]将分析任务建模为可在SQL查询中使用并在PostgreSQL内部执行的用户定义聚合函数(UDAFs)，但这些UDAFs对底层查询引擎仍是黑盒，引擎需先计算特征提取查询，再将UDAF计算委托给MADlib的专用代码处理查询结果。

A second line of work exploits join dependencies for efficient in-database analytics. Join dependencies form the basis of the theory of (generalized) hypertree decompositions [25] and factorized databases [41], with applications such as inference in probabilistic graphical models, CSP, SAT, and databases. In databases, they have been originally used as a tractability yardstick for Boolean conjunctive queries [25] and more recently for the computation and result representation of queries with free variables [41], with group-by aggregates $\left\lbrack  {8,{13}}\right\rbrack$ ,and with order-by clauses $\left\lbrack  {13}\right\rbrack$ . Our approach builds on earlier work that exploits join dependencies for learning linear regression models with continuous features [48]. Factorization machines [47] represent a regression model used for real-world analytics and that we investigate in this paper. In contrast to polynomial regression models, factorization machines factorize the space of model parameters to better capture data correlations. We further this idea by also factorizing the training dataset, which relies on join dependencies present in the data.

第二类研究利用连接依赖关系实现高效库内分析。连接依赖构成了（广义）超树分解理论[25]和因子化数据库[41]的基础，应用于概率图模型推理、CSP、SAT及数据库等领域。在数据库中，它们最初用作布尔连接查询的可处理性衡量标准[25]，近年则用于含自由变量查询的计算与结果表示[41]、分组聚合$\left\lbrack  {8,{13}}\right\rbrack$以及排序子句$\left\lbrack  {13}\right\rbrack$。我们的方法基于早期利用连接依赖学习连续特征线性回归模型的研究[48]。因子分解机[47]作为本文研究的现实分析用回归模型，相较于多项式回归模型，其通过参数空间因子分解更好地捕捉数据相关性。我们进一步提出训练数据集因子化方法，这依赖于数据中存在的连接依赖。

A third line of prior work uses functional dependencies (FDs) to avoid key-foreign key joins and reduce the number of features in Naïve Bayes classification and feature selection [36]. We consider the effect of FDs on the reparameterization of regression models, where a non-trivial development is on the effect of FDs on the model (non-linear) regularization function.

第三类研究利用函数依赖(FDs)避免主外键连接，减少朴素贝叶斯分类和特征选择中的特征数量[36]。我们探讨FDs对回归模型重参数化的影响，其中关键突破在于发现FDs对模型（非线性）正则化函数的作用机制。

Several state-of-the-art machine learning systems use a sparse representation of the input data to avoid redundancy introduced by one-hot encoding $\left\lbrack  {{20},{46}}\right\rbrack$ . In our setting,however,such systems require an additional data transformation step after the result of the feature extraction query is exported. This additional step is time consuming and makes the use of such systems very inefficient in many practical applications. In statistics and machine learning, there is a rich literature on learning with sparse and/or multilinear structures [29]. Such methods complement our framework and it would be of interest to leverage and adapt them to our setting.

当前多数先进机器学习系统采用输入数据的稀疏表示以避免独热编码$\left\lbrack  {{20},{46}}\right\rbrack$带来的冗余。但在我们的场景中，这类系统需要在特征提取查询结果导出后进行额外数据转换，这一步骤耗时且导致实际应用效率低下。统计学与机器学习领域存在大量关于稀疏/多线性结构学习的文献[29]，这些方法可与我们框架互补，值得探索如何将其适配至我们的体系。

Finally, there is a large collection of gradient-based methods proposed in the optimization literature. The description of our approach assumes batch gradient descent (BGD), though our insights are applicable to other methods, including Quasi-Newton algorithms. The main rationale for our choice is simplicity and good statistical properties. When combined with backtracking line search (as we do in this paper) or second-order gradient estimation (as in Quasi-Newton methods), BGD is guaranteed to converge to a minimum with linear asymptotic convergence rate. A naïve computation of the gradient requires a full pass over the data, which can be inefficient in large-scale analytics. A popular alternative is stochastic gradient descent (SGD), which estimates the gradient with a randomly selected mini-batch of training samples. The convergence of SGD, however, is noisy, requires careful setting of hyperparameters, and does not achieve the linear asymptotic convergence rate of BGD [16]. In our setting, the entire BGD execution can be arbitrarily faster than one SGD iteration over the result of the feature extraction query [5].

最终，优化文献中提出了大量基于梯度的方法。虽然我们的方法描述采用批量梯度下降法(BGD)，但我们的见解同样适用于包括拟牛顿算法在内的其他方法。选择BGD的主要考量在于其简洁性和优良的统计特性。当结合回溯线性搜索（如本文所用）或二阶梯度估计（如拟牛顿法）时，BGD能保证以线性渐近收敛速率收敛至最小值。梯度计算的原始实现需要完整遍历数据，在大规模分析中效率较低。常用替代方案是随机梯度下降法(SGD)，该方法通过随机选取小批量训练样本来估计梯度。然而SGD的收敛过程存在噪声，需要谨慎设置超参数，且无法达到BGD的线性渐近收敛速率[16]。在我们的设定中，完整的BGD执行过程可能比特征提取查询结果上的一次SGD迭代任意地快[5]。

## 2 问题表述

The goal of this section is to present a general optimization formulation encompassing a range of machine learning tasks, and then to lay out a versatile mathematical representation suitable for the in-database treatment of these tasks.

本节旨在提出一个涵盖多种机器学习任务的通用优化框架，继而建立适用于这些任务数据库内处理的通用数学表示形式。

Notational Convention. Bold face letters,e.g., $\mathbf{x},\mathbf{\theta },{\mathbf{x}}_{i},{\mathbf{\theta }}_{j}$ ,denote vectors or matrices,and normal face letters,e.g., ${x}_{i},{\theta }_{j},{\theta }_{i}^{\left( j\right) }$ ,denote scalars. For any positive integer $n,\left\lbrack  n\right\rbrack$ denotes the set $\{ 1,\ldots ,n\}$ . For any set $S$ and positive integer $k,\left( \begin{array}{l} S \\  k \end{array}\right)$ denotes the collection of all $k$ -subsets of $S$ . We use the following matrix operations: $\otimes$ denotes the Kronecker/tensor product; $\circ$ the Hadamard product; $\star$ the Khatri-Rao product; and $\langle  \cdot  , \cdot  \rangle$ denotes the Frobenius inner product of two matrices, which reduces to the vector inner product when the matrices have one column each.

符号约定。粗体字母（如$\mathbf{x},\mathbf{\theta },{\mathbf{x}}_{i},{\mathbf{\theta }}_{j}$）表示向量或矩阵，普通字体字母（如${x}_{i},{\theta }_{j},{\theta }_{i}^{\left( j\right) }$）表示标量。对任意正整数$n,\left\lbrack  n\right\rbrack$，表示集合$\{ 1,\ldots ,n\}$。对任意集合$S$与正整数$k,\left( \begin{array}{l} S \\  k \end{array}\right)$，表示$S$的所有$k$元子集构成的集合。我们使用以下矩阵运算：$\otimes$表示克罗内克/张量积；$\circ$表示哈达玛积；$\star$表示Khatri-Rao积；$\langle  \cdot  , \cdot  \rangle$表示两个矩阵的Frobenius内积，当矩阵均为单列时退化为向量内积。

Let $S$ be a finite set and Dom be any domain,then ${\mathbf{a}}_{S} = {\left( {a}_{j}\right) }_{j \in  S} \in$ ${\operatorname{Dom}}^{\left| S\right| }$ is a tuple indexed by $S$ ,whose components are in $\operatorname{Dom}$ . If $S$ and $T$ are disjoint,and given tuples ${\mathbf{a}}_{S}$ and ${\mathbf{a}}_{T}$ ,then tuple $\left( {{\mathbf{a}}_{S},{\mathbf{a}}_{T}}\right)$ is interpreted naturally as the tuple ${\mathbf{a}}_{S \cup  T}$ . The tuple ${\mathbf{0}}_{S}$ is the all-0 tuple indexed by $S$ . If $S \subseteq  G$ ,then the tuple ${\mathbf{1}}_{S \mid  G}$ is the characteristic vector of the subset $S$ ,i.e., ${1}_{S \mid  G}\left( v\right)  = 1$ if $v \in  S$ ,and 0 if $v \in  G - S$ .

设$S$为有限集且Dom为任意域，则${\mathbf{a}}_{S} = {\left( {a}_{j}\right) }_{j \in  S} \in$${\operatorname{Dom}}^{\left| S\right| }$表示以$S$为索引的元组，其分量属于$\operatorname{Dom}$。若$S$与$T$互斥，给定元组${\mathbf{a}}_{S}$和${\mathbf{a}}_{T}$，则元组$\left( {{\mathbf{a}}_{S},{\mathbf{a}}_{T}}\right)$自然解释为${\mathbf{a}}_{S \cup  T}$。${\mathbf{0}}_{S}$表示以$S$为索引的全零元组。若$S \subseteq  G$，则元组${\mathbf{1}}_{S \mid  G}$表示子集$S$的特征向量，即当$v \in  S$时${1}_{S \mid  G}\left( v\right)  = 1$=1，否则为0。

We make extensive use of basic concepts and results from matrix calculus summarized in Appendix A, where we also discuss a connection between tensor computation and the FAQ-framework [8].

我们广泛运用附录A总结的矩阵微积分基本概念与结论，其中还讨论了张量计算与FAQ框架[8]的关联性。

Feature Extraction Query. We consider the setting where the training dataset $D$ used as input to machine learning is the result of a natural join query $Q$ ,called feature extraction query,over a relational database $I$ . Each tuple $\left( {\mathbf{x},y}\right)  \in  D$ contains a scalar response (regressand) $y$ and a tuple $\mathbf{x}$ encoding features (regressors).

特征提取查询。我们考虑机器学习训练数据集$D$作为输入的情形，该数据集是关系数据库$I$上自然连接查询$Q$（称为特征提取查询）的结果。每条元组$\left( {\mathbf{x},y}\right)  \in  D$包含标量响应变量（因变量）$y$和编码特征（自变量）的元组$\mathbf{x}$。

We use standard notation for query hypergraphs. Let $\mathcal{H} =$ (V,E)denote the hypergraph of the query $Q$ ,where $\mathcal{V}$ is the set of variables occurring in $Q$ and $\mathcal{E}$ is the set of hyperedges with one hyperedge per set of variables in a relation symbol $R$ in the body of $Q$ . We denote by $V \subseteq  \mathcal{V}$ the subset of variables selected as features,and let $n = \left| V\right|$ . The features in $V$ corresponding to qualitative attributes are called categorical, while those corresponding to quantitative attributes are continuous. Let $N$ be the size of the largest input relation $R$ in $Q$ .

我们采用标准符号表示查询超图。设$\mathcal{H} =$(V,E)表示查询$Q$的超图，其中$\mathcal{V}$是$Q$中出现的变量集合，$\mathcal{E}$是超边集合，每个超边对应$Q$主体中关系符号$R$内的一组变量。用$V \subseteq  \mathcal{V}$表示被选为特征的变量子集，$n = \left| V\right|$表示其余变量。$V$中对应定性属性的特征称为分类特征，对应定量属性的则为连续特征。设$N$为$Q$中最大输入关系$R$的规模。

### 2.1 Formulation with continuous features

### 2.1 连续特征建模

Let $m \geq  n$ be an integer. The feature map $h : {\mathbb{R}}^{n} \rightarrow  {\mathbb{R}}^{m}$ transforms the raw input vector $\mathbf{x} \in  {\mathbb{R}}^{n}$ into an $m$ -vector of "monomial features" $h\left( \mathbf{x}\right)  = {\left( {h}_{j}\left( \mathbf{x}\right) \right) }_{j \in  \left\lbrack  m\right\rbrack  }$ . Each component ${h}_{j}$ is a multivariate monomial designed to capture the interactions among dimensions of input $\mathbf{x}$ . In particular,we write ${h}_{j}\left( \mathbf{x}\right)  \mathrel{\text{:=}} \mathop{\prod }\limits_{{i \in  \left\lbrack  n\right\rbrack  }}{x}_{i}^{{a}_{j}\left( i\right) }$ ,where degree ${a}_{j}\left( i\right)$ represents the level of participation of input dimension $i$ in the $j$ -th monomial feature. Let $p$ be the number of parameters $\mathbf{\theta } =$ $\left( {{\theta }_{1},\ldots ,{\theta }_{p}}\right)  \in  {\mathbb{R}}^{p}$ ,which produce the coefficients associated with features $h$ via parameter map $g : {\mathbb{R}}^{p} \rightarrow  {\mathbb{R}}^{m},g\left( \theta \right)  = {\left( {g}_{j}\left( \theta \right) \right) }_{j \in  \left\lbrack  m\right\rbrack  }$ . Each component ${g}_{j}$ is a multivariate polynomial of $\theta$ .

设$m \geq  n$为整数。特征映射$h : {\mathbb{R}}^{n} \rightarrow  {\mathbb{R}}^{m}$将原始输入向量$\mathbf{x} \in  {\mathbb{R}}^{n}$转换为$m$维"单项式特征"向量$h\left( \mathbf{x}\right)  = {\left( {h}_{j}\left( \mathbf{x}\right) \right) }_{j \in  \left\lbrack  m\right\rbrack  }$。每个分量${h}_{j}$都是多元单项式，用于捕捉输入$\mathbf{x}$各维度间的交互作用。具体表示为${h}_{j}\left( \mathbf{x}\right)  \mathrel{\text{:=}} \mathop{\prod }\limits_{{i \in  \left\lbrack  n\right\rbrack  }}{x}_{i}^{{a}_{j}\left( i\right) }$，其中次数${a}_{j}\left( i\right)$表示输入维度$i$在第$j$个单项式特征中的参与程度。设$p$为参数数量$\mathbf{\theta } =$$\left( {{\theta }_{1},\ldots ,{\theta }_{p}}\right)  \in  {\mathbb{R}}^{p}$，这些参数通过参数映射$g : {\mathbb{R}}^{p} \rightarrow  {\mathbb{R}}^{m},g\left( \theta \right)  = {\left( {g}_{j}\left( \theta \right) \right) }_{j \in  \left\lbrack  m\right\rbrack  }$生成与特征$h$关联的系数。每个分量${g}_{j}$都是$\theta$的多元多项式。

A large number of machine learning tasks learn a functional quantity of the form $\langle g\left( \mathbf{\theta }\right) ,h\left( \mathbf{x}\right) \rangle$ ,where the parameters $\mathbf{\theta }$ are obtained by solving $\mathop{\min }\limits_{\mathbf{\theta }}J\left( \mathbf{\theta }\right)$ with

$$
J\left( \mathbf{\theta }\right)  = \mathop{\sum }\limits_{{\left( {\mathbf{x},y}\right)  \in  D}}\mathcal{L}\left( {\langle g\left( \mathbf{\theta }\right) ,h\left( \mathbf{x}\right) \rangle ,y}\right)  + \Omega \left( \mathbf{\theta }\right) . \tag{1}

其中$\sum  \mathrel{\text{:=}} \frac{1}{\left| D\right| }\mathop{\sum }\limits_{{\mathbf{x} \in  D}}{\mathbf{{xx}}}^{\top }$为给定数据的（经验）相关矩阵。虽然不存在响应变量/类别标签$y$，但在上述迭代的每次循环中，对于固定$\lambda$，存在作用于特征向量$h\left( \mathbf{x}\right)$与参数向量$g\left( \mathbf{\theta }\right)$的损失函数$\mathcal{L}$及正则化项$\Omega$。具体而言，我们采用Frobenius内积，此时$h\left( \mathbf{x}\right)  = \sum  \in  {\mathbb{R}}^{p \times  p}$，$g\left( \mathbf{\theta }\right)  = \mathbf{\theta } \otimes  \mathbf{\theta } \in  {\mathbb{R}}^{p \times  p},\mathcal{L} = \langle g\left( \mathbf{\theta }\right) ,h\left( \mathbf{x}\right) {\rangle }_{F}$。此外，$\Omega \left( \mathbf{\theta }\right)  = \lambda \left( {\parallel \mathbf{\theta }{\parallel }^{2} - 1}\right)$。

### 2.2 Categorical features

### 2.2 类别型特征

The active domain of a categorical feature/variable consists of a set of possible values or categories. For example, vietnam, england, and usa are possible categories of the categorical feature country. Categorical features constitute the vast majority (up to 99%) of features we observed in our clients' machine learning applications.

类别型特征/变量的有效域由一组可能取值（即类别）构成。例如，vietnam、england和usa是类别型特征country的可能取值。在我们客户端的机器学习应用中，类别型特征占比极高（可达99%）。

It is common practice to one-hot encode categorical variables [28]. Whereas a continuous variable such as salary is mapped to a scalar value ${x}_{\text{salary }}$ ,a categorical variable such as country is mapped to an indicator vector ${\mathbf{x}}_{\text{country }} -$ a vector of binary values indicating the category that the variable takes on. For example, if the active domain of country consists of vietnam, england, and usa, then ${\mathbf{x}}_{\text{country }} = \left\lbrack  {{x}_{\text{vietnam }},{x}_{\text{england }},{x}_{\text{usa }}}\right\rbrack   \in  \{ 0,1{\} }^{3}$ . If a tuple in the training dataset has country $=$ "england",then ${\mathbf{x}}_{\text{country }} = \left\lbrack  {0,1,0}\right\rbrack$ for that tuple.

常规做法是对类别型变量进行独热编码[28]。连续变量（如salary）被映射为标量值${x}_{\text{salary }}$，而类别型变量（如country）则被映射为指示向量${\mathbf{x}}_{\text{country }} -$——该二进制向量用于标识变量所属类别。例如，若country的有效域包含vietnam、england和usa，则${\mathbf{x}}_{\text{country }} = \left\lbrack  {{x}_{\text{vietnam }},{x}_{\text{england }},{x}_{\text{usa }}}\right\rbrack   \in  \{ 0,1{\} }^{3}$。若训练数据集中某条记录的country$=$值为"england"，则该记录的对应编码为${\mathbf{x}}_{\text{country }} = \left\lbrack  {0,1,0}\right\rbrack$。

In general,the feature vector $\mathbf{x}$ in a tuple $\left( {\mathbf{x},y}\right)  \in  D$ has the form $\mathbf{x} = {\left( {\mathbf{x}}_{c}\right) }_{c \in  V}$ ,where each component ${\mathbf{x}}_{c}$ is an indicator vector if $c$ is a categorical variable and a scalar otherwise. Similarly,each component of the parameter vector $\mathbf{\theta }$ becomes a matrix (or a vector if the matrix has one column).

一般而言，元组$\left( {\mathbf{x},y}\right)  \in  D$中的特征向量$\mathbf{x}$具有$\mathbf{x} = {\left( {\mathbf{x}}_{c}\right) }_{c \in  V}$的形式，其中每个分量${\mathbf{x}}_{c}$当$c$为分类变量时是指示向量，否则为标量。类似地，参数向量$\mathbf{\theta }$的每个分量将变为矩阵（若矩阵仅有一列则为向量）。

### 2.3 Tensor product representation

### 2.3 张量积表示

We accommodate both continuous and categorical features in our problem formulation (2) by replacing arithmetic product by tensor product in the component functions of the parameter map $g$ and the feature map $h$ . Specifically,monomials ${h}_{j}$ now take the form

我们通过将参数映射$g$和特征映射$h$的组件函数中的算术积替换为张量积，在问题表述(2)中同时容纳连续型和分类特征。具体而言，单项式${h}_{j}$现在呈现如下形式：

$$
{h}_{j}\left( \mathbf{x}\right)  = {\bigotimes }_{f \in  V}{\mathbf{x}}_{f}^{\otimes {a}_{j}\left( f\right) } \tag{3}
$$

with degree vector ${\mathbf{a}}_{j} = {\left( {a}_{j}\left( f\right) \right) }_{f \in  V} \in  {\mathbb{N}}^{n}$ . For each $j \in  \left\lbrack  m\right\rbrack$ ,the set ${V}_{j} \mathrel{\text{:=}} \left\{  {f \in  V \mid  {a}_{j}\left( f\right)  > 0}\right\}$ consists of features that participate in the interaction captured by the (hyper-) monomial ${h}_{j}$ . Let $C \subseteq  V$ denote the set of categorical variables and ${C}_{j} \mathrel{\text{:=}} C \cap  {V}_{j}$ the subset of categorical variables in ${V}_{j}$ . For $f \in  {C}_{j},{h}_{j}$ represents $\mathop{\prod }\limits_{{f \in  {C}_{j}}}\left| {{\pi }_{f}\left( D\right) }\right|$ many monomials, one for each combination of the categories, where ${\pi }_{f}\left( D\right)$ denotes the projection of $D$ onto variable $f$ . Due to one-hot encoding,each element in the vector ${\mathbf{x}}_{f}$ for a categorical variable $f$ is either 0 or 1,and ${\mathbf{x}}_{f}^{{a}_{j}\left( f\right) } = {\mathbf{x}}_{f}$ for ${a}_{j}\left( f\right)  > 0$ . Hence, ${h}_{j}$ can be simplified as follows:

其中度向量为${\mathbf{a}}_{j} = {\left( {a}_{j}\left( f\right) \right) }_{f \in  V} \in  {\mathbb{N}}^{n}$。对于每个$j \in  \left\lbrack  m\right\rbrack$，集合${V}_{j} \mathrel{\text{:=}} \left\{  {f \in  V \mid  {a}_{j}\left( f\right)  > 0}\right\}$包含参与由（超）单项式${h}_{j}$捕获的交互作用的特征。令$C \subseteq  V$表示分类变量集合，${C}_{j} \mathrel{\text{:=}} C \cap  {V}_{j}$表示${V}_{j}$中分类变量的子集。对于$f \in  {C}_{j},{h}_{j}$代表$\mathop{\prod }\limits_{{f \in  {C}_{j}}}\left| {{\pi }_{f}\left( D\right) }\right|$个单项式，每个对应类别组合，其中${\pi }_{f}\left( D\right)$表示$D$在变量$f$上的投影。由于独热编码，分类变量$f$的向量${\mathbf{x}}_{f}$中每个元素非0即1，且当${a}_{j}\left( f\right)  > 0$时${\mathbf{x}}_{f}^{{a}_{j}\left( f\right) } = {\mathbf{x}}_{f}$。因此，${h}_{j}$可简化为：

$$
{h}_{j}\left( \mathbf{x}\right)  = \mathop{\prod }\limits_{{f \in  {V}_{j} - {C}_{j}}}{x}_{f}^{{a}_{j}\left( f\right) } \cdot  {\bigotimes }_{f \in  {C}_{j}}{\mathbf{x}}_{f}. \tag{4}
$$

Note that we use ${x}_{f}$ instead of boldface ${\mathbf{x}}_{f}$ since each variable $f \in  {V}_{j} - {C}_{j}$ is continuous.

注意我们使用${x}_{f}$而非粗体${\mathbf{x}}_{f}$，因为每个变量$f \in  {V}_{j} - {C}_{j}$都是连续型。

## 3 FACTORIZED OPTIMIZATION

## 3 分解优化

In this section we introduce our solution to learning statistical models for the setting of square loss function $J\left( \mathbf{\theta }\right)$ and ${\ell }_{2}$ -norm as in (2). We use a gradient-based optimization algorithm that employs the first-order gradient information to optimize the loss function $J\left( \mathbf{\theta }\right)$ . It repeatedly updates the parameters $\mathbf{\theta }$ by some step size $\alpha$ in the direction of the gradient $\nabla J\left( \mathbf{\theta }\right)$ until convergence. To guarantee convergence,it uses backtracking line search to ensure that $\alpha$ is sufficiently small to decrease the loss for each step. Each update step requires two computations: (1) Point evaluation: Given $\mathbf{\theta }$ ,compute the scalar $J\left( \mathbf{\theta }\right)$ ; and (2) Gradient computation: Given $\mathbf{\theta }$ ,compute the vector $\nabla J\left( \mathbf{\theta }\right)$ . In particular,we use the batch gradient descent (BGD) algorithm with the Armijo line search condition and the Barzilai-Borwein step size adjustment $\left\lbrack  {{14},{22}}\right\rbrack$ ,as depicted in Algorithm 1. Quasi-Newton optimization algorithms (e.g., L-BFGS) and other common line search conditions are also applicable in our framework. We refer the reader to the excellent review article [24] for more details on fast implementations of the gradient-descent method.

本节介绍针对平方损失函数$J\left( \mathbf{\theta }\right)$和(2)式中${\ell }_{2}$-范数场景的统计模型学习方案。我们采用基于梯度的优化算法，利用一阶梯度信息优化损失函数$J\left( \mathbf{\theta }\right)$。该算法沿梯度方向$\nabla J\left( \mathbf{\theta }\right)$以步长$\alpha$反复更新参数$\mathbf{\theta }$直至收敛。为确保收敛性，采用回溯线性搜索保证$\alpha$步长足够小以实现每步损失下降。每次更新需执行两项计算：(1)点评估：给定$\mathbf{\theta }$计算标量$J\left( \mathbf{\theta }\right)$；(2)梯度计算：给定$\mathbf{\theta }$计算向量$\nabla J\left( \mathbf{\theta }\right)$。具体实现采用带Armijo线性搜索条件和Barzilai-Borwein步长调整$\left\lbrack  {{14},{22}}\right\rbrack$的批量梯度下降算法(BGD)，如算法1所示。拟牛顿优化算法（如L-BFGS）及其他常见线性搜索条件同样适用于本框架。关于梯度下降法的快速实现细节，建议参阅权威综述文章[24]。

### 3.1 Continuous features

### 3.1 连续特征

To illustrate the main idea, we first consider the case without categorical features. We rewrite (2) to factor out the data-dependent part of the point evaluation and gradient computation. Recall that, for $j \in  \left\lbrack  m\right\rbrack  ,{h}_{j}$ denotes the $j$ th component function of the vector-valued function $h$ ,and ${h}_{j}$ is a multivariate monomial in $\mathbf{x}$ .

为阐明核心思想，我们首先考虑不含分类特征的情况。将式(2)重写以分解出点评估与梯度计算中数据相关的部分。需注意，$j \in  \left\lbrack  m\right\rbrack  ,{h}_{j}$表示向量值函数$h$的第$j$个分量函数，而${h}_{j}$是$\mathbf{x}$中的多元单项式。

Theorem 3.1. Let $J\left( \theta \right)$ be the function in (2). Define the matrix $\sum  = {\left( {\sigma }_{ij}\right) }_{i,j \in  \left\lbrack  m\right\rbrack  }$ ,the vector $\mathbf{c} = {\left( {c}_{i}\right) }_{i \in  \left\lbrack  m\right\rbrack  }$ ,and the scalar ${s}_{Y}$ by

$$
\sum  = \frac{1}{\left| D\right| }\mathop{\sum }\limits_{{\left( {\mathbf{x},y}\right)  \in  D}}h\left( \mathbf{x}\right) h{\left( \mathbf{x}\right) }^{\top } \tag{8}
$$

$$
\mathbf{c} = \frac{1}{\left| D\right| }\mathop{\sum }\limits_{{\left( {\mathbf{x},y}\right)  \in  D}}y \cdot  h\left( \mathbf{x}\right)  \tag{9}
$$

$$
{s}_{Y} = \frac{1}{\left| D\right| }\mathop{\sum }\limits_{{\left( {\mathbf{x},y}\right)  \in  D}}{y}^{2}. \tag{10}
$$

Then,

则有：

$$
J\left( \mathbf{\theta }\right)  = \frac{1}{2}g{\left( \mathbf{\theta }\right) }^{\top }{\sum g}\left( \mathbf{\theta }\right)  - \langle g\left( \mathbf{\theta }\right) ,\mathbf{c}\rangle  + \frac{{s}_{Y}}{2} + \frac{\lambda }{2}\parallel \mathbf{\theta }{\parallel }^{2} \tag{11}
$$

$$
\nabla J\left( \mathbf{\theta }\right)  = \frac{\partial g{\left( \mathbf{\theta }\right) }^{\top }}{\partial \mathbf{\theta }}{\sum g}\left( \mathbf{\theta }\right)  - \frac{\partial g{\left( \mathbf{\theta }\right) }^{\top }}{\partial \mathbf{\theta }}\mathbf{c} + \lambda \mathbf{\theta }. \tag{12}
$$

Note that $\frac{\partial g{\left( \theta \right) }^{\top }}{\partial \theta }$ is a $p \times  m$ matrix,and $\sum$ is an $m \times  m$ matrix. Statistically, $\sum$ is related to the covariance matrix, $\mathbf{c}$ to the correlation between the response and the regressors,and ${s}_{Y}$ to the empirical second moment of the response variable. Theorem 3.1 allows us to compute the two key steps of BGD without scanning through the data again,because the quantities $\left( {\sum ,\mathbf{c},{s}_{Y}}\right)$ can be computed efficiently in a preprocessing step inside the database as aggregates over the query $Q$ . We shall elaborate on this point further in Section 3.3.

注意$\frac{\partial g{\left( \theta \right) }^{\top }}{\partial \theta }$是$p \times  m$阶矩阵，$\sum$为$m \times  m$阶矩阵。统计意义上，$\sum$与协方差矩阵相关，$\mathbf{c}$对应响应变量与回归量的相关性，${s}_{Y}$则关联响应变量的经验二阶矩。定理3.1使得我们无需重新遍历数据即可计算BGD的两个关键步骤，因为量$\left( {\sum ,\mathbf{c},{s}_{Y}}\right)$可作为查询$Q$的聚合结果在数据库预处理阶段高效计算。第3.3节将对此进行详细阐述。

$$

$$

Let $\mathbf{d} = \nabla J\left( \mathbf{\theta }\right)$ . Then,

Armijo条件$J\left( {\mathbf{\theta } - \alpha \mathbf{d}}\right)  \geq  J\left( \mathbf{\theta }\right)  - \frac{\alpha }{2}\parallel \mathbf{d}{\parallel }_{2}^{2}$可表示为：

$$
\alpha {\mathbf{\theta }}^{\top }\sum \mathbf{d} - \frac{{\alpha }^{2}}{2}{\mathbf{d}}^{\top }\sum \mathbf{d} - \alpha \langle \mathbf{c},\mathbf{d}\rangle  + {\lambda \alpha }\langle \mathbf{\theta },\mathbf{d}\rangle  \leq  \frac{\alpha }{2}\left( {{\lambda \alpha } + 1}\right) \parallel \mathbf{d}{\parallel }_{2}^{2} \tag{16}
$$

The significance of (16) is as follows. In a typical iteration of BGD,we have to backtrack a few times (say $t$ times) for each value of $\alpha$ . If we were to recompute $J\left( {\mathbf{\theta } - \alpha \mathbf{d}}\right)$ using (13) each time,then the runtime of Armijo backtracking search is $O\left( {t{m}^{2}}\right)$ ,even after we have already computed $\mathbf{d}$ and $J\left( \mathbf{\theta }\right)$ . Now,using (16),we can compute in advance the following quantities (in this order): $\mathbf{d},\parallel \mathbf{\theta }{\parallel }_{2}^{2}$ , $\sum \mathbf{d},\langle \mathbf{c},\mathbf{d}\rangle ,\langle \mathbf{\theta },\mathbf{d}\rangle ,{\mathbf{d}}^{\top }\sum \mathbf{d},{\mathbf{\theta }}^{\top }\sum \mathbf{d}$ . Then,each check for inequality (16) can be done in $O\left( 1\right)$ -time,for a total of $O\left( {{m}^{2} + t}\right)$ -times. Once we have determined the step size $\alpha$ ,(15) allows us to compute the next gradient (i.e.,the next $\mathbf{d}$ ) in $O\left( m\right)$ ,because we have already computed $\sum \mathbf{d}$ for line search.

式(16)的意义如下：在BGD的典型迭代中，我们需要对每个$\alpha$值进行数次回溯（例如$t$次）。若每次都用式(13)重新计算$J\left( {\mathbf{\theta } - \alpha \mathbf{d}}\right)$，则即使已计算出$\mathbf{d}$和$J\left( \mathbf{\theta }\right)$，Armijo回溯搜索的时间复杂度仍为$O\left( {t{m}^{2}}\right)$。现在利用式(16)，我们可以预先计算以下量（按此顺序）：$\mathbf{d},\parallel \mathbf{\theta }{\parallel }_{2}^{2}$、$\sum \mathbf{d},\langle \mathbf{c},\mathbf{d}\rangle ,\langle \mathbf{\theta },\mathbf{d}\rangle ,{\mathbf{d}}^{\top }\sum \mathbf{d},{\mathbf{\theta }}^{\top }\sum \mathbf{d}$。这样每次检验不等式(16)只需$O\left( 1\right)$时间，共需检验$O\left( {{m}^{2} + t}\right)$次。一旦确定步长$\alpha$，通过式(15)我们可在$O\left( m\right)$时间内计算下一个梯度（即下一个$\mathbf{d}$），因为线搜索所需的$\sum \mathbf{d}$已预先计算完成。

To implement BGD, we need to compute four quantities efficiently: the covariance matrix $\sum$ in (8),the correlation vector $\mathbf{c}$ in (9), point evaluation in (11), and the gradient in (12). The covariance matrix and the correlation vector only have to be computed once in a pre-processing step. The gradient is computed at every iteration, which includes several point evaluations as we perform line search. ${}^{2}$ We do not need to compute the second moment ${s}_{Y}$ because optimizing $J\left( \mathbf{\theta }\right)$ is the same as optimizing $J\left( \mathbf{\theta }\right)  - {s}_{Y}$ . Before describing how those four quantities can be computed efficiently, we discuss how we deal with categorical features.

实现BGD需要高效计算四个量：式(8)中的协方差矩阵$\sum$、式(9)中的相关向量$\mathbf{c}$、式(11)的点评估值，以及式(12)的梯度。协方差矩阵和相关向量只需在预处理阶段计算一次。梯度在每次迭代时计算，其中包含线搜索过程中的多次点评估。${}^{2}$我们无需计算二阶矩${s}_{Y}$，因为优化$J\left( \mathbf{\theta }\right)$等价于优化$J\left( \mathbf{\theta }\right)  - {s}_{Y}$。在说明这四个量的高效计算方法前，我们先讨论如何处理类别特征。

## 4 FD-AWARE OPTIMIZATION

## 4 函数依赖感知优化

In this section, we show how to exploit functional dependencies among variables to reduce the dimensionality of the optimization problem by eliminating functionally determined variables and re-parameterizing the model. We compute the quantities $\left( {\sum ,\mathrm{c}}\right)$ on the subset of features that are not functionally determined, and then solve the lower-dimensional optimization problem. Finally, we recover the parameters in the original space in closed form. Exploiting functional dependencies drastically reduces the computation time for $\left( {\sum ,\mathbf{c}}\right)$ and the gradient.

本节阐述如何利用变量间的函数依赖关系，通过消除函数确定变量和模型重参数化来降低优化问题的维度。我们首先在非函数确定的特征子集上计算$\left( {\sum ,\mathrm{c}}\right)$量，然后求解降维后的优化问题，最后以闭式解恢复原始空间的参数。利用函数依赖可显著降低$\left( {\sum ,\mathbf{c}}\right)$和梯度的计算时间。

### 4.2 Functional dependencies (FDs)

### 4.2 函数依赖(FDs)

Composite FDs lead to more complex identities. For instance, the FD (guest,hotel,date) $\rightarrow$ room leads to the identity ${x}_{\text{room }} =$ $\sum {x}_{\text{guest }}{x}_{\text{hotel }}{x}_{\text{date }}$ . Let $R$ be a relation on attributes guest,hotel,date,and room,encoding this dependency,i.e., $R$ has a compound key (guest,hotel,date). Then,corresponding to $R$ there is a matrix $\mathbf{R}$ of dimension ${N}_{\text{room }} \times  {N}_{\text{guest }} \cdot  {N}_{\text{hotel }} \cdot  {N}_{\text{date }}$ for which ${\mathbf{x}}_{\text{room }} = \mathbf{R}\left( {{\mathbf{x}}_{\text{guest }} \otimes  {\mathbf{x}}_{\text{hotel }} \otimes  {\mathbf{x}}_{\text{date }}}\right)$ . Our results can be extended to the case of composite FDs, yet with a great notational burden; for the sake of clarity, we only state the results for simple FDs.

复合函数依赖会导致更复杂的恒等式。例如FD（客户，酒店，日期）$\rightarrow$房间会生成恒等式${x}_{\text{room }} =$$\sum {x}_{\text{guest }}{x}_{\text{hotel }}{x}_{\text{date }}$。设$R$是包含客户、酒店、日期和房间属性的关系，编码该依赖关系（即$R$具有复合主键（客户，酒店，日期））。对应于$R$存在维度为${N}_{\text{room }} \times  {N}_{\text{guest }} \cdot  {N}_{\text{hotel }} \cdot  {N}_{\text{date }}$的矩阵$\mathbf{R}$，满足${\mathbf{x}}_{\text{room }} = \mathbf{R}\left( {{\mathbf{x}}_{\text{guest }} \otimes  {\mathbf{x}}_{\text{hotel }} \otimes  {\mathbf{x}}_{\text{date }}}\right)$。我们的结果可推广至复合FD情形，但会显著增加符号复杂度；为清晰起见，本文仅阐述简单FD的结果。

Definition 1. An FD is simple if its left-hand side is one variable. Let a query $Q$ in which there are $k$ disjoint groups ${G}_{1},\ldots ,{G}_{k}$ of features,among other features. Example 13. 示例13. 在零售商客户的典型特征提取查询中，除其他特征外还存在$k = 3$个分组：第一组包含周$\rightarrow$月$\rightarrow$季$\rightarrow$年，因此${f}_{1}$$=$周且${S}_{1} = \{$月、季、年$\}$；第二组中${f}_{2}$$=$商品SKU且${S}_{2} = \{$类型、颜色、尺寸等$\}$（较大分组）；第三组${f}_{3} =$门店且${S}_{3} = \{$城市、国家、地区、大洲$\}$。

### 4.5 Linear algebra with database queries

### 4.5 基于数据库查询的线性代数运算

To apply the above results, we need to solve several computational primitives. The first primitive is to compute the matrix inverse ${\mathbf{B}}_{T,q}^{-1}$ and its product with another vector. This task can be done by either explicitly computing the inverse, or computing the Cholesky decomposition of the matrix ${\mathbf{B}}_{T,q}$ . We next explain how both of these tasks can be done using database queries.

为应用上述结果，需解决若干计算原语。首要原语是计算矩阵逆${\mathbf{B}}_{T,q}^{-1}$及其与向量的乘积。该任务可通过显式计算逆矩阵，或计算矩阵${\mathbf{B}}_{T,q}$的Cholesky分解实现。下文将阐述如何通过数据库查询完成这两类任务。

Maintaining the matrix inverse with rank-1 updates. Using Sherman-Morrison-Woodbury formula [4, 27], we can incrementally compute the inverse of the matrix $\mathbf{I} + \mathop{\sum }\limits_{{c \in  {G}_{i}}}{\mathbf{R}}_{c}^{\top }{\mathbf{R}}_{c}$ as follows. Let $S \subset  {G}_{i}$ be some subset and suppose we have already computed the inverse for ${\mathbf{M}}_{S} = \mathbf{I} + \mathop{\sum }\limits_{{s \in  S}}{\mathbf{R}}_{s}^{\top }{\mathbf{R}}_{s}$ . We now explain how to compute the inverse for ${\mathbf{M}}_{S\cup \{ c\} } = \mathbf{I} + \mathop{\sum }\limits_{{s \in  S\cup \{ c\} }}{\mathbf{R}}_{s}^{\top }{\mathbf{R}}_{s}$ . For concreteness, let the matrix ${\mathbf{R}}_{c}$ map city to country. For each country country, let ${\mathbf{e}}_{\text{country }}$ denote the 01-vector where there is a 1 for each city the country has. For example, ${\mathbf{e}}_{\text{cuba }} = {\left\lbrack  \begin{array}{lllll} 1 & 1 & 0 & 0 & 0 \end{array}\right\rbrack  }^{\top }$ . Then, ${\mathbf{R}}_{c}^{\top }{\mathbf{R}}_{c} =$ $\mathop{\sum }\limits_{\text{country }}{\mathbf{e}}_{\text{country }}^{\top }{\mathbf{e}}_{\text{country }}^{\top }$ . And thus,starting with ${\mathbf{M}}_{S}$ ,we apply the Sherman-Morrison-Woodbury formula for each country, such as:

利用秩-1更新维护矩阵逆。通过Sherman-Morrison-Woodbury公式[4,27]，我们可以增量计算矩阵$\mathbf{I} + \mathop{\sum }\limits_{{c \in  {G}_{i}}}{\mathbf{R}}_{c}^{\top }{\mathbf{R}}_{c}$的逆如下：设$S \subset  {G}_{i}$为某子集，并假定已计算出${\mathbf{M}}_{S} = \mathbf{I} + \mathop{\sum }\limits_{{s \in  S}}{\mathbf{R}}_{s}^{\top }{\mathbf{R}}_{s}$的逆。现阐述如何计算${\mathbf{M}}_{S\cup \{ c\} } = \mathbf{I} + \mathop{\sum }\limits_{{s \in  S\cup \{ c\} }}{\mathbf{R}}_{s}^{\top }{\mathbf{R}}_{s}$的逆。具体而言，设矩阵${\mathbf{R}}_{c}$映射城市至国家。对于每个国家country，令${\mathbf{e}}_{\text{country }}$表示01向量，其对应该国城市的位置为1。例如${\mathbf{e}}_{\text{cuba }} = {\left\lbrack  \begin{array}{lllll} 1 & 1 & 0 & 0 & 0 \end{array}\right\rbrack  }^{\top }$。则${\mathbf{R}}_{c}^{\top }{\mathbf{R}}_{c} =$$\mathop{\sum }\limits_{\text{country }}{\mathbf{e}}_{\text{country }}^{\top }{\mathbf{e}}_{\text{country }}^{\top }$。因此，从${\mathbf{M}}_{S}$开始，我们对每个国家应用Sherman-Morrison-Woodbury公式，例如：

$$

$$

This update can be done with database aggregate queries, because ${\mathbf{e}}_{\text{cuba }}^{\top }{\mathbf{M}}^{-1}{\mathbf{e}}_{\text{cuba }}$ is a sum of entries(i,j)in ${\mathbf{M}}^{-1}$ where both $i$ and $j$ are cities in cuba; $\mathbf{v} = {\mathbf{M}}^{-1}{\mathbf{e}}_{\text{cuba }}$ is the sum of columns of ${\mathbf{M}}^{-1}$ corresponding to cuba; and ${\mathbf{M}}^{-1}{\mathbf{e}}_{\text{cuba }}{\mathbf{e}}_{\text{cuba }}^{\top }{\mathbf{M}}^{-1}$ is exactly ${\mathbf{{vv}}}^{\top }$ .

该更新可通过数据库聚合查询实现，因${\mathbf{e}}_{\text{cuba }}^{\top }{\mathbf{M}}^{-1}{\mathbf{e}}_{\text{cuba }}$是${\mathbf{M}}^{-1}$中满足$i$和$j$同属古巴城市的(i,j)条目之和；$\mathbf{v} = {\mathbf{M}}^{-1}{\mathbf{e}}_{\text{cuba }}$是${\mathbf{M}}^{-1}$中对应古巴的列和；而${\mathbf{M}}^{-1}{\mathbf{e}}_{\text{cuba }}{\mathbf{e}}_{\text{cuba }}^{\top }{\mathbf{M}}^{-1}$恰好等于${\mathbf{{vv}}}^{\top }$。

Overall,each update (38) can be done in $O\left( {N}_{\text{city }}^{2}\right)$ -time,for an overall runtime of $O\left( {{N}_{\text{city }}^{2}{N}_{\text{country }}}\right.$ . When the FDs form a chain,the blocks are nested inside one another, and thus each update is even cheaper as we do not have to access all ${N}_{\text{city }}^{2}$ entries.

总体而言，每次更新(38)可在$O\left( {N}_{\text{city }}^{2}\right)$时间内完成，总运行时间为$O\left( {{N}_{\text{city }}^{2}{N}_{\text{country }}}\right.$。此运行时间应与基于高斯消元的逆矩阵计算时间$O\left( {N}_{\text{city }}^{3}\right)$对比。当函数依赖形成链式结构时，数据块会相互嵌套，此时因无需访问全部${N}_{\text{city }}^{2}$条目，每次更新成本更低。

### 4.6 Discussion

### 4.6 讨论

The prevalence of FDs presents fresh new challenges from both computational and statistical viewpoints. On the one hand, a reasonable and well-worn rule of thumb in statistics dictates that one should always eliminate features that are functionally dependent on others, because this helps reduce both computation and model's complexity, which in turn leads to reduced generalization error (as also noted in [36]). On the other hand, the statistical effectiveness of such a rule is difficult to gauge when the nature of dependence goes beyond linearity. In such scenarios, it might be desirable to keep some redundant variables, but only if they help construct simpler forms of regression/classification functions, leading to improved approximation ability for the model class.

函数依赖(FDs)的普遍存在从计算和统计角度都带来了新挑战。一方面，统计学中一条合理且成熟的经验法则要求剔除功能上依赖于其他变量的特征，这既能降低计算量又能简化模型复杂度，从而减少泛化误差（如文献[36]所述）。另一方面，当依赖关系超出线性范畴时，该法则的统计有效性难以评估。此类场景下，保留某些冗余变量可能更有利——前提是它们能构建更简洁的回归/分类函数形式，从而提升模型类的近似能力。

It is, however, difficult to know a priori which redundant features lead to simple functions. Therefore, the problem of dimensionality reduction cannot be divorced from the model class under consideration. While this remains unsolved in general, in this work we restricted ourselves to specific classes of learning models, the complexity of which may still be varied through regularization via (non-linear) penalties. Within a regularized parametric model class, we introduced dimensionality reduction techniques (variable elimination and re-parameterization) that may not fundamentally change the model's capacity. The reduction in the number of parameters may still help reduce the variance of parameter estimates, leading to improved generalization error guarantees.

然而预先判断哪些冗余特征能简化函数形式十分困难。因此降维问题必须结合具体模型类来考量。虽然该问题在广义上尚未解决，本文我们将研究范围限定于特定学习模型类，其复杂度仍可通过（非线性）惩罚项正则化调节。在正则化参数模型类中，我们提出的降维技术（变量消除与重参数化）不会根本改变模型容量。参数数量的减少仍有助于降低参数估计方差，从而提升泛化误差的理论保证。

We pursued in this section a more tangible benefit that lies in improved computational efficiency. There is substantial runtime saving brought by the reparameterizations from Theorems 4.1 and 4.2. In the setting without exploiting FDs, the runtime of our approach consists of the precomputation time stated in Proposition 3.4, and the per-iteration time stated in Theorem 3.6; this time might be multiplied by the number of backtracking steps depending on the specific iteration. By exploiting the FDs, the quantities in Propositions 3.4 and 3.6 are computed with respect to the smaller dimensional matrix $\bar{\sum }$ . Let $q = \left| {V - \mathop{\bigcup }\limits_{{i \in  \left\lbrack  k\right\rbrack  }}{S}_{i}}\right|$ ,then the dimensionality of $\bar{\sum }$ for ${\mathrm{{PR}}}^{d}$ is $\Theta \left( {q}^{d}\right)  \times  \Theta \left( {q}^{d}\right)$ ,much smaller than that of $\sum$ ,which is $\Theta \left( {n}^{d}\right)  \times  \Theta \left( {n}^{d}\right)$ . (See Example 13.) Last but not least,[4] provides the corresponding version of Corollary 3.2 with respect to $\bar{\sum }$ .

本节我们聚焦于更切实的计算效率提升。定理4.1和4.2的重参数化方案带来了显著运行时优化。在不利用FDs的情况下，算法运行时间包含命题3.4的预处理时间和定理3.6的每轮迭代时间（具体迭代可能需乘以回溯步数）。通过利用FDs，命题3.4和3.6的计算量均针对降维后的矩阵$\bar{\sum }$。设$q = \left| {V - \mathop{\bigcup }\limits_{{i \in  \left\lbrack  k\right\rbrack  }}{S}_{i}}\right|$，则${\mathrm{{PR}}}^{d}$中$\bar{\sum }$的维度为$\Theta \left( {q}^{d}\right)  \times  \Theta \left( {q}^{d}\right)$，远小于原矩阵$\sum$的维度$\Theta \left( {n}^{d}\right)  \times  \Theta \left( {n}^{d}\right)$（参见示例13）。最后，文献[4]给出了针对$\bar{\sum }$的推论3.2对应版本。

## 5 OPEN PROBLEMS

## 5 开放性问题

Our in-database learning framework raises open questions on statistics, algorithm design, and optimization. We next sketch a few representative questions.

我们的库内学习框架提出了统计学、算法设计和优化领域的开放问题。下面概述几个代表性方向。

One research direction is to extend the class of statistical models to train efficiently inside the database beyond those considered in this paper. Our formulation (1) captures a common class of regression models (such as PR and FaMa) and classification models (such as logistic and SVM), which is done by changing the loss function $\mathcal{L}$ . It remains open how to extend our formulation to capture latent variable models.

一个研究方向是扩展可在数据库内高效训练的统计模型类别，超越本文讨论的范畴。我们的公式(1)通过改变损失函数$\mathcal{L}$，已涵盖常见回归模型（如PR和FaMa）和分类模型（如逻辑回归和SVM）。如何扩展该公式以支持隐变量模型仍待探索。

The aggregates defining $\sum$ ,c,point evaluation,and gradient computation are "multi-output" queries. They deserve a systematic investigation, from formulation to evaluation and complexity analysis. In practice, one often reserves a fragment of the training data for model validation. It is an interesting question to incorporate this data partitioning requirement into our framework.

定义$\sum$的聚合运算、常数c、点求值和梯度计算都属于"多输出"查询。这些操作需要从公式表述、求值方法到复杂度分析的系统性研究。实践中常预留部分训练数据进行模型验证，如何将这种数据划分需求融入当前框架是个值得探讨的问题。

Understanding how to adapt further optimization algorithms, such as coordinate descent or stochastic gradient, to our in-database framework is an important research direction. Furthermore, our FD-aware optimization is specific to the ${\ell }_{2}$ -norm in the penalty term. We would also like to understand the effect of other norms, e.g., ${\ell }_{1}$ ,on model reparameterization under FDs.

理解如何将坐标下降法或随机梯度等优化算法适配到我们的数据库内框架中，是一个重要的研究方向。此外，我们提出的FD感知优化技术专门针对惩罚项中的${\ell }_{2}$-范数。我们还想探究其他范数（如${\ell }_{1}$）在函数依赖条件下的模型重参数化效果。

Finally, we conjecture that the cost function may be easier to optimize with respect to the reduced set of parameters that are not functionally determined: As redundant variables are eliminated or optimized out, the cost function's Hessian with respect to reduced parameters becomes less ill-conditioned, resulting in faster convergence behavior for gradient-based optimization techniques. The impact of FD-based dimensionality reduction, from both computational and statistical standpoints, have not been extensively studied for learning (nonlinear) models with categorical variables, which are precisely the kind discussed in our framework.

最后我们推测：对于非函数依赖的简化参数集，代价函数可能更易优化——当冗余变量被消除或优化后，代价函数关于简化参数的Hessian矩阵病态程度降低，从而加速基于梯度的优化技术收敛。从计算和统计双重角度来看，基于函数依赖的降维技术对（非线性）分类变量模型学习的影响尚未得到充分研究，而这正是我们框架所讨论的核心问题。

We discuss some identities for tensors. We use $\otimes$ to denote the tensor product. When taking the tensor product of two matrices, this is called the Kronecker product, which is not the same as the outer product for matrices, even though the two are isomorphic maps. If $\mathbf{A} = \left( {a}_{ij}\right)$ is an $m \times  n$ matrix and $\mathbf{B} = \left( {b}_{k\ell }\right)$ is a $p \times  q$ matrix,then the tensor product $\mathbf{A} \otimes  \mathbf{B}$ is an ${mp} \times  {nq}$ matrix whose $\left( {\left( {i,k}\right) ,\left( {j,\ell }\right) }\right)$ entry is ${a}_{ij}{b}_{k\ell }$ . ### A.2 Tensor computation, FAQ-expression, and the InsideOut algorithm

### A.2 张量计算、FAQ表达式及InsideOut算法

Quite often we need to compute a product of the form $\left( {\mathbf{A} \otimes  \mathbf{B}}\right) \mathbf{C}$ , where $\mathbf{A},\mathbf{B}$ ,and $\mathbf{C}$ are tensors,provided that their dimensionalities match up. For example,suppose $\mathbf{A}$ is an $m \times  n$ matrix, $\mathbf{B}$ a $p \times  q$ matrix,and $\mathrm{C}$ a ${nq} \times  1$ matrix (i.e. a vector). The result is a ${mp} \times  1$ tensor. The brute-force way of computing $\left( {\mathbf{A} \otimes  \mathbf{B}}\right) \mathbf{C}$ is to compute $\mathbf{A} \otimes  \mathbf{B}$ first,taking $\Theta \left( {mnpq}\right)$ -time,and then multiply the result with C,for an overall runtime of $\Theta \left( {mnpq}\right)$ . The brute-force algorithm is a horribly inefficient algorithm.

我们经常需要计算形如$\left( {\mathbf{A} \otimes  \mathbf{B}}\right) \mathbf{C}$的乘积，其中$\mathbf{A},\mathbf{B}$和$\mathbf{C}$为维度匹配的张量。例如，设$\mathbf{A}$为$m \times  n$矩阵，$\mathbf{B}$为$p \times  q$矩阵，$\mathrm{C}$为${nq} \times  1$矩阵（即向量），结果是一个${mp} \times  1$张量。暴力计算法先计算$\mathbf{A} \otimes  \mathbf{B}$耗时$\Theta \left( {mnpq}\right)$，再与C相乘，总耗时为$\Theta \left( {mnpq}\right)$。该暴力算法效率极低。

### A.3 FAQ-width

### A.3 FAQ宽度

A.3.1 Fractional edge cover number and output size bounds. We consider a conjunctive query $Q$ over a relational database instance $I$ . We use $N$ to denote the size of the largest input relation in $Q$ . We also use $Q\left( I\right)$ to denote the output and $\left| {Q\left( I\right) }\right|$ to denote its size. We use the query $Q$ and its hypergraph $\mathcal{H}$ interchangeably.

A.3.1 分数边覆盖数与输出大小边界。我们考虑关系数据库实例$I$上的连接查询$Q$，用$N$表示$Q$中最大输入关系的大小，$Q\left( I\right)$表示输出结果，$\left| {Q\left( I\right) }\right|$表示其大小。查询$Q$与其超图$\mathcal{H}$可互换使用。

Definition 6 (Fractional edge cover number ${\rho }^{ * }$ ). Let $\mathcal{H} = \left( {\mathcal{V},\mathcal{E}}\right)$ be a hypergraph. Let $B \subseteq  \mathcal{V}$ be any subset of vertices. A fractional edge cover of $B$ using edges in $\mathcal{H}$ is a feasible solution $\mathbf{\lambda } = {\left( {\lambda }_{S}\right) }_{S \in  \mathcal{E}}$ to the following linear program:

定义6（分数边覆盖数${\rho }^{ * }$）。设$\mathcal{H} = \left( {\mathcal{V},\mathcal{E}}\right)$为超图，$B \subseteq  \mathcal{V}$为顶点子集。使用$\mathcal{H}$中边对$B$进行分数边覆盖，是以下线性规划的可行解$\mathbf{\lambda } = {\left( {\lambda }_{S}\right) }_{S \in  \mathcal{E}}$：

$$
\min \;\mathop{\sum }\limits_{{S \in  \mathcal{E}}}{\lambda }_{S}
$$

$$
\text{s.t.}\;\mathop{\sum }\limits_{{S : v \in  S}}{\lambda }_{S} \geq  1,\forall v \in  B
$$

$$
{\lambda }_{S} \geq  0,\forall S \in  \mathcal{E}\text{.}
$$

The optimal objective value of the above linear program is called the fractional edge cover number of $B$ in $\mathcal{H}$ and is denoted by ${\rho }_{\mathcal{H}}^{ * }\left( B\right)$ . When $\mathcal{H}$ is clear from the context,we drop the subscript $\mathcal{H}$ and use ${\rho }^{ * }\left( B\right)$ . Given a conjunctive query $Q$ ,the fractional edge cover number of $Q$ is ${\rho }_{\mathcal{H}}^{ * }\left( \mathcal{V}\right)$ where $\mathcal{H} = \left( {\mathcal{V},\mathcal{E}}\right)$ is the hypergraph of $Q$ .

上述线性规划的最优目标值称为$B$在$\mathcal{H}$中的分数边覆盖数，记作${\rho }_{\mathcal{H}}^{ * }\left( B\right)$。当上下文明确$\mathcal{H}$时，省略下标$\mathcal{H}$直接使用${\rho }^{ * }\left( B\right)$。给定合取查询$Q$，其分数边覆盖数为${\rho }_{\mathcal{H}}^{ * }\left( \mathcal{V}\right)$，其中$\mathcal{H} = \left( {\mathcal{V},\mathcal{E}}\right)$是$Q$的超图。

Theorem A. 2 (AGM-bound $\left\lbrack  {{12},{26}}\right\rbrack$ ). Given a full conjunctive query $Q$ over a relational database instance $I$ ,the output size is bounded by

定理A.2（AGM界$\left\lbrack  {{12},{26}}\right\rbrack$）。给定关系数据库实例$I$上的完全合取查询$Q$，其输出大小上界为

$$
\left| {Q\left( I\right) }\right|  \leq  {N}^{{\rho }^{ * }},
$$

where ${\rho }^{ * }$ is the fractional edge cover number of $Q$ .

其中${\rho }^{ * }$是$Q$的分数边覆盖数。

Theorem A. 3 (AGM-bound is tight [12, 26]). Given a full conjunctive query $Q$ and a non-negative number $N$ ,there exists a database instance $I$ whose relation sizes are upper-bounded by $N$ and satisfies

定理A.3（AGM界的紧性[12,26]）。给定完全合取查询$Q$和非负数$N$，存在关系大小不超过$N$的数据库实例$I$满足

$$
\left| {Q\left( I\right) }\right|  = \Theta \left( {N}^{{\rho }^{ * }}\right) .
$$

Worst-case optimal join algorithms $\left\lbrack  {6,{39},{40},{49}}\right\rbrack$ can be used to answer any full conjunctive query $Q$ in time

最坏情况最优连接算法$\left\lbrack  {6,{39},{40},{49}}\right\rbrack$可在以下时间内回答任何完全合取查询$Q$：

$$
O\left( {\left| \mathcal{V}\right|  \cdot  \left| \mathcal{E}\right|  \cdot  {N}^{{\rho }^{ * }} \cdot  \log N}\right) . \tag{48}
$$

A.3.2 Tree decompositions, acyclicity, and width parameters.

A.3.2 树分解、无环性与宽度参数

Definition 7 (Tree decomposition). Let $\mathcal{H} = \left( {\mathcal{V},\mathcal{E}}\right)$ be a hy-pergraph. A tree decomposition of $\mathcal{H}$ is a pair $\left( {T,\chi }\right)$ where $T =$ $\left( {V\left( T\right) ,E\left( T\right) }\right)$ is a tree and $\chi  : V\left( T\right)  \rightarrow  {2}^{\mathcal{V}}$ assigns to each node of $T$ a subset of vertices of $\mathcal{H}$ . The sets $\chi \left( t\right) ,t \in  V\left( T\right)$ ,are called the bags of the tree decomposition. There are two properties the bags must satisfy

定义7（树分解）。设$\mathcal{H} = \left( {\mathcal{V},\mathcal{E}}\right)$为超图，$\mathcal{H}$的树分解是二元组$\left( {T,\chi }\right)$，其中$T =$$\left( {V\left( T\right) ,E\left( T\right) }\right)$是树结构，$\chi  : V\left( T\right)  \rightarrow  {2}^{\mathcal{V}}$为$T$的每个节点分配$\mathcal{H}$的顶点子集。集合$\chi \left( t\right) ,t \in  V\left( T\right)$称为树分解的包，需满足两个性质：

(a) For any hyperedge $F \in  \mathcal{E}$ ,there is a bag $\chi \left( t\right) ,t \in  V\left( T\right)$ ,such that $F \subseteq  \chi \left( t\right)$ .

(a) 对任意超边$F \in  \mathcal{E}$，存在包$\chi \left( t\right) ,t \in  V\left( T\right)$使得$F \subseteq  \chi \left( t\right)$

(b) For any vertex $v \in  \mathcal{V}$ ,the set $\{ t \mid  t \in  V\left( T\right) ,v \in  \chi \left( t\right) \}$ is not empty and forms a connected subtree of $T$ .

(b) 对任意顶点$v \in  \mathcal{V}$，集合$\{ t \mid  t \in  V\left( T\right) ,v \in  \chi \left( t\right) \}$非空且构成$T$的连通子树

Definition 8 (acyclicity). A hypergraph $\mathcal{H} = \left( {\mathcal{V},\mathcal{E}}\right)$ is acyclic iff there exists a tree decomposition $\left( {T,\chi }\right)$ in which every bag $\chi \left( t\right)$ is a hyperedge of $\mathcal{H}$ .

定义8（无环性）。当且仅当存在树分解$\left( {T,\chi }\right)$使得每个包$\chi \left( t\right)$都是$\mathcal{H}$的超边时，超图$\mathcal{H} = \left( {\mathcal{V},\mathcal{E}}\right)$是无环的。

When $\mathcal{H}$ represents a join query,the tree $T$ in the above definition is also called the join tree of the query. A query is acyclic if and only if its hypergraph is acyclic. For non-acyclic queries, we need a measure of how "close" a query is to being acyclic.

当$\mathcal{H}$表示连接查询时，上述定义中的树结构$T$亦称为该查询的连接树。当且仅当超图无环时，查询才无环。对于非无环查询，我们需要度量查询"接近"无环的程度。

We use the following width notions of a query.

我们采用以下查询宽度概念。

Definition 9 ( $g$ -width of a hypergraph: a generic width notion [9]). Let $\mathcal{H} = \left( {\mathcal{V},\mathcal{E}}\right)$ be a hypergraph,and $g : {2}^{\mathcal{V}} \rightarrow  {\mathbb{R}}^{ + }$ be a function that assigns a non-negative real number to each subset of $\mathcal{V}$ . The $g$ - width of a tree decomposition $\left( {T,\chi }\right)$ of $\mathcal{H}$ is $\mathop{\max }\limits_{{t \in  V\left( T\right) }}g\left( {\chi \left( t\right) }\right)$ . The $g$ -width of $\mathcal{H}$ is the minimum $g$ -width over all tree decompositions of $\mathcal{H}$ . (Note that the $g$ -width of a hypergraph is a Minimax function.)

定义9（超图的$g$-宽度：通用宽度概念[9]）。设$\mathcal{H} = \left( {\mathcal{V},\mathcal{E}}\right)$为超图，$g : {2}^{\mathcal{V}} \rightarrow  {\mathbb{R}}^{ + }$为对$\mathcal{V}$的每个子集分配非负实数的函数。树分解$\left( {T,\chi }\right)$的$g$-宽度是$\mathop{\max }\limits_{{t \in  V\left( T\right) }}g\left( {\chi \left( t\right) }\right)$。超图$\mathcal{H}$的$g$-宽度是其所有树分解中$g$-宽度的最小值。（注：超图的$g$-宽度是最小极大函数。）

Definition 10 (Treewidth and fractional hypertree width are special cases of $g$ -width). Let $s$ be the following function: $s\left( B\right)  = \left| B\right|  -$ $1,\forall V \subseteq  \mathcal{V}$ . Then the treewidth of a hypergraph $\mathcal{H}$ ,denoted by $\operatorname{tw}\left( \mathcal{H}\right)$ ,is exactly its $s$ -width,and the fractional hypertree width of a hypergraph $\mathcal{H}$ ,denoted by fhtw(H),is the ${\rho }^{ * }$ -width of $\mathcal{H}$ .

定义10（树宽与分数超树宽是$g$-宽度的特例）。设$s$为如下函数：$s\left( B\right)  = \left| B\right|  -$$1,\forall V \subseteq  \mathcal{V}$。则超图$\mathcal{H}$的树宽（记作$\operatorname{tw}\left( \mathcal{H}\right)$）即其$s$-宽度，而超图$\mathcal{H}$的分数超树宽（记作fhtw(H)）则是${\rho }^{ * }$-宽度。

From the above definitions, $\operatorname{fhtw}\left( \mathcal{H}\right)  \geq  1$ for any hypergraph $\mathcal{H}$ . Moreover, $\operatorname{fhtw}\left( \mathcal{H}\right)  = 1$ if and only if $\mathcal{H}$ is acyclic.

由上述定义可知，对任意超图$\mathcal{H}$都有$\operatorname{fhtw}\left( \mathcal{H}\right)  \geq  1$。此外，当且仅当$\mathcal{H}$无环时，$\operatorname{fhtw}\left( \mathcal{H}\right)  = 1$成立。

A.3.3 Vertex/variable orderings and their equivalence to tree decompositions. Besides tree decompositions, there is another way to define acyclicity and width notions of a hypergraph, which is orderings of the hypergraph vertices. Just like we refer to queries and hypergraphs interchangeably, we also refer to query variables and hypergraph vertices interchangeably.

A.3.3 顶点/变量排序及其与树分解的等价性。除树分解外，定义超图无环性和宽度概念的另一途径是通过顶点排序。正如我们交替使用查询与超图术语，查询变量与超图顶点也可互换指代。

Let $n$ denote the number of vertices of the given hypergraph $\mathcal{H}$ .

设$n$表示给定超图$\mathcal{H}$的顶点数量。

Definition 11 (Vertex ordering of a hypergraph). A vertex ordering of a hypergraph $\mathcal{H} = \left( {\mathcal{V},\mathcal{E}}\right)$ is a listing $\sigma  = \left( {{v}_{1},\ldots ,{v}_{n}}\right)$ of all vertices in $\mathcal{V}$ .

定义11（超图的顶点排序）。超图$\mathcal{H} = \left( {\mathcal{V},\mathcal{E}}\right)$的顶点排序是指其所有顶点$\mathcal{V}$的一个排列$\sigma  = \left( {{v}_{1},\ldots ,{v}_{n}}\right)$。

Definition 12 (Elimination sets ${U}_{j}^{\sigma }$ of a vertex ordering $\sigma$ ). Given a hypergraph $\mathcal{H} = \left( {\mathcal{V},\mathcal{E}}\right)$ and a vertex ordering $\sigma  = \left( {{v}_{1},\ldots ,{v}_{n}}\right)$ , we define sets ${U}_{1}^{\sigma },\ldots ,{U}_{n}^{\sigma } \subseteq  \mathcal{V}$ ,called the elimination sets of $\sigma$ ,as follows: Let $\partial \left( {v}_{n}\right)$ be the set of hyperedges of $\mathcal{H}$ that contain ${v}_{n}$ . We define ${U}_{n}^{\sigma }$ to be the union of all hyperedges in $\partial \left( {v}_{n}\right)$ :

定义12（顶点排序$\sigma$的消解集${U}_{j}^{\sigma }$）。给定超图$\mathcal{H} = \left( {\mathcal{V},\mathcal{E}}\right)$和顶点排序$\sigma  = \left( {{v}_{1},\ldots ,{v}_{n}}\right)$，我们定义集合${U}_{1}^{\sigma },\ldots ,{U}_{n}^{\sigma } \subseteq  \mathcal{V}$（称为$\sigma$的消解集）如下：令$\partial \left( {v}_{n}\right)$为包含${v}_{n}$的超边集合，则${U}_{n}^{\sigma }$定义为$\partial \left( {v}_{n}\right)$中所有超边的并集：

$$
{U}_{n}^{\sigma } \mathrel{\text{:=}} \mathop{\bigcup }\limits_{{S \in  \partial \left( {v}_{n}\right) }}S.
$$

If $n = 1$ ,then we are done. Otherwise,we remove vertex ${v}_{n}$ and all hyperedges in $\partial \left( {v}_{n}\right)$ from $\mathcal{H}$ and add back to $\mathcal{H}$ a new hyperedge ${U}_{n}^{\sigma } - \left\{  {v}_{n}\right\}$ ,thus turning $\mathcal{H}$ into a hypergraph with $n - 1$ vertices:

若$n = 1$成立，则过程终止。否则，我们将顶点${v}_{n}$和超边集$\partial \left( {v}_{n}\right)$从$\mathcal{H}$中移除，并向$\mathcal{H}$添加新超边${U}_{n}^{\sigma } - \left\{  {v}_{n}\right\}$，从而将$\mathcal{H}$转化为具有$n - 1$个顶点的超图：

$$
\mathcal{V} \leftarrow  \mathcal{V} - \left\{  {v}_{n}\right\}  
$$

$$
\mathcal{E} \leftarrow  \left( {\mathcal{E} - \partial \left( {v}_{n}\right) }\right)  \cup  \left\{  {{U}_{n}^{\sigma } - \left\{  {v}_{n}\right\}  }\right\}  
$$

The remaining elimination sets ${U}_{1}^{\sigma },\ldots ,{U}_{n - 1}^{\sigma }$ are defined inductively to be the elimination sets of the resulting hypergraph (whose vertices are now $\left. \left\{  {{v}_{1},\ldots ,{v}_{n - 1}}\right\}  \right)$ . When $\sigma$ is clear from the context, we drop the superscript $\sigma$ and use ${U}_{1},\ldots ,{U}_{n}$ .

归纳定义剩余消解集${U}_{1}^{\sigma },\ldots ,{U}_{n - 1}^{\sigma }$为结果超图（其顶点现为$\left. \left\{  {{v}_{1},\ldots ,{v}_{n - 1}}\right\}  \right)$）的消解集。当上下文明确时，省略上标$\sigma$并记作${U}_{1},\ldots ,{U}_{n}$。

Proposition A. 4 (Every vertex ordering has an "equivalent" tree decomposition [7]). Given a hypergraph $\mathcal{H} = \left( {\mathcal{V},\mathcal{E}}\right)$ ,for every vertex ordering $\sigma$ ,there is a tree decomposition $\left( {T,\chi }\right)$ whose bags $\chi \left( t\right)$ are the elimination sets ${U}_{j}^{\sigma }$ of $\sigma$ .

命题A.4（每个顶点序都存在"等价"树分解[7]）。给定超图$\mathcal{H} = \left( {\mathcal{V},\mathcal{E}}\right)$，对任意顶点序$\sigma$，存在树分解$\left( {T,\chi }\right)$，其包$\chi \left( t\right)$即为$\sigma$的消解集${U}_{j}^{\sigma }$。

By applying the GYO elimination procedure [3] on the bags of a tree decomposition, we can obtain an "equivalent" vertex ordering:

通过对树分解的包应用GYO消解算法[3]，可获得"等价"顶点序：

Proposition A. 5 (Every tree decomposition has an "equivalent" vertex ordering [7]). Given a hypergraph $\mathcal{H} = \left( {\mathcal{V},\mathcal{E}}\right)$ ,for every tree decomposition $\left( {T,\chi }\right)$ ,there is a vertex ordering $\sigma$ such that every elimination set ${U}_{j}^{\sigma }$ of $\sigma$ is contained in some bag $\chi \left( t\right)$ of the tree decomposition $\left( {T,\chi }\right)$ .

命题A.5（每个树分解都存在"等价"顶点序[7]）。给定超图$\mathcal{H} = \left( {\mathcal{V},\mathcal{E}}\right)$，对任意树分解$\left( {T,\chi }\right)$，存在顶点序$\sigma$使得其每个消解集${U}_{j}^{\sigma }$都包含于树分解$\left( {T,\chi }\right)$的某个包$\chi \left( t\right)$中。

A.3.4 FAQ-width of an FAQ query. Just like a conjunctive query, an FAQ query has a query hypergraph $\mathcal{H} = \left( {\mathcal{V},\mathcal{E}}\right)$ . But unlike conjunctive queries, an FAQ query also specifies an order of its variables, which is the order in which we aggregate over those variables in the given FAQ-expression. (For example, in expression (47),we sum over $t$ first,then over $y$ ,and we keep $z$ and $x$ as free variables. Such a variable order for the query can also be interpreted as a vertex order $\sigma$ for the query’s hypergraph.

O\left( {\left| \mathcal{V}\right|  \cdot  \left| \mathcal{E}\right|  \cdot  {N}^{{\rho }_{\mathcal{H}}^{ * }\left( {U}_{n}^{\sigma }\right) } \cdot  \log N}\right) . \tag{49}
$$
