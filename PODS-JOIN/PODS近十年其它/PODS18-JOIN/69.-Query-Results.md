## ABSTRACT

## 摘要

Relational queries, and in particular join queries, often generate large output results when executed over a huge dataset. In such cases, it is often infeasible to store the whole materialized output if we plan to reuse it further down a data processing pipeline. Motivated by this problem, we study the construction of space-efficient compressed representations of the output of conjunctive queries, with the goal of supporting the efficient access of the intermediate compressed result for a given access pattern. In particular, we initiate the study of an important tradeoff: minimizing the space necessary to store the compressed result, versus minimizing the answer time and delay for an access request over the result. Our main contribution is a novel parameterized data structure, which can be tuned to trade off space for answer time. The tradeoff allows us to control the space requirement of the data structure precisely, and depends both on the structure of the query and the access pattern. We show how we can use the data structure in conjunction with query decomposition techniques in order to efficiently represent the outputs for several classes of conjunctive queries.

关系型查询（尤其是连接查询）在庞大数据集上执行时，常会生成大规模输出结果。若需在数据处理流程中复用该结果，完全物化存储整个输出往往不可行。基于此问题，我们研究如何构建合取查询输出的空间高效压缩表示，旨在支持针对特定访问模式高效访问中间压缩结果。我们首次探讨了一个关键权衡：最小化存储压缩结果所需空间与最小化访问请求响应时间及延迟之间的平衡。主要贡献是一种新型参数化数据结构，可通过调节实现空间与响应时间的权衡。该权衡机制能精确控制数据结构空间需求，其效果取决于查询结构与访问模式。我们展示了如何结合查询分解技术，高效表示多类合取查询的输出结果。

## 1 INTRODUCTION

## 1 引言

In this paper, we study the problem of constructing space-efficient compressed representations of the output of conjunctive query results, with the goal of efficiently supporting a given access pattern directly over the compressed result, instead of the original input database. In many data management tasks, the data processing pipeline repeatedly accesses the result of a conjunctive query (CQ) using a particular access pattern. In the simplest case, this access pattern can be to enumerate the full result (e.g., in a multiquery optimization context). Generally, the access pattern can specify, or bound, the values of some variables, and ask to enumerate the values of the remaining variables that satisfy the query.

本文研究合取查询输出的空间高效压缩表示构建问题，旨在直接基于压缩结果（而非原始输入数据库）高效支持特定访问模式。许多数据管理任务中，数据处理流程会通过特定访问模式反复访问合取查询(CQ)结果。最简单情况下，访问模式可能是枚举完整结果（如多查询优化场景）。更一般地，访问模式可指定或限定某些变量值，要求枚举满足查询的其余变量值。

Currently, there are two extremal solutions for this problem. In one extreme, we can materialize the full result of the CQ and index the result according to the access pattern. However, since the output result can often be extremely large, storing this index can be prohibitively expensive. In the other extreme, we can service each access request by executing the CQ directly over the input database every time. This solution does not need extra storage, but can lead to inefficiencies, since computation has to be done from scratch and may be redundant. In this work, we explore the design space between these two extremes. In other words, we want to compress the query output such that it can be stored in a space-efficient way, while we can support a given access pattern over the output as fast as possible.

当前该问题存在两种极端解决方案。一种极端是完全物化CQ结果并按访问模式建立索引。但由于输出结果通常极其庞大，存储此类索引可能代价过高。另一种极端是每次直接对输入数据库执行CQ来响应访问请求。该方案无需额外存储，但可能导致效率低下，因为每次需从头计算且可能产生冗余。本研究探索这两种极端之间的设计空间，即压缩查询输出以实现空间高效存储，同时尽可能快速支持对输出的特定访问模式。

Example 1. Suppose we want to perform an analysis about mutual friends of users in a social network. The friend relation is represented by a symmetric binary relation $R$ of size $N$ ,where a tuple $R\left( {a,b}\right)$ denotes that user a is a friend of user $\mathrm{b}$ . The data analysis involves accessing the database through the following pattern: given any two users $x$ and $z$ who are friends,return all mutual friends $y$ . We formalize this task through an adorned view ${V}^{\mathrm{{bfb}}}\left( {x,y,z}\right)  = R\left( {x,y}\right) ,R\left( {y,z}\right)$ , $R\left( {z,x}\right)$ . The above formalism says that the view $V$ of the database will be accessed as follows: given values for the bound (b) variables $x,z$ , we have to return the values for the free (f) variable $y$ such that the tuple is in the view $V$ . The sequence bfb is called the access pattern for the adorned view.

示例1. 假设需分析社交网络中用户的共同好友。好友关系由大小为$N$的对称二元关系$R$表示，其中元组$R\left( {a,b}\right)$表示用户a是用户$\mathrm{b}$的好友。数据分析涉及以下访问模式：给定互为好友的任意两个用户$x$和$z$，返回所有共同好友$y$。我们通过装饰视图${V}^{\mathrm{{bfb}}}\left( {x,y,z}\right)  = R\left( {x,y}\right) ,R\left( {y,z}\right)$,$R\left( {z,x}\right)$形式化该任务。该形式化表明数据库视图$V$将按以下方式访问：给定绑定(b)变量$x,z$的值，需返回自由(f)变量$y$的值，使得元组存在于视图$V$中。序列bfb称为装饰视图的访问模式。

One option to solve this problem is to satisfy each access by evaluating a query on the input database. This approach is space-efficient, since we work directly on the input and need space $O\left( N\right)$ . However, we may potentially have to wait $\Omega \left( N\right)$ time to even learn whether there is any returned value for $y$ . A second option is to materialize the view $V\left( {x,y,z}\right)$ and build a hash index with key(x,z): in this case, we can satisfy any access optimally with constant delay $\widetilde{O}\left( 1\right)  \cdot  {}^{1}$ On the other hand,the space needed for storing the view can be $\Omega \left( {N}^{3/2}\right)$ .

解决此问题的一种方案是通过在输入数据库上执行查询来满足每次访问。这种方法空间效率高，因为我们直接操作输入数据，仅需占用$O\left( N\right)$空间。但可能需要等待$\Omega \left( N\right)$时间才能确认$y$是否存在返回值。另一种方案是物化视图$V\left( {x,y,z}\right)$并建立键为(x,z)的哈希索引：这种方式能以恒定延迟$\widetilde{O}\left( 1\right)  \cdot  {}^{1}$最优响应访问，但存储视图所需空间可能高达$\Omega \left( {N}^{3/2}\right)$。

In this scenario, we would like to construct representations that trade off between space and delay (or answer time). As we will show later, for this particular example we can construct a data structure for any parameter $\tau$ that needs space $O\left( {{N}^{3/2}/\tau }\right)$ ,and can answer any access request with delay $\widetilde{O}\left( \tau \right)$ .

本场景中，我们需要构建能在空间与延迟（或响应时间）之间取得平衡的数据表示。后文将证明，针对该案例可构建适用于任意参数$\tau$的数据结构，仅需$O\left( {{N}^{3/2}/\tau }\right)$空间，并能以$\widetilde{O}\left( \tau \right)$延迟响应访问请求。

The idea of efficiently compressing query results has recently gained considerable attention, both in the context of factorized databases [22], as well as constant-delay enumeration [5, 26]. In these settings, the focus is to construct compressed representations that allow for enumeration of the full result with constant delay: this means that the time between outputting two consecutive tuples is $O\left( 1\right)$ ,independent of the size of the data. Using factorization techniques,for any input database $D$ ,we can construct a compressed data structure for any CQ without projections, called a $d$ -representation,using space $O\left( {\left| D\right| }^{\text{fhw }}\right)$ ,where fhw is the fractional hypertree width of the query [22]. Such a $d$ -representation guarantees constant delay enumeration of the full result. In [5, 25], the compression of CQs with projections is also studied, but the setting is restricted to $O\left( \left| D\right| \right)$ time preprocessing -which also restricts the size of the compressed representation to $O\left( \left| D\right| \right)$ .

查询结果高效压缩技术近期获得广泛关注，主要体现在因子化数据库[22]和恒定延迟枚举[5,26]领域。这些研究聚焦于构建支持恒定延迟全结果枚举的压缩表示——即连续输出两个元组的时间间隔为$O\left( 1\right)$，与数据规模无关。利用因子化技术，对任意输入数据库$D$，可为无投影的联机查询构建称为$d$表示的压缩数据结构，占用$O\left( {\left| D\right| }^{\text{fhw }}\right)$空间（其中fhw为查询的分数超树宽度[22]）。该$d$表示能保证全结果的恒定延迟枚举。文献[5,25]还研究了含投影联机查询的压缩，但预处理时间限定为$O\left( \left| D\right| \right)$，这同时将压缩表示大小限制在$O\left( \left| D\right| \right)$内。

In this work, we show that we can dramatically decrease the space for the compressed representation by both(i)taking advantage of the access pattern,and(ii)tolerating a possibly increased delay. For instance,a $d$ -representation for the query in Example 1 needs $O\left( {N}^{3/2}\right)$ space,while no linear-time preprocessing can support constant delay enumeration (under reasonable complexity assumptions [5]). However, we show that if we are willing to tolerate a delay of $\widetilde{O}\left( {N}^{1/2}\right)$ ,we can support the access pattern of Example 1 using only $\widetilde{O}\left( N\right)$ space,linear in the input size.

本研究证明，通过(i)利用访问模式特征和(ii)容忍适度增加的延迟，可显著降低压缩表示的空间开销。例如，示例1中查询的$d$表示需要$O\left( {N}^{3/2}\right)$空间，而在线性时间预处理条件下无法支持恒定延迟枚举（基于合理复杂性假设[5]）。但我们发现，若接受$\widetilde{O}\left( {N}^{1/2}\right)$的延迟，仅需$\widetilde{O}\left( N\right)$空间（与输入规模线性相关）即可支持示例1的访问模式。

Applications. We illustrate the applicability of compressed representations of conjunctive queries on two practical problems:(i) processing graph queries over relational databases, and (ii) scaling up statistical inference engines.

应用场景。我们通过两个实际问题展示联机查询压缩表示的适用性：(i)关系数据库上的图查询处理，(ii)统计推理引擎的扩展。

In the context of graph analytics, the graph to be analyzed is often defined as a declarative query over a relational schema [2, 28- 30]. For instance, consider the DBLP dataset, which contains information about which authors write which papers through a table $R$ (author,paper). To analyze the relationships between co-authors, we will need to extract the co-author graph, which we can express as the view $V\left( {x,y}\right)  = R\left( {x,p}\right) ,R\left( {y,p}\right)$ . Most graph analytics algorithms typically access such a graph through an API that asks for the set of neighbors of a given vertex, which corresponds to the adorned view ${V}^{\mathrm{{bf}}}\left( {x,y}\right)  = R\left( {x,p}\right) ,R\left( {y,p}\right)$ . Since the option of materializing the whole graph (here defined as the view $V$ ) may require prohibitively large space, it is desirable to apply techniques that compress $V$ ,while we can still answer any access request efficiently. Recent work [28] has proposed compression techniques for this particular domain, but these techniques are limited to adorned views of the form ${V}^{\text{bf }}\left( {x,y}\right)$ ,rely on heuristics,and do not provide any formal analysis on the tradeoff between space and runtime.

在图分析领域，待分析的图通常被定义为关系模式上的声明式查询[2,28-30]。例如，考虑DBLP数据集，该数据集通过表$R$(作者,论文)存储了作者与论文的对应关系。为分析合著者关系，需提取合著者图，可将其表示为视图$V\left( {x,y}\right)  = R\left( {x,p}\right) ,R\left( {y,p}\right)$。多数图分析算法通过请求给定顶点邻居集的API访问此类图，对应修饰视图${V}^{\mathrm{{bf}}}\left( {x,y}\right)  = R\left( {x,p}\right) ,R\left( {y,p}\right)$。由于物化整个图(此处定义为视图$V$)可能占用过大空间，需应用压缩技术处理$V$，同时保持高效查询响应。近期研究[28]提出了该领域的专用压缩技术，但这些技术仅适用于${V}^{\text{bf }}\left( {x,y}\right)$形式的修饰视图，依赖启发式方法，且未对空间与运行时权衡进行形式化分析。

The second application of query compression is in statistical inference. For example, FELIX [20] is an inference engine for Markov Logic Networks over relational data, which provides scalability by optimizing the access patterns of logical rules that are evaluated during inference. These access patterns over rules are modeled exactly as adorned views. FELIX groups the relations in the body of the view in partitions (optimizing for some cost function), and then materializes each partition (which corresponds to materializing a subquery). In the one extreme, it will eagerly materialize the whole view, and in the other extreme it will lazily materialize nothing. The materialization in FELIX is discrete, in that it is not possible to partially materialize each subquery. In contrast, we consider materialization strategies that explore the full continuum between the two extremes.

查询压缩的第二类应用是统计推断。例如FELIX[20]作为关系数据上马尔可夫逻辑网络的推断引擎，通过优化推断过程中逻辑规则的访问模式实现可扩展性。这些规则访问模式正是以修饰视图建模的。FELIX将视图体中的关系按分区(针对特定成本函数优化)分组后物化每个分区(对应子查询物化)。极端情况下会完全物化整个视图，或完全不物化。FELIX的物化是离散的，无法部分物化子查询。相比之下，我们研究的是在两种极端间连续过渡的物化策略。

Our Contribution. In this work, we study the design space for compressed representations of conjunctive queries in the full continuum between optimal space and optimal runtime, when our goal is to optimize for a specific access pattern.

研究贡献。本文系统研究了在优化特定访问模式时，连接查询压缩表示在最优空间与最优运行时连续区间内的设计空间。

Our main contribution is a novel data structure that (i) can compress the result for every ${CQ}$ without projections according to the access pattern given by an adorned view, and (ii) can be tuned to tradeoff space for delay and answer time. At the one extreme, the data structure achieves constant delay $O\left( 1\right)$ ; At the other extreme it uses linear space $O\left( \left| D\right| \right)$ ,but provides a worst delay guarantee. Our proposed data structure includes as a special case the data structure developed in [11] for the fast set intersection problem.

核心贡献是新型数据结构：(i)能根据修饰视图的访问模式压缩无投影${CQ}$的查询结果；(ii)可调节空间与延迟/响应时间的权衡。极端情况下，该结构可实现恒定延迟$O\left( 1\right)$；另一极端则使用线性空间$O\left( \left| D\right| \right)$但提供最差延迟保证。我们提出的数据结构包含[11]中快速集合交集问题解决方案作为特例。

To construct our data structure, we need two technical ingredients. The first ingredient (Theorem 1) is a data structure that trades space with delay with respect to the worst-case size bound of the query result. As an example of the type of tradeoffs that can be achieved,for any $\mathrm{{CQ}}Q$ without projections and any access pattern, the data structure needs space $\widetilde{O}\left( {{\left| D\right| }^{{\rho }^{ * }}/\tau }\right)$ to achieve delay $\widetilde{O}\left( \tau \right)$ , where ${\rho }^{ * }$ is the fractional edge cover number of $Q$ ,and $\left| D\right|$ the size of the input database. In many cases and for specific access patterns, the data structure can substantially improve upon this tradeoff. To prove Theorem 1, we develop novel techniques on how to encode information about expensive sub-instances of the problem in a balanced way.

构建该数据结构需要两项技术要素。第一要素(定理1)是基于查询结果最坏情况大小边界实现空间与延迟权衡的数据结构。示例性权衡表现为：对任意无投影$\mathrm{{CQ}}Q$和访问模式，实现延迟$\widetilde{O}\left( \tau \right)$需要$\widetilde{O}\left( {{\left| D\right| }^{{\rho }^{ * }}/\tau }\right)$空间，其中${\rho }^{ * }$是$Q$的分数边覆盖数，$\left| D\right|$为输入数据库规模。针对特定访问模式，该结构可显著优化此权衡。为证明定理1，我们创新性地提出了平衡编码问题昂贵子实例信息的技术。

However, Theorem 1 by its own gives suboptimal tradeoffs, since it ignores structural properties of the query (for example, for constant delay it materializes the full result). Our second ingredient (Theorem 2) combines the data structure of Theorem 1 with a type of tree decomposition called connex tree decomposition [5]. This tree decomposition has the property of restricting the tree structure such that the bound variables in the adorned view always form a connected component at the top of the tree.

但定理1单独使用会产生次优权衡，因其忽略查询结构特性(如恒定延迟需物化全部结果)。第二要素(定理2)将定理1的数据结构与称为连接树分解[5]的树分解技术结合。该树分解通过限制树结构，确保修饰视图中的绑定变量始终在树顶部形成连通分量。

Finally, we discuss the complexity of choosing the optimal parameters for our two main theorems, when we want to optimize for delay given a space constraint, or vice versa.

最后，我们讨论了在空间约束条件下优化延迟参数（或反之）时，为两个主要定理选择最优参数的复杂性。

Organization. We present our framework in Section 2, along with the preliminaries and basic notation. Our two main results (Theorems 1 and 2) are presented in Section 3. We then present the detailed construction of the data structure of Theorem 1 in Section 4, and of Theorem 2 in Section 5. Finally, in Section 6, we discuss some complexity results for optimizing the choice of parameters.

论文结构。第2节介绍研究框架、预备知识和基本符号；第3节呈现两个主要结果（定理1和定理2）；第4节详细阐述定理1数据结构的构建；第5节展开定理2的构造过程；第6节最终探讨参数优化选择的复杂度问题。

In this section we present the basic notions and terminology, and then discuss in detail our framework.

### 2.1 Conjunctive Queries

### 2.1 合取查询

In this paper we will focus on the class of conjunctive queries (CQs), which are expressed as

本文重点研究合取查询（CQs）类，其表达式形式为

$$
Q\left( \mathbf{y}\right)  = {R}_{1}\left( {\mathbf{x}}_{1}\right) ,{R}_{2}\left( {\mathbf{x}}_{2}\right) ,\ldots ,{R}_{n}\left( {\mathbf{x}}_{n}\right) 
$$

Here,the symbols $\mathbf{y},{\mathbf{x}}_{1},\ldots ,{\mathbf{x}}_{n}$ are vectors that contain variables or constants,the atom $Q\left( \mathbf{y}\right)$ is the head of the query,and the atoms ${R}_{1}\left( {\mathbf{x}}_{1}\right) ,{R}_{2}\left( {\mathbf{x}}_{2}\right) ,\ldots ,{R}_{n}\left( {\mathbf{x}}_{n}\right)$ form the body. The variables in the head are a subset of the variables that appear in the body. A CQ is full if every variable in the body appears also in the head, and it is boolean if the head contains no variables,i.e. it is of the form $Q\left( \right)$ . We will typically use the symbols $x,y,z,\ldots$ to denote variables, and $a,b,c,\ldots$ to denote constants. If $D$ is an input database,we denote by $Q\left( D\right)$ the result of running $Q$ over $D$ .

此处符号$\mathbf{y},{\mathbf{x}}_{1},\ldots ,{\mathbf{x}}_{n}$表示包含变量或常量的向量，原子公式$Q\left( \mathbf{y}\right)$是查询头，原子公式集合${R}_{1}\left( {\mathbf{x}}_{1}\right) ,{R}_{2}\left( {\mathbf{x}}_{2}\right) ,\ldots ,{R}_{n}\left( {\mathbf{x}}_{n}\right)$构成查询体。查询头中的变量是查询体变量的子集。若查询体中所有变量均出现在查询头，则称为完全合取查询；若查询头不含变量（即形如$Q\left( \right)$），则称为布尔查询。通常用$x,y,z,\ldots$表示变量，$a,b,c,\ldots$表示常量。给定输入数据库$D$时，$Q\left( D\right)$表示$Q$在$D$上的执行结果。

Natural Joins. If a CQ is full, has no constants and no repeated variables in the same atom, then we say it is a natural join query. For instance,the triangle query $\Delta \left( {x,y,z}\right)  = R\left( {x,y}\right) ,S\left( {y,z}\right) ,T\left( {z,x}\right)$ is a natural join query. A natural join can be represented equivalently as a hypergraph $\mathcal{H} = \left( {\mathcal{V},\mathcal{E}}\right)$ ,where $\mathcal{V}$ is the set of variables, and for each hyperedge $F \in  \mathcal{E}$ there exists a relation ${R}_{F}$ with variables $F$ . We will write the join as ${ \bowtie  }_{F \in  \mathcal{E}}{R}_{F}$ . The size of relation ${R}_{F}$ is denoted by $\left| {R}_{F}\right|$ . Given a set of variables $I \subseteq  \mathcal{V}$ ,we define ${\mathcal{E}}_{I} = \{ F \in  \mathcal{E} \mid  F \cap  I \neq  \varnothing \} .$

自然连接。若合取查询满足完全性、无常量且同一原子内无重复变量，则称为自然连接查询。例如三角形查询$\Delta \left( {x,y,z}\right)  = R\left( {x,y}\right) ,S\left( {y,z}\right) ,T\left( {z,x}\right)$即属此类。自然连接可等价表示为超图$\mathcal{H} = \left( {\mathcal{V},\mathcal{E}}\right)$：其中$\mathcal{V}$是变量集合，每个超边$F \in  \mathcal{E}$对应具有变量$F$的关系${R}_{F}$。该连接记作${ \bowtie  }_{F \in  \mathcal{E}}{R}_{F}$，关系${R}_{F}$的规模记为$\left| {R}_{F}\right|$。对于变量集$I \subseteq  \mathcal{V}$，我们定义${\mathcal{E}}_{I} = \{ F \in  \mathcal{E} \mid  F \cap  I \neq  \varnothing \} .$

Valuations. A valuation $v$ over a subset $V$ of the variables is a total function that maps each variable $x \in  V$ to a value $v\left( x\right)  \in$ dom, where dom is a domain of constants. Given a valuation $v$ of the variables $\left( {{x}_{{i}_{1}},\ldots ,{x}_{{i}_{\ell }}}\right)$ ,we denote ${R}_{F}\left( v\right)  = {R}_{F} \ltimes  \left\{  {v\left( {{x}_{{i}_{1}},\ldots ,{x}_{{i}_{\ell }}}\right) }\right\}$ . Join Size Bounds. Let $\mathcal{H} = \left( {\mathcal{V},\mathcal{E}}\right)$ be a hypergraph,and $S \subseteq  \mathcal{V}$ . A weight assignment $\mathbf{u} = {\left( {u}_{F}\right) }_{F \in  \mathcal{E}}$ is called a fractional edge cover of $S$ if(i)for every $F \in  \mathcal{E},{u}_{F} \geq  0$ and(ii)for every $x \in  S,\mathop{\sum }\limits_{{F : x \in  F}}{u}_{F} \geq$ 1. The fractional edge cover number of $S$ ,denoted by ${\rho }_{\mathcal{H}}^{ * }\left( S\right)$ is the minimum of $\mathop{\sum }\limits_{{F \in  \mathcal{E}}}{u}_{F}$ over all fractional edge covers of $S$ . We write ${\rho }^{ * }\left( \mathcal{H}\right)  = {\rho }_{\mathcal{H}}^{ * }\left( \mathcal{V}\right)$

估值。变量子集$V$上的估值$v$是一个全函数，它将每个变量$x \in  V$映射到值域dom中的某个值$v\left( x\right)  \in$，其中dom是常量构成的域。给定变量集$\left( {{x}_{{i}_{1}},\ldots ,{x}_{{i}_{\ell }}}\right)$的估值$v$，我们记作${R}_{F}\left( v\right)  = {R}_{F} \ltimes  \left\{  {v\left( {{x}_{{i}_{1}},\ldots ,{x}_{{i}_{\ell }}}\right) }\right\}$。连接大小界。设$\mathcal{H} = \left( {\mathcal{V},\mathcal{E}}\right)$为超图，且$S \subseteq  \mathcal{V}$。权重分配$\mathbf{u} = {\left( {u}_{F}\right) }_{F \in  \mathcal{E}}$被称为$S$的分数边覆盖，若满足：(i) 对每个$F \in  \mathcal{E},{u}_{F} \geq  0$；(ii) 对每个$x \in  S,\mathop{\sum }\limits_{{F : x \in  F}}{u}_{F} \geq$值为1。$S$的分数边覆盖数记作${\rho }_{\mathcal{H}}^{ * }\left( S\right)$，是所有分数边覆盖中$\mathop{\sum }\limits_{{F \in  \mathcal{E}}}{u}_{F}$的最小值。我们记作${\rho }^{ * }\left( \mathcal{H}\right)  = {\rho }_{\mathcal{H}}^{ * }\left( \mathcal{V}\right)$

In a celebrated result, Atserias, Grohe and Marx [4] proved that for every fractional edge cover $\mathbf{u}$ of $\mathcal{V}$ ,the size of a natural join is bounded using the following inequality, known as the AGM inequality:

在著名成果中，Atserias、Grohe和Marx[4]证明了：对于$\mathcal{V}$的每个分数边覆盖$\mathbf{u}$，自然连接的大小受以下不等式限制（称为AGM不等式）：

$$
\left| {{ \bowtie  }_{F \in  \mathcal{E}}{R}_{F}}\right|  \leq  \mathop{\prod }\limits_{{F \in  \mathcal{E}}}{\left| {R}_{F}\right| }^{{u}_{F}} \tag{1}
$$

The above bound is constructive [18, 19]: there exist worst-case algorithms that compute the join ${ \bowtie  }_{F \in  \mathcal{E}}{R}_{F}$ in time $O\left( {\mathop{\prod }\limits_{{F \in  \mathcal{E}}}{\left| {R}_{F}\right| }^{{u}_{F}}}\right)$ for every fractional edge cover $\mathbf{u}$ of $\mathcal{V}$ .

该上界具有构造性[18,19]：存在最坏情况下能在时间$O\left( {\mathop{\prod }\limits_{{F \in  \mathcal{E}}}{\left| {R}_{F}\right| }^{{u}_{F}}}\right)$内计算连接${ \bowtie  }_{F \in  \mathcal{E}}{R}_{F}$的算法，适用于$\mathcal{V}$的每个分数边覆盖$\mathbf{u}$。

Tree Decompositions. Let $\mathcal{H} = \left( {\mathcal{V},\mathcal{E}}\right)$ be a hypergraph of a natural join query $Q$ . A tree decomposition of $\mathcal{H}$ is a tuple $\left( {\mathcal{T},{\left( {\mathcal{B}}_{t}\right) }_{t \in  V\left( \mathcal{T}\right) }}\right)$ where $\mathcal{T}$ is a tree,and every ${\mathcal{B}}_{t}$ is a subset of $\mathcal{V}$ ,called the bag of $t$ , such that

树分解。设$\mathcal{H} = \left( {\mathcal{V},\mathcal{E}}\right)$为自然连接查询$Q$的超图。$\mathcal{H}$的树分解是元组$\left( {\mathcal{T},{\left( {\mathcal{B}}_{t}\right) }_{t \in  V\left( \mathcal{T}\right) }}\right)$，其中$\mathcal{T}$是树结构，每个${\mathcal{B}}_{t}$是$\mathcal{V}$的子集（称为$t$的包），满足：

(1) each edge in $\mathcal{E}$ is contained in some bag ${\mathcal{B}}_{t}$ ; and

(1) $\mathcal{E}$中的每条边都包含在某个包${\mathcal{B}}_{t}$中；且

(2) for each $x \in  \mathcal{V}$ ,the set of nodes $\left\{  {t \mid  x \in  {\mathcal{B}}_{t}}\right\}$ is connected in $\mathcal{T}$ .

(2) 对每个$x \in  \mathcal{V}$，节点集$\left\{  {t \mid  x \in  {\mathcal{B}}_{t}}\right\}$在$\mathcal{T}$中保持连通。

The fractional hypertree width of a tree decomposition is defined as $\mathop{\max }\limits_{{t \in  V\left( \mathcal{T}\right) }}{\rho }^{ * }\left( {\mathcal{B}}_{t}\right)$ ,where ${\rho }^{ * }\left( {\mathcal{B}}_{t}\right)$ is the minimum fractional edge cover of the vertices in ${\mathcal{B}}_{t}$ . The fractional hypertree width of a query $Q$ ,denoted flw(Q),is the minimum fractional hypertree width among all tree decompositions of its hypergraph.

树分解的分数超树宽度定义为$\mathop{\max }\limits_{{t \in  V\left( \mathcal{T}\right) }}{\rho }^{ * }\left( {\mathcal{B}}_{t}\right)$，其中${\rho }^{ * }\left( {\mathcal{B}}_{t}\right)$表示${\mathcal{B}}_{t}$中顶点的最小分数边覆盖。查询$Q$的分数超树宽度（记作flw(Q)）是其超图所有树分解中分数超树宽度的最小值。

Computational Model. To measure the running time of our algorithms, we will use the uniform-cost RAM model [17], where data values as well as pointers to databases are of constant size. Throughout the paper, all complexity results are with respect to data complexity (unless explicitly mentioned), where the query is assumed fixed.

计算模型。为衡量算法运行时间，我们采用均一成本RAM模型[17]，其中数据值和数据库指针均为常量大小。本文所有复杂度结果均基于数据复杂度（除非特别说明），假定查询是固定的。

We use the notation $\widetilde{O}$ to hide a polylogarithmic factor ${\log }^{k}\left| D\right|$ for some constant $k$ ,where $D$ is the input database.

使用记号$\widetilde{O}$来隐藏某个常数$k$对应的多对数因子${\log }^{k}\left| D\right|$，其中$D$为输入数据库。

### 2.2 Adorned Views

### 2.2 装饰视图

In order to model access patterns over a view $Q$ defined over the input database, we will use the concept of adorned views [27]. In an adorned view, each variable in the head of the view definition is associated with a binding type, which can be either bound (b) or free (f). A view $Q\left( {{x}_{1},\ldots ,{x}_{k}}\right)$ is then written as ${Q}^{\eta }\left( {{x}_{1},\ldots ,{x}_{k}}\right)$ , where $\eta  \in  \{ \mathrm{b},\mathrm{f}{\} }^{k}$ is called the access pattern. We denote by ${\mathcal{V}}_{\mathrm{b}}$ (resp. ${\mathcal{V}}_{\mathrm{f}}$ ) the set of bound (resp. free) variables from $\left\{  {{x}_{1},\ldots ,{x}_{k}}\right\}$ .

为建模输入数据库上视图$Q$的访问模式，我们引入装饰视图概念[27]。在装饰视图中，视图定义头部的每个变量都关联一个绑定类型：约束型(b)或自由型(f)。视图$Q\left( {{x}_{1},\ldots ,{x}_{k}}\right)$可表示为${Q}^{\eta }\left( {{x}_{1},\ldots ,{x}_{k}}\right)$，其中$\eta  \in  \{ \mathrm{b},\mathrm{f}{\} }^{k}$称为访问模式。用${\mathcal{V}}_{\mathrm{b}}$（相应地${\mathcal{V}}_{\mathrm{f}}$）表示$\left\{  {{x}_{1},\ldots ,{x}_{k}}\right\}$中的约束型（自由型）变量集合。

We can interpret an adorned view as a function that maps a valuation over the bound variables ${\mathcal{V}}_{\mathrm{b}}$ to a relation over the free variables ${\mathcal{V}}_{\mathrm{f}}$ . In other words,for each valuation $v$ over ${\mathcal{V}}_{\mathrm{b}}$ ,the adorned view returns the answer for the query ${Q}^{\eta }\left\lbrack  v\right\rbrack   = \left\{  {\mathcal{V}}_{\mathrm{f}}\right.$ $\left. {Q\left( {{x}_{1},\ldots ,{x}_{k}}\right) \land \forall {x}_{i} \in  {\mathcal{V}}_{\mathrm{b}} : {x}_{i} = v\left( {x}_{i}\right) }\right\}$ ,which we will also refer to as an access request.

装饰视图可解释为将约束变量${\mathcal{V}}_{\mathrm{b}}$上的赋值映射到自由变量${\mathcal{V}}_{\mathrm{f}}$关系的函数。换言之，对于${\mathcal{V}}_{\mathrm{b}}$上的每个赋值$v$，装饰视图返回查询${Q}^{\eta }\left\lbrack  v\right\rbrack   = \left\{  {\mathcal{V}}_{\mathrm{f}}\right.$$\left. {Q\left( {{x}_{1},\ldots ,{x}_{k}}\right) \land \forall {x}_{i} \in  {\mathcal{V}}_{\mathrm{b}} : {x}_{i} = v\left( {x}_{i}\right) }\right\}$的答案，该查询也被称为访问请求。

Example 2. ${\Delta }^{\mathrm{{bbf}}}\left( {x,y,z}\right)  = R\left( {x,y}\right) ,S\left( {y,z}\right) ,T\left( {z,x}\right)$ captures the following access pattern: given values $x = a,y = b$ ,list all the $z$ - values that form a triangle with the edge $R\left( {a,b}\right)$ . As another example, ${\Delta }^{\text{fff }}\left( {x,y,z}\right)  = R\left( {x,y}\right) ,S\left( {y,z}\right) ,T\left( {z,x}\right)$ simply captures the case where we want to perform a full enumeration of all the triangles in the result. Finally, ${\Delta }^{\mathrm{b}}\left( x\right)  = R\left( {x,y}\right) ,S\left( {y,z}\right) ,T\left( {z,x}\right)$ expresses the access pattern where given a node with $x = a$ ,we want to know whether there exists a triangle that contains it or not.

示例2。${\Delta }^{\mathrm{{bbf}}}\left( {x,y,z}\right)  = R\left( {x,y}\right) ,S\left( {y,z}\right) ,T\left( {z,x}\right)$描述以下访问模式：给定值$x = a,y = b$，列出所有与边$R\left( {a,b}\right)$构成三角形的$z$值。另一示例${\Delta }^{\text{fff }}\left( {x,y,z}\right)  = R\left( {x,y}\right) ,S\left( {y,z}\right) ,T\left( {z,x}\right)$描述需要完整枚举结果中所有三角形的情况。最后，${\Delta }^{\mathrm{b}}\left( x\right)  = R\left( {x,y}\right) ,S\left( {y,z}\right) ,T\left( {z,x}\right)$表示给定$x = a$节点时，查询是否存在包含该节点的三角形的访问模式。

An adorned view ${Q}^{\eta }\left( {{x}_{1},\ldots ,{x}_{k}}\right)$ is boolean if every head variable is bound, it is non-parametric if every head variable is free, and it is full if the CQ if full (i.e., every variable in the body also appears in the head). Of particular interest is the adorned view that is full and non-parametric, which we call the full enumeration view, and simply asks to output the whole result.

若装饰视图${Q}^{\eta }\left( {{x}_{1},\ldots ,{x}_{k}}\right)$中所有头部变量都被绑定，则称其为布尔型；若所有头部变量均为自由变量，则称其为非参数化；若该视图对应的合取查询是完整的（即主体中所有变量也出现在头部），则称其为完整型。特别值得关注的是既完整又非参数化的装饰视图，我们称之为全枚举视图，其功能仅为输出整个结果集。

### 2.3 Problem Statement

### 2.3 问题陈述

Given an adorned view ${Q}^{\eta }\left( {{x}_{1},\ldots ,{x}_{k}}\right)$ and an input database $D$ , our goal is to answer any access request ${Q}^{\eta }\left\lbrack  v\right\rbrack$ that conforms to the access pattern $\eta$ . The view $Q$ can be expressed through any type of query,but in this work we will focus on the case where $Q$ is a conjunctive query.

给定装饰视图${Q}^{\eta }\left( {{x}_{1},\ldots ,{x}_{k}}\right)$和输入数据库$D$，我们的目标是响应符合访问模式$\eta$的任何访问请求${Q}^{\eta }\left\lbrack  v\right\rbrack$。该视图$Q$可通过任意类型查询表达，但本工作将聚焦于$Q$为合取查询的情况。

There are two extremal approaches to handle this problem. The first solution is to answer any such query directly on the input database $D$ ,without materializing $Q\left( D\right)$ . This solution is efficient in terms of space, but it can lead to inefficient query answering. For instance,consider the adorned view ${\Delta }^{\text{bbf }}\left( {x,y,z}\right)  = R\left( {x,y}\right) ,S\left( {y,z}\right)$ , $T\left( {z,x}\right)$ . Then,every time we are given new values $x = a,y = b$ ,we would have to compute all the nodes $c$ that form a triangle with $a,b$ ,which can be very expensive.

处理该问题存在两种极端方案：第一种是直接在输入数据库$D$上响应查询，无需物化$Q\left( D\right)$。此方案空间效率高，但可能导致查询响应低效。例如对于装饰视图${\Delta }^{\text{bbf }}\left( {x,y,z}\right)  = R\left( {x,y}\right) ,S\left( {y,z}\right)$,$T\left( {z,x}\right)$，每当获取新值$x = a,y = b$时，都需计算与$a,b$构成三角形的所有节点$c$，计算代价极高。

The second solution is to materialize the view $Q\left( D\right)$ ,and then answer any incoming query over the materialized result. For example, we could choose to materialize all triangles, and then create an appropriate index over the output result. The drawback of this approach is that it requires a lot of space, which may not be available.

第二种方案是物化视图$Q\left( D\right)$，然后在物化结果上响应查询。例如可物化所有三角形并在输出结果上创建适当索引。此方法的缺点是需要大量存储空间，而空间资源可能不足。

We propose to study the solution space between these two extremal solutions,that is,instead of materializing all of $Q\left( D\right)$ ,we would like to store a compressed representation ${\mathrm{C}}_{Q}\left( D\right)$ of $Q\left( D\right)$ . The compression function ${\mathrm{C}}_{Q}$ must guarantee that the compression is lossless,i.e.,there exists a decompression function ${\mathrm{D}}_{Q}$ such that for every database $D$ ,it holds that ${\mathrm{D}}_{Q}\left( {{\mathrm{C}}_{Q}\left( D\right) }\right)  = Q\left( D\right)$ . We compute the compressed representation ${\mathrm{C}}_{Q}\left( D\right)$ during a preprocessing phase, and then answer any access request in an online phase.

我们提出研究这两种极端方案之间的折中方案：即不完整物化$Q\left( D\right)$，而是存储其压缩表示${\mathrm{C}}_{Q}\left( D\right)$。压缩函数${\mathrm{C}}_{Q}$必须保证无损压缩，即存在解压函数${\mathrm{D}}_{Q}$使得对任意数据库$D$都满足${\mathrm{D}}_{Q}\left( {{\mathrm{C}}_{Q}\left( D\right) }\right)  = Q\left( D\right)$。预处理阶段计算压缩表示${\mathrm{C}}_{Q}\left( D\right)$，在线阶段响应访问请求。

Parameters. Our goal is to construct a compression that is as space-efficient as possible, while it guarantees that we can efficiently answer any access query. In particular, we are interested in measuring the tradeoff between the following parameters, which are also depicted in Figure 1:

参数指标。我们的目标是构建空间效率最优的压缩方案，同时保证高效响应访问查询。特别关注以下参数的权衡关系（如图1所示）：

Compression Time $\left( {T}_{C}\right)$ : the time to compute ${\mathrm{C}}_{Q}\left( D\right)$ during the preprocessing phase.

压缩时间$\left( {T}_{C}\right)$：预处理阶段计算${\mathrm{C}}_{Q}\left( D\right)$所需时间。

Space(S): the size of ${\mathrm{C}}_{Q}\left( D\right)$ .

空间(S)：${\mathrm{C}}_{Q}\left( D\right)$的存储大小。

Answer Time: this parameter measures the time to enumerate a query result,where the query is of the form ${Q}^{\eta }\left\lbrack  v\right\rbrack$ . The enumeration algorithm must(i)enumerate the query result without any repetitions of tuples,and(ii)use only $O\left( {\log \left| D\right| }\right)$ extra memory ${}^{2}$ . We will measure answer time in two different ways.

响应时间：该参数测量枚举查询结果的时间（查询形式为${Q}^{\eta }\left\lbrack  v\right\rbrack$）。枚举算法必须满足：(i)无重复元组枚举结果，(ii)仅使用$O\left( {\log \left| D\right| }\right)$额外内存${}^{2}$。我们将通过两种方式测量响应时间。

(1) delay $\left( \delta \right)$ : the maximum time to output any two consecutive tuples (and also the time to output the first tuple, and the time to notify that the enumeration has completed).

(1)延迟$\left( \delta \right)$：输出任意两个连续元组的最大间隔时间（包括输出首元组时间和枚举完成通知时间）。

(2) total answer time $\left( {T}_{A}\right)$ : the total time to output the result.

(2)总响应时间$\left( {T}_{A}\right)$：输出结果的总耗时。

In the case of a boolean adorned view, the delay and the total answer time coincide. In an ideal situation, both the compression time and the space are linear to the input size and any query can be answered with constant delay $O\left( 1\right)$ . As we will see later,this is achievable in certain cases, but in most cases we have to tradeoff space and preprocessing time for delay and total answer time.

对于布尔修饰视图而言，延迟时间与总应答时间完全一致。在理想情况下，压缩时间和空间均与输入规模呈线性关系，且任何查询都能以恒定延迟$O\left( 1\right)$应答。后文将说明这种情况在某些特定条件下可以实现，但大多数情况下我们必须在空间/预处理时间与延迟/总应答时间之间进行权衡。

### 2.4 Some Basic Results

### 2.4 基础性结论

We present here some basic results that set up a baseline for our framework. We will study the case where the given view definition $Q$ is a conjunctive query.

本节提出若干基础性结论，为我们的研究框架建立基准。我们将重点研究给定视图定义$Q$为合取查询的情况。

Our first observation is that if we allow the compression time to be at least $\Omega \left( \left| D\right| \right)$ ,we can assume without loss of generality that the adorned view ${Q}^{\eta }$ has no constants or repeated variables in a single atom. Indeed, we can first do a linear time computation to rewrite the adorned view ${Q}^{\eta }$ to a new view where constants and repeated variables are removed, and then compute the compressed representation for this new view (with the same adornment).

首先观察到：若允许压缩时间至少为$\Omega \left( \left| D\right| \right)$，则在不失一般性的前提下可假设修饰视图${Q}^{\eta }$的单原子中不含常量或重复变量。实际上，我们可以通过线性时间计算将修饰视图${Q}^{\eta }$重写为去除常量及重复变量的新视图，再为此新视图（保持相同修饰）计算压缩表示。

Example 3. Consider ${Q}^{\mathrm{{fb}}}\left( {x,z}\right)  = R\left( {x,y,a}\right) ,S\left( {y,y,z}\right)$ . We can first compute in linear time ${R}^{\prime }\left( {x,y}\right)  = R\left( {x,y,a}\right)$ and ${S}^{\prime }\left( {y,z}\right)  = S\left( {y,y,z}\right)$ , and then rewrite the adorned view as ${Q}^{\mathrm{{fb}}}\left( {x,z}\right)  = {R}^{\prime }\left( {x,y}\right) ,{S}^{\prime }\left( {y,z}\right)$ .

## 3 MAIN RESULTS AND APPLICATION

## 3 主要成果与应用

In this section we present our two main results, and show how they can be applied. The first result (Theorem 1) is a compression primitive that can be used with any full adorned view. The second result (Theorem 2) builds upon Theorem 1 and query decomposition techniques to obtain an improved tradeoff between space and delay.

本节呈现两项主要研究成果及其应用。第一项成果（定理1）是可与任何完整装饰视图配合使用的压缩原语。第二项成果（定理2）基于定理1和查询分解技术，实现了空间复杂度与延迟时间的最优权衡。

需特别说明，我们的数据结构严格泛化了文献[11]中针对快速集合交集问题提出的数据结构。给定集合族${S}_{1},\ldots ,{S}_{n}$，该问题的目标是构建空间高效的数据结构，使得给定任意两个集合${S}_{i},{S}_{j}$时能快速计算其交集${S}_{i} \cap  {S}_{j}$。显然，该问题可通过修饰视图${S}_{2}^{\mathrm{{bbf}}}\left( {{x}_{1},{x}_{2},z}\right)  = R\left( {{x}_{1},z}\right) ,R\left( {{x}_{2},z}\right)$捕获，其中$R$是描述集合成员关系的关系，$\left( {R\left( {{S}_{i},a}\right) }\right.$表示$\left. {a \in  {S}_{i}}\right)$。

### 3.2 Second Main Result

### 3.2 第二项主要成果

The direct application of Theorem 1 can lead to suboptimal tradeoffs between space and time/delay, since it ignores the structural properties of the query. In this section, we show how to overcome this problem by combining Theorem 1 with tree decompositions.

直接应用定理1可能导致空间与时间/延迟之间的次优权衡，因其忽略了查询的结构特性。本节将展示如何通过结合定理1与树分解来克服此问题。

We first need to introduce a variant of a tree decomposition of a hypergraph $\mathcal{H} = \left( {\mathcal{V},\mathcal{E}}\right)$ ,defined with respect to a given subset $C \subseteq  \mathcal{V}$ .

Definition 1 (Connex Tree Decomposition [5]). Let $\mathcal{H} =$ (V,E)be a hypergraph,and $C \subseteq  \mathcal{V}$ . AC-connex tree decomposition of $\mathcal{H}$ is a tuple(T,A),where:

(1) $\mathcal{T} = \left( {\mathcal{T},{\left( {\mathcal{B}}_{t}\right) }_{t \in  V\left( \mathcal{T}\right) }}\right)$ is a tree decomposition of $\mathcal{H}$ ; and

(1) $\mathcal{T} = \left( {\mathcal{T},{\left( {\mathcal{B}}_{t}\right) }_{t \in  V\left( \mathcal{T}\right) }}\right)$是$\mathcal{H}$的树分解；且

Observe that when all variables are free,then ${\mathcal{V}}_{\mathrm{b}} = \varnothing$ ,in which case ${f}_{\mathrm{{hw}}}\left( {\mathcal{H} \mid  {\mathcal{V}}_{\mathrm{b}}}\right)  = {f}_{\mathrm{{hw}}}\left( \mathcal{H}\right)$ ,thus recovering the compression result of a $d$ -representation. 注意到当所有变量都自由时，${\mathcal{V}}_{\mathrm{b}} = \varnothing$成立，此时${f}_{\mathrm{{hw}}}\left( {\mathcal{H} \mid  {\mathcal{V}}_{\mathrm{b}}}\right)  = {f}_{\mathrm{{hw}}}\left( \mathcal{H}\right)$，从而恢复了$d$表示的压缩结果。此外，由于所有包的延迟分配均为0，压缩时间${T}_{C} = \widetilde{O}\left( {\left| D\right|  + {\left| D\right| }^{\mathrm{{fhw}}\left( {\mathcal{H} \mid  {\mathcal{V}}_{\mathrm{b}}}\right) }}\right)$。

Beyond full adorned views. Our work provides compression strategies for queries that do not admit out-of-the-box factorization (such as Loomis-Whitney joins), and can also recover the result of compressed $d$ -representations as a special case when all variables are free (Proposition 4). On the other hand, factorized databases support a much richer set of queries such as projections,aggregations $\left\lbrack  {6,7}\right\rbrack$ and analytical tasks such as learning regression models [21, 24]. One possible approach to handling projections in our setting is to force a variable ordering in the ${\mathcal{V}}_{\mathrm{b}}$ -connex decomposition: more precisely, we can force projection variables to appear first in any root to leaf path. This idea of fixing variable ordering would be similar to how order-by clauses are handled in $d$ -tree query plans [6]. Remarkably,the ${\mathcal{V}}_{\mathrm{b}}$ -connex decomposition in our setting also corresponds to the tree decompositions used to compute aggregations and orderings with group-by attributes as ${\mathcal{V}}_{\mathrm{b}}$ [21]. This points to a deeper connection between our compressed representation and $d$ -tree representations used to compute group-by aggregates. We defer the study of these connections and extension of our framework to incorporate more expressive queries to future work.

超越全装饰视图的局限。我们的研究为无法直接进行因子分解的查询（如Loomis-Whitney连接）提供了压缩策略，并且当所有变量都自由时（命题4），还能将压缩$d$表示的结果恢复为特例。另一方面，因子化数据库支持更丰富的查询操作，如投影、聚合$\left\lbrack  {6,7}\right\rbrack$以及回归模型学习等分析任务[21,24]。在我们的框架中处理投影的一种可能方法是强制变量在${\mathcal{V}}_{\mathrm{b}}$-连通分解中按特定顺序排列：更准确地说，我们可以强制投影变量在任何从根到叶的路径中首先出现。这种固定变量顺序的思路类似于$d$树查询计划中处理order-by子句的方式[6]。值得注意的是，我们框架中的${\mathcal{V}}_{\mathrm{b}}$-连通分解也对应于用于计算带有分组属性的聚合和排序的树分解[21]。这表明我们的压缩表示与用于计算分组聚合的$d$树表示之间存在更深层次的联系。关于这些关联的研究以及扩展我们的框架以支持更具表现力的查询，我们将留待未来工作。

### 3.3 A Remark on Optimality

### 3.3 关于最优性的说明

So far we have not discussed the optimality of our results. We remark why proving tight lower bounds might be a hard problem.

迄今为止，我们尚未讨论研究结果的最优性。我们将阐述为何证明严格下界可能是一个难题。

The problem of k-SetDisjointness is defined as follows. Given a family of sets ${S}_{1},\ldots ,{S}_{m}$ of total size $N$ ,we want to ask queries of the following form: given as input a subset $I \subseteq  \{ 1,\ldots ,m\}$ of size $k$ ,is the intersection $\mathop{\bigcap }\limits_{{i \in  I}}{S}_{i}$ empty? The goal is to construct a space-efficient data structure such that we can answer as fast as possible. Note that k-SetDisjointness corresponds to the following adorned view: ${Q}^{\mathrm{b}\cdots \mathrm{b}}\left( {{x}_{1},\ldots ,{x}_{k}}\right)  = R\left( {{x}_{1},z}\right) ,R\left( {{x}_{2},z}\right) ,\ldots ,R\left( {{x}_{k},z}\right)$ , where $R$ has size $N$ . One can see that we can use the data structure for the corresponding full view with head ${Q}^{\mathrm{b}\cdots \mathrm{{bf}}}\left( {{x}_{1},\ldots ,{x}_{k},z}\right)$ (see Example 7) to answer k-SetDisjointness queries in time $\widetilde{O}\left( \tau \right)$ ,using space $\widetilde{O}\left( {{N}^{k}/{\tau }^{k}}\right)$ .

k-集合不相交问题定义如下：给定总大小为$N$的集合族${S}_{1},\ldots ,{S}_{m}$，我们需要回答形如"给定大小为$k$的子集$I \subseteq  \{ 1,\ldots ,m\}$，其交集$\mathop{\bigcap }\limits_{{i \in  I}}{S}_{i}$是否为空？"的查询。目标是构建空间高效的数据结构以实现快速响应。注意k-集合不相交问题对应以下装饰视图：${Q}^{\mathrm{b}\cdots \mathrm{b}}\left( {{x}_{1},\ldots ,{x}_{k}}\right)  = R\left( {{x}_{1},z}\right) ,R\left( {{x}_{2},z}\right) ,\ldots ,R\left( {{x}_{k},z}\right)$，其中$R$的大小为$N$。可以看出，我们可以使用头部为${Q}^{\mathrm{b}\cdots \mathrm{{bf}}}\left( {{x}_{1},\ldots ,{x}_{k},z}\right)$的完整视图数据结构（参见例7），在$\widetilde{O}\left( \tau \right)$时间内回答k-集合不相交查询，占用$\widetilde{O}\left( {{N}^{k}/{\tau }^{k}}\right)$空间。

In a recent work, Goldstein et al. [15] conjecture the following lower bound:

在近期研究中，Goldstein等人[15]提出了以下下界猜想：

Applied in our setting,Conjecture 1 implies that for the adorned view ${Q}^{\mathrm{b}\cdots \mathrm{b}}\left( {{x}_{1},\ldots ,{x}_{k}}\right)  = {R}_{1}\left( {{x}_{1},z}\right)$ , ${R}_{2}\left( {{x}_{2},z}\right) ,\ldots ,{R}_{k}\left( {{x}_{k},z}\right)$ ,the tradeoff between space and delay (or answer time) is essentially optimal when all relations have equal size. Unfortunately, proving even the weaker conjecture of [23] is considered a hard open problem.

上述猜想是对文献[13]中关于$k = 2$情形的猜想之推广，而该猜想本身又是对Patrascu和Roditty[23]提出的民间猜想的泛化——后者仅针对$\tau  = 1$且$k = 2$的情况。应用至我们的场景时，猜想1表明：对于修饰视图${Q}^{\mathrm{b}\cdots \mathrm{b}}\left( {{x}_{1},\ldots ,{x}_{k}}\right)  = {R}_{1}\left( {{x}_{1},z}\right)$和${R}_{2}\left( {{x}_{2},z}\right) ,\ldots ,{R}_{k}\left( {{x}_{k},z}\right)$而言，当所有关系规模相同时，空间与延迟（或应答时间）之间的权衡本质上是最优的。遗憾的是，即便证明[23]中较弱的猜想也被视为一个困难的开放性问题。

### 4.1 Intervals and Boxes

Before we present the compression procedure, we first introduce two important concepts in our construction, f-intervals and f-boxes, both of which describe subspaces of the space of all possible tuples in the output.

Intervals. The active domain $\mathrm{D}\left\lbrack  x\right\rbrack$ of each variable $x$ is equipped with a total order $\leq$ induced from the order of dom. ### 4.2 Two Key Ingredients

### 4.2 两个关键要素

We describe the intuition behind the compression representation. Our data structure is parametrized by an integer $\tau  > 0$ ,which can be viewed as a threshold parameter that works as a knob. We seek to compute the result $\left( {{ \bowtie  }_{F \in  \mathcal{E}}{R}_{F}\left( {v}_{\mathrm{b}}\right) }\right)  \ltimes  \mathrm{I}$ ,where $\mathrm{I}$ is initially the f-interval that represents all possible valuations over ${\mathcal{V}}_{\mathrm{f}}$ . We can upper bound the running time for this instance using the AGM bound. If the bound is less than $\tau$ ,we can compute the answer in time and delay at most $\tau$ .

## 5 查询分解

In this section, we prove Theorem 2. Consider an adorned view over a natural join query (with hypergraph $\mathcal{H}$ ),with bound variables ${\mathcal{V}}_{\mathrm{b}}$ . Fix a ${\mathcal{V}}_{\mathrm{b}}$ -connex tree decomposition(T,A). Observe that,since the bags in $A$ do not play any role in the width or height,we can assume w.l.o.g. that $A$ consists of a single bag ${t}_{\mathrm{b}}$ . We consider the example in Figure 2 as the running example for this section.

本节我们将证明定理2。考虑一个自然连接查询（其超图为$\mathcal{H}$）上的装饰视图，其中绑定变量为${\mathcal{V}}_{\mathrm{b}}$。给定一个${\mathcal{V}}_{\mathrm{b}}$-连通树分解(T,A)。注意到由于$A$中的包对宽度和高度没有影响，我们可以不失一般性地假设$A$仅包含单个包${t}_{\mathrm{b}}$。我们将以图2所示示例作为本节的运行案例。

### 5.1 Constant Delay Enumeration

### 5.1 恒定延迟枚举

As a warm-up, we first show how to construct the data structure for Proposition 4, when our goal is to achieve constant delay for the enumeration of every access query.

作为热身，我们首先展示如何构建命题4所需的数据结构，该结构旨在为每个访问查询实现恒定延迟枚举。

In the full enumeration case,where ${\mathcal{V}}_{\mathrm{b}} = \varnothing$ ,we can take any optimal tree decomposition with fractional hypertree width fhw(H) (so a ${\mathcal{V}}_{\mathrm{b}}$ -connex decomposition),materialize the tuples in each bag by running the query restricted on the vertices of the bag, and finally apply a sequence of semi-joins in a bottom-up order to remove any tuples from the bags that do not participate in the final result. Additionally,for each node $t \in  V\left( \mathcal{T}\right)$ ,we construct a hash index over the materialized result with key ${\mathcal{V}}_{\mathrm{b}}^{t} = {\mathcal{B}}_{t} \cap  \operatorname{anc}\left( t\right)$ ,and output values for the variables in ${\mathcal{V}}_{\mathrm{f}}^{t} = {\mathcal{B}}_{t} \smallsetminus  {\mathcal{V}}_{\mathrm{b}}^{t}$ . For example,the node with bag $\left\{  {{v}_{2},{v}_{3}}\right\}$ constructs an index with key ${v}_{2}$ that returns all the matching values of ${v}_{3}$ . Given such indexes,we can perform a full enumeration in constant delay starting from the root (which will be the empty bag),and visiting the nodes of the tree $\mathcal{T}$ in a pre-order fashion by following the indexes at each bag. This construction uses the same idea as $d$ -representations [22],and requires space $O\left( {\left| D\right| }^{\operatorname{fhw}\left( \mathcal{H}\right) }\right)$ .

在全枚举情况下，当${\mathcal{V}}_{\mathrm{b}} = \varnothing$时，我们可以采用任何分数超树宽度为fhw(H)的最优树分解（即${\mathcal{V}}_{\mathrm{b}}$-连通分解），通过运行限制在袋顶点上的查询具体化每个袋中的元组，最后以自底向上顺序应用一系列半连接操作，移除不参与最终结果的元组。此外，对于每个节点$t \in  V\left( \mathcal{T}\right)$，我们以键${\mathcal{V}}_{\mathrm{b}}^{t} = {\mathcal{B}}_{t} \cap  \operatorname{anc}\left( t\right)$对具体化结果构建哈希索引，并输出${\mathcal{V}}_{\mathrm{f}}^{t} = {\mathcal{B}}_{t} \smallsetminus  {\mathcal{V}}_{\mathrm{b}}^{t}$中变量的值。例如，包含袋$\left\{  {{v}_{2},{v}_{3}}\right\}$的节点会构建一个键为${v}_{2}$的索引，返回所有匹配的${v}_{3}$值。借助这些索引，我们可以从根节点（即空袋）开始以恒定延迟进行全枚举，通过遵循每个袋的索引以前序方式遍历树节点$\mathcal{T}$。该构造采用了与$d$-表示[22]相同的理念，所需空间为$O\left( {\left| D\right| }^{\operatorname{fhw}\left( \mathcal{H}\right) }\right)$。

When ${\mathcal{V}}_{\mathrm{b}} \neq  \varnothing$ ,the standard tree decomposition may not be useful to achieve constant delay enumeration. For instance, for the example hypergraph of Figure 2,if the adorned view has ${\mathcal{V}}_{\mathrm{b}} =$ $\left\{  {{v}_{1},{v}_{5},{v}_{6}}\right\}$ ,then the pre-order traversal of the decomposition on the left will fail to achieve constant delay. However,we can use a ${\mathcal{V}}_{\mathrm{b}}$ - connex decomposition to successfully answer any access request (e.g., the decomposition on the right in Figure 2). We first materialize all the bags,except for the bag of ${t}_{\mathrm{b}}$ . Then,we run a sequence of semi-joins in a bottom-up manner, where we stop right before the node ${t}_{\mathrm{b}}$ (since it is not materialized). For each node $t \in  V\left( \mathcal{T}\right)  \smallsetminus  \left\{  {t}_{\mathrm{b}}\right\}$ , we construct a hash index over the materialized result with key ${\mathcal{V}}_{\mathrm{b}}^{t}$ . Finally,for the root node ${t}_{\mathrm{b}}$ ,we construct a hash index that tests membership for every hyperedge of $\mathcal{H}$ that is contained in ${\mathcal{V}}_{\mathrm{b}}$ . For the example in Figure 2,we construct one such index for the hyperedge $\left\{  {{v}_{5},{v}_{6}}\right\}$ .

当${\mathcal{V}}_{\mathrm{b}} \neq  \varnothing$时，标准树分解可能无法实现恒定延迟枚举。例如在图2的超图示例中，若装饰视图具有${\mathcal{V}}_{\mathrm{b}} =$$\left\{  {{v}_{1},{v}_{5},{v}_{6}}\right\}$，则左侧分解的前序遍历将无法达成恒定延迟。但我们可以使用${\mathcal{V}}_{\mathrm{b}}$-连通分解成功响应任何访问请求（如图2右侧分解）。我们首先具体化除${t}_{\mathrm{b}}$袋之外的所有袋，然后以自底向上方式运行半连接序列，在到达节点${t}_{\mathrm{b}}$前停止（因其未被具体化）。对于每个节点$t \in  V\left( \mathcal{T}\right)  \smallsetminus  \left\{  {t}_{\mathrm{b}}\right\}$，我们以键${\mathcal{V}}_{\mathrm{b}}^{t}$对具体化结果构建哈希索引。最后对于根节点${t}_{\mathrm{b}}$，我们构建一个测试$\mathcal{H}$中每条超边是否包含于${\mathcal{V}}_{\mathrm{b}}$的成员资格哈希索引。针对图2示例，我们为超边$\left\{  {{v}_{5},{v}_{6}}\right\}$构建了此类索引。

Given a valuation ${v}_{\mathrm{b}}$ over ${\mathcal{V}}_{\mathrm{b}}$ ,we answer the access request as follows. We start by checking in constant time whether ${v}_{\mathrm{b}}\left( {{v}_{5},{v}_{6}}\right)$ is in the input. Then, we use the hash index of the node with bag $\left\{  {{v}_{2},{v}_{4},{v}_{1},{v}_{5}}\right\}$ to find the matching values for ${v}_{2},{v}_{4}$ (since ${v}_{1},{v}_{5}$ are bound by ${v}_{\mathrm{b}}$ ),and subsequently use the hash index of $\left\{  {{v}_{3},{v}_{2},{v}_{4}}\right\}$ to find the matching values for ${v}_{3}$ ; similarly,we also traverse the right subtree starting of the root node to find the matching values of ${v}_{7}$ . We keep doing this traversal until all tuples are enumerated. We describe next how this algorithm generalizes for any adorned view and beyond constant delay.

给定在${\mathcal{V}}_{\mathrm{b}}$上的估值${v}_{\mathrm{b}}$，我们按以下方式响应访问请求：首先以恒定时间检查输入中是否存在${v}_{\mathrm{b}}\left( {{v}_{5},{v}_{6}}\right)$；接着利用节点$\left\{  {{v}_{2},{v}_{4},{v}_{1},{v}_{5}}\right\}$的哈希索引查找${v}_{2},{v}_{4}$的匹配值（因${v}_{1},{v}_{5}$受${v}_{\mathrm{b}}$约束）；继而通过$\left\{  {{v}_{3},{v}_{2},{v}_{4}}\right\}$的哈希索引获取${v}_{3}$的匹配值；同时，我们从根节点出发遍历右子树以定位${v}_{7}$的匹配值。此遍历过程持续进行直至枚举完所有元组。下文将阐述该算法如何推广至任意修饰视图及突破恒定延迟的场景。

### 5.2 Beyond Constant Delay

### 5.2 突破恒定延迟

We will now sketch the construction and query answering for the general case. The detailed construction and algorithms are presented in Appendix C, D. Along with the tree decomposition, let us fix a delay assignment $\delta$ .

现概述通用场景下的构建与查询应答流程，具体构建步骤及算法详见附录C、D。在树分解过程中，需固定延迟分配$\delta$。

Construction Sketch. The first step is to apply for each node $t$ in $\mathcal{T}\left( {\text{except}{t}_{\mathrm{b}}}\right)$ the construction of the data structure from Theorem 1, with the following parameters: (i) hypergraph ${\mathcal{H}}^{\prime } = \left( {{\mathcal{V}}^{\prime },{\mathcal{E}}^{\prime }}\right)$ where ${\mathcal{V}}^{\prime } = {\mathcal{B}}_{t}$ and ${\mathcal{E}}^{\prime } = {\mathcal{E}}_{{\mathcal{B}}_{t}}$ ,(ii) bound variables ${\mathcal{V}}_{\mathrm{b}}^{\prime } = {\mathcal{V}}_{\mathrm{b}}^{t}$ , (iii) $\tau  = {\left| D\right| }^{\delta \left( t\right) }$ ,and $\left( {iv}\right) \mathbf{u}$ the fractional edge cover that minimizes ${\rho }_{t}^{ + }$ . For the root node ${t}_{\mathrm{b}}$ ,we simply construct a hash index that tests membership for every hyperedge of $\mathcal{H}$ that is contained in ${\mathcal{V}}_{\mathrm{b}}$ . This construction uses for each bag space $\widetilde{O}\left( {\left| D\right|  + {\left| D\right| }^{{\rho }_{t}^{ + } - \delta \left( t\right)  \cdot  \alpha \left( {\mathcal{V}}_{\mathrm{f}}^{t}\right) }}\right)$ , which means that the compressed representation has size $\widetilde{O}(\left| D\right|  +$ $|D{f}^{f})$ .

构建概要。第一步是为$\mathcal{T}\left( {\text{except}{t}_{\mathrm{b}}}\right)$中的每个节点$t$应用定理1的数据结构构建方法，参数包括：(i)超图${\mathcal{H}}^{\prime } = \left( {{\mathcal{V}}^{\prime },{\mathcal{E}}^{\prime }}\right)$（其中${\mathcal{V}}^{\prime } = {\mathcal{B}}_{t}$且${\mathcal{E}}^{\prime } = {\mathcal{E}}_{{\mathcal{B}}_{t}}$）；(ii)约束变量${\mathcal{V}}_{\mathrm{b}}^{\prime } = {\mathcal{V}}_{\mathrm{b}}^{t}$；(iii)$\tau  = {\left| D\right| }^{\delta \left( t\right) }$及最小化${\rho }_{t}^{ + }$的分数边覆盖$\left( {iv}\right) \mathbf{u}$。根节点${t}_{\mathrm{b}}$处则构建哈希索引，用于检测${\mathcal{V}}_{\mathrm{b}}$内所有超边$\mathcal{H}$的成员关系。该构建过程为每个包空间$\widetilde{O}\left( {\left| D\right|  + {\left| D\right| }^{{\rho }_{t}^{ + } - \delta \left( t\right)  \cdot  \alpha \left( {\mathcal{V}}_{\mathrm{f}}^{t}\right) }}\right)$分配$\widetilde{O}(\left| D\right|  +$$|D{f}^{f})$大小的压缩表示。

The second step is to run a sequence of semi-joins in bottom-up fashion. However, since the bags are not fully materialized anymore, this operation is not straightforward. Instead, we flip all entries of the dictionary ${\mathcal{D}}_{t}\left( {w,{v}_{\mathrm{b}}}\right)$ of the data structure at node $t$ from 1 to 0 if no valuation in the interval $\mathrm{I}\left( w\right)$ joins with its child bag. This step is necessary to guarantee that if we visit an interval in the delay-balanced tree with entry 1 , we are certain to produce an output for the full query (and not only the particular bag). To perform this check, we do not actually materialize the bag of the child, but we simply use its dictionary (hence costing an extra factor of $\mathop{\max }\limits_{t}\delta \left( t\right)$ during preprocessing time). ${}^{5}$

第二步以自底向上方式执行半连接序列。由于数据包不再完全物化，此操作需特殊处理：若节点$t$数据结构字典${\mathcal{D}}_{t}\left( {w,{v}_{\mathrm{b}}}\right)$中的条目在区间$\mathrm{I}\left( w\right)$内未与子包建立连接，则将其所有条目从1翻转为0。此步骤确保当访问延迟平衡树中标记为1的区间时，必能为完整查询（而非单一数据包）生成输出。该检查通过直接调用子包字典实现（预处理阶段额外消耗$\mathop{\max }\limits_{t}\delta \left( t\right)$倍成本）。${}^{5}$

Query Answering. To answer an access query with valuation ${v}_{\mathrm{b}}$ , we start from the root node ${t}_{b}$ of the decomposition and check using the indexes of the node whether ${v}_{\mathrm{b}}$ belongs to all relations ${R}_{F}$ such that $F \subseteq  {\mathcal{V}}_{\mathrm{b}}$ . Then,we invoke Algorithm 2 on the leftmost child ${t}_{0}$ of ${t}_{b}$ ,which outputs a new valuation in time at most $\widetilde{O}\left( {\left| D\right| }^{\delta \left( {t}_{0}\right) }\right)$ ,or returns nothing. As soon as we obtain a new output, we recursively proceed to the next bag in pre-order traversal of $\mathcal{T}$ , and find valuations for the (still free) variables in the bag. If there are no such valuations returned by Algorithm 2 for the node under consideration, this means that the last valuation outputted by the parent node does not lead to any output. In this case, we resume the enumeration for the parent node. Finally, when Algorithm 2 finishes the enumeration procedure, then we resume the enumeration for the pre-order predecessor of the current node (and not the parent). Intuitively, we go the predecessor to fix our next valuation, in order to enumerate the cartesian product of all free variables in the subtree rooted at the least common ancestor of current node and predecessor node.

查询应答。为回答带有估值${v}_{\mathrm{b}}$的访问查询，我们从分解的根节点${t}_{b}$出发，利用该节点的索引检查${v}_{\mathrm{b}}$是否属于所有满足$F \subseteq  {\mathcal{V}}_{\mathrm{b}}$条件的关系${R}_{F}$。接着，在${t}_{b}$的最左子节点${t}_{0}$上调用算法2，该算法最多在$\widetilde{O}\left( {\left| D\right| }^{\delta \left( {t}_{0}\right) }\right)$时间内输出一个新估值，或返回空值。一旦获得新输出，我们递归地转向$\mathcal{T}$前序遍历中的下一个包，并为该包中（仍自由的）变量寻找估值。若算法2对当前节点未返回任何估值，则意味着父节点最后输出的估值未能产生任何结果。此时，我们将恢复对父节点的枚举。最终，当算法2完成枚举过程后，则恢复对当前节点前序前驱（而非父节点）的枚举。直观而言，我们通过前驱节点来修正下一个估值，从而枚举以当前节点与前驱节点最近公共祖先为根的子树下所有自由变量的笛卡尔积。

The delay guarantee of $\widetilde{O}\left( {\left| D\right| }^{h}\right)$ comes from the fact that,at every node $t$ in the tree,we will output in time $\widetilde{O}\left( {\left| D\right| }^{\delta \left( t\right) }\right)$ at most $\widetilde{O}\left( {\left| D\right| }^{\delta \left( t\right) }\right)$ valuations,one of which will produce a final output tuple. Moreover, when a node has multiple children, then for a fixed valuation of the node, the traversal of each child is independent of the other children: if one subtree produces no result, then we can safely exit all subtrees and continue the enumeration of the node. The full details and analysis of the algorithm are in Appendix D.

算法$\widetilde{O}\left( {\left| D\right| }^{h}\right)$的延迟保证源于：在树中每个节点$t$处，我们最多在$\widetilde{O}\left( {\left| D\right| }^{\delta \left( t\right) }\right)$时间内输出若干估值，其中必有一个能生成最终输出元组。此外，当某节点拥有多个子节点时，对于该节点的固定估值，各子树的遍历相互独立——若某子树无结果产生，则可安全退出所有子树并继续该节点的枚举。算法完整细节与分析见附录D。

## 6 THE COMPLEXITY OF MINIMIZING DELAY

## 6 最小化延迟的复杂度

In this section, we study the computational complexity of choosing the optimal parameters for Theorem 1 and Theorem 2. We identify two objectives that guide the parameter choice:(i)given a space constraint,minimize the delay,and (ii) given a delay constraint, minimize the necessary space.

本节研究为定理1和定理2选择最优参数的计算复杂度。我们明确两个指导参数选择的目标：(i)在给定空间约束下最小化延迟；(ii)在给定延迟约束下最小化所需空间。

We start with the following computational task, which we call MinDelayCover. We are given as input a full adorned view ${Q}^{\eta }$ over a CQ,the sizes $\left| {R}_{F}\right|$ of each relation $F$ ,and a positive integer $\sum$ as a space constraint. The size of ${Q}^{\eta }$ ,denoted $\left| {Q}^{\eta }\right|$ ,is defined as the length of ${Q}^{\eta }$ when viewed as a word over alphabet that consists of variable set $\mathcal{V}$ ,dom and atoms in the body of the query. The goal is to output a fractional edge cover $\mathbf{u}$ that minimizes the delay in Theorem 1,subject to the space constraint $S \leq  \sum$ .

我们从称为MinDelayCover的计算任务开始。输入包括CQ上的完整装饰视图${Q}^{\eta }$、各关系$F$的大小$\left| {R}_{F}\right|$，以及作为空间约束的正整数$\sum$。视图${Q}^{\eta }$的大小记作$\left| {Q}^{\eta }\right|$，定义为将${Q}^{\eta }$视为由变量集$\mathcal{V}$、值域及查询体原子组成的字母表上的单词长度。目标是在空间约束$S \leq  \sum$下，输出使定理1中延迟最小的分数边覆盖$\mathbf{u}$。

We observe that we can express MinDelayCover as a linear fractional program with a bounded and non-empty feasible region (see [14]). Such a program can always be transformed to an equivalent linear program [9], which means that the problem can be solved in polynomial time.

我们注意到可将MinDelayCover表述为具有非空有界可行域的线性分式规划（参见[14]）。此类规划总可转化为等价线性规划[9]，意味着该问题可在多项式时间内求解。

Proposition 9. MINDELAYCOVER can be solved in polynomial time in the size of the adorned view, the relation sizes, and the space constraint.

命题9. MINDELAYCOVER可在装饰视图大小、关系规模及空间约束的多项式时间内求解。

We also consider the inverse task, called MINSPACECOVER: given as input a full adorned view ${Q}^{\eta }$ over a CQ,the sizes $\left| {R}_{F}\right|$ of each relation $F$ ,and a positive integer $\Delta$ as a delay constraint,we want to output a fractional edge cover $\mathbf{u}$ that minimizes the space $S$ in Theorem 1,subject to the delay constraint $\tau  \leq  \Delta$ .

我们还考虑其逆问题MINSPACECOVER：给定CQ上的完整装饰视图${Q}^{\eta }$、各关系$F$的大小$\left| {R}_{F}\right|$，以及作为延迟约束的正整数$\Delta$，需在延迟约束$\tau  \leq  \Delta$下输出使定理1中空间$S$最小化的分数边覆盖$\mathbf{u}$。

To solve MINSPACECOVER, observe that we can simply perform a binary search over the space parameter $S$ ,from $\left| D\right|$ to ${\left| D\right| }^{k}$ ,where $k$ is the number of atoms in $Q$ . For each space,we then run MinDe-LAYCOVER and check whether the minimum delay returned satisfies the delay constraint.

求解最小空间覆盖(MINSPACECOVER)时，可观察到我们只需对空间参数$S$进行二分搜索，范围从$\left| D\right|$到${\left| D\right| }^{k}$，其中$k$表示$Q$中的原子数量。针对每个空间值，我们运行最小延迟覆盖(MinDe-LAYCOVER)并检验返回的最小延迟是否满足约束条件。

Proposition 10. MINSPACECOVER can be solved in polynomial time in the size of the adorned view, the relation sizes, and the delay constraint.

命题10. 最小空间覆盖问题可在多项式时间内求解，其复杂度取决于装饰视图的规模、关系表大小及延迟约束条件。

We next turn our attention to how to optimize for the parameters in Theorem 2. Suppose we are given a full adorned view ${Q}^{\eta }$ over a CQ,the database size $\left| D\right|$ ,and a space constraint $\sum$ ,and we want to minimize the delay. If we are given a fixed ${\mathcal{V}}_{\mathrm{b}}$ -connex tree decomposition, then we can compute the optimal delay assignment $\delta$ and optimal fractional edge cover for each bag as follows: we iterate over every bag in the tree decomposition, and then solve MinDelayCover for each bag using the space constraint. It is easy to see that the delay that we obtain in each bag must be the delay of an optimal delay assignment. For the inverse task where we are given a ${\mathcal{V}}_{\mathrm{b}}$ -connex tree decomposition,a delay constraint,and our goal is to minimize the space, we can apply the same binary search technique as in the case of MinSpaceCover (observe the that $\delta$ -height is also easily computable in polynomial time). In other words, we can compute the optimal parameters for our given objective in polynomial time, as long as we are provided with a tree decomposition.

接下来我们探讨如何优化定理2中的参数。假设给定CQ上的完整装饰视图${Q}^{\eta }$、数据库规模$\left| D\right|$和空间约束$\sum$，目标是最小化延迟。若给定固定的${\mathcal{V}}_{\mathrm{b}}$连通树分解，可通过以下方式计算最优延迟分配$\delta$及每个包的最优分数边覆盖：遍历树分解中的每个包，在空间约束下求解最小延迟覆盖(MinDelayCover)。显然，各包获得的延迟必为最优分配结果。对于逆向任务——给定${\mathcal{V}}_{\mathrm{b}}$连通树分解和延迟约束下最小化空间时，可采用与最小空间覆盖(MinSpaceCover)相同的二分搜索技术（注意$\delta$高度也可在多项式时间内计算）。换言之，只要提供树分解，我们就能在多项式时间内计算出给定目标的最优参数。

In the case where the tree decomposition is not given, then the problem of finding the optimal data structure according to Theorem 2 becomes intractable. Indeed, we have already seen that if we want to achieve constant delay $\tau  = 1$ ,then the tree decomposition that minimizes the space $S$ is the one that achieves the ${\mathcal{V}}_{\mathrm{b}}$ -connex fractional hypertree width, $\operatorname{fhw}\left( {\mathcal{H} \mid  {\mathcal{V}}_{\mathrm{b}}}\right)$ . Since for ${\mathcal{V}}_{\mathrm{b}} = \varnothing$ we have fhw $\left( {\mathcal{H} \mid  {\mathcal{V}}_{\mathrm{b}}}\right)  = \operatorname{fhw}\left( \mathcal{H}\right)$ ,and finding the optimal fractional hyper-tree width is NP-hard [16], finding the optimal tree decomposition for our setting is also NP-hard.

若未给定树分解，则根据定理2寻找最优数据结构的问题将变得棘手。事实上，当需要实现恒定延迟$\tau  = 1$时，最小化空间$S$的树分解正是实现${\mathcal{V}}_{\mathrm{b}}$连通分数超树宽度$\operatorname{fhw}\left( {\mathcal{H} \mid  {\mathcal{V}}_{\mathrm{b}}}\right)$的分解。由于${\mathcal{V}}_{\mathrm{b}} = \varnothing$情况下fhw$\left( {\mathcal{H} \mid  {\mathcal{V}}_{\mathrm{b}}}\right)  = \operatorname{fhw}\left( \mathcal{H}\right)$成立，而求解最优分数超树宽度属于NP难问题[16]，因此在本设定中寻找最优树分解同样具有NP难度。

## 7 RELATED WORK

## 7 相关工作

There has been a significant amount of literature on data compression; a common application is to apply compression in column-stores [1]. However, such compression methods typically ignore the logical structure that governs data that is a result of a relational query. The key observation is that we can take advantage of the underlying logical structure in order to design algorithms that can compress the data effectively. This idea has been explored before in the context of factorized databases [22], which can be viewed as a form of logical compression. Our approach builds upon the idea of using query decompositions as a factorized representation, and we show that for certain access patterns it is possible to go below ${\left| D\right| }^{\text{fhw }}$ space for constant delay enumeration. In addition,our results also allow trading off delay for smaller space requirements of the data structure. A long line of work has also investigated the application of a broader set of queries with projections and aggregations $\left\lbrack  {6,7}\right\rbrack$ ,as well as learning linear regression models over factorized databases $\left\lbrack  {{21},{24}}\right\rbrack$ . Closely related to our setting is the investigation of join-at-a-time query plans, where at each step, a join over one variable is computed [10]. The intermediate results of these plans are partial factorized representations that compress only a part of the query result. Thus, they can be used to tradeoff space with delay, albeit in a non-tunable manner.

现有大量关于数据压缩的文献，常见应用包括列式存储压缩[1]。然而这类方法通常忽略关系查询结果数据的逻辑结构。关键洞见在于：利用底层逻辑结构可设计出高效的数据压缩算法。该思想在因子化数据库[22]领域已有探索，可视作逻辑压缩的一种形式。我们的方法基于使用查询分解作为因子化表示的思想，证明对于特定访问模式，恒定延迟枚举可实现${\left| D\right| }^{\text{fhw }}$空间以下的存储。此外，我们的成果还能在延迟与数据结构空间需求之间进行权衡。另有大量研究探讨了包含投影和聚合操作的广义查询集$\left\lbrack  {6,7}\right\rbrack$应用，以及在因子化数据库上学习线性回归模型$\left\lbrack  {{21},{24}}\right\rbrack$。与本研究密切关联的是"单步连接查询计划"的探索，该方案每步计算单个变量的连接操作[10]。这类计划产生的中间结果是部分因子化表示，仅压缩部分查询结果，因而能以不可调节的方式实现空间与延迟的权衡。

Our work is also connected to the problem of constant-delay enumeration $\left\lbrack  {5,{25},{26}}\right\rbrack$ : in this case,we want to enumerate a query result with constant delay after a linear time preprocessing step. We can view the linear time preprocessing step as a compression algorithm,which needs space only $O\left( \left| D\right| \right)$ . It has been shown that the class of connex-free acyclic conjunctive queries can be enumerated with constant delay after a linear-time preprocessing. Hence, in the case of connex-free acyclic CQs, there exists an optimal compression/decompression algorithm. However, many classes of queries are not factorizable to linear size, and can not be enumerated with constant-delay after linear-time preprocessing. Such examples are the triangle query ${\Delta }^{\text{fff }}\left( {x,y,z}\right)  = R\left( {x,y}\right) ,R\left( {y,z}\right) ,R\left( {z,x}\right)$ ,or the 2-path query ${P}_{2}^{\mathrm{{ff}}}\left( {x,y}\right)  = R\left( {x,y}\right) ,R\left( {y,z}\right)$ .

我们的工作还与恒定延迟枚举问题$\left\lbrack  {5,{25},{26}}\right\rbrack$相关：在这种情况下，我们希望通过线性时间预处理步骤后以恒定延迟枚举查询结果。可以将线性时间预处理步骤视为压缩算法，该算法仅需占用$O\left( \left| D\right| \right)$空间。研究表明，无连接环的合取查询类在线性时间预处理后能以恒定延迟进行枚举。因此，在无连接环的合取查询情况下，存在最优的压缩/解压缩算法。然而，许多查询类无法因式分解为线性规模，且无法在线性时间预处理后实现恒定延迟枚举，例如三角形查询${\Delta }^{\text{fff }}\left( {x,y,z}\right)  = R\left( {x,y}\right) ,R\left( {y,z}\right) ,R\left( {z,x}\right)$或2路径查询${P}_{2}^{\mathrm{{ff}}}\left( {x,y}\right)  = R\left( {x,y}\right) ,R\left( {y,z}\right)$。

Query compression is also a central problem in graph analytics. Many applications involve extracting insights from relational databases using graph queries. In such situations, most systems load the relational data in-memory and expand it into a graph representation that can become very dense. Analysis of such graphs is infeasible, as the graph size blows up quickly. Recent work [28- 30] introduced the idea of controlled graph expansion by storing information about high-degree nodes and evaluating acyclic CQs over light sub-instances. However, this work is restricted only to binary views (i.e., graphs), and does not offer any formal guarantees on delay or answer time. It also does not allow the compressed representation to grow more than linear in the size of the input.

查询压缩也是图分析的核心问题。许多应用涉及通过图查询从关系数据库中提取洞察。此类场景中，多数系统将关系数据加载到内存并扩展为可能极为稠密的图表示。由于图规模会迅速膨胀，对此类图进行分析并不可行。近期研究[28-30]提出了通过存储高度数节点信息并在轻量子实例上评估无环合取查询来实现受控图扩展的思路。但该工作仅局限于二元视图（即图结构），且未对延迟或应答时间提供形式化保证，也不允许压缩表示规模超过输入数据的线性增长。

Finally, our work is closely related with the problem of set intersection. Set intersection has applications in problems related to document indexing $\left\lbrack  {3,{11}}\right\rbrack$ and proving hardness results and lower bounds for space/approximation tradeoff of distance oracles for graphs $\left\lbrack  {{12},{23}}\right\rbrack$ . Previous work $\left\lbrack  {11}\right\rbrack$ has looked at creating a data structure for fast set intersection reporting and its corresponding boolean version. Our main data structure is a strict generalization of the one from [11].

最后，我们的工作与集合交集问题密切相关。集合交集在文档索引$\left\lbrack  {3,{11}}\right\rbrack$相关问题和证明图距离预言机的空间/近似权衡硬度结果及下界$\left\lbrack  {{12},{23}}\right\rbrack$中具有应用价值。前人工作$\left\lbrack  {11}\right\rbrack$研究了用于快速集合交集报告的数据结构及其布尔版本实现。我们的主要数据结构是对文献[11]中结构的严格泛化。

## 8 CONCLUSION

## 8 结论

In this paper we propose a novel and tunable data structure that allows us to compress the result of a conjunctive query, so that we can answer efficiently access requests over the query output.

本文提出了一种新颖可调的数据结构，能够压缩合取查询结果，从而实现对查询输出的高效访问请求响应。

This work initiates an exciting direction on studying compression tradeoffs for query results, and thus there are several open problems. The main challenge is to show whether our proposed data structure achieves optimal tradeoffs between the various parameters. Recent work [3] makes it plausible to look for lower bounds in the pointer machine model. A second open problem is to explore how our data structures can be modified to support efficient updates of the base tables. Recent results [8] indicate that efficient maintenance of CQ results under updates is in general a hard problem. This creates a new challenge for designing data structures and algorithms that provide theoretical guarantees and work well in practice. A third challenge is to extend our algorithms to support views with projections: projections add the additional challenge that we have to deal with duplicate tuples in the output. Finally, an interesting question is whether it is possible to build our data structure on-the-fly without a preprocessing step.

本研究开创了查询结果压缩权衡研究的新方向，由此产生若干开放性问题。主要挑战在于证明我们提出的数据结构是否能实现各参数间的最优权衡。近期研究[3]表明在指针机模型中寻找下界具有可行性。第二个开放问题是如何改进数据结构以支持基表的高效更新。最新结果[8]指出，更新操作下维护合取查询结果通常是难题，这为设计兼具理论保证和实践性能的数据结构与算法带来新挑战。第三个挑战是将算法扩展至支持含投影的视图：投影需要额外处理输出中的重复元组。最后，有趣的问题是能否无需预处理步骤而动态构建我们的数据结构。

Consider the decomposition $\mathcal{T}$ along with ${\left( \mathcal{T},\mathcal{D}\right) }_{t \in  V\left( \mathcal{T}\right)  \smallsetminus  {t}_{\mathrm{b}}}$ for each bag. We will modify $\mathcal{T}$ as follows: for each node of the tree, we fix a pointer predecessor(t), that will point to the pre-order predecessor of the node. Intuitively, the pre-order predecessor of a node is the last node where the valuation for a free variable will be fixed in the pre-order traversal of the tree just before visiting the current node. For ease of description of the algorithm, we assume that Algorithm 2 answering ${Q}^{\eta }\left\lbrack  {v}_{\mathrm{b}}^{t}\right\rbrack$ for any bag $t$ is accessible using the procedure ${\operatorname{next}}_{t}\left( {v}_{\mathrm{b}}^{t}\right)$ . Let ${\mathcal{V}}_{\text{pred }}^{t}$ represent all bound variables encountered in the pre-order traversal of the tree from ${t}_{\mathrm{b}}$ to $t$ (including bound variables of $t$ ).

为便于描述算法，我们假设可通过过程${\operatorname{next}}_{t}\left( {v}_{\mathrm{b}}^{t}\right)$访问算法2对任意包$t$的${Q}^{\eta }\left\lbrack  {v}_{\mathrm{b}}^{t}\right\rbrack$应答。令${\mathcal{V}}_{\text{pred }}^{t}$表示从${t}_{\mathrm{b}}$到$t$的树前序遍历中遇到的所有绑定变量（包括$t$的绑定变量）。

Algorithm Description. The algorithm begins from the root node and fixes the valuation for all free variables in the root bag. Then, it proceeds to the next bag recursively considering all ancestor variables as bound variables and finds a valuation for ${\mathcal{B}}_{t} \smallsetminus  \operatorname{anc}\left( t\right)$ . At the first visit to any bag,if the bound variables ${v}_{\mathrm{b}}^{t}$ do not produce an output in delay $\widetilde{O}\left( {\left| D\right| }^{{\delta }_{t}}\right)$ ,then we proceed to the next valuation in the parent bag. However,if the enumeration for some ${v}_{\mathrm{b}}^{t}$ did produce output tuples but the procedure next ${}_{t}\left( {v}_{\mathrm{b}}^{t}\right)$ has finished, we proceed to the predecessor of the bag to fix the next valuation for variables in predecessor bag. In other words, the ancestor variables remain fixed and we enumerate the cartesian product of the remaining variables.

算法描述。该算法从根节点开始，为根包中所有自由变量固定赋值。随后递归进入下一包，将所有祖先变量视为绑定变量，并为${\mathcal{B}}_{t} \smallsetminus  \operatorname{anc}\left( t\right)$寻找赋值。首次访问任何包时，若绑定变量${v}_{\mathrm{b}}^{t}$在延迟$\widetilde{O}\left( {\left| D\right| }^{{\delta }_{t}}\right)$内未产生输出，则转至父包的下一个赋值。反之，若某些${v}_{\mathrm{b}}^{t}$的枚举确实产生了输出元组但过程next${}_{t}\left( {v}_{\mathrm{b}}^{t}\right)$已结束，则转至该包的前驱节点以固定前驱包变量的下一赋值。换言之，祖先变量保持固定，我们枚举剩余变量的笛卡尔积。

Lemma 8. Algorithm 5 enumerates the answers with delay at most $\widetilde{O}\left( {\left| D\right| }^{h}\right)$ where $h$ is the $\delta$ -height of the decomposition tree. Moreover, it requires at most $O\left( {\log \left| D\right| }\right)$ memory

引理8。算法5以最多$\widetilde{O}\left( {\left| D\right| }^{h}\right)$延迟枚举答案，其中$h$是分解树的$\delta$高度。此外，其最多需要$O\left( {\log \left| D\right| }\right)$内存。

Proof. Since the size of the decomposition is a constant, we require at most $O\left( 1\right)$ pointers for predecessors and $O\left( 1\right)$ pointers for storing the valuations of each free variable. Let ${n}_{\ell }$ be the set of nodes at depth $\ell$ . We will express the delay of the algorithm in terms of the delay of the subtrees of every node. The delay at the root ${t}_{\mathrm{b}}$ after checking whether valuation ${v}_{\mathrm{b}}$ is in the base relations is ${d}_{{t}_{\mathrm{b}}} = O\left( {\mathop{\sum }\limits_{{t \in  {n}_{1}}}{d}_{t}}\right)$ . This is because the enumeration of each subtree rooted at depth $\ell  = 1$ depends only on its ancestor variables and is thus independent of the other subtrees at that depth. Since each node in the tree can produce at most ${\left| D\right| }^{{\delta }_{t}}$ valuations in $\widetilde{O}\left( {\left| D\right| }^{{\delta }_{t}}\right)$ time,the recursive expansion of ${\delta }_{{t}_{\mathrm{b}}}$ gives ${\delta }_{{t}_{\mathrm{b}}} = O\left( {\mathop{\sum }\limits_{{p \in  \lambda \left( \mathcal{T}\right) }}\widetilde{O}\left( {\left| D\right| }^{\mathop{\sum }\limits_{{t \in  p}}{\delta }_{t}}\right) }\right)$ . The largest term over all root to leaf paths is $\widetilde{O}\left( {\left| D\right| }^{h}\right)$ which gives us the desired delay guarantee.

证明。由于分解规模为常数，我们最多需要$O\left( 1\right)$指针存储前驱节点，以及$O\left( 1\right)$指针存储各自由变量的赋值。设${n}_{\ell }$为深度$\ell$处的节点集合。我们将根据每个节点子树的延迟来表达算法总延迟。根节点${t}_{\mathrm{b}}$在检查赋值${v}_{\mathrm{b}}$是否属于基关系后的延迟为${d}_{{t}_{\mathrm{b}}} = O\left( {\mathop{\sum }\limits_{{t \in  {n}_{1}}}{d}_{t}}\right)$。这是因为深度$\ell  = 1$处每个子树的枚举仅取决于其祖先变量，因而与该深度其他子树无关。由于树中每个节点最多可在$\widetilde{O}\left( {\left| D\right| }^{{\delta }_{t}}\right)$时间内产生${\left| D\right| }^{{\delta }_{t}}$个赋值，${\delta }_{{t}_{\mathrm{b}}}$的递归展开给出${\delta }_{{t}_{\mathrm{b}}} = O\left( {\mathop{\sum }\limits_{{p \in  \lambda \left( \mathcal{T}\right) }}\widetilde{O}\left( {\left| D\right| }^{\mathop{\sum }\limits_{{t \in  p}}{\delta }_{t}}\right) }\right)$。所有根到叶路径中的最大项为$\widetilde{O}\left( {\left| D\right| }^{h}\right)$，由此得到所需的延迟保证。

## E 宽度概念比较

We briefly discuss the connection of $\operatorname{fhw}\left( {\mathcal{H} \mid  {\mathcal{V}}_{\mathrm{b}}}\right)$ for a ${\mathcal{V}}_{\mathrm{b}}$ -connex decomposition with other related hypergraph notions.

我们简要讨论${\mathcal{V}}_{\mathrm{b}}$-连通分解的$\operatorname{fhw}\left( {\mathcal{H} \mid  {\mathcal{V}}_{\mathrm{b}}}\right)$与其他相关超图概念的联系。

The first observation is that the minimum edge cover number ${\rho }^{ * }$ is always an upper bound on fhw $\left( {\mathcal{H} \mid  {\mathcal{V}}_{\mathrm{b}}}\right)$ .
