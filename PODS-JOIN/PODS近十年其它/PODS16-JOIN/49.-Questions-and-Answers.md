## ABSTRACT

摘要

In the database context, the hypertree decomposition method is used for query optimization, whereby conjunctive queries having a low degree of cyclicity can be recognized and decomposed automatically, and efficiently evaluated. Hypertree decompositions were introduced at ACM PODS 1999. The present paper reviews -in form of questions and answers- the main relevant concepts and algorithms and surveys selected related work including applications and test results.

在数据库领域，超树分解方法用于查询优化，可自动识别并分解具有低循环度的联合查询，实现高效求值。该方法于1999年ACM PODS会议首次提出。本文以问答形式回顾了核心概念与算法，并综述了包括应用案例与测试结果在内的相关研究成果。

## 1. INTRODUCTION

引言

### 1.1 What Is This All About?

研究背景

This paper is about hypertree decompositions [74], a hypergraph-based method for decomposing conjunctive queries (or, equivalently,their associated hypergraphs) into tree-structures called hy-pertrees, in order to process them more efficiently. Each hypertree decomposition of a query is associated with a width. The smallest width over all such decompositions is the query's hypertree width. Queries of bounded hypertree width can be answered efficiently [74] in combined complexity. In particular, while Boolean conjunctive queries are NP-complete to answer in general [30], in the case of bounded hypertree width, they can be processed in polynomial time. Moreover, conjunctive queries with output, in case of bounded hypertree width, can be processed in time polynomial in the size of the input plus the size of the output. Queries having bounded hypertree width are also highly parallelizable. This was already noted in $\left\lbrack  {{72},{68}}\right\rbrack$ and has gained renewed interest in the context of MapReduce [43] and more advanced models of parallel query processing [7].

本文探讨超树分解[74]——一种基于超图的方法，用于将合取查询（或其关联超图）分解为称为超树的树状结构，以实现高效处理。每个查询的超树分解都对应一个宽度值，所有分解中的最小宽度称为该查询的超树宽度。具有有界超树宽度的查询在组合复杂度下可高效求解[74]。具体而言，布尔合取查询在一般情况下是NP完全问题[30]，但在有界超树宽度条件下可在多项式时间内处理。此外，对于带输出的合取查询，若超树宽度有界，其处理时间与输入规模加输出规模呈多项式关系。这类查询还具有高度并行性，这一特性在$\left\lbrack  {{72},{68}}\right\rbrack$中已被指出，并在MapReduce[43]和更先进的并行查询处理模型[7]背景下重获关注。

The notion of bounded hypertree width generalizes the wellknown concept of query acyclicity. The hypertree width of a query is a good measure of its degree of cyclicity. In particular, the class of all conjunctive queries (CQs) of hypertree width 1 coincides with the class of acyclic CQs. Hypertree decompositions, in a precise sense, lift the great benefits of acyclic queries to much larger and more general classes of queries which, in addition to acyclic queries, contain queries that are, so to say, mildly cyclic. A large number of realistic queries are of bounded hypertree width, as we shall discuss in Sections 3 and 9. Such queries can be answered efficiently, by using specific algorithms that exploit hy-pertree decompositions. However, the same queries would often require time exponential in their length if evaluated by classical methods. Hypertree decompositions are thus a powerful query optimization method with a huge potential for practical applications. Moreover, the problem of conjunctive query answering is equivalent to the query containment problem and, in AI, to the constraint satisfaction problem (CSPs) [44]. Thus, the algorithms and favorable complexity results for hypertree decompositions presented in this paper also apply to these problems.

有界超树宽度的概念推广了著名的查询无环性理论。查询的超树宽度能有效衡量其环化程度：当超树宽度为1时，该类合取查询(CQs)恰好对应无环CQs。超树分解从严格意义上将无环查询的巨大优势拓展至更广泛、更通用的查询类别，这些查询不仅包含无环查询，还涵盖所谓"轻度环化"的查询。如第3、9节所述，大量实际查询具有有界超树宽度，通过利用超树分解的特定算法可高效求解。而传统方法处理这些查询通常需要指数级时间。因此，超树分解是一种极具应用潜力的强大查询优化方法。此外，合取查询应答问题等价于查询包含问题，在人工智能领域则对应约束满足问题(CSPs)[44]，故本文提出的超树分解算法及优越复杂度结论同样适用于这些问题。

### 1.2 What Is so Smart about Acyclic Queries?

### 1.2 无环查询的智能之处何在？

Query acyclicity, which will be discussed in detail in Section 2, is one of the most fundamental and most fascinating concepts in database theory. It was introduced in [18] in the context of acyclic database schemes and, independently, as the tree-query property in [59]. In [19, 58] it was shown that these notions coincide. A query $Q$ is acyclic if its associated hypergraph ${\mathcal{H}}_{Q}$ has a join tree. This is an appropriate arrangement of the (hyperedges associated with the) query atoms in form of a tree-see Section 2 for details. The hypergraph ${\mathcal{H}}_{Q}$ associated with a Boolean conjunctive query $Q$ has as nodes its variables and has,for each query atom,a hyper-edge consisting of the set of all variables appearing in that atom. Note that, unlike for graphs, for hypergraphs there are various different definitions of acyclicity. The join-tree based definition used in the present paper coincides with $\alpha$ -acyclicity as defined in [50]. This type of hypergraph acyclicity is the most general acyclicity notion and is far more sophisticated than graph acyclicity. To appreciate this, consider Figure 1, which shows two acyclic hyper-graphs and their associated join trees. The hypergraph on the left side is intuitively acyclic, less so the one on the right side. In fact, the latter contains an obvious cycle over the nodes $A,B,C$ ,and $D$ ,which is not covered by any single hyperedge. Still,because this cycle is appropriately covered by two consecutive edges of the join tree, the hypergraph is acyclic. Note that, unlike for graphs, an acyclic hypergraph may contain a cyclic one as a sub-hypergraph. This is illustrated yet more drastically by the following example, which also explains how recognizing acyclicity helps processing a query in polynomial time.

第2章将详细讨论的查询无环性，是数据库理论中最基础且最富吸引力的概念之一。它最初在[18]中作为无环数据库模式被提出，并独立于[59]以树查询属性形式出现。[19,58]证明这两种定义等价。当布尔合取查询$Q$对应的超图${\mathcal{H}}_{Q}$存在连接树时，该查询即为无环。这种树状结构是对查询原子的特定排列方式（详见第2章）。布尔合取查询$Q$的超图${\mathcal{H}}_{Q}$以变量为节点，每个查询原子对应一条包含该原子所有变量的超边。需注意，与普通图不同，超图无环性存在多种定义标准。本文采用的基于连接树的定义与[50]提出的$\alpha$-无环性一致，这是最广义的超图无环性概念，其复杂程度远超普通图的无环性。如图1所示的两个无环超图及其连接树：左侧超图直观呈现无环性，右侧则不然——虽然存在节点$A,B,C$与$D$构成的明显环路，但该环路被连接树的两条连续边恰当覆盖，故仍属无环。值得注意的是，无环超图可能包含有环子超图，下例将更生动地说明这点，同时解释无环性识别如何助力多项式时间查询处理。

EXAMPLE 1.1. Let ${\mathrm{{CLIQUE}}}_{r}$ be the query expressing that a graph with edge relation $E$ has an $r$ -clique,i.e.,

示例1.1。设${\mathrm{{CLIQUE}}}_{r}$为表达边关系$E$的图中存在$r$团（即完全子图）的查询，具体形式为：

$$
{\operatorname{CLIQUE}}_{r} \equiv  \mathop{\bigwedge }\limits_{{1 \leq  i < j \leq  r}}E\left( {{x}_{i},{x}_{j}}\right)  \land  E\left( {{x}_{j},{x}_{i}}\right) .
$$

Let,moreover, ${Q}_{r}$ be the query

进一步设${Q}_{r}$为查询

$$
{\operatorname{CLIQUE}}_{r} \land  R\left( {{x}_{1},\ldots ,{x}_{r}}\right) \text{,}
$$

and define the infinite class $\mathcal{C}$ of queries by $\mathcal{C} = \left\{  {{Q}_{r} \mid  r \geq  1}\right\}$ . Each query ${Q}_{r}$ in $C$ is acyclic,and can thus be answered very efficiently. In fact,to answer ${Q}_{r}$ over some database DB,we just need to start by matching the $R\left( {{x}_{1},\ldots ,{x}_{r}}\right)$ atom to the polynomially many tuples of the $R$ relation of DB one by one. Each such match binds all variables, and thus for each such match it suffices to check in linear time whether all other instantiated query atoms are in the database.

并通过$\mathcal{C} = \left\{  {{Q}_{r} \mid  r \geq  1}\right\}$定义无限查询类$\mathcal{C}$。其中每个查询${Q}_{r}$都是无环的，因此能高效求解。实际上，在数据库DB上求解${Q}_{r}$时，只需先将$R\left( {{x}_{1},\ldots ,{x}_{r}}\right)$原子式与DB中$R$关系的多项式数量元组逐一匹配。每次匹配将绑定所有变量，因此只需线性时间验证其他实例化查询原子式是否都在数据库中。

However, if we used a more naïve evaluation strategy that processes the query by performing joins from left to right, we would first solve the NP-hard CLIQUE ${}_{r}$ query and only then evaluate the $R\left( {{x}_{1},\ldots ,{x}_{r}}\right)$ atom. Unless $\mathrm{P} = \mathrm{{NP}}$ ,this would require an exponential effort (in combined complexity) in the worst case.

但若采用从左到右执行连接运算的朴素求值策略，将先求解NP难度的CLIQUE${}_{r}$查询，再评估$R\left( {{x}_{1},\ldots ,{x}_{r}}\right)$原子式。除非$\mathrm{P} = \mathrm{{NP}}$成立，否则最坏情况下需要指数级计算量（组合复杂度）。

Boolean acyclic conjunctive queries (ACQs) with $m$ atoms,where $r$ is the size of the largest database relation relevant to the query, can be answered in time $O\left( {m \cdot  r \cdot  \log r}\right)$ ,while non-Boolean ACQs in time $O\left( {m \cdot  N \cdot  \log N}\right)$ ),where $N$ is the size of the output plus $r$ . This is achieved by first automatically recognizing whether a query is acyclic, which is feasible in linear time [133], and if so, by processing the query efficiently using a smart algorithm, such as Yannakakis' algorithm [137], which reduces the relevant database relations via semi-joins along the edges of the query join tree in such a way that no remaining tuple is superfluous (see Section 2).

含$m$个原子式的布尔型无环连接查询(ACQ)，在$r$（查询相关最大数据库关系规模）条件下可在$O\left( {m \cdot  r \cdot  \log r}\right)$时间内求解；非布尔型ACQ则需$O\left( {m \cdot  N \cdot  \log N}\right)$时间，其中$N$为输出规模与$r$之和。该过程首先通过线性时间[133]自动识别查询无环性，若成立则采用Yannakakis算法[137]等智能算法沿查询连接树边进行半连接缩减，确保无冗余元组（参见第2节）。

### 1.3 How to Generalize Query-Acyclicity?

### 1.3 如何推广查询无环性？

A significant proportion of the conjunctive queries (and the constraint satisfaction problems) arising in practice are not properly acyclic, but are in some sense nearly acyclic. Efforts have therefore been made since the 1990s to weaken the notion of acyclicity by defining appropriate concepts of near acyclicity and by finding query evaluation algorithms that are efficient for nearly acyclic queries. In this context, the degree of acyclicity of a hypergraph (or of a corresponding query) is mostly referred to as its width.

实践中大量出现的连接查询（及约束满足问题）并非严格无环，而是具有某种近无环特性。自1990年代起，学界通过定义近无环概念及开发高效求值算法，持续弱化无环性要求。在此背景下，超图（或对应查询）的无环程度多被称为其宽度。

In defining a generalization of acyclicity, one seeks to ensure the following fundamental three conditions to hold for each fixed constant $k \geq  1$ :

定义无环性推广时，需确保对每个固定常数$k \geq  1$满足以下三个基本条件：

1. Generalization of Acyclicity: Queries of width $k$ include the acyclic ones.

1. 无环性推广：宽度$k$的查询应包含无环查询

2. Tractable Recognizability: Queries of width $k$ can be recognized in polynomial time.

2. 可识别性：宽度$k$的查询需在多项式时间内可识别

3. Tractable Query-Answering: Queries of width $k$ can be answered in polynomial time (in combined complexity).

3. 可求解性：宽度$k$的查询需在多项式时间内可求解（组合复杂度）

In Condition 3, in case of non-Boolean queries, the polynomial-time bound is considered with respect to the combined size of the input and the output (indeed, in general, we may get exponentially many tuples in the output).

对于条件3中的非布尔查询，多项式时间界限需考虑输入与输出的组合规模（实际上输出可能包含指数级数量的元组）。

In graph theory, there is an appropriate and well-known generalization of graph acyclicity: bounded treewidth [124, 123]. This notion is based on tree decompositions as explained in detail in Section 3. Tree decompositions can straightforwardly be defined for hypergraphs, and thus for queries. They have been considered for conjunctive query answering (or, equivalently, CSP-solving) in [46, 31,108]. Briefly,a tree decomposition of a hypergraph $\mathcal{H}$ consists of a tree $T$ ,whose vertices are each associated with a so called bag, i.e.,a set of nodes of $\mathcal{H}$ ,such that each hyperedge is covered by some bag,and such that for each node $v$ of $\mathcal{H}$ all vertices of the decomposition tree whose bag contains $v$ induce a connected subtree of $T$ . The width of a decomposition is $s - 1$ ,where $s$ is the cardinality of the largest bag. The treewidth $\operatorname{tw}\left( \mathcal{H}\right)$ of $\mathcal{H}$ is the minimum treewidth among all tree decompositions of $\mathcal{H}$ . The treewidth ${tw}\left( Q\right)$ of a query $Q$ is defined to be the treewidth ${tw}\left( {\mathcal{H}}_{Q}\right)$ of its associated hypergraph ${\mathcal{H}}_{Q}$ . A similar convention will be adopted for other notions of width introduced below.

在图论中，关于无环性存在一个恰当且广为人知的推广概念：有界树宽[124,123]。该概念基于第3节详述的树分解理论。树分解可直接推广至超图结构，因而适用于查询处理。文献[46,31,108]已将其应用于合取查询应答（即CSP求解）领域。简言之，超图$\mathcal{H}$的树分解由树结构$T$构成，其每个顶点关联一个称为"包"的$\mathcal{H}$节点集合，需满足：每条超边被某个包覆盖，且对于$\mathcal{H}$的每个节点$v$，包含$v$的所有分解树顶点在$T$中形成连通子树。分解宽度定义为$s - 1$（其中$s$表示最大包的基数）。超图$\mathcal{H}$的树宽$\operatorname{tw}\left( \mathcal{H}\right)$是其所有树分解中的最小宽度值。查询$Q$的树宽${tw}\left( Q\right)$定义为其对应超图${\mathcal{H}}_{Q}$的树宽${tw}\left( {\mathcal{H}}_{Q}\right)$。下文引入的其他宽度概念也将采用类似约定。

Conjunctive queries of treewidth $k$ can be answered on a database DB in time $O\left( {{m}^{\prime } \cdot  {D}^{k + 1} \cdot  \log D}\right)$ ,where ${m}^{\prime }$ is the number of vertices of the decomposition tree $T$ ,and $D$ is the number of distinct values occurring in DB. So, the tree decomposition method enjoys our criterion of Tractable Query-Answering (Condition 3 above), because we can always find a tree decomposition of width $k$ ,whose number of vertices ${m}^{\prime }$ is at most the number of variables occurring in the query. It is also well-known that,for fixed constant $k$ ,determining whether a hypergraph has treewidth $k$ is feasible in linear time [23], therefore tree decompositions also enjoy Tractable Recognizability (Condition 2). There is, however, a significant drawback of the tree decomposition method: it does not generalize hy-pergraph acyclicity, and therefore does not fulfill Condition 1. For instance,for each integer $r$ ,the acyclic query ${Q}_{r}$ of Example 1.1 has treewidth $r - 1$ . Therefore,the class $\mathcal{C}$ of all these queries has unbounded treewidth.

树宽为$k$的合取查询可在数据库DB上以$O\left( {{m}^{\prime } \cdot  {D}^{k + 1} \cdot  \log D}\right)$时间应答，其中${m}^{\prime }$表示分解树$T$的顶点数，$D$为DB中不同值的出现次数。因此树分解方法满足我们提出的"可追踪查询应答"标准（前文条件3），因为总能找到宽度为$k$且顶点数${m}^{\prime }$不超过查询变量数的树分解。已知对于固定常数$k$，判定超图是否具有该树宽可在线性时间内完成[23]，故树分解也满足"可识别性"条件（条件2）。但该方法存在显著缺陷：无法推广超图无环性，因此不满足条件1。例如示例1.1中的无环查询${Q}_{r}$对任意整数$r$都具有树宽$r - 1$，故该类查询$\mathcal{C}$的树宽无界。

Another method introduced in an attempt to capture the degree of acyclicity of a query is the method of biconnected components [52]. In this method,the degree of acyclicity of a query $Q$ is defined as the number of nodes of the largest biconnected component of ${\mathcal{H}}_{Q}$ . This method, too, satisfies conditions 2 and 3, but not Condition 1, as it does not generalize acyclicity. According to this method, for each integer $r$ ,the acyclic query ${Q}_{r}$ of Example 1.1 has degree of acyclicity $r$ . Further methods that do not suitably generalize acyclicity are reviewed and compared in [70].

另一种用于量化查询无环性程度的方法是双连通分量法[52]。该方法将查询$Q$的无环度定义为其关联图${\mathcal{H}}_{Q}$最大双连通分量的节点数。该方法同样满足条件2和3，但因无法推广无环性而不满足条件1。根据该方法，示例1.1中的无环查询${Q}_{r}$对任意整数$r$都具有无环度$r$。文献[70]对其它不适用于无环性推广的方法进行了综述比较。

A significantly more appropriate, but still not fully satisfactory approach to the generalization of query acyclicity is the notion of query width [31], which is based on the concept of query decompositions. Essentially,a query decomposition of width $k$ of a query $Q$ is a tree decomposition of ${\mathcal{H}}_{Q}$ each of whose bags coincides with the union of $k$ or fewer hyperedges from ${\mathcal{H}}_{Q}$ ,and where at least one bag is the union of precisely $k$ such hyperedges-as shown in [72], this definition is equivalent to the original definition in [31]. The query width(qw)of $Q$ is the minimum width among all possible query decompositions of $Q$ . Bounded query width generalizes query acyclicity, as each join-tree is a query decomposition of query width 1 . Thus, Condition 1 is satisfied. Queries of bounded query width can be answered in polynomial time by the same algorithms that are also used for hypertree decompositions (which we will discuss in Section 4), thus also Condition 3 is satisfied. Unfortunately, however, queries of bounded query width are hard to recognize. In fact,as shown in [74],deciding for a query $Q$ whether ${qw}\left( Q\right)  = k$ for fixed constants $k > 3$ is NP-complete. Thus,unless $\mathrm{P} = \mathrm{{NP}}$ ,Condition 2 is not satisfied. In addition,the fact that the bags need to coincide exactly to a union of $\leq  k$ hyperedges is restrictive and gives rise to a higher than necessary width [74].

对查询无环性进行泛化的一个更为合适但仍不完全令人满意的方案是查询宽度[31]的概念，该概念基于查询分解的思想。本质上，查询$Q$的宽度$k$的查询分解是指${\mathcal{H}}_{Q}$的一个树分解，其中每个包恰好对应于${\mathcal{H}}_{Q}$中$k$条或更少超边的并集，且至少有一个包正好是$k$条此类超边的并集——如[72]所示，该定义与[31]中的原始定义等价。查询$Q$的查询宽度(qw)是其所有可能查询分解中的最小宽度。有界查询宽度泛化了查询无环性，因为每个连接树都是查询宽度为1的查询分解，因此满足条件1。有界查询宽度的查询可通过与超树分解相同的多项式时间算法求解（第4节将讨论），故条件3也满足。但遗憾的是，识别有界查询宽度的查询本身是困难的。事实上，[74]证明：对于固定常数$k > 3$，判定查询$Q$是否满足${qw}\left( Q\right)  = k$是NP完全问题。因此，除非$\mathrm{P} = \mathrm{{NP}}$，否则条件2不满足。此外，要求包必须精确对应于$\leq  k$条超边的并集这一限制会导致宽度值高于必要值[74]。

To redress the latter issue, it is sufficient to merely require that each bag of the tree decomposition of ${\mathcal{H}}_{Q}$ be covered by a union of $k$ hyperedges (rather than requiring it coincides with their union). This generalization gives rise to the concept of generalized hyper-tree decomposition (GHD) and to the associated notion of generalized hypertree width (ghw). Thus, a GHD of a hypergraph (or query) is a tree decomposition together with a specified covering of its bags by hyperedges. The ghw of a particular GHD is the maximum number of hyperedges used to cover a bag, and the generalized hypertree width of the original hypergraph (or query) is the minimum generalized hypertree width over all GHDs for this hy-pergraph. GHDs properly generalize query decompositions (query decompositions are GHDs but not vice-versa), and thus also acyclic queries. Hence, Condition 1 is satisfied. Queries of bounded ghw can be answered in polynomial time [74], thus Condition 3 is satisfied. However,as shown in [76],for fixed constants $k \geq  3$ ,it is NP-hard to decide whether for a query $Q,\operatorname{ghw}\left( {\mathcal{H}}_{Q}\right)  = k$ . Thus, unless $\mathrm{P} = \mathrm{{NP}}$ ,Condition 2 is still not satisfied.

为解决后一个问题，只需要求${\mathcal{H}}_{Q}$的树分解中每个包被$k$条超边的并集覆盖（而非要求与之精确对应）。这种泛化产生了广义超树分解(GHD)概念及相关的广义超树宽度(ghw)。因此，超图（或查询）的GHD是一个树分解加上对其各包的超边覆盖方案。特定GHD的ghw是覆盖单个包所用超边数的最大值，而原始超图（或查询）的广义超树宽度则是其所有GHD中的最小ghw值。GHD严格泛化了查询分解（查询分解是GHD的特例），因而也泛化了无环查询，故满足条件1。有界ghw的查询可在多项式时间内求解[74]，因此满足条件3。但如[76]所示，对于固定常数$k \geq  3$，判定查询$Q,\operatorname{ghw}\left( {\mathcal{H}}_{Q}\right)  = k$是否满足给定条件是NP困难的。因此，除非$\mathrm{P} = \mathrm{{NP}}$，条件2仍不满足。

To achieve tractability,an additional restriction,called the ${De}$ - scendant Condition or also the Special Condition, was added to the definition of GHD. This condition, which will be defined and explained in Section 3.2,while attempting to construct a width- $k$ GHD, reduces in a rather natural way the choice of possible child-bags of an already computed bag to a polynomial number of alternatives (each of which can be represented in logarithmic space). Based on this,a width- $k$ decomposition of a hypergraph $\mathcal{H}$ can be computed via an alternating logspace procedure and thus in deterministic polynomial time (see Section 3.3). GHDs that satisfy the Descendant Condition are called hypertree decompositions (HDs), and the associated width is the hypertree width,denoted by ${hw}\left( \mathcal{H}\right)$ . Hypertree decompositions were originally defined in [74], where also their fundamental properties were studied. In [70] they were carefully compared to other types of decompositions. There has been since then much further research related to (G)HDs, as well as several implementations and applications. Much of this work is reviewed in the sequel of the present paper.

为实现易处理性，在GHD定义中引入了称为${De}$后裔条件（亦称特殊条件）的附加限制。该条件将在第3.2节定义和解释，它在尝试构建宽度$k$的GHD时，能以较自然的方式将已计算包的子包选择缩减为多项式数量的备选方案（每个方案可用对数空间表示）。基于此，超图$\mathcal{H}$的宽度$k$分解可通过交替对数空间过程计算，从而在确定性多项式时间内完成（见第3.3节）。满足后裔条件的GHD称为超树分解(HD)，其对应宽度称为超树宽度，记作${hw}\left( \mathcal{H}\right)$。超树分解最初在[74]中定义并研究其基本性质，[70]对其与其他分解类型进行了细致比较。此后关于(G)HD的研究持续深入，并发展出多种实现与应用，本文后续章节将综述这些成果。

### 1.4 What Are the Main Advantages of HDs?

### 1.4 HD的主要优势是什么？

We give here only a very short itemized summary of the advantages of HDs here. For more details, see Sections 3-6.

此处仅简要列举HD的核心优势，详见第3-6节。

- For a fixed constant $k$ ,it can be checked in polynomial time whether a conjunctive query $Q$ is of hypertree width $\leq  k$ ,and if so,a HD of width ${hw}\left( {\mathcal{H}}_{Q}\right)$ can be computed in polynomial time. The best upper bound currently known for this is $O\left( {{m}^{2k}{v}^{2}}\right)$ time,where $m$ and $v$ are the number of atoms and the number of variables in $Q$ ,respectively [69]. The decision and computation problems are, moreover, at a very low level of structural complexity and are highly parallelizable problems in LOGCFL, a low class within ${\mathrm{{NC}}}^{2}$ . These results are discussed in Section 3.

- 对于固定常数$k$，可在多项式时间内验证合取查询$Q$是否具有超树宽度$\leq  k$，若存在则可在多项式时间内计算出宽度为${hw}\left( {\mathcal{H}}_{Q}\right)$的HD（超树分解）。目前已知的最佳时间复杂度上界为$O\left( {{m}^{2k}{v}^{2}}\right)$，其中$m$和$v$分别表示$Q$中原子公式和变量的数量[69]。该判定与计算问题处于极低的结构复杂度层级，属于高度可并行化的LOGCFL类问题（${\mathrm{{NC}}}^{2}$中的低复杂度类）。这些结果将在第3节讨论。

- A Boolean conjunctive query $Q$ having (generalized) hypertree width $k$ can be answered in time $O\left( {v \cdot  {r}^{k} \cdot  \log r}\right)$ where $r$ is the size of the largest database relation mentioned by the query. For queries with output (whose results may consist of exponentially many tuples) an output-polynomial upper bound is $O\left( {v \cdot  \left( {{r}^{k} + }\right. }\right.$ $s) \cdot  \log \left( {r + s}\right)$ ),where $s$ is the number of output tuples. In particular, for each query of bounded hw, we can generate in polynomial time an efficient query plan for a relational machine. This and further improved bounds are discussed in Section 4.

- 对于具有（广义）超树宽度$k$的布尔合取查询$Q$，其应答时间复杂度为$O\left( {v \cdot  {r}^{k} \cdot  \log r}\right)$，其中$r$表示查询涉及的最大数据库关系表规模。对于含输出的查询（其结果可能包含指数级元组），输出多项式时间上界为$O\left( {v \cdot  \left( {{r}^{k} + }\right. }\right.$$s) \cdot  \log \left( {r + s}\right)$），其中$s$为输出元组数量。特别地，对于任何hw有界的查询，我们都能在多项式时间内为关系型机器生成高效查询计划。第4节将讨论该结论及更优的改进边界。

- Generalized hypertree decompositions (and thus, in particular, HDs) can be used for generating efficient query plans not only for standard query processing engines, but also for systems using multiway joins or for systems using parallel processing at various levels of granularity (see Section 4.1). Moreover, just as for acyclic queries, evaluating queries of bounded hw is complete for the parallel class LOGCFL [72].

- 广义超树分解（特别是HD）不仅能用于标准查询处理引擎，还可为采用多元连接或不同粒度并行处理的系统生成高效查询计划（参见4.1节）。此外，与无环查询类似，评估hw有界查询对于并行类LOGCFL具有完备性[72]。

- Generalized hypertree decompositions (and thus also HDs) cannot just be used for plain conjunctive query answering, but, as shown in Section 5,they are also usable for top- $k$ queries,and queries with aggregation operators, such as COUNT.

- 广义超树分解（含HD）不仅适用于普通合取查询应答，如第5节所示，还可应用于top-$k$查询及含COUNT等聚合算子的查询。

- Hypertree width is not very far apart from the tighter acyclicity-measure of ghw. In fact, in [6] it was proven that for each hyper-graph $\mathcal{H},\operatorname{ghw}\left( \mathcal{H}\right)  \leq  {hw}\left( \mathcal{H}\right)  \leq  3 \cdot  \operatorname{ghw}\left( \mathcal{H}\right)  + 1$ ,which implies that a class of queries has bounded ghw iff it has bounded hw.

- 超树宽度与更严格的ghw（广义无环性度量）相差不大。文献[6]证明：对于每个超图$\mathcal{H},\operatorname{ghw}\left( \mathcal{H}\right)  \leq  {hw}\left( \mathcal{H}\right)  \leq  3 \cdot  \operatorname{ghw}\left( \mathcal{H}\right)  + 1$，这意味着某类查询具有有界ghw当且仅当其具有有界hw。

### 1.5 Do HDs Have Any Disadvantage?

### 1.5 HD是否存在缺陷？

There is a small price we have to pay for the significant improvement HDs offer over other decompositions. While HDs of bounded width $k$ ,if they exist,can be computed in polynomial time,the exponent of the polynomial in the upper bound involves $k$ as a factor. It is deemed very unlikely that we can get rid of the factor $k$ in the exponent, because the problem of deciding whether a query has hy-pertree width $k$ was shown to be fixed-parameter intractable [66].

HD相较其他分解方法的显著优势需付出微小代价。虽然宽度有界$k$的HD（若存在）可在多项式时间内计算，但该多项式上界的指数项包含$k$因子。由于判定查询是否具有超树宽度$k$的问题已被证明是固定参数难解的[66]，消除该指数因子被认为极不可能。

In the database context this is not really a problem. First, as we will see below, in all benchmarks analyzed so far, the hypertree width of queries is extremely low. For an effective practical query optimization, it actually suffices to detect queries of hw 2 or 3 . Second, while conjunctive queries can become quite large in practice, they hardly reach sizes of over, say, 50 atoms. With these figures, even exact HD algorithms can be used very effectively. Finally, note that in database applications it is very often the case that the same query is repeated extremely frequently over constantly changing data. It is then worthwhile first spending a little computational effort so as to get a really good decomposition and being rewarded a myriad of times afterwards by running a highly optimized query.

在数据库场景中这并非实质问题。首先，现有基准测试表明查询的超树宽度普遍极低——实际查询优化仅需检测hw为2或3的查询即可。其次，实践中合取查询规模虽可能较大，但原子公式数量极少超过50个。在此量级下，精确HD算法仍能高效运行。最后需注意，数据库应用中同一查询常在海量变化数据上重复执行，此时投入少量计算资源获取优质分解方案，后续通过高度优化的查询执行可获得千万倍的回报。

The situation is more problematic in the context of large constraint satisfaction problems. Such problems may have hundreds or even thousands of constraint atoms and we may want to look for decompositions of hypertree width around 20 . For such problems, the current exact HD algorithms often cause memory overflow or take very long time to complete. However, more efficient algorithms have been developed that use heuristics that do not necessarily aim at an optimal HD (see Section 3.4). Moreover, for such problems, if the constraint relations are relatively small, then methods of computing the answer of a query by implicitly exploiting an assumed small hw, but without computing the decomposition explicitly, may be appropriate. Such methods are discussed in Section 4.2.

在大型约束满足问题中，情况更为复杂。这类问题可能包含数百甚至数千个约束原子，且我们通常需要寻找超树宽度约为20的分解方案。对于此类问题，当前精确的超树分解(HD)算法常导致内存溢出或耗时极长。不过，已有更高效的启发式算法被开发出来，这些算法并不追求最优HD（参见第3.4节）。此外，若约束关系相对较小，采用隐式利用假设较小超树宽度(hw)来查询应答的方法可能更为合适，而无需显式计算分解。这类方法将在第4.2节讨论。

### 1.6 Do HDs Matter in Practice?

### 1.6 超树分解在实践中重要吗？

Yes, definitely. As discussed in Section 6, and as noted by many authors, hypertree decompositions are a significant and very beneficial query optimization technique. The low hypertree width of all queries in the database benchmarks we and others have analyzed, and the fact that a substantial part of the queries are not plainly acyclic supports this. HDs have been used profitably in experimental systems $\left\lbrack  {1,7,{10},8}\right\rbrack$ ,and we believe the time is ripe for using them in for query optimization in commercial DBMSs too.

当然重要。如第6节所述且多位学者指出，超树分解是一种极具价值的查询优化技术。我们与其他研究者分析的数据库基准测试中，所有查询均呈现较低的超树宽度，且大量查询并非简单无环的事实印证了这一点。实验系统已成功应用HD技术$\left\lbrack  {1,7,{10},8}\right\rbrack$，我们认为将其用于商业数据库管理系统(DBMS)查询优化的时机已经成熟。

### 1.7 Which Applications Are HDs Suited For?

### 1.7 超树分解适用于哪些应用场景？

As already discussed, hypertree decompositions are, in the first place, useful for database query optimization, not only in the classical DBMS setting, but also in the context of more modern query processing using multiway joins, and for parallel and distributed query processing. In each of this contexts, HDs can be used for generating smart and efficient query plans.

如前所述，超树分解首要适用于数据库查询优化，不仅限于传统DBMS环境，还包括使用多路连接的现代查询处理，以及并行与分布式查询处理。在这些场景中，HD都能用于生成智能高效的查询计划。

Another large application area is constraint satisfaction (see Section 7.1). The constraint satisfaction problem (CSP) has been recognized to be equivalent to conjunctive query evaluation-see [92, 108, 25]. In particular, Kolaitis and Vardi [108] pointed out that both problems are, in turn, equivalent to the homomorphism problem between finite relational structures. However, as already noted, practical CSPs may differ from conjunctive query answering in that they have many more constraint atoms but often (though not always) quite small relations. Therefore, with CSPs, approximate algorithms using heuristics may work better than exact decomposition algorithms, for some applications.

另一重要应用领域是约束满足问题（参见7.1节）。约束满足问题(CSP)已被证明等价于合取查询求值——参见[92,108,25]。特别是Kolaitis和Vardi[108]指出，这两个问题又等同于有限关系结构间的同态问题。但需注意，实际CSP可能包含更多约束原子而关系通常较小（虽非绝对），因此对某些应用场景，采用启发式的近似算法可能比精确分解算法更有效。

Other applications, which we discuss in Section 7, relate to computing Nash equilibria of games, and to the problem of winner determination in combinatorial auctions. More in general, any application that is any easier on restrictions characterized by acyclic hypergraph structures may find useful to exploit (G)HDs.

第7节讨论的其他应用包括计算博弈的纳什均衡，以及组合拍卖中的赢家确定问题。更广泛地说，任何能受益于无环超图结构特性的应用，都可能通过(广义)超树分解获得助益。

### 1.8 Can the Concept of HD Be Improved?

### 1.8 超树分解概念能否改进？

It is shown in [76] that if, in addition to the original hyperedges of a hypergraph $\mathcal{H}$ ,we also use some proper subsets of these hyper-edges for covering the bags of a tree decomposition of $\mathcal{H}$ ,then we still obtain a correct decomposition, whose associated width may be smaller than ${hw}\left( \mathcal{H}\right)$ . In particular,if all subsets of the hyper-edges of $H$ are allowed,then the obtained width coincides with ${ghw}\left( H\right)$ . However,this causes an exponential blow-up,as there is an exponential number of hyperedge-subsets. If, on the other hand, we use a polynomial-time function that associates a polynomial number of such subsets with each hypergraph, then we may obtain an improvement of HD-decompositions yielding in some cases a smaller width, while still fulfilling Conditions 1-3. This is precisely the idea of subset-based decompositions as defined in [76]. Specific subset-based decompositions are the component decompositions defined in [76] and the spread-cut decompositions defined in [37], while an interesting way of computing a subset-based decomposition dynamically provides the new notion of greedy hy-pertree decomposition [82, 88]. In essence, however, subset-based decompositions are generalizations of HDs that are mainly based on the same principles.

文献[76]表明，若在超图$\mathcal{H}$原有超边基础上，还使用这些超边的真子集来覆盖树分解的各个包，仍能得到正确分解，且其关联宽度可能小于${hw}\left( \mathcal{H}\right)$。特别地，若允许使用$H$所有超边子集，所得宽度将与${ghw}\left( H\right)$一致。但这会导致指数级膨胀，因为子集数量呈指数增长。若改用多项式时间函数为每个超图关联多项式数量的子集，则可在满足条件1-3前提下，获得宽度更优的HD改进方案。这正是文献[76]定义的基于子集分解的核心思想。具体实现包括文献[76]的组件分解和文献[37]的扩散切割分解，而动态计算子集分解的新方法则催生了贪婪超树分解的新概念[82,88]。本质上，基于子集的分解是对HD的泛化，两者基本原理相通。

A more radical approach to improve HDs and even GHDs, was taken by Grohe and Marx [90], who defined fractional hypertree decompositions (FHDs), giving rise to the fractional hypertree width fhw(H)of a hypergraph $\mathcal{H}$ (or of a query). While hypertree decompositions exploit low cyclicity, which in a sense means a loose coherence of the variables in a query, FHDs manage to exploit, in addition, certain types of strong coherence between sets of variables. Moreover,even for hypergraphs $\mathcal{H}$ of low cyclicity,FHDs may yield width ${fhw}\left( \mathcal{H}\right)  < {ghw}\left( \mathcal{H}\right)$ . The current problem with FHDs is that it is unknown whether $\operatorname{fhw}\left( \mathcal{H}\right)  \leq  k$ ,for a fixed $k$ ,is recognizable in polynomial time. Thus, Condition 2 is not known to be satisfied. An approximate decomposition whose width is bounded by a cubic function of the fractional hypertree width can be computed in polynomial time [113]. A yet more general width-concept is submodular width [115]. Unfortunately, recognizing queries of bounded submodular width is not known to be tractable. Moreover, having bounded submodular width (smw) does (unfortunately) not guarantee a polynomial-time combined complexity as for GHDs, but just fixed-parameter tractability where the query hypergraph is used as a parameter. This means that we have a polynomial-time data complexity of the form $O\left( {{f}_{1}\left( {\mathcal{H}}_{Q}\right)  \cdot  {\left| \mathrm{{DB}}\right| }^{{f}_{2}\left( \mathrm{{smw}}\right) }}\right)$ ,where ${f}_{1}$ is an exponential function of the query size. Unlike the previous methods, the decompositions used to answer the query depend not only on the hypergraph ${\mathcal{H}}_{Q}$ ,but on the actual database DB,too. The relationships among these methods are illustrated in Figure 2- see also Section 8.

Grohe和Marx[90]提出了一种更为激进的改进HD乃至GHD的方法，他们定义了分数超树分解(FHDs)，由此产生了超图$\mathcal{H}$(或查询)的分数超树宽度fhw(H)。超树分解利用了低环性(某种意义上意味着查询中变量的松散关联)，而FHDs还能额外利用变量集合间某些类型的强关联特性。更重要的是，即使对于低环性超图$\mathcal{H}$，FHDs仍可能产生宽度${fhw}\left( \mathcal{H}\right)  < {ghw}\left( \mathcal{H}\right)$。当前FHDs的困境在于，对于固定$k$，尚不清楚$\operatorname{fhw}\left( \mathcal{H}\right)  \leq  k$是否能在多项式时间内被识别。因此，条件2的满足性尚未可知。通过多项式时间可以计算出宽度以分数超树宽度立方函数为界的近似分解[113]。更广义的宽度概念是子模宽度[115]。遗憾的是，识别具有有界子模宽度的查询尚未被证明是易处理的。此外，(不幸的是)有界子模宽度(smw)并不能像GHDs那样保证多项式时间组合复杂度，仅能实现以查询超图作为参数的固定参数可处理性。这意味着我们具有形如$O\left( {{f}_{1}\left( {\mathcal{H}}_{Q}\right)  \cdot  {\left| \mathrm{{DB}}\right| }^{{f}_{2}\left( \mathrm{{smw}}\right) }}\right)$的多项式时间数据复杂度，其中${f}_{1}$是查询规模的指数函数。与之前方法不同，用于回答查询的分解不仅取决于超图${\mathcal{H}}_{Q}$，还依赖于实际数据库DB。这些方法间的关系如图2所示(另见第8节)。

In summary, to the best of our knowledge, except for improvements such as subset-based decompositions that are essentially HD-based, there is no other improvement of hypertree decompositions that fulfills the three fundamental conditions of (1) Generalization of Acyclicity, (2) Tractable Recognizability, and (3) Tractable Query-Answering.

综上所述，据我们所知，除了本质上基于HD的改进(如基于子集的分解)之外，目前尚未出现能同时满足三大基本条件的超树分解改进方案：(1)无环性泛化，(2)可识别性易处理，(3)查询应答易处理。

## 2. WHAT IS HYPERGRAPH ACYCLICITY?

## 2. 什么是超图无环性？

We will adopt the standard convention of identifying a relational database instance with a logical theory consisting of ground facts [3, 134]. Accordingly,a tuple $\left\langle  {{a}_{1},\ldots ,{a}_{k}}\right\rangle$ of constants belonging to relation $r$ of a database DB is simply denoted by $r\left( {{a}_{1},\ldots ,{a}_{k}}\right)  \in$ DB. The set of all constants in DB is denoted by $\operatorname{dom}\left( \mathrm{{DB}}\right)$ .

我们将采用标准惯例，将关系数据库实例视为由基本事实组成的逻辑理论[3,134]。因此，属于数据库DB关系$r$的常量元组$\left\langle  {{a}_{1},\ldots ,{a}_{k}}\right\rangle$可简记为$r\left( {{a}_{1},\ldots ,{a}_{k}}\right)  \in$DB。DB中所有常量的集合记作$\operatorname{dom}\left( \mathrm{{DB}}\right)$。

### 2.1 Conjunctive Queries and Hypergraphs

### 2.1 合取查询与超图

A conjunctive query $Q$ is a rule of the form

合取查询$Q$是形如以下形式的规则

$$
\operatorname{ans}\left( \mathbf{u}\right)  \leftarrow  {r}_{1}\left( {\mathbf{u}}_{\mathbf{1}}\right)  \land  \ldots  \land  {r}_{m}\left( {\mathbf{u}}_{\mathbf{m}}\right) ,
$$

where ${r}_{1},\ldots ,{r}_{m}$ are relation symbols,and $\mathbf{u},{\mathbf{u}}_{\mathbf{1}},\ldots ,{\mathbf{u}}_{\mathbf{m}}$ are lists of terms (i.e.,variables or constants). We denote by $\operatorname{atoms}\left( Q\right)$ the set of all atoms in the right-hand side,i.e., $\operatorname{atoms}\left( Q\right)  = \left\{  {{r}_{1}\left( {\mathbf{u}}_{\mathbf{1}}\right) ,\ldots }\right.$ , $\left. {{r}_{m}\left( {\mathbf{u}}_{\mathbf{m}}\right) }\right\}$ . For a set $A$ of atoms, $\operatorname{vars}\left( A\right)$ is the set of all variables in $A$ ,and $\operatorname{vars}\left( Q\right)$ is used for short in place of $\operatorname{vars}\left( {\operatorname{atoms}\left( Q\right) }\right)$ . If $\mathbf{u}$ is empty,then the query $Q$ is said Boolean.

其中${r}_{1},\ldots ,{r}_{m}$是关系符号，$\mathbf{u},{\mathbf{u}}_{\mathbf{1}},\ldots ,{\mathbf{u}}_{\mathbf{m}}$是项列表（即变量或常量）。我们用$\operatorname{atoms}\left( Q\right)$表示右侧所有原子的集合，即$\operatorname{atoms}\left( Q\right)  = \left\{  {{r}_{1}\left( {\mathbf{u}}_{\mathbf{1}}\right) ,\ldots }\right.$，$\left. {{r}_{m}\left( {\mathbf{u}}_{\mathbf{m}}\right) }\right\}$。对于原子集合$A$，$\operatorname{vars}\left( A\right)$表示$A$中所有变量的集合，$\operatorname{vars}\left( Q\right)$作为$\operatorname{vars}\left( {\operatorname{atoms}\left( Q\right) }\right)$的简写形式。若$\mathbf{u}$为空，则称查询$Q$为布尔型。

The answer of $Q$ on a database DB,denoted by ${Q}^{\mathrm{{DB}}}$ ,consists of the set of all ground facts $\operatorname{ans}\left( {\theta \left( \mathbf{u}\right) }\right)$ where $\theta  : \operatorname{vars}\left( Q\right)  \mapsto$ ${dom}\left( \mathrm{{DB}}\right)$ is a substitution such that:

在数据库DB上，$Q$的答案记作${Q}^{\mathrm{{DB}}}$，由所有满足以下条件的基事实$\operatorname{ans}\left( {\theta \left( \mathbf{u}\right) }\right)$组成：存在替换$\theta  : \operatorname{vars}\left( Q\right)  \mapsto$${dom}\left( \mathrm{{DB}}\right)$使得：

$$
{\theta }^{\prime }\left( {{r}_{i}\left( {\mathbf{u}}_{\mathbf{i}}\right) }\right)  \in  \mathrm{{DB}}\text{holds,}{}^{1}\text{for each}i \in  \{ 1,\ldots ,m\} \text{,}
$$

where ${\theta }^{\prime }\left( t\right)  = \theta \left( t\right)$ if $t \in  \operatorname{vars}\left( Q\right)$ and ${\theta }^{\prime }\left( t\right)  = t$ otherwise (i.e.,if the term $t$ is a constant).

其中${\theta }^{\prime }\left( t\right)  = \theta \left( t\right)$当$t \in  \operatorname{vars}\left( Q\right)$时成立，否则${\theta }^{\prime }\left( t\right)  = t$（即当项$t$为常量时）。

There is a very natural way to associate a hypergraph ${\mathcal{H}}_{Q} =$ (N,H)with a conjunctive query $Q$ : The set $N$ of nodes consists of all variables in $Q$ ; for each atom in $Q$ ,the set $H$ of hyperedges contains a hyperedge including all its variables; and no other hy-peredge is in $H$ . Note that the cardinality of $H$ can be smaller than the cardinality of atoms(Q),because two query atoms having exactly the same set of variables in their arguments give rise to only one edge in $H$ . In the following the set of the nodes and the set of the hyperedges of any hypergraph $\mathcal{H}$ will be shortly denoted by nodes(H)and edges(H),respectively.

存在一种自然方式将超图${\mathcal{H}}_{Q} =$(N,H)与合取查询$Q$关联：节点集$N$由$Q$中所有变量构成；对于$Q$中的每个原子，超边集$H$包含一条涵盖其所有变量的超边；且$H$中不含其他超边。注意$H$的基数可能小于原子集(Q)的基数，因为两个查询原子若参数变量集完全相同，在$H$中仅生成一条边。下文将任意超图$\mathcal{H}$的节点集和超边集简记为nodes(H)和edges(H)。

EXAMPLE 2.1. Consider the following conjunctive query ${Q}_{0}$ over the set $\{ A,B,C,D\}$ of variables:

示例2.1. 考虑以下定义在变量集$\{ A,B,C,D\}$上的合取查询${Q}_{0}$：

$$
\text{ans}\left( \right)  \leftarrow  {c}_{1}\left( {A,B}\right)  \land  {c}_{2}\left( {B,C}\right)  \land  {c}_{3}\left( {C,D}\right)  \land  {c}_{4}\left( {D,A}\right) \text{.}
$$

This is a Boolean query whose associated hypergraph ${\mathcal{H}}_{{Q}_{0}}$ is actually a graph, because each query atom is defined over precisely two variables. Indeed,nodes $\left( {\mathcal{H}}_{{Q}_{0}}\right)  = \{ A,B,C,D\}$ and $\operatorname{edges}\left( {\mathcal{H}}_{{Q}_{0}}\right)  = \{ \{ A,B\} ,\{ B,C\} ,\{ C,D\} ,\{ D,A\} \} .$

这是一个布尔查询，其关联超图${\mathcal{H}}_{{Q}_{0}}$实际为普通图，因为每个查询原子恰好定义在两个变量上。具体而言，节点$\left( {\mathcal{H}}_{{Q}_{0}}\right)  = \{ A,B,C,D\}$与$\operatorname{edges}\left( {\mathcal{H}}_{{Q}_{0}}\right)  = \{ \{ A,B\} ,\{ B,C\} ,\{ C,D\} ,\{ D,A\} \} .$

A hypergraph $\mathcal{H}$ is acyclic iff it has a join tree [20]. A join tree ${JT}\left( \mathcal{H}\right)$ for a hypergraph $\mathcal{H}$ is a tree whose vertices are the hyperedges of $\mathcal{H}$ such that,whenever the same node $X \in  V$ occurs in two hyperedges ${h}_{1}$ and ${h}_{2}$ of $\mathcal{H}$ ,then $X$ occurs in each vertex on the unique path linking ${h}_{1}$ and ${h}_{2}$ in ${JT}\left( \mathcal{H}\right)$ . This is equivalent to requiring that the decomposition vertices where $X$ appears induce a connected subtree of $T$ (connectedness condition). Note that this notion of hypergraph acyclicity,known as $\alpha$ -acyclicity,is the most general one [50]. Moreover, it is efficiently recognizable: Deciding whether a hypergraph is acyclic is feasible in linear time [133], and also in deterministic logspace. This latter property follows from the fact that hypergraph acyclicity belongs to symmetric logspace [72], and that this is equal to deterministic logspace [122].

超图$\mathcal{H}$是无环的当且仅当它存在连接树[20]。超图$\mathcal{H}$的连接树${JT}\left( \mathcal{H}\right)$是指其顶点为$\mathcal{H}$超边的树结构，满足：当同一节点$X \in  V$出现在$\mathcal{H}$的两个超边${h}_{1}$和${h}_{2}$中时，$X$必须出现在${JT}\left( \mathcal{H}\right)$内连接${h}_{1}$与${h}_{2}$的唯一路径上的每个顶点中。这等价于要求$X$出现的分解顶点必须构成$T$的连通子树（连通性条件）。需注意这种被称为$\alpha$-无环性的超图无环概念是最广义的定义[50]。此外，其可高效识别：判定超图无环性可在线性时间[133]及确定性对数空间内完成。后者性质源于超图无环性属于对称对数空间[72]，而该空间等同于确定性对数空间[122]。

示例2.2 例2.1查询对应的(超)图${\mathcal{H}}_{{Q}_{0}}$在$A,B,C$和$D$上存在环路。实际上无法为其构建连接树。

考虑以下关于变量集$\{ A,\ldots ,M\}$的合取查询${Q}_{1}$：

$$
\text{ans}\left( \right)  \leftarrow  {r}_{1}\left( {A,B,C}\right)  \land  {r}_{2}\left( {A,C,D,E,F,G,H}\right)  \land  
$$

$$
{r}_{3}\left( {H,I}\right)  \land  {r}_{4}\left( {I,J,K}\right)  \land  {r}_{5}\left( {K,L}\right)  \land  {r}_{6}\left( {L,M}\right) \text{.}
$$

The hypergraph ${\mathcal{H}}_{{Q}_{1}}$ associated with the query ${Q}_{1}$ is the one discussed in the introduction (and reported in the left part of Figure 1). The hypergraph is acyclic as witnessed by the join tree depicted for it. More interestingly, if we consider the conjunctive query ${Q}_{0 \land  1}$ such that atoms $\left( {Q}_{0 \land  1}\right)  = \operatorname{atoms}\left( {Q}_{0}\right)  \cup  \operatorname{atoms}\left( {Q}_{1}\right)$ , i.e.,the query obtained by joining all the atoms occurring in ${Q}_{0}$ and ${Q}_{1}$ ,then we obtain a hypergraph ${\mathcal{H}}_{{Q}_{0 \land  1}}$ that is acyclic. Indeed, the cycle in ${Q}_{0}$ ,due to the atoms ${c}_{1}\left( {A,B}\right) ,{c}_{2}\left( {B,C}\right) ,{c}_{3}\left( {C,D}\right)$ , and ${c}_{4}\left( {D,A}\right)$ is now "absorbed" by two hyperedges of ${Q}_{1}$ . 查询${Q}_{1}$对应的超图${\mathcal{H}}_{{Q}_{1}}$即引言所述（见图1左部）。该超图具有无环性，其连接树已图示。更有趣的是，若考察合取查询${Q}_{0 \land  1}$（其原子$\left( {Q}_{0 \land  1}\right)  = \operatorname{atoms}\left( {Q}_{0}\right)  \cup  \operatorname{atoms}\left( {Q}_{1}\right)$由${Q}_{0}$与${Q}_{1}$中所有原子连接而成），所得超图${\mathcal{H}}_{{Q}_{0 \land  1}}$实为无环。原本${Q}_{0}$中因原子${c}_{1}\left( {A,B}\right) ,{c}_{2}\left( {B,C}\right) ,{c}_{3}\left( {C,D}\right)$和${c}_{4}\left( {D,A}\right)$形成的环路，现被${Q}_{1}$的两个超边"吸收"。实际上，只需将新增顶点$\{ A,B\} ,\{ B,C\} ,\{ C,D\}$和$\{ D,A\}$作为$\{ A,C,D,E,F,G,H\}$与$\{ A,B,C\}$的子节点（如图1右部所示），即可从原连接树轻松构建${\mathcal{H}}_{{Q}_{0 \land  1}}$的连接树。

### 2.2 Basic Properties

### 2.2 基本性质

Acyclic queries, i.e., queries whose associated hypergraphs are acyclic, can be efficiently answered. More precisely, using Yan-nakakis' algorithm [137], Boolean acyclic queries can be evaluated by processing any of their join trees bottom-up, by performing upward semijoins between the relations associated with the query atoms, thus keeping the size of the intermediate relations small. At the end, if the relation associated with the root of the join tree is not empty, then the query evaluates to true.

无环查询（acyclic queries），即关联超图为无结构的查询，可被高效解答。具体而言，利用Yannakakis算法[137]，布尔型无环查询可通过自底向上处理其任意连接树进行评估，通过在查询原子关联关系间执行向上半连接操作，从而保持中间关系规模较小。最终，若连接树根节点关联的关系非空，则查询结果为真。

For non-Boolean queries, after the bottom-up step we have described above, one can perform the opposite top-down step by filtering each child vertex from those tuples that do not match with its parent tuples. The filtered database enjoys the global consistency property: every tuple in every relation participates in some solution. By exploiting this property, all solutions can be computed with a backtrack-free procedure (i.e., with backtracks used to look for further solutions, and never caused by wrong choices).

对于非布尔型查询，在完成上述自底向上步骤后，可执行反向的自顶向下步骤：通过筛选每个子顶点中与其父元组不匹配的元组。经过筛选的数据库具有全局一致性特性——每个关系中的每个元组都参与某些解。利用该特性，所有解都可通过无回溯过程计算（即回溯仅用于寻找更多解，而非由错误选择引发）。

Combining the fact that acyclic queries can be efficiently answered with the fact that acyclicity is efficiently recognizable, such queries identify a so-called (accessible) "island of tractability" for the query answering problem [107]- and for equivalent problems, such as conjunctive query containment, constraint satisfaction problems, and so on [72].

结合无环查询可高效解答与无环性可高效识别的特性，此类查询为查询应答问题[107]（及等价问题如合取查询包含、约束满足问题等[72]）界定了一个所谓的（可访问的）"易处理性孤岛"。

### 3.1 Tree Decompositions

### 3.1 树分解

The notion of tree decomposition [123] represents a significant success story in Computer Science (see, e.g., [65]). The associated notion of treewidth was meant to provide a measure of the degree of cyclicity in graphs and hypergraphs. ${}^{2}$

树分解概念[123]是计算机科学领域的重大成功案例（参见[65]等）。其关联的树宽概念旨在量化图和超图中的环度。${}^{2}$

Formally,a tree decomposition [123] of a hypergraph $\mathcal{H}$ is a pair $\langle T,\chi \rangle$ ,where $T = \left( {V,F}\right)$ is a tree,and $\chi$ is a labeling function assigning to each vertex $p \in  V$ a set of vertices $\chi \left( p\right)  \subseteq  \operatorname{nodes}\left( \mathcal{H}\right)$ , such that the following three conditions are satisfied: (1) for each node $b$ of $\mathcal{H}$ ,there exists $p \in  V$ such that $b \in  \chi \left( p\right)$ ; (2) for each hyperedge $h \in  \operatorname{edges}\left( \mathcal{H}\right)$ ,there exists $p \in  V$ such that $h \subseteq  \chi \left( p\right)$ ; and (3) for each node $b$ in $\operatorname{nodes}\left( \mathcal{H}\right)$ ,the set $\{ p \in  V \mid  b \in  \chi \left( p\right) \}$ induces a connected subtree of $T$ . The width of $\langle T,\chi \rangle$ is the number $\mathop{\max }\limits_{{p \in  V}}\left( {\left| {\chi \left( p\right) }\right|  - 1}\right)$ . The treewidth of $\mathcal{H}$ ,denoted by $\operatorname{tw}\left( \mathcal{H}\right)$ , is the minimum width over all its tree decompositions.

形式上，超图$\mathcal{H}$的树分解[123]是一个二元组$\langle T,\chi \rangle$，其中$T = \left( {V,F}\right)$是树结构，$\chi$是给每个顶点$p \in  V$分配顶点集$\chi \left( p\right)  \subseteq  \operatorname{nodes}\left( \mathcal{H}\right)$的标记函数，需满足以下三个条件：(1) 对于$\mathcal{H}$的每个节点$b$，存在$p \in  V$使得$b \in  \chi \left( p\right)$；(2) 对于每条超边$h \in  \operatorname{edges}\left( \mathcal{H}\right)$，存在$p \in  V$使得$h \subseteq  \chi \left( p\right)$；(3) 对于$\operatorname{nodes}\left( \mathcal{H}\right)$中的每个节点$b$，集合$\{ p \in  V \mid  b \in  \chi \left( p\right) \}$能生成$T$的连通子树。该树分解$\langle T,\chi \rangle$的宽度是数值$\mathop{\max }\limits_{{p \in  V}}\left( {\left| {\chi \left( p\right) }\right|  - 1}\right)$，而超图$\mathcal{H}$的树宽（记作$\operatorname{tw}\left( \mathcal{H}\right)$）是其所有树分解中的最小宽度。

Recall from the introduction that the notion of treewidth does not generalize hypergraph acyclicity. For instance, consider the query ${Q}_{1}$ and its associated hypergraph shown in Figure 1. We have already observed that the hypergraph is acyclic (see Example 2.2), but the treewidth of this acyclic hypergraph is 6- note that there is a hyperedge defined over the variables $\{ A,C,D,E,F,G,H\}$ .

回顾引言部分，树宽概念并不能推广超图的无环性。例如，考虑图1所示的查询${Q}_{1}$及其关联超图。我们已观察到该超图是无环的（见示例2.2），但这个无环超图的树宽却是6——注意存在一个基于变量集$\{ A,C,D,E,F,G,H\}$定义的超边。

On the other hand, treewidth is a true generalization of graph acyclicity. Indeed, a graph is acyclic if, and only if, it has treewidth 1. In particular,note that the treewidth of a hypergraph $\mathcal{H}$ coincides with the treewidth of its primal graph, which is defined over the same set $\operatorname{nodes}\left( \mathcal{H}\right)$ of nodes of $\mathcal{H}$ and contains an edge for each pair of nodes included in some hyperedge of edges(H). In fact, the notion can be applied to other graph-based representations of hypergraphs, including dual and incidence graphs representations. These approaches are contrasted with each other in [81].

另一方面，树宽是图无环性的严格推广。事实上，当且仅当图的树宽为1时，该图是无环的。特别地，超图$\mathcal{H}$的树宽与其原始图（定义在相同节点集$\operatorname{nodes}\left( \mathcal{H}\right)$上，并为edges(H)中每条超边包含的节点对建立边）的树宽一致。该概念还可应用于超图的其他图表示形式，包括对偶图和关联图表示法。[81]中对这些方法进行了对比分析。

Determining the treewidth of a (hyper)graph is NP-hard. However,for each fixed natural number $k$ ,checking whether its treewidth is bounded by $k$ ,and if so,computing a tree decomposition of optimal width, is achievable in linear time [23], and was shown to be achievable in logarithmic space [48]. Note that the multiplicative constant factor of Bodlaender's linear algorithm [23] is a fast growing exponential in $k$ . However,there are algorithms that find in reasonable time tree decompositions whose width is a good upper approximation of the treewidth, in many cases of practical relevance [24].

确定（超）图的树宽是NP难问题。但对于每个固定自然数$k$，判断其树宽是否以$k$为界（若是则计算最优宽度的树分解）可在线性时间[23]内完成，并被证明能在对数空间[48]内实现。需注意Bodlaender线性算法[23]的倍增常数因子是$k$的快速增长指数函数。不过，对于许多实际应用场景[24]，现有算法能在合理时间内找到宽度接近树宽上界的树分解。

### 3.2 Hypertree Decompositions

### 3.2 超树分解

A crucial limitation for the practical use of the tree decomposition method in databases is that the method obscures, in many cases, the actual degree of cyclicity of the query hypergraph. Intuitively, many problems are easy if cycles are kept under control. In tree decompositions, this is obtained by using suitable bags of variables in the vertices of the decomposition trees. However, in hypergraph-based problems, any hyperedge may contain a large number of variables at once, so that in order to keep cycles under control, one can exploit the power of hyperedges. Therefore, we expect that a useful measure of degree of cyclicity for hyper-graphs depends on bags of hyperedges, rather than just bags of nodes. With this respect, the natural counter-part of the tree decomposition method over hypergraphs is the notion of (generalized) hypertree decomposition [74, 75].

树分解方法在数据库实践中应用的关键局限在于，该方法往往掩盖了查询超图的实际循环程度。直观而言，若能控制循环结构，许多问题将迎刃而解。在树分解中，这是通过在分解树顶点处使用恰当的变量包实现的。但对于基于超图的问题，任何超边都可能一次性包含大量变量，因此要控制循环结构，必须充分利用超边的特性。由此我们推断，超图循环程度的有效度量应依赖于超边包而非单纯的节点包。就此而言，超图上的树分解方法自然对应着（广义）超树分解的概念[74,75]。

DEFINITION 3.1 ([74]). A generalized hypertree decomposition of a hypergraph $\mathcal{H}$ is a triple ${HD} = \langle T,\chi ,\lambda \rangle$ ,called a hy-pertree for $\mathcal{H}$ ,where $\langle T,\chi \rangle$ is a tree decomposition of $\mathcal{H}$ ,and $\lambda$ is a function labeling the vertices of $T$ by sets of hyperedges of $\mathcal{H}$ such that,for each vertex $p$ of $T,\chi \left( p\right)  \subseteq  \mathop{\bigcup }\limits_{{h \in  \lambda \left( v\right) }}h$ . That is,all nodes in the $\chi$ labeling are covered by hyperedges in the $\lambda$ labeling.

定义3.1([74])。超图$\mathcal{H}$的广义超树分解是一个三元组${HD} = \langle T,\chi ,\lambda \rangle$（称为$\mathcal{H}$的超树），其中$\langle T,\chi \rangle$是$\mathcal{H}$的树分解，$\lambda$是将$T$顶点标记为超边集的函数，满足对于$T,\chi \left( p\right)  \subseteq  \mathop{\bigcup }\limits_{{h \in  \lambda \left( v\right) }}h$的每个顶点$p$而言——即$\chi$标记中的所有节点都被$\lambda$标记中的超边覆盖。

A hypertree decomposition is a generalized hypertree decomposition that satisfies the following additional condition,called ${De}$ - scendant Condition or also special condition: for each vertex $p$ of $T$ and for each hyperedge $h \in  \lambda \left( p\right)$ ,it holds that $h \cap  \chi \left( {T}_{p}\right)  \subseteq  \chi \left( p\right)$ , where ${T}_{p}$ denotes the subtree of $T$ rooted at $p$ ,and $\chi \left( {T}_{p}\right)$ the set of all variables occurring in the $\chi$ labeling of this subtree. Note that we are really interested in the variables occurring in the $\chi$ labels, with hyperedges in the $\lambda$ labels allowing us to effectively deal with such variables. In particular, according to the Descendant Condition,if we have to deal with some variable $X$ in the subtree ${T}_{p}$ , then we must immediately care about it in $p$ if it is possible (i.e., if $X$ occurs in some hyperedge in $\lambda \left( p\right)$ ). This condition was introduced to simplify the computation of decompositions, as we shall see in the next section. Moreover, note that all nodes that appear in the hyperedges of $\lambda \left( p\right)$ but that are not included in $\chi \left( p\right)$ are "ineffective" for $v$ and do not count w.r.t. the connectedness condition.

超树分解是满足以下附加条件（称为${De}$后代条件或特殊条件）的广义超树分解：对于$T$的每个顶点$p$和每条超边$h \in  \lambda \left( p\right)$，必有$h \cap  \chi \left( {T}_{p}\right)  \subseteq  \chi \left( p\right)$成立，其中${T}_{p}$表示$T$中以$p$为根的子树，$\chi \left( {T}_{p}\right)$表示该子树$\chi$标记中所有变量的集合。需注意我们真正关注的是$\chi$标签中的变量，而$\lambda$标签中的超边使我们能有效处理这些变量。特别地，根据后代条件，若需处理子树${T}_{p}$中的变量$X$，则只要可能（即$X$出现在$\lambda \left( p\right)$的某超边中），就必须在$p$处立即处理。引入该条件旨在简化分解计算（详见下节）。此外注意：出现在$\lambda \left( p\right)$超边中但未包含于$\chi \left( p\right)$的节点对$v$是"无效的"，不参与连通性条件判定。

The width of $\langle T,\chi ,\lambda \rangle$ is the number $\mathop{\max }\limits_{{p \in  V}}\left( \left| {\lambda \left( p\right) }\right| \right)$ . The (generalized) hypertree width of $\mathcal{H}$ ,denoted by $\left( g\right) {hw}\left( \mathcal{H}\right)$ ,is the minimum width over all its (generalized) hypertree decompositions. A class of hypergraphs has bounded (generalized) hypertree width if every hypergraph in the class has (generalized) hypertree width at most $k$ ,for some finite natural number $k > 0$ .

$\langle T,\chi ,\lambda \rangle$的宽度是数值$\mathop{\max }\limits_{{p \in  V}}\left( \left| {\lambda \left( p\right) }\right| \right)$。$\mathcal{H}$的（广义）超树宽度记作$\left( g\right) {hw}\left( \mathcal{H}\right)$，即所有（广义）超树分解中的最小宽度。若某类超图中每个超图的（广义）超树宽度都不超过有限自然数$k > 0$定义的$k$，则称该类具有有界（广义）超树宽度。

The notions of hypertree width and generalized hypertree width are true generalizations of acyclicity, as the acyclic hypergraphs are precisely those hypergraphs having (generalized) hypertree width one [75]. Moreover, recall from the introduction that for each hy-pergraph $\mathcal{H},\operatorname{ghw}\left( \mathcal{H}\right)  \leq  {hw}\left( \mathcal{H}\right)  \leq  3 \cdot  \operatorname{ghw}\left( \mathcal{H}\right)  + 1$ . Hence,this entails that a class of hypergraphs has bounded generalized hyper-tree width if, and only if, it has bounded hypertree width.

超树宽度和广义超树宽度的概念确实是无环性的广义化，因为无环超图正是那些（广义）超树宽度为1的超图[75]。此外，从引言中回顾可知，对于每个超图$\mathcal{H},\operatorname{ghw}\left( \mathcal{H}\right)  \leq  {hw}\left( \mathcal{H}\right)  \leq  3 \cdot  \operatorname{ghw}\left( \mathcal{H}\right)  + 1$而言，当且仅当某类超图具有有界广义超树宽度时，它才具有有界超树宽度。

### 3.3 Complexity of Computing HDs

### 3.3 超树分解的计算复杂度

Choosing a decomposition tree and suitable labelings $\chi$ and $\lambda$ in order to get a hypertree decomposition of width $\leq  k$ is not that easy, and it is definitely more difficult than computing a bounded-width tree decomposition. While, as already said, deciding whether a hy-pergraph has generalized hypertree width at most $k$ is NP-complete for any fixed $k \geq  3$ [76],the problem is fixed-parameter tractable if the parameter is the maximum hyperedge size (this follows from a more general result on tree projections [88]).

选择分解树及合适的标签$\chi$和$\lambda$以获得宽度为$\leq  k$的超树分解并非易事，这远比计算有界宽度树分解困难。虽然如前所述，判定超图是否具有至多$k$的广义超树宽度对任意固定$k \geq  3$都是NP完全问题[76]，但若参数设为最大超边尺寸时该问题存在固定参数可解性（这源于树投影更一般性结论[88]）。

For those instances where the number of hyperedges and their cardinality is not small,it is convenient to look for width- $k$ hyper-tree decompositions that, due to the Descendant Condition, can be computed in polynomial time [74]. Moreover, as observed above, they can differ from the best generalized hypertree decomposition of a very small constant factor. In order to get an intuition on this, it is convenient to recall here a useful characterization of hypertree decompositions in terms of the robber and marshals game [75].

当超边数量及其基数较大时，寻找满足后代条件、可在多项式时间内计算的宽度$k$超树分解更为适宜[74]。如上所述，它们与最优广义超树分解的差异可能仅在于极小常数因子。为理解这点，可通过"强盗与警察"游戏模型来回顾超树分解的有趣特征[75]。

The game is played by one robber and a number of marshals on a hypergraph. The robber moves on nodes, while marshals move on hyperedges. At each step, any marshal controls an entire hyper-edge. During a move of the marshals from the set of hyperedges $E$ to the set of hyperedges ${E}^{\prime }$ ,the robber cannot pass through the nodes in $B = \left( {\cup E}\right)  \cap  \left( {\cup {E}^{\prime }}\right)$ ,where,for a set of hyperedges $F$ , $\cup  F$ denotes the union of all hyperedges in $F$ . Intuitively,the vertices in $B$ are those not released by the marshals during their move from $E$ to ${E}^{\prime }$ . The game is won by the marshals if they corner and capture the robber somewhere in the hypergraph, by monotonically shrinking the moving space of the robber. A hypergraph $\mathcal{H}$ has $k$ - bounded hypertree width if,and only if, $k$ marshals win the robber and marshals game on $\mathcal{H}$ [75]. In particular, $\mathcal{H}$ is acyclic if,and only if,one marshal wins on $\mathcal{H}$ .

该游戏在一张超图上由一名盗贼与多名执法者进行。盗贼在节点间移动，执法者则在超边间行动。每一步中，任何执法者可控制整条超边。当执法者从超边集$E$移动至${E}^{\prime }$时，盗贼无法穿越$B = \left( {\cup E}\right)  \cap  \left( {\cup {E}^{\prime }}\right)$中的节点——此处对于超边集$F$，$\cup  F$表示$F$内所有超边的并集。直观而言，$B$中的顶点是执法者从$E$移至${E}^{\prime }$时未释放的区域。若执法者通过单调缩减盗贼活动空间将其围捕，则赢得游戏。当且仅当$k$名执法者能在超图$\mathcal{H}$上获胜时，该超图具有$k$界限超树宽度[75]。特别地，当且仅当一名执法者能胜出时，$\mathcal{H}$为无环结构。

It can be seen that winning strategies for the marshals correspond to certain normal form decompositions, where the escape spaces of the robber correspond to certain components of the hypergraph and redundancies are ruled out. In such decompositions, formally defined in [74] and later strengthened in [130, 87], the number of vertices cannot exceed the number of variables of $\mathcal{H}$ ,and is typically much smaller. Moreover, $\mathcal{H}$ has a hypertree decomposition of width $w$ if,and only if,it has a normal-form hypertree decomposition of the same width $w$ . It follows that the game characterization immediately gives to us an algorithm for computing hypertree decompositions. Indeed, one can use a logspace alternating Turing machine (ATM) for deciding whether the marshals win the game in a quite natural way. It can be shown that such a machine has always polynomial space computation trees for "yes" instances, which entails that,for any fixed $k \geq  1$ ,deciding whether a given hyper-graph has hypertree width at most $k$ is in LOGCFL. For the sake of completeness, we recall here that the class LOGCFL consists of all decision problems that are logspace reducible to a context-free language. Note that,since LOGCFL $\subseteq  {\mathrm{{AC}}}^{1} \subseteq  {\mathrm{{NC}}}^{2}$ ,deciding if a given hypergraph has hypertree width at most $k$ is a highly par-allelizable problem. Correspondingly, the problem of computing a $k$ -bounded hypertree decomposition belongs to the functional version of LOGCFL [74].

可以看出，执法者的获胜策略对应特定的范式分解，其中盗贼的逃逸空间对应超图的特定组件且冗余被消除。这类在[74]中正式定义、后经[130,87]强化的分解中，顶点数不超过$\mathcal{H}$的变量数，且通常更少。此外，当且仅当$\mathcal{H}$存在宽度为$w$的范式超树分解时，其才具有相同宽度的超树分解。由此，游戏特征直接给出了计算超树分解的算法。实际上，可自然运用对数空间交替图灵机(ATM)判定执法者是否获胜。可证明该机对"是"实例总有多项式空间计算树，故对于固定$k \geq  1$，判定超图是否具有至多$k$的超树宽度属于LOGCFL类。需说明LOGCFL包含所有可对数空间归约为上下文无关语言的决策问题。鉴于LOGCFL$\subseteq  {\mathrm{{AC}}}^{1} \subseteq  {\mathrm{{NC}}}^{2}$，该判定问题是高度可并行化的。相应地，计算$k$界限超树分解的问题属于LOGCFL的功能版本[74]。

### 3.4 Algorithms for Computing HDs

### 3.4 超树分解计算算法

Based on the intuitions discussed above, a number of algorithms for computing hypertree decompositions have been proposed. The (historically) first implementation is based on dynamic programming and is a quite direct simulation of the method suggested by the game, where we evaluate a bipartite graph whose nodes encodes the possible choices of the $k$ marshals (i.e., $k$ -uples of hyperedges) and the possible escape spaces for the robber (i.e., components of nodes determined by the moves of the marshals) [71]. This algorithm,called opt- $k$ -decomp,is good if we would like to compute an optimal hypertree decomposition, that is, a decomposition whose width is precisely the hypertree width of the given hyper-graph. Whenever we are instead satisfied with any (possibly not optimal) width- $k$ hypertree decomposition for some a-priori chosen width $k$ ,it may be better to tackle an opposite top-down approach, as done in the algorithm proposed in [77], which exhibits good performances by using heuristic approaches to accelerate the search for a (generalized) hypertree decomposition of width at most $k$ (not necessarily the minimal one). The resulting algorithm det- $k$ -decomp is based on backtracking,and can also be implemented for parallel executions.

基于上述原理，研究者提出了多种超树分解算法。首个实现方案采用动态规划，直接模拟游戏方法：通过评估二分图（其节点编码$k$名执法者的可能选择即$k$元超边组，以及盗贼逃逸空间即执法者移动决定的节点组件）[71]。该opt-$k$-decomp算法适用于计算最优超树分解（即宽度精确等于超图超树宽度的分解）。若仅需获取预先选定宽度$k$的（未必最优）超树分解，则采用[77]提出的自顶向下算法更佳，其通过启发式方法加速搜索宽度至多$k$的（广义）超树分解（未必最小），表现优异。由此产生的det-$k$-decomp算法基于回溯，亦可并行化实现。

We note however that,if the threshold width $k$ is not very small and the hypergraph has many hyperedges, then exact algorithms may require too much time. In fact, unlike treewidth, the problem of deciding whether ${hw}\left( \mathcal{H}\right)  \leq  k$ is fixed-parameter intractable (more precisely,W[2]-hard) if the threshold $k$ is used as parameter [66]. Therefore, unless some unlikely collapse occurs in the classes defined by the fixed-parameter complexity theory, an exponential dependency on $k$ of the form $O\left( {{f}_{1}{\left( n\right) }^{{f}_{2}\left( k\right) }}\right)$ is unavoidable. This is usually not a problem for database applications, but large hypergraphs may occur in other applications of hypertree decompositions, such as constraint satisfaction problems or those that we mention in Section 7.

然而我们注意到，若阈值宽度$k$并非极小且超图存在大量超边，则精确算法可能耗时过长。事实上，与树宽不同，当采用阈值$k$作为参数时，判定${hw}\left( \mathcal{H}\right)  \leq  k$的问题属于固定参数难解类（更准确地说，是W[2]-难问题）[66]。因此，除非固定参数复杂性理论定义的类出现意外塌缩，否则形式为$O\left( {{f}_{1}{\left( n\right) }^{{f}_{2}\left( k\right) }}\right)$的对$k$的指数级依赖不可避免。这对数据库应用通常不成问题，但在超树分解的其他应用场景（如约束满足问题或第7节提及的应用）中可能出现大型超图。

For dealing with large instances, a number of algorithms based on heuristics have been proposed, in order to find efficiently (generalized) hypertree decompositions of a given hypergraph $\mathcal{H}$ ,without a bounded guarantee on their width. A widely used technique is to look for some tree decomposition of $\mathcal{H}$ ,e.g.,by using the bucket elimination method by [44] or any other algorithm developed for tree decompositions [22], and then cover the bags of nodes with as few hyperedge as possible (by using set covering heuristics) in order to get a generalized hypertree decomposition. As proposed in $\left\lbrack  {{47},{109}}\right\rbrack$ ,this can be improved by using techniques to find good separators, that is, suitable sets of nodes that are able to partition the hypergraph to deal with the components to be decomposed-think of them as the possible escape spaces for the robber.

针对大规模实例处理，学界提出了多种基于启发式的算法，旨在高效获取给定超图$\mathcal{H}$的（广义）超树分解，而无需保证宽度有界。常用技术是先寻找$\mathcal{H}$的某种树分解（例如采用[44]的桶消元法或专为树分解设计的其他算法[22]），再通过集合覆盖启发式方法用尽可能少的超边覆盖节点包，从而得到广义超树分解。如$\left\lbrack  {{47},{109}}\right\rbrack$所述，可通过寻找优质分隔符（即能将超图分割成待分解组件的合适节点集——可视作盗贼的潜在逃逸空间）的技术来优化此过程。

Other heuristic approaches aim at finding some restricted kinds of decompositions, such as the connected hypertree decompositions of [132]. Another technique has been discussed in [127], which shows how to use the branch-decomposition approach for ordinary graphs [38] for the heuristic construction of generalized hypertree decompositions (based on the fact that every branch decomposition of width $k$ can be transformed into a tree decomposition of width at most ${3k}/2$ ). The use of tabu search for computing (generalized) hypertree decompositions was considered in [116].

其他启发式方法致力于寻找特定类型的分解，例如[132]提出的连通超树分解。[127]中探讨了另一种技术，展示如何将普通图的枝分解方法[38]应用于广义超树分解的启发式构造（基于宽度为$k$的枝分解可转化为宽度至多${3k}/2$的树分解这一事实）。[116]研究了利用禁忌搜索计算（广义）超树分解的可能性。

A list of available implementations of algorithms for computing hypertree decompositions (and heuristics) is available at the Hyper-tree Decomposition HomePage [128].

超树分解算法（及启发式方法）的可用实现清单可查阅超树分解主页[128]。

### 4.HOW TO ANSWER A QUERY VIA HY- PERTREE DECOMPOSITIONS?

### 4.如何通过超树分解应答查询？

There are different ways to use (generalized) hypertree decompositions for answering a query (as well as, for instance, to check query containment). We here review some of them, starting with the most natural one.

利用（广义）超树分解应答查询（或检验查询包含等）存在多种方式。下文将回顾其中几种，从最自然的方法开始。

### 4.1 HDs and Query Plans

### 4.1 超树分解与查询计划

Let $Q$ be a conjunctive query over a database instance DB,and let ${HD} = \langle T,\chi ,\lambda \rangle$ be a generalized hypertree decomposition for ${\mathcal{H}}_{Q}$ whose width is $k$ . The basic idea is to use ${HD}$ as a guide for obtaining a logical query plan that allows us to answer the query in a similar way we can do for acyclic queries. A high level view of this approach is given by the following two steps.

设$Q$为数据库实例DB上的联合查询，${HD} = \langle T,\chi ,\lambda \rangle$为${\mathcal{H}}_{Q}$的宽度$k$的广义超树分解。基本思路是将${HD}$作为指导，获取逻辑查询计划，从而以处理无环查询的类似方式应答查询。该方法的高层视角包含以下两个步骤。

First,for each vertex $p$ in the decomposition tree $T$ ,we compute a fresh atom such that: its set of variables is $\chi \left( p\right)$ ; its relation is obtained by projecting on $\chi \left( p\right)$ the join of all relations associated with the query atoms whose sets of variables are the hyperedges in $\lambda \left( p\right)$ . After that,because the $\chi$ labeling encodes a tree decomposition, it can be seen that the conjunction of these fresh atoms forms an acyclic conjunctive query,say ${Q}^{\prime }$ ,equivalent to $Q$ . Indeed,the decomposition tree $T$ represents a join tree of ${\mathcal{H}}_{{Q}^{\prime }}$ ; all fresh atoms encodes subqueries of $Q$ (hence cannot be more restrictive than the original query); and all query atoms are included in some of these subqueries (so that ${Q}^{\prime }$ cannot be more liberal than $Q$ ). Moreover, because the hypertree width is at most $k$ ,each subquery consists of $k$ atoms at most and can be answered in polynomial time.

首先，对于分解树$T$中的每个顶点$p$，我们计算一个新原子，其变量集合为$\chi \left( p\right)$；该原子的关系是通过将所有与查询原子相关联的关系（这些原子的变量集合是$\lambda \left( p\right)$中的超边）在$\chi \left( p\right)$上进行投影连接而获得。此后，由于$\chi$标记编码了树分解结构，可以看出这些新原子的合取构成了一个无环合取查询${Q}^{\prime }$，其等价于$Q$。实际上，分解树$T$表示了${\mathcal{H}}_{{Q}^{\prime }}$的连接树；所有新原子编码了$Q$的子查询（因此不会比原查询更具限制性）；且所有查询原子都包含在这些子查询中（因此${Q}^{\prime }$不会比$Q$更宽松）。此外，由于超树宽度至多为$k$，每个子查询最多包含$k$个原子，并可在多项式时间内求解。

#### 4.1.1 More Accurate Bounds

#### 4.1.1 更精确的边界估计

The above bounds are largely determined by the output size of the subqueries associated with the vertices of the decomposition tree,for which the estimate ${r}^{\prime } = {r}^{k}$ is a very rough upper bound. In fact, a number of works recently investigated in detail how to derive more accurate bounds. For each vertex $p$ of the decomposition tree,let ${Q}_{p}$ be the conjunctive subquery associated with $p$ , that is,the join of the relations associated with hyperedges in $\lambda \left( p\right)$ , projected over its "local output variables" $\chi \left( p\right)$ . In [67],the notion of coloring number $C\left( {Q}_{p}\right)$ of such a query is defined and shown to provide a tight bound,namely ${r}_{p}^{C\left( {Q}_{p}\right) }$ ,for the output size of ${Q}_{p}$ , where ${r}_{p}$ is the size of the largest relation occurring in the input database for ${Q}_{p}$ . By using the fact that we are interested only in the output variables of the subquery ${Q}_{p}$ ,this bound improves an earlier defined bound, called AGM bound after the authors of [14]. This bound is based on the notion of fractional cover $\left\lbrack  {{90},{14}}\right\rbrack$ (see also Section 8). Moreover, the coloring number is able to take into account certain kinds of functional dependencies, such as keys, and can be used to provide a tight bound for the output size of the whole query $Q$ ,too.

上述边界主要由分解树顶点关联子查询的输出规模决定，而估算值${r}^{\prime } = {r}^{k}$是个非常宽松的上界。事实上，近期多项研究详细探讨了如何推导更精确的边界。对于分解树每个顶点$p$，设${Q}_{p}$为关联的合取子查询（即$\lambda \left( p\right)$中超边对应关系在其"局部输出变量"$\chi \left( p\right)$上的投影连接）。文献[67]定义了该查询的着色数$C\left( {Q}_{p}\right)$概念，证明其能给出${Q}_{p}$输出规模的紧确界${r}_{p}^{C\left( {Q}_{p}\right) }$（其中${r}_{p}$是子查询${Q}_{p}$输入数据库中最大关系的规模）。通过聚焦子查询${Q}_{p}$的输出变量，该边界改进了早先基于分数覆盖$\left\lbrack  {{90},{14}}\right\rbrack$概念的AGM边界（得名自文献[14]作者）。着色数还能考量键值等函数依赖关系，并为整个查询$Q$的输出规模提供紧确界。

Similar size bounds were also obtained for the factorised representations of query results [119], where relations are succinctly represented through relational algebra expressions comprising Cartesian products, relations with singleton tuples, and their unions.

查询结果的因子化表示[119]同样获得了类似的规模边界，该表示法通过包含笛卡尔积、单例元组关系及其并集的关系代数表达式来简洁描述关系。

The above bounds are based on structural information only, without considering (besides keys) auxiliary information about data such as relation sizes, histograms, or attributes selectivities. By using such information on the input database, yet more refined bounds can be obtained, which can also guide the search for a "good" decomposition for the given database, as we shall see later in Section 6. Besides classical estimates used in database optimization (see, e.g., [54]), we mention here the recent DBP bound, based on the notion of degree-based packing [97], which exploits the information on the number of tuples in which any value occurs in a relation (degree of the value).

上述边界仅基于结构信息，未考虑（除键值外）关系规模、直方图或属性选择性等数据辅助信息。利用输入数据库的此类信息可获得更精细的边界，并能指导寻找适合特定数据库的"优质"分解方案（详见第6节）。除数据库优化中的经典估计方法（如[54]）外，我们特别提及基于度数打包[97]概念的DBP边界，该边界利用了关系中每个值出现的元组数（值的度数）信息。

#### 4.1.2 Hypertree-Based Plans for Multiway Joins

#### 4.1.2 多元连接的基于超树计划

Recent works have shown that traditional query optimizers are provably suboptimal on large classes of queries, and worst-case optimal algorithms have been developed [118, 136]. Such algorithms, based on a multiway join approach that may look at all atoms at once, have been implemented, e.g., in the LogicBlox system [11] and in the EmptyHeaded relational engine [1, 2]. Unfortunately, these algorithms are not able to recover the polynomial-time worst-case bounds for queries having bounded hypertree width. For instance, they may require exponential time for acyclic queries with an empty output (as long as, in principle, such queries could have an exponential number of answers). To overcome these troubles, EmptyHeaded additionally features a query compiler based on hy-pertrees: it searches for a GHD having the minimum possible estimated size for the intermediate results (by using fractional covers and the AGM bound), and then uses this information to determine the order of attributes to be used in the multiway joins. Such an order is also exploited for the multi-level data structures, called tries, used to store input and output relations, and to perform the joins efficiently. For experimental results, see Section 9. We also mention a different approach designed for the Leapfrog Trie Join algorithm [136], where (hyper)tree decompositions are used to guide a flexible caching of intermediate results [98]. The algorithm described in [103] considers also possible functional dependencies, by using the coloring number bound of [67].

近期研究表明，传统查询优化器在大量查询类别上存在可证明的次优性，为此研究者开发了最坏情况最优算法[118, 136]。这类基于多路连接方法（可同时处理所有原子谓词）的算法已在LogicBlox系统[11]和EmptyHeaded关系引擎[1,2]中实现。但这类算法无法为具有有界超树宽度的查询恢复多项式时间的最坏情况界限——例如对于输出为空的非循环查询（只要理论上可能产生指数级数量答案），它们仍需要指数时间。为解决此问题，EmptyHeaded额外配备了基于超树的查询编译器：通过分数覆盖和AGM界寻找具有最小预估中间结果规模的广义超树分解(GHD)，据此确定多路连接中的属性顺序。该顺序还用于构建称为trie的多层数据结构，以高效存储输入/输出关系并执行连接操作（实验结果见第9节）。另有研究针对Leapfrog Trie Join算法[136]提出不同方案：利用（超）树分解指导中间结果的灵活缓存[98]。文献[103]所述算法还通过[67]的着色数界考虑了函数依赖的可能性。

Further algorithms based on multiway joins have been defined in order to guarantee the worst-case upper bound that can be obtained by using generalized hypertree decompositions of the given query (more precisely, the bound determined by its fractional hypertree width-see Section 8), without using a dynamic programming approach á la Yannakakis. This is the case in [104], where a notion of geometric resolution is defined to support different kinds of indices and even multiple indices per table. By performing such resolutions, the proposed algorithm covers the whole multidimensional (tuple) space by distinguishing the output tuples (if any) and the other infeasible (non-matching) tuples. As opposed to the standard bottom-up computation, this method can be viewed as a backtracking algorithm with memoization.

为确保最坏情况下界（由给定查询的广义超树分解决定，具体取决于分数超树宽度，见第8节）且避免Yannakakis式动态规划，研究者定义了更多基于多路连接的算法。文献[104]提出几何分辨率概念，支持多类索引乃至单表多索引。该算法通过执行此类分辨率，在多维元组空间中区分输出元组（若存在）与非匹配元组。与标准自底向上计算不同，该方法可视为带记忆化的回溯算法。

#### 4.1.3 Parallel and Distributed Evaluation

#### 4.1.3 并行与分布式评估

From a computational complexity viewpoint, evaluating Boolean queries having bounded hypertree-width is LOGCFL-complete (even for binary acyclic queries) [72]. Combining the result with the techniques discussed by [73], it can be seen easily that the corresponding computation problem (output an answer) is in (functional) LOGCFL. It is known that this class contains highly par-allelizable problems: Any problem in LOGCFL is solvable in logarithmic time by a concurrent-read concurrent-write parallel random access machine (CRCW PRAM) with a polynomial number of processors,or in ${\log }^{2}$ -time by an exclusive-read exclusive-write (EREW) PRAM with a polynomial number of processors. In fact, efforts have been spent in the literature to translate these theoretical results into practical implementation of algorithms for parallel (and distributed) query evaluation.

从计算复杂度角度看，评估具有有界超树宽度的布尔查询属于LOGCFL完全问题（即使二元非循环查询亦然）[72]。结合文献[73]的技术可知，对应计算问题（输出答案）属于（函数型）LOGCFL类。该类包含高度可并行化问题：任何LOGCFL问题均可由多项式数量处理器的并发读写随机存取机器(CRCW PRAM)在对数时间内求解，或由多项式数量处理器的互斥读写机器(EREW PRAM)在${\log }^{2}$时间内求解。学界正致力于将这些理论成果转化为并行（及分布式）查询评估算法的实际实现。

A parallel algorithm, called DB-SHUNT, has been defined in [72] for answering Boolean acyclic queries-an extension, called ACQ, which is able to deal with acyclic queries with output variables is discussed in [68]. This algorithm is well-suited for bounded hypertree-width queries once the transformation process in Section 4.1 has been performed. The transformation itself can be done by exploiting parallelism. For instance, the data storage in the Emp-tyHeaded system is specifically designed to leverage SIMD parallel architectures, in particular, for the execution of the multiway joins to be performed at every vertex of the decomposition tree. Having the (equivalent) acyclic query at hand, DB-SHUNT (and ACQ) uses a special shunt operation based on relational algebra for contracting a join tree, akin the well-known shunt operation used for the parallel evaluation of arithmetic expressions [100]. This way, any tree can be contracted to a single node by a logarithmic number of parallel steps, independently of the shape of the tree (e.g., even if the tree is a highly unbalanced chain).

文献[72]提出的DB-SHUNT并行算法专用于回答布尔型非循环查询，其扩展版本ACQ[68]可处理含输出变量的非循环查询。该算法特别适用于完成第4.1节转换后的有界超树宽度查询，转换过程本身也可并行化。例如EmptyHeaded系统专门优化了SIMD并行架构下的数据存储，以支持分解树各顶点处多路连接的执行。DB-SHUNT（及ACQ）利用基于关系代数的特殊分流操作收缩连接树，类似于算术表达式并行评估中的经典分流操作[100]。通过对数级并行步骤，任何树结构（包括高度不平衡链）均可收缩为单节点。

More in detail,the decomposition tree $T$ is preliminary made strictly binary, and its leaves are numbered from left to right. At each iteration, the shunt operation is applied in parallel to all odd numbered leaves of $T$ . To avoid concurrent changes on the same relation, left and right leaves are processed in two distinct steps. Thus, after each iteration, the number of leaves is halved, and the tree-contraction ends within $2\log m$ parallel steps by using $O\left( m\right)$ processors and $O\left( m\right)$ intermediate relations having size at most $O\left( {r}^{2}\right)$ ,where $r$ is the size of the largest relation of the database instance and $m$ is the number of vertices of $T$ . It can be shown that, if we have a fixed number of processors $c < m/2$ ,then the number of parallel shunt operations becomes $2\left( {\lceil \log c\rceil  + 2\lceil m/\left( {4c}\right) \rceil }\right)$ . Here, transformations of query atoms and input other than relations are considered costless as long as they are polynomial. Moreover, the above cost refers to the first bottom-up processing of the decomposition tree, which is enough for the evaluation of a Boolean query. For computing the answers of a non-Boolean query, two further processing of the tree are needed, with the same cost (but for the space consumption of the final ascending phase, where we have to consider an additional cost that is linear in the output size).

具体而言，分解树$T$首先被预处理为严格二叉树，其叶子节点从左至右编号。每次迭代时，分流操作并行作用于$T$所有奇数编号的叶节点。为避免对同一关系进行并发修改，左右叶节点的处理分为两个独立步骤。因此每次迭代后叶节点数量减半，在使用$O\left( m\right)$个处理器和不超过$O\left( {r}^{2}\right)$规模的$O\left( m\right)$个中间关系时，树收缩过程可在$2\log m$个并行步骤内完成——其中$r$表示数据库实例中最大关系的规模，$m$是$T$的顶点数。可以证明，当处理器数量固定为$c < m/2$时，并行分流操作次数将变为$2\left( {\lceil \log c\rceil  + 2\lceil m/\left( {4c}\right) \rceil }\right)$。需说明的是，只要满足多项式复杂度，查询原子及非关系输入的转换视为零成本。上述复杂度指标针对分解树的首次自底向上处理，该过程足以完成布尔查询求值。对于非布尔查询，还需进行两次相同复杂度的树处理（但最终自顶向下阶段需额外考虑与输出规模线性相关的空间开销）。

An implementation of the above strategy has been recently described in [7] for the Valiant's bulk synchronous parallel (BSP) computational model [135], which can simulate the PRAM model. In this model, there are a set of connected machines that do not share any memory. The computation consists in general in a series of rounds, where machines perform some local computation in parallel and communicate messages over the network. Moreover, the same authors use generalized hypertree decompositions for parallel query answering in their GYM algorithm [7], which is a distributed and generalized version of Yannakakis' algorithm specifically designed for MapReduce [43] (as well as for other BSP-based frameworks). In fact, especially after the introduction of Google MapRe-duce, the problem of evaluating joins efficiently in distributed environments has been attracting much attention in the literature. In a BSP distributed environment, algorithms should mainly deal with the communication costs between the machines, and the number of global synchronizations that are needed to take place between the machines, in particular, the number of rounds of MapReduce jobs that need to be executed.

该策略的最新实现见于文献[7]提出的Valiant批量同步并行(BSP)计算模型[135]，该模型可模拟PRAM模型。该模型中，多台互联机器不共享内存，计算过程由若干轮次构成：各机器并行执行本地计算并通过网络交换消息。作者团队在其GYM算法[7]中进一步采用广义超树分解实现并行查询应答，该算法是Yannakakis算法针对MapReduce[43]（及其他BSP框架）的分布式广义版本。事实上，自Google MapReduce问世以来，分布式环境下的高效连接计算问题始终是学界热点。在BSP分布式环境中，算法设计需重点考虑机器间通信成本及全局同步次数，特别是所需执行的MapReduce作业轮次。

### 4.2 Answering Queries without Decompositions

### 4.2 无分解结构的查询应答

The above approaches to answer a query need to exploit the knowledge of a suitable decomposition tree. However, approaches have been proposed in the literature that do not need this knowledge and that can answer the query by means of "local" computations only. The basic idea is, again, inspired by an interesting property of acyclic queries: local consistency entails global consistency.

上述查询应答方法均需依赖特定分解树知识。然而现有文献已提出仅通过"局部"计算即可应答查询的无分解方法，其核心思想源自无环查询的重要特性：局部一致性可推导全局一致性。

#### 4.2.1 Answering Acyclic Queries without Join Trees

#### 4.2.1 无连接树的无环查询应答

Let $\mathrm{{DB}}$ be a database instance,let $Q$ be a Boolean acyclic query, and let ${\mathcal{V}}_{Q}$ denote the set of relations associated with the query atoms of $Q$ . Recall that,according to Yannakakis’ algorithm [137], we can answer $Q$ on DB by processing any join tree bottom-up,by performing upward semijoins on the relations in ${\mathcal{V}}_{Q}$ .

设$\mathrm{{DB}}$为数据库实例，$Q$为布尔型无环查询，${\mathcal{V}}_{Q}$表示与该查询原子关联的关系集合。根据Yannakakis算法[137]，我们可通过自底向上处理任意连接树并对${\mathcal{V}}_{Q}$中的关系执行上向半连接，在DB上应答$Q$。

Consider now a different approach that, at the first step, performs the semijoin between all pairs of relations in ${\mathcal{V}}_{Q}$ ,without any specific ordering. Note that the semijoin that Yannakakis' algorithm would perform as the first one is also performed at the first step of this novel approach, even though interleaved with other semijoins. The crucial observation is that these additional semijoins preserve the semantics of the query, and they can possibly help to speed up the computation: If some relation becomes empty during the process, then the answer of the query is clearly empty, too.

现考虑一种新方法：首步对${\mathcal{V}}_{Q}$中所有关系对执行无特定顺序的半连接。需注意，Yannakakis算法首步执行的半连接在此新方法首步中同样会被执行（尽管可能与其他半连接交错进行）。关键发现在于，这些额外半连接能保持查询语义，并可能加速计算——若某关系在此过程中变为空集，查询结果显然也为空。

Let us iterate the method, by performing again semijoins between all pairs of relations. Of course, the semijoin that Yan-nakakis' algorithm would perform as the second one is also performed at this second step, even though interleaved with other semi-joins that might have filtered out only tuples that will never contribute to the answer of $Q$ .

通过重复执行所有关系对间的半连接来迭代该方法。显然，Yannakakis算法第二步执行的半连接在此方法的第二步同样会被执行（尽管可能与那些仅过滤掉对$Q$结果无贡献元组的其他半连接交错进行）。

By repeating this method for $\left| {\mathcal{V}}_{Q}\right|$ steps,since any join tree contains $\left| {\mathcal{V}}_{Q}\right|$ nodes at most,it is now clear that all semijoins that Yan-nakakis' algorithm would perform are also performed in the same order, just being interleaved with other semijoins - irrelevant as far as the correctness is concerned. Hence, we derive that the answer of $Q$ is empty if,and only if,some relation becomes empty at the end of the process. Therefore,the query $Q$ has been answered without the knowledge of any join tree, but only under the guarantee (promise) that it is actually an acyclic query. In fact, this approach involves computing $O\left( {\left| {\mathcal{V}}_{Q}\right| }^{3}\right)$ semijoins in the worst case. Hence, it is hardly useful in practice for dealing with acyclic queries, since computing a join tree is feasible in linear time [133] and since, based on it,we can answer the query with $O\left( \left| {\mathcal{V}}_{Q}\right| \right)$ semijoins only.

通过重复此方法$\left| {\mathcal{V}}_{Q}\right|$步后，由于任何连接树最多包含$\left| {\mathcal{V}}_{Q}\right|$个节点，现在可以明确：Yannakakis算法执行的所有半连接都以相同顺序被执行，只是与其他半连接（就正确性而言无关紧要的）交叉进行。因此，我们推导出$Q$的答案为空当且仅当某些关系在过程结束时变为空。故该查询$Q$的解答无需知晓任何连接树，仅需保证（承诺）其确实是无环查询。实际上，该方法在最坏情况下需要计算$O\left( {\left| {\mathcal{V}}_{Q}\right| }^{3}\right)$次半连接。因此，在处理无环查询时几乎无实用价值，因为计算连接树可在线性时间内完成[133]，且基于连接树仅需$O\left( \left| {\mathcal{V}}_{Q}\right| \right)$次半连接即可解答查询。

Actually, the approach described above is a correct query answering method not only for acyclic queries, but also for queries whose cores are acyclic $\left\lbrack  {{82},{84}}\right\rbrack$ . For the sake of completeness, let us recall and exemplify the concept of core. Let ${Q}^{\prime }$ be such that atoms $\left( {Q}^{\prime }\right)  \subseteq  \operatorname{atoms}\left( Q\right)$ ,i.e., ${Q}^{\prime }$ is a subquery of $Q$ ,and assume there is a homomorphism from $Q$ to ${Q}^{\prime }$ . Then, $Q$ and ${Q}^{\prime }$ are homomorphically equivalent. Moreover,if ${Q}^{\prime }$ is a minimal homo-morphically equivalent subquery of $Q$ ,then ${Q}^{\prime }$ is a core of $Q$ . All cores are isomorphic with each other.

实际上，上述方法不仅是无环查询的正确解答方法，也适用于核心为无环的查询$\left\lbrack  {{82},{84}}\right\rbrack$。为完备性起见，让我们回顾并示例"核心"概念。设${Q}^{\prime }$满足原子式$\left( {Q}^{\prime }\right)  \subseteq  \operatorname{atoms}\left( Q\right)$，即${Q}^{\prime }$是$Q$的子查询，并假设存在从$Q$到${Q}^{\prime }$的同态映射。那么$Q$与${Q}^{\prime }$同态等价。此外，若${Q}^{\prime }$是$Q$的最小同态等价子查询，则${Q}^{\prime }$是$Q$的核心。所有核心彼此同构。

Note that Yannakakis' algorithm can be still applied on queries with acyclic cores, in particular by building a join tree associated with a core. However, computing a core is a NP-hard task so that, for large queries involving many atoms or in the equivalent setting of constraint satisfaction (see Section 7), the above computation approach that does not need the knowledge of a join tree might be a more viable option. Moreover and somehow surprisingly, acyclicity of a core is a necessary condition for the approach to work. Indeed, the approach is a sound and complete query answering method for a query $Q$ on every database instance DB if, and only if, $Q$ has an acyclic core $\left\lbrack  {{82},{84}}\right\rbrack$ .

需注意Yannakakis算法仍可应用于具有无环核心的查询，特别是通过构建与核心关联的连接树。然而，计算核心属于NP难问题，因此对于涉及大量原子式的大型查询或等效约束满足场景（见第7节），这种无需知晓连接树的计算方法可能是更可行的选择。此外出人意料的是，核心的无环性是该方法的必要条件。实际上，该方法当且仅当查询$Q$具有无环核心$\left\lbrack  {{82},{84}}\right\rbrack$时，才是针对每个数据库实例DB的可靠且完备的查询解答方法。

Note that having acyclic cores characterizes the (Boolean) semantic acyclic queries, that is, those conjunctive queries that are equivalent to acyclic ones [17] (see also [16]). Putting it all together, we get that a Boolean conjunctive query is a semantic acyclic query if, and only if, it can be answered by just enforcing local consistency. However, this result stated on classes defined via "cores" is a tractability result for the promise version of the problem, that is, the method can be applied only if we have a guarantee on the fact that $Q$ is a semantic acyclic query. In fact,it has been observed $\left\lbrack  {{129},{27}}\right\rbrack$ that,unless $\mathrm{P} = \mathrm{{NP}}$ ,there is no efficient way to distinguish whether a non-empty answer means that the query has a true non-empty answer,or that $Q$ has no acyclic core.

值得注意的是，具有无环核心是（布尔）语义无环查询的特征，即那些等价于无环查询的合取查询[17]（另见[16]）。综合来看，布尔合取查询是语义无环查询当且仅当仅通过强制局部一致性即可解答。但基于"核心"定义的类所表述的这一结果，是该问题承诺版本的易处理性结果——即仅当我们能保证$Q$是语义无环查询时方可应用此方法。事实上已有研究$\left\lbrack  {{129},{27}}\right\rbrack$表明，除非$\mathrm{P} = \mathrm{{NP}}$，否则无法有效区分非空答案究竟意味着查询确有真实非空答案，还是$Q$不存在无环核心。

#### 4.2.2 Answering Low-Width Queries without HDs

#### 4.2.2 无超分解的低宽度查询解答

Using algorithms for answering queries that are not acyclic, without the knowledge of a decomposition, attracted much attention in the literature (e.g., $\left\lbrack  {{32},{41},{13},{61}}\right\rbrack$ ). In fact,the precise relationship between generalized hypertree decompositions and such algorithms has recently been clarified.

在缺乏分解知识的情况下，利用算法回答非环状查询的问题引起了学界广泛关注（如$\left\lbrack  {{32},{41},{13},{61}}\right\rbrack$）。事实上，广义超树分解与此类算法之间的精确关系近期已得到阐明。

For any fixed natural number $k > 0$ ,let ${\mathcal{V}}_{Q,k}$ be the set of relations containing,for each $k$ -tuple of query atoms,one relation obtained as the join of the corresponding $k$ database relations. In this case, the idea is to repeatedly perform semijoins between all pairs of relations in ${\mathcal{V}}_{Q,k}$ until a fixpoint is reached. At this point,either some relation is empty or we got the so-called $k$ -local consistency property. In the former case,we are sure that the answer of $Q$ on the given database is empty. We say that a Boolean query $Q$ can be answered by enforcing $k$ -local consistency if,for any given database, its answer is non-empty if, and only if, the above procedure ends without getting empty relations (that is,we achieve $k$ -local consistency). It has been shown that this happens if,and only if, $Q$ has a core whose generalized hypertree width is at most $k\left\lbrack  {{82},{84}}\right\rbrack$ . Therefore, similarly to the case of acyclic queries, we can answer the query $Q$ neither knowing the core nor knowing any generalized hypertree decomposition $\langle T,\chi ,\lambda \rangle$ of ${\mathcal{H}}_{Q}$ . In this extension, the semijoin operations are defined with respect to all variables occurring in the $k$ -tuples of query atoms,that is,without considering the key role played by the variables occurring in the $\chi$ labeling in any decomposition tree. The correctness of this approach follows immediately from the correctness of the projection-free variant for answering width- $k$ queries described in Section 4.1.

对于任意固定自然数$k > 0$，令${\mathcal{V}}_{Q,k}$为包含所有查询原子$k$元组的关系集合，其中每个关系由对应$k$个数据库关系的连接构成。此时的核心思想是在${\mathcal{V}}_{Q,k}$中所有关系对之间反复执行半连接操作直至达到不动点。此时，要么某关系为空，要么获得所谓的$k$-局部一致性属性。前者情况下可确定给定数据库上查询$Q$的答案为空。若对任意数据库，当且仅当上述过程未产生空关系（即达成$k$-局部一致性）时查询答案非空，则称布尔查询$Q$可通过强制$k$-局部一致性解答。研究表明，这当且仅当$Q$存在广义超树宽度不超过$k\left\lbrack  {{82},{84}}\right\rbrack$的核心时成立。因此，类似于环状查询情形，我们无需知晓核心或任何广义超树分解$\langle T,\chi ,\lambda \rangle$即可回答查询$Q$。此扩展中，半连接操作针对查询原子$k$元组中所有变量定义，不考虑分解树$\chi$标记变量的关键作用。该方法的正确性直接源于第4.1节所述无投影变体处理宽度$k$查询的正确性。

Let $v$ be the number of variables occurring in the core of $Q$ . Assume the core has a generalized hypertree decomposition of width $k$ . From the results in [87] it follows that it has a decomposition of the same width which has at most $v$ decomposition vertices. Therefore,the fixpoint for enforcing $k$ -local consistency must end after at most $2 \cdot  v$ rounds of semijoins. In particular this entails that,if a fixpoint is not reached after $2 \cdot  \operatorname{vars}\left( Q\right)$ rounds,then we are sure that the generalized hypertree width of $Q$ (and of its core) is greater than $k$ . Again,the notion of core plays a crucial role,so that the approach might be viewed as a viable query answering procedure in the presence of large queries for which computing a core-and a generalized hypertree decomposition (both NP-hard tasks)-may be practically infeasible. However, the tractability result holds for the promise version of the problem.

设$v$为查询$Q$核心中变量的数量。假定该核心存在宽度$k$的广义超树分解。根据文献[87]结论，必存在同宽度且至多含$v$个分解顶点的分解结构。因此，强制$k$-局部一致性的不动点必在最多$2 \cdot  v$轮半连接后终止。特别地，若$2 \cdot  \operatorname{vars}\left( Q\right)$轮后仍未达不动点，则可确定$Q$（及其核心）的广义超树宽度大于$k$。核心概念在此仍具关键作用，这使得该方法可能成为处理大型查询时的可行方案——对于这类查询，计算核心及广义超树分解（均为NP难问题）实际不可行。但该可处理性结果仅适用于问题的承诺版本。

A related characterization is also known for queries that are not Boolean. In this case, $k$ -local consistency is a sound and complete method to compute the answer of a query $Q$ over a set $W$ of output variables if,and only if,variables in $W$ are covered by some vertex of a width- $k$ generalized hypertree decomposition of some query ${Q}^{\prime }$ that is homomorphically equivalent to $Q\left\lbrack  {{82},{84}}\right\rbrack$ . In particular, for $k = 1$ this provides a precise characterization of the relationship between (1-)local consistency and global consistency that was missing in the classical results about acyclic queries: local consistency entails global consistency if, and only if, the variables occurring in each atom $p$ of $Q$ are covered by a join tree of some (acyclic) query homomorphically equivalent to $Q$ . Note that we do not require the existence of a join tree covering all atoms (this would mean that $Q$ is acyclic). Instead,we can use different equivalent queries (with their join trees/decompositions) for different atoms.

非布尔查询也存在相关特征描述。此时，当且仅当输出变量集$W$中的变量被某个与$Q\left\lbrack  {{82},{84}}\right\rbrack$同态等价的查询${Q}^{\prime }$的宽度$k$广义超树分解的顶点覆盖时，$k$-局部一致性才是计算查询$Q$答案的可靠完备方法。特别对$k = 1$而言，这精确刻画了经典环状查询理论中缺失的（1-）局部一致性与全局一致性关系：当且仅当$Q$的每个原子$p$所含变量被某个同态等价查询的连接树覆盖时，局部一致性蕴含全局一致性。注意我们并不要求存在覆盖所有原子的连接树（这意味着$Q$是环状的），而是允许对不同原子采用不同等价查询（及其连接树/分解结构）。

### 5.CAN WE GO BEYOND CONJUNCTIVE QUERIES?

### 5.能否超越合取查询？

Aggregation operators are very often at the basis of decision support systems examining large volumes of data, in order to obtain business intelligence. We briefly review some results based on GHDs for such queries.

聚合运算符通常是决策支持系统分析海量数据以获取商业智能的基础。我们简要回顾了基于广义超树分解(GHDs)处理此类查询的部分研究成果。

### 5.1 Counting Query Answers

### 5.1 计数查询应答

Let $Q$ be a conjunctive query and let DB be a database instance. So far,we have focused on the problem of computing the set ${Q}^{\mathrm{{DB}}}$ , but in many cases we might just be interested in computing the cardinality of this set. This counting problem is, indeed, a natural abstraction for SQL queries specifying "COUNT" aggregates (see, e.g, $\left\lbrack  {{26},{28}}\right\rbrack  )$ . The challenge in counting problems is to compute the right number in polynomial time without actually computing the (possibly exponentially-many) query answers. In particular it is crucial, both in theory and in practice, to deal with queries where output variables can be specified, so that we are only interested in counting the answers projected on them. Technically, such distinguished variables are free, while all the other variables are existentially quantified. As a matter of fact, in almost all practical applications, there are many of such "auxiliary" (existentially quantified) variables whose instantiations must not be counted.

设$Q$为合取查询，DB为数据库实例。此前我们主要关注计算集合${Q}^{\mathrm{{DB}}}$的问题，但实际应用中往往只需获取该集合的基数。这个计数问题本质上是SQL中"COUNT"聚合查询的自然抽象（参见$\left\lbrack  {{26},{28}}\right\rbrack  )$）。计数问题的核心挑战在于不实际计算（可能指数级数量的）查询结果，而是在多项式时间内获得正确数值。理论与实践中都需重点处理可指定输出变量的查询，即仅统计这些变量上的投影结果。技术层面，这类特殊变量是自由变量，其余则为存在量化变量。事实上，几乎所有实际应用都包含大量不应被计数的"辅助"（存在量化）变量实例。

Whenever all variables are free, having bounded generalized hy-pertree width is a sufficient condition for the tractability of the counting problem [121]. Moreover, on fixed-arity queries, this condition is also necessary (under widely believed assumptions in parameterized complexity) [40]. ${}^{3}$ However,in presence of projections, classical decomposition methods are not helpful. Indeed, even for acyclic queries [121], counting answers is $\# \mathrm{P}$ -hard in this case. An algorithm counting the answers of an acyclic query $Q$ in $O\left( {m \cdot  {r}^{2} \cdot  {4}^{r}}\right)$ ,with $r$ being the size of the largest database relation and $m$ the number of atoms,has been exhibited in [121]. Therefore, the evaluation is tractable over acyclic instances w.r.t. query complexity (where the database is fixed and not part of the input). The technique can be extended easily to queries having generalized hypertree width at most $k$ ,for some fixed number $k$ (cf. [86]). Thus, to get more powerful structural results, we should distinguish the hypergraph nodes associated with free and existentially quantified variables. A sufficient condition for tractability is the existence of a homomorphically equivalent subquery ${Q}^{\prime }$ of $Q$ that includes all free variables,and such that there is a width- $k$ generalized hypertree decomposition for ${Q}^{\prime }$ which covers all frontiers of the free variables with the existential variables (see [86] for more information). Interestingly, it turns out that for fixed-arity queries this structural condition precisely characterizes the queries where the counting problem is tractable [33].

当所有变量均为自由变量时，有界广义超树宽度是保证计数问题可高效处理的充分条件[121]。对于固定元数查询，该条件在参数化复杂度公认假设下也是必要条件[40]${}^{3}$。然而涉及投影时，传统分解方法将失效——即使对无环查询[121]，计数问题也变为$\# \mathrm{P}$困难。文献[121]提出了在$O\left( {m \cdot  {r}^{2} \cdot  {4}^{r}}\right)$时间内计算无环查询$Q$结果数的算法，其中$r$表示最大数据库关系规模，$m$为原子公式数量。因此就查询复杂度而言（固定数据库不视为输入），无环实例的求值是可高效处理的。该技术可推广至广义超树宽度不超过固定值$k$的查询（参见[86]）。为获得更强结构特征，需区分自由变量与存在量化变量对应的超图节点。一个充分条件是存在包含所有自由变量的同态等价子查询${Q}^{\prime }$，且该子查询具有宽度$k$的广义超树分解，能覆盖自由变量与存在量化变量的所有边界（详见[86]）。值得注意的是，对固定元数查询，该结构条件恰好刻画了计数问题可高效处理的查询类别[33]。

### 5.2 Further Aggregations

### 5.2 高级聚合运算

Answering ORDER BY queries is intimately related to the problem of computing the best solution according to the given ordering, which is incidentally another important aggregate (MAX) in SQL queries. This was first given in the context of ranking solutions to discrete optimization problems [110]. In particular, whenever the MAX problem of computing an optimal solution is feasible in polynomial time, then we can solve the problem of returning all the solutions in the ranked order with polynomial delay, as well as the more general problem of returning the best $K$ -ranked solutions over all solutions,i.e.,the top- $K$ query evaluation problem [94].

处理ORDER BY查询本质上与按给定排序计算最优解密切相关，后者恰是SQL查询中另一个重要聚合运算(MAX)。该问题最早出现在离散优化问题解的排序研究中[110]。特别地，当计算最优解的MAX问题可在多项式时间求解时，我们就能以多项式延迟返回所有排序解，以及更一般的返回所有解中前$K$个最优解（即top-$K$查询求值问题）[94]。

A number of structural tractability results for MAX (so, for top- $K$ and ORDER BY) queries are known in the literature (see,e.g., [64]). For monotone functions built on top of one binary aggregation operator (such as the standard+and $\times$ ),MAX is feasible in polynomial time over queries that have bounded treewidth [45], and over queries that have bounded generalized hypertree width [106, 60]. Structural tractability results for extensions to certain (possibly) non-monotone functions which manipulate "small" (in fact, polynomially-bounded) values, called smooth evaluation functions, have also been studied $\left\lbrack  {{83},{64}}\right\rbrack$ .

现有文献已报道多项关于MAX查询（即top-$K$和ORDER BY）的结构化可处理性结果（如[64]）。对于基于二元聚合运算符（如标准+和$\times$）构建的单调函数，在树宽度有界[45]或广义超树宽度有界[106,60]的查询上，MAX可在多项式时间求解。针对处理"小"值（即多项式有界值）的特定（可能）非单调函数（称为平滑求值函数）的扩展，其结构化可处理性结果也已被研究$\left\lbrack  {{83},{64}}\right\rbrack$。

An implementation of some aggregation operators based on hy-pertree decompositions is described in [56, 57]. It can be used with any system at a logical level. For the sake of efficiency, a semi-join operator that supports the execution of these operators over decompositions is implemented in the open-source DBMS Post-greSQL. Further operators are considered in [96] for the so-called AJAR queries, that is, queries with annotated relations over which (possibly multiple) aggregations can be used. Technically, aggregations are modeled by means of semiring quantifiers that "sum over" or "marginalize out" values. It is argued that such queries can be used to extend conjunctive queries with most SQL-like aggregation operators, as well as to capture data processing problems such as probabilistic inference via message passing on graphical models [101]. The problem with these queries is finding a variable ordering that allows us to manage the aggregations by using a suitable generalized hypertree decompositions ("compatible" with the ordering), together with standard join algorithms. The proposed algorithm can efficiently be implemented in the parallel framework, by using GYM [7] and the degree-based MapReduce algorithm in [97]. Answering AJAR queries is equivalent to answering Functional Aggregate Queries [105].

文献[56,57]描述了一种基于超树分解的聚合算子实现方案，该系统可在逻辑层面与任何系统兼容。为提高效率，开源数据库管理系统PostgreSQL中实现了支持这类算子执行的半连接算子。针对所谓AJAR查询（即可在带注解关系上使用多重聚合操作的查询），文献[96]探讨了更多算子技术细节。从技术角度看，聚合操作通过半环量词建模，这些量词可对数值进行"求和"或"边缘化"处理。研究表明，此类查询既能扩展带有大多数类SQL聚合算子的联合查询，也能通过图模型消息传递解决概率推理等数据处理问题[101]。这类查询的关键在于寻找变量排序方案，以便利用合适的广义超树分解（与排序"兼容"）结合标准连接算法来管理聚合操作。所提算法可借助GYM框架[7]和基于度数的MapReduce算法[97]在并行计算框架中高效实现。回答AJAR查询等价于回答函数式聚合查询[105]。

### 6.CAN WE COMBINE STRUCTURAL AND DATA PROPERTIES?

### 6.能否结合结构与数据特性？

The basic notion of hypertree decomposition ignores the quantitative aspects of data, such as attributes selectivity and degree, and cardinality of relations, as well as information on functional dependencies such as primary or external keys, and so on. Clearly enough, such knowledge, in the practice of query evaluation, may dramatically speed-up the evaluation time. In general there is an exponential number of hypertree decompositions of a given width, and every decomposition encodes a different way of aggregating groups of atoms and arranging them in a tree-like fashion. Now, as far as the theoretical tractability is concerned, we may be happy with any minimum-width decomposition, possibly measured according to the accurate bounds in Section 4. However, in practical real-world applications we have to exploit all information available about the database, and compute a decomposition that will eventually lead to the best possible evaluation performances. For instance, by using information on functional dependencies and their closure, it is possible to obtain a useful generalization of hypertree decompositions [5], while further information on the data have been used in the algorithms in $\left\lbrack  {{97},2}\right\rbrack$ .

超树分解的基本概念忽略了数据的量化特征，如属性选择性、关系基数和度数，以及主外键等函数依赖信息。显然，这些知识在实际查询评估中能显著提升执行效率。给定宽度的超树分解存在指数级数量可能，每种分解都对应着不同的原子组聚合方式及树形排列方案。虽然从理论可处理性角度，任何满足最小宽度的分解（参照第4节精确边界）都足以接受，但在实际应用中必须充分利用数据库信息来计算能获得最佳评估性能的分解。例如，利用函数依赖及其闭包信息可获得超树分解的有用推广[5]，而$\left\lbrack  {{97},2}\right\rbrack$中的算法则运用了更多数据特征信息。

In order to express preferences about hypertree decompositions of a given query, a notion of weighted hypertree decomposition has been proposed by [130]. In a nutshell, the notion is based on fixing a weighting function that equips each (generalized) hypertree decomposition ${HD} = \langle T,\chi ,\lambda \rangle$ of $\mathcal{H}$ with a rational number,and then on looking for a decomposition minimizing this value over all possible decompositions of some desired width.

为表达对给定查询超树分解的偏好，文献[130]提出了加权超树分解概念。简言之，该概念通过设定权重函数为$\mathcal{H}$的每个（广义）超树分解${HD} = \langle T,\chi ,\lambda \rangle$分配有理数值，然后在特定宽度范围内寻找使该值最小化的分解方案。

In particular, an interesting weighting function can be obtained by estimating the cost associated with the operations required to answer $Q$ according to the algorithm discussed in Section 4.1. Formally,if $p$ is a vertex of $T$ ,then we define ${v}^{ * }\left( p\right)$ as the cost of computing the join of all atoms associated with hyperedges in $\lambda \left( p\right)$ ,by eventually projecting the result over $\chi \left( p\right)$ . Similarly,if ${p}^{\prime }$ is a child of $p$ ,then we define ${e}^{ * }\left( {p,{p}^{\prime }}\right)$ as the cost of evaluating the semi-join between the reletion hereby computed for $p$ and ${p}^{\prime }$ . These costs can be estimated via standard techniques (see, e.g., [55]), possibly combined with recent proposals [35].

特别地，可通过估算4.1节算法求解$Q$所需操作的成本来构建有趣权重函数。形式上，若$T$的顶点$p$，则定义$\lambda \left( p\right)$中所有超边关联原子的连接计算成本为${v}^{ * }\left( p\right)$，最终将结果投影至$\chi \left( p\right)$。类似地，若$p$的子节点${p}^{\prime }$，则定义${e}^{ * }\left( {p,{p}^{\prime }}\right)$为$p$与${p}^{\prime }$之间半连接评估成本。这些成本可通过标准技术（如[55]）或结合最新方案[35]进行估算。

Based on the functions ${v}^{ * }$ and ${e}^{ * }$ ,every decomposition ${HD}$ can be then associated with the weight: ${\omega }^{ * }\left( {HD}\right)  = \mathop{\sum }\limits_{p}{v}^{ * }\left( p\right)  +$ $\mathop{\sum }\limits_{\left( p,{p}^{\prime }\right) }{e}^{ * }\left( {p,{p}^{\prime }}\right)$ . In [130],it has been observed that,for any fixed natural number $k > 0$ ,computing a normal form width- $k$ hyper-tree decomposition whose ${\omega }^{ * }$ -weight is the minimum possible is feasible in polynomial time. For arbitrary weighting functions, the problem has been shown to be intractable.

基于函数${v}^{ * }$和${e}^{ * }$，每个分解${HD}$可关联权重值：${\omega }^{ * }\left( {HD}\right)  = \mathop{\sum }\limits_{p}{v}^{ * }\left( p\right)  +$$\mathop{\sum }\limits_{\left( p,{p}^{\prime }\right) }{e}^{ * }\left( {p,{p}^{\prime }}\right)$。文献[130]指出，对于任意固定自然数$k > 0$，计算具有最小${\omega }^{ * }$-权重的规范形式宽度-$k$超树分解可在多项式时间内完成。对于任意加权函数，该问题已被证明是难解的。

Further hybrid approaches, specifically designed to deal with counting problems, are discussed in [86].

文献[86]还讨论了专门用于处理计数问题的混合方法。

### 7.ARE THERE APPLICATIONS OUTSIDE THE DATABASE AREA?

### 7.是否存在数据库领域外的应用？

While originally tailored for database applications, hypertree decompositions have emerged over the years as a powerful approach to identify islands of tractability in a number of different areas of research. A few applications are discussed below. Further applications include, e.g., matrix reordering [53] and circuit design [109].

虽然最初为数据库应用设计，但超树分解已逐渐发展成为识别多个研究领域中易处理问题孤岛的有效方法。下文将讨论部分应用案例，其他应用还包括矩阵重排序[53]和电路设计[109]等。

### 7.1 CSPs and Homomorphisms

### 7.1 约束满足问题与同态映射

An instance of a constraint satisfaction problem (CSP) (also constraint network) (e.g.,[44]) is a triple $I = \left( {\operatorname{Var},U,\mathcal{C}}\right)$ ,where Var is a finite set of variables, $U$ is a finite domain of values,and $\mathcal{C} = \left\{  {{C}_{1},{C}_{2},\ldots ,{C}_{q}}\right\}$ is a finite set of constraints. Each constraint ${C}_{i}$ is a pair $\left( {{S}_{i},{r}_{i}}\right)$ ,where ${S}_{i}$ is a list of variables of length ${m}_{i}$ called the constraint scope,and ${r}_{i}$ is an ${m}_{i}$ -ary relation over $U$ ,called the constraint relation. In fact,the tuples of ${r}_{i}$ indicate the allowed combinations of simultaneous values for the variables ${S}_{i}$ . A solution to a CSP instance is a substitution $\theta  :$ Var $\rightarrow  U$ , such that for each $1 \leq  i \leq  q,{S}_{i}\theta  \in  {r}_{i}$ . The problem of deciding whether a CSP instance has any solution is called constraint satisfiability. This problem is in general NP-complete.

约束满足问题(CSP)实例（亦称约束网络）(如[44])是一个三元组$I = \left( {\operatorname{Var},U,\mathcal{C}}\right)$，其中Var是有限变量集，$U$是有限值域，$\mathcal{C} = \left\{  {{C}_{1},{C}_{2},\ldots ,{C}_{q}}\right\}$是有限约束集。每个约束${C}_{i}$由二元组$\left( {{S}_{i},{r}_{i}}\right)$表示，其中${S}_{i}$是长度为${m}_{i}$的变量列表（称为约束作用域），${r}_{i}$是$U$上的${m}_{i}$元关系（称为约束关系）。实际上，${r}_{i}$的元组表示变量${S}_{i}$允许的取值组合。CSP实例的解是替换映射$\theta  :$Var$\rightarrow  U$，使得对每个$1 \leq  i \leq  q,{S}_{i}\theta  \in  {r}_{i}$成立。判定CSP实例是否存在解的问题称为约束可满足性问题，该问题通常具有NP完全性。

The structure of a CSP instance $I$ can be represented by its associated hypergraph $\mathcal{H}\left( I\right)  = \left( {V,H}\right)$ ,where $V =$ Var and $H =$ $\{ S \mid  \left( {S,r}\right)  \in  \mathcal{C}\}$ . Constraint satisfiability is feasible in polynomial time on classes of instances having bounded hypertree width [74]. The result is the natural consequence of the fact that constraint satisfiability is essentially the same problem of answering conjunctive queries, reformulated in a different context and with a different syntax (see, e.g., [10, 93] for a recent implementation in the CSP area). Indeed, as said in Section 1.7, the two settings (CSPs and conjunctive queries) can be abstractly viewed as special instances of the homomorphism problem, which takes as input two finite relational structures $\mathcal{A}$ and $\mathcal{B}$ ,and asks whether there is a homomorphism from $\mathcal{A}$ to $\mathcal{B}$ [108]. In the CSP setting, $\mathcal{A}$ models the variables and the scopes of the constraints,while $\mathcal{B}$ models the relations associated with constraints; in the database setting,instead, $\mathcal{A}$ models the conjunctive query and $\mathcal{B}$ models the database instance.

CSP实例$I$的结构可通过其关联超图$\mathcal{H}\left( I\right)  = \left( {V,H}\right)$表示，其中$V =$Var且$H =$$\{ S \mid  \left( {S,r}\right)  \in  \mathcal{C}\}$。在具有有界超树宽度的实例类上，约束可满足性可在多项式时间内求解[74]。该结果本质源于约束可满足性问题与合取查询应答问题的等价性，只是表述语境和语法不同（参见CSP领域最新实现[10,93]）。如第1.7节所述，CSP与合取查询可抽象视为同态问题的特例：给定两个有限关系结构$\mathcal{A}$和$\mathcal{B}$，判断是否存在从$\mathcal{A}$到$\mathcal{B}$的同态映射[108]。在CSP设定中，$\mathcal{A}$建模变量及约束作用域，$\mathcal{B}$建模约束关系；而在数据库设定中，$\mathcal{A}$对应合取查询，$\mathcal{B}$对应数据库实例。

Structural methods are used to support different techniques, too. For instance, hypertree decompositions are used for improving the performance of AND/OR search algorithms, by producing tighter bounds on the search space explored by these algorithms [120]. Some approaches also use structural methods to improve performances of algorithms based on enforcing high levels of consistencies localized to the decomposition clusters (see, e.g., [99]).

结构方法也被用于支持不同技术。例如，通过为AND/OR搜索算法探索的搜索空间生成更紧密的边界，超树分解被用于提升这些算法的性能[120]。某些方法还利用结构技术来改进基于在分解簇内实施高度一致性水平的算法性能（参见[99]）。

Note that the tractability results discussed in this paper refer to the so-called uniform CSP (homomorphism) problem, where both structures are part of the input, i.e., nothing is fixed. For completeness we recall that an interesting line of research in the CSP community looks at the so-called non-uniform problem,where $\mathcal{B}$ is a fixed structure (thus, any instance of such a problem just consists of some structure $\mathcal{A}$ ). In this case,the challenge is identifying any relational structure $\mathcal{B}$ such that all instances over this fixed structure is tractable,for any input structure $\mathcal{A}$ (see. e.g. [36]).

需注意的是，本文讨论的易处理性结果针对所谓统一CSP（同态）问题，其中两个结构均为输入部分（即无固定参数）。为完整起见，我们回顾CSP领域一个有趣的研究方向——考察所谓非均匀问题，其中$\mathcal{B}$是固定结构（因此此类问题的任何实例仅由某个结构$\mathcal{A}$构成）。此时的研究挑战在于识别任何关系结构$\mathcal{B}$，使得针对该固定结构的所有实例对于任意输入结构$\mathcal{A}$都具有易处理性（参见[36]）。

### 7.2 Strategic Games and Nash Equilibria

### 7.2 策略博弈与纳什均衡

The theory of strategic games has important applications in economics and decision making [117]. Nash equilibria are the most prominent solution concept therein, and problems related to their computation have attracted much research in computer science [42, 34]. In general, Nash equilibria admit strategies played according to probability distributions, but in many cases it is useful to focus on pure strategies, which have to be played deterministically [49].

策略博弈理论在经济学和决策制定领域具有重要应用[117]。纳什均衡是该理论中最突出的解概念，其相关计算问题已引发计算机科学界的广泛研究[42,34]。一般而言，纳什均衡允许按概率分布执行的混合策略，但在许多情况下，聚焦于必须确定性执行的纯策略更具实际意义[49]。

A strategic game [117] $\mathcal{G}$ is a tuple $\langle P,$ Neigh,Act $,U\rangle$ ,where $P$ is a non-empty set of distinct players, $\operatorname{Neigh} : P \rightarrow  {2}^{P}$ is a function such that for each $p \in  P,\operatorname{Neigh}\left( p\right)  \subseteq  P - \{ p\}$ contains all players of interest for $p,{Act} : P \rightarrow  A$ is a function returning for each player $p$ a set of possible actions $\operatorname{Act}\left( p\right)$ ,and $U$ associates a utility function ${u}_{p} : \operatorname{Act}\left( p\right) { \times  }_{j \in  \operatorname{Neigh}\left( p\right) }\operatorname{Act}\left( j\right)  \rightarrow  \Re$ to each player $p$ . For a player $p,{p}_{a}$ denotes her strategy to play the action $a \in  {Act}\left( p\right)$ . A global strategy $\mathbf{x}$ is a set containing a strategy for each player $p \in  P$ and,with a small abuse of notation, ${u}_{p}\left( \mathbf{x}\right)$ denotes the output of ${u}_{p}$ on the projection of $\mathbf{x}$ to the domain of ${u}_{p}$ ,i.e.,the output of the function ${u}_{p}$ applied to the actions played by $p$ and her neighbors according to the strategy $\mathbf{x}$ . Moreover,we denote by ${\mathbf{x}}_{-p}$ the set obtained by removing from $\mathbf{x}$ the strategy associated with player $p$ . Then,we say that a global strategy $\mathbf{x}$ is a pure Nash Equilibrium for $\mathcal{G}$ if,for every player $p \in  P$ ,there is no strategy ${p}_{a}$ such that ${u}_{p}\left( \mathbf{x}\right)  < {u}_{p}\left( {{\mathbf{x}}_{-p} \cup  \left\{  {p}_{a}\right\}  }\right)$ . A game $\mathcal{G}$ is naturally associated with the strategic dependency hypergraph $\mathcal{H}\left( \mathcal{G}\right)$ , whose vertices are the players $P$ and whose set of hyperedges is $\{ \{ p\}  \cup  \operatorname{Neigh}\left( p\right)  \mid  p \in  P\}$ . Deciding the existence of pure Nash equilibria (and compute one, if any) is NP-hard on arbitrary strategic games. However, the problem becomes tractable on classes of games whose associated have bounded hypertree width [63]. Tractability results also hold on such structurally-restricted games, for related solution concepts $\left\lbrack  {{102},{80}}\right\rbrack$ .

战略博弈[117]$\mathcal{G}$是一个元组$\langle P,$Neigh,Act$,U\rangle$，其中$P$是非空玩家集合，$\operatorname{Neigh} : P \rightarrow  {2}^{P}$为每个玩家$p \in  P,\operatorname{Neigh}\left( p\right)  \subseteq  P - \{ p\}$返回其关联玩家集合的函数，$p,{Act} : P \rightarrow  A$是为每个玩家$p$返回可能行动集合的函数，$U$则为每个玩家$p$关联效用函数${u}_{p} : \operatorname{Act}\left( p\right) { \times  }_{j \in  \operatorname{Neigh}\left( p\right) }\operatorname{Act}\left( j\right)  \rightarrow  \Re$。玩家$p,{p}_{a}$的策略表示其采取行动$a \in  {Act}\left( p\right)$的方案。全局策略$\mathbf{x}$是包含所有玩家策略的集合，在不严格表述时，${u}_{p}\left( \mathbf{x}\right)$表示${u}_{p}$在$\mathbf{x}$投影到${u}_{p}$定义域上的输出，即函数${u}_{p}$应用于玩家$p$及其邻居根据策略$\mathbf{x}$所采取行动的结果。此外，${\mathbf{x}}_{-p}$表示从$\mathbf{x}$中移除玩家$p$对应策略后的集合。当每个玩家$p \in  P$都不存在能使${u}_{p}\left( \mathbf{x}\right)  < {u}_{p}\left( {{\mathbf{x}}_{-p} \cup  \left\{  {p}_{a}\right\}  }\right)$成立的策略${p}_{a}$时，全局策略$\mathbf{x}$称为$\mathcal{G}$的纯纳什均衡。博弈$\mathcal{G}$自然关联着战略依赖超图$\mathcal{H}\left( \mathcal{G}\right)$，其顶点为玩家集合$P$，超边集为$\{ \{ p\}  \cup  \operatorname{Neigh}\left( p\right)  \mid  p \in  P\}$。判定纯纳什均衡存在性（及其计算）在任意战略博弈中属于NP难问题，但在关联超图具有有界超树宽[63]的博弈类中可高效求解。此类结构受限博弈对于相关解概念$\left\lbrack  {{102},{80}}\right\rbrack$同样具有可计算性。

Decomposition methods have also been used in the related setting of coalitional games (see, e.g., [79, 29]), where players are not selfish and the main goal is to compute worth distributions among the agents that can be perceived as fair and stable by all of them.

分解方法也应用于联盟博弈场景（参见[79,29]），其中玩家非自私主体，主要目标是计算被全体参与者认可为公平稳定的价值分配方案。

### 7.3 Combinatorial Auctions

### 7.3 组合拍卖

Combinatorial auctions are well-known mechanisms for resource and task allocation where bidders are allowed to simultaneously bid on combinations of items. Such mechanisms apply to those situations where the bidders' valuations of bundles of items are not equal to the sum of their valuations of individual items [39].

组合拍卖是资源与任务分配的经典机制，允许投标者对物品组合进行联合竞价。该机制适用于投标者对物品组合的估值不等于单个物品估值之和的情形[39]。

A combinatorial auction is a pair $\langle \mathcal{I},\mathcal{B}\rangle$ ,where $\mathcal{I} = \left\{  {{I}_{1},\ldots }\right.$ , $\left. {I}_{m}\right\}$ is the set of items the auctioneer has to sell,and $\mathcal{B} = \left\{  {{B}_{1},\ldots }\right.$ , $\left. {B}_{n}\right\}$ is the set of bids from the buyers interested in the items in $\mathcal{I}$ . Each bid ${B}_{i}$ has the form $\left\langle  {\text{item}\left( {B}_{i}\right) ,\operatorname{pay}\left( {B}_{i}\right) }\right\rangle$ ,where $\operatorname{pay}\left( {B}_{i}\right)$ is a rational number denoting the price a buyer offers for the items in item $\left( {B}_{i}\right)  \subseteq  \mathcal{I}$ . An outcome for $\langle \mathcal{I},\mathcal{B}\rangle$ is a subset $\mathbf{b}$ of $\mathcal{B}$ such that $\operatorname{item}\left( {B}_{i}\right)  \cap  \operatorname{item}\left( {B}_{j}\right)  = \varnothing$ ,for each pair ${B}_{i}$ and ${B}_{j}$ of bids in $\mathbf{b}$ with $i \neq  j$ . Bidder interaction in a combinatorial auction $\langle \mathcal{I},\mathcal{B}\rangle$ can be represented by the so-called dual hypergraph $\overline{\mathcal{H}}\left( {\langle \mathcal{I},\mathcal{B}\rangle }\right)$ ,whose nodes are the various bids in the auction and hyperedges represent items,that is,each item $\mathrm{I} \in  \mathcal{I}$ is associated with a hyperedge consisting of the set of bids that contain $I$ .

组合拍卖(combinatorial auction)是一个二元组$\langle \mathcal{I},\mathcal{B}\rangle$，其中$\mathcal{I} = \left\{  {{I}_{1},\ldots }\right.$表示拍卖方待售物品集合，$\left. {I}_{m}\right\}$表示买家对$\mathcal{I}$中物品的投标集合。每个投标${B}_{i}$采用$\left\langle  {\text{item}\left( {B}_{i}\right) ,\operatorname{pay}\left( {B}_{i}\right) }\right\rangle$形式，其中$\operatorname{pay}\left( {B}_{i}\right)$为有理数表示买家对物品$\left( {B}_{i}\right)  \subseteq  \mathcal{I}$的报价。$\langle \mathcal{I},\mathcal{B}\rangle$的拍卖结果是指$\mathcal{B}$的子集$\mathbf{b}$，需满足对于$\mathbf{b}$中任意两个投标${B}_{i}$与${B}_{j}$，当$i \neq  j$时成立。组合拍卖$\langle \mathcal{I},\mathcal{B}\rangle$的投标交互关系可通过对偶超图(dual hypergraph)$\overline{\mathcal{H}}\left( {\langle \mathcal{I},\mathcal{B}\rangle }\right)$表示：其节点对应各投标，超边对应物品——即每个物品$\mathrm{I} \in  \mathcal{I}$关联一个包含$I$的所有投标构成的超边。

For example, the hypergraph in Figure 6, on the left, encodes an auction over items $\left\{  {{\mathrm{I}}_{1},\ldots ,{\mathrm{I}}_{5}}\right\}$ and where bids are on the following bundles of items: ${h}_{1} : \left\{  {\mathrm{I}}_{1}\right\}  ,{h}_{2} : \left\{  {{\mathrm{I}}_{1},{\mathrm{I}}_{2},{\mathrm{I}}_{3}}\right\}  ,{h}_{3} : \left\{  {{\mathrm{I}}_{1},{\mathrm{I}}_{2},{\mathrm{I}}_{5}}\right\}$ , ${h}_{4} : \left\{  {{\mathrm{I}}_{3},{\mathrm{I}}_{4}}\right\}$ ,and ${h}_{5} : \left\{  {{\mathrm{I}}_{3},{\mathrm{I}}_{4},{\mathrm{I}}_{5}}\right\}$ . Note that this hypergraph is not acyclic and its hypertree width 2 , as it is witnessed by the decomposition reported in Figure 6.

例如图6左侧的超图编码了物品$\left\{  {{\mathrm{I}}_{1},\ldots ,{\mathrm{I}}_{5}}\right\}$的拍卖，投标针对以下物品组合：${h}_{1} : \left\{  {\mathrm{I}}_{1}\right\}  ,{h}_{2} : \left\{  {{\mathrm{I}}_{1},{\mathrm{I}}_{2},{\mathrm{I}}_{3}}\right\}  ,{h}_{3} : \left\{  {{\mathrm{I}}_{1},{\mathrm{I}}_{2},{\mathrm{I}}_{5}}\right\}$、${h}_{4} : \left\{  {{\mathrm{I}}_{3},{\mathrm{I}}_{4}}\right\}$和${h}_{5} : \left\{  {{\mathrm{I}}_{3},{\mathrm{I}}_{4},{\mathrm{I}}_{5}}\right\}$。注意该超图是非无环的，其超树宽度为2，图6所示的分解结构可证明此性质。

A crucial problem for combinatorial auctions is the winner determination problem of determining the outcome ${\mathbf{b}}^{ * }$ that maximizes the sum of the accepted bid prices (i.e., $\mathop{\sum }\limits_{{{B}_{i} \in  {\mathbf{b}}^{ * }}}\operatorname{pay}\left( {B}_{i}\right)$ ) over all possible outcomes. The problem is in general NP-hard [125]. However, it is tractable on auctions with bounded hypertree-width dual hypergraphs [60] (see also [51]).

组合拍卖的核心问题是胜者确定问题(winner determination problem)，即在所有可能结果中找出使中标价格总和$\mathop{\sum }\limits_{{{B}_{i} \in  {\mathbf{b}}^{ * }}}\operatorname{pay}\left( {B}_{i}\right)$最大化的${\mathbf{b}}^{ * }$。该问题通常属于NP难问题[125]，但对于对偶超图具有有界超树宽度的拍卖实例[60]（另见[51]）存在多项式时间解法。

### 8.CAN WE GO BEYOND HYPERTREES?

### 8. 我们能超越超树结构吗？

Consider a generalized hypertree decomposition ${HD} = \langle T,\chi ,\lambda \rangle$ . The cyclicity measure used in standard generalized hypertree decompositions is based on the cardinality of the set $\lambda \left( p\right)$ in charge of covering $\chi \left( p\right)$ ,for each vertex $p$ of the decomposition tree. It has been observed that a more general notion can be obtained by allowing the use of more general functions ${f}_{HD}\left( \cdot \right)$ ,to measure the weight ${f}_{HD}\left( p\right)$ of such a vertex,and hence to define the width of a decomposition. This is formalized in [4], where possibly infinite hypergraphs are considered, too.

考虑一个广义超树分解${HD} = \langle T,\chi ,\lambda \rangle$。标准广义超树分解中使用的环性度量基于集合$\lambda \left( p\right)$的基数，该集合负责覆盖分解树每个顶点$p$的$\chi \left( p\right)$。研究发现，通过允许使用更一般的函数${f}_{HD}\left( \cdot \right)$来衡量该顶点的权重${f}_{HD}\left( p\right)$，从而定义分解宽度，可以获得更广义的概念。文献[4]对此进行了形式化描述，其中还考虑了可能无限的超图。

In Section 1.8 a number of restrictions of GHDs, such as the greedy hypertree decompositions [88] and the subset-based decompositions [76], have been mentioned. The notion of width in such methods was however still based on the cardinality of the $\lambda$ label-ings. We recall some further decompositions based on more general width functions.

第1.8节提到了GHDs（广义超树分解）的若干限制，如贪婪超树分解[88]和基于子集的分解[76]。然而这些方法中的宽度概念仍基于$\lambda$标记的基数。我们将回顾基于更广义宽度函数的其他分解方法。

### 8.1 Fractional HDs

### 8.1 分数超树分解

A fractional hypertree decomposition [90] of a hypergraph $\mathcal{H}$ is a pair ${FHD} = \langle {HD},\gamma \rangle$ ,where ${HD} = \langle T,\chi ,\lambda \rangle$ is a generalized hypertree decomposition of $\mathcal{H}$ ,and $\gamma$ is a mapping associating each vertex $p$ of $T$ with a function ${\gamma }_{p} : \lambda \left( p\right)  \mapsto  \mathbb{R}$ mapping hy-peredges to non-negative real numbers. For each vertex $p$ in $T,{\gamma }_{p}$ encodes a fractional cover of the nodes in $\chi \left( p\right)$ : for each $v \in  \chi \left( p\right)$ , $\mathop{\sum }\limits_{{h \in  \lambda \left( p\right) ,v \in  h}}{\gamma }_{p}\left( h\right)  \geq  1$ . Define $\rho \left( p\right)  = \mathop{\sum }\limits_{{h \in  \lambda \left( p\right) }}{\gamma }_{p}\left( h\right)$ . The width of ${FHD}$ is the maximum of $\rho \left( p\right)$ over all vertices $p$ in $T$ . The fractional hypertree width of $\mathcal{H}$ ,denoted by ${fhw}\left( \mathcal{H}\right)$ ,is the minimum width over all its fractional hypertree decompositions. ${}^{4}$

超图$\mathcal{H}$的分数超树分解[90]是一个二元组${FHD} = \langle {HD},\gamma \rangle$，其中${HD} = \langle T,\chi ,\lambda \rangle$是$\mathcal{H}$的广义超树分解，$\gamma$是将分解树$T$的每个顶点$p$映射到超边的非负实数函数${\gamma }_{p} : \lambda \left( p\right)  \mapsto  \mathbb{R}$的映射。对于$T,{\gamma }_{p}$中的每个顶点$p$，$\chi \left( p\right)$中的节点都对应一个分数覆盖：对于每个$v \in  \chi \left( p\right)$，$\mathop{\sum }\limits_{{h \in  \lambda \left( p\right) ,v \in  h}}{\gamma }_{p}\left( h\right)  \geq  1$。定义$\rho \left( p\right)  = \mathop{\sum }\limits_{{h \in  \lambda \left( p\right) }}{\gamma }_{p}\left( h\right)$。${FHD}$的宽度是$T$中所有顶点$p$对应的$\rho \left( p\right)$的最大值。超图$\mathcal{H}$的分数超树宽度（记作${fhw}\left( \mathcal{H}\right)$）是其所有分数超树分解中的最小宽度。${}^{4}$

Queries whose ${fhw}$ is bounded by some constant $k$ can be answered in polynomial time by applying the transformation of the given query $Q$ to an acyclic query,based on the generalized hy-pertree decomposition ${HD}$ at hand (see Section 4.1). Indeed,the maximum number of answers of the subquery ${Q}_{p}$ associated with each vertex $p$ is at most ${\left| {r}_{p}\right| }^{\rho \left( p\right) }$ ,where ${r}_{p}$ is the largest database relation associated with the hyperedges in $\lambda \left( p\right) \left\lbrack  {{90},{14}}\right\rbrack$ . Generalized hypertree width is obtained if in the definition of fractional hypertree decomposition we restrict the codomain of each ${\gamma }_{p}$ to be integral. It is thus not surprising that there are hypergraphs where the fractional hypertree width is smaller than the (generalized) hy-pertree width-see Figure 2.

当${fhw}$受某个常数$k$约束时，通过基于现有广义超树分解${HD}$将给定查询$Q$转换为无环查询（参见第4.1节），可以在多项式时间内解答该查询。实际上，与每个顶点$p$关联的子查询${Q}_{p}$的最大答案数不超过${\left| {r}_{p}\right| }^{\rho \left( p\right) }$，其中${r}_{p}$是与$\lambda \left( p\right) \left\lbrack  {{90},{14}}\right\rbrack$中超边关联的最大数据库关系。若在分数超树分解定义中限制每个${\gamma }_{p}$的值域为整数，则得到广义超树宽度。因此，存在分数超树宽度小于（广义）超树宽度的超图并不令人意外——见图2。

EXAMPLE 8.1 ([90]). For any value of $n \geq  1$ ,consider the hypergraph ${\mathcal{H}}_{n}$ built as follows: ${\mathcal{H}}_{n}$ has a node ${v}_{S}$ ,for each sub-seteq $S \subseteq  \{ 1,\ldots ,{2n}\}$ ; furthermore,for every $i \in  \{ 1,\ldots ,{2n}\}$ , ${\mathcal{H}}_{n}$ has a hyperedge ${h}_{i} = \left\{  {{v}_{S} \mid  i \in  S}\right\}$ . It can be checked that ${fhw}\left( {\mathcal{H}}_{n}\right)  = 2$ . This is witnessed by the fractional decomposition ${FHD} = \langle T,\chi ,\gamma \rangle$ consisting of one vertex $p$ only and such that ${\gamma }_{p}\left( {h}_{i}\right)  = 1/n$ ,for each hyperedge ${h}_{i} \in  \operatorname{edges}\left( {\mathcal{H}}_{n}\right)$ . On the other hand,the generalized hypertree width of ${\mathcal{H}}_{n}$ is $n$ .

例8.1（[90]）。对于任意$n \geq  1$值，考虑按如下方式构建的超图${\mathcal{H}}_{n}$：${\mathcal{H}}_{n}$为每个子集eq$S \subseteq  \{ 1,\ldots ,{2n}\}$包含节点${v}_{S}$；此外，对于每个$i \in  \{ 1,\ldots ,{2n}\}$，${\mathcal{H}}_{n}$都含有一条超边${h}_{i} = \left\{  {{v}_{S} \mid  i \in  S}\right\}$。可以验证${fhw}\left( {\mathcal{H}}_{n}\right)  = 2$。这由分数分解${FHD} = \langle T,\chi ,\gamma \rangle$所证实，该分解仅包含单一顶点$p$，且对每条超边${h}_{i} \in  \operatorname{edges}\left( {\mathcal{H}}_{n}\right)$满足${\gamma }_{p}\left( {h}_{i}\right)  = 1/n$。另一方面，${\mathcal{H}}_{n}$的广义超树宽度为$n$。

The complexity of checking whether a hypergraph has fractional hypertree width at most $w$ ,for some fixed constant $w \geq  0$ ,is an open problem. However, there is a polynomial-time algorithm for deciding whether the fractional hypertree width is $f\left( w\right)$ for a function $f$ in $O\left( {w}^{3}\right)$ [113].

判定超图分数超树宽度是否不超过某固定常数$w \geq  0$的$w$，其计算复杂度仍属开放问题。但对于函数$f$在$O\left( {w}^{3}\right)$中的情形，存在多项式时间算法可判定分数超树宽度是否为$f\left( w\right)$[113]。

### 8.2 Tree Projections

### 8.2 树投影

All the known purely-structural decomposition methods, where decompositions are only based on the (hyper)graph structure of the given query, are in fact specializations of the general and abstract framework of tree projections [126]. In this framework, a query $Q$ is given together with a set $\mathcal{V}$ of atoms,called views,which are defined over the variables in $Q$ . The question is whether (parts of) the views can be arranged as to form a tree projection (playing the role of a decomposition tree), i.e., a novel acyclic query that still "covers" $Q$ . By representing $Q$ and $\mathcal{V}$ via the hypergraphs ${\mathcal{H}}_{Q}$ and ${\mathcal{H}}_{\mathcal{V}}$ ,where hyperedges one-to-one correspond with query atoms and views, respectively, the tree projection problem reveals its graph-theoretic nature. For two hypergraphs ${\mathcal{H}}_{1}$ and ${\mathcal{H}}_{2}$ ,let ${\mathcal{H}}_{1} \leq  {\mathcal{H}}_{2}$ denote that each hyperedge of ${\mathcal{H}}_{1}$ is contained in some hyperedge of ${\mathcal{H}}_{2}$ . Then,a tree projection of ${\mathcal{H}}_{Q}$ w.r.t. ${\mathcal{H}}_{\mathcal{V}}$ is any acyclic hypergraph ${\mathcal{H}}_{a}$ such that ${\mathcal{H}}_{Q} \leq  {\mathcal{H}}_{a} \leq  {\mathcal{H}}_{\mathcal{V}}$ .

所有已知的纯结构分解方法（其分解仅基于给定查询的（超）图结构）实质上都是树投影[126]这一抽象通用框架的特例。该框架中，查询$Q$与一组称为视图的原子$\mathcal{V}$共同给出，这些视图定义在$Q$的变量上。核心问题是视图（部分）能否被组织成树投影（承担分解树角色），即形成仍能"覆盖"$Q$的新型无环查询。通过用超图${\mathcal{H}}_{Q}$和${\mathcal{H}}_{\mathcal{V}}$分别表示$Q$与$\mathcal{V}$（其中超边与查询原子及视图一一对应），树投影问题揭示了其图论本质。对于两个超图${\mathcal{H}}_{1}$和${\mathcal{H}}_{2}$，记${\mathcal{H}}_{1} \leq  {\mathcal{H}}_{2}$表示${\mathcal{H}}_{1}$的每条超边都包含于${\mathcal{H}}_{2}$的某条超边中。则${\mathcal{H}}_{Q}$关于${\mathcal{H}}_{\mathcal{V}}$的树投影是任何满足${\mathcal{H}}_{Q} \leq  {\mathcal{H}}_{a} \leq  {\mathcal{H}}_{\mathcal{V}}$的无环超图${\mathcal{H}}_{a}$。

The existence of a tree projection is often a key to establish tractability results for decision problems [126] and for enumeration ones [85]. Moreover, it guarantees that interesting consistency properties [82] and game-theoretic characterizations [87] hold. Indeed, according to this unifying view [62], differences among the various (purely) structural decomposition methods just come in the way the resource hypergraph ${\mathcal{H}}_{2}$ is defined. In particular,for a fixed natural number $k$ ,the treewidth method is obtained by considering as available hyperedges in the resource hypergraph all combinations of $k$ nodes of ${\mathcal{H}}_{1}$ ; while the generalized hypertree-width method is obtained by considering,as resource hypergraph ${\mathcal{H}}_{2}$ ,the hypergraph ${\mathcal{H}}_{1}^{k}$ such that each of its hyperedge is the union of $k$ hyperedges of ${\mathcal{H}}_{1}$ . However,note that the notion of tree projection is more general then both treewidth and hypertree width, because the hyperedges of the "resource" hypergraph ${\mathcal{H}}_{2}$ may model arbitrary subproblems of the given instance whose solutions are easy to compute, or already available from previous computations (for instance, materialized views while answering database queries).

树状投影的存在往往是确立决策问题[126]和枚举问题[85]可处理性结果的关键。此外，它保证了有趣的相容性特性[82]和博弈论特征[87]得以成立。事实上，根据这一统合观点[62]，各种（纯粹）结构分解方法之间的差异仅体现在资源超图${\mathcal{H}}_{2}$的定义方式上。具体而言，对于固定自然数$k$，树宽方法是通过将${\mathcal{H}}_{1}$的所有$k$节点组合视为资源超图中的可用超边而获得；而广义超树宽方法则是通过将资源超图${\mathcal{H}}_{2}$视为超图${\mathcal{H}}_{1}^{k}$（其每条超边都是${\mathcal{H}}_{1}$的$k$条超边的并集）来获得。但需注意，树状投影概念比树宽和超树宽更广义，因为"资源"超图${\mathcal{H}}_{2}$的超边可以建模给定实例中解易于计算或已通过先前计算获得的任意子问题（例如数据库查询应答时的物化视图）。

### 8.3 Submodular Width

### 8.3 次模宽度

While the frontier of polynomial-time tractability for conjunctive queries is still unknown, some important advances have been made with regard to a weaker notion of tractability based on parameterized complexity. Let $p - \mathrm{{CQ}}$ be the problem of answering a Boolean conjunctive query $Q$ ,parameterized by the hypergraph ${\mathcal{H}}_{Q}$ . Given a set $\mathbf{H}$ of hypergraphs,let ${CQ}\left( \mathbf{H}\right)$ denote the set of all Boolean conjunctive queries, whose associated hypergraphs belong to $\mathbf{H}$ . It has been shown that,for each recursively enumerable class of hypergraphs $\mathbf{H}$ ,the problem $p$ -CQ over the class of queries ${CQ}\left( \mathbf{H}\right)$ is fixed-parameter tractable if,and only if, $\mathbf{H}$ has bounded submodular width (unless the Exponential Time Hypothesis [95] fails) [115]. Consider such a class $\mathbf{H}$ and assume that the submodular width of all hypergraphs in the class is at most $w$ . Then, the result guarantees that there are two computable functions ${f}_{1}$ and ${f}_{2}$ such that each query $Q$ in ${CQ}\left( \mathbf{H}\right)$ can be answered over a database DB in time $O\left( {{f}_{1}\left( {\mathcal{H}}_{Q}\right)  \cdot  {\left| \mathrm{{DB}}\right| }^{{f}_{2}\left( w\right) }}\right)$ . In the algorithm described in [115], ${f}_{1}$ has a term of the form ${2}^{{2}^{O\left( \left| V\right| \right) }}$ ,where $V$ is the set of nodes in ${\mathcal{H}}_{Q}$ . For the submodular width,the decompositions used to answer the query depend not only on the query hypergraph, but on the actual database DB, too. It follows that, unlike for all methods based on generalized hypertree decompositions (and tree projections), we cannot amortize the time spent in computing a good query plan beforehand through the time saved later, when $Q$ is executed multiple times. Rather,at each query execution,we incur the same overhead exponential in the size of ${\mathcal{H}}_{Q}$ .

尽管合取查询在多项式时间可解性领域的前沿仍属未知，但基于参数化复杂度的弱可解性概念已取得重要进展。设$p - \mathrm{{CQ}}$为回答布尔合取查询$Q$的问题，其参数化依据超图${\mathcal{H}}_{Q}$。给定超图集合$\mathbf{H}$，令${CQ}\left( \mathbf{H}\right)$表示所有关联超图属于$\mathbf{H}$的布尔合取查询集合。研究表明：对于每个递归可枚举的超图类$\mathbf{H}$，当且仅当$\mathbf{H}$具有有界次模宽度时（除非指数时间假说[95]不成立），查询类${CQ}\left( \mathbf{H}\right)$上的$p$-CQ问题属于固定参数可解[115]。考虑此类$\mathbf{H}$并假设其超图的次模宽度最大为$w$，该结果保证存在两个可计算函数${f}_{1}$和${f}_{2}$，使得对数据库DB执行${CQ}\left( \mathbf{H}\right)$中每个查询$Q$的时间复杂度为$O\left( {{f}_{1}\left( {\mathcal{H}}_{Q}\right)  \cdot  {\left| \mathrm{{DB}}\right| }^{{f}_{2}\left( w\right) }}\right)$。在[115]描述的算法中，${f}_{1}$包含形如${2}^{{2}^{O\left( \left| V\right| \right) }}$的项，其中$V$是${\mathcal{H}}_{Q}$的节点集。对于次模宽度，用于回答查询的分解不仅取决于查询超图，还依赖于实际数据库DB。这意味着与基于广义超树分解（及树投影）的所有方法不同，我们无法通过后续多次执行$Q$时节省的时间来分摊预先计算优质查询计划的成本。相反，每次查询执行时都会产生与${\mathcal{H}}_{Q}$规模成指数关系的固定开销。

Submodular width is more general than the fractional (and hence the generalized) hypertree width. Indeed, it has been shown that there are classes of hypergraphs having bounded submodular width, but unbounded fractional hypertree width. This follows from the results on the adaptive width in [114], and from its equivalence with the submodular width [115].

次模宽度比分数（进而广义）超树宽度更具普适性。事实上已证实，存在具有有界次模宽度但无界分数超树宽度的超图类。这源于[114]关于自适应宽度的研究成果及其与次模宽度的等价性证明[115]。

## 9. WHAT DO EXPERIMENTS SHOW?

## 9. 实验数据揭示了什么？

Experimental evidence of the benefits gained from structural decomposition methods in query optimization (and CSP solving) has been provided in the literature by a number of different authors and in different application domains.

结构分解方法在查询优化（及CSP求解）中的优势已获多位学者在不同应用领域的实验验证。

As already mentioned, the EmptyHeaded relational engine uses generalized hypertree decompositions in its query planner [1]. The system, supporting a rich datalog-like query language, has been tested on popular graphs datasets (Google+, Higgs, LiveJournal, Orkuts, Patent, Twitter). It emerged that graph engines supporting the same kind of high-level query language are outperformed by EmptyHeaded, which is even an order of magnitude faster than many low-level graph engines on such queries. The system has been also tested in the context of RDF processing [2], by comparing its performances with those of state-of-the-art specialized RDF engines. Experiments have been performed on the LUBM benchmark [91]. The results show that EmptyHeaded outperforms all other engines on many cyclic queries, while remaining competitive with the specialized RDF engines on the others.

如前所述，EmptyHeaded关系引擎在其查询规划器中使用广义超树分解[1]。该系统支持类datalog高级查询语言，已在主流图数据集（Google+、Higgs、LiveJournal、Orkuts、Patent、Twitter）完成测试。结果表明，支持同类高级查询语言的图计算引擎性能均逊于EmptyHeaded，其速度甚至比许多底层图引擎快一个数量级。该系统还在RDF处理场景[2]中与尖端专用RDF引擎进行性能对比测试，实验基于LUBM基准[91]。数据显示EmptyHeaded在多数环形查询中表现最优，在其他查询场景仍与专用RDF引擎保持竞争力。

In [98], similar techniques based on structural decompositions (but using a different width function) have been used to guide a flexible caching of intermediate results in the context of computing multiway joins. Experimental validation has been conducted on the SNAP collection (https://snap.stanford.edu/data) showing benefits over both earlier ad-hoc algorithms and standard DBMSs.

文献[98]采用基于结构分解的类似技术（但使用不同宽度函数）指导多路连接计算中的中间结果灵活缓存。通过在SNAP数据集(https://snap.stanford.edu/data)上的实验验证，该方法相较早期专用算法和标准DBMS均展现出优势。

In [56, 57], a query optimizer using hypertree decompositions and taking into account the cost model discussed in Section 6 has been implemented. The optimizer can be put on top of any existing database management system supporting JDBC technology, by transparently replacing its standard optimization module. Moreover, to exploit the potential of HDs in a proper way, a special semijoin operator supporting some aggregation operators has been implemented within the PostgreSQL DBMS. The resulting prototype has been compared with standard PostgreSQL and with a well-known commercial DBMS on the TPC-H (www.tpc.org/tpch) benchmark, consisting of queries designed for simulating classical tasks in decision support systems. The results demonstrate a significant gain obtained by using query plans based on hypertree decompositions on queries involving more than two query atoms.

文献[56,57]实现了一种采用超树分解技术并整合第6节所述成本模型的查询优化器。该优化器可通过透明替换标准优化模块，部署于任何支持JDBC技术的现有数据库管理系统之上。此外，为充分发挥超树分解潜力，PostgreSQL数据库管理系统内特别实现了支持聚合操作的半连接算子。在TPC-H基准测试(www.tpc.org/tpch)中，该原型系统与标准PostgreSQL及知名商业数据库管理系统进行了对比测试，这些查询专为模拟决策支持系统中的经典任务设计。实验结果表明，对于涉及两个以上查询原子的复杂查询，基于超树分解的查询方案能带来显著性能提升。

In [10], a CSP solving technique based on generalized hypertree decompositions and using compressed representations for the relations has been proposed, and its scalability has been assessed over well-known CPS benchmarks (Large bdd, VarDimacs, Modified Renault, Pret, Dubois). Another implementation focusing on large (CSP) instances is described in [112] that, in particular, focused on the so-called Modified Renault benchmark, ${}^{5}$ which comes from a real application concerning the configuration of a car (the Renault Megane) [9, 12]. The considered instances consist of about 150 atoms/constraints and 110 variables, with database instances where attributes have degree at most 42 , and the largest constraint relation contains 48721 tuples. The generalized hypertree width is 3 for most instances (with a maximum of 4). The total number of solutions is about $2 \cdot  {10}^{12}$ ,however this information is not very meaningful, because of the many auxiliary variables occurring in the problem. Rather, by using the algorithms based on generalized hypertree decompositions, it is possible to compute the solutions of these instances (or just their number) over the actual variables of interest. None of the other available engines that we know, either in the database or in the CSP community, were able to compute such a result for those large instances. For more information, we refer to the Hypertree Decomposition Web-page [128].

文献[10]提出了一种基于广义超树分解并采用关系压缩表示的CSP求解技术，其可扩展性已在主流CPS基准测试(Large bdd、VarDimacs、Modified Renault、Pret、Dubois)中得到验证。文献[112]则描述了针对大规模CSP实例的另一实现方案，重点研究了源自汽车配置实际应用(雷诺梅甘娜车型)[9,12]的Modified Renault基准测试${}^{5}$。这些实例包含约150个原子/约束和110个变量，数据库实例中属性最大度数为42，最大约束关系含48721个元组。多数实例的广义超树宽度为3(最大为4)。虽然总解数量约$2 \cdot  {10}^{12}$，但由于存在大量辅助变量，该数值实际意义有限。通过广义超树分解算法，可针对目标变量计算解集或其数量——这是当前数据库和CSP领域其他已知引擎均无法为如此大规模实例实现的功能。更多信息请参阅超树分解专题网页[128]。

## 10. CONCLUSION & FUTURE RESEARCH

## 十、结论与未来研究方向

The aim of decomposition methods is to extend the nice computational properties of acyclic queries to larger classes of queries. Hypertree decompositions serve this aim very well. They fulfill three important criteria postulated for decompositions: (1) Generalization of Acyclicity, (2) Tractable Recognizability, and (3) Tractable Query-Answering. There has been a large body of research on HDs since their introduction in 1999. However, there are still many interesting questions that deserve further research, some of purely theoretical nature, some of more practical relevance.

分解方法的根本目标是将无环查询的良好计算特性拓展至更广泛的查询类别。超树分解在这方面表现卓越，满足分解方法三大核心准则：(1)无环性泛化；(2)可识别性；(3)高效查询应答。自199年提出以来，相关研究已取得丰硕成果，但仍存在诸多兼具理论价值与实践意义的问题值得深入探索。

We conclude this paper by listing those research issues which we deem most important.

本文最后列出我们认为最具价值的研究方向：

- Are there substantially different decomposition methods generalizing hypertree decompositions, which still fulfill criteria 1-3?

- 是否存在满足准则1-3且本质上不同于超树分解的分解方法？

- Are there more efficient exact algorithms for computing HDs? The best known algorithm for checking for hypertree width $k$ runs in time exponential in ${2k}$ . Given that the problem is fixed-parameter intractable in parameter $k$ ,we most likely cannot get rid of the constant $k$ in the exponent,but is it maybe possible to get rid of the factor 2 in front of $k$ ?

- 能否开发更高效的超树宽度精确计算算法？当前最优算法在$k$宽度检测时具有${2k}$的指数时间复杂度。鉴于该问题对参数$k$具有固定参数难解性，虽无法消除指数项的$k$常数，但能否去除$k$前的系数2？

- Further research on heuristic methods for computing HDs of "reasonably" low width would be beneficial, especially in the context of constraint satisfaction.

- 针对约束满足问题，开发能计算"合理"低宽度超树分解的启发式算法将大有裨益。

- In order to suitably integrate the HD method into query optimizers of existing and future DBMSs, research is needed on how this method can be effectively combined with the standard methods of logical and physical query optimization. Such combined methods could, for example, use weighted hypertree decompositions [130], see Section 6.

- 为将超树分解方法有效整合至现有及未来数据库管理系统的查询优化器，需研究其与逻辑/物理查询优化标准方法的协同机制。例如可采用加权超树分解[130](参见第6节)等混合方法。

- It has been shown [89] (under a standard complexity assumption) that Boolean queries in a recursively enumerable class $\mathbf{Q}$ can be answered in polynomial time if, and only if, the cores of the queries in $\mathbf{Q}$ have bounded treewidth (or bounded hyper-tree width, as boundedness for tw and hw coincides in case of bounded arity). Is there a similar characterization for tractability for the case of unbounded arities (see also Section 8.3)? A related open question is to chart the tractability frontier for arbitrary queries, i.e., not necessarily Boolean [27, 85, 131, 15].

- 研究[89]表明(基于标准复杂性假设)：当且仅当递归可枚举类$\mathbf{Q}$中布尔查询的核心具有有界树宽(或在有界元数情况下等价的有界超树宽度)时，该类查询可在多项式时间内求解。对于无界元数情况是否存在类似的可处理性表征(参见8.3节)？另一相关开放性问题是如何界定任意查询(不限于布尔查询)[27,85,131,15]的可处理性边界。

- Find new applications that profit from the technique of hypertree decompositions. As an example, it would be interesting to see if hypertree decompositions could be used profitably for speeding up Datalog engines (see $\left\lbrack  {{78},{134}}\right\rbrack$ ),and,more specifically, widely used Datalog-based answer set programming (ASP) systems such as e.g. DLV [111]. In such systems, Datalog rules bodies essentially consist of conjunctive queries.

- 寻找能够受益于超树分解技术的新应用领域。例如，探究超树分解是否可用于加速Datalog引擎（参见$\left\lbrack  {{78},{134}}\right\rbrack$），特别是广泛使用的基于Datalog的答案集编程（ASP）系统（如DLV[111]）将极具价值。此类系统中，Datalog规则体本质上由合取查询构成。
