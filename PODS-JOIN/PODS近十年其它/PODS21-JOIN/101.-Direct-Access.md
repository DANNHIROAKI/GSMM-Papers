## Abstract

## 摘要

We study the question of when we can provide logarithmic-time direct access to the $k$ -th answer to a Conjunctive Query (CQ) with a specified ordering over the answers, following a preprocessing step that constructs a data structure in time quasilinear in the size of the database. Specifically, we embark on the challenge of identifying the tractable answer orderings that allow for ranked direct access with such complexity guarantees.

我们研究在预处理阶段构建与数据库大小拟线性时间相关的数据结构后，如何实现对连接查询(CQ)结果按指定排序提供对数时间直接访问第$k$个答案的问题。具体而言，我们致力于识别那些允许在此复杂度保证下实现排序直接访问的可处理答案排序方案。

We begin with lexicographic orderings and give a decidable characterization (under conventional complexity assumptions) of the class of tractable lexicographic orderings for every CQ without self-joins. We then continue to the more general orderings by the sum of attribute weights and show for it that ranked direct access is tractable only in trivial cases. Hence, to better understand the computational challenge at hand, we consider the more modest task of providing access to only a single answer (i.e., finding the answer at a given position) - a task that we refer to as the selection problem. We indeed achieve a quasilinear-time algorithm for a subset of the class of full CQs without self-joins, by adopting a solution of Frederickson and Johnson to the classic problem of selection over sorted matrices. We further prove that none of the other queries in this class admit such an algorithm.

首先研究字典序，针对无自连接的每个CQ，给出可处理字典序类别的可判定特征（基于常规复杂性假设）。接着研究更一般的属性权重和排序，证明仅在简单情况下可实现排序直接访问。为深入理解计算挑战，我们考虑更基础的单一答案访问任务（即查找给定位置的答案）——称为选择问题。通过采用Frederickson和Johnson对排序矩阵选择经典问题的解决方案，我们确实为无自连接的全CQ子集设计了拟线性时间算法。进一步证明该类中其他查询均不适用此算法。

## 1 INTRODUCTION

## 1 引言

When can we allow for direct access to a ranked list of answers to a database query without (and considerably faster than) materializing all answers? To illustrate the concrete instantiation of this question, assume the following simple relational schema for information about pandemic spread and relevant activity of residents:

在什么情况下，我们无需（且远快于）物化所有答案，就能直接访问数据库查询的排序答案列表？为具体说明这个问题，假设以下关于疫情传播和居民相关活动的简单关系模式：

Visits(person, age, city) Cases(city, date, #cases)

访问记录(人员，年龄，城市) 病例数据(城市，日期，#病例数)

Here, Visits mentions, for each person, the cities that the person visits regularly (e.g., for work and relatives) and the age of the person (for risk assessment); the relation Cases specifies the number of new infection cases in specific cities at specific dates (a measure that is commonly used for spread assessment albeit being sensitive to the amount of testing).

其中，访问记录记载了每个人定期访问的城市（如工作地和亲属所在地）及其年龄（用于风险评估）；病例数据则记录了特定城市在特定日期的新增感染病例数（这是衡量传播程度的常用指标，但易受检测量影响）。

Suppose that we wish to efficiently compute the natural join Visits $\bowtie$ Cases based on equality of the city attribute,so that we have all combinations of people (with their age), the cities they regularly visit, and the city's daily new cases. For example,

假设我们希望基于城市属性的等值连接高效计算自然连接 访问记录 $\bowtie$ 病例数据，从而获得人员（及其年龄）、其常访城市与城市每日新增病例的所有组合。例如，

$$
\text{(Anna, 72, Boston, 12/7/2020, 179) .}
$$

While the number of such answers could be quadratic in the size of the database, the seminal work of Bagan, Durand, and Grandjean [3] has established that it can be evaluated using an enumeration algorithm with a constant delay between consecutive answers, after a linear-time preprocessing phase. This is due to the fact that this join is a special case of a free-connex Conjunctive Query (CQ). In the case of CQs without self-joins, being free-connex is a sufficient and necessary condition for such efficient evaluation [3, 8]. The necessity requires conventional assumptions in fine-grained complexity ${}^{1}$ and it holds even if we multiply the preprocessing time and delay by a logarithmic factor in the size of the database. ${}^{2}$

虽然这类答案数量可能与数据库规模呈平方关系，但Bagan、Durand和Grandjean的开创性研究[3]表明，通过线性时间预处理后，可以使用在连续答案间保持恒定延迟的枚举算法进行评估。这是因为该连接属于自由连接合取查询(CQ)的特例。对于无自连接的CQ，自由连接性是实现这种高效评估的充要条件[3,8]。必要性要求细粒度复杂度中的常规假设${}^{1}$，即使将预处理时间和延迟乘以数据库大小的对数因子仍成立。${}^{2}$

To realize the constant (or logarithmic) delay, the preprocessing phase builds a data structure that allows for efficient iteration over the answers in the enumeration phase. Brault-Baron [8] showed that in the linear-time preprocessing phase, we can build a structure with better guarantees: not only log-delay enumeration, but even log-time direct access: a structure that,given $k$ ,allows to directly retrieve the ${k}^{\text{th }}$ answer in the enumeration without needing to enumerate the preceding $k - 1$ answers first. ${}^{3}$ Later,Carmeli et al. [10] showed how such a structure can be used for enumerating answers in a random order (random permutation) ${}^{4}$ with the statistical guarantee that the order is uniformly distributed. In particular, in the above example we can enumerate the answers of Visits $\bowtie$ Cases in a provably uniform random permutation (hence, ensuring statistical validity of each prefix) with logarithmic delay, after a linear-time preprocessing phase. Their direct-access structure also allows for inverted access: given an answer,return the index $k$ of that answer (or determine that it is not a valid answer). Recently, Keppeler [23] proposed another direct-access structure with the additional ability to allow efficient database updates, but at the cost of only supporting a limited subset of free-connex CQs.

为实现恒定（或对数级）延迟，预处理阶段会构建支持枚举阶段高效迭代答案的数据结构。Brault-Baron[8]证明在线性时间预处理阶段可构建具有更强保证的结构：不仅支持对数延迟枚举，还能实现对数时间直接访问——该结构在给定$k$时可直接检索枚举中的第${k}^{\text{th }}$个答案，而无需先枚举前$k - 1$个答案。${}^{3}$ 后来Carmeli等人[10]展示了如何利用该结构以随机顺序（随机排列）${}^{4}$枚举答案，并统计保证顺序的均匀分布。特别地，在上例中经过线性时间预处理后，我们可用对数延迟以可证明的均匀随机排列枚举访问记录$\bowtie$病例数据的答案（从而确保每个前缀的统计有效性）。其直接访问结构还支持逆向访问：给定答案，返回该答案的索引$k$（或判定其非有效答案）。近期Keppeler[23]提出另一种支持高效数据库更新的直接访问结构，但代价是仅支持自由连接CQ的有限子集。

All known direct-access structures $\left\lbrack  {8,{10},{23}}\right\rbrack$ allow the answers to be sorted by some lexicographic order (even if they do not explicitly state it). For instance,in our Visits $\bowtie$ Cases the structure could be such that the tuples are in the (descending or ascending) order of #cases and then by date, or in the order of city and then by age. Hence, in logarithmic time we can evaluate quantile queries (find the ${k}^{\text{th }}$ answer in order) and determine the position of a tuple inside the sorted list. From this we can also conclude (fairly easily) that we can enumerate the answers ordered by age where ties are broken randomly, again provably uniformly. Carmeli et al. [10] have also shown how the order of the answers can be useful for generalizing direct-access algorithms from CQs to UCQs. Note that direct access to the sorted list of answers is a stronger requirement than ranked enumeration that has been studied in recent work [7, 11, 31, 32, 34].

所有已知的直接访问结构$\left\lbrack  {8,{10},{23}}\right\rbrack$都允许答案按某种字典序排列（即便未明确声明）。例如在我们的Visits$\bowtie$Cases案例中，结构可能使元组按#cases（降序或升序）和日期排序，或按城市和年龄排序。因此，我们可在对数时间内评估分位数查询（按序查找${k}^{\text{th }}$答案）并确定元组在排序列表中的位置。由此还可（较易）推论：我们能按年龄枚举随机破阶的排序答案，且可证明其均匀性。Carmeli等人[10]亦论证了答案排序对将直接访问算法从CQ推广到UCQ的价值。需注意，直接访问排序答案列表是比近期研究[7,11,31,32,34]中的排序枚举更强的要求。

Yet, the choice of which lexicographic order is taken is an artefact of the structure construction (e.g., the elimination order [8], the join tree [10],or the $q$ -tree [8]). If the application desires a specific lexicographic order, we can only hope to find a matching construction. However, this is not necessarily possible. For example, could we construct in (quasi)linear time a direct-access structure for Visits $\bowtie$ Cases ordered by #cases and then by age? Interestingly, we will show that the answer is negative: it is impossible to build in quasilinear time a direct-access structure with logarithmic access time for that lexicographic order.

然而，字典序的选择是结构构建的副产品（如消解序[8]、连接树[10]或$q$树[8]）。若应用需要特定字典序，我们只能寻求匹配的构建方案。但这未必可行。例如：能否以（拟）线性时间为Visits$\bowtie$Cases构建按#cases和年龄排序的直接访问结构？有趣的是，我们将证明答案是否定的：不可能在拟线性时间内为该字典序构建具有对数访问时间的直接访问结构。

Getting back to the question posed at the beginning of this section, in this paper we embark on the challenge of identifying, for each CQ, the orders that allow for efficiently constructing a direct-access structure. We adopt the tractability yardstick of quasilinear construction (preprocessing) time and logarithmic access time. In addition, we focus on two types of orders: lexicographic orders, and scoring by the sum of attribute weights.

回到本节开头的问题，本文致力于为每个CQ识别支持高效构建直接访问结构的排序方案。我们采用拟线性构建（预处理）时间和对数访问时间的可操作性标准，并聚焦两类排序：字典序和属性权重求和评分。

Contributions. Our first main result is an algorithm for direct access for lexicographic orders, including ones that are not achievable by past structures. We further show that within the class of CQs without self-joins, our algorithm covers all the tractable cases (in the sense adopted here), and we establish a decidable and easy to test classification of the lexicographic orders over the free variables into tractable and intractable ones. For instance,in the case of Visits $\bowtie$ Cases the lexicographic order (#cases, age, city, date, person) is intractable. It is classified as such because #cases and age are non-neighbours (i.e., do not co-occur in the same atom), but city, which comes after #cases and age in the order, is a neighbour of both. This is what we call a disruptive trio. The lexicographic order (#cases, age) is also intractable since the query Visits $\bowtie$ Cases is not $\{ \#$ cases,age $\}$ -connex. In contrast, the lexicographic order (#cases, city, age) is tractable. We also show that within the tractable side, the structure we construct allows for inverted access in constant time.

研究贡献。首个主要成果是针对字典序（包括既往结构无法实现的排序）的直接访问算法。我们进一步证明：在无自连接的CQ类中，该算法覆盖了所有可操作情形（按本文标准），并对自由变量的字典序建立了可判定、易测试的可操作与不可操作分类。例如Visits<b0></b1>Cases中，字典序（#cases,年龄,城市,日期,人员）不可操作——因#cases与年龄非相邻（即不在同一原子中共现），但排序中位于二者后的城市却与两者相邻，此即所谓破坏性三元组。字典序（#cases,年龄）亦不可操作，因查询Visits<b0></b1>Cases非$\{ \#$cases,age$\}$-连通。相反，字典序（#cases,城市,年龄）可操作。我们还证明在可操作范围内，所构建结构支持常数时间逆向访问。

Our classification is proved in two steps. We begin by considering the complete lexicographic orders (that involve all free variables). We show that for free-connex CQs without self-joins, the absence of a disruptive trio is a sufficient and necessary condition for tractability. We then generalize to partial lexicographic orders $L$ where the ordering is determined only by a subset of the free variables. There, the condition is that there is no disruptive trio and that the query is $L$ -connex (a similar condition to being free-connex,but for the subset of the variables that appear in $L$ instead of the free ones). Interestingly, it turns out that a partial lexicographic order is tractable if and only if it is the prefix of a complete tractable lexicographic order.

分类证明分两步：首先考虑完整字典序（含所有自由变量），证明对无自连接的自由连通CQ，不存在破坏性三元组是可操作性的充要条件；继而推广到部分字典序$L$（仅由自由变量子集决定排序），其条件为无破坏性三元组且查询是$L$-连通的（类似自由连通条件，但针对$L$中的变量子集而非自由变量）。有趣的是，部分字典序可操作当且仅当它是某个完整可操作字典序的前缀。

A lexicographic order is a special case of an ordering by the sum of attribute weights, where every database value is mapped to some number. Hence, a natural question is which CQs have a tractable direct access by the order of sum. For example, what about Visits $\bowtie$ Cases with the order $\left( {\alpha  \cdot  \# \text{cases} + \beta  \cdot  \text{age}}\right)$ ? It is easy to see that this order is intractable because the lexicographic order (#cases, age) is intractable. In fact, it is easy to show that an order by sum is intractable whenever any lexicographic order is intractable (e.g., there is a disruptive trio). However, the situation is worse: the only tractable case is the one where the CQ is acyclic and there is an atom that contains all of the free variables. In particular, ordering by sum is intractable already for the Cartesian product $Q\left( {{c}_{1},d,x,p,a,{c}_{2}}\right)  \mathrel{\text{:-Visits}} \left( {p,a,{c}_{1}}\right) ,\operatorname{Cases}\left( {{c}_{2},d,x}\right)$ ,even though every lexicographic order is tractable (according to our aforementioned classification). This daunting hardness also emphasizes how ranked direct access is fundamentally harder than ranked enumeration where, in the case of the sum of attributes, the answers of every full acyclic CQ can be enumerated with logarithmic delay after a linear preprocessing time [31].

字典序是依据属性权重之和进行排序的特殊情形，其中每个数据库值都被映射为某个数值。因此，一个自然的问题是哪些合取查询(CQ)能通过求和排序实现可处理的直接访问。例如，以$\left( {\alpha  \cdot  \# \text{cases} + \beta  \cdot  \text{age}}\right)$顺序排列的Visits$\bowtie$Cases查询如何？显然该排序不可处理，因为字典序(#cases, age)本就不可处理。事实上可以证明，只要存在任何不可处理的字典序（例如存在破坏性三元组），求和排序就必然不可处理。但更严峻的是：唯一可处理的情况是当合取查询为无环且存在包含所有自由变量的原子时。特别地，对于笛卡尔积$Q\left( {{c}_{1},d,x,p,a,{c}_{2}}\right)  \mathrel{\text{:-Visits}} \left( {p,a,{c}_{1}}\right) ,\operatorname{Cases}\left( {{c}_{2},d,x}\right)$，尽管所有字典序都可处理（根据我们前文的分类），求和排序已然不可处理。这一惊人难度也凸显了排序直接访问从根本上比排序枚举更困难——在属性求和情形下，所有无环合合查询的答案在线性预处理时间后都能以对数延迟枚举[31]。

To understand the root cause of the hardness of sum, we narrow our question to a considerably weaker guarantee. Our notion of tractability so far requires the construction of a structure in quasi-linear time and a direct access in logarithmic time. In particular, if our goal is to compute just a single quantile,say the ${k}^{\text{th }}$ answer, then it takes quasilinear time. Computing a single quantile is known as the selection problem [6]. The question we ask is to what extent is selection a weaker requirement than direct access in the case of CQs. That is, how much larger is the class of CQs with quasilin-ear selection than that of CQs with a quasilinear construction of a logarithmic-access structure?

为理解求和难度的根源，我们将问题弱化为更宽松的保证条件。当前的可处理性概念要求准线性时间构建结构和对数时间直接访问。特别地，若仅需计算单个分位数（如${k}^{\text{th }}$答案），则需准线性时间。计算单一分位数即选择问题[6]。我们探讨的核心是：对于合取查询，选择问题在多大程度上弱于直接访问要求？即具有准线性选择能力的合查查询类，比具有对数访问结构准线性构建能力的合查查询类大多少？

We answer the above question for the class of full CQs without self-joins by establishing the following dichotomy for the order by sum (again assuming fine-grained hypotheses): the selection problem can be solved in $O\left( {n\log n}\right)$ time,where $n$ is the size of the database, if and only if the hypergraph of the CQ contains at most two maximal hyperedges (w.r.t. containment). The tractable side is applicable even in the presence of self-joins, and it is achieved by adopting an algorithm by Frederickson and Johnson [15] originally developed for selection on sorted matrices. For illustration, the selection problem is solvable in quasilinear time for the query Visits $\bowtie$ Cases ordered by sum.

针对无自连接的全合取查询类，我们通过建立求和排序的二分性回答上述问题（再次假设细粒度假设）：选择问题可在$O\left( {n\log n}\right)$时间内解决（其中$n$为数据库规模），当且仅当该查询的超图最多包含两条极大超边（关于包含关系）。可处理侧即使存在自连接也适用，这通过采用Frederickson和Johnson[15]最初为有序矩阵选择设计的算法实现。例如，对按求和的Visits$\bowtie$Cases查询，选择问题可在准线性时间内求解。

Applicability. It is important to note that while our results are stated over a limited class of queries (a fragment of acyclic CQs), there are some implications beyond this class that are immediate yet significant. In particular, we can use known techniques that reduce other CQs to a tractable form and then apply our direct-access solutions. An example is the common case where the relations are associated with functional dependencies; in this case, some queries become easier since we can make assumptions on the internal structure of the input relations. ${}^{5}$ More specifically,FD-extensions can be used to transform CQs with an otherwise intractable structure into queries with a tractable structure [9]. As another example, a hyper-tree decomposition can be used to transform a cyclic CQ to an acyclic form by paying a non-linear overhead during preprocessing [20].

## 2 预备知识

### 2.1 Basic Notions

### 2.1 基本概念

Database. A schema $\mathcal{S}$ is a set of relational symbols $\left\{  {{R}_{1},\ldots ,{R}_{m}}\right\}$ . We use ar(R)for the arity of a relational symbol $R$ . A database instance $I$ contains a finite relation ${R}^{I} \subseteq  {\operatorname{dom}}^{\operatorname{ar}\left( R\right) }$ for each $R \in  \mathcal{S}$ , where dom is a set of constant values called the domain. We use $n$ for the size of the database, i.e., the total number of tuples.

数据库。模式$\mathcal{S}$是关系符号集$\left\{  {{R}_{1},\ldots ,{R}_{m}}\right\}$。用ar(R)表示关系符号$R$的元数。数据库实例$I$为每个$R \in  \mathcal{S}$包含有限关系${R}^{I} \subseteq  {\operatorname{dom}}^{\operatorname{ar}\left( R\right) }$，其中dom称为域的常量值集合。用$n$表示数据库大小（即元组总数）。

Queries. A conjunctive query (CQ) $Q$ over schema $\mathcal{S}$ is an expression of the form $Q\left( {\overrightarrow{X}}_{f}\right)  :  - {R}_{1}\left( {\overrightarrow{X}}_{1}\right) ,\ldots ,{R}_{\ell }\left( {\overrightarrow{X}}_{\ell }\right)$ ,where the tuples ${\overrightarrow{X}}_{f},{\overrightarrow{X}}_{1},\ldots ,{\overrightarrow{X}}_{\ell }$ hold variables,every variable in ${\overrightarrow{X}}_{f}$ appears in some ${\overrightarrow{X}}_{1},\ldots ,{\overrightarrow{X}}_{\ell }$ ,and ${R}_{1},\ldots ,{R}_{\ell } \subseteq  \mathcal{S}$ . Each ${R}_{i}\left( {\overrightarrow{X}}_{i}\right)$ is called an atom of the query $Q$ ,and atoms(Q)denotes the set of all atoms. We use $\operatorname{var}\left( e\right)$ or $\operatorname{var}\left( Q\right)$ for the set of variables that appear in an atom $e$ or query $Q$ ,respectively. The variables ${\overrightarrow{X}}_{f}$ are called free and are denoted by free(Q). A CQ is full if $\operatorname{free}\left( Q\right)  = \operatorname{var}\left( Q\right)$ and Boolean if $\operatorname{free}\left( Q\right)  = \varnothing$ . Sometimes,we say that CQs that are not full have projections. A repeated occurrence of a relational symbol is a self-join and if no self-joins exist, a CQ is called self-join-free. A homomorphism $\mu$ from a CQ $Q$ to a database $I$ is a mapping of $\operatorname{var}\left( Q\right)$ to constants from dom,such that every atom of $Q$ maps to a tuple in the database $I$ . A query answer $q$ is such a homomorphism followed by a projection of $\mu$ on the free variables,denoted by ${\pi }_{\text{free }\left( Q\right) }\left( \mu \right)$ . The answer to a Boolean CQ is whether such a homomorphism exists. The set of query answers is $Q\left( I\right)$ .

查询。模式$\mathcal{S}$上的合取查询(CQ)$Q$是形如$Q\left( {\overrightarrow{X}}_{f}\right)  :  - {R}_{1}\left( {\overrightarrow{X}}_{1}\right) ,\ldots ,{R}_{\ell }\left( {\overrightarrow{X}}_{\ell }\right)$的表达式，其中元组${\overrightarrow{X}}_{f},{\overrightarrow{X}}_{1},\ldots ,{\overrightarrow{X}}_{\ell }$包含变量，${\overrightarrow{X}}_{f}$中的每个变量都出现在某个${\overrightarrow{X}}_{1},\ldots ,{\overrightarrow{X}}_{\ell }$中，且${R}_{1},\ldots ,{R}_{\ell } \subseteq  \mathcal{S}$。每个${R}_{i}\left( {\overrightarrow{X}}_{i}\right)$称为查询$Q$的一个原子，atoms(Q)表示所有原子的集合。我们分别用$\operatorname{var}\left( e\right)$或$\operatorname{var}\left( Q\right)$表示出现在原子$e$或查询$Q$中的变量集合。变量${\overrightarrow{X}}_{f}$称为自由变量，记作free(Q)。当$\operatorname{free}\left( Q\right)  = \operatorname{var}\left( Q\right)$时称CQ为满射查询，当$\operatorname{free}\left( Q\right)  = \varnothing$时称布尔查询。有时我们会称非满射的CQ具有投影特性。关系符号的重复出现称为自连接，若不存在自连接则称该CQ为无自连接查询。从CQ$Q$到数据库$I$的同态$\mu$是将$\operatorname{var}\left( Q\right)$映射到dom域中常量的函数，使得$Q$的每个原子都映射到数据库$I$中的一个元组。查询答案$q$是这样一个同态后对自由变量$\mu$的投影，记作${\pi }_{\text{free }\left( Q\right) }\left( \mu \right)$。布尔CQ的答案取决于是否存在这样的同态。所有查询答案的集合记为$Q\left( I\right)$。

Hypergraphs. A hypergraph $\mathcal{H} = \left( {V,E}\right)$ is a set $V$ of vertices and a set $E$ of subsets of $V$ called hyperedges. Two vertices in a hypergraph are neighbors if they appear in the same edge. A path of $\mathcal{H}$ is a sequence of vertices such that every two succeeding vertices are neighbors. A chordless path is a path in which no two non-succeeding vertices appear in the same hyperedge (in particular, no vertex appears twice). A join tree of a hypergraph $\mathcal{H} = \left( {V,E}\right)$ is a tree $T$ where the nodes ${}^{6}$ are the hyperedges of $\mathcal{H}$ and the running intersection property holds,namely: for all $u \in  V$ the set $\{ e \in  E \mid$ $u \in  e\}$ forms a (connected) subtree in $T$ . An equivalent phrasing of the running intersection property is that given two vertices ${e}_{1},{e}_{2}$ of the tree,for any vertex ${e}_{3}$ on the simple path between them,we have that ${e}_{1} \cap  {e}_{2} \subseteq  {e}_{3}$ . A hypergraph $\mathcal{H}$ is acyclic if there exists a join tree for $\mathcal{H}$ . We associate a hypergraph $\mathcal{H}\left( Q\right)  = \left( {V,E}\right)$ to a CQ $Q$ where the vertices are the variables of $Q$ ,and every atom of $Q$ corresponds to a hyperedge with the same set of variables. Stated differently, $V = \operatorname{var}\left( Q\right)$ and $E = \{ \operatorname{var}\left( e\right)  \mid  e \in  \operatorname{atoms}\left( Q\right) \}$ . With a slight abuse of notation,we identify atoms of $Q$ with hyperedges of $\mathcal{H}\left( Q\right)$ . A CQ $Q$ is acyclic if $\mathcal{H}\left( Q\right)$ is acyclic,otherwise it is cyclic.

超图。超图$\mathcal{H} = \left( {V,E}\right)$是由顶点集合$V$和称为超边的$V$子集集合$E$构成。超图中两个顶点若出现在同一条边中则互为邻居。$\mathcal{H}$的路径是指一个顶点序列，其中每两个连续顶点都是邻居。无弦路径是指路径中任意两个非连续顶点不会出现在同一超边中（特别地，没有顶点重复出现）。超图$\mathcal{H} = \left( {V,E}\right)$的连接树是一棵树$T$，其节点${}^{6}$是$\mathcal{H}$的超边且满足运行交集性质，即：对于所有$u \in  V$，集合$\{ e \in  E \mid$$u \in  e\}$在$T$中形成（连通的）子树。运行交集性质的等价表述是：给定树中两个顶点${e}_{1},{e}_{2}$，对于它们之间简单路径上的任意顶点${e}_{3}$，都有${e}_{1} \cap  {e}_{2} \subseteq  {e}_{3}$。若超图$\mathcal{H}$存在连接树，则称其为无环超图。我们将超图$\mathcal{H}\left( Q\right)  = \left( {V,E}\right)$与CQ（合取查询）$Q$相关联，其中顶点是$Q$的变量，且$Q$的每个原子对应于具有相同变量集的超边。换言之，$V = \operatorname{var}\left( Q\right)$且$E = \{ \operatorname{var}\left( e\right)  \mid  e \in  \operatorname{atoms}\left( Q\right) \}$。在不严格区分符号的情况下，我们将$Q$的原子与$\mathcal{H}\left( Q\right)$的超边视为等同。若$\mathcal{H}\left( Q\right)$是无环的，则CQ$Q$是无环的，否则为有环的。

Free-connex CQs. A hypergraph ${\mathcal{H}}^{\prime }$ is an inclusive extension of $\mathcal{H}$ if every edge of $\mathcal{H}$ appears in ${\mathcal{H}}^{\prime }$ ,and every edge of ${\mathcal{H}}^{\prime }$ is a subset of some edge in $\mathcal{H}$ . Given a subset $S$ of the vertices of $\mathcal{H}$ ,a tree $T$ is an ext- $S$ -connex tree (i.e.,extension- $S$ -connex tree) for a hypergraph $\mathcal{H}$ if: (1) $T$ is a join tree of an inclusive extension of $\mathcal{H}$ , and (2) there is a subtree ${}^{7}{T}^{\prime }$ of $T$ that contains exactly the vertices $S$ [3]. We say that a hypergraph is $S$ -connex if it has an ext- $S$ -connex tree [3]. A hypergraph is $S$ -connex iff it is acyclic and it remains acyclic after the addition of a hyperedge containing exactly $S\left\lbrack  8\right\rbrack$ . Given a hypergraph $\mathcal{H}$ and a subset $S$ of its vertices,an $S$ -path is a chordless path $\left( {x,{z}_{1},\ldots ,{z}_{k},y}\right)$ in $\mathcal{H}$ with $k \geq  1$ ,such that $x,y \in  L$ , and ${z}_{1},\ldots ,{z}_{k} \notin  L$ . A hypergraph is $S$ -connex iff it has no $S$ -path [3]. A CQ $Q$ is free-connex if $\mathcal{H}\left( Q\right)$ is free(Q)-connex [3]. Note that a free-connex $\mathrm{{CQ}}$ is necessarily acyclic. ${}^{8}$ An implication of the characterization given above is that it suffices to find a join-tree for an inclusive extension of a hypergraph $\mathcal{H}$ to infer that $\mathcal{H}$ is acyclic. To simplify notation,we also say that a CQ is $L$ -connex for a (partial) lexicographic order $L$ if the CQ is $S$ -connex for the variables $S$ that appear in $L$ . Generalizing the notion of an inclusive extension,we say that a hypergraph ${\mathcal{H}}^{\prime }$ is inclusion equivalent to $\mathcal{H}$ if every hyperedge of $\mathcal{H}$ is a subset of some hyperedge of ${\mathcal{H}}^{\prime }$ and vice versa.

自由连接CQ（Free-connex CQs）。若超图${\mathcal{H}}^{\prime }$的每条边都出现在$\mathcal{H}$中，且${\mathcal{H}}^{\prime }$的每条边都是$\mathcal{H}$中某条边的子集，则称${\mathcal{H}}^{\prime }$是$\mathcal{H}$的包容扩展。给定$\mathcal{H}$顶点集的子集$S$，若满足：(1)树$T$是$\mathcal{H}$某包容扩展的连接树；(2)存在$T$的子树${}^{7}{T}^{\prime }$恰好包含顶点集$S$[3]，则称$T$为超图$\mathcal{H}$的外$S$连接树（即扩展$S$连接树）。当超图存在外$S$连接树时，称其为$S$连通的[3]。超图是$S$连通的当且仅当它是无环的，且在添加恰好包含$S\left\lbrack  8\right\rbrack$的超边后仍保持无环性。给定超图$\mathcal{H}$及其顶点子集$S$，若弦less路径$\left( {x,{z}_{1},\ldots ,{z}_{k},y}\right)$满足$k \geq  1$、$x,y \in  L$及${z}_{1},\ldots ,{z}_{k} \notin  L$，则称其为$S$路径。超图是$S$连通的当且仅当不存在$S$路径[3]。当$\mathcal{H}\left( Q\right)$是free(Q)-连通时，称CQ$Q$为自由连通的[3]。注意自由连通的$\mathrm{{CQ}}$必然是无环的。${}^{8}$上述特性的一个重要推论是：只需找到超图$\mathcal{H}$某包容扩展的连接树，即可判定$\mathcal{H}$的无环性。为简化表述，若CQ对（部分）字典序$L$中出现的变量集$S$是$S$连通的，则称该CQ是$L$连通的。推广包容扩展的概念，若超图${\mathcal{H}}^{\prime }$与$\mathcal{H}$的每一条超边互为对方某条超边的子集，则称二者是包容等价的。

### 2.2 Problem Definitions

### 2.2 问题定义

Orders of Answers. For a CQ $Q$ and database instance $I$ ,a ranking function rank : $Q\left( I\right)  \times  Q\left( I\right)  \rightarrow  Q\left( I\right)$ compares two query answers and returns the smaller one according to some underlying total order. ${}^{9}$ We consider two types of orders in this paper. Assuming that the domain values are ordered,a lexicographic order $L$ is an ordering of free(Q)such that $\operatorname{rank}\left( {{q}_{1},{q}_{2}}\right)$ first compares ${q}_{1},{q}_{2}$ on the value of the first $L$ variable,and if they are equal on the value of the second $L$ variable,and so on. A lexicographic order is called partial if the variables in $L$ are a subset of free(Q).

答案排序。对于CQ$Q$和数据库实例$I$，排序函数rank:$Q\left( I\right)  \times  Q\left( I\right)  \rightarrow  Q\left( I\right)$通过某种全序关系比较两个查询结果。本文研究两种排序方式：假定域值有序，字典序$L$是对free(Q)变量的排序，首先比较第一个$L$变量的值，若相等则比较第二个$L$变量的值，以此类推。当$L$中的变量是free(Q)的子集时，称该字典序为部分的。

The second type of order assumes a given weight function that assigns a real-valued weight to the domain values of each variable. More precisely,for a variable $x$ ,we define ${w}_{x} :$ dom $\rightarrow  \mathbb{R}$ and then the weight of a query answer is computed by aggregating the weights of the assigned values of free variables. In a sum-of-weights order,denoted by ${\sum w}$ ,we have ${w}_{Q}\left( q\right)  = \mathop{\sum }\limits_{{x \in  \operatorname{free}\left( Q\right) }}{w}_{x}\left( {q\left( x\right) }\right) ,q \in$ $Q\left( I\right)$ and $\operatorname{rank}\left( {{q}_{1},{q}_{2}}\right)$ compares ${w}_{Q}\left( {q}_{1}\right)$ with ${w}_{Q}\left( {q}_{2}\right)$ . To simplify notation,we refer to all ${w}_{x}$ and ${w}_{Q}$ together as one weight function $w$ . If two query answers have the same weight,then we break ties arbitrarily but consistently, e.g., according to a lexicographic order on their assigned values.

第二种排序类型假设存在一个给定的权重函数，该函数为每个变量的定义域值分配实数值权重。具体而言，对于变量$x$，我们定义${w}_{x} :$定义域$\rightarrow  \mathbb{R}$，查询答案的权重通过聚合自由变量赋值对应权值得出。在求和权重排序（记作${\sum w}$）中，${w}_{Q}\left( q\right)  = \mathop{\sum }\limits_{{x \in  \operatorname{free}\left( Q\right) }}{w}_{x}\left( {q\left( x\right) }\right) ,q \in$$Q\left( I\right)$且$\operatorname{rank}\left( {{q}_{1},{q}_{2}}\right)$将${w}_{Q}\left( {q}_{1}\right)$与${w}_{Q}\left( {q}_{2}\right)$进行比较。为简化表示，我们将所有${w}_{x}$和${w}_{Q}$统称为一个权重函数$w$。若两个查询答案权重相同，则按任意但一致的规则（如基于赋值值的字典序）打破平局。

Attribute Weights vs. Tuple Weights. Notice that in the definition above, we assume that the input weights are assigned to the domain values of the attributes. Alternatively, the input weights could be assigned to the relation tuples, a convention that has been used in past work on ranked enumeration [31]. Since there are several reasonable semantics for interpreting a tuple-weight ranking for CQs with projections and/or self-joins [30], we elect to present our results for the case of attribute weights. For self-join-free CQs, attribute weights can easily be transformed to tuple weights in linear time such that the weights of the query answers remain the same. This works by assigning each variable to one of the atoms that it appears in, and computing the weight of a tuple by aggregating the weights of the assigned attribute values. Therefore, our hardness results for sum-of-weights orders directly extend to the case of tuple weights. Moreover, note that our positive results on direct access (Section 5) and selection (Section 6.2) rely on algorithms that innately operate on tuple weights, thus we cover that case too.

属性权重与元组权重。需注意上述定义中，我们假设输入权重是分配给属性定义域值的。另一种做法是将输入权重分配给关系元组，这是既往排序枚举研究采用的惯例[31]。鉴于投影和/或自连接CQs的元组权重排序存在多种合理语义解释[30]，我们选择展示属性权重情形下的研究成果。对于无自连接CQs，属性权重可通过线性时间转换为元组权重并保持查询答案权重不变——具体方法是为每个变量指定其所属的某个原子，并通过聚合属性赋值的权重计算元组权重。因此，求和权重排序的硬度结论可直接推广至元组权重情形。此外需注意，我们在直接访问（第5节）和选择（第6.2节）中的正向结果所依赖的算法本质上是基于元组权重操作的，故该情形亦被涵盖。

Direct Access vs. Selection. In the problem of direct access by an underlying order,we are given as an input a query $Q$ ,and a database $I$ ,and the goal is to construct a data structure which then allows us to support accesses on the sorted array of query answers. Specifically,an access asks for the query answer at index $k$ on the (implicit) array containing $Q\left( I\right)$ sorted via rank comparisons,for a given integer $k$ . This data structure is built in a preprocessing phase, after which we have to be able to support multiple such accesses. Our goal is to achieve efficient access (in polylogarithmic time) with a preprocessing phase that is significantly smaller than $Q\left( I\right)$ (quasilinear in the database size).

直接访问与选择。在基于底层排序的直接访问问题中，给定查询$Q$和数据库$I$，目标是构建一个支持对排序后的查询答案数组进行访问的数据结构。具体而言，访问操作要求根据给定整数$k$，返回按秩比较排序的（隐式）数组$Q\left( I\right)$中第$k$个查询答案。该数据结构在预处理阶段构建，之后需支持多次此类访问。我们的目标是在预处理阶段显著小于$Q\left( I\right)$（数据库规模的拟线性）的前提下，实现高效访问（多对数时间）。

### 2.3 Complexity Framework and Sorting

### 2.3 复杂度框架与排序

We measure asymptotic complexity in terms of the size of the database $n$ ,while the size of the query is considered constant. If the time for preprocessing is $O\left( {f\left( n\right) }\right)$ and the time for each access is $O\left( {g\left( n\right) }\right)$ ,we denote that as $\langle f\left( n\right) ,g\left( n\right) \rangle$ ,where $f,g$ are functions from $\mathbb{N}$ to $\mathbb{R}$ . Note that by definition,the problem of selection asks for a $\langle 1,g\left( n\right) \rangle$ solution.

我们以数据库规模$n$来衡量渐近复杂度，同时将查询大小视为常量。若预处理时间为$O\left( {f\left( n\right) }\right)$且每次访问时间为$O\left( {g\left( n\right) }\right)$，则记为$\langle f\left( n\right) ,g\left( n\right) \rangle$，其中$f,g$是从$\mathbb{N}$到$\mathbb{R}$的函数。需注意根据定义，选择问题要求的是$\langle 1,g\left( n\right) \rangle$解。

The model of computation is the RAM model with uniform cost measure. In particular, it allows for linear time construction of lookup tables, which can be accessed in constant time. We would like to point out that some past works $\left\lbrack  {3,{10}}\right\rbrack$ have assumed that in certain variants of the model, sorting can be done in linear time [21]. Since we consider problems related to summation and sorting [15] where a linear-time sort would improve otherwise optimal bounds, we adopt a more standard assumption that sorting is comparison-based and possible only in quasilinear time. As a consequence, some upper bounds mentioned in this paper are weaker than the original sources which assumed linear-time sorting $\left\lbrack  {8,{10}}\right\rbrack$ .

计算模型采用统一成本度量的RAM模型。该模型特别允许线性时间构建查找表，并支持常量时间访问。需要指出的是，既往研究$\left\lbrack  {3,{10}}\right\rbrack$曾假设在该模型的某些变体中，排序可在线性时间内完成[21]。鉴于我们研究的求和与排序相关问题[15]中，线性时间排序会改变最优边界条件，因此采用更标准的假设：排序基于比较且仅能在拟线性时间内完成。由此，本文提及的部分上界结果弱于原先假设线性时间排序$\left\lbrack  {8,{10}}\right\rbrack$的文献。

### 2.4 Hardness Hypotheses

### 2.4 困难性假设

Denote by sparseBMM the hypothesis that two Boolean matrices $A$ and $B$ ,represented as lists of their non-zero entries,cannot be multiplied in time ${m}^{1 + o\left( 1\right) }$ ,where $m$ is the number of non-zero entries in $A,B$ ,and ${AB}$ . A consequence of this hypothesis is that we cannot answer the query $Q\left( {x,z}\right)  :  - R\left( {x,y}\right) ,S\left( {y,z}\right)$ with quasilinear preprocessing and polylogarithmic delay. In more general terms, any self-join-free acyclic non-free-connex CQ cannot be enumerated with quasilinear ${}^{10}$ preprocessing time and polylogarithmic delay assuming the SPARSEBMM hypothesis $\left\lbrack  {3,5}\right\rbrack$ .

设sparseBMM假设指：当布尔矩阵$A$和$B$以非零项列表表示时，其乘法运算无法在${m}^{1 + o\left( 1\right) }$时间内完成，其中$m$表示$A,B$中非零项数量，且${AB}$。该假设的推论是：在拟线性预处理时间和多对数延迟条件下，我们无法回答$Q\left( {x,z}\right)  :  - R\left( {x,y}\right) ,S\left( {y,z}\right)$查询。更广义地说，在SPARSEBMM假设$\left\lbrack  {3,5}\right\rbrack$下，任何无自连接的非自由连接无环CQ都无法以拟线性${}^{10}$预处理时间和多对数延迟进行枚举。

A $\left( {k + 1,k}\right)$ -hyperclique is a set of $k + 1$ vertices in a hypergraph such that every $k$ -element subset is a hyperedge. Denote by Hy-PERCLIQUE the hypothesis that for every $k \geq  2$ there is no $O\left( {m\text{polylog}m}\right)$ algorithm for deciding the existence of a $\left( {k + 1,k}\right)$ - hyperclique in a $k$ -uniform hypergraph with $m$ hyperedges. When $k = 2$ ,this follows from the $\delta$ -Triangle hypothesis [1] for any $\delta  > 0$ . When $k \geq  3$ ,this is a special case of the $\left( {\ell ,k}\right)$ - Hyperclique Hypothesis [25]. A known consequence is that Boolean cyclic and self-join-free CQs cannot be answered in quasilinear ${}^{10}$ time [8]. Moreover, cyclic and self-join-free CQs do not admit enumeration with quasilinear preprocessing time and polylogarithmic delay assuming the HYPERCLIQUE hypothesis [8].

$\left( {k + 1,k}\right)$-超团指超图中满足每$k$元素子集皆为超边的$k + 1$个顶点集合。Hy-PERCLIQUE假设断言：对于任意$k \geq  2$，不存在$O\left( {m\text{polylog}m}\right)$算法可判定具有$m$条超边的$k$-均匀超图中是否存在$\left( {k + 1,k}\right)$-超团。当$k = 2$时，该假设可由$\delta$-三角形假设[1]推导得出（对任意$\delta  > 0$成立）；当$k \geq  3$时，则是$\left( {\ell ,k}\right)$-超团假设[25]的特例。已知推论包括：布尔循环且无自连接的CQ无法在拟线性${}^{10}$时间内解答[8]。此外，在HYPERCLIQUE假设下，循环且无自连接的CQ不支持拟线性预处理时间与多对数延迟的枚举方案[8]。

In its simplest form, the 3SUM problem asks for three distinct real numbers $a,b,c$ from a set $S$ with $n$ elements that satisfy $a + b + c =$ 0 . There is a simple $O\left( {n}^{2}\right)$ algorithm for the problem,but it is conjectured that in general, no truly subquadratic solution exists [29]. The significance of this conjecture has been highlighted by many conditional lower bounds for problems in computational geometry [17] and within the P class in general [33]. Note that the problem remains hard even for integers provided that they are sufficiently large (i.e.,in the order of $O\left( {n}^{3}\right)$ ) [29]. We denote by 3sum the following equivalent hypothesis [4] that uses three different sets of numbers: Deciding whether there exist $a \in  A,b \in  B,c \in  C$ from three sets of integers $A,B,C$ such that $a + b + c = 0$ cannot be done in time $O\left( {n}^{2 - \epsilon }\right)$ for any $\epsilon  > 0$ . This lower bound has been confirmed in some restricted models of computation [2, 12].

3SUM问题的最简形式是：给定包含$S$个元素的集合$a,b,c$，寻找三个不同的实数使其和等于$a + b + c =$0。虽然存在简单的$O\left( {n}^{2}\right)$算法，但学界普遍猜想该问题不存在真正的亚二次方解[29]。这一猜想的重要性体现在计算几何领域[17]和P类问题[33]的诸多条件性下界证明中。值得注意的是，即使对于足够大的整数（量级为$O\left( {n}^{3}\right)$），该问题仍保持计算难度[29]。我们通过3sum假设[4]给出等价表述：判断三个整数集$A,B,C$中是否存在$a \in  A,b \in  B,c \in  C$满足$a + b + c = 0$，该问题无法在$O\left( {n}^{2 - \epsilon }\right)$时间内解决（对于任意$\epsilon  > 0$）。该下界已在某些受限计算模型中得到验证[2,12]。

### 2.5 Known Results for CQs

### 2.5 合取查询的已知结果

Eliminating Projection. We now provide some background that relates to the efficient handling of CQs. For a query with projections, a standard strategy is to reduce it to an equivalent one where techniques for acyclic full CQs can be leveraged. The following proposition, that is widely known and used [5], shows that this is possible for free-connex CQs.

投影消除。本节阐述与高效处理合取查询相关的背景知识。对于含投影的查询，标准策略是将其转化为等价的无环全合取查询以利用现有技术。如下广为人知的命题[5]表明，自由连接查询可实现这种转换。

Proposition 2.1 (Folkhlore). Given a database instance $I$ ,a ${CQ}$ $Q$ ,a join tree $T$ of an inclusive extension of $Q$ ,and a subtree ${T}^{\prime }$ of $T$ that contains all the free variables, we can compute in linear time a database instance ${I}^{\prime }$ over the schema of a ${CQ}{Q}^{\prime }$ that consists of the nodes of ${T}^{\prime }$ such that $Q\left( I\right)  = {Q}^{\prime }\left( {I}^{\prime }\right)$ and $\left| {I}^{\prime }\right|  \leq  \left| I\right|$ .

命题2.1（经典结论）。给定数据库实例$I$、${CQ}$$Q$、$Q$包容扩展的连接树$T$，以及包含所有自由变量的子树${T}^{\prime }$，我们可在线性时间内构建模式为${CQ}{Q}^{\prime }$的新实例${I}^{\prime }$（其节点来自${T}^{\prime }$），使得$Q\left( I\right)  = {Q}^{\prime }\left( {I}^{\prime }\right)$且$\left| {I}^{\prime }\right|  \leq  \left| I\right|$。

This reduction is done by first creating a relation for every node in $T$ using projections of existing relations,then performing the classic semi-join reduction by Yannakakis [35] to filter the relations of ${T}^{\prime }$ according to the relations of $T$ ,and then we can simply ignore all relations that do not appear in ${T}^{\prime }$ and obtain the same answers. Afterwards, they can be handled efficiently, e.g. their answers can be enumerated with constant delay [3].

该转换首先为$T$中每个节点创建投影关系，接着执行Yannakakis半连接约简[35]根据$T$关系过滤${T}^{\prime }$关系，最终可忽略${T}^{\prime }$之外的所有关系而保持结果一致。转换后的查询可被高效处理，例如实现常数延迟的枚举[3]。

Ranked enumeration. Enumerating the answers to a CQ in ranked order is a special case of direct access where the accessed indexes are consecutive integers starting from 0 . In contrast to direct access, ranked enumeration by sum orderings (thus also lexicographic orderings) is possible with logarithmic delay after a linear-time preprocessing phase for all full acyclic CQs [31]. This result has also been extended to free-connex CQs [30]. Existing ranked-enumeration algorithms rely on priority queue structures that compare a minimal number of candidate answers to produce the ranked answers one-by-one in order. There is no straightforward way to extend them to the task of direct access where we may skip over a large number of answers to get to an arbitrary index $k$ .

排序枚举。按序枚举合取查询结果是直接访问的特殊形式，其访问索引为从0开始的连续整数。与直接访问不同，对于全无环查询，经过线性时间预处理后，可实现按求和排序（含字典序）的对数延迟枚举[31]。该结果已扩展至自由连接查询[30]。现有排序枚举算法依赖优先队列结构，通过最小化候选答案比较次数来顺序生成结果。这些方法难以直接推广到需要跳过大量结果访问任意索引$k$的直接访问场景。

Direct Access. Past work on direct access identified the tractable queries without guarantees on the order of the query answers.

直接访问。既往研究在不保证结果顺序的前提下，界定了可高效处理的查询类型。

THEOREM 2.2 ([8,10]). Let $Q$ be a ${CQ}$ . If $Q$ is free-connex,then direct access (in some order) is possible in $\langle n\log n,\log n\rangle$ . Otherwise, if it is also self-join-free, then direct access (in any order) is not possible in $\langle n$ polylog $n$ ,polylog $n\rangle$ ,assuming SPARSEBMM and HYPERCLIQUE.

定理2.2([8,10])。设$Q$为${CQ}$。若$Q$是自由连接查询，则可在$\langle n\log n,\log n\rangle$时间内实现（某种顺序的）直接访问；若同时无自连接且假设SPARSEBMM与HYPERCLIQUE成立，则无法在$\langle n$polylog$n$或polylog$n\rangle$时间内实现（任意顺序的）直接访问。

Even though these algorithms do not explicitly discuss the order of the answers, a closer look shows that they internally use and produce some lexicographic order.

尽管这些算法未显式讨论结果顺序，深入分析表明其内部生成并使用了某种字典序。

Recent work by Keppeler [23] suggests another direct-access solution by lexicographic order, which also supports efficient insertion and deletion of input tuples. Given these additional requirements, the supported CQs are more limited, and are only a subset of free-connex CQs called $q$ -hierarchical. This is a subclass of the well-known hierarchical queries with an additional restriction on the existential variables. As an example, the following CQs are not $q$ -hierarchical even though they are free-connex: ${Q}_{1}\left( {x,y}\right)  \mathrel{\text{:-}} {R}_{1}\left( x\right) ,{R}_{2}\left( {x,y}\right) ,{R}_{3}\left( y\right)$ and ${Q}_{2}\left( x\right)  \mathrel{\text{:-}} {R}_{1}\left( {x,y}\right) ,{R}_{2}\left( y\right)$ . For these queries, direct access is not supported by the solution of Keppeler [23], even though it is possible without the update requirements.

Keppeler[23]的最新研究提出了一种基于字典序的直接访问解决方案，该方案同时支持输入元组的高效插入与删除操作。鉴于这些额外需求，所支持的合取查询(CQs)范围更为受限，仅属于自由连接型合取查询的一个子集，称为$q$层次化查询。这是著名层次化查询的一个子类，对存在变量施加了额外限制。例如下列合取查询虽属自由连接型，却不符合$q$层次化特征：${Q}_{1}\left( {x,y}\right)  \mathrel{\text{:-}} {R}_{1}\left( x\right) ,{R}_{2}\left( {x,y}\right) ,{R}_{3}\left( y\right)$和${Q}_{2}\left( x\right)  \mathrel{\text{:-}} {R}_{1}\left( {x,y}\right) ,{R}_{2}\left( y\right)$。对于这类查询，Keppeler[23]的解决方案不支持直接访问——尽管在不考虑更新需求时本可实现。

All previous direct-access solutions of which we are aware have two gaps compared to this work: (1) they do not discuss which lexicographic orders (given by orderings of the free variables) are supported; (2) they do not support all possible lexicographic orders. We conclude this section with a short survey of existing solutions and their supported orders.

我们所知的所有先前直接访问解决方案与本研究相比存在两大局限：(1)未阐明支持哪些自由变量排序生成的字典序；(2)不能支持所有可能的字典序。本节最后将简要综述现有解决方案及其支持的排序方式。

All prior direct-access solutions use some underlying component that depends on the query structure and constrains the supported orders. The algorithm of Carmeli et al. [10, Algorithm 3] assumes that a join tree is given with the CQ, and the lexicographic order is imposed by the join tree. Specifically, it is an ordering of the variables achieved by a preorder depth-first traversal of the tree. As a result, it does not support any order that requires jumping back-and-forth between different branches of the tree. In particular, it does not support ${Q}_{3}\left( {{v}_{1},{v}_{2},{v}_{3},{v}_{4}}\right)  :  - R\left( {{v}_{1},{v}_{3}}\right) ,S\left( {{v}_{2},{v}_{4}}\right)$ with the lexicographic order given by the increasing variable indices (we adopt this convention for all the examples below). We show how to handle this CQ and order in detail in Example 3.5. The algorithm of Brault-Baron [8, Algorithm 4.3] assumes that an elimination order is given along with the CQ. The resulting lexicographic order is affected by that elimination order, but is not exactly the same. This solution suffers from similar restrictions,and it does not support ${Q}_{3}$ either. The algorithm of Keppeler [23] assumes that a $q$ -tree is given with the CQ, and the possible lexicographic orders are affected by this tree. Unlike the previous ones, this algorithm can interleave variables from different atoms, yet cannot support some orders that are possible for the previous algorithms. As an example, it does not support ${Q}_{4}\left( {{v}_{1},{v}_{2},{v}_{3}}\right)  :  - {R}_{1}\left( {{v}_{1},{v}_{2}}\right) ,{R}_{2}\left( {{v}_{2},{v}_{3}}\right)$ as ${v}_{2}$ is highest in the hierarchy (the atoms containing it strictly subsume the atoms containing any other variable) and so it is necessarily the first variable in the q-tree and in the ordering produced.

所有先前的直接访问解决方案都依赖某种受查询结构制约的基础组件，从而限制了可支持的排序方式。Carmeli等人[10，算法3]的方案假设合取查询附带连接树，字典序由连接树决定——具体是通过树的前序深度优先遍历实现的变量排序。因此，该算法不支持需要在树的不同分支间来回跳转的排序，尤其不支持按变量索引升序排列的字典序(下文中所有示例均采用此惯例)。我们将在示例3.5详细演示如何处理此类查询与排序。Brault-Baron[8，算法4.3]的方案假设合取查询附带消解序，生成的字典序受该消解序影响但并非完全一致。此方案存在类似限制，同样无法支持${Q}_{3}$。Keppeler[23]的算法假设合取查询附带$q$树，可能的字典序受此树结构制约。与前两种方案不同，该算法能交叉处理不同原子中的变量，却无法支持前两种算法允许的某些排序。例如不支持${Q}_{4}\left( {{v}_{1},{v}_{2},{v}_{3}}\right)  :  - {R}_{1}\left( {{v}_{1},{v}_{2}}\right) ,{R}_{2}\left( {{v}_{2},{v}_{3}}\right)$，因为${v}_{2}$在层次结构中处于最高层级(包含它的原子严格包含任何其他变量所属原子)，必然成为查询树和生成排序中的首个变量。

Finally, we should mention that there are query-ordering pairs that require both jumping back-and-forth in the join tree and visiting the variables in an order different than any hierarchy. As a result, these are not supported by any previous solution. Two such examples are ${Q}_{5}\left( {{v}_{1},{v}_{2},{v}_{3},{v}_{4},{v}_{5}}\right)  :  - {R}_{1}\left( {{v}_{1},{v}_{3}}\right) ,{R}_{2}\left( {{v}_{3},{v}_{4}}\right) ,{R}_{3}\left( {{v}_{2},{v}_{5}}\right)$ and ${Q}_{6}\left( {{v}_{1},{v}_{2},{v}_{3},{v}_{4},{v}_{5}}\right)  :  - {R}_{1}\left( {{v}_{1},{v}_{2},{v}_{4}}\right) ,{R}_{2}\left( {{v}_{2},{v}_{3},{v}_{5}}\right)$ . In Section 3, we provide an algorithm that supports both of these CQs.

最后需要指出，存在某些查询排序组合需要在连接树中来回跳转，并以不同于任何层次结构的顺序访问变量。因此，这些情况是先前所有解决方案都无法支持的。两个典型例子是${Q}_{5}\left( {{v}_{1},{v}_{2},{v}_{3},{v}_{4},{v}_{5}}\right)  :  - {R}_{1}\left( {{v}_{1},{v}_{3}}\right) ,{R}_{2}\left( {{v}_{3},{v}_{4}}\right) ,{R}_{3}\left( {{v}_{2},{v}_{5}}\right)$和${Q}_{6}\left( {{v}_{1},{v}_{2},{v}_{3},{v}_{4},{v}_{5}}\right)  :  - {R}_{1}\left( {{v}_{1},{v}_{2},{v}_{4}}\right) ,{R}_{2}\left( {{v}_{2},{v}_{3},{v}_{5}}\right)$。在第三节中，我们将提出一个能同时支持这两类合取查询的算法。

## 3 DIRECT ACCESS BY LEXICOGRAPHIC ORDERS

## 3 基于字典序的直接访问

In this section, we answer the following question: for which underlying lexicographic orders can we achieve "tractable" direct access to ranked CQ answers, i.e. with quasilinear preprocessing and polylogarithmic time per answer?

本节我们将回答：对于哪些底层字典序可以实现对排序合取查询结果的"易处理"直接访问，即具备拟线性预处理时间和多对数级单结果访问时间？

Example 3.1 (No direct access). Consider the lexicographic order $L = \left\langle  {{v}_{1},{v}_{2},{v}_{3}}\right\rangle$ for the query $Q\left( {{v}_{1},{v}_{2},{v}_{3}}\right)  :  - R\left( {{v}_{1},{v}_{3}}\right) ,S\left( {{v}_{3},{v}_{2}}\right)$ . Direct access to the query answers according to that order would allow us to "jump over" the ${v}_{3}$ values via binary search and essentially enumerate the answers to ${Q}^{\prime }\left( {{v}_{1},{v}_{2}}\right)  :  - R\left( {{v}_{1},{v}_{3}}\right) ,S\left( {{v}_{3},{v}_{2}}\right)$ . However,we know that ${Q}^{\prime }$ is not free-connex and that is impossible to achieve enumeration with quasilinear preprocessing and poly-logarithmic delay (if sparseBMM holds). Therefore, the bounds we are hoping for are out of reach for the given query and order. The core difficulty is that the joining variable ${v}_{3}$ appears after the other two in the lexicographic order.

例3.1（不可直接访问）。考虑查询$Q\left( {{v}_{1},{v}_{2},{v}_{3}}\right)  :  - R\left( {{v}_{1},{v}_{3}}\right) ,S\left( {{v}_{3},{v}_{2}}\right)$的字典序$L = \left\langle  {{v}_{1},{v}_{2},{v}_{3}}\right\rangle$。若允许按该顺序直接访问查询结果，则可通过二分查找"跳过"${v}_{3}$值，本质上相当于枚举${Q}^{\prime }\left( {{v}_{1},{v}_{2}}\right)  :  - R\left( {{v}_{1},{v}_{3}}\right) ,S\left( {{v}_{3},{v}_{2}}\right)$的答案。然而已知${Q}^{\prime }$不属于自由连接查询类，且不可能实现拟线性预处理配合多对数延迟的枚举（在稀疏矩阵乘法猜想成立前提下）。因此，给定查询与排序组合无法达到我们期望的时间复杂度界限。核心难点在于连接变量${v}_{3}$在字典序中排在另外两个变量之后。

We formalize this notion of "variable in the middle" in order to detect similar situations in more complex queries.

我们将形式化这种"中间变量"的概念，以便在更复杂查询中识别类似情况。

Definition 3.2 (Disruptive Trio). Let $Q$ be a CQ and $L$ a lexicographic order of its free variables. We say that three free variables ${u}_{1},{u}_{2},{u}_{3}$ are a disruptive trio in $Q$ with respect to $L$ if ${u}_{1}$ and ${u}_{2}$ are not neighbors (i.e. they don’t appear together in an atom), ${u}_{3}$ is a neighbor of both ${u}_{1}$ and ${u}_{2}$ ,and ${u}_{3}$ anpears after ${u}_{1}$ and ${u}_{2}$ in $L$ .

定义3.2（破坏性三元组）。设$Q$为合取查询，$L$是其自由变量的字典序。若三个自由变量${u}_{1},{u}_{2},{u}_{3}$满足：${u}_{1}$与${u}_{2}$非邻接（即不存在共同出现的原子），${u}_{3}$同时是${u}_{1}$和${u}_{2}$的邻接变量，且在$L$中${u}_{3}$的排序位于${u}_{1}$和${u}_{2}$之后，则称它们构成相对于$L$的破坏性三元组。

As it turns out, when considering free-connex and self-join-free CQs, the tractable CQs are precisely captured by this simple criterion. Regarding self-join-free CQs that are not free-connex, their known intractability of enumeration implies that direct access is also intractable. This leads to the following dichotomy:

研究表明，对于自由连接且无自连接的合取查询，该简单准则可精确刻画易处理查询类。而对于非自由连接的无自连接查询，其枚举的已知难处理性意味着直接访问同样不可行。由此得到以下二分定理：

THEOREM 3.3. Let $Q$ be a ${CQ}$ and $L$ be a lexicographic order.

定理3.3。设$Q$为${CQ}$类查询，$L$为字典序。

- If $Q$ is free-connex and does not have a disruptive trio with respect to $L$ ,then direct access by $L$ is possible in $\langle n\log n,\log n\rangle$ .

- 若$Q$是自由连接查询且相对于$L$不存在破坏性三元组，则可通过$\langle n\log n,\log n\rangle$实现$L$序的直接访问。

- Otherwise,if $Q$ is also self-join-free,then direct access by $L$ is not possible in $\langle n$ polylog $n$ ,polylog $n\rangle$ assuming SPARSEBMM and HypercutIQUE.

- 否则，若$Q$亦无自连接特性，则在假设SPARSEBMM与HypercutIQUE条件下，通过$L$直接访问在$\langle n$多对数时间$n$、多对数空间$n\rangle$内不可行。

REMARK 1. On the positive side of Theorem 3.3, the preprocessing time is dominated by sorting the input relations, which we assume requires $O\left( {n\log n}\right)$ time. If we assume instead that sorting takes linear time (as assumed in some related work $\left\lbrack  {8,{10},{21}}\right\rbrack$ ),then the time required for preprocessing is only $O\left( n\right)$ instead of $O\left( {n\log n}\right)$ .

注记1. 定理3.3的积极方面在于，预处理时间主要消耗在对输入关系进行排序，我们假设该过程需要$O\left( {n\log n}\right)$时间。若改为采用线性时间排序假设（如部分相关研究$\left\lbrack  {8,{10},{21}}\right\rbrack$所述），则预处理所需时间将缩减至$O\left( n\right)$而非$O\left( {n\log n}\right)$。

Then, we show how to find such a layered join tree whenever there is no disruptive trio in Section 3.2. In Section 3.3, we explain how to adapt our solution for CQs with projections, and in Section 3.4 we prove a lower bound which establishes that our algorithm applies to all cases where direct access is tractable.

在第3.1节中，我们针对具有特定连接树（称为分层连接树）的完全无环CQ提出算法。第3.2节将展示如何在无破坏性三元组时构建此类分层连接树。第3.3节阐述如何将解决方案适配至含投影的CQ，第3.4节通过下界证明该算法适用于所有直接访问可行的情况。

### 3.1 Layer-Based Algorithm

### 3.1 基于分层的算法

Before we explain the algorithm, we first define one of its main components. A layered join tree is a join tree where each node belongs to a layer. The layer number matches the position in the lexicographic order of the last variable that the node contains. Intuitively, "peeling" off the outermost (largest) layers must result in a valid join tree (for a hypergraph with fewer variables). To find such a join tree for a CQ $Q$ ,we may have to introduce hyperedges that are contained in those of $\mathcal{H}\left( Q\right)$ (this corresponds to taking the projection of a relation) or remove hyperedges of $\mathcal{H}\left( Q\right)$ that are contained in others (this corresponds to filtering relations that contain a superset of the variables). Thus, we define the layered join tree with respect to a hypergraph that is inclusion equivalent.

在阐述算法前，我们首先定义其核心组件。分层连接树是一种每个节点归属于特定层级的连接树，其层号与该节点包含的末位变量在字典序中的位置相对应。直观而言，"剥离"最外层（最大编号层）后必须仍能形成有效连接树（针对变量更少的超图）。为CQ$Q$构建此类连接树时，可能需要引入包含于$\mathcal{H}\left( Q\right)$的超边（对应关系投影操作）或移除被其他超边包含的$\mathcal{H}\left( Q\right)$超边（对应变量超集的过滤操作）。因此，我们基于包含等价的超图来定义分层连接树。

Definition 3.4 (Layered Join Tree). Let $Q$ be a full acyclic CQ,and let $L = \left\langle  {{v}_{1},\ldots ,{v}_{f}}\right\rangle$ be a lexicographic order. A layered join tree for $Q$ with respect to $L$ is a join tree of a hypergraph that is inclusion equivalent to $\mathcal{H}\left( Q\right)$ where (1) every node $V$ of the tree is assigned to layer $\max \left\{  {i \mid  {v}_{i} \in  V}\right\}$ ,(2) there is exactly one node for each layer, and (3) for all $j \leq  f$ the induced subgraph with only the nodes that belong to the first $j$ layers is a tree.

定义3.4（分层连接树）。设$Q$为完全无环CQ，$L = \left\langle  {{v}_{1},\ldots ,{v}_{f}}\right\rangle$为字典序。关于$L$的分层连接树需满足：(1)每个树节点$V$被分配至$\max \left\{  {i \mid  {v}_{i} \in  V}\right\}$层；(2)每层仅含唯一节点；(3)对于所有$j \leq  f$，仅含前$j$层节点的诱导子图仍为树状结构。该连接树所属超图应与$\mathcal{H}\left( Q\right)$包含等价。

We now describe an algorithm that takes as an input a CQ $Q$ ,a lexicographic order $L$ ,and a corresponding layered join tree and provides direct access to the query answers after a preprocessing phase. 现描述算法：输入合取查询(CQ)$Q$、字典序$L$及对应分层连接树，预处理阶段后可直接访问查询结果。预处理采用Carmeli等人[10，算法2]的构建方法并应用于分层连接树。完整起见，下文简述其原理。随后说明访问阶段如何利用树层级结构适配字典序。需强调本访问方式与既往研究[10]不同，由此支持了原有访问流程无法实现的字典序（如示例3.5的排序）。

Preprocessing. The preprocessing phase (1) creates a relation for every node of the tree, (2) removes dangling tuples, (3) sorts the relations, (4) partitions the relations into buckets, and (5) uses dynamic programming on the tree to compute and store certain counts. After preprocessing,we are guaranteed that for all $i$ ,the node of layer $i$ has a corresponding relation where each tuple participates in at least one query answer; this relation is partitioned into buckets by the assignment of the variables preceding $i$ . In each bucket,we sort the tuples lexicographically by ${v}_{i}$ . Each tuple is given a weight that indicates the number of different answers this tuple agrees with when only joining its subtree. The weight of each bucket is the sum of its tuple weights. We denote both by the function weight. Moreover,for every tuple $t$ ,we compute the sum of weights of the preceding tuples in the bucket,denoted by start(t). We use end(t)for the sum that corresponds to the tuple following $t$ in the same bucket; if $t$ is last,we set this to be the bucket weight. If we think of the query answers in the subtree sorted in the order of ${v}_{i}$ values,then start and end distribute the indices between 0 and the bucket weight to tuples. The number of indices within the range of each tuple corresponds to its weight.

预处理。预处理阶段(1)为树每个节点创建关系(2)移除悬空元组(3)关系排序(4)将关系分区为桶(5)通过树形动态规划计算存储特定计数。预处理后确保：对于所有$i$，第$i$层节点对应的关系中，每个元组至少参与一个查询结果；该关系按$i$前变量的赋值分桶。各桶内元组按${v}_{i}$字典序排列。每个元组被赋予权重，表示仅连接其子树时该元组匹配的不同结果数。桶权重为其元组权重之和，记作weight函数。此外，对每个元组$t$，计算同桶前驱元组权重和记作start(t)，末位元组的end(t)设为桶权重。若将子树查询结果按${v}_{i}$值排序，则start与end将0至桶权重的索引区间分配给元组，各元组索引范围大小对应其权重。

Access. The access phase works by going through the tree layer by layer. When resolving a layer $i$ ,we select a tuple from its corresponding relation,which sets a value for the $i$ th variable in $L$ ,and also determines a bucket for each child. Then, we erase the node of layer $i$ and its outgoing edges.

访问阶段。访问阶段通过逐层遍历树结构进行。当解析$i$层时，我们从对应关系中选择一个元组，该元组为$L$中的第$i$个变量设定值，并为每个子节点确定一个桶。随后删除$i$层节点及其出边。

The access algorithm maintains a directed forest and an assignment to a prefix of the variables. Each tree in the forest represents the answers obtained by joining its relations. Each root contains a single bucket that agrees with the already assigned values, thus every answer agrees on the prefix. Due to the running intersection property, different trees cannot share unassigned variables. As a consequence, any combination of answers from different trees can be added to the prefix assignment to form an answer to $Q$ . The answers obtained this way are exactly the answers to $Q$ that agree with the already set assignment. Since we start with a layered join tree, we are guaranteed that at each step, the next layer (which corresponds to the variable following the prefix for which we have an assignment) appears as a root in the forest.

访问算法维护一个有向森林和部分变量赋值。森林中每棵树代表通过关系连接获得的答案。每个根节点包含与已赋值匹配的单个桶，因此所有答案在已赋值部分保持一致。由于运行交集性质，不同树不能共享未赋值变量。因此，不同树答案的任意组合都可添加到当前赋值中，形成$Q$的完整答案。如此获得的答案正是与当前赋值匹配的$Q$解。由于我们从分层连接树出发，可确保每一步中下一层（对应赋值变量后的首个未赋值变量）始终作为森林中的根节点出现。

Recall that from the preprocessing phase, the weight of each root is the number of answers in its tree. When we are at layer $i$ ,we have to take into account the weights of all the other roots in order to compute the number of query answers for a particular tuple. More specifically,the number of answers to $Q$ containing the already selected attributes (smaller than $i$ ) and some ${v}_{i}$ value contained in a tuple is found by multiplying the tuple weight with the weights of all other roots. That is because the answers from all trees can be combined into a query answer. Let $t$ be the selected tuple when resolving the ${i}^{\text{th }}$ layer. The number of answers to $Q$ that have a value of $L\left\lbrack  i\right\rbrack$ smaller than that of $t$ and a value of $L\left\lbrack  j\right\rbrack$ equal to that of $t$ for all $j < i$ is then:

回顾预处理阶段，每个根节点的权重即其子树包含的答案数量。处理$i$层时，需综合所有其他根节点权重来计算特定元组对应的查询答案数。具体而言，计算既包含已选属性（序号小于$i$）又包含某元组中${v}_{i}$值的$Q$答案数时，需将该元组权重与其他所有根节点权重相乘——因为各子树的答案可自由组合成查询解。设$t$是解析${i}^{\text{th }}$层时选定的元组，则满足以下条件的$Q$答案数量为：所有$j < i$对应的$L\left\lbrack  i\right\rbrack$值小于$t$且$L\left\lbrack  j\right\rbrack$值等于$t$的解数目为：

$$
\mathop{\sum }\limits_{{t}^{\prime }}\left( {\text{weight}\left( {t}^{\prime }\right) \mathop{\prod }\limits_{{r \in  \text{roots}}}\text{weight}\left( r\right) }\right) 
$$

where ${t}^{\prime }$ ranges over tuples preceding $t$ in its bucket. Denote by factor the product of all root weights. Then we can rewrite as:

其中${t}^{\prime }$遍历该桶中$t$之前的所有元组。令factor表示所有根节点权重的乘积，则可改写为：

$$
\left( {\mathop{\sum }\limits_{{t}^{\prime }}\operatorname{weight}\left( {t}^{\prime }\right) }\right) \left( {\mathop{\prod }\limits_{{r \in  \text{ roots }}}\operatorname{weight}\left( r\right) }\right)  = \operatorname{start}\left( t\right)  \cdot  \text{ factor }.

### 3.2 Finding Layered Join Trees

### 3.2 寻找分层连接树

We now have an algorithm that can be applied whenever we have a layered join tree. We next show that the existence of such a join tree relies on the disruptive trio condition we introduced earlier. In particular, if no disruptive trio exists, we are able to construct a layered join tree for full acyclic CQs.

我们现在拥有一个可应用于任何分层连接树的算法。接下来证明，此类连接树的存在性依赖于前文提出的破坏性三元组条件。特别地，若不存在破坏性三元组，我们能为完全无环CQ构建分层连接树。

LEMMA 3.9. Let $Q$ be a full acyclic ${CQ}$ ,and $L$ be a lexicographic order. If $Q$ does not have a disruptive trio with respect to $L$ ,then there is a layered join tree for $Q$ with respect to $L$ .

引理3.9。设$Q$为完全无环的${CQ}$，$L$为字典序。若$Q$关于$L$不存在破坏性三元组，则存在$Q$关于$L$的分层连接树。

Proof. We show by induction on $i$ that there exists a layered join tree for the hypergraph containing the hyperedges $\left\{  {V \cap  \left\{  {{v}_{1},\ldots ,{v}_{i}}\right\}   \mid  V \in  \operatorname{atoms}\left( Q\right) }\right\}$ with respect to the prefix of $L$ containing its first $i$ elements. The induction base is the tree that contains the node $\left\{  {v}_{1}\right\}$ and no edges.

证明。通过对$i$的归纳，我们证明存在包含超边$\left\{  {V \cap  \left\{  {{v}_{1},\ldots ,{v}_{i}}\right\}   \mid  V \in  \operatorname{atoms}\left( Q\right) }\right\}$的超图关于$L$前$i$个元素前缀的分层连接树。归纳基是仅含节点$\left\{  {v}_{1}\right\}$且无边的树。

In the inductive step,we assume a layered join tree with $i - 1$ layers for $\left\{  {V \cap  \left\{  {{v}_{1},\ldots ,{v}_{i - 1}}\right\}   \mid  V \in  \operatorname{atoms}\left( Q\right) }\right\}$ ,and we build a layer on top of it. Denote by $\mathcal{V}$ the sets of $\left\{  {V \cap  \left\{  {{v}_{1},\ldots ,{v}_{i}}\right\}  }\right\}$ $V \in  \operatorname{atoms}\left( Q\right) \}$ that contain ${v}_{i}$ (these are the sets that need to be included in the new layer). First note that $\mathcal{V}$ is acyclic. Indeed,by the running intersection property,the join tree for $\mathcal{H}\left( Q\right)$ has a subtree with all the nodes that contain ${v}_{i}$ . By taking this subtree and projecting out all variables that occur after ${v}_{i}$ in $L$ ,we get a join tree for an inclusion equivalent hypergraph to $\mathcal{V}$ ,and its existence proves that $\mathcal{V}$ is acyclic.

归纳步骤中，我们假设已有$\left\{  {V \cap  \left\{  {{v}_{1},\ldots ,{v}_{i - 1}}\right\}   \mid  V \in  \operatorname{atoms}\left( Q\right) }\right\}$的$i - 1$层分层连接树，并在其顶部构建新层。用$\mathcal{V}$表示包含${v}_{i}$的$\left\{  {V \cap  \left\{  {{v}_{1},\ldots ,{v}_{i}}\right\}  }\right\}$$V \in  \operatorname{atoms}\left( Q\right) \}$集合（这些集合需包含在新层中）。首先注意$\mathcal{V}$是无环的——根据运行交集性质，$\mathcal{H}\left( Q\right)$的连接树存在包含所有含${v}_{i}$节点的子树。通过提取该子树并投影掉$L$中${v}_{i}$之后出现的所有变量，我们得到与$\mathcal{V}$等包含超图的连接树，其存在性证明了$\mathcal{V}$的无环性。

We next claim that some set in $\mathcal{V}$ contains all the others; that is, there exists ${V}_{m} \in  \mathcal{V}$ such that for all $V \in  \mathcal{V}$ ,we have that $V \subseteq  {V}_{m}$ . Consider a join-tree for $\mathcal{V}$ . Every variable of $\mathcal{V}$ defines a subtree induced by the nodes that contain this variable. If two variables are neighbors, their subtrees share a node. It is known that every collection of subtrees of a tree satisfies the Helly property [19]: if every two subtrees share a node, then some node is shared by all subtrees. In particular,since $\mathcal{V}$ is acyclic,if every two variables of $\mathcal{V}$ are neighbors,then some element of $\mathcal{V}$ contains all variables that appear in (elements of) $\mathcal{V}$ . Thus,if,by way of contradiction,there is no such ${V}_{m}$ ,there exist two non-neighboring variables ${v}_{a}$ and ${v}_{b}$ that appear in (elements of) $\mathcal{V}$ . Since ${v}_{i}$ appears in all elements of $\mathcal{V}$ ,this means that there exist ${V}_{a},{V}_{b} \in  \mathcal{V}$ with $\left\{  {{v}_{a},{v}_{i}}\right\}   \subseteq  {V}_{a}$ and $\left\{  {{v}_{b},{v}_{i}}\right\}   \subseteq  {V}_{b}$ . Since ${v}_{a}$ and ${v}_{b}$ are not neighbors,these three variables are a disruptive trio with respect to $L : {v}_{a}$ and ${v}_{b}$ are both neighbors of the later variable ${v}_{i}$ . The existence of a disruptive trio contradicts the assumption of the lemma we are proving, and so we conclude that there is ${V}_{m} \in  \mathcal{V}$ such that for all $V \in  \mathcal{V}$ ,we have that $V \subseteq  {V}_{m}$ .

我们接下来断言，集合$\mathcal{V}$中存在某个子集包含所有其他元素；即存在${V}_{m} \in  \mathcal{V}$使得对于所有$V \in  \mathcal{V}$，都有$V \subseteq  {V}_{m}$。考虑$\mathcal{V}$的连接树，该集合中每个变量都定义了一个由包含该变量的节点诱导的子树。若两个变量相邻，则它们的子树共享一个节点。已知树的子树集合满足Helly性质[19]：若每两棵子树都共享一个节点，则存在某个节点被所有子树共享。特别地，由于$\mathcal{V}$是无环的，若$\mathcal{V}$中每两个变量都相邻，则存在某个元素包含$\mathcal{V}$中出现的所有变量。因此，若反设不存在这样的${V}_{m}$，则存在两个不相邻的变量${v}_{a}$和${v}_{b}$出现在$\mathcal{V}$的元素中。由于${v}_{i}$出现在$\mathcal{V}$的所有元素中，这意味着存在${V}_{a},{V}_{b} \in  \mathcal{V}$满足$\left\{  {{v}_{a},{v}_{i}}\right\}   \subseteq  {V}_{a}$和$\left\{  {{v}_{b},{v}_{i}}\right\}   \subseteq  {V}_{b}$。由于${v}_{a}$与${v}_{b}$不相邻，这三个变量相对于$L : {v}_{a}$构成破坏性三元组，且${v}_{b}$与后置变量${v}_{i}$相邻。破坏性三元组的存在与我们正在证明的引理假设矛盾，故可推出存在${V}_{m} \in  \mathcal{V}$使得对于所有$V \in  \mathcal{V}$都有$V \subseteq  {V}_{m}$。

With ${V}_{m}$ at hand,we can now add the additional layer to the tree given by the inductive hypothesis. By the inductive hypothesis, the layered join tree with $i - 1$ layers contains the hyperedge ${V}_{m} \cap$ $\left\{  {{v}_{1},\ldots ,{v}_{i - 1}}\right\}   = {V}_{m} \smallsetminus  \left\{  {v}_{i}\right\}$ . We insert ${V}_{m}$ with an edge to the node containing ${V}_{m} \smallsetminus  \left\{  {v}_{i}\right\}$ . This results in the join tree we need: (1) the hyperedges $\left\{  {V \cap  \left\{  {{v}_{1},\ldots ,{v}_{i}}\right\}   \mid  V \in  \operatorname{atoms}\left( Q\right) }\right\}$ are all contained in nodes, since the ones that do not appear in the tree from the inductive hypothesis are contained in the new node; (2) it is a tree since we add one leaf to an existing tree; and (3) the running intersection property holds since the added node is connected to all of its variables that already appear in the tree.

根据归纳假设，我们现在可以为已有树结构添加${V}_{m}$对应的新层级。该具有$i - 1$个层级的分层连接树包含超边${V}_{m} \cap$$\left\{  {{v}_{1},\ldots ,{v}_{i - 1}}\right\}   = {V}_{m} \smallsetminus  \left\{  {v}_{i}\right\}$。我们将${V}_{m}$插入并与包含${V}_{m} \smallsetminus  \left\{  {v}_{i}\right\}$的节点相连，从而得到所需的连接树：(1) 超边$\left\{  {V \cap  \left\{  {{v}_{1},\ldots ,{v}_{i}}\right\}   \mid  V \in  \operatorname{atoms}\left( Q\right) }\right\}$均被包含在节点中，因为未出现在归纳假设树中的边都包含在新节点内；(2) 通过向现有树添加叶节点仍保持树结构；(3) 运行相交性质成立，因为新增节点已与树中现存的所有相关变量建立连接。

Lemmas 3.8 and 3.9 give a direct-access algorithm for full acyclic CQs and lexicographic orders without disruptive trios.

引理3.8和3.9为无破坏性三元组的完全无环CQ（合取查询）及字典序提供了直接访问算法。

### 3.3 Supporting Projection

### 3.3 支持投影操作

Next, we show how to support CQs that have projections. A free-connex CQ can be efficiently reduced to a full acyclic CQ using Proposition 2.1. We next show that the resulting CQ contains no disruptive trio if the original CQ does not.

接下来我们将展示如何支持含投影的CQ。根据命题2.1，自由连接CQ可被高效规约为完全无环CQ。我们将证明：若原CQ不含破坏性三元组，则规约后的CQ也不会包含。

LEMMA 3.10. Given a database instance $I$ ,a free-connex ${CQQ}$ , and a lexicographic order $L$ with no disruptive trio with respect to $L$ ,we can compute in linear time a database instance ${I}^{\prime }$ and a full acyclic ${CQ}{Q}^{\prime }$ with no disruptive trio with respect to $L$ such that ${Q}^{\prime }\left( {I}^{\prime }\right)  = Q\left( I\right) ,\left| {I}^{\prime }\right|  \leq  \left| I\right|$ ,and ${Q}^{\prime }$ does not depend on $I$ or ${I}^{\prime }$ .

引理3.10. 给定数据库实例$I$、自由连接查询${CQQ}$以及关于$L$无破坏性三元组的字典序$L$，我们可在线性时间内计算出数据库实例${I}^{\prime }$和关于$L$无破坏性三元组的完全无环结构${CQ}{Q}^{\prime }$，使得${Q}^{\prime }\left( {I}^{\prime }\right)  = Q\left( I\right) ,\left| {I}^{\prime }\right|  \leq  \left| I\right|$成立，且${Q}^{\prime }$不依赖于$I$或${I}^{\prime }$。

Proof. See Appendix A.1. $\square$

证明. 见附录A.1.$\square$

By combining Lemmas 3.8 to 3.10, we conclude an efficient algorithm for CQs and orders with no disruptive trios. The next lemma summarizes our results so far.

综合引理3.8至3.10，我们得出针对无破坏性三元组的联合查询与排序的高效算法。以下引理总结当前研究成果。

LEMMA 3.11. Let $Q$ be a ${CQ}$ ,and $L$ be a lexicographic order. If $Q$ does not have a disruptive trio with respect to $L$ ,direct access by $L$ is possible in $\langle n\log n,\log n\rangle$ .

### 3.4 联合查询的下界

接下来证明我们的算法支持所有可处理情形（针对无自连接联合查询），并证实所有未支持情形均不可处理。

## 4 PARTIAL LEXICOGRAPHIC ORDERS

## 4 部分字典序

We now investigate the case where the desired lexicographic order is partial, i.e., it contains only some of the free variables. This means that there is no particular order requirement for the rest of the variables. One way to achieve direct access to a partial order is to complete it into a full lexicographic order and then leverage the results of the previous section. If such a completion is impossible, we have to consider cases where tie breaking between the non-ordered variables is done in an arbitrary way. However, we will show in this section that the tractable partial orders are precisely those that can be completed into a full lexicographic order. In particular, we will prove the following dichotomy which also gives an easy-to-detect criterion for the tractability of direct access.

本节研究部分字典序情形，即排序仅包含部分自由变量。这意味着其余变量无特定顺序要求。实现部分序直接访问的一种方法是将其补全为完整字典序，然后应用前文结论。若无法补全，则需考虑非排序变量间任意断点的情况。本节将证明，可处理的部分序恰好是那些可补全为完整字典序的情形，并通过以下二象性定理给出直接访问可处理性的简易判定标准。

THEOREM 4.1. Let $Q$ be a ${CQ}$ and $L$ be a partial lexicographic order.

定理4.1. 设$Q$为${CQ}$，$L$为部分字典序。

- If $Q$ is free-connex and $L$ -connex and does not have a disruptive trio with respect to $L$ ,then direct access by $L$ is possible in $\langle n\log n,\log n\rangle$ .

- 若$Q$为自由连接且$L$连通，且关于$L$无破坏性三元组，则通过$L$的直接访问可在$\langle n\log n,\log n\rangle$时间内实现。

- Otherwise,if $Q$ is also self-join-free,then direct access by $L$ is not possible in $\langle n$ polylog $n$ ,polylog $n\rangle$ ,assuming SPARSEBMM and HypERCLIQUE.

- 否则，若$Q$同时无自连接，则在SPARSEBMM与HypERCLIQUE假设下，通过$L$的直接访问不可能在$\langle n$拟对数时间、$n$拟对数空间内实现。

Example 4.2. Consider the CQ ${Q}_{7} :  - \left( {x,y}\right) ,S\left( {y,z}\right)$ . If the free variables are exactly $x$ and $z$ ,then the query is not free-connex, and so it is intractable. Next assume that all variables are free. If $L = \langle x,z\rangle$ ,then the query is not $L$ -connex,and so it is intractable. If $L = \langle x,z,y\rangle$ ,then $x,z,y$ is a disruptive trio,thus the query is intractable. However,if $L = \langle x,y,z\rangle$ or $L = \langle z,y\rangle$ ,then the query is free-connex, $L$ -connex and has no disruptive trio,so it is tractable.

例4.2 考虑CQ查询${Q}_{7} :  - \left( {x,y}\right) ,S\left( {y,z}\right)$。若自由变量仅为$x$和$z$，则该查询非自由连接，故不可高效求解。假设所有变量皆自由：当$L = \langle x,z\rangle$时，查询不满足$L$连接性，故不可解；若$L = \langle x,z,y\rangle$，则$x,z,y$构成破坏性三元组导致查询不可解。但当$L = \langle x,y,z\rangle$或$L = \langle z,y\rangle$时，查询同时满足自由连接性、$L$连接性且无破坏性三元组，因此可高效求解。

### 4.1 Tractable Cases

### 4.1 可高效求解的情形

For the positive side, we can solve our problem efficiently if the CQ is free-connex and there is a completion of the lexicographic order to all free variables with no disruptive trio. Lemma 4.4 identifies these cases with a connexity criterion. To prove it, we first need a way to combine two different connexity properties. The proof of the following proposition uses ideas from a proof of the characterization of free-connex CQs in terms of the acyclicity of the hypergraph obtained by including a hyperedge with the free variables [5].

在积极情况下，当CQ查询满足自由连接性且词典序可扩展至所有自由变量而不产生破坏性三元组时，问题可高效求解。引理4.4通过连接性准则识别这些情形。为证明该引理，我们首先需要融合两种不同连接特性的方法。下述命题的证明借鉴了文献[5]中通过引入自由变量超边来判定自由连接CQ超图无环性的论证思路。

Proposition 4.3. ### 4.2 Intractable Cases

### 4.2 难解情形

For the negative part, we prove a generalization of Lemma 3.12. For that, we use the hardness of Boolean matrix multiplication with a construction that is similar to that of Bagan et al. [3] for the hardness of enumeration on acyclic CQs that are not free-connex.

对于负面部分，我们推广了引理3.12的证明。为此采用布尔矩阵乘法的难解性构造，该方法类似于Bagan等人[3]关于非自由连接无环CQ枚举难解性的证明。

LEMMA 4.5. Let $Q$ be a self-join-free ${CQ}$ and $L$ be a partial lexicographic order. 引理4.5. 设$Q$为无自连接的${CQ}$，$L$为部分字典序。若存在无弦路径${u}_{1},{z}_{1},\ldots ,{z}_{k},{u}_{2}$使得${u}_{1}$与${u}_{2}$在$L$中出现，且无变量${z}_{i}$在$L$中先于它们出现，则在假设SPARSEBMM条件下，无法通过$L$在$\langle n$多重对数$n$或$n\rangle$时间内实现直接访问。

Proof. Let ${U}_{3} = \left\{  {{z}_{1},\ldots ,{z}_{k}}\right\}$ . We encode Boolean matrix multiplication with $Q$ such that,in the answers to $Q$ ,the assignments to ${u}_{1}$ and ${u}_{2}$ form the answers to the given matrix multiplication instance,the assignments to variables of ${U}_{3}$ can be skipped using binary search (given direct access), and all other variables are assigned a constant value $\bot$ .

证明. 设${U}_{3} = \left\{  {{z}_{1},\ldots ,{z}_{k}}\right\}$。我们通过$Q$对布尔矩阵乘法进行编码，使得在$Q$的解答中，对${u}_{1}$和${u}_{2}$的赋值构成给定矩阵乘法实例的解，对${U}_{3}$变量的赋值可通过二分搜索跳过（给定直接访问），其余变量均赋常数值$\bot$。

That is, $A \subseteq  \{ 1,\ldots ,n{\} }^{2}$ ,and $\left( {a,b}\right)  \in  A$ means that the entry in the $a$ th row and $b$ th column is 1 . We define a partition of the atoms of $Q$ where ${\mathcal{R}}_{A}$ is the set of all atoms that contain ${u}_{1}$ ,and ${\mathcal{R}}_{B}$ holds all other atoms. Note that no atom in ${\mathcal{R}}_{A}$ contains ${u}_{2}$ (since ${u}_{1}$ and ${u}_{2}$ are not neighbors) and no atom in ${\mathcal{R}}_{B}$ contains ${u}_{1}$ . Given three values(a,b,c),we define a function ${\tau }_{\left( a,b,c\right) } : \operatorname{var}\left( Q\right)  \rightarrow$ $\{ a,b,c, \bot  \}$ as follows:

设$A$和$B$为表示为二元关系的布尔$n \times  n$矩阵。即$A \subseteq  \{ 1,\ldots ,n{\} }^{2}$，且$\left( {a,b}\right)  \in  A$表示第$a$行第$b$列元素为1。我们定义$Q$原子的划分：${\mathcal{R}}_{A}$包含所有含${u}_{1}$的原子，${\mathcal{R}}_{B}$包含其余原子。注意${\mathcal{R}}_{A}$中原子不含${u}_{2}$（因${u}_{1}$与${u}_{2}$非邻接），${\mathcal{R}}_{B}$中原子不含${u}_{1}$。给定三元组(a,b,c)，定义函数${\tau }_{\left( a,b,c\right) } : \operatorname{var}\left( Q\right)  \rightarrow$$\{ a,b,c, \bot  \}$如下：

$$
{\tau }_{\left( a,b,c\right) }\left( v\right)  = \left\{  \begin{array}{ll} a & \text{ if }v = {u}_{1}, \\  b & \text{ if }v \in  {U}_{3}, \\  c & \text{ if }v = {u}_{2}, \\   \bot  & \text{ otherwise,} \end{array}\right.

Since ${U}_{3}$ is connected,our construction guarantees that in every answer to $Q$ all ${U}_{3}$ variables are assigned the same value. Then, set $i$ to be the index of the next answer which assigns $\left( {{u}_{1},{u}_{2}}\right)$ to different values and repeat. Therefore, we obtain that the last two cases are hard too, assuming the SPARSEBMM hypothesis.

二分法的消极部分包含三种情况。首先，若$Q$非自由连通，则根据定理2.2，任何顺序的直接访问都是难解的。其次，若$Q$存在相对于$L$的破坏性三元组${u}_{1},{u}_{2},{u}_{3}$，则${u}_{1},{u}_{3},{u}_{2}$构成满足引理4.5条件的无弦路径。最后一种情况是$Q$非$L$连通，此时存在$L$路径且该路径满足引理4.5条件。因此在SPARSEBMM假设下，后两种情况同样属于难解问题。

## 5 DIRECT ACCESS BY SUM OF WEIGHTS

## 5 基于权重和的直接访问

We now consider direct access for the more general orderings based on ${\sum w}$ (the sum of attribute weights). As with lexicographic orderings, we are able to exhaustively classify the self-join-free CQs, even those with projections, in terms of tractability. We will show that direct access for ${\sum w}$ is significantly harder and tractable only for a small class of queries.

我们现在研究基于${\sum w}$（属性权重和）的更通用排序的直接访问问题。与字典序类似，即使对于含投影的自连接无关联合查询，我们也能完整划分其可解性。我们将证明${\sum w}$的直接访问难度显著更高，仅对少量查询类别可解。

### 5.1 Overview of Results

### 5.1 结果概览

The main result of this section is a dichotomy for direct access by ${\sum w}$ ordering:

本节主要成果是${\sum w}$排序的直接访问二分定理：

THEOREM 5.1. Let $Q$ be a ${CQ}$ and $w$ be a weight function.

定理5.1. 设$Q$为${CQ}$，$w$为权重函数。

- If $Q$ is acyclic and an atom of $Q$ contains all the free variables, then direct access by ${\sum w}$ is possible in $\langle n\log n,1\rangle$ .

- 若$Q$为无环查询且其某个原子包含全部自由变量，则${\sum w}$排序的直接访问可在$\langle n\log n,1\rangle$时间内实现。

- Otherwise,if $Q$ is also self-join-free,direct access by ${\sum w}$ is not possible in $\langle n$ polylog $n$ ,polylog $n\rangle$ ,assuming $3\mathrm{{SUM}}$ and HYPERCLIQUE.

- 否则，若$Q$亦无自连接，则在$\langle n$多对数$n$、多对数$n\rangle$中无法通过${\sum w}$直接访问（假设$3\mathrm{{SUM}}$与HYPERCLIQUE成立）。

The proof of the negative part of the above theorem requires the query answers to express certain combinations of weights. If the query contains independent free variables, then its answers may contain all possible combinations of their corresponding attribute weights. We will thus rely on this independence measure to identify hard cases.

上述定理的否定部分证明要求查询结果能表达特定的权重组合。若查询包含独立自由变量，则其答案可能包含对应属性权重的所有可能组合。我们将基于此独立性度量来识别困难案例。

Definition 5.2 (Independent free variables). A set of vertices ${V}_{I} \subseteq$ $V$ of a hypergraph $\mathcal{H}\left( {V,E}\right)$ is called independent iff no pair of these vertices appears in the same hyperedge,i.e., $\left| {{V}_{I} \cap  e}\right|  \leq  1$ for all $e \in  E$ . For a $\mathrm{{CQ}}Q$ ,we denote by ${\alpha }_{\text{free }}\left( Q\right)$ the maximum number of variables among free(Q)that are independent in $\mathcal{H}\left( Q\right)$ .

定义5.2（独立自由变量）。超图$\mathcal{H}\left( {V,E}\right)$的顶点集${V}_{I} \subseteq$$V$称为独立的，当且仅当这些顶点中无任何两个出现在同一条超边中，即对所有$e \in  E$有$\left| {{V}_{I} \cap  e}\right|  \leq  1$。对于$\mathrm{{CQ}}Q$，我们用${\alpha }_{\text{free }}\left( Q\right)$表示free(Q)中在$\mathcal{H}\left( Q\right)$内独立的最大变量数。

Intuitively, we can construct a database instance where each independent free variable is assigned to $n$ different domain values with $n$ different weights. By appropriately choosing the assignment of the other variables,all possible ${n}^{{\alpha }_{\text{free }}\left( Q\right) }$ combinations of these weights will appear in the query answers. Providing direct access then implies that we can retrieve these sums in ranked order.

直观上，可构造一个数据库实例，其中每个独立自由变量被赋予$n$个不同域值及$n$个不同权重。通过适当设置其他变量赋值，这些权重的所有${n}^{{\alpha }_{\text{free }}\left( Q\right) }$种组合都将出现在查询结果中。实现直接访问意味着我们能按序检索这些加权和。

Example 5.3. For ${Q}_{8}\left( {x,y,z}\right)  :  - R\left( {x,z}\right) ,S\left( {z,y}\right) ,T\left( {y,u}\right)$ ,we have ${\alpha }_{\text{free }}\left( {Q}_{8}\right)  = 2$ ,namely for variables $\{ x,y\}$ . If the database instance is $R = \left\lbrack  {1,n}\right\rbrack   \times  \{ 0\} ,S = \{ 0\}  \times  \left\lbrack  {1,n}\right\rbrack  ,T = \left\lbrack  {1,n}\right\rbrack   \times  \{ 0\}$ ,then the ${n}^{2}$ query answers are $\left\lbrack  {1,n}\right\rbrack   \times  \left\lbrack  {1,n}\right\rbrack   \times  \{ 0\}$ . The $n$ values of $x$ and $y$ can be respectively assigned to any real-valued weights such that direct access on ${Q}_{8}$ retrieves their ${i}^{\text{th }}$ sum in ranked order.

例5.3。对于${Q}_{8}\left( {x,y,z}\right)  :  - R\left( {x,z}\right) ,S\left( {z,y}\right) ,T\left( {y,u}\right)$，存在${\alpha }_{\text{free }}\left( {Q}_{8}\right)  = 2$个独立变量（即变量$\{ x,y\}$）。若数据库实例为$R = \left\lbrack  {1,n}\right\rbrack   \times  \{ 0\} ,S = \{ 0\}  \times  \left\lbrack  {1,n}\right\rbrack  ,T = \left\lbrack  {1,n}\right\rbrack   \times  \{ 0\}$，则${n}^{2}$个查询结果为$\left\lbrack  {1,n}\right\rbrack   \times  \left\lbrack  {1,n}\right\rbrack   \times  \{ 0\}$。$x$与$y$的$n$值可分别赋任意实数权重，使得对${Q}_{8}$的直接访问能按序检索其${i}^{\text{th }}$加权和。

Our independence measure ${\alpha }_{\text{free }}\left( Q\right)$ is related to the classification of Theorem 5.1 in the following way:

我们的独立性度量${\alpha }_{\text{free }}\left( Q\right)$与定理5.1的分类存在如下关联：

LEMMA 5.4. For an acyclic ${CQQ}$ ,an atom contains all the free variables iff ${\alpha }_{\text{free }}\left( Q\right)  \leq  1$ .

引理5.4。对于无环查询${CQQ}$，一个原子包含所有自由变量当且仅当${\alpha }_{\text{free }}\left( Q\right)  \leq  1$成立。

Proof. See Appendix A.3.

证明。见附录A.3。

Therefore, the dichotomy of Theorem 5.1 can equivalently be stated using ${\alpha }_{\text{free }}\left( Q\right)  \leq  1$ as a criterion. We chose to use the other criterion (all free variables contained in one atom) in the statement of our theorem statement as it is more straightforward to check. In the next section, we proceed to prove our theorem by showing intractability for all queries with ${\alpha }_{\text{free }}\left( Q\right)  > 1$ .

因此，定理5.1的二分性等价于采用${\alpha }_{\text{free }}\left( Q\right)  \leq  1$作为判定标准。我们选择在定理陈述中使用另一标准（所有自由变量包含于单个原子中），因其更便于验证。下节将通过证明所有满足${\alpha }_{\text{free }}\left( Q\right)  > 1$的查询均存在计算困难性来完成定理证明。

### 5.2 Proofs

### 5.2 证明

For the hardness results, we rely mainly on the 3Sum hypothesis. To more easily relate our direct-access problem to $3\mathrm{{SUM}}$ ,which asks for the existence of a particular sum of weights, it is useful to define an auxiliary problem:

对于困难性结果，我们主要基于3Sum假设。为更便捷地将直接访问问题与$3\mathrm{{SUM}}$（要求特定权重和存在）相关联，可定义辅助问题：

Definition 5.5 (weight lookup). Given a CQ $Q$ ,weight function $w$ ,and $\lambda  \in  \mathbb{R}$ ,weight lookup by ${\sum w}$ returns the first position of a query answer $q$ of weight $w\left( q\right)  = \lambda$ in the sorted array of answers.

定义5.5（权重查找）。给定一个连续查询$Q$、权重函数$w$及$\lambda  \in  \mathbb{R}$，通过${\sum w}$进行的权重查找将返回排序后的答案数组中，具有权重$w\left( q\right)  = \lambda$的查询答案$q$的首个出现位置。

The following lemma associates direct access with weight lookup via binary search on the query answers:

以下引理通过查询答案上的二分搜索，将直接访问与权重查找关联起来：

LEMMA 5.6. If the ${k}^{\text{th }}$ query answer according to some ranking function can be directly accessed in $O\left( {{T}_{d}\left( n\right) }\right)$ time for every $k$ ,then weight lookup can be performed in $O\left( {{T}_{d}\left( n\right) \log n}\right)$ .

引理5.6. 若根据某排序函数的${k}^{\text{th }}$查询答案可在$O\left( {{T}_{d}\left( n\right) }\right)$时间内直接访问，则权重查找可在$O\left( {{T}_{d}\left( n\right) \log n}\right)$时间内完成。

Proof. See Appendix A.4.

证明. 见附录A.4。

Lemma 5.6 implies that whenever we are able to support efficient direct access on the sorted array of query answers, weight lookup increases time complexity only by a logarithmic factor, i.e., it is also efficient. The main idea behind our reductions is that via weight lookups on a CQ with an appropriately constructed database, we can decide the existence of a zero-sum triplet over three distinct sets of numbers, thus hardness follows from 3SUM. First, we consider the case of three independent variables that are free. These three variables are able to simulate a three-way Cartesian product in the query answers. This allows us to directly encode the 3SUM triplets using attribute weights, obtaining a lower bound for direct access.

引理5.6表明，只要我们能支持对排序后的查询答案数组进行高效直接访问，权重查找仅会使时间复杂度增加对数级因子，即仍保持高效。我们归约的核心思想是：通过在适当构建的数据库上对CQ进行权重查找，可以判定三个不同数集中是否存在零和三元组，从而由3SUM问题导出计算难度。首先考虑三个自由独立变量的情况，这三个变量能在查询答案中模拟三维笛卡尔积，使我们能直接用属性权重编码3SUM三元组，从而得到直接访问的下界。

LEMMA 5.7. If a ${CQQ}$ is self-join-free and ${\alpha }_{\text{free }}\left( Q\right)  \geq  3$ ,then direct access by ${\sum w}$ is not possible in $\left\langle  {{n}^{2 - \epsilon },{n}^{2 - \epsilon }}\right\rangle$ for any $\epsilon  > 0$ assuming 3SUM.

引理5.7. 若${CQQ}$无自连接且${\alpha }_{\text{free }}\left( Q\right)  \geq  3$，则在3SUM假设下，任何$\epsilon  > 0$都无法在$\left\langle  {{n}^{2 - \epsilon },{n}^{2 - \epsilon }}\right\rangle$时间内实现按${\sum w}$的直接访问。

Proof. Assume for the sake of contradiction that the lemma does not hold. We show that this would imply an $O\left( {n}^{2 - \epsilon }\right)$ -time algorithm for 3Sum. To this end, consider an instance of 3Sum with integer sets $A,B$ ,and $C$ of size $n$ ,given as arrays. We reduce 3SUM to direct access over the appropriate query and input instance by using a construction similar to Example 5.3. Let $x,y$ ,and $z$ be free and independent variables of $Q$ ,which exist because ${\alpha }_{\text{free }}\left( Q\right)  \geq  3$ . We create a database instance where $x,y$ ,and $z$ take on each value in $\left\lbrack  {1,n}\right\rbrack$ ,while all the other attributes have value 0 . This ensures that $Q$ has exactly ${n}^{3}$ answers-one for each(x,y,z)combination in ${\left\lbrack  1,n\right\rbrack  }^{3}$ ,no matter the number of atoms and the variables they contain. To see this,note that since $x,y$ ,and $z$ are independent,they never appear together in an atom. Also,since $Q$ is self-join-free, each relation appears once in the query, hence contains at most one of $x,y$ ,and $z$ . Thus each relation either contains 1 tuple (if neither $x,y$ ,nor $z$ is present) or $n$ tuples (if one of $x,y$ ,or $z$ is present). No matter on which attributes these relations are joined (including Cartesian products), the output result is always the "same" set ${\left\lbrack  1,n\right\rbrack  }^{3} \times  \{ 0{\} }^{f}$ of size ${n}^{3}$ ,where $f$ is the number of free variables other than $x,y$ ,and $z$ . (We use the term "same" loosely for the sake of simplicity. Clearly,for different values of $f$ the query-result schema changes,e.g.,consider Example 5.3 with $z$ removed from the head. However, this only affects the number of additional 0s in each of the ${n}^{3}$ answer tuples,therefore it does not impact our construction.)

证明. 假设引理不成立。我们将证明这将导致3SUM问题存在$O\left( {n}^{2 - \epsilon }\right)$时间算法。考虑一个3SUM实例，其整数集$A,B$、$C$大小为$n$并以数组形式给出。通过类似例5.3的构造，我们将3SUM归约为特定查询和输入实例上的直接访问问题。设$x,y$、$z$为$Q$的自由独立变量（因${\alpha }_{\text{free }}\left( Q\right)  \geq  3$而存在），创建数据库实例使$x,y$、$z$取$\left\lbrack  {1,n}\right\rbrack$中每个值，其他属性值均为0。这确保$Q$恰好有${n}^{3}$个答案——对应${\left\lbrack  1,n\right\rbrack  }^{3}$中每个(x,y,z)组合，无论原子数量和所含变量如何。由于$x,y$、$z$独立且不共现于同一原子，且$Q$无自连接，每个关系要么含1个元组（不含$x,y$、$z$），要么含$n$个元组（含其中之一）。无论这些关系如何连接（包括笛卡尔积），输出始终是大小为${n}^{3}$的"相同"集合${\left\lbrack  1,n\right\rbrack  }^{3} \times  \{ 0{\} }^{f}$，其中$f$表示除$x,y$、$z$外的自由变量数。（此处"相同"为简化表述，实际$f$不同会导致查询结果模式变化，如移除$z$的例5.3，但这仅影响答案元组中额外0的数量，不影响构造。）

For the reduction from 3SUM, weights are assigned to the attribute values as ${w}_{x}\left( i\right)  = A\left\lbrack  i\right\rbrack  ,{w}_{y}\left( i\right)  = B\left\lbrack  i\right\rbrack  ,{w}_{z}\left( i\right)  = C\left\lbrack  i\right\rbrack  ,i \in  \left\lbrack  {1,n}\right\rbrack$ ,and ${w}_{u}\left( 0\right)  = 0$ for all other attributes $u$ . By our weight assignment, the weights of the answers are $A\left\lbrack  i\right\rbrack   + B\left\lbrack  j\right\rbrack   + C\left\lbrack  k\right\rbrack  ,i,j,k \in  \left\lbrack  {1,n}\right\rbrack$ , and thus in one-to-one correspondence with the possible value combinations in the 3sum problem. We first perform the preprocessing for direct access in $O\left( {n}^{2 - \epsilon }\right)$ ,which enables direct access to any position in the sorted array of query answers in $O\left( {n}^{2 - \epsilon }\right)$ . By Lemma 5.6, weight lookup for a query result with zero weight is possible in $O\left( {{n}^{2 - \epsilon }\log n}\right)$ . Thus,we answer the original 3sum problem in $O\left( {n}^{2 - {\epsilon }^{\prime }}\right)$ for any $0 < {\epsilon }^{\prime } < \epsilon$ ,violating the3sum hypothesis.

在3SUM问题的归约中，属性值权重分配如下：其他所有属性$u$的值被赋予${w}_{x}\left( i\right)  = A\left\lbrack  i\right\rbrack  ,{w}_{y}\left( i\right)  = B\left\lbrack  i\right\rbrack  ,{w}_{z}\left( i\right)  = C\left\lbrack  i\right\rbrack  ,i \in  \left\lbrack  {1,n}\right\rbrack$和${w}_{u}\left( 0\right)  = 0$。通过这种权重分配方式，查询结果的权重呈现$A\left\lbrack  i\right\rbrack   + B\left\lbrack  j\right\rbrack   + C\left\lbrack  k\right\rbrack  ,i,j,k \in  \left\lbrack  {1,n}\right\rbrack$特征，从而与3SUM问题中可能的值组合形成一一对应关系。我们首先在$O\left( {n}^{2 - \epsilon }\right)$中进行直接访问的预处理，这使得可以快速访问$O\left( {n}^{2 - \epsilon }\right)$中排序后的查询结果数组任意位置。根据引理5.6，在$O\left( {{n}^{2 - \epsilon }\log n}\right)$时间内可对零权重查询结果进行权重查找。因此，我们能在$O\left( {n}^{2 - {\epsilon }^{\prime }}\right)$时间内解答任意$0 < {\epsilon }^{\prime } < \epsilon$条件下的原始3SUM问题，这与3SUM假设相矛盾。

For queries that do not have three independent free variables we need a slightly different construction. We show next that two variables are sufficient to encode partial 3SUM solutions (i.e., pairs of elements), enabling a full solution of 3sum via weight lookups. This yields a weaker lower bound than Lemma 5.7, but still is sufficient to prove intractability according to our yardstick.

对于不含三个独立自由变量的查询，我们需要采用稍有不同的构造方法。接下来证明仅需两个变量即可编码部分3SUM解（即元素对），通过权重查找实现完整3SUM求解。虽然这产生的下界弱于引理5.7，但根据我们的衡量标准，仍足以证明问题的难解性。

LEMMA 5.8. If a ${CQQ}$ is self-join-free and ${\alpha }_{\text{free }}\left( Q\right)  = 2$ ,then direct access by ${\sum w}$ is not possible in $\left\langle  {{n}^{2 - \epsilon },{n}^{1 - \epsilon }}\right\rangle$ for any $\epsilon  > 0$ assuming 3SUM.

引理5.8. 若${CQQ}$无自连接且满足${\alpha }_{\text{free }}\left( Q\right)  = 2$，则在3SUM假设下，任何$\epsilon  > 0$条件下都无法通过${\sum w}$在$\left\langle  {{n}^{2 - \epsilon },{n}^{1 - \epsilon }}\right\rangle$时间内实现直接访问。

## Proof. See Appendix A.5.

## 证明. 参见附录A.5。

A special case of Lemma 5.8 is closely related to the problem of selection in X+Y [22],where we want to access the ${k}^{th}$ smallest sum of pairs between two sets $X$ and $Y$ . This is equivalent to accessing the answers to ${Q}_{XY}\left( {x,y}\right)  :  - R\left( x\right) ,S\left( y\right)$ by ${\sum w}$ ordering. It has been shown that if $X$ and $Y$ are given sorted,then selection (a single access) is possible even in linear time [15,26]. Thus,for ${Q}_{XY}$ direct access by ${\sum w}$ is possible with $O\left( {n\log n}\right)$ preprocessing (where we simply sort the input relations) and $O\left( n\right)$ per access.

引理5.8的特殊情况与X+Y集合的选择问题[22]密切相关，该问题要求访问两个集合$X$与$Y$间第${k}^{th}$小的元素对和。这等价于按${\sum w}$排序访问${Q}_{XY}\left( {x,y}\right)  :  - R\left( x\right) ,S\left( y\right)$的查询结果。研究表明，若$X$和$Y$已排序，则单次选择操作甚至可在线性时间内完成[15,26]。因此，对于${Q}_{XY}$查询，通过${\sum w}$排序实现直接访问仅需$O\left( {n\log n}\right)$预处理时间（即简单排序输入关系）和每次$O\left( n\right)$的访问时间。

So far,we have covered all self-join-free CQs with ${\alpha }_{\text{free }}\left( Q\right)  > 1$ , which, by Lemma 5.4, proves the negative part of Theorem 5.1. Next, we show that the remaining acyclic CQs (those with ${\alpha }_{\text{free }}\left( Q\right)  \leq  1$ or equivalently, an atom containing all the free variables) are tractable. For these queries, a single relation contains all the answers, and so direct access can easily be supported by reducing and sorting that relation.

至此，我们已涵盖所有无自连接且满足${\alpha }_{\text{free }}\left( Q\right)  > 1$的CQ查询，根据引理5.4，这完成了定理5.1的否定部分证明。接下来将证明剩余的无环CQ查询（含${\alpha }_{\text{free }}\left( Q\right)  \leq  1$或等价地包含所有自由变量的原子）是可高效处理的。这类查询的答案全集存储在单个关系中，因此通过归约和排序该关系即可轻松支持直接访问。

LEMMA 5.9. If a ${CQQ}$ is acyclic and an atom contains all the free variables,then direct access by ${\sum w}$ is possible in $\langle n\log n,1\rangle$ .

引理5.9. 若${CQQ}$是非循环的且某个原子包含所有自由变量，则通过${\sum w}$的直接访问在$\langle n\log n,1\rangle$中可实现。

Proof. See Appendix A.6.

证明. 见附录A.6。

Combining these lemmas with the hardness of Boolean self-join-free cyclic CQs based on HyperclIQUE, gives a proof of Theorem 5.1.

将这些引理与基于HyperclIQUE的无自连接布尔循环CQ的硬度相结合，即可证明定理5.1。

## 6 SELECTION BY SUM OF WEIGHTS

## 6 基于权重和的选取

Given that direct access by ${\sum w}$ order with quasilinear preprocessing and polylogarithmic delay is possible only in very few cases, we next investigate the tractability of a simpler version of the problem: When is selection, i.e., direct access to a single query answer, possible in quasilinear time? We further simplify the problem by not allowing any projections in the query, i.e., we limit our attention to full CQs. Our main result is a dichotomy theorem that covers all full self-join-free CQs.

鉴于仅能在极少数情况下实现拟线性预处理和多对数延迟的${\sum w}$顺序直接访问，我们接下来研究该问题简化版本的易处理性：何时能在拟线性时间内实现选取（即直接访问单个查询结果）？我们通过禁止查询中的任何投影进一步简化问题，即仅关注完全CQ。我们的主要成果是涵盖所有无自连接完全CQ的二分定理。

### 6.1 Overview of Results

### 6.1 结果概览

We show that the simplifications move only a narrow class of queries to the tractable side. For example, the 2-path query ${Q}_{7}\left( {x,y,z}\right)  \mathrel{\text{:-}} R\left( {x,y}\right) ,S\left( {y,z}\right)$ is tractable for selection (a single direct access), even though it is not for direct access. Still, the 3-path query ${Q}_{9}\left( {x,y,z,u}\right)  \mathrel{\text{:-}} R\left( {x,y}\right) ,S\left( {y,z}\right) ,T\left( {z,u}\right)$ remains intractable. Given that ${Q}_{7}$ and ${Q}_{9}$ both have two free and independent variables,a different criterion than ${\alpha }_{\text{free }}\left( Q\right)$ is needed for classification.

研究表明，简化处理仅使少量查询类型转为易处理类。例如，2路径查询${Q}_{7}\left( {x,y,z}\right)  \mathrel{\text{:-}} R\left( {x,y}\right) ,S\left( {y,z}\right)$虽不支持直接访问，但其选取（单次直接访问）是易处理的。然而3路径查询${Q}_{9}\left( {x,y,z,u}\right)  \mathrel{\text{:-}} R\left( {x,y}\right) ,S\left( {y,z}\right) ,T\left( {z,u}\right)$仍属难解类。鉴于${Q}_{7}$和${Q}_{9}$均具有两个自由独立变量，需要不同于${\alpha }_{\text{free }}\left( Q\right)$的分类标准。

Definition 6.1 (Maximal Hyperedges). For a CQ $Q$ with hyper-graph $\mathcal{H}\left( Q\right)  = \left( {V,E}\right)$ ,the maximal number of hyperedges w.r.t. containment is $\operatorname{mh}\left( Q\right)$ ,i.e., $\operatorname{mh}\left( Q\right)  = \max \left| \left\{  {e \in  E\mid \nexists {e}^{\prime } \in  R \land  e \subseteq  {e}^{\prime }}\right\}  \right|$ .

定义6.1（最大超边）. 对于含超图$\mathcal{H}\left( Q\right)  = \left( {V,E}\right)$的CQ$Q$，其包含关系的最大超边数为$\operatorname{mh}\left( Q\right)$，即$\operatorname{mh}\left( Q\right)  = \max \left| \left\{  {e \in  E\mid \nexists {e}^{\prime } \in  R \land  e \subseteq  {e}^{\prime }}\right\}  \right|$。

Note that for full $\mathrm{{CQs}},{\alpha }_{\text{free }}\left( Q\right)  \leq  \operatorname{mh}\left( Q\right)$ since each independent variable can be associated with a distinct maximal hyperedge. We summarize the results of this section in the following theorem, which classifies full $\mathrm{{CQs}}Q$ based on $\mathrm{{mh}}\left( Q\right)$ :

注意在完全$\mathrm{{CQs}},{\alpha }_{\text{free }}\left( Q\right)  \leq  \operatorname{mh}\left( Q\right)$中，每个独立变量可关联到不同的最大超边。我们在下定理中总结本节结果，该定理基于$\mathrm{{mh}}\left( Q\right)$对完全$\mathrm{{CQs}}Q$进行分类：

THEOREM 6.2. Let $Q$ be a full ${CQ}$ and $w$ be a weight function.

定理6.2. 设$Q$为完全${CQ}$，$w$为权重函数。

- If $\operatorname{mh}\left( Q\right)  \leq  2$ ,then selection by ${\sum w}$ is possible in $\langle 1,n\log n\rangle$ .

- 若$\operatorname{mh}\left( Q\right)  \leq  2$，则${\sum w}$选取可在$\langle 1,n\log n\rangle$中实现。

- Otherwise,if $Q$ is also self-join-free,then selection by ${\sum w}$ is not possible in $\langle 1,n$ polylog $n\rangle$ . assuming 3SUM and HYPERCLIQUE.

- 否则，若$Q$亦为无自连接，则在3SUM和HYPERCLIQUE假设下，${\sum w}$选取无法在$\langle 1,n$多对数$n\rangle$时间内实现。

We prove the positive part of the theorem in Section 6.2 and the negative part in Section 6.3.

我们将在6.2节证明定理的积极部分，在6.3节证明消极部分。

Example 6.3. For the query ${Q}_{7}\left( {x,y,z}\right)  :  - R\left( {x,y}\right) ,S\left( {y,z}\right)$ we have already shown in Section 5 that direct access by ${\sum w}$ is intractable. However, given that it has two maximal hyperedges, only one access (or a constant number of them) is in fact possible in $O\left( {n\log n}\right)$ .

示例6.3. 对于查询${Q}_{7}\left( {x,y,z}\right)  :  - R\left( {x,y}\right) ,S\left( {y,z}\right)$，我们已在第5节证明${\sum w}$直接访问是难处理的。但鉴于其具有两个最大超边，实际上可在$O\left( {n\log n}\right)$中实现单次（或常数次）访问。

Absorbed atoms. We say that an atom (identified by its hyperedge) $V$ is absorbed by an atom ${V}^{\prime }$ if $V \subseteq  {V}^{\prime }$ . As evident from Theorem 6.2, adding to a query atoms that are absorbed by existing ones does not affect the complexity of selection. We prove this claim first and use it later in our analysis in order to treat queries that contain absorbed atoms.

被吸收原子。若某原子（通过其超边标识）$V$被原子${V}^{\prime }$吸收，当满足条件$V \subseteq  {V}^{\prime }$时。如定理6.2所示，向查询中添加被现有原子吸收的新原子不会改变选择操作的复杂度。我们将先证明这一主张，并在后续分析中利用该结论处理含吸收原子的查询。

A query ${Q}^{\prime }$ is a contraction of $Q$ if every atom of ${Q}^{\prime }$ appears in $Q$ ,and all the rest of the atoms of $Q$ are absorbed by some atom of ${Q}^{\prime }.{Q}^{m}$ is a maximal contraction of $Q$ if it is a contraction and there is no ${Q}^{\prime \prime }$ that is a contraction of ${Q}^{m}$ except itself. It is easy to see that the number of atoms of ${Q}^{m}$ is $\operatorname{mh}\left( Q\right)$ .

当查询${Q}^{\prime }$的每个原子都存在于$Q$中，且$Q$的其余原子均被${Q}^{\prime }.{Q}^{m}$的某个原子吸收时，称${Q}^{\prime }$是$Q$的收缩。若该收缩不存在除自身外的其他收缩${Q}^{\prime \prime }$，则称其为$Q$的最大收缩。显然${Q}^{m}$的原子数量为$\operatorname{mh}\left( Q\right)$。

Example 6.4. Consider $Q\left( {x,y,z}\right)  :  - R\left( {x,y}\right) ,S\left( y\right) ,T\left( {y,z}\right) ,U\left( {x,y}\right)$ . Here, $S\left( y\right)$ is absorbed by $R\left( {x,y}\right)$ and $U\left( {x,y}\right)$ ,and the latter two absorb each other. There are two maximal contractions that we can obtain from $Q$ : either ${Q}_{1}^{m} :  - R\left( {x,y}\right) ,T\left( {y,z}\right)$ or ${Q}_{2}^{m} :  - T\left( {y,z}\right) ,U\left( {x,y}\right)$ . The number of maximal hyperdges of $Q$ is $\operatorname{mh}\left( Q\right)  = 2$ .

示例6.4 考察$Q\left( {x,y,z}\right)  :  - R\left( {x,y}\right) ,S\left( y\right) ,T\left( {y,z}\right) ,U\left( {x,y}\right)$。此处$S\left( y\right)$被$R\left( {x,y}\right)$和$U\left( {x,y}\right)$吸收，而后两者又相互吸收。从$Q$可得到两种最大收缩：${Q}_{1}^{m} :  - R\left( {x,y}\right) ,T\left( {y,z}\right)$或${Q}_{2}^{m} :  - T\left( {y,z}\right) ,U\left( {x,y}\right)$。$Q$的最大超边数量为$\operatorname{mh}\left( Q\right)  = 2$。

LEMMA 6.5. Selection on a ${CQQ}$ is possible in $O\left( {{T}_{S}\left( n\right) }\right)$ if selection on a maximal contraction ${Q}^{m}$ of $Q$ is possible in $O\left( {{T}_{S}\left( n\right) }\right)$ . The converse is also true if $Q$ is self-join-free.

### 6.2 可处理性证明

In this section, we provide tractability results for full CQs with $\operatorname{mh}\left( Q\right)  \leq  2$ . First,we consider the trivial case of $\operatorname{mh}\left( Q\right)  = 1$ where the maximal contraction of $Q$ has only one atom. The lemma below is a direct consequence of the linear-time array selection algorithm of Blum et al. [6].

本节将给出含$\operatorname{mh}\left( Q\right)  \leq  2$的完全合取查询的可处理性结果。首先考察$Q$的最大收缩仅含单个原子的平凡情况$\operatorname{mh}\left( Q\right)  = 1$。下述引理直接源自Blum等人提出的线性时间数组选择算法[6]。

LEMMA 6.6. For a full ${CQQ}$ with ${mh}\left( Q\right)  = 1$ ,selection by ${\sum w}$ is possible in $\langle 1,n\rangle$ .

引理6.6 对于含${mh}\left( Q\right)  = 1$的完全查询${CQQ}$，通过${\sum w}$进行选择可在$\langle 1,n\rangle$时间内完成。

Proof. See Appendix A.8.

证明。见附录A.8。

For the $\operatorname{mh}\left( Q\right)  = 2$ case,we rely on an algorithm by Frederickson and Johnson [15], which generalizes selection on the X+Y problem. If the two sets $X$ and $Y$ are given sorted,then the pairwise sums can be represented as a sorted matrix. A sorted matrix $M$ contains a sequence of non-decreasing elements in every row and every column. For the $X + Y$ problem,a cell $M\left\lbrack  {i,j}\right\rbrack$ contains the sum $X\left\lbrack  i\right\rbrack   + Y\left\lbrack  j\right\rbrack$ . Even though the matrix $M$ has quadratically many cells, there is no need to construct it in advance given that we can compute each cell in constant time. Selection on a union of such matrices $\left\{  {{M}_{1},\ldots ,{M}_{\ell }}\right\}$ asks for the ${k}^{\text{th }}$ smallest cell among the cells of all matrices.

针对$\operatorname{mh}\left( Q\right)  = 2$情形，我们采用Frederickson和Johnson提出的算法[15]，该算法推广了X+Y问题上的选择操作。若两个集合$X$与$Y$已排序，则其两两和可表示为有序矩阵。有序矩阵$M$的每行每列元素均呈非递减排列。对于$X + Y$问题，单元格$M\left\lbrack  {i,j}\right\rbrack$存储的是和值$X\left\lbrack  i\right\rbrack   + Y\left\lbrack  j\right\rbrack$。尽管矩阵$M$具有平方级数量的单元格，但由于我们能在常数时间内计算每个单元格，故无需预先构建该矩阵。在此类矩阵$\left\{  {{M}_{1},\ldots ,{M}_{\ell }}\right\}$的并集上进行选择操作，即要求从所有矩阵单元格中找出第${k}^{\text{th }}$小的单元格。

THEOREM 6.7 ([15]). Selection on a union of sorted matrices $\left\{  {{M}_{1},\ldots ,{M}_{\ell }}\right\}$ ,where ${M}_{m}$ has dimension ${p}_{m} \times  {q}_{m}$ with ${p}_{m} \geq  {q}_{m}$ ,is possible in time $O\left( {\mathop{\sum }\limits_{{m = 1}}^{\ell }{q}_{m}\log \left( {2{p}_{m}/{q}_{m}}\right) }\right)$ .

定理6.7 ([15])。对于维度为${p}_{m} \times  {q}_{m}$（其中${p}_{m} \geq  {q}_{m}$）的有序矩阵${M}_{m}$的并集$\left\{  {{M}_{1},\ldots ,{M}_{\ell }}\right\}$，其选择操作可在$O\left( {\mathop{\sum }\limits_{{m = 1}}^{\ell }{q}_{m}\log \left( {2{p}_{m}/{q}_{m}}\right) }\right)$时间内完成。

Leveraging this algorithm, we provide our next positive result:

基于该算法，我们得出以下积极结论：

LEMMA 6.8. For a full ${CQQ}$ with ${mh}\left( Q\right)  = 2$ ,selection by ${\sum w}$ is possible in $\langle 1,n\log n\rangle$ .

引理6.8。对于具有${mh}\left( Q\right)  = 2$属性的完整${CQQ}$，通过${\sum w}$进行选择操作可在$\langle 1,n\log n\rangle$时间内实现。

Proof. The maximal contraction of queries with $\operatorname{mh}\left( Q\right)  = 2$ is $Q\left( {\overrightarrow{X},\overrightarrow{Y}}\right)  :  - R\left( \overrightarrow{X}\right) ,S\left( \overrightarrow{Y}\right)$ ,with $\overrightarrow{X} \neq  \overrightarrow{Y}$ ,thus by Lemma 6.5,it is enough to prove an $O\left( {n\log n}\right)$ bound for this query. As before,we turn the attribute weights into tuple weights. Since a variable may occur in both atoms, we make sure to assign each attribute weight to only one relation to avoid double-counting. Thus, we compute $w\left( r\right)  = \mathop{\sum }\limits_{{x \in  \overrightarrow{X}}}{w}_{x}\left( {r\left( x\right) }\right)$ and $w\left( s\right)  = \mathop{\sum }\limits_{{y \in  \left( {\overrightarrow{Y} \smallsetminus  \overrightarrow{X}}\right) }}{w}_{y}\left( {s\left( y\right) }\right)$ for all $r \in  R$ and $s \in  S$ ,respectively. Since the query is full,the weights of the query answers are in one-to-one correspondence with the pairwise sums of weights of tuples from $R$ and $S$ .

证明。带有$\operatorname{mh}\left( Q\right)  = 2$的查询最大收缩度为$Q\left( {\overrightarrow{X},\overrightarrow{Y}}\right)  :  - R\left( \overrightarrow{X}\right) ,S\left( \overrightarrow{Y}\right)$（其中$\overrightarrow{X} \neq  \overrightarrow{Y}$），根据引理6.5，只需证明该查询具有$O\left( {n\log n}\right)$上界。如前所述，我们将属性权重转换为元组权重。由于变量可能同时出现在两个原子中，需确保每个属性权重仅分配给一个关系以避免重复计算。因此，我们分别计算所有$r \in  R$和$s \in  S$对应的$w\left( r\right)  = \mathop{\sum }\limits_{{x \in  \overrightarrow{X}}}{w}_{x}\left( {r\left( x\right) }\right)$与$w\left( s\right)  = \mathop{\sum }\limits_{{y \in  \left( {\overrightarrow{Y} \smallsetminus  \overrightarrow{X}}\right) }}{w}_{y}\left( {s\left( y\right) }\right)$。由于查询是完整的，查询答案权重与来自$R$和$S$的元组权重两和呈一一对应关系。

Let $\overrightarrow{Z} = \overrightarrow{X} \cap  \overrightarrow{Y}$ . We next group the $R$ and $S$ tuples by their $Z$ values: we create $\ell$ buckets of tuples where all tuples $t$ within a bucket have equal $t\left( z\right)$ values, $z \in  \overrightarrow{Z}$ . This can be done in linear time. If $\overrightarrow{Z} = \varnothing$ ,i.e.,the query is the Cartesian product,then we place all tuples in a single bucket. For each assignment of $\overrightarrow{Z}$ values, the query answers with those values are formed by the Cartesian product of $R$ and $S$ tuples inside that bucket. Also,if the size of bucket $m$ is ${n}_{m}$ ,then ${n}_{1} + \ldots  + {n}_{\ell } = \left| R\right|  + \left| S\right|$ . We sort the tuples in the buckets according to their weight in $O\left( {n\log n}\right)$ time. Assume ${R}_{m}$ and ${S}_{m}$ are the partitions of $R$ and $S$ in bucket $m$ and ${R}_{m}\left\lbrack  i\right\rbrack$ denotes the ${i}^{\text{th }}$ tuple of ${R}_{m}$ in sorted order (equivalently for ${S}_{m}\left\lbrack  j\right\rbrack$ ). We define a union of sorted matrices $\left\{  {{M}_{1},\ldots ,{M}_{\ell }}\right\}$ as follows: For bucket $m$ ,we have ${M}_{m}\left\lbrack  {i,j}\right\rbrack   = w\left( {{R}_{m}\left\lbrack  i\right\rbrack  }\right)  + w\left( {{S}_{m}\left\lbrack  j\right\rbrack  }\right)$ . Selection on these matrices is equivalent to selection on the query answers of $Q$ . By Theorem 6.7,if matrix ${M}_{m}$ has dimension ${p}_{m} \times  {q}_{m}$ with ${p}_{m} \geq  {q}_{m}$ ,we can achieve selection in $O\left( {\mathop{\sum }\limits_{{m = 1}}^{\ell }{q}_{m}\log \left( {2{p}_{m}/{q}_{m}}\right) }\right)  =$ $O\left( {\mathop{\sum }\limits_{{m = 1}}^{\ell }{q}_{m} \cdot  2{p}_{m}/{q}_{m}}\right)  = O\left( {\mathop{\sum }\limits_{{m = 1}}^{\ell }{p}_{m}}\right)  = O\left( {\mathop{\sum }\limits_{{m = 1}}^{\ell }{n}_{m}}\right)  = O\left( n\right) .$ Overall,the time spent is $O\left( {n\log n}\right)$ because of sorting.

设$\overrightarrow{Z} = \overrightarrow{X} \cap  \overrightarrow{Y}$。我们接着按$Z$值对$R$和$S$元组进行分组：创建$\ell$个元组桶，每个桶内所有$t$元组都具有相同的$t\left( z\right)$值$z \in  \overrightarrow{Z}$。该操作可在线性时间内完成。若$\overrightarrow{Z} = \varnothing$（即查询为笛卡尔积），则将所有元组置于单个桶中。对于每个$\overrightarrow{Z}$值的赋值，查询结果由该桶内$R$和$S$元组的笛卡尔积构成。此外，若桶$m$的大小为${n}_{m}$，则${n}_{1} + \ldots  + {n}_{\ell } = \left| R\right|  + \left| S\right|$。我们在$O\left( {n\log n}\right)$时间内按权重对桶内元组排序。假设${R}_{m}$和${S}_{m}$是桶$m$中$R$和$S$的分区，${R}_{m}\left\lbrack  i\right\rbrack$表示${R}_{m}$排序后的第${i}^{\text{th }}$个元组（对${S}_{m}\left\lbrack  j\right\rbrack$同理）。定义排序矩阵的并集$\left\{  {{M}_{1},\ldots ,{M}_{\ell }}\right\}$如下：对于桶$m$，有${M}_{m}\left\lbrack  {i,j}\right\rbrack   = w\left( {{R}_{m}\left\lbrack  i\right\rbrack  }\right)  + w\left( {{S}_{m}\left\lbrack  j\right\rbrack  }\right)$。对这些矩阵的选择等价于对$Q$查询结果的选择。根据定理6.7，若矩阵${M}_{m}$维度为${p}_{m} \times  {q}_{m}$且${p}_{m} \geq  {q}_{m}$，可在$O\left( {\mathop{\sum }\limits_{{m = 1}}^{\ell }{q}_{m}\log \left( {2{p}_{m}/{q}_{m}}\right) }\right)  =$$O\left( {\mathop{\sum }\limits_{{m = 1}}^{\ell }{q}_{m} \cdot  2{p}_{m}/{q}_{m}}\right)  = O\left( {\mathop{\sum }\limits_{{m = 1}}^{\ell }{p}_{m}}\right)  = O\left( {\mathop{\sum }\limits_{{m = 1}}^{\ell }{n}_{m}}\right)  = O\left( n\right) .$内完成选择。总体耗时因排序操作保持为$O\left( {n\log n}\right)$。

### 6.3 Intractability Proofs

### 6.3 难解性证明

Though selection is a special case of direct access, we show that for most full CQs tractable time complexity $O\left( {n\text{polylog}n}\right)$ is still unattainable. We start from the cases covered by Lemma 5.7. To extend that result to the selection problem, note that a selection algorithm can be repeatedly applied for solving direct access. For queries with three free and independent variables,an $O\left( {n}^{2 - \epsilon }\right)$ selection algorithm would imply a $\left\langle  {{n}^{2 - \epsilon },{n}^{2 - \epsilon }}\right\rangle$ direct-access algorithm, which we showed to be impossible. Therefore, the following immediately follows from Lemma 5.7:

尽管选择是直接访问的特例，但我们证明对于大多数完全CQ而言，仍无法获得易处理的时间复杂度$O\left( {n\text{polylog}n}\right)$。我们从引理5.7覆盖的案例出发。将该结果推广到选择问题时需注意：选择算法可重复应用于解决直接访问。对于含三个自由独立变量的查询，$O\left( {n}^{2 - \epsilon }\right)$选择算法将意味着存在$\left\langle  {{n}^{2 - \epsilon },{n}^{2 - \epsilon }}\right\rangle$直接访问算法——而这已被证明不可实现。因此，以下结论可直接由引理5.7得出：

COROLLARY 6.9. If a full ${CQQ}$ is self-join-free and ${\alpha }_{\text{free }}\left( Q\right)  \geq$ 3,then selection by ${\sum w}$ is not possible in $\left\langle  {1,{n}^{2 - \epsilon }}\right\rangle$ for any $\epsilon  > 0$ assuming 3SUM.

推论6.9. 若一个完整的${CQQ}$是无自连接且${\alpha }_{\text{free }}\left( Q\right)  \geq$3的，则在3SUM假设下，任何$\epsilon  > 0$中通过${\sum w}$进行选择在$\left\langle  {1,{n}^{2 - \epsilon }}\right\rangle$中均不可实现。

This leaves only a small fraction of full acyclic CQs to be covered: queries with two or fewer independent variables and three or more maximal hyperedges. We next show that these queries are essentially variants of the general three-path query template where three atoms are organized in a chain.

至此仅剩少量无环完全联立查询待覆盖：即含两个或更少独立变量及三个或更多最大超边的查询。接下来我们将证明，这些查询本质上是三路径通用查询模板的变体——其中三个原子以链式结构组织。

LEMMA 6.10. The full acyclic ${CQ}$ s $Q$ that satisfy ${\alpha }_{\text{free }}\left( Q\right)  < 3$ and ${mh}\left( Q\right)  > 2$ are ${Q}_{3g}\left( {\overrightarrow{X},\overrightarrow{Y},\overrightarrow{Z},\overrightarrow{U}}\right)  :  - R\left( {\overrightarrow{X},\overrightarrow{Y}}\right) ,S\left( {\overrightarrow{Y},\overrightarrow{Z}}\right) ,T\left( {\overrightarrow{Z},\overrightarrow{U}}\right)$ for non-empty $\overrightarrow{X},\overrightarrow{Y},\overrightarrow{Z},\overrightarrow{U}$ ,up to atom absorption.

引理6.10. 满足${\alpha }_{\text{free }}\left( Q\right)  < 3$和${mh}\left( Q\right)  > 2$的无环完全${CQ}$$Q$，在原子吸收意义下，等同于非空$\overrightarrow{X},\overrightarrow{Y},\overrightarrow{Z},\overrightarrow{U}$的${Q}_{3g}\left( {\overrightarrow{X},\overrightarrow{Y},\overrightarrow{Z},\overrightarrow{U}}\right)  :  - R\left( {\overrightarrow{X},\overrightarrow{Y}}\right) ,S\left( {\overrightarrow{Y},\overrightarrow{Z}}\right) ,T\left( {\overrightarrow{Z},\overrightarrow{U}}\right)$。

Proof. See Appendix A.9. $\square$

证明. 见附录A.9.$\square$

Now that we established the precise form of the queries we want to classify, we proceed to prove their intractability. We approach this in a different way than the other hardness proofs: instead of relying on the 3sum hypothesis, we instead show that tractable selection would lead to unattainable bounds for Boolean cyclic queries.

既然已确定待分类查询的精确形式，我们开始证明其难解性。本证明采用与其他硬度证明不同的方法：不依赖3sum假设，而是证明若选择可高效处理，将导致布尔循环查询出现无法达到的复杂度边界。

LEMMA 6.11. Selection by ${\sum w}$ is not possible in $\langle 1,n$ polylog $n\rangle$ for ${Q}_{3g}\left( {\overrightarrow{X},\overrightarrow{Y},\overrightarrow{Z},\overrightarrow{U}}\right)  :  - R\left( {\overrightarrow{X},\overrightarrow{Y}}\right) ,S\left( {\overrightarrow{Y},\overrightarrow{Z}}\right) ,T\left( {\overrightarrow{Z},\overrightarrow{U}}\right)$ assuming ${H}_{YPERCLIQUE}$ .

Proof. Let ${Q}_{\Delta }\left( \right)  :  - {R}^{\prime }\left( {{x}^{\prime },{y}^{\prime }}\right) ,{S}^{\prime }\left( {{y}^{\prime },{z}^{\prime }}\right) ,{T}^{\prime }\left( {{z}^{\prime },{x}^{\prime }}\right)$ be a query over a database $I$ . Since accessing the sorted array of ${Q}_{3g}$ answers takes $O\left( {n\text{polylog}n}\right)$ ,by Lemma 5.6,weight lookup also takes $O\left( {n\text{polylog}n}\right)$ .

证明。我们将证明，若针对${Q}_{3q}$的选择能在$O\left( {n\text{polylog}n}\right)$时间内完成，则布尔三角查询可在相同时间界限内求值，这与HYPERCLIQUE假设相矛盾。设${Q}_{\Delta }\left( \right)  :  - {R}^{\prime }\left( {{x}^{\prime },{y}^{\prime }}\right) ,{S}^{\prime }\left( {{y}^{\prime },{z}^{\prime }}\right) ,{T}^{\prime }\left( {{z}^{\prime },{x}^{\prime }}\right)$为数据库$I$上的查询。我们将为${Q}_{3q}$构建数据库${I}^{\prime }$，通过权重查找即可回答$I$上的${Q}_{\Delta }$。令$x \in  \overrightarrow{X},y \in  \overrightarrow{Y},z \in  \overrightarrow{Z},u \in  \overrightarrow{U}$。对于${I}^{\prime }$，我们将关系${R}^{\prime }$扩展至$R$：为$x = {x}^{\prime },y = {y}^{\prime }$赋值，并将其他所有属性$\left( {\overrightarrow{X} \cup  \overrightarrow{Y}}\right)  \smallsetminus  \{ x,y\}$设为固定域值$\bot$。对其他关系重复该过程：为$S$赋值$y = {y}^{\prime },z = {z}^{\prime }$，为$T$赋值$z = {z}^{\prime },u = {x}^{\prime }$。考虑查询结果$q \in  {Q}_{3g}\left( {I}^{\prime }\right)$。若${\pi }_{u}\left( q\right)  = {\pi }_{x}\left( q\right)$，则根据构造可知${\pi }_{xyz}\left( q\right)$满足$R,S$与$T$，故$I$上的${Q}_{\bigtriangleup }$成立。现按如下规则分配权重：若$\operatorname{dom} \subseteq  \mathbb{R}$，则${w}_{x}\left( i\right)  = i,{w}_{u}\left( i\right)  =  - i$，其余属性$t,{w}_{t}\left( i\right)  = 0$赋零值；否则亦可通过维护将域值映射为任意实数的查找表，确保${w}_{x}\left( i\right)  = {w}_{x}\left( j\right)$当且仅当$i = j$且${w}_{u}\left( i\right)  =  - {w}_{x}\left( i\right)$时成立。通过对${Q}_{3g}$执行权重查找，可判断是否存在零权重查询结果。若某结果$q$满足条件，则${w}_{x}\left( {{\pi }_{x}\left( q\right) }\right)  + \ldots  + {w}_{u}\left( {{\pi }_{u}\left( u\right) }\right)  = 0$成立，故${\pi }_{x}\left( q\right)  = {\pi }_{u}\left( q\right)$且${Q}_{\bigtriangleup }$为真；否则为假。由于访问${Q}_{3g}$答案的排序数组耗时$O\left( {n\text{polylog}n}\right)$，根据引理5.6，权重查找同样耗时$O\left( {n\text{polylog}n}\right)$。

The negative part of Theorem 6.2 for acyclic queries is proved by combining Corollary 6.9 and Lemma 6.11 together with Lemma 6.10 and Lemma 6.5 that show we cover all cases. For self-join-free cyclic CQs, we once again resort to the hardness of their Boolean version based on HyperclIQUE.

通过将推论6.9、引理6.11与证明我们覆盖所有情况的引理6.10、引理6.5相结合，证明了无环查询情形下定理6.2的否定部分。对于无自连接的循环CQ，我们再次基于HyperclIQUE问题归约其布尔版本的难解性。

## 7 CONCLUSIONS

## 7 结论

We investigated the task of constructing a direct-access data structure to the output of a query with an ordering over the answers. We presented algorithms for fragments of the class of CQs for lexicographic orders and sum of weights. In these algorithms, the construction time is quasilinear in the size of the database, and the access time is logarithmic. We showed that within the class of CQs without self-joins, our algorithms cover all the cases where these complexity guarantees are feasible, assuming conventional hypotheses in the theory of fine-grained complexity. In the case of sum, where the tractable fragment is limited, we also studied the restriction of the problem to accessing a single answer (the selection problem) and established a corresponding classification for full CQs.

我们研究了为带有答案排序的查询输出构建直接访问数据结构的任务。针对词典序和权重求和的CQ子类，提出了构造算法。这些算法的构建时间在数据库规模上呈拟线性，访问时间呈对数级。我们证明在无自连接的CQ类中，基于细粒度复杂性理论的常规假设，这些算法覆盖了所有满足该复杂度保证的情形。对于求解范围受限的求和问题，我们还研究了仅访问单个答案（选择问题）的限制条件，并建立了完整CQ的对应分类。

This work opens up several directions for future work, including the generalization to more expressive queries (CQs with self-joins, union of CQs, negation, etc.), other kinds of orders (e.g., min/max over the tuple entries), and a continuum of complexity guarantees (beyond (quasilinear, logarithmic time)). It would also be important to understand how integrity constraints, such as functional dependencies, change the frontier of tractability as they have in the case of enumeration [9], deletion propagation [24], resilience [16], and probabilistic inference [18].

本研究开辟了多个未来方向：推广到更具表达力的查询（含自连接的CQ、CQ并集、否定等）、其他排序类型（如元组项的最小/最大值）、以及连续复杂度保证（超越（拟线性，对数时间））。理解函数依赖等完整性约束如何改变易处理性边界也至关重要，正如在枚举[9]、删除传播[24]、弹性分析[16]和概率推理[18]等领域所展现的那样。

Generalizing the question posed at the beginning of the Introduction, we view this work as part of a bigger challenge that continues the line of research on factorized representations in databases $\left\lbrack  {{27},{28}}\right\rbrack$ : how can we represent the output of a query in a way that, compared to the explicit representation, is fundamentally more compact and efficiently computable, yet equally useful to downstream operations?

延伸引言部分提出的问题，我们将本工作视为数据库因子化表示研究脉络$\left\lbrack  {{27},{28}}\right\rbrack$中的重大挑战：如何以相比显式表示更紧凑、计算更高效，且对下游操作同等有用的方式表示查询输出？

### A.1 Proof of Lemma 3.10

### A.1 引理3.10证明

Let $Q$ be a free-connex $\mathrm{{CQ}}$ ,and let $T$ be an ext-free(Q)-connex tree for $Q$ where ${T}^{\prime }$ is the subtree of $T$ that contains exactly the free variables.

We show the other direction. Let $u$ and $v$ be free variables of $Q$ that are neighbors in $T$ . That is,there is a node ${V}_{T}$ in $T$ that contains them both. Consider the unique path from $V$ to any node in ${T}^{\prime }$ such that only the last node on the path,which we denote ${V}_{{T}^{\prime }}$ ,is in ${T}^{\prime }$ . Since both variables appear in ${T}^{\prime }$ and in $V$ , by the running intersection property,both variables appear in ${V}_{{T}^{\prime }}$ . 首先，我们主张两个自由变量在$T$中是邻居当且仅当它们在${T}^{\prime }$中是邻居。"仅当"方向直接成立，因为${T}^{\prime }$包含于$T$。我们证明另一方向。设$u$和$v$是$Q$的自由变量且在$T$中相邻，即存在$T$中的节点${V}_{T}$同时包含二者。考虑从$V$到${T}^{\prime }$中任意节点的唯一路径，该路径上仅末节点${V}_{{T}^{\prime }}$属于${T}^{\prime }$。由于两变量同时出现在${T}^{\prime }$和$V$中，根据运行相交性，它们必出现在${V}_{{T}^{\prime }}$中。因此，$u$与$v$在${T}^{\prime }$中也是邻居。

### A.3 Proof of Lemma 5.4

### A.3 引理5.4的证明

The "only if" part is trivial. For ${\alpha }_{\text{free }}\left( Q\right)  = 1$ and acyclic query $Q$ , we prove that there is an atom ${R}_{f}\left( {\overrightarrow{X}}_{f}\right)$ which contains all the free variables. First note that for $\left| {\operatorname{free}\left( Q\right) }\right|  = 1$ this is trivially true. For $\left| {\operatorname{free}\left( Q\right) }\right|  > 1$ ,let $V$ be a node in the join tree (corresponding to some atom of $Q$ ) that contains the maximum number of free variables and assume for the sake of contradiction that there exists a free variable $y$ with $y \notin  V$ . We use ${\mathcal{V}}_{y}$ to denote the set of nodes in the join tree that contain variable $y$ ; thus $V \notin  {\mathcal{V}}_{y}$ . From $Q$ being acyclic follows that the nodes in ${\mathcal{V}}_{y}$ form a connected graph and there exists a node ${V}^{\prime }$ that lies on every path from $V$ to a node in ${\mathcal{V}}_{y}$ . Since ${\alpha }_{\text{free }}\left( Q\right)  = 1$ ,each variable $x \in  V$ must appear together with $y$ in some query atom,implying that $x$ appears in some node ${V}^{\prime \prime } \in  {\mathcal{V}}_{y}$ . From that and the running intersection property follows that $x$ must also appear in ${V}^{\prime }$ since ${V}^{\prime }$ lies on the path from $V$ to any such ${V}^{\prime \prime }$ . Hence ${V}^{\prime }$ contains $y$ and all the $V$ variables,violating the maximality assumption for $V$ .

"仅当"部分显然成立。对于${\alpha }_{\text{free }}\left( Q\right)  = 1$和无环查询$Q$，我们证明存在一个包含所有自由变量的原子${R}_{f}\left( {\overrightarrow{X}}_{f}\right)$。首先注意到对于$\left| {\operatorname{free}\left( Q\right) }\right|  = 1$这显然成立。对于$\left| {\operatorname{free}\left( Q\right) }\right|  > 1$，设$V$为连接树中（对应$Q$的某个原子）包含最多自由变量的节点，并假设存在自由变量$y$且$y \notin  V$。我们用${\mathcal{V}}_{y}$表示连接树中包含变量$y$的节点集合，因此$V \notin  {\mathcal{V}}_{y}$。由$Q$的无环性可知${\mathcal{V}}_{y}$中的节点形成连通图，且存在节点${V}^{\prime }$位于从$V$到${\mathcal{V}}_{y}$中任意节点的所有路径上。由于${\alpha }_{\text{free }}\left( Q\right)  = 1$，每个变量$x \in  V$必须与$y$共同出现在某个查询原子中，这意味着$x$出现在某个节点${V}^{\prime \prime } \in  {\mathcal{V}}_{y}$中。根据运行交集性质及${V}^{\prime }$位于从$V$到任何此类${V}^{\prime \prime }$的路径上，可推出$x$也必然出现在${V}^{\prime }$中。因此${V}^{\prime }$包含$y$和所有$V$的变量，这与$V$的最大性假设矛盾。

For ${\alpha }_{\text{free }}\left( Q\right)  = 0,Q$ is a Boolean query and any atom trivially contains the empty set.

当${\alpha }_{\text{free }}\left( Q\right)  = 0,Q$是布尔查询时，任何原子都显然包含空集。

### A.4 Proof of Lemma 5.6

### A.4 引理5.6的证明

We use binary search on the sorted array of query answers. Each direct access returns a query answer whose weight can be computed in $O\left( 1\right)$ . Thus,in a logarithmic number of accesses we can find the first occurrence of the desired weight. Since the number of answers is polynomial in $n$ ,the number of accesses is $O\left( {\log n}\right)$ and each one takes $O\left( {T}_{d}\right)$ time.

我们在排序后的查询答案数组上执行二分查找。每次直接访问返回的查询答案，其权重可在$O\left( 1\right)$时间内计算。因此通过对数次访问即可定位目标权重的首次出现。由于答案数量是$n$的多项式，访问次数为$O\left( {\log n}\right)$，每次耗时$O\left( {T}_{d}\right)$。

### A.5 Proof of Lemma 5.8

### A.5 引理5.8的证明

We show that the contrary contradicts the 3sum hypothesis. Let $A$ , $B$ ,and $C$ be three integer arrays of a 3Sum instance of size $n$ . We construct a database instance with attribute weights like in the proof of Lemma 5.7, but now with only 2 free and independent variables $x$ and $y$ . Hence the weights of the ${n}^{2}$ query results are in one-to-one correspondence with the corresponding sums $A\left\lbrack  i\right\rbrack   + B\left\lbrack  j\right\rbrack$ , $i,j \in  \left\lbrack  {1,n}\right\rbrack$ . We run the preprocessing phase for direct access in $O\left( {n}^{2 - \epsilon }\right)$ ,which allows us to access the sorted array of query results in $O\left( {n}^{1 - \epsilon }\right)$ . For each value $C\left\lbrack  k\right\rbrack$ in $C$ ,we perform a weight lookup on $Q$ for weight $- C\left\lbrack  k\right\rbrack$ ,which takes time $O\left( {{n}^{1 - \epsilon }\log n}\right)$ (Lemma 5.6). Since there are $n$ values in $C$ ,total time complexity is $O\left( {n \cdot  {n}^{1 - \epsilon }\log n}\right)  = O\left( {{n}^{2 - \epsilon }\log n}\right)$ . This procedure solves 3sum in $O\left( {n}^{2 - {\epsilon }^{\prime }}\right)$ for any $0 < {\epsilon }^{\prime } < \epsilon$ ,violating the 3sum hypothesis.

我们证明相反情况与3sum假设相矛盾。设$A$、$B$和$C$为规模$n$的3Sum实例中的三个整数数组。如引理5.7证明所示，我们构建一个具有属性权重的数据库实例，但此时仅含两个自由独立变量$x$和$y$。因此${n}^{2}$查询结果的权重与对应和$A\left\lbrack  i\right\rbrack   + B\left\lbrack  j\right\rbrack$、$i,j \in  \left\lbrack  {1,n}\right\rbrack$呈一一对应关系。我们在$O\left( {n}^{2 - \epsilon }\right)$中运行预处理阶段以实现直接访问，从而可在$O\left( {n}^{1 - \epsilon }\right)$内访问排序后的查询结果数组。对于$C$中的每个值$C\left\lbrack  k\right\rbrack$，我们在$Q$上执行权重$- C\left\lbrack  k\right\rbrack$的查找操作，耗时$O\left( {{n}^{1 - \epsilon }\log n}\right)$（引理5.6）。若返回有效索引，则存在$A$与$B$的配对(i,j)满足$\operatorname{sum}A\left\lbrack  i\right\rbrack   + B\left\lbrack  j\right\rbrack   =  - C\left\lbrack  k\right\rbrack$，这意味着$A\left\lbrack  i\right\rbrack   + B\left\lbrack  j\right\rbrack   + C\left\lbrack  k\right\rbrack   = 0$；否则不存在此类配对。由于$C$中有$n$个值，总时间复杂度为$O\left( {n \cdot  {n}^{1 - \epsilon }\log n}\right)  = O\left( {{n}^{2 - \epsilon }\log n}\right)$。该流程可在$O\left( {n}^{2 - {\epsilon }^{\prime }}\right)$时间内求解任意$0 < {\epsilon }^{\prime } < \epsilon$的3sum问题，违背了3sum假设。

### A.6 Proof of Lemma 5.9

### A.6 引理5.9的证明

### A.7 Proof of Lemma 6.5

### A.7 引理6.5的证明

For the "if" direction,we can eliminate absorbed atoms from $Q$ to obtain ${Q}^{m}$ after making sure that the tuples in the database satisfy those atoms. Thus,to remove an atom $S\left( \overrightarrow{Y}\right)$ which is absorbed by $R\left( \overrightarrow{X}\right)$ ,we filter the relation $R$ based on the tuples of $S$ . Then, ${Q}^{m}$ over the filtered database has the same answers as $Q$ over the original one. For the "only if" direction,each atom $S\left( \overrightarrow{Y}\right)$ that appears in $Q$ but not ${Q}^{m}$ is absorbed by some $R\left( \overrightarrow{X}\right)$ . We create the relation $S$ by copying ${\pi }_{\overrightarrow{Y}}\left( R\right)$ into it,essentially making the atom $S\left( \overrightarrow{Y}\right)$ obsolete. Note that we are allowed to create $S$ without restrictions because $Q$ has no self-joins,hence the database doesn’t already contain the relation. Then, $Q$ over the extended database has the same answers as ${Q}^{m}$ over the original one. The above reductions take linear time, which is dominated by ${T}_{S}\left( n\right)$ since ${T}_{S}\left( n\right)$ is trivially in $\Omega \left( n\right)$ for the selection problem.

对于"若"方向，在确保数据库中的元组满足这些原子条件后，我们可以从$Q$中消除被吸收的原子以获得${Q}^{m}$。具体而言，要移除被$R\left( \overrightarrow{X}\right)$吸收的原子$S\left( \overrightarrow{Y}\right)$，需根据$S$的元组对关系$R$进行过滤。此时，过滤后数据库上的${Q}^{m}$与原数据库上$Q$的查询结果相同。对于"仅若"方向，每个出现在$Q$但未出现在${Q}^{m}$中的原子$S\left( \overrightarrow{Y}\right)$都被某个$R\left( \overrightarrow{X}\right)$吸收。我们通过将${\pi }_{\overrightarrow{Y}}\left( R\right)$复制到其中来创建关系$S$，这使得原子$S\left( \overrightarrow{Y}\right)$实质上失效。注意由于$Q$无自连接，我们可以无限制地创建$S$，因为数据库原本就不包含该关系。此时，扩展数据库上的$Q$与原数据库上${Q}^{m}$的查询结果相同。上述归约过程耗时线性，由${T}_{S}\left( n\right)$主导，因为对于选择问题而言${T}_{S}\left( n\right)$显然属于$\Omega \left( n\right)$。

### A.8 Proof of Lemma 6.6

### A.8 引理6.6的证明

根据引理6.5，只需在查询$Q\left( \overrightarrow{X}\right)  :  - R\left( \overrightarrow{X}\right)$上解决选择问题即可，该查询是所有具有$\operatorname{mh}\left( Q\right)  = 1$的查询的最大收缩。首先将属性权重转换为元组权重。对于每个元组$r \in  R$，其权重计算为$w\left( r\right)  =$$\mathop{\sum }\limits_{{x \in  \overrightarrow{X}}}{w}_{x}\left( {r\left( x\right) }\right)$。因此，权重$w\left( r\right)$即为查询答案的权重。该过程对$R$的$O\left( n\right)$个元组耗时$O\left( n\right)$。随后，在$R$上应用线性时间选择算法[6]即可获得第${k}^{\text{th }}$小的查询结果。

### A.9 Proof of Lemma 6.10

### A.9 引理6.10的证明

## B INVERTED ACCESS BY LEXICOGRAPHIC ORDER

## B 按字典序的倒排访问

A straightforward adaptation of Algorithm 1 can be used to achieve inverted access: given a query result as the input, we return its index according to the lexicographic order. Algorithm 2 is almost the same algorithm as Algorithm 1 except that the choices in each iteration are made according to the given answer and the corresponding index is constructed (instead of the opposite). The algorithm runs in constant time per answer since every operation can be done within that time (unlike Algorithm 1, there is no need for binary search here).

通过直接改编算法1即可实现逆向访问：以查询结果作为输入，我们根据字典序返回其索引。算法2与算法1几乎是相同的算法，区别仅在于每次迭代中的选择是根据给定答案做出的，并构建相应索引（而非相反操作）。该算法在每个答案上的运行时间为常数级，因为每个操作都能在该时间内完成（与算法1不同，此处无需进行二分查找）。
