## ABSTRACT

## 摘要

Most of the prior work in massively parallel data processing assumes homogeneity, i.e., every computing unit has the same computational capability and can communicate with every other unit with the same latency and bandwidth. However, this strong assumption of a uniform topology rarely holds in practical settings, where computing units are connected through complex networks. To address this issue, Blanas et al. [9] recently proposed a topology-aware massively parallel computation model that integrates the network structure and heterogeneity in the modeling cost. The network is modeled as a directed graph, where each edge is associated with a cost function that depends on the data transferred between the two endpoints. The computation proceeds in synchronous rounds and the cost of each round is measured as the maximum cost over all the edges in the network.

现有大规模并行数据处理研究大多基于同构性假设，即所有计算单元具有相同算力且通信时延与带宽均等。然而这种均匀拓扑的强假设在实际场景中极少成立，计算单元往往通过复杂网络互连。针对此问题，Blanas等人[9]近期提出了一种拓扑感知的大规模并行计算模型，将网络结构和异构性纳入成本建模。该模型将网络表示为有向图，每条边配备与端点间传输数据量相关的成本函数。计算过程以同步轮次推进，每轮成本按网络中所有边的最大成本计。

In this work, we take the first step into investigating three fundamental data processing tasks in this topology-aware parallel model: set intersection, cartesian product, and sorting. We focus on network topologies that are tree topologies, and present both lower bounds as well as (asymptotically) matching upper bounds. Instead of assuming a worst-case distribution as in previous results, the optimality of our algorithms is with respect to the initial data distribution among the network nodes. Apart from the theoretical optimality of our results, our protocols are simple, use a constant number of rounds, and we believe can be implemented in practical settings as well.

本研究首次在该拓扑感知并行模型中探索三个基础数据处理任务：集合交集、笛卡尔积和排序。我们聚焦树状拓扑网络，不仅给出了下界证明，还提出了（渐进）匹配的上界算法。与先前研究采用最坏情况分布假设不同，我们算法的优化目标针对网络节点间的初始数据分布。除理论最优性外，所提协议实现简洁，仅需恒定轮次，且具备实际部署可行性。

## 1 INTRODUCTION

## 1 引言

The popularity of massively parallel data processing systems has led to an increased interest in studying the formal underpinnings of massively parallel models. As a simplification of the Bulk Synchronous Parallel (BSP) model [47], the Massively Parallel Computation (MPC) model [30] has enjoyed much success in studying algorithms for query evaluation [7, 8, 25-29, 48], as well as other fundamental data processing tasks $\left\lbrack  {2 - 4,6,{21},{22},{24}}\right\rbrack$ . In the MPC model,any pair of compute nodes in a cluster communicates via a point-to-point channel. Computation proceeds in synchronous rounds: at each round, all nodes first exchange messages and then perform computation on their local data.

大规模并行数据处理系统的普及引发了人们对研究大规模并行模型形式化基础的浓厚兴趣。作为批量同步并行(BSP)模型[47]的简化，大规模并行计算(MPC)模型[30]在查询评估算法[7,8,25-29,48]以及其他基础数据处理任务$\left\lbrack  {2 - 4,6,{21},{22},{24}}\right\rbrack$的研究中取得了显著成功。MPC模型中，集群内任意计算节点通过点对点通道进行通信，计算以同步轮次推进：每轮所有节点先交换消息，再对本地数据执行计算。

Algorithms in the MPC model operate on a strong assumption of homogeneity: every compute node has the same data processing capability and communicates with every other node with the same latency and bandwidth. In practice, however, large deployments are heterogeneous in their computing capabilities, often consisting of different generations of CPUs and GPUs. In the cloud, the speed of communication differs based on whether the compute nodes are located within the same rack, across racks, or across datacenters. In addition to static effects from the network topology, a model needs to capture the dynamic effects of different algorithms that may cause network contention. This homogeneity assumption is not confined in the theoretical development of algorithms, but it is also used when deploying algorithms in the real world.

MPC模型算法建立在强同质性假设上：每个计算节点具有相同数据处理能力，且节点间通信延迟与带宽均相同。然而实际部署中，大型计算集群通常由不同代际的CPU和GPU组成，存在计算能力异构性。云环境中，通信速度也因计算节点位于同机架、跨机架或跨数据中心而存在差异。除网络拓扑的静态影响外，模型还需捕捉不同算法可能导致网络争用的动态效应。这种同质性假设不仅存在于算法理论研究中，实际部署时也常被沿用。

Recent work has started taking into account the impact of network topology for data processing. In the model proposed by Chat-topadhyay et al. $\left\lbrack  {{11},{12}}\right\rbrack$ ,the underlying network is modeled as a graph, where nodes communicate with their neighbors through the connected edges. Computation proceeds in rounds. In each round, $\widetilde{O}\left( 1\right)$ bits ${}^{1}$ can be exchanged per edge. The complexity of algorithms in such a model is measured by the number of rounds. Using the same model, Langberg et al. [32] prove tight topology-sensitive bounds on the round complexity for computing functional aggregate queries. Although these algorithmic results have appealing theoretical guarantees, they are unrealistic starting points for implementation. As the number of rounds required is usually polynomial in terms of the data size, the synchronization cost would be extremely high in practice. In addition, the size of the data that can be exchanged per edge in each round is too small; the compute nodes in today's mainstream parallel data processing systems can process gigabytes of data in each round.

近期研究开始关注网络拓扑对数据处理的影响。Chattopadhyay等人$\left\lbrack  {{11},{12}}\right\rbrack$提出的模型中，底层网络被建模为图结构，节点通过连接边与相邻节点通信。计算仍按轮次推进，每轮每条边可交换$\widetilde{O}\left( 1\right)$比特${}^{1}$数据。该模型通过轮次数量衡量算法复杂度。基于相同模型，Langberg等人[32]证明了功能聚合查询计算轮次复杂度的紧拓扑敏感边界。尽管这些算法结果具有吸引人的理论保证，但作为实现起点并不现实：所需轮次通常与数据规模呈多项式关系，实践中同步开销极高；且每轮单边数据交换量过小，而现代主流并行数据处理系统每轮可处理GB级数据。

Recently, Blanas et al. [9] proposed a new massively parallel data processing model that is aware of the network topology as well as network bandwidth. The underlying communication network is represented as a directed graph, where each edge is associated with a cost function that depends on the data transferred between the two endpoints. A subset of the nodes in the network consists of compute nodes, i.e., nodes that can store data and perform computation-the remaining nodes can only route data to the desired destination. Computation still proceeds in rounds: in each round, each compute node sends data to other compute nodes, receives data, and then performs local computation. There is no limit on the size of the data that can be transmitted per edge; the cost is defined as the sum across all rounds of the maximum cost over all edges in the network at each round. This model is general enough to capture the MPC model as a special case.

近期Blanas等人[9]提出新型感知网络拓扑与带宽的大规模并行数据处理模型。底层通信网络表示为有向图，每条边关联取决于端点间传输数据的成本函数。网络节点子集构成计算节点（可存储数据并执行计算），其余节点仅作数据路由。计算仍分轮次进行：每轮各计算节点发送数据、接收数据后执行本地计算。单边传输数据量无限制，成本定义为所有轮次中每轮网络各边最大成本之和。该模型具有足够通用性，可将MPC模型作为特例包含。

In this work, we use the above topology-aware model to prove lower bounds and design algorithms for three fundamental data processing tasks: set intersection, cartesian product, and sorting. These three tasks are the essential building blocks for evaluating any complex analytical query in a data processing system.

本研究中，我们采用上述拓扑感知模型来证明下界并设计三种基础数据处理任务的算法：集合交集、笛卡尔积和排序。这三个任务是数据处理系统中评估任何复杂分析查询的基本构建模块。

In contrast to prior work, which either assumes a worst-case or uniform initial data distribution over the nodes in the network, we study algorithms in a more fine-grained manner by assuming that the cardinality of the initial data placed at each node can be arbitrary and is known in advance. This information allows us to build more optimized algorithms that can take advantage of data placement to discover a more efficient communication pattern.

与先前假设网络节点初始数据分布为最坏情况或均匀分布的研究不同，我们通过假设每个节点初始数据基数可任意指定且预先已知，以更细粒度方式研究算法。这些信息使我们能构建更优化的算法，利用数据布局发现更高效的通信模式。

Our contributions. We summarize our algorithmic results in Table 1. Our results are restricted to network topologies that have two properties. First,they are symmetric,i.e.,for each link(u,v) there exists a link(v,u)with the same bandwidth. Second,the network graph is a tree. Even with these two restrictions, we can capture several widely deployed topologies, such as star topologies and fat trees. All our algorithms are simple to describe and run either in a single round or in a constant number of rounds, hence requiring minimal synchronization. We thus believe that they form a good starting point for an efficient practical implementation. We next present our results for each data processing task in more detail.

我们的贡献。我们在表1中总结了算法成果。研究结果限于具备两个特性的网络拓扑：一是对称性（即每条链路(u,v)都存在带宽相同的反向链路(v,u)）；二是网络图呈树状结构。即便有这两个限制，仍可涵盖星型拓扑和胖树等广泛部署的拓扑结构。所有算法描述简单，仅需单轮或恒定轮次运行，同步需求极低，因此是高效实际实现的理想起点。下文将详细阐述各数据处理任务的研究成果。

- Set Intersection (Section 3). In this task, we want to compute the intersection $R \cap  S$ of two sets. Our lower bound for set intersection uses classic results from communication complexity on the lopsided set disjointness problem. This lower bound has a rather complicated form (as shown in Section 3.1), since each link has a different data capacity budget depending on the underlying network as well as the initial data distribution. Since set intersection is a computation-light but communication-heavy task, the challenge is how to effectively route the data according to the capacity of each link. We design a single-round randomized routing strategy for set intersection that matches the lower bound with high probability, losing only a polylogarithmic factor (w.r.t. the input size and network size). Surprisingly, the routing depends only on the topology and initial data placement, but not the bandwidth of the links.

- 集合交集（第3节）。该任务需计算两个集合的交集$R \cap  S$。我们基于非对称集合不相交问题的通信复杂度经典结果推导下界，其形式较为复杂（如第3.1节所示），因为每条链路的数据容量预算取决于底层网络和初始数据分布。由于集合交集是计算轻量但通信密集的任务，核心挑战在于如何根据链路容量有效路由数据。我们设计了单轮随机路由策略，以极高概率匹配下界，仅损失输入规模与网络规模的多对数因子。值得注意的是，该路由策略仅依赖拓扑结构和初始数据布局，与链路带宽无关。

- Cartesian Product (Section 4). Here we want to compute the cross product $R \times  S$ of two sets. This task is fundamental for various join operators,such as natural join, $\theta$ -join,similarity join and set containment join. We derive two lower bounds of different flavor. The first lower bound has a similar form as that for set intersection. The second lower bound uses instead a counting argument, which states that each pair in the cartesian product must be enumerated by at least one compute node, and the two elements participating in this result should reside on the same node when it is enumerated. We propose a one-round deterministic routing strategy for computing the cartesian product, which has asymptotically optimal guarantees. Our protocol generalizes the HyperCube algorithm that is used to compute the cartesian product in the MPC model [1].

- 笛卡尔积（第4节）。本任务需计算两个集合的叉积$R \times  S$，这是自然连接、$\theta$连接、相似性连接和集合包含连接等各类连接操作的基础。我们推导了两种不同风格的下界：第一种形式与集合交集下界相似；第二种采用计数论证，说明笛卡尔积中每个结果对必须被至少一个计算节点枚举，且参与该结果的元素在枚举时应驻留同一节点。我们提出计算笛卡尔积的单轮确定性路由策略，具有渐近最优保证。该协议推广了MPC模型[1]中计算笛卡尔积的HyperCube算法。

- Sorting (Section 5). We define a valid ordering of compute nodes as any left-to-right traversal of the underlying network tree, after picking an arbitrary node as the root. If the ordering of compute nodes is ${v}_{1},{v}_{2},{v}_{3},\ldots$ ,at the end of the algorithm all elements on node ${v}_{i}$ are in sorted order and no larger than those on node ${v}_{j}$ if $i < j$ . Our lower bound again has a similar form to the one we derived for set intersection. We present a sampling-based sorting algorithm which runs in a constant number of rounds and matches our lower bound with high probability. The protocol is again independent of the topology and the bandwidth, and depends only on the initial placement of the data.

- 排序（第5节）。我们将计算节点的有效排序定义为选定任意根节点后，对底层网络树的任意从左到右遍历。若计算节点排序为${v}_{1},{v}_{2},{v}_{3},\ldots$，算法结束时节点${v}_{i}$上的所有元素均有序排列，且当$i < j$时不大于节点${v}_{j}$上的元素。我们的下界形式与集合交集下界相似。提出的基于采样的排序算法在恒定轮次内运行，以极高概率匹配下界。该协议同样独立于拓扑和带宽，仅取决于数据初始布局。

## 2 THE COMPUTATIONAL MODEL

## 2 计算模型

In this section, we present the computational model we will use for this work.

本节阐述本研究所采用的计算模型。

Network Model. We model the network topology using a directed graph $G = \left( {V,E}\right)$ . Each edge $e \in  E$ represents a network link with bandwidth ${w}_{e} \geq  0$ ,where the direction of the edge captures the direction of the data flow. We distinguish a subset of nodes in the network, ${V}_{C} \subseteq  V$ ,to be compute nodes. Compute nodes are the only nodes in the network that can store data and perform computation on their local data. Non-compute nodes can only route data. We only consider connected networks, where every pair of compute nodes is connected through a directed path.

网络模型。我们使用有向图$G = \left( {V,E}\right)$建模网络拓扑，每条边$e \in  E$代表带宽为${w}_{e} \geq  0$的网络链路，边方向表示数据流向。网络中存在特定计算节点子集${V}_{C} \subseteq  V$，唯有计算节点可存储数据并执行本地计算，非计算节点仅能路由数据。我们仅考虑连通网络，其中任意计算节点对都通过有向路径相连。

Computation. A parallel algorithm A proceeds in sequential rounds (or phases). We denote by $r \in  \mathbb{N}$ the number of rounds of the algorithm. In the beginning,each compute node $v \in  {V}_{C}$ holds part of the input $I$ ,denoted as ${X}_{0}\left( v\right)  \subseteq  I$ . In this work,we assume that ${\left\{  {X}_{0}\left( v\right) \right\}  }_{v \in  {V}_{C}}$ forms a partition of the input $I$ ; in other words, there is no initial data duplication across the nodes. The goal of the algorithm is to compute a function over the input $I$ ,such that in the end the compute nodes together hold the function output.

计算过程。并行算法A按顺序轮次（或阶段）推进。我们用$r \in  \mathbb{N}$表示算法的总轮次数。初始时，每个计算节点$v \in  {V}_{C}$持有部分输入数据$I$，记为${X}_{0}\left( v\right)  \subseteq  I$。本研究中，我们假定${\left\{  {X}_{0}\left( v\right) \right\}  }_{v \in  {V}_{C}}$构成输入数据$I$的一个划分，即节点间不存在初始数据重复。算法的目标是对输入$I$执行函数计算，最终使计算节点共同持有函数输出结果。

We also assume that algorithm $\mathbb{A}$ has knowledge of the following: (i) the topology of the graph, (ii) the bandwidth of each link, and (iii) $\left| {{X}_{0}\left( v\right) }\right|$ for each compute node $v \in  {V}_{C}$ . In the case of relational data, we further assume that the algorithm knows the cardinality of the local fragment for each relation.

我们进一步假设算法$\mathbb{A}$知晓以下信息：(i) 图的拓扑结构，(ii) 每条链路的带宽，以及(iii) 每个计算节点$v \in  {V}_{C}$的$\left| {{X}_{0}\left( v\right) }\right|$。对于关系型数据，我们还假定算法知晓每个关系的本地片段基数。

We use ${X}_{i}\left( v\right)$ to denote the data stored at compute node $v \in  {V}_{C}$ after the $i$ -th round completes,where $i = 1,2,\ldots ,r$ . At every round, the compute nodes first perform some computation on their local data. Then, they communicate by sending data to other compute nodes in the network. We assume that for a data transfer from compute node $u$ to compute node $v$ ,the algorithm must explicitly specify the routing path (or a collection of routing paths). We use ${Y}_{i}\left( e\right)$ to denote the data that is routed through link $e$ during round $i$ ,and $\left| {{Y}_{i}\left( e\right) }\right|$ denote its total size measured in bits.

采用${X}_{i}\left( v\right)$表示第$i$轮完成后计算节点$v \in  {V}_{C}$存储的数据，其中$i = 1,2,\ldots ,r$。每轮运行时，计算节点首先对其本地数据进行运算，随后通过网络向其他计算节点发送数据实现通信。我们规定：当数据从计算节点$u$传输至$v$时，算法必须明确指定路由路径（或路径集合）。用${Y}_{i}\left( e\right)$表示第$i$轮期间经链路$e$路由的数据，$\left| {{Y}_{i}\left( e\right) }\right|$表示其以比特为单位的总体大小。

Cost Model. Since the algorithm proceeds in sequential rounds, we can decompose the cost of the algorithm,denoted $\operatorname{cost}\left( \mathbb{A}\right)$ ,as the sum of the costs for each round $i$ ,

成本模型。由于算法按序贯轮次执行，可将算法总成本$\operatorname{cost}\left( \mathbb{A}\right)$分解为各轮次成本$i$之和。

$$
\operatorname{cost}\left( \mathbb{A}\right)  = \mathop{\sum }\limits_{{i = 1}}^{r}{\operatorname{cost}}_{i}\left( \mathbb{A}\right) 
$$

The model captures the cost of each round by considering only the cost of communication. The cost of the $i$ -th round is

该模型通过仅考虑通信成本来捕获每轮开销。第$i$轮的成本为

$$
{\operatorname{cost}}_{i}\left( \mathbb{A}\right)  \mathrel{\text{:=}} \mathop{\max }\limits_{{e \in  E}}\left| {{Y}_{i}\left( e\right) }\right| /{w}_{e}.
$$

In other words, the cost of each round is captured by the cost of transferring data through the most bottlenecked link in the network. In some cases, it will be convenient to express the cost using tuples/elements instead of bits, which we will mention explicitly.

换言之，每轮成本由网络中最拥堵链路的数据传输成本决定。某些情况下更适合用元组/元素而非比特表示成本，我们将明确说明。

Even though the model does not take into account any computation time in the cost, it is possible to incorporate computation costs in the model by appropriately transforming the underlying graph - for more details, see [10]. We should note here that our model does not capture factors such as congestion on a router node, or communication delays due to large network diameter.

虽然该模型未计入计算时间成本，但可通过适当转换底层图结构来纳入计算成本——详见文献[10]。需特别说明，本模型未考虑路由节点拥塞或大网络直径导致的通信延迟等因素。

### 2.1 Network Topologies

### 2.1 网络拓扑结构

Even though the model supports general network topologies, computer networks often have a specific structure. When the underlying topology has some structure, several problems (such as routing $\left\lbrack  {5,{13},{14},{36}}\right\rbrack  )$ admit more efficient solutions than what is achievable for general topologies. It is therefore natural to consider restrictions on the topology that are of either theoretical or practical interest.

尽管模型支持通用网络拓扑，但计算机网络通常具有特定结构。当底层拓扑存在规律时，诸如路由$\left\lbrack  {5,{13},{14},{36}}\right\rbrack  )$等问题可获得比通用拓扑更高效的解决方案。因此研究具有理论或实践意义的受限拓扑很自然。

Symmetric Network. Wired networks support full duplex operation that allows simultaneous communication in both directions of a link. Furthermore, datacenter networks allocate the same bandwidth for transmitting and receiving data for each node. These networks are represented in the model using a symmetric network. We say that a network topology is symmetric if for every edge $e = \left( {u,v}\right)  \in  E$ ,we also have that ${e}^{\prime } = \left( {v,u}\right)  \in  E$ with ${w}_{e} = {w}_{{e}^{\prime }}$ . In other words,the cost of sending data from $u$ to $v$ is the same as the cost of sending the same data from $v$ to $u$ .

对称网络。有线网络支持全双工操作，允许链路双向同时通信。此外，数据中心网络为各节点分配相同的收发带宽。这类网络在模型中表示为对称网络：若对任意边$e = \left( {u,v}\right)  \in  E$都存在${e}^{\prime } = \left( {v,u}\right)  \in  E$且${w}_{e} = {w}_{{e}^{\prime }}$，则称拓扑对称。即从$u$到$v$与反向传输相同数据的成本相等。

Star Topology. The most common topology for small clusters is the star topology, where all computers are connected to a single switch. A star network with $p + 1$ nodes has $p$ compute nodes ${V}_{C} = \left\{  {{v}_{1},{v}_{2},\ldots ,{v}_{p}}\right\}$ that are all connected to a central node $w$ that only does routing. Figure 1a depicts an example of a star network. Within a node, a multi-core CPU also exhibits a star topology: individual CPU cores exchange data through a shared cache and memory hierarchy, which implicitly forms the center of the star.

星型拓扑。小型集群最常用的是星型拓扑，所有计算机连接至单一交换机。含$p + 1$个节点的星型网络中，$p$个计算节点${V}_{C} = \left\{  {{v}_{1},{v}_{2},\ldots ,{v}_{p}}\right\}$全部连接至仅负责路由的中心节点$w$。图1a展示星型网络示例。节点内部的多核CPU也呈现星型拓扑：各CPU核心通过共享缓存和内存层次交换数据，隐式形成星型中心。

Tree Topology. As the network grows, a single router is no longer sufficient to connect all nodes. A common solution to scale the network further is to arrange $r$ routers $\left\{  {{o}_{1},{o}_{2},\cdots ,{o}_{r}}\right\}$ in a star topology,and connect $p$ compute nodes ${V}_{C} = \left\{  {{v}_{1},\cdots ,{v}_{p}}\right\}$ to individual routers. Figure $1\mathrm{\;b}$ shows an example of a tree topology. A key property in a tree topology is that there exists a unique directed path between any two compute nodes, hence routing is trivial.

树状拓扑。当网络规模扩大时，单一路由器无法连接所有节点。常用扩展方案是将$r$台路由器$\left\{  {{o}_{1},{o}_{2},\cdots ,{o}_{r}}\right\}$按星型排列，并将$p$个计算节点${V}_{C} = \left\{  {{v}_{1},\cdots ,{v}_{p}}\right\}$连接至各路由器。图$1\mathrm{\;b}$展示树状拓扑示例。其关键特性是任意两计算节点间存在唯一有向路径，因此路由选择变得简单。

In this work, we will focus on symmetric tree topologies. We make two observations about such topologies:

本研究聚焦对称树状拓扑，对此类拓扑有两个重要观察：

- Assume w.l.o.g. that every compute node is a leaf. Indeed, if we have a non-leaf compute node $v \in  {V}_{C}$ ,we can transform $G$ to a new graph ${G}^{\prime }$ by adding a new compute node ${v}^{\prime }$ , introduce a new link between $v,{v}^{\prime }$ with bandwidth $+ \infty$ ,and make $v$ a non-compute node.

- 不妨假设所有计算节点均为叶节点。若存在非叶计算节点$v \in  {V}_{C}$，可通过新增计算节点${v}^{\prime }$、添加带宽为$+ \infty$的链路$v,{v}^{\prime }$，并将$v$转为非计算节点，将$G$转换为新图${G}^{\prime }$。

- Assume w.l.o.g. that there are no nodes with degree 2. Indeed, consider a node $v$ with two adjacent edges ${e}_{1} = \left( {v,{u}_{1}}\right)$ and ${e}_{2} = \left( {v,{u}_{2}}\right)$ . We can remove $v$ and replace the two edges with a single edge $e = \left( {{u}_{1},{u}_{2}}\right)$ with bandwidth $\min \left\{  {{w}_{{e}_{1}},{w}_{{e}_{2}}}\right\}$ .

- 不失一般性，假设不存在度为2的节点。具体而言，考虑一个节点$v$及其两条相邻边${e}_{1} = \left( {v,{u}_{1}}\right)$和${e}_{2} = \left( {v,{u}_{2}}\right)$。我们可以移除$v$，并将这两条边替换为一条带宽为$\min \left\{  {{w}_{{e}_{1}},{w}_{{e}_{2}}}\right\}$的边$e = \left( {{u}_{1},{u}_{2}}\right)$。

### 2.2 Relation to the MPC Model

### 2.2 与MPC模型的关联

We discuss here how the topology-aware model can capture the MPC model $\left\lbrack  {7,{31}}\right\rbrack$ as a special case.

此处我们讨论拓扑感知模型如何将MPC模型$\left\lbrack  {7,{31}}\right\rbrack$作为特例进行捕捉。

Recall that in the MPC model we have a collection of $p$ nodes. The MPC model is topology-agnostic: every machine can communicate with any other machine, and the cost of a round is defined as the maximum amount of data that is received during this round across all machines. The MPC model corresponds to an asymmetric star topology with $p$ compute nodes. For every edge $e = \left( {{v}_{i},o}\right)$ that goes from a compute node to the center $o$ the bandwidth is ${w}_{e} =  + \infty$ , while for the inverse edge ${e}^{\prime } = \left( {o,{v}_{i}}\right)$ the bandwidth is ${w}_{{e}^{\prime }} = 1$ .

回顾MPC模型，我们拥有$p$个节点的集合。该模型与拓扑无关：每台机器可与任意其他机器通信，每轮成本定义为该轮次所有机器接收数据的最大量。MPC模型对应具有$p$个计算节点的非对称星型拓扑。对于从计算节点指向中心$o$的边$e = \left( {{v}_{i},o}\right)$，其带宽为${w}_{e} =  + \infty$；而反向边${e}^{\prime } = \left( {o,{v}_{i}}\right)$的带宽则为${w}_{{e}^{\prime }} = 1$。

It should be noted that all previous works using the MPC model assume a uniform data distribution, where each node initially receives $N/p$ data,where $N$ is the input size. This assumption has been used both for lower and upper bounds. In contrast, our algorithms and lower bounds take the sizes of the initial data distribution as parameters.

需注意，此前所有基于MPC模型的研究均假设数据均匀分布，即每个节点初始接收$N/p$数据（其中$N$为输入规模）。该假设同时用于上界与下界证明。与之相对，我们的算法和下界证明将初始数据分布规模作为参数。

## 3 SET INTERSECTION

## 3 集合求交

In the set intersection problem,we are given two sets $R$ and $S$ . Our goal is to enumerate all pairs $\left( {r,s}\right)  \in  R \cap  S$ . Note that there is no designated node for each output pair, as long as it is emitted by at least one node. We assume that all elements from both sets are drawn from the same domain.

在集合求交问题中，给定两个集合$R$和$S$。目标是枚举所有配对$\left( {r,s}\right)  \in  R \cap  S$。注意输出配对无需指定归属节点，只要至少被一个节点输出即可。假设两集合所有元素均来自相同域。

Given an initial distribution $\mathcal{D}$ of the data across the compute nodes,we denote by ${R}_{v}^{\mathcal{D}},{S}_{v}^{\mathcal{D}}$ the elements from $R$ and $S$ respectively in node $v$ . Let ${N}_{\mathcal{v}}^{\mathcal{D}} = \left| {R}_{\mathcal{v}}^{\mathcal{D}}\right|  + \left| {S}_{\mathcal{v}}^{\mathcal{D}}\right|$ ,and ${N}^{\mathcal{D}} = \mathop{\sum }\limits_{\mathcal{v}}{N}_{\mathcal{v}} = \left| R\right|  + \left| S\right|$ . Whenever the context is clear,we will drop $\mathcal{D}$ from the notation.

给定计算节点间的初始数据分布$\mathcal{D}$，用${R}_{v}^{\mathcal{D}},{S}_{v}^{\mathcal{D}}$表示节点$v$中分别来自$R$和$S$的元素。设${N}_{\mathcal{v}}^{\mathcal{D}} = \left| {R}_{\mathcal{v}}^{\mathcal{D}}\right|  + \left| {S}_{\mathcal{v}}^{\mathcal{D}}\right|$，且${N}^{\mathcal{D}} = \mathop{\sum }\limits_{\mathcal{v}}{N}_{\mathcal{v}} = \left| R\right|  + \left| S\right|$。上下文明确时将省略$\mathcal{D}$的标注。

### 3.1 Lower Bound for Tree Topologies

### 3.1 树形拓扑的下界

We present a lower bound on the cost for the case of a symmetric tree topology. To prove the lower bound, we use a reduction from the lopsided set disjointness problem in communication complexity. In this problem,Alice holds a set $X$ of $n$ elements and Bob holds a set $Y$ of $m$ elements from some common domain. The goal is to decide whether the intersection $X \cap  Y$ is empty by minimizing communication. It is known $\left\lbrack  {{19},{44}}\right\rbrack$ that for any multi-round randomized communication protocol,either Alice has to send $\Omega \left( n\right)$ bits to Bob,or Bob has to send $\Omega \left( m\right)$ bits to Alice.

针对对称树形拓扑，我们提出成本下界证明。通过通信复杂性中的倾斜集合互斥问题归约，Alice持有$n$个元素的集合$X$，Bob持有$m$个元素的集合$Y$（元素来自共同域）。目标是通过最小化通信量判定$X \cap  Y$是否为空集。已知$\left\lbrack  {{19},{44}}\right\rbrack$：对于任何多轮随机通信协议，要么Alice需向Bob发送$\Omega \left( n\right)$比特，要么Bob需向Alice发送$\Omega \left( m\right)$比特。

To construct the reduction,we observe that any edge $e = \left( {u,v}\right)$ defines a partitioning of the compute nodes in the tree $G$ into two subsets: ${V}_{e}^{ - }$ and ${V}_{e}^{ + }$ . Here, ${V}_{e}^{ - }$ is the set of compute nodes in the same side as $u$ ,and ${V}_{e}^{ + }$ in the same side as $v$ . Hence,any algorithm that computes the set intersection in the tree topology also solves a lopsided set disjointness problem, where Alice holds all data located in ${V}_{e}^{ - }$ ,Bob holds all data located in ${V}_{e}^{ + }$ ,and they can only communicate through the edge $e$ . Following this core idea,we can show the following lower bound.

在构建归约时，我们观察到任意边$e = \left( {u,v}\right)$将树形结构$G$中的计算节点划分为两个子集：${V}_{e}^{ - }$和${V}_{e}^{ + }$。其中，${V}_{e}^{ - }$表示与$u$同侧的计算节点集合，${V}_{e}^{ + }$表示与$v$同侧的集合。因此，任何在树形拓扑中计算集合交集的算法，实际上都在解决一个倾斜集合不相交问题——Alice持有${V}_{e}^{ - }$内的所有数据，Bob持有${V}_{e}^{ + }$内的所有数据，且两者仅能通过边$e$通信。基于这一核心思想，我们可以推导出如下下界。

$$

### 3.2 Warmup on Symmetric Star

### 3.2 对称星型拓扑预热

We first consider the star topology to present some of the key ideas. W.l.o.g. we assume $\left| R\right|  \leq  \left| S\right|$ . We present a one-round algorithm based on randomized hashing.

我们首先分析星型拓扑以阐述核心思想。不失一般性，假设$\left| R\right|  \leq  \left| S\right|$。现提出基于随机哈希的单轮算法。

Our algorithm (Algorithm 1) in its core performs a randomized hash join. It first partitions the compute nodes into two subsets, ${V}_{\alpha }$ and ${V}_{\beta }$ ,depending on the size of the local data. Define ${N}^{\prime } = \left| R\right|  + \mathop{\sum }\limits_{{v \in  {V}_{\alpha }}}\left| {S}_{v}\right|$ . Let $h$ be a random hash function that maps independently each $a$ in the domain to node $v \in  {V}_{C}$ with the following probability:

我们的算法（算法1）核心执行随机化哈希连接。它首先根据本地数据大小将计算节点划分为两个子集${V}_{\alpha }$和${V}_{\beta }$。定义${N}^{\prime } = \left| R\right|  + \mathop{\sum }\limits_{{v \in  {V}_{\alpha }}}\left| {S}_{v}\right|$。设$h$为随机哈希函数，独立地将定义域内每个$a$映射到节点$v \in  {V}_{C}$，映射概率如下：

$$
\Pr \left\lbrack  {h\left( a\right)  = v}\right\rbrack   = \left\{  \begin{array}{ll} {N}_{v}/{N}^{\prime }, & v \in  {V}_{\alpha } \\  \left| {R}_{v}\right| /{N}^{\prime }, & v \in  {V}_{\beta } \end{array}\right. 
$$

If ${V}_{\beta } = \varnothing$ ,then the algorithm performs a distributed hash join using the above hash function $h$ . Observe that the algorithm does not hash each value uniformly across the compute nodes, but with probability proportional to the input data ${N}_{v}$ that each node holds.

若${V}_{\beta } = \varnothing$，则算法使用上述哈希函数$h$执行分布式哈希连接。需注意该算法并非将每个值均匀哈希到计算节点，而是根据各节点持有输入数据${N}_{v}$的比例进行概率映射。

If ${V}_{\beta } \neq  \varnothing$ ,we perform hashing only on a subset of the data using a subset of the nodes. In particular,each node $v \in  {V}_{\beta }$ first gathers all the elements from $R$ (the smaller relation) and locally computes $R \cap  {S}_{\mathcal{U}}$ ,while hashing is used to compute the remaining set intersection. After the data is communicated, the intersection can be computed locally at each node.

若${V}_{\beta } \neq  \varnothing$，我们仅使用节点子集对数据子集执行哈希。具体而言，每个节点$v \in  {V}_{\beta }$首先从$R$（较小关系）收集所有元素并本地计算$R \cap  {S}_{\mathcal{U}}$，而哈希运算用于计算剩余集合交集。数据通信完成后，各节点可本地计算交集。

We next show that the above algorithm is optimal within a poly-logarithmic factor.

接下来我们将证明该算法在多项式对数因子内是最优的。

LEMMA 2. Let $G = \left( {V,E}\right)$ be a symmetric star topology,and consider sets $R,S$ with $N = \left| R\right|  + \left| S\right|$ . Then,STARINTERSECT computes the set intersection $R \cap  S$ with cost $O\left( {\log N\log \left| V\right| }\right)$ away from the optimal solution with high probability.

引理2. 设$G = \left( {V,E}\right)$为对称星型拓扑，考虑集合$R,S$满足$N = \left| R\right|  + \left| S\right|$。则STARINTERSECT算法以$O\left( {\log N\log \left| V\right| }\right)$的代价差高概率计算集合交集$R \cap  S$，该结果接近最优解。

Proof. The correctness of the algorithm is straightforward. We will next bound the cost of the algorithm. We will measure the cost using elements of the set; to translate to bits it suffices to add a $\log \left( N\right)$ factor which captures the number of bits necessary to represent each element.

证明。算法正确性显而易见。接下来我们将界定算法成本。使用集合元素度量成本；转换为比特数只需添加$\log \left( N\right)$因子，该因子表示表示每个元素所需的比特数。

To make the notation simpler,we will use ${w}_{v}$ to refer to the bandwidth ${w}_{e}$ of edge $e = \left( {v,w}\right)$ ,where $v \in  {V}_{C}$ and $w$ is the central node of the star topology. We can now reformulate the lower bound from Theorem 1 as

为简化符号，我们将用${w}_{v}$表示边$e = \left( {v,w}\right)$的带宽${w}_{e}$，其中$v \in  {V}_{C}$且$w$是星型拓扑的中心节点。现在可将定理1中的下界重新表述为：

$$
{C}_{LB} = \max \left\{  {\mathop{\max }\limits_{{v \in  {V}_{\alpha }}}\frac{\min \left\{  {{N}_{v},N - {N}_{v}}\right\}  }{{w}_{v}},\mathop{\max }\limits_{{v \in  {V}_{\beta }}}\frac{\left| R\right| }{{w}_{v}}}\right\}  
$$

We now distinguish two cases, depending on whether the edge is adjacent to a node in ${V}_{\alpha }$ or ${V}_{\beta }$ .

现在根据边是否与${V}_{\alpha }$或${V}_{\beta }$中的节点相邻，区分两种情况。

Case 1: $v \in  {V}_{\beta }$ . Consider the two edges(v,w)and(w,v). The number of tuples that will be sent through edge(v,w)is $\left| {R}_{v}\right|  \leq  \left| R\right|$ . As for the tuples received,node $v$ will receive $\left| R\right|  - \left| {R}_{v}\right|$ tuples from $R$ ,as well as some tuples from $S$ which are in expectation: $\frac{\left| {R}_{v}\right| }{{N}^{\prime }} \cdot  \mathop{\sum }\limits_{{v \in  {V}_{\alpha }}}\left| {S}_{v}\right|  \leq  \left| {R}_{v}\right|$ . Thus,the cost incurred by edges adjacent to ${V}_{\beta }$ is: $\mathop{\max }\limits_{{v \in  {V}_{\beta }}}\frac{\left| R\right| }{{w}_{v}} \leq  {C}_{LB}$ . Even though the above analysis just bounds the expectation, we can use Chernoff bounds to show that with probability polynomially small in the number of compute nodes, the number of tuples will not exceed the expectation by more than an $O\left( {\log \left| V\right| }\right)$ factor for any of the edges.

情况1：$v \in  {V}_{\beta }$。考虑边(v,w)和(w,v)。通过边(v,w)发送的元组数为$\left| {R}_{v}\right|  \leq  \left| R\right|$。对于接收的元组，节点$v$将从$R$接收$\left| R\right|  - \left| {R}_{v}\right|$个元组，以及来自$S$的若干元组，其期望值为：$\frac{\left| {R}_{v}\right| }{{N}^{\prime }} \cdot  \mathop{\sum }\limits_{{v \in  {V}_{\alpha }}}\left| {S}_{v}\right|  \leq  \left| {R}_{v}\right|$。因此，与${V}_{\beta }$相邻边的成本为：$\mathop{\max }\limits_{{v \in  {V}_{\beta }}}\frac{\left| R\right| }{{w}_{v}} \leq  {C}_{LB}$。尽管上述分析仅约束期望值，但我们可以使用切尔诺夫界证明：对于任何边，元组数量超过期望值的倍数不大于$O\left( {\log \left| V\right| }\right)$因子的概率是计算节点数量的多项式小量。

Case 2: $v \in  {V}_{\alpha }$ . We will bound separately the number of $R$ -tuples and $S$ -tuples that go through each edge.

情况2：$v \in  {V}_{\alpha }$。我们将分别约束通过每条边的$R$-元组和$S$-元组数量。

The expected number of $S$ -tuples that go through edge(w,v)is

经过边(w,v)的$S$元组期望数量为

$$
\left( {\mathop{\sum }\limits_{{u \in  {V}_{\alpha }}}\left| {S}_{u}\right|  - \left| {S}_{v}\right| }\right)  \cdot  \frac{{N}_{v}}{{N}^{\prime }} \leq  \left( {{N}^{\prime } - R - \left| {S}_{v}\right| }\right)  \cdot  \frac{{N}_{v}}{{N}^{\prime }}
$$

$$
 \leq  \frac{\left( {{N}^{\prime } - {N}_{v}}\right) {N}_{v}}{{N}^{\prime }} \leq  \min \left\{  {{N}_{v},N - {N}_{v}}\right\}  
$$

The third inequality is a direct application of the facts that $\min \{ a,b\}$ $\geq  \frac{a \cdot  b}{a + b}$ for any $a,b \geq  0$ and ${N}^{\prime } < N$ . Similarly,the expected number of $S$ -tuples that go through edge(v,w)is

第三个不等式直接应用了以下事实：对于任意$a,b \geq  0$和${N}^{\prime } < N$，有$\min \{ a,b\}$$\geq  \frac{a \cdot  b}{a + b}$。同理，经过边(v,w)的$S$元组期望数量为

$$
\left| {S}_{v}\right|  \cdot  \frac{{N}^{\prime } - {N}_{v}}{{N}^{\prime }} \leq  \frac{\left( {{N}^{\prime } - {N}_{v}}\right) {N}_{v}}{{N}^{\prime }} \leq  \min \left\{  {{N}_{v},N - {N}_{v}}\right\}  
$$

For $R$ -tuples,we distinguish two cases. If ${V}_{\beta } = \varnothing$ ,then we can bound the expected size using the same argument as above for $S$ -tuples. We now turn to the case where ${V}_{\beta } \neq  \varnothing$ . We first claim that ${N}_{v} \leq  N - {N}_{v}$ for each vertex $v \in  {V}_{\alpha }$ . Indeed,if not then we must have that $N - {N}_{\mathcal{U}} < \left| R\right|$ ,which implies that ${N}_{\mathcal{U}} > \left| S\right|$ . However,this is a contradiction since there exists $u \in  {V}_{\beta }$ with ${N}_{u} > \left| R\right|$ . Hence, it suffices to bound the $R$ -tuples that go through each edge by ${N}_{v}$ . Indeed,the number of $R$ -tuples that go through(v,w)for $v \in  {V}_{\alpha }$ are at most $\left| {R}_{v}\right|  \leq  {N}_{v}$ . As for the edge(w,v),the expected number of tuples that use the edge is:

对于$R$元组，我们区分两种情况。若${V}_{\beta } = \varnothing$，则可沿用前述$S$元组的论证方法来界定期望规模。现考虑${V}_{\beta } \neq  \varnothing$的情形。我们首先断言：对每个顶点$v \in  {V}_{\alpha }$都有${N}_{v} \leq  N - {N}_{v}$。若不成立，则必有$N - {N}_{\mathcal{U}} < \left| R\right|$，这将导致${N}_{\mathcal{U}} > \left| S\right|$。然而这与存在满足${N}_{u} > \left| R\right|$的$u \in  {V}_{\beta }$相矛盾。因此，只需将每条边通过的$R$元组数量界定在${N}_{v}$内。具体而言，对于$v \in  {V}_{\alpha }$，通过(v,w)的$R$元组数量至多为$\left| {R}_{v}\right|  \leq  {N}_{v}$。至于边(w,v)，使用该边的元组期望数量为：

$$
\left( {\left| R\right|  - \left| {R}_{v}\right| }\right)  \cdot  \frac{{N}_{v}}{{N}^{\prime }} \leq  \frac{\left| R\right| }{{N}^{\prime }} \cdot  {N}_{v} \leq  {N}_{v}
$$

Combining these two cases above yields the desired claim. Note that all expectation calculations can be extended to high probability statements by losing a factor of $O\left( {\log \left| V\right| }\right)$ as mentioned before.

综合上述两种情况可得所需结论。注意如前所述，所有期望计算均可通过损失$O\left( {\log \left| V\right| }\right)$倍系数扩展为高概率陈述。

平衡划分。算法第一步是计算计算节点${V}_{C}$的划分$\left\{  {{V}_{C}^{1},{V}_{C}^{2},\cdots ,{V}_{C}^{k}}\right\}$。具体而言，该算法寻求如图2所示的平衡划分。

Definition 4. A partition $\left\{  {{V}_{C}^{1},{V}_{C}^{2},\cdots ,{V}_{C}^{k}}\right\}$ of ${V}_{C}$ is balanced for data distribution $\mathcal{D}$ if the following properties hold:

定义4。对于数据分布$\mathcal{D}$，当满足以下性质时称${V}_{C}$的划分$\left\{  {{V}_{C}^{1},{V}_{C}^{2},\cdots ,{V}_{C}^{k}}\right\}$是平衡的：

(1) If two nodes are connected in ${G}_{a}$ ,they belong in the same block of the partition ;

(1) 若两个节点在${G}_{a}$中连通，则它们属于划分的同一区块；

(2) 每条边至多出现在划分一个区块的生成树中；

(3) For every block $i,\mathop{\sum }\limits_{{\mathcal{U} \in  {V}_{C}^{i}}}{N}_{\mathcal{U}}^{\mathcal{D}} \geq  \left| R\right|$ ;

(3) 对于每个区块$i,\mathop{\sum }\limits_{{\mathcal{U} \in  {V}_{C}^{i}}}{N}_{\mathcal{U}}^{\mathcal{D}} \geq  \left| R\right|$；

接下来分析通信成本。沿用先前方法，以元组数量衡量成本，再乘以$O\left( {\log N}\right)$系数转换为比特数。首先将下界重写为：

$$
{C}_{LB} = \max \left\{  {\mathop{\max }\limits_{{e \in  {E}_{\alpha }}}\frac{1}{{w}_{e}}\min \left\{  {\mathop{\sum }\limits_{{v \in  {V}_{e}^{ + }}}{N}_{v},\mathop{\sum }\limits_{{v \in  {V}_{e}^{ - }}}{N}_{v}}\right\}  ,\mathop{\max }\limits_{{e \in  {E}_{\beta }}}\frac{\left| R\right| }{{w}_{e}}}\right\}  
$$

We analyze the cost for the edges in ${E}_{\alpha },{E}_{\beta }$ separately.

Case: $e \in  {E}_{\beta }$ . We will bound the amount of data that goes through $e$ by $O\left( \left| R\right| \right)$ . By property (2) of a balanced partition, $e$ is included in at most one spanning tree,say of block ${V}_{C}^{i}$ . Then,w.h.p. the expected amount of $S$ -tuples that goes through $e$ is at most

$$
\frac{1}{\mathop{\sum }\limits_{{v \in  {V}_{C}^{i}}}{N}_{v}} \cdot  \left( {\mathop{\sum }\limits_{{v \in  {V}_{C}^{i} \cap  {V}_{e}^{ - }}}{N}_{v}}\right)  \cdot  \left( {\mathop{\sum }\limits_{{v \in  {V}_{C}^{i} \cap  {V}_{e}^{ + }}}{N}_{v}}\right)

 \leq  \min \left\{  {\mathop{\sum }\limits_{{v \in  {V}_{C}^{i} \cap  {V}_{e}^{ - }}}{N}_{v},\mathop{\sum }\limits_{{v \in  {V}_{C}^{i} \cap  {V}_{e}^{ + }}}{N}_{v}}\right\}   \leq  \left| R\right| 
$$

The first inequality comes from the fact that $\frac{a \cdot  b}{a + b} \leq  \min \{ a,b\}$ for any $a,b > 0$ . The second inequality is implied directly by property (4) of a balanced partition.

第一不等式源于对任意$a,b > 0$都有$\frac{a \cdot  b}{a + b} \leq  \min \{ a,b\}$。第二不等式直接由平衡分区性质(4)得出。

Case: $e \in  {E}_{\alpha }$ . We will bound the amount of data that goes through $e$ by $\min \left\{  {\mathop{\sum }\limits_{{v \in  {V}_{e}^{ - }}}{N}_{v},\mathop{\sum }\limits_{{v \in  {V}_{e}^{ + }}}{N}_{v}}\right\}$ . To bound the number of $S$ -tuples, we again notice that $e$ can belong in the spanning tree of at most one block,say ${V}_{C}^{i}$ . Hence,as in the previous case,w.h.p. the expected amount of $S$ -tuples that goes through $e$ is at most

情形：$e \in  {E}_{\alpha }$。将通过$e$的数据量上界设为$\min \left\{  {\mathop{\sum }\limits_{{v \in  {V}_{e}^{ - }}}{N}_{v},\mathop{\sum }\limits_{{v \in  {V}_{e}^{ + }}}{N}_{v}}\right\}$。为界定$S$元组数量，我们再次注意到$e$最多属于一个块的生成树（假设为块${V}_{C}^{i}$）。因此，类比前例，高概率条件下通过$e$的$S$元组期望数量至多为

$$
\frac{1}{\mathop{\sum }\limits_{{v \in  {V}_{C}^{i}}}{N}_{v}} \cdot  \left( {\mathop{\sum }\limits_{{v \in  {V}_{C}^{i} \cap  {V}_{e}^{ - }}}{N}_{v}}\right)  \cdot  \left( {\mathop{\sum }\limits_{{v \in  {V}_{C}^{i} \cap  {V}_{e}^{ + }}}{N}_{v}}\right)

## 4 CARTESIAN PRODUCT

## 4 笛卡尔积

In the cartesian product problem,we are given two sets $R,S$ with $\left| R\right|  = \left| S\right|  = N/2$ . (We will discuss in the end why the unequal case is challenging, even on the simple symmetric star topology). Our goal is to enumerate all pairs(r,s)for any $r \in  R,s \in  S$ ,such that the output pairs are distributed among the compute nodes by the end of the algorithm. Similar to set intersection, there is no designated node for each output pair, as long as it is emitted by at least one node. We assume that all elements are drawn from the same domain, and that initially the input data is partitioned across the compute nodes.

笛卡尔积问题中，给定两个集合$R,S$（基数$\left| R\right|  = \left| S\right|  = N/2$）。我们将讨论非对称情形（即使在简单对称星型拓扑下）的挑战性。目标是枚举所有(r,s)对（$r \in  R,s \in  S$），使输出对在算法结束时分布于各计算节点。与集合交类似，不要求每个输出对指定特定节点，只需至少被一个节点输出。假设所有元素来自同一域，且输入数据初始分布于计算节点间。

### 4.1 Lower Bounds on Symmetric Trees

### 4.1 对称树的下界

We present two lower bounds on cost for the case of a symmetric tree topology. The first one as stated in Theorem 7 has the same form as the one in Theorem 1 when $\left| R\right|  = \left| S\right|  = N/2$ ,but uses a slightly different argument. Both lower bounds are expressed in terms of elements, and not bits.

针对对称树拓扑，我们给出两个成本下界。定理7所述第一个下界形式与定理1相同（当$\left| R\right|  = \left| S\right|  = N/2$时），但论证略有不同。两个下界均以元素数量（非比特数）表示。

THEOREM 7. Let $G = \left( {V,E}\right)$ be a symmetric tree topology. Any algorithm computing $R \times  S$ has (tuple) cost $\Omega \left( {C}_{LB}\right)$ ,where

定理7. 设$G = \left( {V,E}\right)$为对称树拓扑，任何计算$R \times  S$的算法具有（元组）成本$\Omega \left( {C}_{LB}\right)$，其中

$$
{C}_{LB} = \mathop{\max }\limits_{{e \in  E}}\frac{1}{{w}_{e}} \cdot  \min \left\{  {\mathop{\sum }\limits_{{v \in  {V}_{e}^{ - }}}{N}_{v},\mathop{\sum }\limits_{{v \in  {V}_{e}^{ + }}}{N}_{v}}\right\}  .

Summing up the two inequalities,and observing that $\min \left\{  {\mathop{\sum }\limits_{{v \in  {V}_{e}^{ - }}}{N}_{v},\mathop{\sum }\limits_{{v \in  {V}_{e}^{ + }}}{N}_{v}}\right\}   \leq$ $\left| R\right| \left( { = \left| S\right|  = N/2}\right)$ ,we obtain the lower bound on edge $e$ .

证明。设${C}_{\text{opt }}$为在树拓扑结构$G$上计算$R \times  S$的任何算法的成本。考虑边$e \in  E$。假设${C}_{opt} \cdot  {w}_{e} \leq  \mathop{\sum }\limits_{{v \in  {V}_{e}^{ - }}}\left| {R}_{v}\right|$。则对于某个$u \in  {V}_{e}^{ - }$，${R}_{u}$中至少有一个元素不经过$e$，即进入${V}_{e}^{ + }$中的任意顶点。此时，为保证正确性，$S$中的所有数据必须发送至$u$，因此${C}_{\text{opt }} \cdot  {w}_{e} \geq  \mathop{\sum }\limits_{{\mathcal{v} \in  {V}_{e}^{ + }}}\left| {S}_{\mathcal{v}}\right|$。故${C}_{\text{opt }}$。${w}_{e} \geq  \min \left\{  {\mathop{\sum }\limits_{{v \in  {V}_{e}^{ - }}}\left| {R}_{v}\right| ,\mathop{\sum }\limits_{{v \in  {V}_{e}^{ + }}}\left| {S}_{v}\right| }\right\}$。通过对称论证可得${C}_{opt} \cdot  {w}_{e} \geq  \min \left\{  {\mathop{\sum }\limits_{{v \in  {V}_{e}^{ - }}}\left| {S}_{v}\right| ,\mathop{\sum }\limits_{{v \in  {V}_{e}^{ + }}}\left| {R}_{v}\right| }\right\}$。将两个不等式相加，并注意到$\min \left\{  {\mathop{\sum }\limits_{{v \in  {V}_{e}^{ - }}}{N}_{v},\mathop{\sum }\limits_{{v \in  {V}_{e}^{ + }}}{N}_{v}}\right\}   \leq$$\left| R\right| \left( { = \left| S\right|  = N/2}\right)$，我们得到边$e$的下界。

### 4.2 The Weighted HyperCube Algorithm

### 4.2 加权超立方体算法

In this section, we present a deterministic one-round protocol on a symmetric star topology, named weighted HyperCube (wHC), which generalizes the HyperCube algorithm [1].

本节提出一种对称星型拓扑上的确定性单轮协议——加权超立方体(wHC)算法，该算法推广了超立方体算法[1]。

The wHC Algorithm. We assume that the data statistics $\left| {R}_{v}\right|$ , $\left| {S}_{\mathcal{V}}\right|$ are known to all compute nodes. We give a strict ordering $\leq$ on the compute nodes in ${V}_{C}$ . Each node assigns consecutive numbers to its local data. More specifically,node $v$ labels its data in ${R}_{v}$ from $1 + \mathop{\sum }\limits_{{u < v}}\left| {R}_{u}\right|$ to $\mathop{\sum }\limits_{{u \leq  v}}\left| {R}_{u}\right|$ ,and data in ${S}_{v}$ from $1 + \mathop{\sum }\limits_{{u < v}}\left| {S}_{u}\right|$ to $\mathop{\sum }\limits_{{u \leq  v}}\left| {S}_{u}\right|$ . In this way,each element from $R$ is labeled with a unique index,as well as each one from $S$ . In this way,each answer in the cartesian product can be uniquely mapped to a point in the grid $\square  = \{ 1,2,\ldots ,\left| R\right| \}  \times  \{ 1,2,\ldots ,\left| S\right| \} .$

wHC算法。我们假设所有计算节点均已知数据统计量$\left| {R}_{v}\right|$和$\left| {S}_{\mathcal{V}}\right|$。在${V}_{C}$中对计算节点建立严格序关系$\leq$。每个节点为本地数据分配连续编号：节点$v$将${R}_{v}$中的数据标记为$1 + \mathop{\sum }\limits_{{u < v}}\left| {R}_{u}\right|$到$\mathop{\sum }\limits_{{u \leq  v}}\left| {R}_{u}\right|$，将${S}_{v}$中的数据标记为$1 + \mathop{\sum }\limits_{{u < v}}\left| {S}_{u}\right|$到$\mathop{\sum }\limits_{{u \leq  v}}\left| {S}_{u}\right|$。由此，$R$和$S$中的每个元素都获得唯一索引，笛卡尔积中的每个解都能唯一映射到网格$\square  = \{ 1,2,\ldots ,\left| R\right| \}  \times  \{ 1,2,\ldots ,\left| S\right| \} .$中的坐标点。

The wHC protocol assigns to each compute node $v$ a square ${\square }_{v}$ centered at $\left( {{x}_{v},{y}_{v}}\right)$ with dimensions ${l}_{v} \times  {l}_{v}$ . Then,a tuple ${r}_{i} \in  R$ will be sent to $v$ if ${x}_{v} - {l}_{v} \leq  i \leq  {x}_{v} + {l}_{v}$ ,and a tuple ${s}_{j} \in  S$ will be sent to $v$ if ${y}_{v} - {l}_{v} \leq  j \leq  {y}_{v} + {l}_{v}$ . After all tuples are routed,the cartesian product will be computed locally at each compute node. To guarantee correctness,we have to make sure that $\mathop{\bigcup }\limits_{\mathcal{O}}{\square }_{\mathcal{O}} = \square$ , i.e., the squares assigned to each node fully cover the grid.

wHC协议为每个计算节点$v$分配以$\left( {{x}_{v},{y}_{v}}\right)$为中心、边长为${l}_{v} \times  {l}_{v}$的正方形区域${\square }_{v}$。当满足条件${x}_{v} - {l}_{v} \leq  i \leq  {x}_{v} + {l}_{v}$时，元组${r}_{i} \in  R$将被发送至$v$；当满足${y}_{v} - {l}_{v} \leq  j \leq  {y}_{v} + {l}_{v}$时，元组${s}_{j} \in  S$将被发送至$v$。完成所有元组路由后，各计算节点将本地计算笛卡尔积。为确保正确性，必须满足$\mathop{\bigcup }\limits_{\mathcal{O}}{\square }_{\mathcal{O}} = \square$，即各节点分配的正方形区域完全覆盖整个网格。

In the sorting problem,we are given a set $R$ whose elements are drawn from a totally ordered domain. We first define an ordering of compute nodes in the following way: after picking an arbitrary node as the root, any left-to-right traversal of the underlying network tree is a valid ordering of compute nodes. The goal is to redistribute the elements of $R$ such that on an ordering of compute nodes as ${v}_{1},{v}_{2},\cdots ,{v}_{\left| {V}_{C}\right| }$ ,elements on node ${v}_{i}$ are always smaller than those on node ${v}_{j}$ if $i < j$ .

在排序问题中，给定一个元素取自全序域集合$R$。我们首先按以下方式定义计算节点序：任选节点作为根后，底层网络树的任何从左到右遍历都是有效的计算节点序。目标是将$R$元素重新分配，使得在计算节点序${v}_{1},{v}_{2},\cdots ,{v}_{\left| {V}_{C}\right| }$中，当$i < j$时，节点${v}_{i}$上的元素始终小于节点${v}_{j}$上的元素。

Given an initial distribution $\mathcal{D}$ of the data across the compute nodes,we denote by ${N}_{v}^{\mathcal{D}}$ the initial data size in node $v$ . Whenever the context is clear,we drop the superscript $\mathcal{D}$ from the notation.

给定计算节点间数据的初始分布$\mathcal{D}$，用${N}_{v}^{\mathcal{D}}$表示节点$v$中的初始数据量。上下文明确时，我们将省略符号中的上标$\mathcal{D}$。

### 5.1 Lower Bound

### 5.1 下界

Our lower bound for sorting has the same form as the one for set intersection (Theorem 1), with the only difference that the cost is expressed as tuples,and not bits. Recall that any edge $e = \left( {u,v}\right)$ in the tree topology $G$ defines a partitioning of the compute nodes in the tree $G$ into two subsets: ${V}_{e}^{ - }$ and ${V}_{e}^{ + }$ . Here, ${V}_{e}^{ - }$ is the set of compute nodes in the same side as $u$ ,and ${V}_{e}^{ + }$ in the same side as $v$ . Hence, any sorting algorithm in the tree topology also performs some necessary comparisons between data located at ${V}_{e}^{ - }$ and ${V}_{e}^{ + }$ . Following this core idea, we can show the following lower bound.

排序问题的下界与集合交问题（定理1）形式相同，唯一区别在于成本以元组而非比特表示。注意树拓扑$G$中任何边$e = \left( {u,v}\right)$都将计算节点划分为两个子集：${V}_{e}^{ - }$和${V}_{e}^{ + }$。其中${V}_{e}^{ - }$是与$u$同侧的节点集，${V}_{e}^{ + }$是与$v$同侧的节点集。因此，树拓扑中的任何排序算法都需要对${V}_{e}^{ - }$和${V}_{e}^{ + }$上的数据执行必要比较。基于该核心思想，可证明如下下界。

THEOREM 15. Let $G = \left( {V,E}\right)$ be a symmetric tree topology. Any algorithm sorting elements in a set $R$ has (tuple) cost $\Omega \left( {C}_{LB}\right)$ ,where

定理15. 设$G = \left( {V,E}\right)$为对称树拓扑。对集合$R$中元素排序的任何算法具有（元组）成本$\Omega \left( {C}_{LB}\right)$，其中

$$
{C}_{LB} = \mathop{\max }\limits_{{e \in  E}}\frac{1}{{w}_{e}} \cdot  \min \left\{  {\mathop{\sum }\limits_{{v \in  {V}_{e}^{ - }}}{N}_{v},\mathop{\sum }\limits_{{v \in  {V}_{e}^{ + }}}{N}_{v}}\right\}  .
$$

Proof. We construct an initial data distribution $R$ as follows. Assume elements in $R$ are ordered as ${r}_{1},{r}_{2},\cdots ,{r}_{N}$ . W.l.o.g.,assume $N$ is even. We assign elements to compute nodes in the ordering of $\left\{  {{r}_{1},{r}_{3},\cdots ,{r}_{N - 1},{r}_{2},{r}_{4},\cdots ,{r}_{N}}\right\}$ . Moreover,we pick one arbitrary node of $G$ as the root,where all compute nodes are leaves of the tree. All compute nodes in ${V}_{C}$ are also labeled as ${v}_{1},{v}_{2},\cdots ,{v}_{\left| {V}_{C}\right| }$ in an left-to-right traversal ordering. For example,node ${v}_{1}$ with initial data size ${N}_{1}$ will be assigned with $\left\{  {{r}_{1},{r}_{3},\cdots ,{r}_{2{N}_{1} - 1}}\right\}$ if ${N}_{1} \leq  \frac{N}{2}$ , and $\left\{  {{r}_{1},{r}_{3},\cdots ,{r}_{N - 1},{r}_{2},{r}_{4},\cdots ,{r}_{2{N}_{1} - N}}\right\}$ otherwise. We will argue that any algorithm correctly sorting $R$ must incur a cost of $\Omega \left( {C}_{LB}\right)$ .

证明. 构造初始数据分布$R$如下：假设$R$中元素按${r}_{1},{r}_{2},\cdots ,{r}_{N}$排序。不妨设$N$为偶数。按$\left\{  {{r}_{1},{r}_{3},\cdots ,{r}_{N - 1},{r}_{2},{r}_{4},\cdots ,{r}_{N}}\right\}$序将元素分配至计算节点，并任选$G$中节点为根（所有计算节点均为叶节点）。${V}_{C}$中计算节点按左到右遍历序标记为${v}_{1},{v}_{2},\cdots ,{v}_{\left| {V}_{C}\right| }$。例如，初始数据量为${N}_{1}$的节点${v}_{1}$，当${N}_{1} \leq  \frac{N}{2}$时分配$\left\{  {{r}_{1},{r}_{3},\cdots ,{r}_{2{N}_{1} - 1}}\right\}$，否则分配$\left\{  {{r}_{1},{r}_{3},\cdots ,{r}_{N - 1},{r}_{2},{r}_{4},\cdots ,{r}_{2{N}_{1} - N}}\right\}$。我们将论证任何正确排序$R$的算法必然产生$\Omega \left( {C}_{LB}\right)$成本。

Consider an arbitrary edge $e \in  E$ with the partition ${V}_{e}^{ - },{V}_{e}^{ + }$ . Denote ${R}_{e}^{ - } = \mathop{\bigcup }\limits_{{v \in  {V}_{e}^{ - }}}{R}_{v}$ and ${R}_{e}^{ + } = \mathop{\bigcup }\limits_{{v \in  {V}_{e}^{ + }}}{R}_{v}$ . It should be noted that ${R}_{e}^{ - }$ or ${R}_{e}^{ + }$ is a sub-interval of $\left\{  {{r}_{1},{r}_{3},\cdots ,{r}_{N - 1},{r}_{2},{r}_{4},\cdots ,{r}_{N}}\right\}$ , or a sub-interval of $\left\{  {{r}_{2},{r}_{4},\cdots ,{r}_{N},{r}_{1},{r}_{3},\cdots ,{r}_{{N}_{1}}}\right\}$ . Every element transmitted between ${V}_{e}^{ - }$ and ${V}_{e}^{ + }$ must go through edge $e$ . W.l.o.g., assume $\left| {R}_{e}^{ - }\right|  \leq  \frac{N}{2} \leq  \left| {R}_{e}^{ + }\right|$ . It suffices to show that the total number of elements exchanged between ${V}_{e}^{ - }$ and ${V}_{e}^{ + }$ is at least $\Omega \left( \left| {R}_{e}^{ - }\right| \right)$ .

考虑任意一条边$e \in  E$及其分区${V}_{e}^{ - },{V}_{e}^{ + }$。记${R}_{e}^{ - } = \mathop{\bigcup }\limits_{{v \in  {V}_{e}^{ - }}}{R}_{v}$和${R}_{e}^{ + } = \mathop{\bigcup }\limits_{{v \in  {V}_{e}^{ + }}}{R}_{v}$。需注意${R}_{e}^{ - }$或${R}_{e}^{ + }$是$\left\{  {{r}_{1},{r}_{3},\cdots ,{r}_{N - 1},{r}_{2},{r}_{4},\cdots ,{r}_{N}}\right\}$的子区间，或是$\left\{  {{r}_{2},{r}_{4},\cdots ,{r}_{N},{r}_{1},{r}_{3},\cdots ,{r}_{{N}_{1}}}\right\}$的子区间。在${V}_{e}^{ - }$与${V}_{e}^{ + }$之间传输的每个元素都必须经过边$e$。不失一般性，假设$\left| {R}_{e}^{ - }\right|  \leq  \frac{N}{2} \leq  \left| {R}_{e}^{ + }\right|$。只需证明${V}_{e}^{ - }$与${V}_{e}^{ + }$之间交换的元素总数至少为$\Omega \left( \left| {R}_{e}^{ - }\right| \right)$。

We start with the case when $\left| {R}_{e}^{ - }\right|  = 1$ ,say ${R}_{e}^{ - } = \left\{  {r}_{i}\right\}$ . If ${r}_{i}$ is not sent through $e$ ,at least one element in ${R}_{e}^{ + }$ must be sent to ${V}_{e}^{ - }$ ; otherwise,no comparison between ${r}_{i}$ and elements in ${R}_{e}^{ + }$ is performed, contradicting to the correctness of algorithms. ### 5.2 A Sampling-based Algorithm

### 5.2 基于采样的算法

In the MPC model, the theoretically optimal sorting algorithm inherited from [23] is rather complicated. Instead, sampling-based techniques, such as TeraSort [42], are more amenable to be extended to more complex networks. In this section, we present a randomized communication protocol for a symmetric tree topology, named weighted TeraSort (wTS), which generalizes the TeraSort algorithm in three fundamental ways. First, TeraSort is designed for the MapReduce [20] framework, which is an instantiation of the theoretical MPC model (with star topology), and we extend it to the general tree topology. Second, not all nodes participate in the splitting of the data, but only the ones that initially have a substantial amount of data. Third, we do not split the data uniformly, but proportionally to the size of the initial data. Before introducing our algorithm, we revisit the TeraSort algorithm.

## 6 RELATED WORK

## 6 相关工作

The fundamental difference of the topology-aware model we use with other parallel models (e.g., BSP [47], MPC [7], LogP [18]) is that the cost depends both on the topology and properties of the network and the nodes. Prior models view the network as a star topology, where each link and each node have exactly the same cost functions. In this sense, our model can be viewed as a generalization, where the topology and the node heterogeneity is taken into account.

我们采用的拓扑感知模型与其他并行模型（如BSP[47]、MPC[7]、LogP[18]）的根本区别在于：其成本同时取决于网络拓扑属性与节点特性。先前模型将网络视为星型拓扑，所有链路和节点都具有完全相同的成本函数。从这个意义上说，我们的模型可视为将拓扑结构和节点异构性纳入考量的广义模型。

There have already been some efforts to introduce topology-aware models, including [11, 32] as mentioned in the introduction.

已有部分研究尝试引入拓扑感知模型，包括引言中提到的[11,32]。

One line of work in distributed computing on networks are the classical LOCAL and CONGEST models [37, 45], where distributed problems are also considered in networks modeled as an arbitrary graph. These two models differentiate from ours in two important aspects. First, in each round, each node can only communicate with its neighbors; instead, in our model we can send messages to other nodes that may be located several hops away. Second, the target is to design algorithms that minimize the number of rounds. As a combination of both aspects, the diameter of the communication network cannot be avoided as a cost in these models. Moreover, system synchronization after each round is a huge bottleneck of modern massively parallel systems; thus, any algorithm in these two models running in non-constant number of rounds would become hard to implement efficiently in practice.

网络分布式计算领域存在经典的LOCAL和CONGEST模型[37,45]，这些模型也将分布式问题置于任意图建模的网络中研究。这两个模型与我们的模型存在两个重要差异：其一，每轮计算中节点仅能与相邻节点通信，而我们的模型支持向多跳外节点发送消息；其二，其目标是设计最小化轮次的算法。这两个特点使得通信网络的直径必然成为这些模型的固有成本。此外，每轮计算后的系统同步是现代大规模并行系统的重大瓶颈，因此任何需要非恒定轮次的算法都难以高效实现。

Network routing has been studied in the context of parallel algorithms (see $\left\lbrack  {{33},{34}}\right\rbrack$ ),distributed computing (see,e.g. [35]),and mobile networks [40]. Several general-purpose optimization methods for network problems have been proposed [43]. Our proposed research deviates from prior literature by considering a "distribution-aware" setting, and tasks that have not been considered before.

网络路由问题已在并行算法($\left\lbrack  {{33},{34}}\right\rbrack$)、分布式计算（如[35]）和移动网络[40]领域得到研究。现有研究提出了多种通用网络优化方法[43]。我们的创新在于引入"分布感知"设置，并研究前人未涉及的任务类型。

The topology-aware model we use in this paper has been previously used to design algorithms for aggregation [38]. However, only star topologies were considered. Madden et al. $\left\lbrack  {{39},{41}}\right\rbrack$ also proposed a tiny aggregation service which does topology-aware in-network aggregation in sensor networks. Culhane et al. [16, 17] propose LOOM, a system that builds an aggregation tree with fixed fan-in for all-to-one aggregations, and assigns nodes to different parts of the plan according to the amount of data reduced during aggregation. Chowdhury et al. [15] propose Orchestra, a system to manage network activities in MapReduce systems. Both systems are cognizant of the network topology, but agnostic to the distribution of the input data. They also lack any theoretical guarantees.

本文采用的拓扑感知模型先前已被用于设计聚合算法[38]，但仅考虑了星型拓扑。Madden等人$\left\lbrack  {{39},{41}}\right\rbrack$提出了一种微型聚合服务，在传感器网络中实现拓扑感知的网内聚合。Culhane等人[16,17]提出的LOOM系统为全对一聚合构建固定扇入的聚合树，并根据聚合过程中数据缩减量将节点分配到计划的不同部分。Chowdhury等人[15]提出的Orchestra系统用于管理MapReduce系统中的网络活动。这两个系统虽能感知网络拓扑，但对输入数据分布无感知，且缺乏理论保证。

## 7 CONCLUSION

## 7 结论

In this paper, we studied three fundamental data processing tasks in a topology-aware massively parallel computational model. We derived lower bounds based on the cardinality of the initial data distribution at each node and we designed provably optimal algorithms for each task with respect to the initial data distribution. Interestingly, these problems have different dependency on the topology structure, the cost functions (bandwidth), as well as the data distribution.

本文在拓扑感知的大规模并行计算模型中研究了三个基本数据处理任务。我们基于各节点初始数据分布的基数推导了下界，并针对初始数据分布为每个任务设计了可证明的最优算法。值得注意的是，这些问题对拓扑结构、成本函数（带宽）以及数据分布的依赖关系各不相同。

There are several exciting directions for future research. For one, we would like to extend our algorithms and lower bounds to non-symmetric and general (non-tree) topologies. General topologies (e.g., grid, torus) are particularly challenging because there are multiple routing paths between two compute nodes, and thus a topology-aware algorithm needs to consider all nodes in the routing path, instead of just the destination. Looking further ahead, it would be interesting to study more complex tasks that have so far been analyzed only in the context of the MPC model, starting from a simple join between two relations, and continuing to ensembles of tasks in more complex queries.

未来研究有几个值得探索的方向：首先，我们希望将算法和下界扩展到非对称及通用（非树状）拓扑结构。通用拓扑（如网格、环面）尤其具有挑战性，因为计算节点间存在多条路由路径，拓扑感知算法需考虑路由路径上的所有节点，而不仅是目标节点。更长远来看，研究更复杂的任务将很有意义——目前这些任务仅在MPC模型背景下被分析过，从简单双关系到复杂查询中的任务组合都值得探索。
