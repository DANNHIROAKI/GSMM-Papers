## ABSTRACT

## 摘要

We study synthetic data release for answering multiple linear queries over a set of database tables in a differentially private way. Two special cases have been considered in the literature: how to release a synthetic dataset for answering multiple linear queries over a single table, and how to release the answer for a single counting (join size) query over a set of database tables. Compared to the single-table case, the join operator makes query answering challenging, since the sensitivity (i.e., by how much an individual data record can affect the answer) could be heavily amplified by complex join relationships.

我们研究以差分隐私方式发布合成数据，用于回答多张数据库表上的线性查询。现有文献已考虑两种特殊情况：如何发布合成数据集以回答单表上的多重线性查询，以及如何发布多表间单一计数（连接大小）查询的答案。与单表情况相比，连接操作符使查询应答更具挑战性，因为连接关系可能大幅放大敏感度（即单个数据记录对查询结果的影响程度）。

We present an algorithm for the general problem, and prove a lower bound illustrating that our general algorithm achieves parameterized optimality (up to logarithmic factors) on some simple queries (e.g., two-table join queries) in the most commonly-used privacy parameter regimes. For the case of hierarchical joins, we present a data partition procedure that exploits the concept of uniformized sensitivities to further improve the utility.

我们提出针对该通用问题的算法，并通过下界证明表明：在常用隐私参数范围内，该算法对某些简单查询（如双表连接查询）实现了参数化最优性（对数因子范围内）。针对层次化连接场景，我们提出利用均匀化敏感度概念的数据分区方法，进一步提升数据效用。

## 1 INTRODUCTION

## 1 引言

Synthetic data release is a very useful objective in private data analysis. Differential privacy (DP) [17, 18] has emerged as a compelling model that enables us to formally study the tradeoff between utility of released information and the privacy of individuals. In the literature, there has been a large body of work that studies synthetic data release over a single table, e.g., the private multiplicative weight algorithm [25], the histogram-based algorithm [43], the matrix mechanism [33], the Bayesian network algorithm [45], and other works on geometric range queries $\left\lbrack  {7,9,{11},{19},{20},{28},{34},{35}}\right\rbrack$ and datacubes [13].

合成数据发布是隐私数据分析中极具价值的研究目标。差分隐私（DP）[17,18]已成为一个引人注目的模型，使我们能够形式化研究发布信息效用与个体隐私之间的权衡。现有文献中已有大量关于单表合成数据发布的研究，例如私有乘法权重算法[25]、基于直方图的算法[43]、矩阵机制[33]、贝叶斯网络算法[45]，以及关于几何范围查询$\left\lbrack  {7,9,{11},{19},{20},{28},{34},{35}}\right\rbrack$和数据立方体[13]的其他成果。

Data analysis over multiple private tables connected via join operators has been the subject of significant interest within the area of modern database systems. In particular, the challenging question of releasing the join size over a set of private tables has been studied in several recent works including the sensitivity-based framework $\left\lbrack  {{15},{16},{30}}\right\rbrack$ ,the truncation-based mechanism $\left\lbrack  {{14},{32},{42}}\right\rbrack$ , as well as in works on one-to-one joins $\left\lbrack  {{37},{41}}\right\rbrack$ ,and on graph databases $\left\lbrack  {6,{10}}\right\rbrack$ . In practice,multiple queries (as opposed to a single one) are typically issued for data analysis, for example, a large class of linear queries on top of join results with different weights on input tuples, as a generalization of the counting join size query. One might consider answering each query independently but the utility would be very low due to the limited privacy budget, implied by DP composition rules $\left\lbrack  {{17},{18}}\right\rbrack$ . Hence the question that we tackle in this paper is: how can we release synthetic data for accurately answering a large class of linear queries over multiple tables privately?

通过连接运算符关联的多个私有表数据分析，一直是现代数据库系统领域的重要研究方向。特别是关于私有表集合的连接规模发布这一挑战性课题，近期多项研究进行了探讨，包括基于敏感度的框架$\left\lbrack  {{15},{16},{30}}\right\rbrack$、基于截断的机制$\left\lbrack  {{14},{32},{42}}\right\rbrack$，以及一对一连接$\left\lbrack  {{37},{41}}\right\rbrack$和图数据库$\left\lbrack  {6,{10}}\right\rbrack$的相关研究。实际数据分析中通常涉及多查询（而非单一查询），例如在连接结果上对不同权重输入元组进行线性查询的大类，作为计数连接规模查询的泛化。虽然可以考虑独立回答每个查询，但受限于差分隐私组合规则$\left\lbrack  {{17},{18}}\right\rbrack$的隐私预算，这种方式的效用极低。因此本文研究的核心问题是：如何通过合成数据发布来精准回答多表上的大类线性查询？

Multi-way Join and Linear Queries. A (natural) join query can be represented as a hypergraph $\mathcal{H} = \left( {\mathbf{x},\left\{  {{\mathbf{x}}_{1},\ldots ,{\mathbf{x}}_{m}}\right\}  }\right) \left\lbrack  1\right\rbrack$ ,where $\mathbf{x}$ is the set of vertices or attributes and each ${\mathbf{x}}_{i} \subseteq  \mathbf{x}$ is a hyperedge or relation. Define $\mathbb{D} =$ $\operatorname{dom}\left( \mathbf{x}\right)  = \mathop{\prod }\limits_{{x \in  \mathbf{x}}}\operatorname{dom}\left( x\right)$ ,and ${\mathbb{D}}_{i} = \operatorname{dom}\left( {\mathbf{x}}_{i}\right)  = \mathop{\prod }\limits_{{x \in  {\mathbf{x}}_{i}}}\operatorname{dom}\left( x\right)$ for any $i \in  \left\lbrack  m\right\rbrack$ . Given an instance $\mathbf{I} = \left( {{R}_{1}^{\mathrm{I}},\ldots ,{R}_{m}^{\mathrm{I}}}\right)$ of $\mathcal{H}$ ,each table ${R}_{i}^{\mathrm{I}} : {\mathbb{D}}_{i} \rightarrow$ ${\mathbb{Z}}^{ \geq  0}$ is defined as a function from domain ${\mathbb{D}}_{i}$ to a non-negative integer,indicating the frequency of each tuple in ${\mathbb{D}}_{i}$ . The input size of $\mathbf{I}$ is defined as the sum of frequencies of all data records,i.e., $n = \mathop{\sum }\limits_{{i \in  \left\lbrack  m\right\rbrack  }}\mathop{\sum }\limits_{{t \in  {\mathbb{D}}_{i}}}{R}_{i}^{\mathbf{I}}\left( t\right)$ .

给定一个$\mathcal{H}$的实例$\mathbf{I} = \left( {{R}_{1}^{\mathrm{I}},\ldots ,{R}_{m}^{\mathrm{I}}}\right)$，每个表${R}_{i}^{\mathrm{I}} : {\mathbb{D}}_{i} \rightarrow$${\mathbb{Z}}^{ \geq  0}$被定义为从域${\mathbb{D}}_{i}$到非负整数的映射函数，用于表示${\mathbb{D}}_{i}$中每个元组的出现频率。这种设定比每个元组在关系中至多出现一次的情形更通用，因为它能捕捉带有非负标注的注释关系[24]。$\mathbf{I}$的输入规模定义为所有数据记录频率的总和，即$n = \mathop{\sum }\limits_{{i \in  \left\lbrack  m\right\rbrack  }}\mathop{\sum }\limits_{{t \in  {\mathbb{D}}_{i}}}{R}_{i}^{\mathbf{I}}\left( t\right)$。

$$

DP Setting. Two DP settings have been studied in the relational model, depending on whether foreign key constraints are considered or not. The one considering foreign key constraints assumes the existence of a primary private table, and deleting a tuple in the primary private relation will delete all other tuples referencing it; see $\left\lbrack  {{14},{32},{42}}\right\rbrack$ . In this work,we adopt the other notion,which does not consider foreign key constrains, but defines instances to be neighboring if one can be converted into the other by adding/removing a single tuple; this is the same as the notion studied in some previous works $\left\lbrack  {{30},{31},{38},{41}}\right\rbrack$ . ${}^{1}$

Definition 1.2 (Differential Privacy [17,18]). For $\epsilon ,\delta  > 0$ ,an algorithm $\mathcal{A}$ is $\left( {\epsilon ,\delta }\right)$ -differentially private (denoted by $\left( {\epsilon ,\delta }\right)$ -DP) if for any pair $\mathbf{I},{\mathbf{I}}^{\prime }$ of neighboring instances and any subset $\mathcal{S}$ of outputs, $\Pr \left( {\mathcal{A}\left( \mathrm{I}\right)  \in  \mathcal{S}}\right)  \leq  {e}^{\epsilon } \cdot  \Pr \left( {\mathcal{A}\left( {\mathrm{I}}^{\prime }\right)  \in  \mathcal{S}}\right)  + \delta$ .

### 1.2 Prior Work

### 1.2 已有研究

We first review the problem of releasing synthetic data for a single table, and mention two important results in the literature. In the single table case, nearly tight upper and lower bounds are known:

我们首先回顾单表合成数据发布问题，并列举文献中两个重要结论。在单表情况下，已知近乎紧致的上下界：

THEOREM 1.3 ([25]). We note that the sensitivity-based framework can be adapted to answering any single linear query, as long as the sensitivity of the specific linear query is correctly computed. In building our data release algorithm, we also resort to the existing sensitivities derived for the counting join size query but in a more careful way.

Notation. For random variables $X,Y$ and scalars $\epsilon  > 0,\delta  \in  \lbrack 0,1)$ , we use $X{ \approx  }_{\left( \epsilon ,\delta \right) }Y$ for short if $\Pr \left\lbrack  {X \in  S}\right\rbrack   \leq  {e}^{\epsilon } \cdot  \Pr \left\lbrack  {Y \in  S}\right\rbrack   + \delta$ and $\Pr \left\lbrack  {Y \in  S}\right\rbrack   \leq  {e}^{\epsilon } \cdot  \Pr \left\lbrack  {X \in  S}\right\rbrack   + \delta$ for all sets $S$ of outcomes. For convenience, we sometimes write the distribution in place of a random variable drawn from that distribution. E.g., $a + \mathcal{D}$ is a shorthand for $a + X$ ,where $X$ is a random variable with distribution $\mathcal{D}$ (denoted $X \sim  \mathcal{D}$ ).

(Truncated) Laplace Distribution. The Laplace distribution with parameter $b$ ,denoted ${\operatorname{Lap}}_{b}$ ,has probability density function (PDF) ${\operatorname{Lap}}_{b}\left( x\right)  \propto  {e}^{-\left| x\right| /b}$ . The shifted and truncated Laplace distribution with parameters $b$ and $\tau$ ,denoted ${\mathrm{{TLap}}}_{b}^{\tau }$ ,is the distribution supported on $\left\lbrack  {0,{2\tau }}\right\rbrack$ whose PDF over the support satisfies ${\operatorname{TLap}}_{b}^{\tau }\left( x\right)  \propto$ ${e}^{-\left| {x - \tau }\right| /b}$ . The DP guarantees of the Laplace and truncated Laplace distributions are well-known (e.g., $\left\lbrack  {{18},{22},{23}}\right\rbrack$ ): for any pair $u,v$ with $\left| {u - v}\right|  \leq  \Delta ,u + {\operatorname{Lap}}_{\Delta /\epsilon }{ \approx  }_{\left( \epsilon ,0\right) }v + {\operatorname{Lap}}_{\Delta /\epsilon }$ and $u + {\operatorname{TLap}}_{\Delta /\epsilon }^{\tau }{ \approx  }_{\left( \epsilon ,\delta \right) }$ $v + {\operatorname{TLap}}_{\Delta /\epsilon }^{\tau }$ for $\tau  = \tau \left( {\epsilon ,\delta ,\Delta }\right)  = \frac{\Delta }{\epsilon }\ln \left( {1 + \frac{{e}^{\epsilon } - 1}{\delta }}\right)$ . Exponential Mechanism. The exponential mechanism (EM) [36] selects a "good" candidate from a set $\mathcal{C}$ of candidates. The goodness is defined by a scoring function $s\left( {\mathrm{I},c}\right)$ for an input dataset $\mathrm{I}$ and a candidate $c \in  \mathcal{C}$ and is assumed to have sensitivity at most one. 现在简要说明为何该算法违反差分隐私。设$\widetilde{J},\widetilde{{J}^{\prime }}$是该算法针对两个相邻数据库$\mathbf{I},{\mathbf{I}}^{\prime }$分别发布的合成数据集。根据单表PMW算法的特性，整个域内元组总数保持不变，即计数$\left( \mathbf{I}\right)  = \mathop{\sum }\limits_{{\overrightarrow{t} \in  {\mathbb{D}}_{1} \times  {\mathbb{D}}_{2}}}\widetilde{J}\left( \overrightarrow{t}\right)$与$\operatorname{count}\left( {\mathbf{I}}^{\prime }\right)  =$$\mathop{\sum }\limits_{{\overrightarrow{t} \in  {\mathbb{D}}_{1} \times  {\mathbb{D}}_{2}}}{\widetilde{J}}^{\prime }\left( \overrightarrow{t}\right)$。但I与I'可能产生截然不同的连接规模：图1展示了连接规模分别为$n$和0的两个相邻数据库。因此，攻击者可利用$\widetilde{J},\widetilde{{J}^{\prime }}$来区分${\mathrm{I}}^{\prime }$与${\mathrm{I}}^{\prime }$，导致该算法不满足$\mathrm{{DP}}$。

Another Natural (but Still Flawed) Idea. To remedy the leakage in the above algorithm, we seek to protect the total number of tuples in the released dataset, say, by padding with dummy tuples:

另一个自然（但仍存缺陷）的构想。为修正上述算法的信息泄露问题，我们尝试通过填充虚拟元组来保护发布数据集中的元组总数：

(1) Compute the join result $J =$ Join ${}^{\mathrm{I}}$ and release a synthetic dataset ${\widetilde{J}}_{1}$ for $J$ by invoking the single-table PMW algorithm;

(1) 计算连接结果$J =$ Join ${}^{\mathrm{I}}$，并通过调用单表PMW算法生成$J$的合成数据集${\widetilde{J}}_{1}$；

(2) $\widetilde{\Delta } \leftarrow  \Delta  + {\operatorname{TLap}}_{2/\epsilon }^{\tau \left( {\epsilon /2,\delta /2,1}\right) }$ ;

(3) ${\widetilde{J}}_{2} \leftarrow$ random sample of $\eta$ records from ${\mathbb{D}}_{1} \times  {\mathbb{D}}_{2}$ ,where $\eta  \sim$ TLap $\frac{\tau \left( {\epsilon /2,\delta /2,\widetilde{\Delta }}\right) }{2\widetilde{\Delta }/\epsilon }$ ;

(3) 从${\mathbb{D}}_{1} \times  {\mathbb{D}}_{2}$中${\widetilde{J}}_{2} \leftarrow$随机抽样$\eta$条记录，其中$\eta  \sim$ TLap $\frac{\tau \left( {\epsilon /2,\delta /2,\widetilde{\Delta }}\right) }{2\widetilde{\Delta }/\epsilon }$；

(4) Release the union of these two datasets: $\mathbb{F} = {\widetilde{J}}_{1} \cup  {\widetilde{J}}_{2}$ ;

(4) 发布这两个数据集的并集：$\mathbb{F} = {\widetilde{J}}_{1} \cup  {\widetilde{J}}_{2}$；

As noted, the local sensitivity cannot be directly used for privately releasing the join size,however,the global sensitivity of ${\mathrm{{LS}}}_{\text{count }}\left( \cdot \right)$ is 1 . Hence, the second step is to obtain an upper bound on the local sensitivity, which will be used to calibrate the noise needed to mask the join size of I. More specifically, for any neighboring databases $\mathrm{I},{\mathrm{I}}^{\prime }$ ,let $\mathbb{F},{\mathbb{F}}^{\prime }$ be the synthetic datasets released for $\mathrm{I},{\mathrm{I}}^{\prime }$ respectively. As mentioned, $\mathop{\sum }\limits_{{t \in  {\mathbb{D}}_{1} \times  {\mathbb{D}}_{2}}}\mathbb{F}\left( t\right) { \approx  }_{\left( \epsilon ,\delta \right) }\mathop{\sum }\limits_{{t \in  {\mathbb{D}}_{1} \times  {\mathbb{D}}_{2}}}{\mathbb{F}}^{\prime }\left( t\right)$ , which resolves the information leakage of the join size. However, it turns out that this approach can still lead to the distinguishability of neighboring databases $\mathbf{I},{\mathbf{I}}^{\prime }$ . Indeed,consider the following example.

如前所述，局部敏感度无法直接用于隐私发布连接大小，但${\mathrm{{LS}}}_{\text{count }}\left( \cdot \right)$的全局敏感度为1。因此，第二步是获取局部敏感度的上界，该上界将用于校准掩盖I的连接大小所需的噪声。更具体地说，对于任何相邻数据库$\mathrm{I},{\mathrm{I}}^{\prime }$，令$\mathbb{F},{\mathbb{F}}^{\prime }$分别为$\mathrm{I},{\mathrm{I}}^{\prime }$发布的合成数据集。如前所述，$\mathop{\sum }\limits_{{t \in  {\mathbb{D}}_{1} \times  {\mathbb{D}}_{2}}}\mathbb{F}\left( t\right) { \approx  }_{\left( \epsilon ,\delta \right) }\mathop{\sum }\limits_{{t \in  {\mathbb{D}}_{1} \times  {\mathbb{D}}_{2}}}{\mathbb{F}}^{\prime }\left( t\right)$解决了连接大小的信息泄露问题。然而，事实证明这种方法仍可能导致相邻数据库$\mathbf{I},{\mathbf{I}}^{\prime }$的可区分性。实际上，考虑以下示例。

We next extend the join-as-one approach to multi-table queries. First, notice that Algorithm 1 does not work in the multi-table setting because ${\mathrm{{LS}}}_{\text{count }}\left( \cdot \right)$ may itself have a large global sensitivity (unlike the two-table case where the global sensitivity of ${\mathrm{{LS}}}_{\text{count }}\left( \cdot \right)$ is 1.) As noted, several previous works have proposed various smooth upper bounds on the local sensitivity [40]: For $\beta  > 0,{S}^{\beta }\left( \cdot \right)$ is a $\beta$ -smooth upper bound on local sensitivity,if (1) ${S}^{\beta }\left( \mathrm{I}\right)  \geq  {\mathrm{{LS}}}_{\text{count }}\left( \mathrm{I}\right)$ for every instance $\mathrm{I}$ ; and (2) for any pair of neighboring instances $\mathbf{I},{\mathbf{I}}^{\prime },{S}^{\beta }\left( {\mathbf{I}}^{\prime }\right)  \leq  {e}^{\beta }{S}^{\beta }\left( \mathbf{I}\right)$ .

## 4 均匀化敏感度

So far, we have shown a parameterized algorithm for answering linear queries whose utility is in terms of the join size and the residual sensitivity. A natural question arises: can we achieve a more fine-grained parameterized algorithm with better utility?

迄今为止，我们展示了一种参数化算法用于回答线性查询，其效用取决于连接大小和残余敏感度。一个自然的问题是：能否实现更细粒度、具有更好效用的参数化算法？

Let us start with an instance of two-table join (see Figure 3), with input size $\Theta \left( n\right)$ ,join size $\Theta \left( {n\sqrt{n}}\right)$ ,and local sensitivity $\sqrt{n}$ . Algorithm 1 achieves an error of $O\left( n\right)$ . However,this instance is beyond the scope of Theorem 3.5, as the degree distribution over join values is extremely non-uniform. Revisiting the error bound in Theorem 3.3, we can gain an intuition regarding why Algorithm 1 does not perform well on this instance. The costly term is $O\left( {\sqrt{\operatorname{count}\left( \mathrm{I}\right) } \cdot  \sqrt{\Delta }}\right)$ ,where $\Delta$ is the largest degree of join values in the input instance I. However, there are many join values whose degree is much smaller than $\Delta$ . Therefore,a natural idea is to uniformize sensitivities, i.e., partition the input instance into a set of sub-instances by join values, where join values with similar sensitivities are in the same sub-instance. We then invoke our previous join-as-one algorithm as a primitive on each sub-instance independently, and return the union of the synthetic datasets generated for all sub-instances. Finally, we return all the sub-instances as the partition.

如前所述，存在一种相当直观的方法来实现双表连接的均匀化。如算法5所述，其核心思想是根据连接值在${R}_{1}$和${R}_{2}$中的最大度数进行分桶处理。为保护单个元组的隐私，在确定其所属桶之前，我们会从${\operatorname{TLap}}_{2/\epsilon }^{\tau \left( {\epsilon /2,\delta /2,1}\right) }$随机采样并添加到该连接值的度数中。回顾$\lambda  =$$\frac{1}{\epsilon }\log \frac{1}{\delta }$。设${\gamma }_{0} = 0$且对所有$i \in  \mathbb{N}$有${\gamma }_{i} = {2}^{i}\lambda$。概念上，我们将$\left\lbrack  {0,n + \lambda }\right\rbrack$划分为$\ell  = \left\lceil  {\log \left( {\frac{n}{\lambda } + 1}\right) }\right\rceil$个桶，其中第$i$个桶对应于$i \in  \left\lbrack  \ell \right\rbrack$时的$\left( {{\gamma }_{i - 1},{\gamma }_{i}}\right\rbrack$。将$\operatorname{dom}\left( B\right)$中在${R}_{1}$和${R}_{2}$具有最大噪声度数且落入第$i$个桶的值集合记为${B}^{i}$。对每个$i$，我们将${R}_{1},{R}_{2}$中连接值属于${B}^{i}$的元组标记为${R}_{1}^{i},{R}_{2}^{i}$，形成子实例$\left( {{R}_{1}^{i},{R}_{2}^{i}}\right)$。更具体地说，${R}_{1}^{i} : {B}^{i} \rightarrow  {\mathbb{Z}}^{ \geq  0}$满足：当${\pi }_{B}t \in  {B}^{i}$时${R}_{1}^{i}\left( t\right)  = {R}_{1}\left( t\right)$，否则${R}_{1}^{i}\left( t\right)  = {R}_{1}\left( t\right)$。${R}_{2}^{i}$的定义类似。最终返回所有子实例作为划分结果。

This uniformization technique, surprisingly, can be further extended beyond two-table queries to the class of hierarchical queries. A join query $\mathcal{H} = \left\{  {\mathbf{x},\left\{  {{\mathbf{x}}_{1},\ldots ,{\mathbf{x}}_{m}}\right\}  }\right\}$ is hierarchical,if for any pair $x,y$ of attributes,either atom $\left( x\right)  \subseteq  \operatorname{atom}\left( y\right)$ ,or atom $\left( y\right)  \subseteq  \operatorname{atom}\left( x\right)$ , or $\operatorname{atom}\left( x\right)  \cap  \operatorname{atom}\left( y\right)  = \varnothing$ ,where $\operatorname{atom}\left( x\right)  = \left\{  {i \in  \left\lbrack  m\right\rbrack   : x \in  {\mathbf{x}}_{i}}\right\}$ is the set of relations containing attribute $x$ . One can always organize the attributes of a hierarchical join into a tree such that every relation corresponds to a root-to-node path (see Figure 4).

令人惊讶的是，这种统一化技术可以进一步扩展到双表查询之外的层次查询类。当且仅当对于任意属性对$x,y$，要么原子$\left( x\right)  \subseteq  \operatorname{atom}\left( y\right)$，要么原子$\left( y\right)  \subseteq  \operatorname{atom}\left( x\right)$，或者$\operatorname{atom}\left( x\right)  \cap  \operatorname{atom}\left( y\right)  = \varnothing$（其中$\operatorname{atom}\left( x\right)  = \left\{  {i \in  \left\lbrack  m\right\rbrack   : x \in  {\mathbf{x}}_{i}}\right\}$是包含属性$x$的关系集合）时，连接查询$\mathcal{H} = \left\{  {\mathbf{x},\left\{  {{\mathbf{x}}_{1},\ldots ,{\mathbf{x}}_{m}}\right\}  }\right\}$是层次化的。层次化连接的属性总可以组织成树形结构，使得每个关系对应一条从根到节点的路径（见图4）。

We show how to exploit this nice property to improve Algorithm 3 on hierarchical joins with uniformization. Recall that the essence of uniformization is to decompose the instance into a set of sub-instances so that we can upper bound the residual sensitivity as tight as possible, as implied by the error expression in Theorem 1.5. In Definition 3.6, the residual sensitivity is built on the join sizes of a set of maximum boundary queries ${T}_{E}\left( \mathrm{I}\right)$ ’s,but these statistics are too far away from being the partition criteria. Instead, we find an upper bound of residual sensitivity in terms of degrees.

我们将展示如何利用这一优良特性来改进算法3在统一化层次连接上的表现。回顾统一化的本质是将实例分解为若干子实例，从而如定理1.5误差表达式所示，尽可能严格地限制残余敏感度。定义3.6中，残余敏感度是基于最大边界查询集${T}_{E}\left( \mathrm{I}\right)$的连接规模建立的，但这些统计量远不足以作为划分标准。为此，我们通过度数找到了残余敏感度的上界。

4.2.1 An Upper Bound on ${T}_{E}$ . In a hierarchical join $\mathcal{H}$ ,we denote $\mathcal{T}$ as the attribute tree for $\mathcal{H}$ . For any $E \subseteq  \left\lbrack  m\right\rbrack$ ,the partial attributes $\partial E$ forms a connected subtree of $\mathcal{T}$ including the root (see Figure 4). To derive an upper bound on ${T}_{E}$ ,we identify a broader class of $q$ -aggregate queries by generalizing aggregate attributes from ${\partial }_{E}$ to any subset of attributes that form a connected subtree of $\mathcal{T}$ including the root (i.e.,sitting on top of $\mathcal{T}$ ). For simplicity,we define $\mathop{\bigwedge }\limits_{E} = \mathop{\cap }\limits_{{i \in  E}}{\mathbf{x}}_{i}$ and $\mathop{\bigvee }\limits_{E} = \mathop{\cup }\limits_{{i \in  E}}{\mathbf{x}}_{i}$ .

4.2.1 ${T}_{E}$的上界。在层次化连接$\mathcal{H}$中，我们将$\mathcal{T}$表示为$\mathcal{H}$的属性树。对于任意$E \subseteq  \left\lbrack  m\right\rbrack$，部分属性$\partial E$构成包含根节点的$\mathcal{T}$连通子树（见图4）。为推导${T}_{E}$的上界，我们通过将聚合属性从${\partial }_{E}$推广至构成包含根节点的属性树连通子树（即位于$\mathcal{T}$顶端）的任意属性子集，从而定义更广泛的$q$聚合查询类。为简化表述，我们定义$\mathop{\bigwedge }\limits_{E} = \mathop{\cap }\limits_{{i \in  E}}{\mathbf{x}}_{i}$和$\mathop{\bigvee }\limits_{E} = \mathop{\cup }\limits_{{i \in  E}}{\mathbf{x}}_{i}$。

Definition 4.6 (q-aggregate Query). For a hierarchical join $\mathcal{H} =$ $\left( {\mathbf{x},\left\{  {{\mathbf{x}}_{1},\ldots ,{\mathbf{x}}_{m}}\right\}  }\right)$ ,an instance $\mathbf{I}$ ,and a subset $E \subseteq  \left\lbrack  m\right\rbrack$ of relations, assume that a subset $\mathbf{y} \subseteq  \mathop{\bigvee }\limits_{E}$ of attributes satisfies the following property ${}^{4}$ : for any ${x}_{1},{x}_{2} \in  \mathbf{x}$ ,if atom $\left( {x}_{1}\right)  \subseteq  \operatorname{atom}\left( {x}_{2}\right)$ and ${x}_{1} \in  \mathbf{y}$ , then ${x}_{2} \in  \mathbf{y}$ . A $q$ -aggregate query defined over $E$ on $\mathbf{y}$ is defined as

定义4.6（q-聚合查询）。对于层次化连接$\mathcal{H} =$$\left( {\mathbf{x},\left\{  {{\mathbf{x}}_{1},\ldots ,{\mathbf{x}}_{m}}\right\}  }\right)$、实例$\mathbf{I}$及关系子集$E \subseteq  \left\lbrack  m\right\rbrack$，若属性子集$\mathbf{y} \subseteq  \mathop{\bigvee }\limits_{E}$满足以下性质${}^{4}$：对于任意${x}_{1},{x}_{2} \in  \mathbf{x}$，若原子$\left( {x}_{1}\right)  \subseteq  \operatorname{atom}\left( {x}_{2}\right)$与${x}_{1} \in  \mathbf{y}$，则${x}_{2} \in  \mathbf{y}$。定义在$\mathbf{y}$上基于$E$的$q$聚合查询可表示为

$$
{T}_{E,\mathbf{y}}\left( \mathbf{I}\right)  = \mathop{\max }\limits_{{t \in  \operatorname{dom}\left( \mathrm{y}\right) }}\mathop{\sum }\limits_{{{t}^{\prime } \in  \operatorname{dom}\left( {\bigvee }_{E}\right)  : {\pi }_{\mathbf{y}}{t}^{\prime } = t}}\mathop{\prod }\limits_{{i \in  E}}{R}_{i}\left( {{\pi }_{{\mathbf{x}}_{i}}{t}^{\prime }}\right) .
$$

It is not hard to see ${T}_{E}\left( \mathrm{I}\right)  = {T}_{E,\partial E}\left( \mathrm{I}\right)$ from (1). Below,we focus on an upper bound for ${T}_{E,\mathbf{y}}\left( \mathbf{I}\right)$ with general $\mathbf{y}$ characterized by Definition 4.6, which boils down to the product of maximum degrees:

不难从(1)式看出${T}_{E}\left( \mathrm{I}\right)  = {T}_{E,\partial E}\left( \mathrm{I}\right)$。下文我们将重点讨论具有一般性$\mathbf{y}$（由定义4.6表征）的${T}_{E,\mathbf{y}}\left( \mathbf{I}\right)$上界，该上界可归结为最大度数的乘积：

Definition 4.7 (Maximum Degree). For a hierarchical join $\mathcal{H} =$ $\left( {\mathbf{x},\left\{  {{\mathbf{x}}_{1},\ldots ,{\mathbf{x}}_{m}}\right\}  }\right)$ ,an instance $\mathbf{I},E \subseteq  \left\lbrack  m\right\rbrack$ and $\mathbf{y} \subseteq  \mathop{\bigwedge }\limits_{E}$ ,the degree of tuple $t \in  \operatorname{dom}\left( \mathbf{y}\right)$ is:

定义4.7（最大度数）。对于层次化连接$\mathcal{H} =$$\left( {\mathbf{x},\left\{  {{\mathbf{x}}_{1},\ldots ,{\mathbf{x}}_{m}}\right\}  }\right)$、实例$\mathbf{I},E \subseteq  \left\lbrack  m\right\rbrack$及$\mathbf{y} \subseteq  \mathop{\bigwedge }\limits_{E}$，元组$t \in  \operatorname{dom}\left( \mathbf{y}\right)$的度数为：

$$
{\deg }_{E,\mathbf{y}}^{\mathrm{I}}\left( t\right)  = \begin{cases} \mathop{\sum }\limits_{{{t}^{\prime } \in  \operatorname{dom}\left( {\mathbf{x}}_{i}\right)  : {\pi }_{\mathbf{y}}{t}^{\prime } = t}}{R}_{i}\left( {t}^{\prime }\right) & \text{ if }\left| E\right|  = 1,\text{ say }E = \{ i\} \\  \left| \left\{  {{t}^{\prime } \in  {\Psi }_{E}\left( \mathrm{I}\right)  : {\pi }_{\mathbf{y}}{t}^{\prime } = t}\right\}  \right| & \text{ otherwise,} \end{cases}
$$

where ${\Psi }_{E}\left( \mathbf{I}\right)  = \left\{  {{\pi }_{\mathop{\bigwedge }\limits_{E}}{t}^{\prime } : {t}^{\prime } \in  \operatorname{dom}\left( \mathop{\bigvee }\limits_{E}\right) ,\mathop{\prod }\limits_{{i \in  E}}{R}_{i}\left( {{\pi }_{{\mathbf{x}}_{i}}{t}^{\prime }}\right)  > 0}\right\}$ . The maximum degree is defined as ${\operatorname{mdeg}}_{E}^{\mathrm{I}}\left( \mathbf{y}\right)  = \mathop{\max }\limits_{{t \in  \operatorname{dom}\left( \mathbf{y}\right) }}{\deg }_{E,\mathbf{y}}^{\mathrm{I}}\left( t\right)$ .

其中${\Psi }_{E}\left( \mathbf{I}\right)  = \left\{  {{\pi }_{\mathop{\bigwedge }\limits_{E}}{t}^{\prime } : {t}^{\prime } \in  \operatorname{dom}\left( \mathop{\bigvee }\limits_{E}\right) ,\mathop{\prod }\limits_{{i \in  E}}{R}_{i}\left( {{\pi }_{{\mathbf{x}}_{i}}{t}^{\prime }}\right)  > 0}\right\}$。最大度数定义为${\operatorname{mdeg}}_{E}^{\mathrm{I}}\left( \mathbf{y}\right)  = \mathop{\max }\limits_{{t \in  \operatorname{dom}\left( \mathbf{y}\right) }}{\deg }_{E,\mathbf{y}}^{\mathrm{I}}\left( t\right)$。

We next show an upper bound on ${T}_{E,\mathbf{y}}\left( \mathbf{I}\right)$ using ${\operatorname{mdeg}}_{E}^{\mathbf{I}}\left( \mathbf{y}\right)$ ’s. When the context is clear,we drop the superscript $\mathbf{I}$ from ${\operatorname{mdeg}}_{E}^{\mathbf{I}}\left( \mathbf{y}\right)$ .

接下来我们利用${\operatorname{mdeg}}_{E}^{\mathbf{I}}\left( \mathbf{y}\right)$给出${T}_{E,\mathbf{y}}\left( \mathbf{I}\right)$的上界。当上下文明确时，我们将省略${\operatorname{mdeg}}_{E}^{\mathbf{I}}\left( \mathbf{y}\right)$中的上标$\mathbf{I}$。

Case (1). When $\left| E\right|  = 1$ ,say $E = \{ i\}$ ,we note that $\mathbf{y} \subseteq  {\mathbf{x}}_{i}$ and ${T}_{E,\mathbf{y}}\left( \mathbf{I}\right)$ is essentially equivalent to ${\operatorname{mdeg}}_{i}\left( \mathbf{y}\right)$ ,since

情况(1)。当$\left| E\right|  = 1$时（例如$E = \{ i\}$），注意到$\mathbf{y} \subseteq  {\mathbf{x}}_{i}$且${T}_{E,\mathbf{y}}\left( \mathbf{I}\right)$本质上等价于${\operatorname{mdeg}}_{i}\left( \mathbf{y}\right)$，因为

$$
{T}_{E,\mathbf{y}}\left( \mathbf{I}\right)  = \mathop{\max }\limits_{{t \in  \operatorname{dom}\left( \mathbf{y}\right) }}\mathop{\sum }\limits_{{{t}^{\prime } \in  \operatorname{dom}\left( {\mathbf{x}}_{i}\right)  : {\pi }_{\mathbf{y}}{t}^{\prime } = t}}{R}_{i}\left( {t}^{\prime }\right)  = {\operatorname{mdeg}}_{E}\left( \mathbf{y}\right) .
$$

Case (2). In general,let ${\mathcal{H}}_{E,\mathbf{y}} = \left( {\mathop{\bigvee }\limits_{E} - \mathbf{y},\left\{  {{\mathbf{x}}_{i} - \mathbf{y} : i \in  E}\right\}  }\right)$ be the residual join defined on relations in $E$ after removing attributes $\mathbf{y}$ . We next distinguish two cases based on the connectivity ${}^{5}$ of ${\mathcal{H}}_{E,\mathbf{y}}$ :

情况(2)。一般而言，设${\mathcal{H}}_{E,\mathbf{y}} = \left( {\mathop{\bigvee }\limits_{E} - \mathbf{y},\left\{  {{\mathbf{x}}_{i} - \mathbf{y} : i \in  E}\right\}  }\right)$为移除属性$\mathbf{y}$后，基于$E$中关系定义的剩余连接。接下来我们根据${\mathcal{H}}_{E,\mathbf{y}}$的连接性${}^{5}$区分两种情况：

Case (2.1): ${\mathcal{H}}_{E,y}$ is disconnected. Let ${C}_{E}$ be the set of connected subqueries of ${\mathcal{H}}_{E,\mathbf{y}}$ . We can further decompose ${T}_{E,\mathbf{y}}\left( \mathbf{I}\right)$ as:

情况(2.1)：${\mathcal{H}}_{E,y}$不连通。设${C}_{E}$为${\mathcal{H}}_{E,\mathbf{y}}$的连通子查询集合，可将${T}_{E,\mathbf{y}}\left( \mathbf{I}\right)$进一步分解为：

$$
{T}_{E,\mathbf{y}}\left( \mathbf{I}\right)  = \mathop{\max }\limits_{{t \in  \operatorname{dom}\left( \mathbf{y}\right) }}\mathop{\prod }\limits_{{{E}^{\prime } \in  {\mathcal{C}}_{E}}}\mathop{\sum }\limits_{{{t}^{\prime } \in  \operatorname{dom}\left( {\bigvee }_{{E}^{\prime }}\right)  : {\pi }_{\mathbf{y} \cap  \left( {\bigvee }_{{E}^{\prime }}\right) }{t}^{\prime } = t}}\mathop{\prod }\limits_{{i \in  {E}^{\prime }}}{R}_{i}\left( {{\pi }_{{\mathbf{x}}_{i}}{t}^{\prime }}\right) 
$$

$$
 \leq  \mathop{\prod }\limits_{{{E}^{\prime } \in  {\mathcal{C}}_{E}}}\mathop{\max }\limits_{{t \in  \operatorname{dom}\left( \mathrm{y}\right) }}\mathop{\sum }\limits_{{{t}^{\prime } \in  \operatorname{dom}\left( {\bigvee }_{{E}^{\prime }}\right)  : {\pi }_{\mathrm{y} \cap  \left( {\bigvee }_{{E}^{\prime }}\right) }{t}^{\prime } = t}}\mathop{\prod }\limits_{{i \in  {E}^{\prime }}}{R}_{i}\left( {{\pi }_{{\mathbf{x}}_{i}}{t}^{\prime }}\right) 
$$

$$
 = \mathop{\prod }\limits_{{{E}^{\prime } \in  {\mathcal{C}}_{E}}}{T}_{{E}^{\prime },\mathbf{y} \cap  \left( {\nabla }_{{E}^{\prime }}\right) }\left( \mathbf{I}\right) ,
$$

since $\mathbf{y} \cap  \left( \mathop{\bigvee }\limits_{{E}^{\prime }}\right)  \subseteq  \mathop{\bigvee }\limits_{{E}^{\prime }}$ and $\mathbf{y} \cap  \left( \mathop{\bigvee }\limits_{{E}^{\prime }}\right)$ satisfies the property in Definition 4.7, if $\mathbf{y}$ satisfies the same property.

由于$\mathbf{y} \cap  \left( \mathop{\bigvee }\limits_{{E}^{\prime }}\right)  \subseteq  \mathop{\bigvee }\limits_{{E}^{\prime }}$和$\mathbf{y} \cap  \left( \mathop{\bigvee }\limits_{{E}^{\prime }}\right)$满足定义4.7中的性质，若$\mathbf{y}$也满足相同性质。

Case (2.2): ${\mathcal{H}}_{E,\mathbf{y}}$ is connected. In this case,we have $\mathbf{y} \subsetneq  \mathop{\bigwedge }\limits_{E}$ .

情况(2.2)：${\mathcal{H}}_{E,\mathbf{y}}$是连通的。此时我们有$\mathbf{y} \subsetneq  \mathop{\bigwedge }\limits_{E}$。

$$
{T}_{E,\mathbf{y}}\left( \mathrm{I}\right)  \leq  {\operatorname{mdeg}}_{E}\left( \mathbf{y}\right)  \cdot  \mathop{\max }\limits_{{t \in  \operatorname{dom}\left( {\bigwedge }_{E}\right) }}\mathop{\sum }\limits_{{{t}^{\prime } \in  \operatorname{dom}\left( {\bigvee }_{E}\right)  : {\pi }_{{\bigwedge }_{E}}{t}^{\prime } = t}}\mathop{\prod }\limits_{{i \in  E}}{R}_{i}\left( {{\pi }_{{\mathbf{x}}_{i}}{t}^{\prime }}\right) 
$$

$$
 = {\operatorname{mdeg}}_{E}\left( \mathbf{y}\right)  \cdot  {T}_{E,\mathop{\bigwedge }\limits_{E}}\left( \mathbf{I}\right) ,
$$

since $\mathop{\bigwedge }\limits_{E} \subseteq  \mathop{\bigvee }\limits_{E}$ and $\mathop{\bigwedge }\limits_{E}$ satisfies the property in Definition 4.7.

因为$\mathop{\bigwedge }\limits_{E} \subseteq  \mathop{\bigvee }\limits_{E}$和$\mathop{\bigwedge }\limits_{E}$满足定义4.7中的性质。

Hence, ${T}_{E,\mathbf{y}}\left( \mathbf{I}\right)$ is eventually upper bounded by a product chain of maximum degrees (see Figure 4). A careful inspection reveals that the maximum degrees participating in ${T}_{E}\left( \mathbf{I}\right)$ for $\mathbf{y} = \partial E$ are not arbitrary; instead, they display rather special structures captured by Lemma 4.8, which is critical to our partition procedure.

因此，${T}_{E,\mathbf{y}}\left( \mathbf{I}\right)$最终被最大度数的乘积链所上界（见图4）。仔细检查可发现，参与${T}_{E}\left( \mathbf{I}\right)$的最大度数对于$\mathbf{y} = \partial E$并非任意的，而是呈现出由引理4.8捕捉的特殊结构，这对我们的分割过程至关重要。

LEMMA 4.8. Every maximum degree ${\operatorname{mdeg}}_{{E}^{\prime }}\left( \mathrm{y}\right)$ participating in the upper bound of ${T}_{E}\left( \mathrm{I}\right)$ corresponds to a distinct attribute $x \in  \mathbf{x}$ such that ${E}^{\prime } = \operatorname{atom}\left( x\right)$ and $\mathbf{y}$ corresponds to the ancestors of $x$ in $\mathcal{T}$ .

引理4.8。每个参与${T}_{E}\left( \mathrm{I}\right)$上界的最大度数${\operatorname{mdeg}}_{{E}^{\prime }}\left( \mathrm{y}\right)$都对应一个独特属性$x \in  \mathbf{x}$，使得${E}^{\prime } = \operatorname{atom}\left( x\right)$且$\mathbf{y}$对应于$\mathcal{T}$中$x$的祖先。

4.2.2 Partition with Maximum Degrees. After getting an upper bound on ${T}_{E}\left( \mathbf{I}\right)$ ,we now define degree configuration for hierarchical joins, similarly to the two-table join. Our target is to decompose the input instance into a set of sub-instances (which may not be tuple-disjoint), such that each sub-instance is characterized by one distinct degree configuration, and join results of all sub-instances form a partition of the final join result.

4.2.2 基于最大度数的分割。在获得${T}_{E}\left( \mathbf{I}\right)$的上界后，我们现在定义层次化连接的度数配置，类似于两表连接。目标是将输入实例分解为一组子实例（可能非元组互斥），每个子实例由唯一的度数配置表征，且所有子实例的连接结果构成最终连接结果的划分。

Definition 4.9 (Degree Configuration). For a hierarchical join $\mathcal{H} =$ $\left( {\mathbf{x},\left\{  {{\mathbf{x}}_{1},\ldots ,{\mathbf{x}}_{m}}\right\}  }\right)$ ,a degree configuration is defined as $\sigma  : {2}^{\left\lbrack  m\right\rbrack  } \times$ ${2}^{\mathbf{x}} \rightarrow  {\mathbb{Z}}^{ \geq  0} \cup  \{  \bot  \}$ such that for any $E \subseteq  \left\lbrack  m\right\rbrack$ and $\mathbf{y} \subseteq  \mathbf{x},\sigma \left( {E,\mathbf{y}}\right)  \neq   \bot$ if and only if there exists an attribute $x \in  \mathbf{x}$ such that $E = \operatorname{atom}\left( x\right)$ and $\mathbf{y}$ is the set of ancestors of $x$ in the attribute tree $\mathcal{T}$ of $\mathcal{H}$ .

定义4.9（度数配置）。对于层次化连接$\mathcal{H} =$$\left( {\mathbf{x},\left\{  {{\mathbf{x}}_{1},\ldots ,{\mathbf{x}}_{m}}\right\}  }\right)$，度数配置定义为$\sigma  : {2}^{\left\lbrack  m\right\rbrack  } \times$${2}^{\mathbf{x}} \rightarrow  {\mathbb{Z}}^{ \geq  0} \cup  \{  \bot  \}$，其中对于任意$E \subseteq  \left\lbrack  m\right\rbrack$和$\mathbf{y} \subseteq  \mathbf{x},\sigma \left( {E,\mathbf{y}}\right)  \neq   \bot$，当且仅当存在属性$x \in  \mathbf{x}$使得$E = \operatorname{atom}\left( x\right)$，且$\mathbf{y}$是$\mathcal{H}$属性树$\mathcal{T}$中$x$的祖先集合。

Algorithm 6 recursively decomposes the input instance by attributes in a bottom-up way on $\mathcal{T}$ ,and invokes Algorithm 7 as a primitive to further decompose every sub-instance. Algorithm 7 takes as input an attribute $x$ and an instance $\mathbf{I}$ that has been decomposed by all descendants of $x$ ,and outputs a set of sub-instances such that their join results form a partition of join result of $\mathbf{I}$ ,and for every sub-instance ${\mathbf{I}}^{\prime },{\deg }_{\operatorname{atom}\left( x\right) ,\mathbf{y}}^{{\mathbf{I}}^{\prime }}\left( t\right)$ is roughly the same for every tuple $t \in  \operatorname{dom}\left( \mathbf{y}\right)$ ,where $\mathbf{y}$ is the set of ancestors of $x$ in $\mathcal{T}$ .

算法6以自底向上的方式在$\mathcal{T}$上按属性递归分解输入实例，并调用算法7作为基础操作进一步分解每个子实例。算法7以属性$x$和已被$x$所有后代属性分解的实例$\mathbf{I}$作为输入，输出一组子实例，这些子实例的连接结果构成$\mathbf{I}$连接结果的划分，且对于每个子实例${\mathbf{I}}^{\prime },{\deg }_{\operatorname{atom}\left( x\right) ,\mathbf{y}}^{{\mathbf{I}}^{\prime }}\left( t\right)$，其中$\mathbf{y}$是$x$在$\mathcal{T}$中的祖先属性集合时，每个元组$t \in  \operatorname{dom}\left( \mathbf{y}\right)$的值大致相同。

## 5 CONCLUSIONS AND DISCUSSION

## 5 结论与讨论

In this paper, we proposed algorithms for releasing synthetic data for answering linear queries over multi-table joins. Our work opens up several interesting directions listed below.

本文提出了多表连接线性查询合成数据发布的算法，开辟了以下若干研究方向：

Non-Hierarchical Queries. Perhaps the most immediate question is if uniformization can benefit the non-hierarchical case, even for the simplest join $\mathcal{H}$ defined on $\mathbf{x} = \{ A,B,C\}$ with ${\mathbf{x}}_{1} = \{ A,B\}$ , ${\mathbf{x}}_{2} = \{ B,C\}$ ,and ${\mathbf{x}}_{3} = \{ C,D\}$ . In determining the residual sensitivity in Definition 3.6,we observe that ${T}_{23}\left( \mathrm{I}\right)  \leq  {\operatorname{mdeg}}_{2}\left( B\right)  \cdot  {\operatorname{mdeg}}_{3}\left( C\right)$ , ${T}_{12}\left( \mathbf{I}\right)  \leq  {\operatorname{mdeg}}_{1}\left( B\right)  \cdot  {\operatorname{mdeg}}_{2}\left( C\right)$ ,and ${T}_{13} \leq  {\operatorname{mdeg}}_{1}\left( B\right)  \cdot  {\operatorname{mdeg}}_{3}\left( C\right)$ . It is easy to uniformize ${\operatorname{mdeg}}_{1}\left( B\right) ,{\operatorname{mdeg}}_{3}\left( C\right)$ by partitioning ${R}_{1},{R}_{3}$ by attributes $B,C$ respectively. However,it is challenging to uniformize ${\operatorname{mdeg}}_{2}\left( B\right) ,{\operatorname{mdeg}}_{2}\left( C\right)$ by partitioning ${R}_{2}$ ,while keeping the number of sub-instances small. For example, a trivial strategy simply puts every individual tuple $t \in  {\mathbb{D}}_{2}$ with ${R}_{2}\left( t\right)  > 0$ ,together with tuples in ${R}_{1},{R}_{3}$ that can be joined with $t$ ,as one sub-instance. In this case,it is great to have small ${\operatorname{mdeg}}_{2}\left( B\right)$ and ${\operatorname{mdeg}}_{2}\left( C\right)$ ,but each tuple from ${R}_{1}$ or ${R}_{3}$ may participate in ${\operatorname{mdeg}}_{1}\left( B\right)$ or ${\operatorname{mdeg}}_{3}\left( C\right)$ sub-instances, hence the privacy consumption increases linearly when applying the parallel decomposition! Alternatively, one may uniformize ${\operatorname{mdeg}}_{2}\left( B\right)$ and ${\operatorname{mdeg}}_{2}\left( C\right)$ independently,say with partitions ${\pi }_{1}$ of $\operatorname{dom}\left( B\right)$ and ${\pi }_{2}$ of $\operatorname{dom}\left( C\right)$ . However,the degrees ${\deg }_{2,B}$ as well as ${\deg }_{2,C}$ are defined on the whole relation ${R}_{2}$ ,hence we may still end up with very non-uniform distribution of ${\deg }_{2,B},{\deg }_{2,C}$ when restricting to a sub-instance induced by ${B}_{{\pi }_{1}}^{i},{C}_{{\pi }_{2}}^{j}$ together. We leave this interesting question for future work.

非层次化查询。最直接的问题或许是均匀化技术能否适用于非层次化场景，即便是针对定义在$\mathbf{x} = \{ A,B,C\}$上、包含${\mathbf{x}}_{1} = \{ A,B\}$、${\mathbf{x}}_{2} = \{ B,C\}$和${\mathbf{x}}_{3} = \{ C,D\}$的最简单连接$\mathcal{H}$。在确定定义3.6中的残余敏感度时，我们注意到${T}_{23}\left( \mathrm{I}\right)  \leq  {\operatorname{mdeg}}_{2}\left( B\right)  \cdot  {\operatorname{mdeg}}_{3}\left( C\right)$、${T}_{12}\left( \mathbf{I}\right)  \leq  {\operatorname{mdeg}}_{1}\left( B\right)  \cdot  {\operatorname{mdeg}}_{2}\left( C\right)$和${T}_{13} \leq  {\operatorname{mdeg}}_{1}\left( B\right)  \cdot  {\operatorname{mdeg}}_{3}\left( C\right)$。通过分别按属性$B,C$划分${R}_{1},{R}_{3}$来实现${\operatorname{mdeg}}_{1}\left( B\right) ,{\operatorname{mdeg}}_{3}\left( C\right)$的均匀化是容易的，但在保持子实例数量较少的情况下，通过划分${R}_{2}$来实现${\operatorname{mdeg}}_{2}\left( B\right) ,{\operatorname{mdeg}}_{2}\left( C\right)$的均匀化则具有挑战性。例如，一种简单策略将每个包含${R}_{2}\left( t\right)  > 0$的独立元组$t \in  {\mathbb{D}}_{2}$与${R}_{1},{R}_{3}$中能与$t$连接的元组合并为一个子实例。这种情况下，较小的${\operatorname{mdeg}}_{2}\left( B\right)$和${\operatorname{mdeg}}_{2}\left( C\right)$固然理想，但来自${R}_{1}$或${R}_{3}$的每个元组可能参与${\operatorname{mdeg}}_{1}\left( B\right)$或${\operatorname{mdeg}}_{3}\left( C\right)$个子实例，导致并行分解时隐私消耗线性增长！另一种方案是独立均匀化${\operatorname{mdeg}}_{2}\left( B\right)$和${\operatorname{mdeg}}_{2}\left( C\right)$，比如采用$\operatorname{dom}\left( B\right)$的分区${\pi }_{1}$和$\operatorname{dom}\left( C\right)$的分区${\pi }_{2}$。然而，由于度数${\deg }_{2,B}$和${\deg }_{2,C}$是基于整个关系${R}_{2}$定义的，当限制在由${B}_{{\pi }_{1}}^{i},{C}_{{\pi }_{2}}^{j}$共同诱导的子实例时，${\deg }_{2,B},{\deg }_{2,C}$仍可能出现高度非均匀分布。这个有趣的问题留待未来研究。

Query-Specific Optimality. Throughout this work, we consider worst-case set $Q$ of queries parameterized by its size. Although this is a reasonable starting point, it is also plausible to hope for an algorithm that is nearly optimal for all query sets $Q$ . In the single-table case, this has been achieved in [5, 26, 39]. However, the situation is more complicated in the multi-table setting since we have to take the local sensitivity into account, whereas, in the single-table case, the query family already dictates the possible change resulting from moving to a neighboring dataset. This is also an interesting open question for future research.

查询特异性最优解。本研究中我们始终考虑以查询集规模为参数的最坏情况集合$Q$。虽然这是合理的起点，但我们也期望能获得对所有查询集$Q$都近乎最优的算法。单表场景下，该目标已在[5,26,39]中实现。然而多表设置更为复杂，因为必须考虑局部敏感度——而在单表情况下，查询族本身就已决定了相邻数据集转换可能引发的变动。这也是未来研究中值得探索的开放性课题。

Instance-Specific Optimality. We have considered worst-case instances in this work. One might instead prefer to achieve finer-grained instance-optimal errors. For the single-table case, [2] observed that an instance-optimal DP algorithm is not achievable, since a trivial algorithm can return the same answer(s) for all input instances, which could work perfectly on one specific instance but poorly on all remaining instances. To overcome this, a notion of "neighborhood optimality" has been proposed [2, 16], where we consider not only a single instance but also its neighbors at some constant distance. We note, however, that this would not work in our setting when there are a large number of queries. Specifically, if we again consider an algorithm that always returns the true answer for this instance, then its error with respect to the entire neighborhood set is still quite small-at most the distance times the maximum local sensitivity in the set. This is independent of the table size $n$ ,whereas our lower bounds show that the dependence on $n$ is inevitable. As such,the question of how to define and prove instance-optimal errors remains open for the multi-query case.

实例特定最优性。本文我们研究了最坏情况下的实例，但有人可能更希望实现更细粒度的实例最优误差。针对单表情况，文献[2]指出实例最优的差分隐私算法是不可实现的，因为一个平凡算法可以对所有输入实例返回相同答案，这在特定实例上表现完美却在其他所有实例上表现糟糕。为解决此问题，文献[2,16]提出了"邻域最优性"概念，不仅考虑单个实例还包含其固定距离内的邻域实例。但需注意，当存在大量查询时该方案将失效——若某算法始终返回当前实例的真实答案，其相对于整个邻域集的误差仍然很小（至多为距离乘以集合中最大局部敏感度）。该误差与表规模$n$无关，而我们的下界证明表明对$n$的依赖不可避免。因此，在多查询场景下如何定义并证明实例最优误差仍是未解难题。

We distinguish two cases below: (1) ${R}_{i} : {\mathbb{D}}_{i} \rightarrow  \{ 0,1\} ;\left( 2\right) {R}_{i} : {\mathbb{D}}_{i} \rightarrow$ ${\mathbb{Z}}^{ \geq  0}$ . So, ${T}_{E}\left( \mathbf{I}\right)$ is bounded by the maximum join size of ${\mathcal{H}}_{E,\partial E} = \left( {{ \cup  }_{e \in  E}e \smallsetminus  }\right.$ $\partial E,\left\{  {{\mathbf{x}}_{i} \smallsetminus  \partial E : i \in  E}\right\}$ . From the AGM bound,we have ${T}_{E}\left( \mathbf{I}\right)  \leq$ ${n}^{\rho \left( {\mathcal{H}}_{E,\partial E}\right) }$ . In the second case, the AGM bound does not hold any more. A simpler tight bound on the maximum join size is $\Theta \left( {n}^{m}\right)$ . Correspondingly, $\mathop{\max }\limits_{{E \subseteq  \left\lbrack  m\right\rbrack  }}{T}_{E}\left( \mathrm{I}\right)  \leq  {n}^{m - 1}$ . THEOREM C.2. 定理C.2。对于任意层次化连接$\mathcal{H}$及实例$\mathbf{I}$，线性查询族$Q$与参数$\epsilon  > 0,\delta  > 0$，存在一个满足$\left( {\epsilon ,\delta }\right)$-差分隐私的算法，该算法以至少$1 - 1/\operatorname{poly}\left( \left| \mathcal{Q}\right| \right)$的概率生成$\mathbb{F}$，使得$Q$中所有查询的应答误差不超过：

$$
\alpha  = O\left( {\left( {\mathop{\sum }\limits_{\sigma }\sqrt{\operatorname{count}\left( {\mathbf{I}}_{{\pi }^{ * }}^{\sigma }\right)  \cdot  R{S}_{\text{count }}^{\sigma } \cdot  \lambda } + R{S}_{\text{count }}^{\sigma } \cdot  \lambda }\right)  \cdot  {f}^{\text{upper }}}\right) ,

where $\sigma$ is over all degree configurations of $\mathcal{H},{\mathbf{I}}_{{\pi }^{ * }}^{\sigma }$ is the sub-instance characterized by $\sigma$ under the uniform partition ${\pi }^{ * }$ ,and ${\mathrm{{RS}}}_{\text{count }}^{\sigma }$ be the residual sensitivity derived for instance characterized by $\sigma$ .

设$\overrightarrow{\mathrm{{OUT}}} = \left\{  {{\mathrm{{OUT}}}^{\sigma } \in  {\mathbb{Z}}^{ \geq  }0 : \sigma \text{is a degree configuration}}\right\}$为均匀划分${\pi }^{ * }$上的连接规模分布。若实例I满足：对于每个度配置$\sigma$，计数$\left( {\mathrm{I}}_{{\pi }^{ * }}^{\sigma }\right)  = \Theta \left( {\mathrm{{OUT}}}^{\sigma }\right)$（其中${\mathbf{I}}_{{\pi }^{ * }}^{\sigma }$是$\mathbf{I}$在$\sigma ,{\pi }^{ * }$下的子实例），则称I符合$\overrightarrow{\mathrm{{OUT}}}$。通过扩展定理4.5的下界论证，我们得到层次化查询的以下参数化下界。

THEOREM C.3. 定理C.3. 给定一个分层连接$\mathcal{H}$和任意参数$\overrightarrow{\mathrm{{OUT}}}$，对于所有足够小的$\epsilon  > 0,{n}_{D} \geq  {\mathrm{{OUT}}}^{O\left( 1\right) }$和${n}_{Q} \geq  {\left( \mathrm{{OUT}} \cdot  \log {n}_{D}\right) }^{O\left( 1\right) }$，存在一个查询族$Q$，其规模为${n}_{O}$，定义域大小为$\mathbb{D}$，使得任何$\left( {\epsilon ,1/{n}^{\omega \left( 1\right) }}\right)$-差分隐私算法在输入规模不超过$n$的$\mathcal{H}$多表实例并遵循$\overrightarrow{\mathrm{{OUT}}}$约束时，若要对$Q$中每个查询输出误差在$\alpha$以内的近似答案，则必须满足

where the maximum is over all degree configurations $\sigma$ of $\mathcal{H}$ and ${\mathrm{{LS}}}_{\text{count }}^{\sigma } = \mathop{\max }\limits_{{i \in  \left\lbrack  m\right\rbrack  }}{T}_{\left\lbrack  m\right\rbrack  \smallsetminus \{ i\} }^{\sigma }$ is the local sensitivity of count(-) under $\sigma$ .
