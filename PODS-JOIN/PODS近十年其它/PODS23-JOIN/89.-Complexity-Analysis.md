## ABSTRACT

## 摘要

Even though query evaluation is a fundamental task in databases, known classifications of conjunctive queries by their fine-grained complexity only apply to queries without self-joins. We study how self-joins affect enumeration complexity, with the aim of building upon the known results to achieve general classifications. We do this by examining the extension of two known dichotomies: one with respect to linear delay, and one with respect to constant delay after linear preprocessing. As this turns out to be an intricate investigation, this paper is structured as an example-driven discussion that initiates this analysis. We show enumeration algorithms that rely on self-joins to efficiently evaluate queries that otherwise (i.e., if the relation names were replaced to eliminate self-joins) cannot be answered with the same guarantees. Due to these additional tractable cases, the hardness proofs are more complex than the self-join-free case. We show how to harness a known tagging technique to prove hardness of queries with self-joins. Our study offers sufficient conditions and necessary conditions for tractability and settles the cases of queries of low arity and queries with cyclic cores. Nevertheless, many cases remain open.

尽管查询评估是数据库的基础任务，但现有的合取查询细粒度复杂性分类仅适用于无自连接查询。我们研究自连接如何影响枚举复杂性，旨在基于已知成果建立普适性分类框架。通过扩展两种经典二分法——线性延迟与线性预处理后恒定延迟——展开研究。鉴于问题的复杂性，本文采用案例驱动的讨论方式开启分析。我们展示了利用自连接高效评估查询的枚举算法，这些查询若消除自连接（即替换关系名称）则无法获得相同效率保证。由于新增易处理案例，其硬度证明比无自连接情形更为复杂。我们演示如何运用标记技术证明带自连接查询的硬度。本研究提出了易处理性的充分条件与必要条件，并解决了低元数查询和具有循环核心查询的分类问题，但仍有诸多案例待解。

## 1 INTRODUCTION

## 1 引言

Query evaluation is one of the most central problems in database systems. This task asks to compute the set of solutions to a given query over a given database. In this paper we focus on joins and sometimes projections, the basic building blocks of queries, expressed as conjunctive queries. When treating both the database and the query as input, query evaluation is then NP-complete [6]. Here, we adopt the data complexity point of view: the complexity is analyzed with respect to the database size, while the query size (which is usually small) is considered constant. In this setting, query answering takes polynomial time. However, not all queries are equally hard as for some queries this polynomial is much smaller than for others. Ideally, we would like to understand, given any specific query, how fast this query can be evaluated. As the number of solutions may be much larger than the input, considering the delay between solutions and not just the total computation time can be meaningful: the user does not have to wait for the entire computation to be done before seeing some of the solutions. The ideal time guarantee we can hope to achieve is linear time before the first solution (required to read the input and determine whether a first solution exists) and constant time between successive solutions (required to print the output).

查询评估是数据库系统中最核心的问题之一。该任务要求计算给定查询在给定数据库上的解集。本文聚焦于连接操作和偶尔的投影操作——这些以合取查询形式表示的基本查询构建模块。当同时将数据库和查询作为输入时，查询评估问题属于NP完全问题[6]。本文采用数据复杂度的视角：复杂度分析针对数据库规模，而查询规模（通常较小）被视为常数。在此设定下，查询应答可在多项式时间内完成。但不同查询的难度存在差异，某些查询的多项式时间远小于其他查询。理想情况下，我们希望理解对于任意特定查询，其评估速度的理论极限。由于解集规模可能远超输入规模，考量解之间的延迟（而非仅总计算时间）具有意义：用户无需等待全部计算完成即可看到部分解。我们期望达到的理想时间保证是：首解前线性时间（用于读取输入并判断首解是否存在），连续解间恒定时间（用于输出结果）。

We know that any acyclic query with a free-connex form can be answered with linear preprocessing and constant delay. For acyclic queries that are not free-connex, we do not have an algorithm with such guarantees, but we do have algorithms with linear delay (and linear preprocessing). At this point, it is natural to ask: Are free-connex and acyclic queries the only ones for which such efficient algorithms exist or should we keep looking for efficient algorithms for additional queries?

已知任何具有自由连接形式(free-connex)的无环查询都可通过线性预处理和恒定延迟应答。对于非自由连接的无环查询，虽无算法能提供同等保证，但存在具有线性延迟（及线性预处理）的算法。此时自然产生疑问：自由连接和无环查询是否是唯一存在高效算法的类型？抑或我们应继续寻找其他查询的高效算法？

To answer this question, we have conditional lower bounds showing that other queries cannot be answered within these time bounds unless there would be a significant breakthrough in well-studied problems. However, these hardness results were only proved for self-join-free conjunctive queries, queries in which each relation appears at most once. More specifically, if a self-join-free query is acyclic but not free-connex, then the set of all its solutions cannot be computed in time linear in the input and output sizes, assuming Boolean matrices cannot be multiplied in quadratic time [1]. Moreover, one cannot even produce a single solution to a self-join-free cyclic query in linear time, assuming hypercliques cannot be detected in linear time [3]. The hardness results described in this introduction also assume the hardness of the two aforementioned algorithmic problems.

针对该问题，我们通过条件性下界证明：除非在经典难题上取得重大突破，否则其他查询无法在既定时间界限内应答。但现有硬度结果仅针对无自连接(self-join-free)的合取查询（即每个关系至多出现一次的查询）。具体而言：若某无自连接查询是无环但非自由连接的，则假设布尔矩阵无法在平方时间内完成乘法[1]，其所有解的计算时间无法与输入输出规模呈线性关系；更进一步，假设超团(hyperclique)无法在线性时间内检测[3]，甚至无法为无自连接的环状查询生成单个线性时间解。本节所述硬度结果同样基于上述两个算法难题的未解性。

For years, database researchers were satisfied with these hardness results despite the limitation to self-join-free queries, as self-joins are known to be problematic. We remark that self-joins are very common in some contexts (e.g., graph databases). It was believed that the above characterization would extend to queries with self-joins and that this restriction is merely a limitation of our lower-bound tools. This extension was even claimed along with a proof sketch [3]. However, Berkholz, Gerhardt, and Schweikardt [2] recently refuted this claim by showing a cyclic query with self-joins that can be evaluated efficiently. That is, we now know that queries with self-joins can be easier than self-join-free queries of the same form. Now that we have an example that shows it is possible, we would like to understand how, and in which cases, self-joins can be used to streamline query evaluation. Here, we initiate the complexity analysis for the evaluation of conjunctive queries with self-joins.

多年来，数据库研究者虽受限于无自连接的前提，仍对这些硬度结果感到满意——因为自连接本就以棘手著称。需指出自连接在某些场景（如图数据库）极为常见。学界曾认为上述特征可推广至含自连接的查询，现有局限仅源于下界证明工具的不足。该推论甚至曾被附带证明纲要提出[3]。然而Berkholz、Gerhardt和Schweikardt[2]最近通过展示可高效评估的含自连接环状查询，推翻了这一论断。这表明：含自连接的查询可能比同结构的无自连接查询更易处理。既然存在可能性实例，我们亟需理解自连接在何种情况下能优化查询评估。本文首次对含自连接的合取查询展开复杂度分析。

In this paper, we explore the effects of self-joins on query evaluation complexity from an enumeration point of view. The aim is to use known results for the self-join-free case to reason about general queries that may contain self-joins. We show enumeration algorithms that rely on self-joins to efficiently evaluate queries that otherwise cannot be answered with the same guarantees. That is, existing conditional lower bounds suggest that similar queries with unique relation names (the same query structure but no self-joins) cannot be answered within the time guarantees obtained by our algorithms. Due to these additional tractable cases, the hardness proofs also require additional complications compared to the self-join-free case. We show how to harness a known tagging technique to prove hardness of queries with self-joins.

本文从枚举视角探究自连接对查询求值复杂度的影响。旨在利用无自连接场景的已知结论，推导可能包含自连接的一般性查询。我们展示的枚举算法通过自连接高效求值那些原本无法获得相同保证的查询——现有条件性下界表明，具有唯一关系名的类似查询（相同结构但无自连接）无法达到我们算法的时间保证。由于这些新增的可处理案例，其难度证明相较无自连接情况也需更复杂的处理。我们将阐述如何运用已知的标记技术来证明含自连接查询的难度。

We discuss the difficulty in proving lower bounds for queries with self-joins in Section 3 and then define the tagging technique and explain the importance of endomorphism images for its analysis. Section 4 uses this technique to establish that self-joins do not change whether a query of arity two or less can be enumerated with constant delay. In Section 5, we show that queries with a cyclic "core" are hard in the sense that they cannot be answered with only linear preprocessing, even if they contain self-joins. As a result, we focus on queries with an acyclic core in the rest of the paper.

第3节讨论自连接查询下界证明的难点，随后定义标记技术并阐释自同态像对其分析的重要性。第4节运用该技术证实：自连接不会改变二元及以下查询能否以恒定延迟枚举的特性。第5节表明，具有循环"核心"的查询即使在含自连接时，也无法仅通过线性预处理来应答，这体现了其难度。因此本文后续将聚焦于具有非循环核心的查询。

Next, we focus on full conjunctive queries, with no projection. In Section 6, we phrase a sufficient condition and a necessary condition for enumeration with linear delay, but we also give examples of cases that are not covered by either of these conditions. In Section 7, we identify a class of cyclic queries that can be answered with constant delay (we call these mirror queries). We then provide an example-driven discussion of how simple acyclic additions (unary atoms and spikes) to tractable queries can affect the complexity. We finish with a simple (single-cycle) query of unknown complexity. Missing details appear in the appendix.

接下来我们专注于无投影的完全合取查询。第6节提出线性延迟枚举的充分条件与必要条件，同时也给出不满足这两个条件的案例。第7节界定了一类能以恒定延迟应答的循环查询（称为镜像查询），并通过示例讨论可处理查询添加简单非循环结构（一元原子与尖峰）对复杂度的影响。最后给出一个复杂度未知的简单（单循环）查询，附录包含缺失细节。

## 2 PRELIMINARIES

## 2 预备知识

A database $D$ is a finite relational structure consisting of a relational schema $\sigma$ ,a finite domain $V$ ,and for each relational symbol $R$ of $\sigma$ of arity $r$ ,a subset ${R}^{D}$ of ${V}^{r}$ . A term $R\left( \bar{a}\right)$ where $\bar{a} \in  {R}^{D}$ is called a fact of $D$ .

数据库$D$是有限关系结构，包含关系模式$\sigma$、有限域$V$，以及对于$\sigma$中每个元数为$r$的关系符号$R$，对应${V}^{r}$的子集${R}^{D}$。当$\bar{a} \in  {R}^{D}$时，项$R\left( \bar{a}\right)$称为$D$的事实。

In this paper, query always refers to a conjunctive query, i.e., a conjunction of atoms $R\left( \bar{x}\right)$ ,where $R \in  \sigma$ and $\bar{x}$ is a tuple of variables of the appropriate arity, with some of the variables existentially quantified. The variables that are not quantified in $q$ are called the free variables of $q$ . The arity of a query is the number of its free variables. A Boolean/unary/binary query is a query of arity $0/1/2$ respectively. A query is full if it contains no quantified variables, i.e., all the variables are free. A query has self-joins if it contains two atoms with the same relational symbol; otherwise, it is called self-join-free. For example,the query $R\left( {{x}_{1},{x}_{2}}\right)  \land  R\left( {{x}_{2},{x}_{3}}\right)$ has self-joins while the query $R\left( {{x}_{1},{x}_{2}}\right)  \land  S\left( {{x}_{2},{x}_{3}}\right)$ is self-join-free.

本文中，查询均指合取查询，即原子式<b0></b1>的合取（其中$\bar{x}$为适当元数的变量元组），部分变量存在存在量词约束。在$q$中未被量化的变量称为自由变量。查询的元数即其自由变量数量，布尔/一元/二元查询分别对应元数$0/1/2$。若查询不含量化变量（所有变量皆自由），则称为完全查询。当查询包含两个相同关系符号的原子式时称为含自连接，否则称为无自连接。例如查询$R\left( {{x}_{1},{x}_{2}}\right)  \land  R\left( {{x}_{2},{x}_{3}}\right)$含自连接，而$R\left( {{x}_{1},{x}_{2}}\right)  \land  S\left( {{x}_{2},{x}_{3}}\right)$无自连接。

We will often specify full conjunctive queries using a colored hypergraph rather than a formula. Each node represents a variable of the query and is depicted by the number of the variable or a black dot when this number is not relevant. Each colored edge represents a binary atom, and each colored circle around a node represents a unary atom. The exact relation names are not depicted, but they are irrelevant to the complexity analysis. As an example, ${q}_{2}$ of Figure 1 defines the query $E\left( {{x}_{1},{x}_{2}}\right)  \land  E\left( {{x}_{2},{x}_{3}}\right)  \land  E\left( {{x}_{1},{x}_{4}}\right)  \land  E\left( {{x}_{4},{x}_{3}}\right)  \land  \operatorname{Red}\left( {x}_{2}\right)$ . We sometimes use a big circle to represent a relation of arity three or more (as in ${q}_{6}$ of Figure 3). When we do so,the order of the variables in this relation is not important for the example.

我们常用带色超图而非公式来完整描述合取查询。节点代表查询变量，用变量编号或无关时的黑点表示。彩色边表示二元原子，节点周围的彩色圆圈表示一元原子。具体关系名称未显示，因其对复杂度分析无影响。例如图1中的${q}_{2}$定义了查询$E\left( {{x}_{1},{x}_{2}}\right)  \land  E\left( {{x}_{2},{x}_{3}}\right)  \land  E\left( {{x}_{1},{x}_{4}}\right)  \land  E\left( {{x}_{4},{x}_{3}}\right)  \land  \operatorname{Red}\left( {x}_{2}\right)$。有时用大圆圈表示三元及以上关系（如图3的${q}_{6}$），此时变量顺序对示例不重要。

A query is acyclic if it has a join tree. A join tree for the query $q$ is a tree $T$ such that the nodes of $T$ are the atoms of $q$ and,for each variable $x$ of $q$ ,the nodes of $T$ whose atoms contain $x$ are connected in $T$ . An acyclic query $q$ is said to be free-connex if we obtain an acyclic query by adding to $q$ a new atom containing all the free variables of $q$ . As an example,the acyclic query $\exists {x}_{2}R\left( {{x}_{1},{x}_{2}}\right)  \land  S\left( {{x}_{2},{x}_{3}}\right)$ is not free-connex because the query $\exists {x}_{2}R\left( {{x}_{1},{x}_{2}}\right)  \land  S\left( {{x}_{2},{x}_{3}}\right)  \land  T\left( {{x}_{1},{x}_{3}}\right)$ is cyclic; however,the full acyclic query $R\left( {{x}_{1},{x}_{2}}\right)  \land  S\left( {{x}_{2},{x}_{3}}\right)$ is free-connex because the query $R\left( {{x}_{1},{x}_{2}}\right)  \land  S\left( {{x}_{2},{x}_{3}}\right)  \land  T\left( {{x}_{1},{x}_{2},{x}_{3}}\right)$ is acyclic. In fact, it follows from the definition of free-connexity that full acyclic queries are always free-connex. Similarly, Boolean or unary acyclic queries are free-connex as well.

若查询存在连接树则称其为无环查询。查询$q$的连接树$T$需满足：其节点是$q$的原子，且对每个变量$x$，包含该变量的节点在$T$中连通。若向无环查询$q$添加包含所有自由变量的新原子后仍保持无环性，则称其为自由连接查询。例如无环查询$\exists {x}_{2}R\left( {{x}_{1},{x}_{2}}\right)  \land  S\left( {{x}_{2},{x}_{3}}\right)$因$\exists {x}_{2}R\left( {{x}_{1},{x}_{2}}\right)  \land  S\left( {{x}_{2},{x}_{3}}\right)  \land  T\left( {{x}_{1},{x}_{3}}\right)$存在环而非自由连接；而完全无环查询$R\left( {{x}_{1},{x}_{2}}\right)  \land  S\left( {{x}_{2},{x}_{3}}\right)$因$R\left( {{x}_{1},{x}_{2}}\right)  \land  S\left( {{x}_{2},{x}_{3}}\right)  \land  T\left( {{x}_{1},{x}_{2},{x}_{3}}\right)$无环故满足条件。事实上根据定义，完全无环查询必为自由连接，布尔或一元无环查询亦然。

The solutions of a query $q$ over a database $D$ are denoted by $q\left( D\right)$ . They correspond to the set of tuples $\bar{a}$ such that: there exists an assignment of the elements of the domain of $D$ to the variables of $q$ making every atom of $q$ a fact of $D$ ,and $\bar{a}$ is the assignment to the free variables of $q$ . When we specify a solution to a query,we assume the free variables are ordered according to their numbering. The output size is the number of tuples in the set $q\left( D\right)$ . Two queries $q$ and ${q}^{\prime }$ are said to be equivalent if for every database $D,q\left( D\right)  = {q}^{\prime }\left( D\right)$ .

查询$q$在数据库$D$上的解记作$q\left( D\right)$，即满足以下条件的元组集$\bar{a}$：存在将$D$域中元素赋值给$q$变量的映射，使所有原子成为$D$中的事实，且$\bar{a}$是对自由变量的赋值。指定查询解时默认按变量编号排序。输出大小为$q\left( D\right)$中元组数。若对任意数据库$D,q\left( D\right)  = {q}^{\prime }\left( D\right)$均有相同解，则称查询$q$与${q}^{\prime }$等价。

An endomorphism of $q$ is a mapping from the variables of $q$ to the variables of $q$ that preserves the atoms of $q$ ; that is,if $R\left( \bar{x}\right)$ is an atom of $q$ and $v$ is an endomorphism of $q$ ,then $R\left( {v\left( \bar{x}\right) }\right)$ is also an atom of $q$ . An automorphism is a bijective endomorphism. A query $q$ is said to be minimal ${}^{1}$ if any endomorphism of $q$ that is the identity on the free variables of $q$ is an automorphism of $q$ . Notice that every self-join-free query is minimal as the only endomorphism in such a query is the identity mapping. Any query $q$ has an equivalent minimal query,called the minimal form of $q$ in what follows.

$q$的自同态(endomorphism)是指将$q$的变量映射到其自身变量、且保持$q$原子性的映射；即若$R\left( \bar{x}\right)$是$q$的原子，$v$是$q$的自同态，则$R\left( {v\left( \bar{x}\right) }\right)$仍是$q$的原子。自同构(automorphism)是双射的自同态。当$q$上所有自由变量恒等的自同态都是自同构时，称查询$q$是极小(minimal)${}^{1}$的。注意无自连接查询必然极小，因其唯一自同态就是恒等映射。任何查询$q$都存在等价的极小查询，后文称之为$q$的极小形式。

The problems we consider are parameterized by a query $q$ and take as input a database $D$ . The evaluation problem computes the set of solutions $q\left( D\right)$ . The testing problem asks whether $q\left( D\right)$ is empty. The enumeration problem is decomposed into two phases: the preprocessing phase computes a data structure that is used during the enumeration phase for outputting the solutions of $q\left( D\right)$ one by one and with no repetition. The maximal time between two consecutive answers during enumeration is called the delay.

我们研究的问题以查询$q$为参数，以数据库$D$为输入。求值问题计算解集$q\left( D\right)$，检测问题判定$q\left( D\right)$是否为空。枚举问题分为两个阶段：预处理阶段构建数据结构，枚举阶段利用该结构无重复地逐个输出$q\left( D\right)$的解。枚举过程中两个连续解之间的最长时间称为延迟(delay)。

We use the RAM computation model with uniform addition and multiplication, and we adopt the data complexity point of view. That is,the constants hidden in the big $O$ notation may depend on the query but not the database. The input size,denoted $\parallel D\parallel$ ,corresponds to the size of a reasonable encoding of the database $D$ ,linear in the number of database tuples. Note that an enumeration algorithm with linear preprocessing implies that the testing problem can be solved in linear time. A constant delay after linear preprocessing enumeration algorithm implies that the evaluation problem can be solved in linear input plus output time.

我们采用支持加法与乘法运算的RAM计算模型，并基于数据复杂度视角。即大$O$记号中的常数可依赖查询但不依赖数据库。输入规模$\parallel D\parallel$表示数据库$D$的合理编码大小，与元组数量线性相关。注意线性预处理时间的枚举算法意味着检测问题可在线性时间内解决。线性预处理后常数延迟的枚举算法意味着求值问题可在"输入加输出"线性时间内解决。

Many known enumeration algorithms for database queries conform to a strict definition of linear preprocessing and constant delay where the memory used during preprocessing is linear and the extra memory used after the preprocessing remains bounded by a constant $\left\lbrack  {1,7 - {10}}\right\rbrack$ . Our enumeration algorithms use the allowed time in the most general way, without memory restrictions. In particular, we assume we can test in constant time whether a given tuple is a fact of the database. It is not clear how to do this test without using perfect hashing, which requires polynomial memory in the size of the input database. The enumeration phases of our algorithms may also require a total memory of a similar size. This is required to store each produced solution (or parts of the solution), used later for producing more solutions. As this distinction is important, we will make it explicit when we use this extra memory. This is in particular the case in the proof of the Cheater's Lemma [5] that we use to eliminate duplicate answers.

多数已知数据库查询枚举算法遵循严格的线性预处理与常数延迟定义：预处理阶段内存使用线性增长，预处理后额外内存使用恒定受限$\left\lbrack  {1,7 - {10}}\right\rbrack$。我们的算法以最通用方式利用允许时间，无内存限制。特别地，我们假设可在常数时间内测试给定元组是否为数据库事实。若不使用完美哈希（需输入数据库规模的多项式内存）则难以实现该测试。算法枚举阶段也可能需要同等量级的总内存来存储已生成解（或部分解）以供后续生成更多解。鉴于这一区别的重要性，我们将明确标注额外内存的使用场景，特别是在应用作弊者引理[5]消除重复解时。

LEMMA 1 (CHEATER’s LEMMA) [5]. Let $q$ be a conjunctive query. If there is an algorithm evaluating $q$ with linear preprocessing time and constant/linear delay, where the number of times each output is produced is bounded by a constant, then there is an enumeration algorithm for $q$ that runs with linear preprocessing time and constant/linear delay, producing the solutions with no repetition. This new algorithm may use during the enumeration phase a memory of size $O\left( {\parallel D{\parallel }^{\left| q\right| }}\right)$ over an input database $D$ .

引理1（作弊者引理）[5]. 设$q$为合取查询。若存在算法能以线性预处理时间和常数/线性延迟评估$q$，且每个解的输出次数有界，则存在具有相同时间复杂度的无重复解枚举算法。新算法在枚举阶段可能使用<input database>$D$上规模为$O\left( {\parallel D{\parallel }^{\left| q\right| }}\right)$的内存。

As usual in this area, our lower bounds assume algorithmic conjectures,described next. A hypergraph is(k - 1)-uniform if every hyperedge is of size $k - 1$ . A $k$ -hyperclique is a set of $k$ nodes such that any subset of these nodes of size $k - 1$ forms a hyperedge.

该领域通常做法下，我们的下界证明基于以下算法猜想：若超图中每条超边大小为$k - 1$，则称其为(k-1)-均匀超图。$k$-超团是指$k$个节点构成的集合，其中任意$k - 1$个节点的子集都构成超边。

- sBMM conjectures that two Boolean matrices $A$ and $B$ ,represented as lists of their non-zero entries, cannot be multiplied in time $O\left( m\right)$ ,where $m$ is the number of non-zero entries in $A,B$ ,and ${AB}$ .

- sBMM猜想认为：以非零项列表表示的两个布尔矩阵$A$和$B$，其乘法时间复杂度不可能为$O\left( m\right)$，其中$m$表示$A,B$中非零项数量，且${AB}$。

- SHYPERCLIQUE conjectures that for all $k \geq  3$ ,it is not possible to determine the existence of a $k$ -hyperclique in a(k - 1)- uniform hypergraph with $m$ hyperedges in time $O\left( m\right)$ .

- SHYPERCLIQUE猜想认为，对于所有$k \geq  3$，无法在$O\left( m\right)$时间内确定一个具有$m$条超边的(k-1)-均匀超图中是否存在$k$-超团。

- HYPERCLIQUE conjectures that for all $k \geq  3$ ,it is not possible to determine the existence of a $k$ -hyperclique in a(k - 1)- uniform hypergraph with $n$ nodes in time $O\left( {n}^{k - 1}\right)$ .

- HYPERCLIQUE猜想认为，对于所有$k \geq  3$，无法在$O\left( {n}^{k - 1}\right)$时间内确定一个具有$n$个节点的(k-1)-均匀超图中是否存在$k$-超团。

Notice that sHYPERCLIQUE implies that we cannot detect a triangle in an undirected graph in linear time. HYPERCLIQUE implies the sparse hypotheses sHYPERCLIQUE and sBMM.

注意sHYPERCLIQUE意味着我们无法在线性时间内检测无向图中的三角形。HYPERCLIQUE蕴含稀疏假设sHYPERCLIQUE和sBMM。

We can now state the known results for query evaluation.

现在我们可以陈述查询评估的已知结果。

THEOREM 2. Let $q$ be a self-join-free conjunctive query.

定理2. 设$q$为无自连接合取查询。

- If $q$ is cyclic,the testing problem cannot be solved in linear time, assuming sHYPERCLIQUE [3].

- 若$q$是循环的，则在sHYPERCLIQUE假设下[3]，测试问题无法在线性时间内解决。

- If $q$ is acyclic,the enumeration problem can be solved with linear delay and linear preprocessing [1].

- 若$q$是非循环的，枚举问题可通过线性延迟和线性预处理解决[1]。

- If $q$ is acyclic but not free-connex,the evaluation problem cannot be solved in linear time in the input plus output sizes, assuming sBMM [1].

- 若$q$是非循环但不满足自由连接性，在sBMM假设下[1]，评估问题无法在输入加输出大小的线性时间内解决。

- If $q$ is acyclic and free-connex,the enumeration problem can be solved with constant delay and linear preprocessing [1].

- 若$q$是非循环且满足自由连接性，枚举问题可通过常数延迟和线性预处理解决[1]。

In the above theorem, the upper bounds also hold for queries with self-joins. The enumeration algorithms obtained in [1] use the strict definition of constant delay, where the total memory used during the enumeration phase only adds a constant to the memory used during the preprocessing phase.

上述定理中的上界也适用于含自连接的查询。文献[1]获得的枚举算法采用严格的常数延迟定义，其中枚举阶段使用的总内存仅比预处理阶段增加一个常数。

## 3 PROVING HARDNESS WITH SELF-JOINS

## 3 自连接情况下的硬度证明

Since we have a good understanding of the complexity of self-join-free queries, we are interested in comparing the complexity of general conjunctive queries to self-join-free queries with the same shape. More formally,we associate a self-join-free query ${q}^{\prime }$ to any query $q$ by giving distinct names to all relation symbols. As an example,the self-join-free query associated to $R\left( {{x}_{1},{x}_{2}}\right)  \land  R\left( {{x}_{2},{x}_{3}}\right)$ is ${R}_{1}\left( {{x}_{1},{x}_{2}}\right)  \land  {R}_{2}\left( {{x}_{2},{x}_{3}}\right)$ . Notice that this modification does not affect properties such as acyclicity or free-connexity.

由于我们已经充分理解无自连接查询的复杂性，我们感兴趣的是比较具有相同结构的普通合取查询与无自连接查询的复杂度。更正式地说，我们通过为所有关系符号赋予不同名称，将无自连接查询${q}^{\prime }$关联到任意查询$q$。例如，与$R\left( {{x}_{1},{x}_{2}}\right)  \land  R\left( {{x}_{2},{x}_{3}}\right)$关联的无自连接查询是${R}_{1}\left( {{x}_{1},{x}_{2}}\right)  \land  {R}_{2}\left( {{x}_{2},{x}_{3}}\right)$。注意这种修改不会影响非循环性或自由连接性等属性。

Going from a query $q$ to its associated self-join-free query ${q}^{\prime }$ can only make the evaluation task harder. This folklore proposition holds since ${q}^{\prime }$ can be used to compute $q$ ,and it implies that the upper bounds of Theorem 2 also hold for queries with self-joins.

从查询$q$转换到其关联的无自连接查询${q}^{\prime }$只会使评估任务变得更困难。这个常识性命题成立，因为${q}^{\prime }$可用于计算$q$，这意味着定理2的上界也适用于含自连接的查询。

Proposition 3. For any conjunctive query $q$ ,its associated self-join-free query ${q}^{\prime }$ is at least as hard as $q$ for the evaluation problem, the testing problem, and the enumeration problem.

命题3. 对于任何合取查询$q$，其关联的无自连接查询${q}^{\prime }$在评估问题、测试问题和枚举问题上的难度至少与$q$相当。

When trying to show the other direction, reducing the self-join-free query to its initial query with self-joins, we need more care. Let us now explain why the lower bounds of Theorem 2 only apply to self-join-free queries.

当尝试证明反方向——将无自连接查询归约到初始的自连接查询时，我们需要更加谨慎。现在让我们解释为什么定理2的下界仅适用于无自连接查询。

Example 4. Consider the self-join-free variant ${q}_{1}^{\prime }$ of ${q}_{1}$ from Figure 1: ${R}_{1}\left( {{x}_{1},{x}_{2}}\right)  \land  {R}_{2}\left( {{x}_{2},{x}_{3}}\right)  \land  {R}_{3}\left( {{x}_{1},{x}_{4}}\right)  \land  {R}_{4}\left( {{x}_{4},{x}_{3}}\right)$ . Theorem 2 proves that the ability to determine whether ${q}_{1}^{\prime }$ has answers in linear time would imply finding triangles in an undirected graph in linear time, which is conjectured to be impossible. The reduction works as follows: for every edge(a,b)of the input graph with $a < b,{}^{2}$ we add to the database the facts: ${R}_{1}\left( {a,b}\right) ,{R}_{2}\left( {a,b}\right) ,{R}_{3}\left( {a,b}\right)$ ,and ${R}_{4}\left( {b,b}\right)$ . With this construction,every answer to ${q}_{1}^{\prime }$ is of the form(a,b,c,c) such that(a,b,c)is a triangle. If we try to use the same technique to prove the hardness of ${q}_{1}$ ,we encounter the problem that we cannot assign different atoms with different relations. In particular, if we add to the database the facts $R\left( {a,b}\right)$ and $R\left( {b,b}\right)$ for every edge(a,b) of the graph,the query ${q}_{1}$ will also have solutions corresponding to 2-paths (where every atom maps to the edge relation and ${x}_{2}$ and ${x}_{4}$ map to the same value). Thus,we do not get that the query has a solution iff the graph has a triangle.

示例4. 考虑图1中${q}_{1}$的无自连接变体${q}_{1}^{\prime }$：${R}_{1}\left( {{x}_{1},{x}_{2}}\right)  \land  {R}_{2}\left( {{x}_{2},{x}_{3}}\right)  \land  {R}_{3}\left( {{x}_{1},{x}_{4}}\right)  \land  {R}_{4}\left( {{x}_{4},{x}_{3}}\right)$。定理2证明，若能在线性时间内判定${q}_{1}^{\prime }$是否有解，则意味着能在线性时间内发现无向图中的三角形，这被学界推测为不可能实现。归约过程如下：对于输入图中每条边(a,b)及$a < b,{}^{2}$，我们向数据库添加事实：${R}_{1}\left( {a,b}\right) ,{R}_{2}\left( {a,b}\right) ,{R}_{3}\left( {a,b}\right)$和${R}_{4}\left( {b,b}\right)$。通过这种构造，${q}_{1}^{\prime }$的每个解都形如(a,b,c,c)，其中(a,b,c)构成三角形。若尝试用相同技术证明${q}_{1}$的难解性，会遇到无法为不同原子分配不同关系的问题。具体而言，若为图中每条边(a,b)添加事实$R\left( {a,b}\right)$和$R\left( {b,b}\right)$，查询${q}_{1}$将出现对应2-路径的解（所有原子映射到边关系且${x}_{2}$与${x}_{4}$映射相同值）。因此，仅当图中存在三角形时查询才有解的结论不再成立。

To prove the hard cases, we need a technique that allows us to assign different relations to different atoms despite the self-joins. For this reason, we will use variations of the tagging technique described below that aims to assign different variables with different domains by concatenating the variable names to the domain values.

为证明困难情形，我们需要一种能在自连接存在时为不同原子分配不同关系的技术。为此，将采用下述标记技术的变体——通过将变量名与域值拼接，实现为不同变量分配不同域。

Tagging technique. ${}^{3}$ Let $q$ be a minimal conjunctive query and ${q}^{\prime }$ be its associated self-join-free query. Let ${D}^{\prime }$ be a database for ${q}^{\prime }$ . We construct a database $D$ for $q$ as follows. Let ${R}_{1}\left( \bar{x}\right)$ be an atom of ${q}^{\prime }$ associated to the atom $R\left( \bar{x}\right)$ of $q$ ,where $R$ is of arity $l$ . For every fact ${R}_{1}\left( \bar{a}\right)$ of ${D}^{\prime }$ ,we add to $D$ the fact $R\left( {\left\langle  {{a}_{1},{x}_{1}}\right\rangle  ,\ldots ,\left\langle  {{a}_{l},{x}_{l}}\right\rangle  }\right)$ .

标记技术。${}^{3}$设$q$为极小合取查询，${q}^{\prime }$为其对应的无自连接查询。给定${q}^{\prime }$的数据库${D}^{\prime }$，按如下方式构建$q$的数据库$D$：对于$q$中原子$R\left( \bar{x}\right)$关联的${q}^{\prime }$原子${R}_{1}\left( \bar{x}\right)$（其元数为$l$），将${D}^{\prime }$中每个事实${R}_{1}\left( \bar{a}\right)$转换为$D$中的事实$R\left( {\left\langle  {{a}_{1},{x}_{1}}\right\rangle  ,\ldots ,\left\langle  {{a}_{l},{x}_{l}}\right\rangle  }\right)$。

With this construction,every element of the domain of $D$ is of the form $\langle a,x\rangle$ . We refer to $a$ as the data part and to $x$ as the tag. Let us now inspect $q\left( D\right)$ . Every solution $\left( {\left\langle  {{a}_{1},{y}_{1}}\right\rangle  ,\ldots ,\left\langle  {{a}_{k},{y}_{k}}\right\rangle  }\right)$ in $q\left( D\right)$ is witnessed by an assignment $\mu$ associating an element of $D$ to every variable of $q$ . As above, $\mu$ can be split into two parts: a data map associating ${a}_{i}$ to ${x}_{i}$ whenever $\mu \left( {x}_{i}\right)  = \left\langle  {{a}_{i},{y}_{i}}\right\rangle$ and a tagging map associating ${y}_{i}$ to ${x}_{i}$ in the same cases. The data part of the solution of $\mu$ is $\left( {{a}_{1},\cdots ,{a}_{k}}\right)$ . Notice that every solution to ${q}^{\prime }\left( {D}^{\prime }\right)$ appears as a data part of a solution of $q\left( D\right)$ with an identity tagging map. For the converse direction,consider a solution of $q\left( D\right)$ . There are two cases.

通过这种构造，$D$定义域的每个元素都具有$\langle a,x\rangle$的形式。我们将$a$称为数据部分，$x$称为标签。现在考察$q\left( D\right)$：其中每个解$\left( {\left\langle  {{a}_{1},{y}_{1}}\right\rangle  ,\ldots ,\left\langle  {{a}_{k},{y}_{k}}\right\rangle  }\right)$都由一个赋值$\mu$所见证，该赋值将$D$的元素关联到$q$的每个变量。如前所述，$\mu$可拆分为两部分：当$\mu \left( {x}_{i}\right)  = \left\langle  {{a}_{i},{y}_{i}}\right\rangle$时将${a}_{i}$关联到${x}_{i}$的数据映射，以及相同情况下将${y}_{i}$关联到${x}_{i}$的标签映射。解$\mu$的数据部分是$\left( {{a}_{1},\cdots ,{a}_{k}}\right)$。注意${q}^{\prime }\left( {D}^{\prime }\right)$的每个解都表现为$q\left( D\right)$某个解的数据部分（其标签映射为恒等映射）。对于反向情况，考虑$q\left( D\right)$的解时存在两种情形。

(1) If the tagging map $v$ is an automorphism,then the data map contains a solution of ${q}^{\prime }\left( {D}^{\prime }\right)$ as follows. Consider the mapping ${\mu }^{\prime }$ defined by ${\mu }^{\prime }\left( x\right)  = \mu \left( {{v}^{-1}\left( x\right) }\right)$ . It clearly witnesses a solution of $q\left( D\right)$ with an identity tagging map whose data part then belongs to ${q}^{\prime }\left( {D}^{\prime }\right)$ .

(1) 若标签映射$v$是自同构，则数据映射包含${q}^{\prime }\left( {D}^{\prime }\right)$的解如下：由${\mu }^{\prime }\left( x\right)  = \mu \left( {{v}^{-1}\left( x\right) }\right)$定义的映射${\mu }^{\prime }$显然见证了$q\left( D\right)$的一个解（其标签映射为恒等映射），因此该解的数据部分属于${q}^{\prime }\left( {D}^{\prime }\right)$。

(2) If the tagging map is not an automorphism, the data part of the solution may then not correspond to a solution in ${q}^{\prime }\left( {D}^{\prime }\right)$ .

(2) 若标签映射非自同构，则解的数据部分可能不对应${q}^{\prime }\left( {D}^{\prime }\right)$中的解。

If $q$ is minimal and the tagging map $v$ is the identity on the free variables,then $v$ must be an automorphism. Thus,when using the tagging technique, solutions with the identity tagging map are the ones we wish to return in order to answer ${q}^{\prime }$ ,and we need to ensure that there are not too many interfering solutions of the other cases. We will see that if the query is of low arity, then the number of extra solutions remains small, and so they can be ignored without incurring a high cost. For full queries, other solutions of the first case are not a problem: As we are given the assignment to all variables as part of a solution,we can compute ${\mu }^{\prime }$ and an answer to ${q}^{\prime }$ given any such solution to $q$ . Every solution to ${q}^{\prime }$ will be obtained a constant number of times this way, once for each automorphism, and these duplicates can be eliminated using the Cheater's Lemma. Solutions of the second case are the ones we need to beware of. For this technique to result in a useful reduction, we need to limit the number of these extra solutions, and this cannot always be achieved. We summarize the discussion above into the following lemma.

当$q$极小且标签映射$v$在自由变量上为恒等映射时，$v$必为自同构。因此采用标签技术时，我们希望返回具有恒等标签映射的解来回答${q}^{\prime }$，并需确保其他情形的干扰解不会过多。对于低元数查询，额外解的数量将保持较少，故可忽略不计；对于完整查询，第一种情形的其他解不构成问题——由于解中已包含对所有变量的赋值，我们可以计算${\mu }^{\prime }$并根据$q$的任意此类解给出${q}^{\prime }$的答案。每个${q}^{\prime }$的解将通过这种方式被获取常数次（每次对应一个自同构），利用Cheater引理可消除这些重复解。真正需要警惕的是第二种情形的解。要使该技术实现有效归约，必须限制这些额外解的数量，但这并非总能实现。我们将上述讨论总结为如下引理。

LEMMA 5. Let ${q}^{\prime }$ be the self-join-free query associated with a minimal conjunctive query $q$ ,and let $D$ be the database for $q$ constructed using the tagging technique from a database ${D}^{\prime }$ for ${q}^{\prime }$ . Then, ${q}^{\prime }\left( {D}^{\prime }\right)$ is precisely the data parts of those solutions to $q\left( D\right)$ in which every free variable is assigned itself as a tag. Moreover, if $q$ is full,then each solution to $q\left( D\right)$ tagged by an automorphism can be translated in constant time to a solution of ${q}^{\prime }\left( {D}^{\prime }\right)$ such that each solution of ${q}^{\prime }\left( {D}^{\prime }\right)$ is obtained a constant number of times.

引理5. 设${q}^{\prime }$为与极小合取查询$q$关联的无自连接查询，且$D$是通过标记技术从${q}^{\prime }$的数据库${D}^{\prime }$构建的$q$的数据库。那么，${q}^{\prime }\left( {D}^{\prime }\right)$恰好是那些$q\left( D\right)$解中数据部分，其中每个自由变量都被分配其自身作为标记。此外，若$q$是满的，则每个由自同构标记的$q\left( D\right)$解可在常数时间内转换为${q}^{\prime }\left( {D}^{\prime }\right)$的一个解，且${q}^{\prime }\left( {D}^{\prime }\right)$的每个解均被获取常数次。

The following is an example of the tagging technique and how it can fail to prove hardness due to extra solutions. Later in the paper, we will see how this difficulty can be circumvented in some cases so that the tagging technique works.

以下是标记技术的一个示例，以及由于额外解导致无法证明硬度的情形。后文将展示在某些情况下如何规避这一困难，使标记技术得以奏效。

Example 6. Consider ${q}_{1}^{\prime }$ and ${q}_{1}$ from Example 4. Notice that ${q}_{1}$ has two automorphisms: the identity and the one that switches ${x}_{2}$ and ${x}_{4}$ . ## 4 QUERIES OF LOW ARITY

## 4 低元数查询

We use the tagging from the previous section to show that self-joins do not affect the tractable cases for constant delay enumeration of conjunctive queries with few free variables.

我们利用上一节的标记技术证明：对于自由变量较少的合取查询，自连接不会影响恒定延迟枚举的可处理情形。

For Boolean and unary queries, the number of solutions is at most linear in the database size. If we could compute the entire solution set in linear time then constant delay enumeration easily follows. This situation is characterized by the following result.

对于布尔查询和一元查询，解的数量最多与数据库大小呈线性关系。若能在线性时间内计算出全部解集，则常数延迟枚举自然成立。这一情形由以下结果所刻画。

## 5 QUERIES WITH A CYCLIC CORE

## 5 含循环核心的查询

Given a conjunctive query $q$ with free variables $\bar{x}$ ,let $p$ be the minimal form of the Boolean query $\exists \bar{x}q$ . We denote by the core of $q$ the query constructed from $p$ by removing all quantifications. Notice that the core of $q$ is a full query that may not be equivalent to $q$ . Notice also that an acyclic query has an acyclic core but the converse is not necessarily true: the core of the cyclic query ${q}_{1}$ of Figure 1 is acyclic. Observe that a query has a solution iff its core has a solution. Hence the following result is an immediate consequence of Theorem 7.

给定一个包含自由变量$\bar{x}$的合取查询$q$，令$p$表示布尔查询$\exists \bar{x}q$的最小化形式。我们将$q$的核心定义为通过移除所有量词从$p$构造出的查询。注意：$q$的核心是一个完全查询，但可能不等价于原查询；同时，无环查询必有无环核心，但逆命题不成立——图1中循环查询${q}_{1}$的核心就是无环的。观察到当且仅当其核心有解时，原查询才有解。因此以下结论可直接由定理7推出。

THEOREM 9. It is possible to test in linear time whether a conjunctive query has a solution iff it has an acyclic core, assuming SHYPERCLIQUE.

定理9. 在SHYPERCLIQUE假设下，当且仅当合取查询具有无环核心时，才可能在线性时间内判定该查询是否有解。

Example 10. Consider the full conjunctive query ${q}_{3}$ depicted by Figure 1. The core of the query is the query itself and is therefore cyclic. It follows from Theorem 9 that the query is hard, i.e., we cannot test whether it has a solution in linear time.

示例10. 考虑图1描述的完全合取查询${q}_{3}$。该查询的核心即其自身，因此是循环的。根据定理9可知这是困难查询——我们无法在线性时间内判定其解的存在性。

## 6 FULL CONJUNCTIVE QUERIES AND LINEAR DELAY

## 6 完全合取查询与线性延迟

Assuming sHYPERCLIQUE, acyclic self-join-free queries can be enumerated with linear delay (after linear preprocessing) while cyclic self-join-free queries cannot. We now ask how self-joins affect this classification. Following Proposition 3 and Theorem 9, it remains to handle cyclic queries with an acyclic core. In this section, we begin this investigation by considering only full queries of this form. We start with a simple example showing that some cyclic queries with self-joins can be enumerated with linear delay.

在sHYPERCLIQUE假设下，无环无自连接查询可在线性预处理后实现线性延迟枚举，而循环无自连接查询则不能。现在探讨自连接如何影响该分类。根据命题3和定理9，尚需处理具有无环核心的循环查询。本节我们首先仅研究这类完全查询，并通过简单示例说明某些带自连接的循环查询可实现线性延迟枚举。

Example 11. Consider the full query ${q}_{2}$ of Figure 1. It can be enumerated with linear delay as follows. We enumerate the solutions of the core of ${q}_{2}$ ,depicted by $1 \rightarrow  2 \rightarrow  3$ . As the core is acyclic and free-connex, by Theorem 2, this can be done with constant delay after linear preprocessing. For each solution(a,b,c)of the core,we try all elements $d$ of the database and test,in constant time,whether $d$ is connected to $a$ and $c$ as specified by ${q}_{2}$ . If it is, we output the solution(a,b,c,d). Remark that any solution(a,b,c) to the core gives rise to a solution(a,b,c,b)to ${q}_{2}$ . Thus,at least one solution to ${q}_{2}$ is printed for each solution to the core,and so the delay is at most linear.

示例11. 考虑图1的完全查询${q}_{2}$。其枚举过程如下：首先枚举由$1 \rightarrow  2 \rightarrow  3$表示的核心解。由于该核心是无环且自由连接的，根据定理2可在线性预处理后实现常数延迟枚举。对每个核心解(a,b,c)，我们测试数据库中所有元素$d$是否如${q}_{2}$所定义与$a$、$c$相连（常数时间完成）。若满足则输出解(a,b,c,d)。值得注意的是，每个核心解(a,b,c)都对应原查询的解(a,b,c,b)，因此核心的每个解至少产生原查询的一个解，从而保证延迟至多为线性。

### 6.1 Sufficient condition

### 6.1 充分条件

We now present a sufficient condition for enumeration with linear delay that builds on two key concepts: image and untangling. Consider an endomorphism $v$ of a full query $q$ . The restriction of a conjunctive query $q$ to a set of its variables $S$ ,denoted ${\left. q\right| }_{S}$ ,is the query obtained from the self-join-free query associated to $q$ by removing all variables not in $S$ from its atoms. Notice that the arities of the relations may change. An untangling of $q$ is a sequence of images ${I}_{0},\ldots ,{I}_{k}$ of $q$ such that: ${I}_{0} = q,{I}_{k}$ is acyclic,and for all $0 \leq  i < k : {I}_{i + 1}$ is an image of ${I}_{i}$ and the restriction of ${I}_{i}$ to its variables that do not appear in ${I}_{i + 1}$ is acyclic.

将合取查询$q$限制在其变量子集$S$上的操作记作${\left. q\right| }_{S}$，该查询是通过从$q$对应的无自连接查询中移除所有不属于$S$的原子变量而获得。需注意此时关系的元数可能发生变化。$q$的解缠是指满足以下条件的查询映像序列${I}_{0},\ldots ,{I}_{k}$：${I}_{0} = q,{I}_{k}$是非循环查询，且对于所有$0 \leq  i < k : {I}_{i + 1}$，${I}_{i}$是$q$的映像，同时将${I}_{i}$限制于不出现在${I}_{i + 1}$中的变量后仍保持非循环性。

定理13. 任何具有解缠的完全合取查询均可实现线性延迟枚举（经线性预处理后）。

Proof SKETCH. Let ${I}_{0},{I}_{1},\cdots ,{I}_{k}$ be an untangling of $q$ . The proof goes by induction on $k$ . If $k = 0$ ,then the query is acyclic and can be enumerated with linear delay by Theorem 2 . If $k > 0$ ,consider the image ${I}_{1}$ . Let ${q}^{\prime }$ be the restriction of $q$ to its variables not in ${I}_{1}$ . By construction, ${q}^{\prime }$ is acyclic and can be enumerated with linear delay. By induction, ${I}_{1}$ can be enumerated with linear delay. We show that $q$ can then be enumerated with linear delay as well.

证明概要. 设${I}_{0},{I}_{1},\cdots ,{I}_{k}$是$q$的解缠序列。采用归纳法对$k$进行证明：若$k = 0$，则该查询为非循环查询，根据定理2可实现线性延迟枚举；若$k > 0$，考虑映像${I}_{1}$。令${q}^{\prime }$表示将$q$限制于${I}_{1}$未包含变量的结果，由构造可知${q}^{\prime }$为非循环查询且可线性延迟枚举。根据归纳假设，${I}_{1}$可线性延迟枚举，由此可证$q$同样具备线性延迟枚举性。

On an input database $D$ ,the enumeration of $q$ works as follows. We start the enumeration for ${I}_{1}$ . For each solution $\bar{a}$ to ${I}_{1}$ ,as witnessed by a mapping $\mu$ from the variables of ${I}_{1}$ to the elements of $D$ ,we compute in linear time a database ${D}^{\prime }$ over the schema of ${q}^{\prime }$ as follows. By definition,each atom ${R}^{\prime }\left( \bar{x}\right)$ of ${q}^{\prime }$ is computed from an atom $R\left( \bar{y}\right)$ of $q$ by removing all variables in ${I}_{1}$ . We filter $R\left( \overrightarrow{y}\right)$ to only keep the tuples that "agree" with $\overrightarrow{a}$ ,and then we project the result to only keep the columns corresponding to $\overrightarrow{x}$ . More formally, let $\overrightarrow{u}$ be the variables of $\bar{y}$ occurring in ${I}_{1}$ and $\overrightarrow{v}$ those not occurring in ${I}_{1}$ . Then, ${R}^{\prime }\left( {D}^{\prime }\right)$ consists of all the tuples $v\left( \overrightarrow{v}\right)$ such that $v$ is a mapping from $\bar{y}$ to a tuple of $R$ with $\mu \left( \overrightarrow{u}\right)  = v\left( \overrightarrow{u}\right)$ .

在输入数据库$D$上，$q$的枚举过程如下。我们首先为${I}_{1}$启动枚举。对于每个由映射$\mu$（将${I}_{1}$的变量映射到$D$的元素）所验证的${I}_{1}$解$\bar{a}$，我们以线性时间计算模式${q}^{\prime }$上的数据库${D}^{\prime }$。根据定义，${q}^{\prime }$的每个原子${R}^{\prime }\left( \bar{x}\right)$是通过从$q$的原子$R\left( \bar{y}\right)$中移除${I}_{1}$的所有变量而得到。我们筛选$R\left( \overrightarrow{y}\right)$仅保留与$\overrightarrow{a}$"相符"的元组，然后投影结果仅保留对应$\overrightarrow{x}$的列。更形式化地说，设$\overrightarrow{u}$为$\bar{y}$中出现在${I}_{1}$的变量，$\overrightarrow{v}$为未出现的变量。那么${R}^{\prime }\left( {D}^{\prime }\right)$包含所有满足$v$是从$\bar{y}$到$R$元组的映射且具有$\mu \left( \overrightarrow{u}\right)  = v\left( \overrightarrow{u}\right)$性质的元组$v\left( \overrightarrow{v}\right)$。

We then start the enumeration for ${q}^{\prime }$ on ${D}^{\prime }$ . Every solution to ${q}^{\prime }$ can be combined with $\bar{a}$ to form a solution to $q$ ,and the algorithm outputs all solutions with no repetitions. Since ${I}_{1}$ is an image,each $\bar{a}$ yields at least one solution to ${q}^{\prime }$ ,and we get linear delay.

接着我们在${D}^{\prime }$上为${q}^{\prime }$启动枚举。每个${q}^{\prime }$的解都能与$\bar{a}$组合形成$q$的解，算法输出所有无重复的解。由于${I}_{1}$是映像，每个$\bar{a}$至少产生一个${q}^{\prime }$的解，从而获得线性延迟。

### 6.2 Necessary condition

### 6.2 必要条件

We provide a condition identifying full queries that cannot be enumerated with linear delay, assuming sHYPERCLIQUE. We essentially reduce sHYPERCLIQUE to the computation of a constant number of solutions to the query in linear time. The construction is illustrated in the next example.

我们提出一个条件，用于识别在sHYPERCLIQUE假设下无法以线性延迟枚举的完整查询。本质上，我们将sHYPERCLIQUE问题归约为在线性时间内计算查询的常数数量解。该构建方法将在下例中说明。

Theorem 15 builds upon the idea outlined in Example 14, and provides a necessary condition for linear delay tractability. 定理15. 设$q$为完全合取查询。若$q$包含变量集$S$使得限制${\left. q\right| }_{S}$是循环的，且其所有自同态都是幂等的、且像集要么包含$S$中所有变量要么不包含任何变量，则在SHYPERCLIQUE假设下，$q$无法以线性延迟（及线性预处理）进行枚举。

Proof sketch. We show that the enumeration for $q$ is at least as hard as the enumeration for ${\left. q\right| }_{S}$ ,using a construction that assigns the constant $\bot$ to the extra variables and a case analysis according to the endomorphism producing each answer. The idempotency and the fact that each image that contains a variable of $S$ contains all variables of $S$ guarantee that each answer that contains a nonconstant value corresponds to an answer to ${\left. q\right| }_{S}$ .

证明概要。我们通过构造将常量$\bot$赋给额外变量，并依据产生每个答案的同态进行案例分析，证明$q$的枚举问题至少与${\left. q\right| }_{S}$的枚举问题同等困难。幂等性以及每个包含$S$变量的映像必然包含$S$所有变量的特性，保证了每个含非常量值的答案都对应着${\left. q\right| }_{S}$的一个解。

## 7 FULL CONJUNCTIVE QUERIES AND CONSTANT DELAY

## 7 完全合取查询与恒定延迟

In this section, we aim to distinguish the queries that can be enumerated with constant delay after a linear time preprocessing from those where this is not possible. As in the previous section, all our queries will be full cyclic queries with an acyclic core.

本节旨在区分哪些查询可通过线性时间预处理后实现恒定延迟枚举，哪些则无法实现。如前所述，所有查询均为具有无环核心的完全循环查询。

### 7.1 Mirror queries

### 7.1 镜像查询

We start by showing that some cyclic queries can be solved with constant delay following linear preprocessing due to self-joins. This happens when half of the query can be seen as a reflection of the other half, as demonstrated in the following example.

我们首先证明：由于自连接特性，部分循环查询经线性预处理后可实现恒定延迟求解。当查询的一半可视为另一半的镜像时即属此情况，如下例所示。

Example 19. The cyclic query ${q}_{1}$ of Figure 1 can be enumerated with constant delay as we describe next. First notice that the core $p$ of ${q}_{1}$ ,depicted by $1 \rightarrow  2 \rightarrow  3$ ,is acyclic and free-connex,and so by Theorem 2, $p$ can be enumerated with constant delay after linear preprocessing time. We will maintain a table, initialized as empty,that on entry a pair(a,b)returns a list of elements $c$ such that(a,c,b)is a solution to $p$ . The enumeration of ${q}_{1}$ works as follows. We perform the preprocessing necessary for $p$ ,start its enumeration,and for every solution(a,c,b)we do the following. First,we output the solution(a,c,b,c). Then,for every ${c}^{\prime }$ that is given by the table for the entry(a,b),we output the solutions $\left( {a,c,b,{c}^{\prime }}\right)$ and $\left( {a,{c}^{\prime },b,c}\right)$ . Finally,we add $c$ to the table entry(a,b). We get that the delay is constant, and every result is printed once.

示例19. 图1中的循环查询${q}_{1}$可按以下方式实现恒定延迟枚举。首先注意${q}_{1}$的核心$p$（由$1 \rightarrow  2 \rightarrow  3$描绘）是无环且自由连通的，根据定理2，$p$经线性预处理后可实现恒定延迟枚举。我们将维护一个初始为空的表，该表在输入(a,b)时返回元素列表$c$使得(a,c,b)是$p$的解。${q}_{1}$的枚举流程如下：先对$p$进行必要预处理并启动枚举，对每个解(a,c,b)执行：1)输出解(a,c,b,c)；2)对表中(a,b)条目提供的每个${c}^{\prime }$，输出解$\left( {a,c,b,{c}^{\prime }}\right)$和$\left( {a,{c}^{\prime },b,c}\right)$；3)将$c$添加至表条目(a,b)。由此实现恒定延迟且每个解仅输出一次。

Example 19 puts forward the following sufficient condition. We call a query a mirror if it has an acyclic image $I$ such that the remaining atoms form a query isomorphic to $I$ ,where the isomorphism is the identity on the variables shared between the image and the remaining atoms.

示例19提出了以下充分条件：若查询存在无环映像$I$，且剩余原子组成与$I$同构的查询（其中同构映射在映像与剩余原子共享变量上为恒等映射），则称该查询为镜像查询。

Proposition 20. Any full mirror conjunctive query can be enumerated with constant delay after a linear preprocessing time.

命题20. 任何完全镜像连接查询经线性时间预处理后均可实现恒定延迟枚举。

As in Example 19, in the proof of Proposition 20 we use during the enumeration a memory linear in the output size (which may not be linear in the input size).

如示例19所示，命题20的证明在枚举过程中使用了与输出规模线性相关的内存（该内存量可能与输入规模非线性相关）。

### 7.2 The effect of unary atoms

### 7.2 一元原子的影响

In contrast to the self-join-free case, we show that unary atoms can affect query complexity. Intuitively, when adding a unary atom to one of the sides of a mirror query, the solutions to this side no longer form all possible solutions to the other side, and so the algorithm we proposed for mirror queries fails. The following example differs from the previous one only by the addition of a unary atom.

与无自连接的情况不同，我们证明一元原子会影响查询复杂度。直观而言，当在镜像查询的某侧添加一元原子时，该侧的解不再构成另一侧的所有可能解，导致镜像查询算法失效。下例与前例仅相差一个一元原子的添加。

Example 21. Consider again the query ${q}_{2}$ depicted in Figure 1. We have seen in Example 11 that it can be enumerated with linear delay. It turns out that it cannot be enumerated with linear preprocessing and constant delay unless we can test in linear time whether a graph contains a triangle, contradicting sHYPERCLIQUE. Given a graph $G$ with $m$ edges,we construct a database $D$ as follows. For every edge(a,b)of $G$ with $a < b$ ,we add to $D$ the facts $R\left( {\left\langle  {a,{x}_{1}}\right\rangle  ,\left\langle  {b,{x}_{2}}\right\rangle  }\right)$ , $R\left( {\left\langle  {b,{x}_{2}}\right\rangle  ,\left\langle  {b,{x}_{3}}\right\rangle  }\right) ,R\left( {\left\langle  {a,{x}_{1}}\right\rangle  ,\left\langle  {b,{x}_{4}}\right\rangle  }\right)$ ,and $R\left( {\left\langle  {b,{x}_{4}}\right\rangle  ,\left\langle  {a,{x}_{3}}\right\rangle  }\right)$ ,together with the fact $\operatorname{Red}\left( \left\langle  {b,{x}_{2}}\right\rangle  \right)$ . By considering all endomorphisms of ${q}_{2}$ , as we explained when introducing the tagging technique, we get that a solution in $q\left( D\right)$ is either obtained by the identity automorphism and so it is of the form $\left( {\left\langle  {a,{x}_{1}}\right\rangle  ,\left\langle  {b,{x}_{2}}\right\rangle  ,\left\langle  {b,{x}_{3}}\right\rangle  ,\left\langle  {c,{x}_{4}}\right\rangle  }\right)$ for a triangle(a,b,c)in $G$ ,or it is obtained by the endomorphism that maps ${x}_{4}$ to ${x}_{2}$ and so it is of the form $\left( {\left\langle  {a,{x}_{1}}\right\rangle  ,\left\langle  {b,{x}_{2}}\right\rangle  ,\left\langle  {b,{x}_{3}}\right\rangle  ,\left\langle  {b,{x}_{2}}\right\rangle  }\right)$ for an edge(a,b)in $G$ . As there are at most $m$ solutions of the latter kind,any constant delay enumeration of $q$ in $D$ would be able to test in $O\left( m\right)$ whether $G$ has a triangle.

示例21. 再次考虑图1所示的查询${q}_{2}$。在示例11中我们已经看到，该查询可通过线性延迟枚举。但事实上，除非能在线性时间内检测图形是否包含三角形（这与sHYPERCLIQUE假设矛盾），否则无法在线性预处理和恒定延迟条件下完成枚举。给定具有$m$条边的图$G$，我们按如下方式构建数据库$D$：对于$G$中每条边(a,b)及其$a < b$，我们向$D$添加事实$R\left( {\left\langle  {a,{x}_{1}}\right\rangle  ,\left\langle  {b,{x}_{2}}\right\rangle  }\right)$、$R\left( {\left\langle  {b,{x}_{2}}\right\rangle  ,\left\langle  {b,{x}_{3}}\right\rangle  }\right) ,R\left( {\left\langle  {a,{x}_{1}}\right\rangle  ,\left\langle  {b,{x}_{4}}\right\rangle  }\right)$、$R\left( {\left\langle  {b,{x}_{4}}\right\rangle  ,\left\langle  {a,{x}_{3}}\right\rangle  }\right)$以及$\operatorname{Red}\left( \left\langle  {b,{x}_{2}}\right\rangle  \right)$。通过考虑${q}_{2}$的所有自同态（如引入标记技术时所解释），我们得出$q\left( D\right)$中的解要么通过恒等自同构获得（即呈现为$G$中三角形(a,b,c)的$\left( {\left\langle  {a,{x}_{1}}\right\rangle  ,\left\langle  {b,{x}_{2}}\right\rangle  ,\left\langle  {b,{x}_{3}}\right\rangle  ,\left\langle  {c,{x}_{4}}\right\rangle  }\right)$形式），要么通过将${x}_{4}$映射到${x}_{2}$的自同态获得（即呈现为$G$中边(a,b)的$\left( {\left\langle  {a,{x}_{1}}\right\rangle  ,\left\langle  {b,{x}_{2}}\right\rangle  ,\left\langle  {b,{x}_{3}}\right\rangle  ,\left\langle  {b,{x}_{2}}\right\rangle  }\right)$形式）。由于后者类型的解最多有$m$个，任何$D$中对$q$的恒定延迟枚举都能在$O\left( m\right)$时间内检测$G$是否包含三角形。

This added difficulty is caused by any structure that breaks the symmetry between the two sides. As an example, we could replace the unary atom in ${q}_{2}$ by a directed path of length 2 starting in ${x}_{2}$ and still obtain the hardness with a similar proof.

这种额外复杂性源于破坏两侧对称性的任何结构。例如，我们可以将${q}_{2}$中的一元原子替换为从${x}_{2}$出发的长度为2的有向路径，并通过类似证明依然获得硬度结果。

Example 22. Consider ${q}_{11}$ and its images of Figure 7. The top and left images can be enumerated with linear preprocessing and constant delay as they are acyclic and free-connex. Example 23. The query ${q}_{12}$ can be enumerated with constant delay using its images depicted in Figure 8. ## 8 CONCLUSION

## 8 结论

We have initiated the study of the fine-grained complexity of conjunctive queries with self-joins. We have seen that queries with low arity can be enumerated with constant delay iff their associated self-join-free query can. We do not know whether this property remains true with linear delay enumeration. There are several ways in which the complexity analysis is more complicated for queries with self-joins. In particular, the complexity may change with the reordering of variables inside an atom, with the addition of unary atoms, or with the addition of binary atoms where only one of their variables appears in the rest of the query (called "spikes" above). Despite showing several ways in which self-joins can be used in algorithms for queries that are otherwise hard, as well as showing ways to prove the hardness of queries with self-joins, determining the complexity of some queries (see Example 18 and Section 7.4) is left open. Most of our results concern full conjunctive queries and going beyond this would require significant additional work.

我们开创性地研究了含自连接合查询的细粒度复杂度。发现低元数查询当且仅当其关联的无自连接查询可实现常数延迟枚举时，自身才能实现。尚不清楚该性质在线性延迟枚举中是否成立。自连接使复杂度分析更加复杂，具体表现在：原子内部变量重排、一元原子添加、或添加仅含一个变量出现在查询其余部分的二元原子（前称"尖峰"）都可能改变复杂度。尽管我们展示了自连接在算法中的多种应用场景及证明其硬度的途径，但部分查询（见示例18和7.4节）的复杂度判定仍悬而未决。本研究主要针对完全合查询，进一步拓展需要大量后续工作。

Let us now discuss the time complexity. Each time we enumerate something in our algorithm, it is acyclic and can be done with linear preprocessing and constant delay. The "danger" is that we need to go over all pairs of a value in ${T}_{6}\left( d\right)$ and a value in ${T}_{7}\left( e\right)$ and check whether they share an edge. In the worst case, if this check always fails, we can get a step of quadratic delay, which is a problem if we want linear preprocessing and constant delay. However, we will show later that the number of such pairs is bounded by the number of solutions we print before these checks,using the top and left images. Overall,we get that,for all $n$ ,the time from the beginning of the execution until printing the $n$ th solution is linear in the input size plus $n$ . A general version of the Cheater’s Lemma [5,Lemma 7] relies on this to deduce that our algorithm can be tweaked into working with linear preprocessing and constant delay with no duplicates, by withholding some of the solutions before printing them.
