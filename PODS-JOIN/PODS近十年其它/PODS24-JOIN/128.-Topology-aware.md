## Topology-aware Parallel Joins*

## 拓扑感知并行连接算法*

XIAO HU, University of Waterloo, Canada

胡晓，加拿大滑铁卢大学

PARASCHOS KOUTRIS, University of Wisconsin-Madison, USA

帕拉肖斯·库特里斯，美国威斯康星大学麦迪逊分校

We study the design and analysis of parallel join algorithms in a topology-aware computational model. In this model, the network is modeled as a directed graph, where each edge is associated with a cost function that depends on the data transferred between the two endpoints and the link bandwidth. The computation proceeds in synchronous rounds and the cost of each round is measured as the maximum cost over all the edges in the network. Our main result is an asymptotically optimal join algorithm over symmetric tree topologies. The algorithm generalizes prior topology-aware protocols for set intersection and cartesian product to a binary join over an arbitrary input distribution with possible data skew.

我们在拓扑感知计算模型中研究并行连接算法的设计与分析。该模型将网络建模为有向图，其中每条边关联的成本函数取决于两个端点间传输的数据量及链路带宽。计算以同步轮次进行，每轮成本按网络中所有边的最大成本计量。我们的主要成果是在对称树拓扑上实现了渐近最优的连接算法。该算法将先前针对集合交集和笛卡尔积的拓扑感知协议，推广至任意输入分布（含可能的数据倾斜）下的二元连接操作。

## 1 INTRODUCTION

## 1 引言

Due to the rapid development of massively parallel data processing systems, such as MapRe-duce [14] and Spark [33], there has been a huge interest in the theoretical community to study algorithms $\left\lbrack  {2 - 7,{15} - {19},{21},{22},{24},{24} - {26},{32}}\right\rbrack$ in massively parallel computation models,such as BSP [31] and MPC [27] models. Algorithms in these models are based on the assumption of homogeneity: nodes have the same computational power, and links have the same bandwidth. However, practical systems are much more complicated and display heterogeneous properties. For example, computational capability varies dramatically across nodes due to their different generations of CPUs and GPUs. Network parameters (e.g., bandwidth, latency) also differ among links depending on the network architecture. To capture these critical issues in practice, Blanas et al. [10] recently proposed a heterogeneous massively parallel data processing model. In their model, the underlying communication network is a directed graph, where nodes in the network are identified as routers and compute nodes depending on their computational capabilities. In addition, network links are associated with a cost function for data transmission, which is also general enough to capture the different computational capabilities of compute nodes.

随着MapReduce[14]和Spark[33]等大规模并行数据处理系统的快速发展，理论界对BSP[31]和MPC[27]等并行计算模型中的算法研究产生了浓厚兴趣。这些模型基于同质性假设：节点具有相同的计算能力，链路具有相同的带宽。但实际系统更为复杂且呈现异构特性——例如不同代际的CPU和GPU导致节点计算能力差异显著，网络架构差异也造成链路带宽、延迟等参数不同。为捕捉这些实际问题，Blanas等人[10]近期提出了异构大规模并行数据处理模型。该模型中，底层通信网络被建模为有向图，节点根据计算能力区分为路由节点和计算节点，网络链路则关联着能同时反映数据传输成本和节点计算差异的通用成本函数。

In this model, Hu et al. [20] proved lower bounds and (almost) matching upper bounds for a few data processing tasks over symmetric tree topologies, including set intersection, Cartesian product, and sorting. It is worth mentioning that their algorithms assume that the cardinality of the initial data distributed across the nodes can be arbitrary and is known in advance as part of the parameter, while previous works assumed worst-case distribution or uniform distribution. Hence, this assumption leads to a more fine-grained notion of optimality, that is parameterized by the cardinality of the initial data distribution. This more strict notion of optimality has introduced significant challenges to algorithm design. As we discuss in Section 5, if only worst-case or uniform distribution is considered, many problems become trivial including all these three tasks as well as join to be investigated in this paper.

胡等人[20]在该模型中证明了对称树拓扑下若干数据处理任务（包括集合交集、笛卡尔积和排序）的下界及（近乎）匹配的上界。值得注意的是，其算法假设节点初始数据分布的基数可以是任意值并作为已知参数，而以往研究仅考虑最坏情况分布或均匀分布。这一假设引出了以初始数据分布基数作为参数的最优性判定标准，为算法设计带来重大挑战。如第5节所述，若仅考虑最坏情况或均匀分布，包括本文研究的连接操作在内的多项任务都将失去研究意义。

We take one further step for designing an (almost) optimal algorithm for the natural join between two relations $R\left( {A,B}\right)  \bowtie  S\left( {B,C}\right)$ . Our algorithm captures the set intersection and Cartesian product on symmetric trees as special cases. However, constructing a general join algorithm requires new techniques, ideas, and primitives.

我们进一步设计了一种（近乎）最优的关系自然连接算法$R\left( {A,B}\right)  \bowtie  S\left( {B,C}\right)$。该算法将对称树上的集合交集与笛卡尔积作为特例进行处理。然而，构建通用连接算法需要新的技术手段、创新思路和基础操作。

Indeed, one can view the set intersection as a particular case of a natural join, where tuples in one relation have distinct join keys. Applying a hashing protocol on the join keys works well, as each join key is associated with at most two tuples (one from each relation). Hence, there will be no load imbalance if the hashing works well. However, such a hash-based protocol does not work when each join key can be associated with multiple tuples. In the extreme case, the join becomes a Cartesian product (all tuples are associated with a single key), and all tuples are routed to the same node, incurring an unbounded cost. In [20], this problem was solved using a packing-based protocol that carefully load-balances each part of the Cartesian product to the compute nodes. However, it is unclear how to combine these two protocols to handle the general case with multiple keys associated with a different number of tuples, especially by targeting the fine-grained optimality with respect to the cardinality of initial data distribution.

实际上，集合交集可视为自然连接的特例——其中一个关系的元组具有唯一连接键。对连接键应用哈希协议效果良好，因为每个连接键最多关联两个元组（来自两个关系各一个）。只要哈希函数有效，就不会出现负载不均。但当单个连接键可能关联多个元组时，这种基于哈希的协议就会失效。极端情况下，连接会退化为笛卡尔积（所有元组关联到单一键），导致所有元组被路由至同一节点，产生无限成本。文献[20]通过基于打包的协议解决了该问题，该协议将笛卡尔积的每个部分精细地负载均衡到计算节点。但如何结合这两种协议来处理连接键关联不同数量元组的通用场景，特别是针对初始数据分布基数的细粒度优化目标，仍不明确。

An additional challenge is that the protocol for the Cartesian product in [20] solves only the case when two input relations have equal size. This turns out to be an essential restriction since the symmetry of the two relations (along with the symmetry in the network links) allows for a relatively simple optimal algorithm with a closed-form cost. When the symmetry breaks, no closed-form solution exists even in the simplest case of a symmetric star topology. This means we have to explore the behavior of an optimal protocol for Cartesian product, and further for join.

另一个挑战是文献[20]中的笛卡尔积协议仅适用于两个输入关系规模相等的情况。这是关键限制条件，因为两个关系的对称性（及网络链路的对称性）使得闭式成本的最优算法相对简单。当对称性打破时，即使在最简单的对称星型拓扑中也不存在闭式解。这意味着我们必须探索笛卡尔积最优协议的行为规律，进而研究通用连接协议。

As the binary join is a critical primitive of more complex analytical queries, we finally discuss two interesting implications of our topology-aware binary join algorithms - acyclic join and sparse-matrix multiplication (a basic join-aggregate query). However, this is not a simple extension, as in the homogeneous massively parallel model $\left\lbrack  {1,{21},{23}}\right\rbrack$ ,since the downstream operators bring new constraints to the initial data distribution, that would significantly affect the overall efficiency. We leave as future work how to optimally apply our topology-aware binary join algorithm to complicated analytical queries, to achieve fine-grained optimality with respect to the cardinality of initial data distribution.

由于二元连接是复杂分析查询的基础操作，我们最后讨论拓扑感知二元连接算法的两个重要应用——无环连接与稀疏矩阵乘法（基础的连接-聚合查询）。但这并非简单扩展，因为在同构大规模并行模型$\left\lbrack  {1,{21},{23}}\right\rbrack$中，下游算子会给初始数据分布带来新约束，显著影响整体效率。如何将拓扑感知二元连接算法最优地应用于复杂分析查询，以实现初始数据分布基数的细粒度优化，将作为未来研究方向。

### 1.1 Computational Model

### 1.1 计算模型

Following prior work [10],we model the network topology using a directed graph $G = \left( {V,E}\right)$ . Each directed edge $e$ in $E$ represents a network link,where the direction follows the flow of data on the link,and it is also associated with a bandwidth parameter ${w}_{e}$ . Every node in $V$ has full knowledge of the graph $G$ . We distinguish a subset of nodes in the network ${V}_{C} \subseteq  V$ ,to be compute nodes. Compute nodes are the only nodes that can store data and perform computation on their local data. The remaining nodes perform only routing decisions. More specifically,if a compute node $u \in  {V}_{C}$ aims to send some amount of data to another compute node $v \in  {V}_{C},u$ just wraps all associated data as a whole package and stamps it with the destination address $v$ as well as a routing path from $u$ to $v$ . Once a non-compute node ${u}^{\prime } \in  V - {V}_{C}$ receives a data package,it first retrieves the destination address $v$ as well as the routing path,and forwards this package to the next node on this path from ${u}^{\prime }$ to $v$ . We only need $O\left( {\log \left| V\right| }\right)$ bits to encode the destination information. Moreover,we will focus on symmetric tree topologie ${s}^{1}$ such that $G$ is a tree,where the links in $E$ are symmetric,i.e.,for two edges $e = \left( {u,v}\right)$ and ${e}^{\prime } = \left( {v,u}\right)$ ,we have ${w}_{e} = {w}_{{e}^{\prime }}$ . In this case, $G$ is a strongly connected tree where every pair of compute nodes is connected/communicated through a unique directed path. For simplicity of algorithm design and presentation,we assume that the compute nodes ${V}_{C}$ are the leaves of $G.{}^{2}$ In a tree topology,there is a unique path between every pair of compute nodes, thus our algorithm does not need to specify the routing path explicitly. We only consider strongly connected networks where every pair of compute nodes is connected through a directed path; in other words, every compute node can send data to any other compute node.

参考先前研究[10]，我们采用有向图$G = \left( {V,E}\right)$对网络拓扑进行建模。图中的每条有向边$e$代表一个网络链路，其方向与链路上的数据流向一致，且关联带宽参数${w}_{e}$。每个节点$V$都完整掌握图$G$的拓扑信息。我们特别区分网络中的计算节点子集${V}_{C} \subseteq  V$，这些节点是唯一能存储数据并对本地数据进行计算的节点，其余节点仅执行路由决策。具体而言，当计算节点$u \in  {V}_{C}$需要向另一计算节点$v \in  {V}_{C},u$发送数据时，会将所有关联数据打包成整体数据包，并标记目标地址$v$以及从$u$到$v$的路由路径。非计算节点${u}^{\prime } \in  V - {V}_{C}$接收到数据包后，首先提取目标地址$v$和路由路径，然后将该数据包转发给路径上的下一节点${u}^{\prime }$。目标地址信息仅需$O\left( {\log \left| V\right| }\right)$比特编码。我们重点研究对称树拓扑${s}^{1}$，即$G$为树状结构，其中$E$的链路具有对称性——对于两条边$e = \left( {u,v}\right)$和${e}^{\prime } = \left( {v,u}\right)$，满足${w}_{e} = {w}_{{e}^{\prime }}$。此时$G$是强连通树，任意计算节点对之间都通过唯一有向路径连接/通信。为简化算法设计与表述，我们假设计算节点${V}_{C}$是$G.{}^{2}$的叶节点。在树状拓扑中，计算节点对之间存在唯一路径，因此算法无需显式指定路由路径。我们仅考虑强连通网络，即任意计算节点对都可通过有向路径连接，换言之，每个计算节点都能向其他任意计算节点发送数据。

A parallel algorithm $\mathcal{A}$ proceeds in sequential rounds. Initially,the input data is distributed across the compute nodes ${V}_{C}$ . At every round,the compute nodes first perform computation on their local data and then communicate by sending data to other compute nodes in the network. After the algorithm finishes, every output result must be emitted by at least one compute node. We confine ourselves to the tuple-based assumption that when a join result is emitted, all participating tuples must reside on the same node. ${}^{3}$

并行算法$\mathcal{A}$按顺序轮次执行。初始时，输入数据分布在计算节点${V}_{C}$上。每轮计算中，节点先对本地数据进行运算，然后通过网络向其他计算节点发送数据通信。算法结束时，每个输出结果必须由至少一个计算节点生成。我们遵循基于元组的假设：当生成连接结果时，所有参与元组必须驻留在同一节点上。${}^{3}$

The cost of such an algorithm $\mathcal{A}$ comes from synchronization and data transmission. The synchronization cost is measured by the number of rounds,denoted as $r$ . The data transmission cost denoted as $C\left( \mathcal{A}\right)$ ,is defined as the sum of the costs over all rounds $i,C\left( \mathcal{A}\right)  = \mathop{\sum }\limits_{{i = 1}}^{r}{C}_{i}\left( \mathcal{A}\right)$ . To model the cost of each round,we first assign to each link $e$ in the network a cost function ${f}_{e} : \mathbb{N} \rightarrow  \mathbb{R}$ . The quantity ${f}_{e}\left( x\right)  = x/{w}_{e}$ is interpreted as the cost of transmitting $x$ bits through link $e$ . Let the quantity ${Y}_{i}\left( e\right)$ denote the total data (measured in bits) that is routed through link $e$ during round $i$ . Then,we can express the cost as ${C}_{i}\left( \mathcal{A}\right)  \mathrel{\text{:=}} \mathop{\max }\limits_{{e \in  E}}{f}_{e}\left( \left| {{Y}_{i}\left( e\right) }\right| \right)$ ,i.e.,the cost of each round is captured by the cost of transferring data through the most bottlenecked link in the network.

该算法的成本$\mathcal{A}$源于同步与数据传输。同步成本通过轮次数量衡量，记为$r$；数据传输成本记为$C\left( \mathcal{A}\right)$，定义为所有轮次$i,C\left( \mathcal{A}\right)  = \mathop{\sum }\limits_{{i = 1}}^{r}{C}_{i}\left( \mathcal{A}\right)$成本之和。为建模每轮成本，我们首先为网络中每条链路$e$分配成本函数${f}_{e} : \mathbb{N} \rightarrow  \mathbb{R}$。量${f}_{e}\left( x\right)  = x/{w}_{e}$表示通过链路$e$传输$x$比特数据的成本。设${Y}_{i}\left( e\right)$表示第$i$轮期间通过链路$e$路由的总数据量（以比特计），则成本可表示为${C}_{i}\left( \mathcal{A}\right)  \mathrel{\text{:=}} \mathop{\max }\limits_{{e \in  E}}{f}_{e}\left( \left| {{Y}_{i}\left( e\right) }\right| \right)$，即每轮成本由网络中瓶颈链路的数据传输成本决定。

In this coarse-grained computational model, we do not consider the delay in routing, since the congestion cost measured above will dominate the overall cost when data size is much larger than network size (i.e., the number of compute nodes), which is a quite reasonable assumption for practical systems dealing with big data. ${}^{4}$ In addition,we do not consider the network size as a constant; otherwise, this model will lose the power of parallelism. In previous works on massively parallel processing $\left\lbrack  {6,7,{21},{24} - {27},{32}}\right\rbrack$ ,the number of compute nodes is a commonly-used parameter in complexity measurement. We compare it with other parallel/distributed model in Section 6.

在此粗粒度计算模型中，我们不考虑路由延迟，因为当数据规模远大于网络规模（即计算节点数量）时，上述测量的拥塞成本将主导总成本——这对处理大数据的实际系统是合理假设。${}^{4}$此外，我们未将网络规模视为常数，否则该模型将丧失并行能力。在大规模并行处理$\left\lbrack  {6,7,{21},{24} - {27},{32}}\right\rbrack$的既往研究中，计算节点数量是复杂度度量的常用参数。我们将在第6节与其他并行/分布式模型进行对比。

Initial Data Distribution. Given a symmetric tree topology $G = \left( {V,E}\right)$ with compute nodes ${V}_{C}$ , and an initial data distribution $\mathcal{D}$ for two input relations $R\left( {A,B}\right) ,S\left( {B,C}\right)$ across ${V}_{C}$ ,we denote by ${R}_{v}^{\mathcal{D}},{S}_{v}^{\mathcal{D}}$ the $R$ -tuples and $S$ -tuples respectively in node $v \in  {V}_{C}$ . Let ${N}_{v}^{\mathcal{D}} = \left| {R}_{v}^{\mathcal{D}}\right|  + \left| {S}_{v}^{\mathcal{D}}\right|$ . When the context is clear,we drop $\mathcal{D}$ from the notation. We note that an input instance $I$ consists of the symmetric tree topology $G = \left( {V,E}\right)$ and the initial data distribution $\mathcal{D}$ .

初始数据分布。给定具有计算节点${V}_{C}$的对称树拓扑$G = \left( {V,E}\right)$，以及两个输入关系$R\left( {A,B}\right) ,S\left( {B,C}\right)$在${V}_{C}$节点间的初始分布$\mathcal{D}$，我们用${R}_{v}^{\mathcal{D}},{S}_{v}^{\mathcal{D}}$分别表示节点$v \in  {V}_{C}$中的$R$元组和$S$元组。设${N}_{v}^{\mathcal{D}} = \left| {R}_{v}^{\mathcal{D}}\right|  + \left| {S}_{v}^{\mathcal{D}}\right|$。上下文明确时，我们将省略符号中的$\mathcal{D}$。需注意输入实例$I$由对称树拓扑$G = \left( {V,E}\right)$和初始数据分布$\mathcal{D}$构成。

${}^{1}$ The restriction to tree topologies is natural,since many practical network topologies can be captured as trees,such as star and fat tree. There is also a technical reason that there is a unique routing path between any two nodes in a tree topology. In a non-tree network, the presence of possibly multiple routing paths would complicates things. To extend from trees to general topologies, one could consider embedding the general topology to a tree, and then use a tree-based algorithm.

${}^{1}$限于树拓扑是自然的，因星型拓扑、胖树等实际网络拓扑均可抽象为树。技术层面而言，树拓扑中任意两节点间存在唯一路由路径。非树网络中可能存在的多路由路径会使问题复杂化。若要从树扩展到通用拓扑，可考虑将通用拓扑嵌入树结构后采用基于树的算法。

${}^{2}$ If some compute node in ${V}_{C}$ is an internal node in $G$ ,we can transform $G$ to a new topology ${G}^{\prime }$ by adding a new compute node ${v}^{\prime }$ ,introducing two links $\left( {v,{v}^{\prime }}\right) ,\left( {{v}^{\prime },v}\right)$ with bandwidth $+ \infty$ ,and making $v$ a non-compute node. Any initial data stored at $v$ is shifted to ${v}^{\prime }$ ,and any local computation performed by $v$ is simulated by ${v}^{\prime }$ .

${}^{2}$ 若${V}_{C}$中的某个计算节点在$G$中属于内部节点，则可通过以下方式将$G$转换为新拓扑${G}^{\prime }$：添加新计算节点${v}^{\prime }$，引入两条带宽为$+ \infty$的链路$\left( {v,{v}^{\prime }}\right) ,\left( {{v}^{\prime },v}\right)$，并将$v$转为非计算节点。原存储于$v$的初始数据将转移至${v}^{\prime }$，且$v$执行的本地计算将由${v}^{\prime }$模拟完成。

Optimality. We introduce the notion of cardinality configuration of data distribution. A cardinality configuration $\phi$ across the compute nodes ${V}_{C}$ is denoted as $\left\{  {\left( {{\phi }_{v}^{1},{\phi }_{v}^{2}}\right)  : {\phi }_{v}^{1},{\phi }_{v}^{2} \in  {\mathbb{Z}}^{ * },v \in  {V}_{C}}\right\}$ . A data distribution $\mathcal{D}$ conforms to a cardinality configuration $\phi$ if $\left| {R}_{v}^{\mathcal{D}}\right|  = {\phi }_{v}^{1}$ and $\left| {S}_{v}^{\mathcal{D}}\right|  = {\phi }_{v}^{2}$ for every compute node $v \in  {V}_{C}$ . We adopt the notion of parameterized analysis,i.e.,we partition the whole space of inputs into disjoint sub-spaces, where instances inside each sub-space share the same symmetric tree topology,cardinality configuration,and output size. Let $\mathbb{I}\left( {G,\phi ,\mathrm{{OUT}}}\right)$ denote that class of instances characterized by the three parameters $G,\phi$ ,OUT. Then the cost of an algorithm $\mathcal{A}$ is thus a function of $G,\phi$ ,OUT,defined as ${L}_{\mathcal{A}}\left( {G,\phi ,\mathrm{{OUT}}}\right)  = \mathop{\max }\limits_{{I \in  \mathbb{I}\left( {G,\phi ,\mathrm{{OUT}}}\right) }}{L}_{\mathcal{A}}\left( I\right)$ ,where ${L}_{\mathcal{A}}\left( I\right)$ is the cost of computing $I$ by $\mathcal{A}$ . An algorithm $\mathcal{A}$ is topology-aware-optimal if for every algorithm ${\mathcal{A}}^{\prime },{L}_{\mathcal{A}}\left( {G,\phi ,\mathrm{{OUT}}}\right)  = O\left( {{L}_{{\mathcal{A}}^{\prime }}\left( {G,\phi ,\mathrm{{OUT}}}\right) }\right)$ .

最优性。我们引入数据分布的基数配置概念。计算节点${V}_{C}$间的基数配置$\phi$记作$\left\{  {\left( {{\phi }_{v}^{1},{\phi }_{v}^{2}}\right)  : {\phi }_{v}^{1},{\phi }_{v}^{2} \in  {\mathbb{Z}}^{ * },v \in  {V}_{C}}\right\}$。当$\left| {R}_{v}^{\mathcal{D}}\right|  = {\phi }_{v}^{1}$且对每个计算节点$v \in  {V}_{C}$满足$\left| {S}_{v}^{\mathcal{D}}\right|  = {\phi }_{v}^{2}$时，数据分布$\mathcal{D}$符合基数配置$\phi$。我们采用参数化分析方法，即将输入空间划分为互斥子空间，每个子空间内的实例共享相同的对称树拓扑、基数配置和输出规模。用$\mathbb{I}\left( {G,\phi ,\mathrm{{OUT}}}\right)$表示由三个参数$G,\phi$和OUT表征的实例类别，则算法$\mathcal{A}$的成本即为$G,\phi$和OUT的函数，定义为${L}_{\mathcal{A}}\left( {G,\phi ,\mathrm{{OUT}}}\right)  = \mathop{\max }\limits_{{I \in  \mathbb{I}\left( {G,\phi ,\mathrm{{OUT}}}\right) }}{L}_{\mathcal{A}}\left( I\right)$（其中${L}_{\mathcal{A}}\left( I\right)$表示$\mathcal{A}$计算$I$的成本）。若对任意算法${\mathcal{A}}^{\prime },{L}_{\mathcal{A}}\left( {G,\phi ,\mathrm{{OUT}}}\right)  = O\left( {{L}_{{\mathcal{A}}^{\prime }}\left( {G,\phi ,\mathrm{{OUT}}}\right) }\right)$均成立，则称算法$\mathcal{A}$具有拓扑感知最优性。

To construct a general join algorithm, we resort to sorting instead of hashing that has been used for set intersection in [20]. The sort-based protocol follows the general idea of [24] for topology-oblivious parallel joins. One first attempt would be to use the sorting protocol from [20] to sort the union of the two relations, $R \cup  S$ using the join key. However,this idea does not give an optimal protocol. Indeed,consider the case where $R \ll  S$ . In this case,the algorithm would have to sort $R \cup  S$ ,redistributing the tuples from the larger relation $S$ . However,if we were to broadcast $R$ to every compute node and not move $S$ at all,we would obtain a much cheaper solution. In other words, instead of sorting globally, we need to sort the largest relation in a topologically "local" way. We achieve this by carefully grouping the compute nodes so that each group's input data is approximately balanced (Section 4.3 and 4.4).

为构建通用连接算法，我们采用排序而非文献[20]中用于集合交集的哈希方法。该基于排序的协议遵循文献[24]提出的拓扑无关并行连接思想。最初尝试是使用[20]中的排序协议对两个关系的并集按连接键排序$R \cup  S$，但此方案并非最优。例如当$R \ll  S$时，算法需对$R \cup  S$排序，这将重新分配较大关系$S$的元组。但若将$R$广播至所有计算节点且不移动$S$，则可获得更经济的解决方案。换言之，我们需以拓扑"局部"方式对最大关系排序，而非全局排序。通过精心分组计算节点使各组的输入数据近似均衡实现该目标（第4.3与4.4节）。

The sorting step guarantees that we can locally compute the join results for join keys that are fully contained within a compute node. However, it cannot deal with join keys that span multiple compute nodes (we call these boundary keys,denoted as $K$ ). This case will happen when data skew exists since a key will not fit in a single node without blowing up the algorithm cost. The main technical contribution of this paper is how to handle the join computation for these boundary keys. To solve this problem, we view it as the simultaneous computation of multiple Cartesian products ${\left\{  {R}_{b} \times  {S}_{b}\right\}  }_{b \in  K}$ . Our solution uses two primitives that may be of independent interest. The first primitive (Section 2) is an optimal protocol that redistributes the data of a relation from an input distribution to the desired output distribution with minimal cost. The second primitive (Section 3) designs an optimal protocol that allocates the computation of a set of Cartesian products from the root to the leaves of a tree. To achieve the topology-aware-optimality, we further explore the structural property of the underlying tree network with respect to the initial data distribution (Section 4.1), such that the tree network is decomposed into multiple edge-disjoint subtrees (denoted as $\alpha$ -tree) connected by a skeleton subtree (denoted as $\beta$ -tree). The remaining challenging question is to pack Cartesian products over $\beta$ -tree such that each $\alpha$ -tree will compute the allocated Cartesian products independently (Section 4.3 and 4.5).

排序步骤确保我们能本地计算完全包含在单个计算节点内的连接键结果，但无法处理跨多个计算节点的连接键（称为边界键，记作$K$）。当存在数据倾斜时，键值会超出单节点容量导致算法成本激增。本文的核心技术贡献在于处理这些边界键的连接计算。我们将该问题视为多个笛卡尔积${\left\{  {R}_{b} \times  {S}_{b}\right\}  }_{b \in  K}$的同步计算。解决方案采用两个具有独立价值的原语：第一原语（第2节）是以最小成本将关系数据从输入分布重分配到目标分布的最优协议；第二原语（第3节）设计从树根到叶子分配笛卡尔积计算的最优协议。为实现拓扑感知最优性，我们深入探究初始数据分布下树网络的结构特性（第4.1节），将其分解为由骨架子树（$\beta$-树）连接的多个边不相交子树（$\alpha$-树）。关键挑战是在$\beta$-树上打包笛卡尔积，使每个$\alpha$-树能独立计算分配的任务（第4.3与4.5节）。

Data Redistribution Primitive. Consider a (not necessarily symmetric) tree topology $G = \left( {V,E}\right)$ with leaf nodes ${V}_{C} = \left\{  {{v}_{1},\ldots ,{v}_{\ell }}\right\}$ . Moreover,assume $k$ input relations ${R}_{1},\ldots ,{R}_{k}$ distributed over leaf nodes according to a distribution $\mathcal{D}$ . We say that $\mathcal{D}$ conforms to a matrix $\Lambda$ of dimensions $k \times  \ell$ with positive integers if for every input relation ${R}_{i}$ and every leaf node ${v}_{j}$ ,there are ${\Lambda }_{ij}$ tuples from ${R}_{i}$ distributed at ${v}_{j}$ . We call such a matrix a size-constraint matrix. Given two size-constraint matrices $\Lambda ,{\Lambda }^{\prime }$ ,our goal is to design an algorithm that transforms any input data distribution $\mathcal{D}$ that conforms to $\Lambda$ to a data distribution ${\mathcal{D}}^{\prime }$ that conforms to ${\Lambda }^{\prime }$ . In other words,we want to redistribute the data such that a new set of size constraints is satisfied at every leaf, and we also want to achieve this with the minimum cost. Note that to properly define the task, we need to make sure that for every relation ${R}_{i},\mathop{\sum }\limits_{j}{\Lambda }_{ij} = \mathop{\sum }\limits_{j}{\Lambda }_{ij}^{\prime } = \left| {R}_{i}\right|$ .

数据重分布原语。考虑一个（非必须对称的）树状拓扑$G = \left( {V,E}\right)$及其叶节点${V}_{C} = \left\{  {{v}_{1},\ldots ,{v}_{\ell }}\right\}$。假设存在$k$个输入关系${R}_{1},\ldots ,{R}_{k}$按照分布$\mathcal{D}$分布在叶节点上。若对于每个输入关系${R}_{i}$和每个叶节点${v}_{j}$，都有${\Lambda }_{ij}$个来自${R}_{i}$的元组分布在${v}_{j}$上，则称$\mathcal{D}$符合维度为$k \times  \ell$的正整数矩阵$\Lambda$。我们称此类矩阵为尺寸约束矩阵。给定两个尺寸约束矩阵$\Lambda ,{\Lambda }^{\prime }$，我们的目标是设计算法，将任何符合$\Lambda$的输入数据分布$\mathcal{D}$转换为符合${\Lambda }^{\prime }$的数据分布${\mathcal{D}}^{\prime }$。换言之，我们需要以最小代价实现数据重分布，使每个叶节点满足新的尺寸约束集。需注意，为确保任务定义完备，必须验证每个关系${R}_{i},\mathop{\sum }\limits_{j}{\Lambda }_{ij} = \mathop{\sum }\limits_{j}{\Lambda }_{ij}^{\prime } = \left| {R}_{i}\right|$的合规性。

- For every node $v \in  V$ and $i \in  \left\lbrack  k\right\rbrack  ,\mathop{\sum }\limits_{u}{f}_{i}\left( {v,u}\right)  = \mathop{\sum }\limits_{u}{f}_{i}\left( {u,v}\right)$ .

Any flow corresponds to an algorithm for the data redistribution problem. Indeed, we can interpret a unit of flow from commodity $i$ as a tuple from relation ${R}_{i}$ . We seek the flow with the minimum cost,which is $\mathop{\max }\limits_{{e \in  E}}\mathop{\sum }\limits_{i}{f}_{i}\left( e\right) /{w}_{e}$ . We can solve the multi-commodity flow problem via a linear program in polynomial time, but the flow solution may be fractional. Instead, we provide a more direct flow solution using tuple differentials,which simply assigns each flow ${f}_{i}\left( e\right)$ to be the tuple differential ${\Delta }_{e}^{i}$ ,incurring an optimal cost of $\mathop{\max }\limits_{{e \in  E}}\left\{  {{\Delta }_{e}^{i}/{w}_{e}}\right\}$ . See an example in Figure 1.

任何流都对应着数据重分配问题的一个算法。实际上，我们可以将来自商品$i$的单位流解释为关系${R}_{i}$中的元组。我们寻求成本最小的流，即$\mathop{\max }\limits_{{e \in  E}}\mathop{\sum }\limits_{i}{f}_{i}\left( e\right) /{w}_{e}$。虽然可以通过多项式时间的线性规划求解多商品流问题，但得到的流解可能是分数形式的。为此，我们提出了一种更直接的基于元组差分的流解法，该方法直接将每个流${f}_{i}\left( e\right)$赋值为元组差分${\Delta }_{e}^{i}$，从而产生$\mathop{\max }\limits_{{e \in  E}}\left\{  {{\Delta }_{e}^{i}/{w}_{e}}\right\}$的最优成本。示例见图1。

THEOREM 2.4. In a tree network, data redistribution problem can be optimally computed in 1 round.

## 3 CARTESIAN PRODUCT PACKING

## 3 笛卡尔积装箱

In this section, we present a second fundamental primitive that we need for our join algorithm. Consider a tree topology $G = \left( {V,E}\right)$ that we have rooted at some node $r$ . We are also given a finite set of relation pairs $\left( {{R}_{b},{S}_{b}}\right)$ ,where $b$ belongs in a finite set $B$ . Initially,all tuples are sitting at the root $r$ . The task is to find an algorithm that routes all tuples from the root to the leaf nodes such that every pair of the Cartesian product ${R}_{b} \times  {S}_{b}$ can be locally computed at some leaf node. We will refer to this task as cartesian product packing.

本节介绍连接算法所需的第二个基础原语。给定以节点$r$为根的树状拓扑$G = \left( {V,E}\right)$，以及有限的关系对集合$\left( {{R}_{b},{S}_{b}}\right)$（其中$b$属于有限集$B$）。初始时所有元组都位于根节点$r$。我们的目标是找到一种算法，将元组从根节点路由至叶节点，使得笛卡尔积${R}_{b} \times  {S}_{b}$的每对元素都能在某个叶节点本地计算。我们将此任务称为笛卡尔积装箱。

For a tree $G = \left( {V,E}\right)$ rooted at $r$ ,let ${\mathcal{L}}_{v}$ be the set of leaf nodes contained in the subtree rooted at node $v \in  V$ . If $v \in  {V}_{C},{\mathcal{L}}_{v} = \varnothing$ . For any non-root node $v \in  V \smallsetminus  \{ r\}$ ,we use ${w}_{v}$ to denote the bandwidth of the edge between node $v$ and its (unique) parent node.

对于以$r$为根的树$G = \left( {V,E}\right)$，设${\mathcal{L}}_{v}$表示以节点$v \in  V$为根的子树包含的叶节点集合。若$v \in  {V}_{C},{\mathcal{L}}_{v} = \varnothing$。对于任意非根节点$v \in  V \smallsetminus  \{ r\}$，用${w}_{v}$表示该节点与其唯一父节点$v$之间边的带宽。

### 3.2 An Algorithm

Given the optimization problem (1) that provides the lower bound, one can solve it to obtain the optimal values of ${x}_{b,v},{y}_{b,v}$ and ${g}_{b,v}$ . Packing Squares. Consider the assignments ${x}_{b.v}^{ * },{y}_{b.v}^{ * },{g}_{b.v}^{ * }$ for (1) that achieves the optimal solution with cost ${L}^{ * }$ . $$

The recursion works in a bottom-up fashion starting from the leaf nodes. 我们将其解释为：存在${c}_{i}$个$i$类型的正方形，其尺寸为${2}^{i} \times  {2}^{i}$。当$i < {i}_{b}^{ * }$时，允许最多存在3个$i$类型的正方形，但对于${i}_{b}^{ * }$类型则数量不限。递归采用自底向上的方式从叶节点开始运作。正方形分配需满足以下特性：其总面积恰好等于$8 \cdot  {g}_{b,v}^{ * }$。换言之，$\mathop{\sum }\limits_{i}{c}_{i} \cdot  {4}^{i} = 8 \cdot  {g}_{b,v}^{ * }$。

For the base case,we assign to compute node $v$ a set ${S}_{b,v}$ such that $\mathop{\sum }\limits_{i}{c}_{i} \cdot  {4}^{i} = 8 \cdot  {g}_{b,v}^{ * }$ . This is always possible, and moreover there is a unique way to achieve this decomposition. Next, consider some internal node $u$ . Each of its children $v$ is assigned a set of squares ${S}_{b,v}$ from the recursion. We start the following procedure in an increasing order of $i \geq  0$ : for each type $i < {i}_{h}^{ * }$ ,if there are 4 squares of type $i$ in $\mathop{\bigcup }\limits_{v}{S}_{b,v}$ ,we pack them into one larger square of type $i + 1$ . ## 4 THE JOIN ALGORITHM

## 4 连接算法

In this section,we present the general algorithm for computing the join $R\left( {A,B}\right)  \bowtie  S\left( {B,C}\right)$ over a symmetric tree topology $G = \left( {V,E}\right)$ . Throughout this section,we assume that $\left| R\right|  \leq  \left| S\right|$ . The algorithm consists of two basic steps, where each step computes a partial join result. In the first step, we compute part of the result using a sort-based protocol. After sorting the tuples according to the join key (attribute $B$ ),the compute nodes can compute locally the result for the join keys that completely reside within a node. The join keys that cross different nodes (called boundary keys) have to be handled by the second step. The boundary keys can be roughly viewed as the "heavy" keys in the join computation.

本节阐述对称树拓扑$G = \left( {V,E}\right)$上计算连接$R\left( {A,B}\right)  \bowtie  S\left( {B,C}\right)$的通用算法。全篇默认$\left| R\right|  \leq  \left| S\right|$。该算法包含两个基本步骤：第一步采用基于排序的协议计算部分结果，元组按连接键（属性$B$）排序后，计算节点可本地处理完全驻留于节点内的连接键；跨节点的边界键则由第二步处理，这些边界键可视为连接计算中的"重"键。

Before we describe the steps of the algorithm, we need to introduce a few useful concepts over the symmetric tree topology.

### 4.1 Edges and Trees

### 4.1 边与树

Recall that each edge $e = \left( {u,v}\right)$ defines a partition of $G$ as two connected subtrees: ${G}_{e}^{ - }$ and ${G}_{e}^{ + }$ . For simplicity,we also use ${G}_{e}^{ - },{G}_{e}^{ + }$ to denote the set of leaf nodes in the corresponding subtree.

每条边$e = \left( {u,v}\right)$将$G$划分为两个连通子树：${G}_{e}^{ - }$与${G}_{e}^{ + }$。为简化表述，${G}_{e}^{ - },{G}_{e}^{ + }$亦表示对应子树的叶节点集合。

We note a lower bound ${C}_{\text{int }} = \mathop{\max }\limits_{{e \in  E}}\frac{1}{{w}_{e}} \cdot  \left\{  {\left| R\right| ,\mathop{\sum }\limits_{{v \in  {G}_{e}}}{N}_{v},\mathop{\sum }\limits_{{v \in  {G}_{e}^{ + }}}{N}_{v}}\right\}$ for the cost of set intersection [20], hence it also forms a lower bound for a general join protocol. Using ${C}_{\text{int }}$ as a guide,we classify the edges in $E$ into two disjoint subsets:

基于集合交运算成本下界${C}_{\text{int }} = \mathop{\max }\limits_{{e \in  E}}\frac{1}{{w}_{e}} \cdot  \left\{  {\left| R\right| ,\mathop{\sum }\limits_{{v \in  {G}_{e}}}{N}_{v},\mathop{\sum }\limits_{{v \in  {G}_{e}^{ + }}}{N}_{v}}\right\}$[20]——这也是通用连接协议的下界，我们将$E$中的边划分为两个互斥子集：

$$
{E}_{\alpha } = \left\{  {e \in  E : \left| R\right|  > \min \left\{  {\mathop{\sum }\limits_{{v \in  {G}_{e}^{ - }}}{N}_{v},\mathop{\sum }\limits_{{v \in  {G}_{e}^{ + }}}{N}_{v}}\right\}  }\right\}  ,{E}_{\beta } = E - {E}_{\alpha }
$$

An edge $e$ is an $\alpha$ -edge if $e \in  {E}_{\alpha }$ and a $\beta$ -edge otherwise. Let ${G}_{\beta }$ be the subgraph of $G$ edge-induced by ${E}_{\beta }$ ; in [20],it has been shown that ${G}_{\beta }$ always forms a connected tree,called the $\beta$ -tree. We denote the nodes of ${G}_{\beta }$ as ${V}_{\beta }$ and the leaf nodes of ${G}_{\beta }$ as ${\mathcal{L}}_{\beta }$ . On the other hand,the graph edge-induced by ${E}_{\alpha }$ may not be connected; let $\left\{  {{G}_{\alpha }^{1},{G}_{\alpha }^{2},\cdots ,{G}_{\alpha }^{\ell }}\right\}$ be the connected subtrees (called $\alpha$ -trees). See Figure 3. If ${E}_{\beta } = \varnothing$ ,the network $G$ itself forms a single $\alpha$ -tree.

若边$e$满足$e \in  {E}_{\alpha }$则称为$\alpha$边，否则为$\beta$边。令${G}_{\beta }$表示$G$中由${E}_{\beta }$导出的边子图，文献[20]已证明${G}_{\beta }$恒形成连通树（称为$\beta$树），其节点集记为${V}_{\beta }$，叶节点集为${\mathcal{L}}_{\beta }$；而${E}_{\alpha }$导出的子图可能不连通，其连通子树（称$\alpha$树）记为$\left\{  {{G}_{\alpha }^{1},{G}_{\alpha }^{2},\cdots ,{G}_{\alpha }^{\ell }}\right\}$（见图3）。当${E}_{\beta } = \varnothing$时，网络$G$本身即构成单一$\alpha$树。

For each $\alpha$ -tree ${G}_{\alpha }^{j}$ ,we can define a directed version ${\overrightarrow{G}}_{\alpha }^{j}$ as follows: $\left( i\right) {\overrightarrow{G}}_{\alpha }^{j}$ has the same vertex set as ${G}_{\alpha }^{j}$ ,and (ii) for an edge $e = \left( {u,v}\right)$ in ${G}_{\alpha }^{j}$ ,if $\mathop{\sum }\limits_{{{v}^{\prime } \in  {G}_{e}^{ - }}}{N}_{{v}^{\prime }} < \mathop{\sum }\limits_{{{v}^{\prime } \in  {G}_{e}^{ + }}}{N}_{{v}^{\prime }}{}^{6},{\overrightarrow{G}}_{\alpha }^{j}$ contains only an edge from $u$ to $v$ ,otherwise only an edge from $v$ to $u$ . We say that a directed tree is rooted at the node $r$ if every edge points towards $r$ . It turns out that the set of directed trees $\left\{  {{\overrightarrow{G}}_{\alpha }^{1},\cdots ,{\overrightarrow{G}}_{\alpha }^{\ell }}\right\}$ has a very specific structure, as the next lemma shows.

对于每棵$\alpha$树${G}_{\alpha }^{j}$，我们可以如下定义其有向版本${\overrightarrow{G}}_{\alpha }^{j}$：(i)$\left( i\right) {\overrightarrow{G}}_{\alpha }^{j}$与${G}_{\alpha }^{j}$具有相同的顶点集，(ii)对于${G}_{\alpha }^{j}$中的边$e = \left( {u,v}\right)$，若$\mathop{\sum }\limits_{{{v}^{\prime } \in  {G}_{e}^{ - }}}{N}_{{v}^{\prime }} < \mathop{\sum }\limits_{{{v}^{\prime } \in  {G}_{e}^{ + }}}{N}_{{v}^{\prime }}{}^{6},{\overrightarrow{G}}_{\alpha }^{j}$仅包含从$u$指向$v$的边，否则仅保留从$v$指向$u$的边。当所有边都指向节点$r$时，我们称该有向树以$r$为根。如后续引理所示，有向树集合$\left\{  {{\overrightarrow{G}}_{\alpha }^{1},\cdots ,{\overrightarrow{G}}_{\alpha }^{\ell }}\right\}$具有特定结构。

LEMMA 4.1. Every ${\overrightarrow{G}}_{\alpha }^{j}$ is a directed rooted tree. Moreover,if ${E}_{\beta } \neq  \varnothing$ ,the root of each ${\overrightarrow{G}}_{\alpha }^{j}$ is the unique node that is adjacent to a $\beta$ -edge.

引理4.1. 每棵${\overrightarrow{G}}_{\alpha }^{j}$都是有向根树。此外，若${E}_{\beta } \neq  \varnothing$，则每棵${\overrightarrow{G}}_{\alpha }^{j}$的根节点是唯一与$\beta$边相邻的节点。

Proof of Lemma 4.1. The proof distinguishes two cases. First,consider the case where ${E}_{\beta } \neq  \varnothing$ . Consider an edge $e = \left( {u,v}\right)$ such that ${G}_{e}^{ + }$ contains the root. Then, ${G}_{e}^{ + }$ contains at least one $\beta$ -edge, so it must be that $\left| R\right|  \leq  \mathop{\sum }\limits_{{w \in  {G}_{e}^{ + }}}{N}_{v}$ . But because $e$ is an $\alpha$ -edge,we also have $\left| R\right|  > \mathop{\sum }\limits_{{w \in  {G}_{e}^{ - }}}{N}_{v}$ . Hence, $\mathop{\sum }\limits_{{w \in  {G}_{e}^{ + }}}{N}_{v} > \mathop{\sum }\limits_{{w \in  {G}_{e}^{ - }}}{N}_{v}$ and the edge is indeed directed towards the root. Second,consider the case where ${E}_{\beta } = \varnothing$ . Since ${\overrightarrow{G}}_{\alpha }$ is a directed tree,there must exist at least one node with no outgoing edges; otherwise, there would be a cycle in the graph, a contradiction. Hence, it suffices to show that there is at most one such a node. By contradiction,assume two nodes $u,v$ with outdegree 0 . Consider the unique path between $u,v$ : then,there must be a node $w$ in the path with out-degree at least two. In other words,we have edges ${e}_{1} = \left( {w,{v}_{1}}\right)$ and ${e}_{2} = \left( {w,{v}_{2}}\right)$ . But then $N \geq  \mathop{\sum }\limits_{{x \in  {G}_{{e}_{1}}^{ + }}}{N}_{x} + \mathop{\sum }\limits_{{x \in  {G}_{{e}_{2}}^{ + }}}{N}_{x} > N/2 + N/2 = N$ ,a contradiction.

引理4.1证明. 证明分两种情况。首先考虑${E}_{\beta } \neq  \varnothing$的情形：设边$e = \left( {u,v}\right)$满足${G}_{e}^{ + }$包含根节点，则${G}_{e}^{ + }$至少含有一条$\beta$边，故必有$\left| R\right|  \leq  \mathop{\sum }\limits_{{w \in  {G}_{e}^{ + }}}{N}_{v}$。但由于$e$是$\alpha$边，可得$\left| R\right|  > \mathop{\sum }\limits_{{w \in  {G}_{e}^{ - }}}{N}_{v}$。因此$\mathop{\sum }\limits_{{w \in  {G}_{e}^{ + }}}{N}_{v} > \mathop{\sum }\limits_{{w \in  {G}_{e}^{ - }}}{N}_{v}$，该边确实指向根节点。其次考虑${E}_{\beta } = \varnothing$的情形：因${\overrightarrow{G}}_{\alpha }$是有向树，必存在至少一个无出边的节点，否则会导致图中出现环，产生矛盾。故只需证明至多存在一个这样的节点。反设存在两个出度为零的节点$u,v$，考虑其唯一路径，则路径中必存在出度至少为2的节点$w$，即存在边${e}_{1} = \left( {w,{v}_{1}}\right)$和${e}_{2} = \left( {w,{v}_{2}}\right)$，这将导致$N \geq  \mathop{\sum }\limits_{{x \in  {G}_{{e}_{1}}^{ + }}}{N}_{x} + \mathop{\sum }\limits_{{x \in  {G}_{{e}_{2}}^{ + }}}{N}_{x} > N/2 + N/2 = N$，形成矛盾。

An illustration of this structure when ${E}_{\beta } \neq  \varnothing$ is given in Figure 3. An important consequence of the lemma that will be of use later is that every compute node $v$ can send its local data (of size ${N}_{v}$ ) to the root node of its corresponding $\alpha$ -tree (which will be a leaf node of the $\beta$ -tree) with a cost that does not exceed the lower bound ${C}_{\text{int }}$ .

### 4.2 Warm Up: A Single $\alpha$ -Tree

### 4.2 热身：单一$\alpha$树场景

We start with an easy case when network $G$ itself forms a single $\alpha$ -tree (i.e., ${E}_{\beta } = \varnothing$ ),rooted at some node $r$ . This case could happen on some simple inputs,such as when there is symmetry on the input size (i.e., $\left| R\right|  = \left| S\right|$ ),or when the initial data distribution is uniform (i.e., ${N}_{u} = {N}_{v}$ for every pair of compute nodes $u,v \in  {V}_{C}$ ) together with the input size constraint $\left| S\right|  < \left( {\left| {V}_{C}\right|  - 1}\right)  \cdot  \left| R\right|$ . Our algorithm is quite straightforward via three steps:

我们从简单情形入手——当网络$G$本身构成单一$\alpha$树时（即${E}_{\beta } = \varnothing$），其根节点为$r$。该情形可能出现在简单输入条件下，例如输入规模对称时（即$\left| R\right|  = \left| S\right|$），或初始数据分布均匀时（即任意计算节点对$u,v \in  {V}_{C}$均满足${N}_{u} = {N}_{v}$）且满足输入规模约束$\left| S\right|  < \left( {\left| {V}_{C}\right|  - 1}\right)  \cdot  \left| R\right|$。我们的算法通过三步实现：

- Step 1. We first invoke the weighted TeraSort algorithm [20] to sort all tuples by their join values. ${}^{7}$ After the data is sorted, each node locally computes the join results with non-boundary keys, where a key is boundary if it is the smallest or the largest one among its local tuples (and hence it can possibly have tuples in other compute nodes as well). Let $K$ be the set of boundary keys.

- 步骤1. 首先调用加权TeraSort算法[20]按连接值排序所有元组。${}^{7}$数据排序后，各节点本地计算非边界键的连接结果（边界键定义为本地元组中最小或最大的键，因此可能在其他计算节点也存在对应元组）。记$K$为边界键集合。

- Step 2. We next compute the input sizes $\left| {R}_{b}\right| ,\left| {S}_{b}\right|$ for each $b \in  K$ by invoking the multi-numbering primitive (see Appendix D),and then broadcast $\left| {R}_{b}\right|$ ’s, $\left| {S}_{b}\right|$ ’s to all compute nodes in ${V}_{C}$ .

- 步骤2. 接着通过调用多编号原语（见附录D）计算每个$b \in  K$的输入规模$\left| {R}_{b}\right| ,\left| {S}_{b}\right|$，然后将$\left| {R}_{b}\right|$和$\left| {S}_{b}\right|$广播至${V}_{C}$内所有计算节点。

- Step 3. At last,we just send all tuples with $b \in  K$ to the root $r$ ,and simply invoke the Cartesian product packing primitive in Section 3 to handle the boundary keys. ${}^{8}$ The whole topology $G$ together with the data statistics of boundary keys are stored at the local memory of each compute node, hence the program (1) can be solved locally by each node.

- 步骤3. 最后将所有含$b \in  K$的元组发送至根节点$r$，并调用第3节的笛卡尔积打包原语处理边界键。${}^{8}$完整拓扑结构$G$及边界键数据统计信息存储于各计算节点本地内存，因此程序(1)可由各节点本地求解。

This protocol incurs a cost of $O\left( {{\mathrm{C}}_{\text{int }} + {\mathrm{C}}_{\text{pack }}}\right)$ ,where ${\mathrm{C}}_{\text{pack }}$ is the optimal solution of (1) parameterized by $\left\{  {\left| {R}_{b}\right| ,\left| {S}_{b}\right|  : b \in  K}\right\}$ .

该协议产生$O\left( {{\mathrm{C}}_{\text{int }} + {\mathrm{C}}_{\text{pack }}}\right)$的通信成本，其中${\mathrm{C}}_{\text{pack }}$为通过$\left\{  {\left| {R}_{b}\right| ,\left| {S}_{b}\right|  : b \in  K}\right\}$参数化的(1)式最优解。

In the remaining,we will deal with the general case where the network $G$ has a $\beta$ -tree as its core, with a set of $\alpha$ -trees incident to the leaf nodes of $\beta$ -tree,as shown in Section 4.1.

后续我们将处理更普遍的情形：如4.1节所示，网络$G$以$\beta$树为核心，其叶节点连接着若干$\alpha$树。

### 4.4 Step 1: Sort-based Join

### 4.4 步骤1：基于排序的连接

The first step of the join algorithm performs a sort-based join. As we discussed in the introduction, we do not sort $R \cup  S$ globally. Instead,we construct a balanced partition $\mathcal{P}$ of ${\mathcal{L}}_{\beta }$ ,and then separately sort $R$ together with the local $S$ -tuples in the nodes of each block of the partition $\mathcal{P}$ . As described in Algorithm 2, it consists of three steps:

- (Step 1.1) We first construct a balanced partition $\mathcal{P}$ of ${\mathcal{L}}_{\beta }$ by invoking Algorithm 1,where $\tau  = \left| R\right|$ and function $\theta \left( P\right)$ for a subset of leaf nodes $P \subseteq  {\mathcal{L}}_{\beta }$ is defined as the sum of ${N}_{v}$ for every compute node $v$ in the $\alpha$ -tree rooted at some $u \in  P$ ,i.e.,

- (步骤1.1) 首先调用算法1构建${\mathcal{L}}_{\beta }$的平衡划分$\mathcal{P}$，其中对于叶节点子集$P \subseteq  {\mathcal{L}}_{\beta }$，定义$\tau  = \left| R\right|$和函数$\theta \left( P\right)$为以$u \in  P$为根的$\alpha$-树中每个计算节点$v$的${N}_{v}$之和，即

$$

- if ${f}_{b,j} \geq  \left| {R}_{b}\right| /\left| {S}_{b}\right|$ ,we assign the computation of a rectangle ${\blacksquare }_{b,j}$ with dimensions $\left| {R}_{b}\right|  \times  \left\lceil  {2 \cdot  {f}_{b,j} \cdot  \left| {S}_{b}\right| }\right\rceil$ . - otherwise,we assign the computation of a square ${\square }_{b,j}$ with size ${\left( 2 \cdot  {f}_{b,j} \cdot  \left| {R}_{b}\right|  \cdot  \left| {S}_{b}\right| \right) }^{1/2}$ rounded up to the closest power of 2 .

- 若${f}_{b,j} \geq  \left| {R}_{b}\right| /\left| {S}_{b}\right|$，则分配计算尺寸为$\left| {R}_{b}\right|  \times  \left\lceil  {2 \cdot  {f}_{b,j} \cdot  \left| {S}_{b}\right| }\right\rceil$的矩形${\blacksquare }_{b,j}$。- 否则，分配计算边长为${\left( 2 \cdot  {f}_{b,j} \cdot  \left| {R}_{b}\right|  \cdot  \left| {S}_{b}\right| \right) }^{1/2}$（向上取整至最接近的2的幂）的正方形${\square }_{b,j}$。

Now,suppose we are given such a fraction function $f$ ,as well as the rectangles/squares ${\mathbf{I}}_{b,j}$ for each ${G}_{\alpha }^{j}$ and $b \in  K$ . We will show for each boundary key $b \in  K$ ,how to organize/pack the above squares/rectangles inside the Cartesian product ${R}_{b} \times  {S}_{b}$ so that they fully cover every pair of ${R}_{b} \times  {S}_{b}$ . This packing procedure is conceptually the reverse of assigning tuples for ${R}_{b,j}$ and ${S}_{b,j}^{f}$ .

假设已给定该分数函数$f$，以及每个${G}_{\alpha }^{j}$和$b \in  K$对应的矩形/正方形${\mathbf{I}}_{b,j}$。我们将展示如何为每个边界键$b \in  K$，在笛卡尔积${R}_{b} \times  {S}_{b}$内组织/排布上述正方形/矩形，使其完全覆盖所有${R}_{b} \times  {S}_{b}$对。该排布过程在概念上等同于为${R}_{b,j}$和${S}_{b,j}^{f}$分配元组的逆过程。

Packing over the $\beta$ -tree. To construct a packing for a boundary key $b \in  K$ ,we will again deploy the tree partition algorithm (Algorithm 1),where $\tau  = \left| {R}_{b}\right| /\left| {S}_{b}\right|$ and the function $\theta$ for a subset leaf nodes $P \subseteq  {\mathcal{L}}_{\beta }$ is defined as sum of the fractions ${f}_{b,j}$ such that the associated directed $\alpha$ -tree is rooted at some node in $P$ ,i.e.,

基于$\beta$树的排布。要为边界键$b \in  K$构建排布方案，我们将再次部署树分区算法（算法1），其中$\tau  = \left| {R}_{b}\right| /\left| {S}_{b}\right|$且子集叶节点$P \subseteq  {\mathcal{L}}_{\beta }$的函数$\theta$定义为分数${f}_{b,j}$之和，前提是关联的有向$\alpha$树根植于$P$的某个节点，即：

$$
\theta \left( P\right)  = \mathop{\sum }\limits_{{u \in  P : {\overrightarrow{G}}_{\alpha }^{j}\text{ is rooted at }u}}{f}_{b,j}.
$$

We slightly modify Algorithm 1 such that in the last possible step when we are left with two vertices $u,v$ ,we do not merge $u$ with $\theta \left( {\Gamma \left( u\right) }\right)  < \tau$ if its parent $v$ has $\theta \left( {\Gamma \left( v\right) }\right)  > \tau$ . This modification means that we could have a block ${P}_{0}$ with $\theta \left( {P}_{0}\right)  \leq  \tau$ ,but there can be at most one of such blocks. We refer this modified version as TREEPARTITION’. Let $\mathcal{P}$ be the resulting partition.

我们微调算法1：当最后仅剩两个顶点$u,v$时，若其父节点$v$满足$\theta \left( {\Gamma \left( v\right) }\right)  > \tau$，则不将$u$与$\theta \left( {\Gamma \left( u\right) }\right)  < \tau$合并。此调整意味着可能存在一个包含$\theta \left( {P}_{0}\right)  \leq  \tau$的块${P}_{0}$，但此类块最多只有一个。修改后的版本称为TREEPARTITION’。设$\mathcal{P}$为最终分区结果。

Now,we show how to pack these squares/rectangles over the $\beta$ -tree based on $\mathcal{P}$ . Note that a rectangle can appear in a block of $\mathcal{P}$ with a single $\alpha$ -tree (since it contributes more than $\tau$ to the total weight). Hence, any block that has more than one tree contains only squares. Since by construction the squares have dimensions that are powers of two, we can use the construction in [20] (Lemma 10) to pack the squares of any block $P \in  \mathcal{P} \smallsetminus  \left\{  {P}_{0}\right\}$ such that they fully cover a square of size at least: $\frac{1}{2}\mathop{\sum }\limits_{{j \in  P}}\left( {2 \cdot  {f}_{b,j} \cdot  \left| {R}_{b}\right|  \cdot  \left| {S}_{b}\right| }\right)  \geq  \left| {R}_{b}\right|  \cdot  \left| {S}_{b}\right|  \cdot  \tau  \geq  {\left| {R}_{b}\right| }^{2}$ . Hence,any block $P \in  \mathcal{P} \smallsetminus  \left\{  {P}_{0}\right\}$ can fully pack a rectangle of dimensions $\left| {R}_{b}\right|  \times  {\kappa }_{P}$ ,where ${\kappa }_{P} \geq  \left| {R}_{b}\right|$ . We can now put these rectangles horizontally next to each other. Let $\kappa$ be the horizontal length covered by these rectangles. We do not use the specific block ${P}_{0}$ (if it exists) to cover any part of the ${R}_{b} \times  {S}_{b}$ grid.

现在，我们将展示如何基于$\mathcal{P}$在$\beta$树上打包这些正方形/矩形。需要注意的是，一个矩形可能出现在仅包含单棵$\alpha$树的$\mathcal{P}$块中（因为其对总权重的贡献超过$\tau$）。因此，任何包含多棵树的块仅由正方形组成。由于构造时正方形的维度是2的幂次，我们可以采用文献[20]（引理10）的构造方法，将任意块$P \in  \mathcal{P} \smallsetminus  \left\{  {P}_{0}\right\}$中的正方形打包，使其完全覆盖至少尺寸为$\frac{1}{2}\mathop{\sum }\limits_{{j \in  P}}\left( {2 \cdot  {f}_{b,j} \cdot  \left| {R}_{b}\right|  \cdot  \left| {S}_{b}\right| }\right)  \geq  \left| {R}_{b}\right|  \cdot  \left| {S}_{b}\right|  \cdot  \tau  \geq  {\left| {R}_{b}\right| }^{2}$的正方形。因此，任意块$P \in  \mathcal{P} \smallsetminus  \left\{  {P}_{0}\right\}$可完整打包一个维度为$\left| {R}_{b}\right|  \times  {\kappa }_{P}$的矩形，其中${\kappa }_{P} \geq  \left| {R}_{b}\right|$。现在我们可以将这些矩形水平并列排列。设$\kappa$为这些矩形覆盖的水平长度。我们不会使用特定块${P}_{0}$（若存在）来覆盖${R}_{b} \times  {S}_{b}$网格的任何部分。

回顾$\theta \left( {P}_{0}\right)  \leq  \tau$可知$\mathop{\sum }\limits_{{j \in  {P}_{0}}}{f}_{b,j} \cdot  \left| {R}_{b}\right|  \cdot  \left| {S}_{b}\right|  \leq  {\left| {R}_{b}\right| }^{2}$。我们得到：$\left| {R}_{b}\right|  \cdot  \left| {S}_{b}\right|  \leq  {\left| {R}_{b}\right| }^{2} + \frac{1}{2} \cdot  \left| {R}_{b}\right|  \cdot  \kappa$因此，$\kappa  \geq  2\left| {S}_{b}\right|  - \left| {R}_{b}\right|  \geq  \left| {S}_{b}\right|$。

Redistributing $S$ -tuples over $\beta$ -tree. It remains to specify how to send the necessary tuples for each ${\blacksquare }_{b,j}$ to the root of the corresponding $\alpha$ -tree ${G}_{\alpha }^{j}$ . Hence,we only need to consider $\log \left( {\left| {R}_{b}\right|  \cdot  \left| {S}_{b}\right| }\right)  = O\left( {\log N}\right)$ possible values for every fraction ${f}_{b,j}$ ,and only lose a constant factor in optimality. The ${f}^{ * }$ is computed locally in each compute node without incurring any data transmission cost. Putting everything together, we obtain:

最优分数。最后我们展示如何通过以2的幂次迭代$\left\lbrack  {1,\left| {R}_{b}\right|  \cdot  \left| {S}_{b}\right| }\right\rbrack$中网格分配的所有可能尺寸来找到最优分数${f}^{ * }$。因此，对于每个分数${f}_{b,j}$只需考虑$\log \left( {\left| {R}_{b}\right|  \cdot  \left| {S}_{b}\right| }\right)  = O\left( {\log N}\right)$个可能值，且最优性仅损失常数因子。${f}^{ * }$在每个计算节点本地计算，不会产生任何数据传输成本。综合所有要素，我们得到：

THEOREM 4.6. Given a symmetric tree topology $G = \left( {V,E}\right)$ ,and any data distribution $\mathcal{D}$ for $R\left( {A,B}\right)  \bowtie  S\left( {B,C}\right)$ ,their join results can be computed in $O\left( 1\right)$ rounds with cost $O\left( {{C}_{\text{int }} + {C}_{\text{pack }}}\right)$ ,for

定理4.6。给定对称树拓扑$G = \left( {V,E}\right)$和$R\left( {A,B}\right)  \bowtie  S\left( {B,C}\right)$的任意数据分布$\mathcal{D}$，其连接结果可在$O\left( 1\right)$轮次内以成本$O\left( {{C}_{\text{int }} + {C}_{\text{pack }}}\right)$计算得到，其中

$$
{C}_{\text{pack }} = \mathop{\min }\limits_{f}\left\{  {\mathop{\max }\limits_{{e \in  {E}_{\beta }}}\frac{{\Delta }_{e}}{{w}_{e}} + \mathop{\max }\limits_{{j \in  \left\lbrack  l\right\rbrack  }}{L}^{ * }\left( {{\overrightarrow{G}}_{\alpha }^{j},\left\{  {{\blacksquare }_{b,j} : b \in  K}\right\}  }\right) }\right\}  ,
$$

where ${\Delta }_{e}$ is the tuple differential defined over $\Lambda$ in (4) and ${\Lambda }^{f}$ in (5),and ${L}^{ * }\left( {{\overrightarrow{G}}_{\alpha }^{j},\left\{  {{\blacksquare }_{b,j} : b \in  K}\right\}  }\right)$ is the optimal solution of (1) defined on the directed tree ${\overrightarrow{G}}_{\alpha }^{j}$ and a set of Cartesian products ${\mathbf{\Xi }}_{b,j}$ for $b \in  K$ .

其中${\Delta }_{e}$是在(4)中定义于$\Lambda$、在(5)中定义于${\Lambda }^{f}$的元组差分，${L}^{ * }\left( {{\overrightarrow{G}}_{\alpha }^{j},\left\{  {{\blacksquare }_{b,j} : b \in  K}\right\}  }\right)$是在有向树${\overrightarrow{G}}_{\alpha }^{j}$和$b \in  K$的一组笛卡尔积${\mathbf{\Xi }}_{b,j}$上定义的(1)式最优解。

### 4.6 Optimality

### 4.6 最优性

The topology-aware-optimality of Theorem 4.6 is established via the lower bound below, whose proof is given in Appendix E. The high-level idea is to construct two sub-instances ${\mathcal{D}}_{1}$ and ${\mathcal{D}}_{2}$ with disjoint domains such that ${\mathcal{D}}_{1} \cup  {\mathcal{D}}_{2}$ conforms to $\phi$ and OUT. We show the lower bound $\Omega \left( {C}_{\text{int }}\right)$ for computing ${\mathcal{D}}_{1}$ via an reduction from the lopsided set disjointness problem. Conditioning on $\Omega \left( {C}_{\text{int }}\right)$ ,we show the other lower bound $\Omega \left( {\mathop{\max }\limits_{{\mathcal{D}}^{\prime }}{C}_{\text{pack }}}\right)$ for computing ${\mathcal{D}}_{2}$ .

定理4.6的拓扑感知最优性通过下界得以确立，其证明详见附录E。核心思路是构建两个定义域不相交的子实例${\mathcal{D}}_{1}$和${\mathcal{D}}_{2}$，使得${\mathcal{D}}_{1} \cup  {\mathcal{D}}_{2}$符合$\phi$及OUT条件。我们通过非对称集合不相交问题的归约，证明了计算${\mathcal{D}}_{1}$的下界$\Omega \left( {C}_{\text{int }}\right)$。在$\Omega \left( {C}_{\text{int }}\right)$条件下，我们进一步展示了计算${\mathcal{D}}_{2}$的另一个下界$\Omega \left( {\mathop{\max }\limits_{{\mathcal{D}}^{\prime }}{C}_{\text{pack }}}\right)$。

THEOREM 4.7. Given a symmetric tree topology $G = \left( {V,E}\right)$ ,a cardinality distribution $\phi$ and output size OUT,there is a data distribution $\mathcal{D}$ for $R\left( {A,B}\right)  \bowtie  S\left( {B,C}\right)$ conforming to $\phi$ and OUT,that any algorithm computing the join results incurs a cost of $\Omega \left( {{C}_{\text{int }} + \mathop{\max }\limits_{{\mathcal{D}}^{\prime }}{C}_{\text{pack }}}\right)$ ,where ${\mathcal{D}}^{\prime }$ is over all data distributions conforming to $\phi$ and OUT.

定理4.7. 给定对称树拓扑$G = \left( {V,E}\right)$、基数分布$\phi$和输出规模OUT，存在符合$\phi$与OUT条件的数据分布$\mathcal{D}$，使得任何计算连接结果的算法必然产生$\Omega \left( {{C}_{\text{int }} + \mathop{\max }\limits_{{\mathcal{D}}^{\prime }}{C}_{\text{pack }}}\right)$的通信代价，其中${\mathcal{D}}^{\prime }$遍历所有符合$\phi$和OUT条件的数据分布。

### 4.7 Simplification of the Algorithm on Easier Input

### 4.7 简化算法在简单输入场景下的应用

Below, we discuss some interesting cases when the underlying topology, the initial data distributions, or the join instance displays simpler properties.

下文将讨论当底层拓扑结构、初始数据分布或连接实例呈现更简单特性时的若干典型案例。

Uniform Data Distribution. Assume each compute node holds the same amount of data, which is a common occurrence in practice. W.l.o.g.,assume $\left| R\right|  \leq  \left| S\right|$ . Recall one of our lower bounds ${C}_{\text{int }}$ for the cost of set intersection. We simply distinguish two cases:

均匀数据分布。假设各计算节点持有等量数据（实践中常见情形），不妨设$\left| R\right|  \leq  \left| S\right|$。回顾我们关于集合交运算代价的下界${C}_{\text{int }}$，现区分两种情况：

- If $\left| R\right|  + \left| S\right|  \leq  \left| R\right|  \cdot  \left| {V}_{C}\right|$ ,we have ${E}_{\alpha } = E$ and ${E}_{\beta } = \varnothing$ . In this case,the network $G$ itself forms a single $\alpha$ -tree,and our simplified algorithm in Section 4.2 directly applies. This case incurs a cost of $O\left( {{C}_{\text{int }} + {C}_{\text{pack }}}\right)$ ,where ${C}_{\text{pack }}$ is the optimal solution of (1) parameterized by $\left\{  {\left| {R}_{b}\right| ,\left| {S}_{b}\right|  : b \in  B}\right\}$ .

- 若$\left| R\right|  + \left| S\right|  \leq  \left| R\right|  \cdot  \left| {V}_{C}\right|$，则有${E}_{\alpha } = E$且${E}_{\beta } = \varnothing$。此时网络$G$本身构成单一$\alpha$树，可直接应用4.2节的简化算法，产生$O\left( {{C}_{\text{int }} + {C}_{\text{pack }}}\right)$的通信代价，其中${C}_{\text{pack }}$表示由$\left\{  {\left| {R}_{b}\right| ,\left| {S}_{b}\right|  : b \in  B}\right\}$参数化的方程(1)最优解。

- If $\left| R\right|  + \left| S\right|  > \left| R\right|  \cdot  \left| {V}_{C}\right|$ ,we have ${E}_{\alpha } = \varnothing$ and ${E}_{\beta } = E$ . In this case,the network $G$ itself is the $\beta$ -tree,and our algorithm just sends all $R$ -tuples to every compute node. This case incurs a cost of $O\left( {\mathop{\max }\limits_{{e \in  E}}\frac{\left| R\right| }{{w}_{e}}}\right)$ .

- 若$\left| R\right|  + \left| S\right|  > \left| R\right|  \cdot  \left| {V}_{C}\right|$，则有${E}_{\alpha } = \varnothing$且${E}_{\beta } = E$。此时网络$G$即为$\beta$树，算法仅需将所有$R$元组广播至各计算节点，产生$O\left( {\mathop{\max }\limits_{{e \in  E}}\frac{\left| R\right| }{{w}_{e}}}\right)$的通信代价。

Symmetric star topology. Assume the underlying topology is a symmetric star $G = \left( {V,E}\right)$ . Let $o \in  V$ be the router. W.l.o.g.,assume $\left| R\right|  \leq  \left| S\right|$ . We partition compute nodes in ${V}_{C}$ into ${V}_{\alpha }$ and ${V}_{\beta }$ :

对称星型拓扑。假设底层拓扑为对称星型结构$G = \left( {V,E}\right)$，设$o \in  V$为路由节点。不妨设$\left| R\right|  \leq  \left| S\right|$，将${V}_{C}$中的计算节点划分为${V}_{\alpha }$和${V}_{\beta }$两类：

$$
{V}_{\alpha } = \left\{  {v \in  {V}_{C} : \left| R\right|  > \min \left\{  {{N}_{v},N - {N}_{v}}\right\}  }\right\}  ,{V}_{\beta } = {V}_{C} - {V}_{\alpha }
$$

Equivalently, ${E}_{\alpha }$ (resp. ${E}_{\beta }$ ) is the set of edges incident to compute nodes in ${V}_{\alpha }$ (resp. ${V}_{\beta }$ ). In the tree partition $\mathcal{P}$ of $G$ ,every node in ${V}_{\beta }$ forms an individual block,and all nodes in ${V}_{\alpha }$ form one block. Our algorithm can be simplified as follows:

等价地，${E}_{\alpha }$（相应地，${E}_{\beta }$）是与${V}_{\alpha }$（相应地，${V}_{\beta }$）中计算节点相关联的边集。在$G$的树分区$\mathcal{P}$中，${V}_{\beta }$中的每个节点形成一个独立块，而${V}_{\alpha }$中的所有节点构成一个块。我们的算法可简化为：

(1) We let all compute nodes send $R$ -tuples to ${V}_{\beta }$ and let nodes in ${V}_{\beta }$ compute local join results.

(1) 令所有计算节点向${V}_{\beta }$发送$R$元组，并让${V}_{\beta }$中的节点计算局部连接结果。

(2) We sort $R \cup  \left( {{ \cup  }_{v \in  {V}_{\alpha }}{S}_{v}}\right)$ over ${V}_{\alpha } \cup  \{ o\}$ ,and let each node in ${V}_{\alpha }$ compute the local join results with non-boundary keys.

(2) 对${V}_{\alpha } \cup  \{ o\}$上的$R \cup  \left( {{ \cup  }_{v \in  {V}_{\alpha }}{S}_{v}}\right)$进行排序，使${V}_{\alpha }$中每个节点计算与非边界键的局部连接结果。

(3) We let all compute nodes in ${V}_{\alpha }$ send their $S$ -tuples of boundary keys to the router $o$ .

(3) 令${V}_{\alpha }$中所有计算节点将其边界键的$S$元组发送至路由器$o$。

(4) Consider an arbitrary boundary key $b \in  K$ and its Cartesian product ${R}_{b} \times  {S}_{b}$ . Consider an arbitrary $f$ . The router $o$ simply forwards ${\Lambda }_{b,v}^{f}$ arbitrary $S$ -tuples with key $b \in  K$ to every $v \in  {V}_{\beta }$ ; and a square ${\blacksquare }_{b,v}$ of ${\Lambda }_{b,v}^{f}R$ -tuples and $S$ -tuples with key $b \in  K$ to every $v \in  {V}_{\alpha }$ . After receiving the data, all nodes compute the local join results.

(4) 考虑任意边界键$b \in  K$及其笛卡尔积${R}_{b} \times  {S}_{b}$。任取$f$，路由器$o$只需将含键$b \in  K$的任意$S$元组${\Lambda }_{b,v}^{f}$转发至每个$v \in  {V}_{\beta }$；并将含键$b \in  K$的${\Lambda }_{b,v}^{f}R$元组与$S$元组的平方${\blacksquare }_{b,v}$发送至每个$v \in  {V}_{\alpha }$。接收数据后，所有节点计算局部连接结果。

Cartesian product. Assume there is a single boundary key value in the join attribute. In this case,the join $R \bowtie  S$ degenerates to the Cartesian product $R \times  S$ . Assume $\left| R\right|  \leq  \left| S\right|$ without loss of generality. The algorithm can be simplified as follows:

笛卡尔积。假设连接属性中存在单一边界键值，此时连接$R \bowtie  S$退化为笛卡尔积$R \times  S$。不失一般性设$\left| R\right|  \leq  \left| S\right|$，算法可简化为：

(1) We first construct a balanced partition $\mathcal{P} = \left\{  {{P}_{1},{P}_{2},\ldots ,{P}_{k}}\right\}$ by Algorithm 1. Recall that $G$ has a $\beta$ -tree as its core,with a set of $\alpha$ -trees $\left\{  {{G}_{\alpha }^{1},{G}_{\alpha }^{2},\cdots ,{G}_{\alpha }^{\ell }}\right\}$ incident to the leaf nodes of $\beta$ -tree.

(1) 首先通过算法1构建平衡分区$\mathcal{P} = \left\{  {{P}_{1},{P}_{2},\ldots ,{P}_{k}}\right\}$。注意$G$核心为$\beta$树，其叶节点连接着$\alpha$树集合$\left\{  {{G}_{\alpha }^{1},{G}_{\alpha }^{2},\cdots ,{G}_{\alpha }^{\ell }}\right\}$。

(2) For each ${G}_{\alpha }^{j}$ ,we let all compute nodes send their $S$ -tuple to the root of ${\overrightarrow{G}}_{\alpha }^{j}$ ,and their $R$ -tuples to every root node of subtrees.

(2) 对每个${G}_{\alpha }^{j}$，令所有计算节点将其$S$元组发送至${\overrightarrow{G}}_{\alpha }^{j}$根节点，$R$元组发送至各子树根节点。

(3) Consider an arbitrary $f$ . We redistribute $S$ -tuples across $\beta$ -tree by invoking the redistribution primitive in Section 2. Assume ${S}_{j}^{f}$ is the set of $S$ -tuples residing at the root of ${G}_{\alpha }^{j}$ after this step. Let ${R}_{j}^{f}$ be the set of $R$ -tuples assigned to ${G}_{\alpha }^{j}$ .

(3) 任取$f$，通过调用第2节重分布原语在$\beta$树间重分配$S$元组。设此步骤后驻留于${G}_{\alpha }^{j}$根节点的$S$元组集合为${S}_{j}^{f}$，分配给${G}_{\alpha }^{j}$的$R$元组集合为${R}_{j}^{f}$。

(4) Each ${G}_{\alpha }^{j}$ is responsible for computing ${R}_{j}^{f} \times  {S}_{j}^{f}$ inside the subtree using the Cartesian product packing primitive in Section 3.

(4) 每个${G}_{\alpha }^{j}$负责使用第3节笛卡尔积打包原语计算子树内的${R}_{j}^{f} \times  {S}_{j}^{f}$。

## 5 DISCUSSIONS

## 5 讨论

Below, we discuss several interesting questions related to optimality.

下面我们将探讨与最优性相关的若干有趣问题。

Worst-case Data Distribution. If targeting optimality with respect to the worst-case data distribution,things becomes easy. We next show a simple algorithm for computing $R\left( {A,B}\right)  \bowtie$ $S\left( {B,C}\right)$ over a symmetric tree topology $G = \left( {V,E}\right)$ . W.l.o.g.,assume $\left| R\right|  \leq  \left| S\right|$ . If $\left| R\right|  = \left| S\right|$ ,we simply pick one arbitrary node,say $v$ and let all nodes send their data to $v$ . If $\left| R\right|  < \left| S\right|$ ,we let every compute node broadcast its $R$ -tuples. The cost of this algorithm is bounded by $O\left( {\mathop{\max }\limits_{{e \in  E}}\frac{\left| R\right| }{{w}_{e}}}\right)$ . Meanwhile, consider an arbitrary cardinality distribution $\phi$ such that $\mathop{\sum }\limits_{{v \in  {G}_{{e}^{ * }}^{ - }}}{N}_{v} = \mathop{\sum }\limits_{{v \in  {G}_{{e}^{ * }}^{ + }}}{N}_{v} = \frac{1}{2}\left( {\left| R\right|  + \left| S\right| }\right)$ for ${e}^{ * } = \arg \mathop{\max }\limits_{{e \in  E}}{w}_{e}$ . Implied by Lemma E.1,there exists an instance conforming to $\phi$ such that any algorithm must incur a cost of $\Omega \left( {C}_{\text{int }}\right)  = \Omega \left( \frac{\left| R\right| }{{w}_{{e}^{ * }}}\right)$ . Thus,this algorithm is already optimal.

最坏情况数据分布。若以最坏情况数据分布为优化目标，问题将变得简单。接下来我们展示一种在对称树拓扑结构$G = \left( {V,E}\right)$上计算$R\left( {A,B}\right)  \bowtie$$S\left( {B,C}\right)$的简易算法。不失一般性，假设$\left| R\right|  \leq  \left| S\right|$。当$\left| R\right|  = \left| S\right|$时，只需任选一个节点（如$v$）并令所有节点向其发送数据；若$\left| R\right|  < \left| S\right|$，则让每个计算节点广播其$R$元组。该算法成本上限为$O\left( {\mathop{\max }\limits_{{e \in  E}}\frac{\left| R\right| }{{w}_{e}}}\right)$。同时考虑任意基数分布$\phi$满足$\mathop{\sum }\limits_{{v \in  {G}_{{e}^{ * }}^{ - }}}{N}_{v} = \mathop{\sum }\limits_{{v \in  {G}_{{e}^{ * }}^{ + }}}{N}_{v} = \frac{1}{2}\left( {\left| R\right|  + \left| S\right| }\right)$（当${e}^{ * } = \arg \mathop{\max }\limits_{{e \in  E}}{w}_{e}$时）。根据引理E.1，存在符合$\phi$的实例使得任何算法必然产生$\Omega \left( {C}_{\text{int }}\right)  = \Omega \left( \frac{\left| R\right| }{{w}_{{e}^{ * }}}\right)$成本，故该算法已达最优。

New challenges by Downstream Applications. For complicated analytical queries, such as acyclic joins and join-aggregate query, we can apply the standard pairwise framework by incorporating binary join as a primitive, but achieving the optimality with respect to the cardinality of initial data distribution becomes quite challenging.

下游应用的新挑战。对于复杂分析查询（如无环连接和连接-聚合查询），可采用标准两两处理框架将二元连接作为基础操作，但实现初始数据分布基数的最优性变得极具挑战性。

Consider a join-aggregate query $\mathop{\sum }\limits_{B}R\left( {A,B}\right)  \bowtie  S\left( {B,C}\right)$ . A basic solution is to materialize the result of binary join and then aggregate the join results over $B$ by invoking the topology-aware reduce-by-key primitive (in Appendix D). However, the distribution of binary join results will serve as the input distribution of the subsequent aggregation. If incorporating our join algorithm without considering subsequent aggregation, it may not be an overall optimal algorithm.

考虑连接-聚合查询$\mathop{\sum }\limits_{B}R\left( {A,B}\right)  \bowtie  S\left( {B,C}\right)$。基础解法是物化二元连接结果后，通过调用拓扑感知的按键归约原语（附录D）在$B$上聚合。但二元连接结果的分布将作为后续聚合的输入分布。若直接采用未考虑后续聚合的连接算法，可能无法实现全局最优。

Consider an acyclic join. A basic solution is to remove all dangling tuples (i.e., those won't participate in any join results) by topology-aware semi-joins (in Appendix D) and then perform pairwise join. In the sequential RAM model as well as the homogeneous MPC model, the pairwise join ordering does not matter, as long as the size of intermediate join result can be bounded by that of final join result. However, this ordering makes a big difference in our topology-aware model, since the distribution of intermediate join results will serve as the initial distribution of an input relation in the subsequent join. Incorporating our binary join algorithm blindly to subsequent joins may not be optimal. Moreover, it would be very costly to pre-compute the best pairwise join ordering locally, since the distribution of intermediate join results could require full information of input data to compute.

以无环连接为例。基础解法是通过拓扑感知半连接（附录D）剔除悬空元组（即不参与任何连接结果的元组），再执行两两连接。在顺序RAM模型和同质MPC模型中，只要中间连接结果规模受限于最终结果，连接顺序无关紧要。但在拓扑感知模型中，该顺序影响显著——中间结果的分布将作为后续连接中输入关系的初始分布。盲目将二元连接算法应用于后续连接可能非最优，且本地预计算最佳连接顺序成本极高，因中间结果分布可能需要完整输入数据信息才能确定。

## 6 RELATED WORK

## 6 相关工作

Topology-aware models have been widely studied in parallel and distributed computations, such as the classical LOCAL/ CONGEST model [29, 30] and their variants [11, 28]. These models are different from ours in the following aspects: (i) all these models take both delay and congestion cost into account, such that limited size of data can only be exchanged between neighbor nodes, while our model only consider the congestion cost, such that any pair of nodes can exchange data in a single round as long as there exists a valid routing path; (ii) LOCAL/CONGEST model does not assume the knowledge of network topology, while our model as well as [11, 28] assume that the algorithm has complete knowledge of network topology; (iii) [28] assumes that one relation completely resides within one node while our model considers the case where relations are split or distributed across compute nodes; (iv) [11, 28] consider the worst-case distribution of input data while we consider the cardinality of initial data distribution as input parameters, thus being able to prove more fine-grained optimality. A hierarchical version of the BSP model has also been studied as D-BSP model $\left\lbrack  {8,9,{13}}\right\rbrack$ . In D-BSP model,nodes are the leaves of a complete binary tree,on which "clusters" are defined. In the $i$ -th round,nodes can only communicate within the same $i$ -level cluster. But, no such hierarchy exists in our topology-aware model since any pair of nodes with a routing path can communicate in a single round. In addition, nodes communicating within some specific cluster in D-BSP have the same transmission cost, while links in our topology-aware model can have arbitrary bandwidth cost, regardless of the topology structure. Later, Chattopadhyay et al. $\left\lbrack  {{11},{12}}\right\rbrack$ studied topology-dependent round complexity for k -party functions (e.g.,set-disjointness and element distinctness) in a similar model as CONGEST. Langberg et al. [28] further improved the round complexity for functional aggregate queries. Topology-aware aggregation has been considered in other systematic works, but without theoretical guarantees. We refer interested readers to $\left\lbrack  {{10},{20}}\right\rbrack$ for more details.

拓扑感知模型在并行与分布式计算领域已被广泛研究，例如经典的LOCAL/CONGEST模型[29,30]及其变体[11,28]。这些模型与我们的区别主要体现在：(i) 现有模型同时考虑通信延迟和拥塞成本，仅允许相邻节点交换有限数据量，而我们的模型仅考虑拥塞成本，只要存在有效路由路径，任意节点对均可单轮完成数据交换；(ii) LOCAL/CONGEST模型不预设网络拓扑知识，而我们的模型与文献[11,28]均假设算法完全知晓网络拓扑；(iii) 文献[28]假设关系完全驻留在单一节点，而我们的模型考虑关系被分割或分布式存储的情况；(iv) 文献[11,28]分析输入数据的最坏分布情况，而我们将初始数据分布的基数作为输入参数，从而能证明更细粒度的最优性。BSP模型的分层版本D-BSP$\left\lbrack  {8,9,{13}}\right\rbrack$亦被研究，其节点构成完全二叉树的叶节点，并定义"簇"结构。在第$i$轮通信中，节点仅限同$i$层级簇内交互。但我们的拓扑感知模型不存在此类层级限制，任何具有路由路径的节点对均可单轮通信。此外，D-BSP中特定簇内节点的传输成本相同，而我们的模型允许链路带宽成本任意设定，与拓扑结构无关。后续Chattopadhyay等人$\left\lbrack  {{11},{12}}\right\rbrack$在类CONGEST模型中研究了k方函数(如集合互斥性和元素相异性)的拓扑相关轮复杂度。Langberg等人[28]进一步改进了函数聚合查询的轮复杂度。其他系统化研究虽涉及拓扑感知聚合，但缺乏理论保证，详见$\left\lbrack  {{10},{20}}\right\rbrack$。

Similarly,(6) is bounded by $\left| R\right|$ for $e \in  {E}_{\beta }$ ,which is implied by the definition of a balanced partition. Also,the inequality $M \leq  \min \left\{  {\mathop{\sum }\limits_{{v \in  {G}_{e}^{ - }}}{N}_{v},\mathop{\sum }\limits_{{v \in  {G}_{e}^{ + }}}{N}_{v}}\right\}$ for $e \in  {E}_{\alpha }$ follows directly.

类似地，(6)式对于$e \in  {E}_{\beta }$受限于$\left| R\right|$，这源于平衡分区的定义。同时，$e \in  {E}_{\alpha }$时的不等式$M \leq  \min \left\{  {\mathop{\sum }\limits_{{v \in  {G}_{e}^{ - }}}{N}_{v},\mathop{\sum }\limits_{{v \in  {G}_{e}^{ + }}}{N}_{v}}\right\}$也直接成立。

## D TOPOLOGY-AWARE PRIMITIVES

## D 拓扑感知原语

All Prefix-Sums. Given an array $A$ of elements $A\left\lbrack  1\right\rbrack  ,A\left\lbrack  2\right\rbrack  ,\cdots ,A\left\lbrack  N\right\rbrack$ which are distributed according to the ordering $\pi$ ,the goal is to compute $S\left\lbrack  i\right\rbrack   = A\left\lbrack  1\right\rbrack   \oplus  A\left\lbrack  2\right\rbrack   \oplus  \cdots  \oplus  A\left\lbrack  i\right\rbrack$ for all $i = 1,2,\cdots ,N$ ,where $\oplus$ is any associative operator. Assume there exists some compute node with its initial data size larger than $\left| {V}_{C}\right|$ ,say $u{.}^{11}$ Let $A\left\lbrack  {{s}_{i} : {t}_{i}}\right\rbrack$ be the sub-array located at node ${v}_{i}$ after sorting. Each node ${v}_{i}$ first computes $B\left\lbrack  i\right\rbrack   = A\left\lbrack  {s}_{i}\right\rbrack   \oplus  A\left\lbrack  {{s}_{i} + 1}\right\rbrack   \oplus  \cdots  \oplus  A\left\lbrack  {t}_{i}\right\rbrack$ and send it to $u$ . After receiving all $B\left\lbrack  i\right\rbrack  ,u$ performs local computation and sends back to ${v}_{i}$ the result of $B\left\lbrack  1\right\rbrack   \oplus  B\left\lbrack  2\right\rbrack   \oplus  \cdots  \oplus  B\left\lbrack  i\right\rbrack$ ,for all $i \in  \left\lbrack  \left| {V}_{C}\right| \right\rbrack$ . After receiving $B\left\lbrack  {i - 1}\right\rbrack$ ,node ${v}_{i}$ computes $S\left\lbrack  j\right\rbrack   = B\left\lbrack  {i - 1}\right\rbrack   + A\left\lbrack  {s}_{i}\right\rbrack   + A\left\lbrack  {{s}_{i} + 1}\right\rbrack   + \cdots  + A\left\lbrack  j\right\rbrack$ for each $j \in  \left\lbrack  {{s}_{i},{t}_{i}}\right\rbrack$ .

全前缀和。给定一个元素数组$A$，其中元素$A\left\lbrack  1\right\rbrack  ,A\left\lbrack  2\right\rbrack  ,\cdots ,A\left\lbrack  N\right\rbrack$按照$\pi$顺序分布，目标是计算所有$i = 1,2,\cdots ,N$对应的$S\left\lbrack  i\right\rbrack   = A\left\lbrack  1\right\rbrack   \oplus  A\left\lbrack  2\right\rbrack   \oplus  \cdots  \oplus  A\left\lbrack  i\right\rbrack$，其中$\oplus$为任意可结合运算符。假设存在某个计算节点，其初始数据规模大于$\left| {V}_{C}\right|$，记为$u{.}^{11}$。令$A\left\lbrack  {{s}_{i} : {t}_{i}}\right\rbrack$表示排序后位于节点${v}_{i}$的子数组。每个节点${v}_{i}$首先计算$B\left\lbrack  i\right\rbrack   = A\left\lbrack  {s}_{i}\right\rbrack   \oplus  A\left\lbrack  {{s}_{i} + 1}\right\rbrack   \oplus  \cdots  \oplus  A\left\lbrack  {t}_{i}\right\rbrack$并将其发送至$u$。在接收完所有$B\left\lbrack  i\right\rbrack  ,u$后，执行本地计算并将$B\left\lbrack  1\right\rbrack   \oplus  B\left\lbrack  2\right\rbrack   \oplus  \cdots  \oplus  B\left\lbrack  i\right\rbrack$的结果返回给${v}_{i}$（针对所有$i \in  \left\lbrack  \left| {V}_{C}\right| \right\rbrack$）。当节点${v}_{i}$收到$B\left\lbrack  {i - 1}\right\rbrack$后，将为每个$j \in  \left\lbrack  {{s}_{i},{t}_{i}}\right\rbrack$计算$S\left\lbrack  j\right\rbrack   = B\left\lbrack  {i - 1}\right\rbrack   + A\left\lbrack  {s}_{i}\right\rbrack   + A\left\lbrack  {{s}_{i} + 1}\right\rbrack   + \cdots  + A\left\lbrack  j\right\rbrack$。

Reduce-By-Key. Given a set of (key,value) pairs and an associate operator $\oplus$ ,the goal is to for each key $k$ compute the "sum" of corresponding values under $\oplus$ . We adapt the algorithm [24] for solving reduce-by-key over MPC model based on prefix-sum. We first sort the pairs by their keys by invoking the algorithm in [20]. The $i$ -th tuple in the sorted order will produce a pair(x,y),which will act as $A\left\lbrack  i\right\rbrack$ . For each tuple that is the first of its key in the sorted order,we produce the pair (0, value); otherwise, we produce (1, value). Note that we need another round of communication to determine whether each tuple is the first of its key, in case that its predecessor resides on another server. Then we define the operator $\oplus$ as $\left( {{x}_{1},{y}_{1}}\right)  \oplus  \left( {{x}_{2},{y}_{2}}\right)  = \left( {{x}_{1} \cdot  {x}_{2},y}\right)$ ,where $y = {y}_{1} \oplus  {y}_{2}$ if ${x}_{2} = 1$ and otherwise $y = {y}_{2}$ . After solving the all prefix-sums problem on the derived array $A$ ,the last tuple for each key is exactly the "sum" of the associated key.

键值归约（Reduce-By-Key）。给定一组（键，值）对及关联运算符$\oplus$，目标是为每个键$k$计算对应值在$\oplus$下的"总和"。我们改进基于前缀和的算法[24]以在MPC模型上实现键值归约：首先调用文献[20]算法按键排序，排序后的$i$号元组将生成(x,y)对作为$A\left\lbrack  i\right\rbrack$。对于排序中每个键的首个元组，生成(0,值)；否则生成(1,值)。需额外通信轮次判定元组是否为键首项（当其前驱位于其他服务器时）。定义运算符$\oplus$为$\left( {{x}_{1},{y}_{1}}\right)  \oplus  \left( {{x}_{2},{y}_{2}}\right)  = \left( {{x}_{1} \cdot  {x}_{2},y}\right)$，其中$y = {y}_{1} \oplus  {y}_{2}$当${x}_{2} = 1$成立，否则为$y = {y}_{2}$。在派生数组$A$上求解全前缀和后，每个键的末位元组即为该键关联值的"总和"。

Multi-number. Given a set of (key,value) pairs,the goal is to for each key $k$ ,assign consecutive numbers $1,2,\cdots ,{n}_{k}$ to elements with key $k$ ,respectively,where ${n}_{k}$ is the total number of elements with key $k$ . The multi-number can be solved by the reduce-by-key primitive. Each tuple will be associated with value 1,and the operator $\oplus$ is simply set as + . After solving the all prefix-sums problem on the derived array $A,S\left\lbrack  i\right\rbrack$ is exactly the number that should be attached to $i$ -th tuple.

多编号（Multi-number）。给定（键，值）对集合，目标是为每个键$k$的元素分别分配连续编号$1,2,\cdots ,{n}_{k}$，其中${n}_{k}$是该键元素总数。可通过键值归约原语实现：每个元组关联值1，运算符$\oplus$设为+。在派生数组$A,S\left\lbrack  i\right\rbrack$上求解全前缀和后，结果即为应附加到$i$号元组的编号。

Multi-Search. Given ${N}_{1}$ distinct keys and ${N}_{2}$ queries,where $N = {N}_{1} + {N}_{2}$ ,for each query,find its predecessor, i.e., the largest key that is no larger than the query. The multi-search can be solved by the prefix-sum primitive. We first sort all the keys and queries together. Then for each key $k$ , define its corresponding $A\left\lbrack  i\right\rbrack$ as itself; for each query,define its $A\left\lbrack  i\right\rbrack   =  - \infty$ ; define $\oplus   = \max$ . Then it should be obvious that $S\left\lbrack  i\right\rbrack$ is the predecessor of the corresponding query.

多搜索（Multi-Search）。给定${N}_{1}$个互异键和${N}_{2}$个查询（其中$N = {N}_{1} + {N}_{2}$），为每个查询寻找前驱（即不大于该查询的最大键）。可通过前缀和原语实现：先合并排序所有键与查询，对每个键$k$定义其对应$A\left\lbrack  i\right\rbrack$为自身值；对每个查询定义$A\left\lbrack  i\right\rbrack   =  - \infty$；定义$\oplus   = \max$。显然$S\left\lbrack  i\right\rbrack$即为对应查询的前驱键。

Semi-join. Given two relations ${R}_{1}\left( {A,B}\right)$ and ${R}_{2}\left( {B,C}\right)$ ,the target is to find tuples in ${R}_{1}$ that can be joined with at least one tuple in ${R}_{2}$ . The semi-join can be solved by the multi-search primitive. We treat tuples in ${R}_{1}$ as queries and tuples in ${R}_{2}$ as keys. We sort ${R}_{1} \cup  {R}_{2}$ by attribute $B$ . After running the multi-search algorithm,we check for each tuple $t \in  {R}_{1}$ with the attached $A\left\lbrack  i\right\rbrack$ . We keep $t$ if and only if ${\pi }_{B}t = A\left\lbrack  i\right\rbrack$ .

半连接（Semi-join）。给定关系${R}_{1}\left( {A,B}\right)$和${R}_{2}\left( {B,C}\right)$，目标是找出${R}_{1}$中能与${R}_{2}$至少一个元组连接的元组。可通过多搜索原语实现：将${R}_{1}$元组视作查询，${R}_{2}$元组视作键，按属性$B$排序${R}_{1} \cup  {R}_{2}$。执行多搜索算法后，检查每个附带$A\left\lbrack  i\right\rbrack$的元组$t \in  {R}_{1}$，当且仅当${\pi }_{B}t = A\left\lbrack  i\right\rbrack$时保留$t$。

## E PROOF OF OPTIMALITY

## 附录E 最优性证明

- 若${k}_{1} < {m}_{1}$，则从${R}_{2}$中选取${k}_{1}$个元组赋予相同值${b}^{ * }$，其余元组从${\mathbb{D}}_{2}$中选择$B$值。若${k}_{1} > {m}_{1}$，则对${R}_{2}$中所有元组赋予相同值${b}^{ * },{k}_{1} - {m}_{1}$，对${R}_{3}$中元组赋予相同值${b}^{ * }$，其余$2{m}_{2} + {m}_{1} - {k}_{1}$个元组从${\mathbb{D}}_{3}$中选择$B$值。

- If ${k}_{2} < {n}_{2}$ ,we set ${k}_{2}$ tuples from ${S}_{2}$ with the same value ${b}^{ * }$ ,and the remaining ${n}_{2} - {k}_{2}$ tuples from ${S}_{2}$ with $B$ -value chosen from ${\mathbb{D}}_{2}$ . If ${k}_{2} > {n}_{2}$ ,we set all tuples from ${S}_{2}$ with the same value ${b}^{ * },{k}_{2} - {n}_{2}$ tuples from ${R}_{3}$ with the same value ${b}^{ * }$ ,and remaining $2{n}_{1} + {n}_{2} - {k}_{2}$ tuples from ${S}_{3}$ with $B$ -value chosen from ${\mathbb{D}}_{5}$ .

若${k}_{2} < {n}_{2}$，我们从${S}_{2}$中选取${k}_{2}$个具有相同值${b}^{ * }$的元组，其余${n}_{2} - {k}_{2}$个元组从${S}_{2}$中选取，其$B$值选自${\mathbb{D}}_{2}$。若${k}_{2} > {n}_{2}$，我们将${S}_{2}$中所有元组设为相同值${b}^{ * },{k}_{2} - {n}_{2}$，从${R}_{3}$中选取具有相同值${b}^{ * }$的元组，剩余$2{n}_{1} + {n}_{2} - {k}_{2}$个元组从${S}_{3}$中选取，其$B$值选自${\mathbb{D}}_{5}$。

The join instance will be $R = {R}_{1} \cup  {R}_{2} \cup  {R}_{3}$ and $S = {S}_{1} \cup  {S}_{2} \cup  {S}_{3}$ . It can be easily checked that $\left| {R \bowtie  S}\right|  = {\mathrm{{OUT}}}^{\prime }$ . Moreover,any algorithm for computing the join instance $R \bowtie  S$ must also solve the set intersection problem $I$ . Thus,the lower bound $\Omega \left( {\min \left\{  {{m}_{1},{n}_{2}}\right\}  }\right)$ of solving $I$ will be applied to computing any instance $R \bowtie  S$ that conforms to ${\phi }^{\prime }$ and OUT ${}^{\prime }$ .

连接实例将是$R = {R}_{1} \cup  {R}_{2} \cup  {R}_{3}$和$S = {S}_{1} \cup  {S}_{2} \cup  {S}_{3}$。易验证$\left| {R \bowtie  S}\right|  = {\mathrm{{OUT}}}^{\prime }$。此外，任何计算该连接实例$R \bowtie  S$的算法也必须解决集合交集问题$I$。因此，解决$I$的下界$\Omega \left( {\min \left\{  {{m}_{1},{n}_{2}}\right\}  }\right)$将适用于计算所有符合${\phi }^{\prime }$且输出为${}^{\prime }$的实例$R \bowtie  S$。

Let the data distribution constructed in Lemma E. 1 be ${\mathcal{D}}_{1}^{ * }$ . Let the data distribution in $\mathbb{D}\left( {\phi ,\mathrm{{OUT}}}\right)$ that achieves the largest ${C}_{\text{pack }}$ to be ${\mathcal{D}}_{2}^{ * }$ . Let $K$ be the set of boundary keys in ${\mathcal{D}}_{2}^{ * }$ . We construct another data distribution ${\mathcal{D}}_{3}^{ * }$ with initial cardinality distribution ${\phi }^{\prime }$ . More specifically,we simply halve the number of tuples for each key distributed at every compute node. It can be easily checked that ${\phi }_{rv}^{\prime } = \frac{1}{2}{\phi }_{rv}$ and ${\phi }_{sv}^{\prime } = \frac{1}{2}{\phi }_{sv}$ for every $v \in  {V}_{C}$ . Moreover,the output size of this new data distribution is $\frac{1}{4}$ OUT. For simplicity,we assume that ${\mathcal{D}}_{1}^{ * }$ and ${\mathcal{D}}_{2}^{ * }$ have disjoint domain of join keys. Let ${\mathcal{D}}^{ * }$ be the data distribution if putting ${\mathcal{D}}_{1}^{ * }$ and ${\mathcal{D}}_{3}^{ * }$ together. It can be easily checked that ${\mathcal{D}}^{ * }$ conforms to $\phi$ and OUT.

设引理E.1中构建的数据分布为${\mathcal{D}}_{1}^{ * }$，令$\mathbb{D}\left( {\phi ,\mathrm{{OUT}}}\right)$中使${C}_{\text{pack }}$最大化的数据分布为${\mathcal{D}}_{2}^{ * }$。设$K$为${\mathcal{D}}_{2}^{ * }$中的边界键集合。我们构建另一个初始基数分布为${\phi }^{\prime }$的数据分布${\mathcal{D}}_{3}^{ * }$，具体而言，将每个计算节点上分配的键值元组数量减半。易验证${\phi }_{rv}^{\prime } = \frac{1}{2}{\phi }_{rv}$且对所有$v \in  {V}_{C}$满足${\phi }_{sv}^{\prime } = \frac{1}{2}{\phi }_{sv}$。此外，新数据分布的输出规模为$\frac{1}{4}$OUT。为简化起见，假设${\mathcal{D}}_{1}^{ * }$与${\mathcal{D}}_{2}^{ * }$的连接键域互不相交。设${\mathcal{D}}^{ * }$为合并${\mathcal{D}}_{1}^{ * }$和${\mathcal{D}}_{3}^{ * }$后的数据分布，可验证${\mathcal{D}}^{ * }$符合$\phi$且输出为OUT。

LEMMA E.2. Any algorithm needs to incur a cost of $\Omega \left( {{C}_{\text{int }} + \mathop{\max }\limits_{{\mathcal{D} \in  \mathbb{D}\left( {\phi ,\mathrm{{OUT}}}\right) }}{C}_{\text{pack }}}\right)$ for computing the join results of ${\mathcal{D}}^{ * }$ .

引理E.2. 任何算法计算${\mathcal{D}}^{ * }$连接结果时都需要承担$\Omega \left( {{C}_{\text{int }} + \mathop{\max }\limits_{{\mathcal{D} \in  \mathbb{D}\left( {\phi ,\mathrm{{OUT}}}\right) }}{C}_{\text{pack }}}\right)$的成本。

Proof. First,we point out that the computation for ${\mathcal{D}}_{1}^{ * }$ and ${\mathcal{D}}_{3}^{ * }$ are independent,since they have disjoint domain of join keys. Then,any algorithm for computing ${\mathcal{D}}^{ * }$ needs to incur a cost of $\Omega \left( {C}_{\text{int }}\right)$ ,implied by the fact that any algorithm for computing ${\mathcal{D}}_{1}^{ * }$ needs to incur such a cost. In the remaining, we only consider the task of computing the Cartesian products for boundary keys ${\left\{  {R}_{b} \times  {S}_{b}\right\}  }_{b \in  K}$ ,where $K$ is defined by ${\mathcal{D}}_{2}^{ * }$ . It suffices to show that any algorithm for this task needs to incur a cost of $\Omega \left( {C}_{\text{pack }}^{ * }\right)$ ,where ${C}_{\text{pack }}^{ * } = \mathop{\max }\limits_{{\mathcal{D} \in  \mathbb{D}\left( {\phi ,\mathrm{{OUT}}}\right) }}{C}_{\text{pack }}$ .

证明。首先指出，由于${\mathcal{D}}_{1}^{ * }$与${\mathcal{D}}_{3}^{ * }$的连接键域互不相交，二者的计算是相互独立的。因此，任何计算${\mathcal{D}}^{ * }$的算法都必然产生$\Omega \left( {C}_{\text{int }}\right)$的成本——这一结论源自计算${\mathcal{D}}_{1}^{ * }$所需的最低成本。下文将仅针对边界键${\left\{  {R}_{b} \times  {S}_{b}\right\}  }_{b \in  K}$的笛卡尔积计算任务展开分析，其中$K$由${\mathcal{D}}_{2}^{ * }$定义。只需证明该任务的任何算法都需承担$\Omega \left( {C}_{\text{pack }}^{ * }\right)$的成本（其中${C}_{\text{pack }}^{ * } = \mathop{\max }\limits_{{\mathcal{D} \in  \mathbb{D}\left( {\phi ,\mathrm{{OUT}}}\right) }}{C}_{\text{pack }}$）即可完成论证。

Consider an optimal algorithm $\mathbb{A}$ for this task,and fix some $b \in  K$ . Since this algorithm correctly computes ${R}_{b} \times  {S}_{b}$ ,each compute node in ${V}_{C}$ must be responsible to produce some pair from the Cartesian product. W.l.o.g., we can assume that these are disjoint (otherwise we can tweak the algorithm to produce disjoint results without increasing the cost). Now,for a ${G}_{\alpha }^{j}$ tree,let ${g}_{b,j}\left( \mathbb{A}\right)$ be the set of tuple pairs assigned to the compute nodes in ${G}_{\alpha }^{j}$ . Note that in this case,the tree is responsible to compute a fraction ${\widehat{f}}_{b,j}\left( \mathbb{A}\right)  = \frac{\left| {g}_{b,j}\left( \mathbb{A}\right) \right| }{\left| {R}_{b}\right|  \cdot  \left| {S}_{b}\right| }$ of the Cartesian product. Since our protocol iterates over all possible fractional allocations, it will also consider the solution for which ${f}_{b,j} = {\widehat{f}}_{b,j}\left( \mathbb{A}\right)$ .

设$\mathbb{A}$是该任务的最优算法，固定某个$b \in  K$。由于该算法需正确计算${R}_{b} \times  {S}_{b}$，${V}_{C}$中的每个计算节点必须负责生成笛卡尔积的若干元组对。不失一般性，可假设这些分配互不重叠（否则可通过调整算法在不增加成本的前提下实现结果分离）。对于${G}_{\alpha }^{j}$树结构，令${g}_{b,j}\left( \mathbb{A}\right)$表示分配给该树计算节点的元组对集合。此时该树负责计算笛卡尔积的${\widehat{f}}_{b,j}\left( \mathbb{A}\right)  = \frac{\left| {g}_{b,j}\left( \mathbb{A}\right) \right| }{\left| {R}_{b}\right|  \cdot  \left| {S}_{b}\right| }$比例部分。由于本协议会遍历所有可能的分配比例，必然包含${f}_{b,j} = {\widehat{f}}_{b,j}\left( \mathbb{A}\right)$对应的解。

Conditioning on the lower bound from set intersection, we first argue one important property:

基于集合交的下界条件，我们首先论证一个重要性质：

- The input data already sitting at the compute nodes does not help the computation.

- 计算节点本地存储的输入数据对当前计算无实质性帮助

- For ${\overrightarrow{G}}_{\alpha }^{j}$ ,it is always more load-efficient for computing ${g}_{b,j}\left( \mathbb{A}\right)$ as a contiguous rectangle such that the dimensions are as close as possible (without exceeding the smaller $\left| {R}_{b}\right|$ ).

- 对${\overrightarrow{G}}_{\alpha }^{j}$而言，将${g}_{b,j}\left( \mathbb{A}\right)$计算为边长尽可能接近（且不超过较小$\left| {R}_{b}\right|$值）的连续矩形时，负载效率始终更高

Consider an arbitrary directed $\alpha$ -tree ${\overrightarrow{G}}_{\alpha }^{j}$ rooted at $r$ . Let ${g}_{b,r} = {g}_{b,j}$ ,and ${g}_{b,v}$ be the number of pairs emitted by $v$ for key $b$ . Let ${x}_{b,v},{y}_{b,v}$ be the number of $R$ -tuples, $S$ -tuples received by node $v$ under $\mathbb{A}$ . Let ${R}_{b,v},{S}_{b,v}$ be the number of $R$ -tuples, $S$ -tuples with key $b$ ,distributed over the subtree rooted at $v$ . We consider the following non-linear integer program:

设${\overrightarrow{G}}_{\alpha }^{j}$是以$r$为根的任意有向$\alpha$树。令${g}_{b,r} = {g}_{b,j}$，${g}_{b,v}$分别表示$v$节点针对键$b$生成的元组对数量。${x}_{b,v},{y}_{b,v}$表示$\mathbb{A}$协议下$v$节点接收的$R$元组与$S$元组数量，${R}_{b,v},{S}_{b,v}$则为分布在$v$子树内、键值为$b$的$R$元组与$S$元组总数。建立如下非线性整数规划模型：

min $L$

最小化 $L$

$$
\text{s.t.}\;\left| {R}_{b}\right|  \cdot  \left| {S}_{b}\right|  = {g}_{b,r},\;b \in  K\text{,}
$$

$$
\mathop{\sum }\limits_{{u \in  {\mathcal{L}}_{v}}}{g}_{b,u} = {g}_{b,v},\;b \in  K,v \in  V,
$$

$$
\mathop{\sum }\limits_{{b \in  K}}\left( {{x}_{b,v} + {y}_{b,v}}\right)  \leq  L \cdot  {w}_{v},\;v \in  V \smallsetminus  \{ r\} ,
$$

$$
\left( {\left| {R}_{b,v}\right|  + {x}_{b,v}}\right) \left( {\left| {S}_{b,v}\right|  + {y}_{b,v}}\right)  \geq  {g}_{b,v},\;b \in  K,v \in  V \smallsetminus  \{ r\} , \tag{7}
$$

$$
\left| {R}_{b,v}\right|  + {x}_{b,v} \leq  \left| {R}_{b}\right| ,\;b \in  K,v \in  V \smallsetminus  \{ r\} ,
$$

$$
\left| {S}_{b,v}\right|  + {y}_{b,v} \leq  \left| {S}_{b}\right| ,\;b \in  K,v \in  V \smallsetminus  \{ r\} ,
$$

$$
\mathop{\sum }\limits_{{b \in  B}}\left( {\left| {R}_{b,v}\right|  + \left| {S}_{b,v}\right| }\right)  \leq  L \cdot  {w}_{v},\;v \in  V \smallsetminus  \{ r\} ,
$$

$$
{g}_{b,v},{x}_{b,v},{y}_{b,v} \in  {\mathbb{Z}}^{ * },\;v \in  V \smallsetminus  \{ r\} 
$$

The optimal solution of the above program provides a lower bound for the cost of computing the Cartesian pairs inside the $\alpha$ -tree. We relate it to (1) as follows: every solution of (1) with $\operatorname{cost}L$ can be transformed into a solution of (7) with cost at most ${2L}$ . From ${x}_{b,v},{y}_{b,v}$ ,we can simply set ${x}_{b,v}^{\prime } = \left| {R}_{b,v}\right|  + {x}_{b,v}$ and ${y}_{b,v}^{\prime } = \left| {S}_{b,v}\right|  + {y}_{b,v}$ satisfying all constraints. Hence,it suffices to find the optimal solution of (1), which is a constant-approximation of the optimal solution of (7). This means that we can w.l.o.g. consider protocols that ignore the local input data, as our protocol class does.

上述规划的最优解为计算$\alpha$树内笛卡尔积对的开销提供了下界。其与问题(1)的关联如下：任何满足$\operatorname{cost}L$的问题(1)解均可转化为问题(7)的解，且转化成本不超过${2L}$。根据${x}_{b,v},{y}_{b,v}$，我们只需设定满足所有约束的${x}_{b,v}^{\prime } = \left| {R}_{b,v}\right|  + {x}_{b,v}$和${y}_{b,v}^{\prime } = \left| {S}_{b,v}\right|  + {y}_{b,v}$即可。因此，只需找到问题(1)的最优解——该解是问题(7)最优解的常数倍近似解。这意味着我们可以不失一般性地考虑忽略本地输入数据的协议，正如本协议类所做的那样。

Next,we will reason about the optimal shape of the ${g}_{b,j}$ area. It is easy to see that an optimal algorithm will always organize ${g}_{b,j}$ such that it forms a contiguous rectangle. Hence,we need to show that the optimal strategy will attempt to make the rectangle as close to a square as possible (will keeping the same area). Indeed, consider a slightly different non-linear integer program of (1), such that $\left| {R}_{b}\right|  < \left| {R}_{b}^{\prime }\right|  \leq  \left| {S}_{b}^{\prime }\right|  < \left| {S}_{b}\right|$ with $\left| {R}_{b}^{\prime }\right|  \cdot  \left| {S}_{b}^{\prime }\right|  = \left| {R}_{b}\right|  \cdot  \left| {S}_{b}\right|$ .

接下来我们将论证${g}_{b,j}$区域的最优形状。显然，最优算法总会将${g}_{b,j}$组织成连续矩形。因此需要证明：在保持面积不变的前提下，最优策略会使矩形尽可能接近正方形。现考虑问题(1)的变体非线性整数规划，其中$\left| {R}_{b}\right|  < \left| {R}_{b}^{\prime }\right|  \leq  \left| {S}_{b}^{\prime }\right|  < \left| {S}_{b}\right|$需满足$\left| {R}_{b}^{\prime }\right|  \cdot  \left| {S}_{b}^{\prime }\right|  = \left| {R}_{b}\right|  \cdot  \left| {S}_{b}\right|$。

min $L$

最小值 $L$

$$
\text{s.t.}\;\left| {R}_{b}^{\prime }\right|  \cdot  \left| {S}_{b}^{\prime }\right|  = {g}_{b,r},\;b \in  K\text{,}
$$

$$
\mathop{\sum }\limits_{{u \in  {\mathcal{L}}_{v}}}{g}_{b,u} = {g}_{b,v},\;b \in  K,v \in  V,
$$

$$
\mathop{\sum }\limits_{{b \in  K}}\left( {{x}_{b,v} + {y}_{b,v}}\right)  \leq  L \cdot  {w}_{v},\;v \in  V \smallsetminus  \{ r\} , \tag{8}
$$

$$
{x}_{b,v} \cdot  {y}_{b,v} \geq  {g}_{b,v},\;b \in  K,v \in  V \smallsetminus  \{ r\} ,
$$

$$
{x}_{b,v} \leq  \left| {R}_{b}^{\prime }\right| ,{y}_{b,v} \leq  \left| {S}_{b}^{\prime }\right| ,\;b \in  K,v \in  V \smallsetminus  \{ r\} ,
$$

$$
{g}_{b,v},{x}_{b,v},{y}_{b,v} \in  {\mathbb{Z}}^{ * },\;b \in  K,v \in  V \smallsetminus  \{ r\} 
$$

Any solution of (1) with cost $L$ can be transformed into another solution of (8) with cost at most $L$ . Consider an arbitrary pair of(b,v). First, ${x}_{b,v} \leq  \left| {R}_{b}\right|  \leq  \left| {R}_{b}^{\prime }\right|$ always holds. If ${y}_{b,v} \leq  \left| {S}_{b}^{\prime }\right|$ ,we just set ${x}_{b,v}^{\prime } = {x}_{b,v}$ and ${y}_{b,v}^{\prime } = {y}_{b,v}$ . Otherwise,we set ${x}_{b,v}^{\prime } = \frac{{x}_{b,v} \cdot  {y}_{b,v}}{\left| {S}_{b}^{\prime }\right| }$ and ${y}_{b,v}^{\prime } = \left| {S}_{b}^{\prime }\right|$ . It is obvious that ${x}_{b,v}^{\prime } < \left| {R}_{b}^{\prime }\right|$ since ${x}_{b,v} \cdot  {y}_{b,v} \leq  \left| {R}_{b}\right|  \cdot  \left| {S}_{b}\right|  = \left| {R}_{b}^{\prime }\right|  \cdot  \left| {S}_{b}^{\prime }\right|$ . Moreover, ${x}_{b,v} + {y}_{b,v} \geq  {x}_{b,v}^{\prime } + {y}_{b,v}^{\prime }$ ,since ${x}_{b,v} \cdot  {y}_{b,v} = {x}_{b,v}^{\prime } \cdot  {y}_{b,v}^{\prime }$ and ${x}_{b,v} \leq  \left| {R}_{b}\right|  < \left| {R}_{b}^{\prime }\right|  \leq  \left| {S}_{b}^{\prime }\right|  < {y}_{b,v} \leq  \left| {S}_{b}\right|$ . Thus,the optimal solution of (8) always has a smaller cost than that of (1).

任何成本为$L$的问题(1)解均可转化为问题(8)的解，且转化成本不超过$L$。任取(b,v)对时：首先，${x}_{b,v} \leq  \left| {R}_{b}\right|  \leq  \left| {R}_{b}^{\prime }\right|$恒成立。若${y}_{b,v} \leq  \left| {S}_{b}^{\prime }\right|$，则直接设定${x}_{b,v}^{\prime } = {x}_{b,v}$与${y}_{b,v}^{\prime } = {y}_{b,v}$；否则设定${x}_{b,v}^{\prime } = \frac{{x}_{b,v} \cdot  {y}_{b,v}}{\left| {S}_{b}^{\prime }\right| }$和${y}_{b,v}^{\prime } = \left| {S}_{b}^{\prime }\right|$。由于${x}_{b,v} \cdot  {y}_{b,v} \leq  \left| {R}_{b}\right|  \cdot  \left| {S}_{b}\right|  = \left| {R}_{b}^{\prime }\right|  \cdot  \left| {S}_{b}^{\prime }\right|$，显然有${x}_{b,v}^{\prime } < \left| {R}_{b}^{\prime }\right|$。又因${x}_{b,v} \cdot  {y}_{b,v} = {x}_{b,v}^{\prime } \cdot  {y}_{b,v}^{\prime }$和${x}_{b,v} \leq  \left| {R}_{b}\right|  < \left| {R}_{b}^{\prime }\right|  \leq  \left| {S}_{b}^{\prime }\right|  < {y}_{b,v} \leq  \left| {S}_{b}\right|$，故${x}_{b,v} + {y}_{b,v} \geq  {x}_{b,v}^{\prime } + {y}_{b,v}^{\prime }$。因此问题(8)的最优解成本恒低于问题(1)。

Conditioning on the lower bound from set intersection, it is safe to assume that for each directed $\alpha$ -tree ${\overrightarrow{G}}_{\alpha }^{j}$ ,the whole set of $R$ set as well as the $S$ -tuples initially distributed at the compute nodes residing at ${\overrightarrow{G}}_{\alpha }^{j}$ . Now,we need to argue the last important property:

基于集合交集中的下界条件，可以合理假设对于每个有向$\alpha$树${\overrightarrow{G}}_{\alpha }^{j}$，整个$R$集合以及最初分布在${\overrightarrow{G}}_{\alpha }^{j}$计算节点上的$S$元组。现在，我们需要论证最后一个重要性质：

- it is also efficient for redistributing the $S$ -tuples across the leaf nodes of $\beta$ -tree,i.e.,the root nodes of directed $\alpha$ -trees,when ${g}_{b,j}\left( \mathbb{A}\right)$ is a contiguous rectangles with the two dimensions as close as possible.

- 该方法还能高效地在$\beta$树的叶节点（即有向$\alpha$树的根节点）之间重新分配$S$元组，当${g}_{b,j}\left( \mathbb{A}\right)$是长宽尽可能接近的连续矩形区域时。

Consider any edge $e \in  {G}_{\beta }$ . Recall that ${\mathcal{L}}_{\beta }$ is the set of leaf nodes of ${G}_{\beta }$ . Assume some $S$ -tuples need to be transferred from ${G}_{e}^{ + } \cap  {\mathcal{L}}_{\beta }$ to ${G}_{e}^{ - } \cap  {\mathcal{L}}_{\beta }$ . It can be easily checked that the total number of $S$ -tuples redistributed over ${G}_{e}^{ - } \cap  {\mathcal{L}}_{\beta }$ is minimized when ${g}_{b,j}$ is a contiguous rectangles with the two dimensions as close as possible,thus the tuple differential ${\Delta }_{e}$ is also minimized correspondingly.

考虑任意边$e \in  {G}_{\beta }$。回顾${\mathcal{L}}_{\beta }$是${G}_{\beta }$的叶节点集合。假设需要将某些$S$元组从${G}_{e}^{ + } \cap  {\mathcal{L}}_{\beta }$传输到${G}_{e}^{ - } \cap  {\mathcal{L}}_{\beta }$。容易验证，当${g}_{b,j}$是长宽尽可能接近的连续矩形时，通过${G}_{e}^{ - } \cap  {\mathcal{L}}_{\beta }$重新分配的$S$元组总数最小，因此元组差分${\Delta }_{e}$也相应最小化。
